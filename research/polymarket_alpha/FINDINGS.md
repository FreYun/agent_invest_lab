## 1. 方法论纪律（本轮建立并守住）

1. **PIT 防未来函数**：信号一律 `shift(1)`；美股 `extra_lag=1` 再滞后一日（时区保守）。有真实数据回归测试守着。
2. **样本 < 2 年 → 不挑最优、不算 Sharpe、不做 monte_carlo/bootstrap**（p 值/CI 不可靠）。
3. **以 diff 版为准，level 版仅参考**——所有 macro_factor 序列在样本内单调趋势，level 相关几乎全是趋势假象（level |IC| 均值 0.205 → diff 后 0.138）。
4. **诚实标注**：全部结论标 as-of / source / n；禁止"显著/生产因子"越界措辞。

## 3. 方法论级发现（比任何单因子都值钱）

1. **去趋势必备**：level 版几乎全是趋势假象。以 diff / pct60 为准。
2. **分位状态（pct60）> 差分 > 水平**：hormuz 从 |IC| 0.11（水平）→ 0.42（分位）。分位状态自动消绝对水位漂移，**对尾部/事件类因子特别有效**。
3. **子分组 > 综合**：geo_only 0.43 > tail_composite 0.23 > econ_only 0.09。不同性质因子混一起会稀释。
4. **前后半切分必做**：tail_composite 上一轮 |IC|=0.23 隐藏了 0.28 → 0.12 的衰减。SOP 步骤 7 的 walk-forward 不能省。
5. **概率变化率 > 概率水平**（对尖峰事件）：hormuz 从 0.10（水平）→ 0.44（diff5）。
6. **PCA 在非平稳序列上不可信**：PC2 |IC| 0.81 数字漂亮但样本内跨时段稳定性未验证、载荷靠单一 tail 因子主导。
7. **组合信号需经济逻辑约束**：geo_only 稳、recession_hawkish 乱——区别在同性质相加 vs 异性质硬拼。

## 4. 对 A 股 / 美股投资的实用建议

### 现在可以用

给 bot101~103（大类资产配置）加**宏观状态 dashboard**，PIT 只读输入这 4 条：
1. `geo_only` z-score（当前值 + 5日变化）
2. `hormuz_normal` 60日分位
3. `recession_2026` 水平（+ diff5 突变告警）
4. `btc_dip_50k_2026` 水平（+ diff5 跳降告警 → QQQ/成长股关注）

**用法必须按 SOP 诚实纪律**：只报读数、不写死"概率>X 就砍仓 Y%"这种没回测过的硬规则，让 bot 自己在推理里参考。

### 不能做

- 任何机械择时因子（|IC|<0.2 中位、样本 <2 年、单一 regime）
- 直接交易 Polymarket 合约（现有数据不支持定价错误发现）
- 相信 PCA 主成分作为择时（PC2 是本轮最漂亮的陷阱）

### 下一轮再做

- **等 6~12 个月**让 systemd timer 攒够 leaderboard/holders：
  - 大户 vs 散户持仓方向背离 → 情绪 contrarian
  - Top PnL wallet 净流方向 → 抢跑信号
  - 极值事件研究法（现在 n=6，样本够时可能决定性）
- **等下一段"风险抬升+股市跌"窗口**出现，重跑本轮所有信号看方向是否反过来——**这是唯一能把 hint 升到有信心的路径**

## 5. 盲区与警告

- **样本 1 年、单一 regime**：所有 |IC| 0.3~0.8 的数字都可能是"风险释放+股市涨"的单趋势副产品。
- **前后半衰减普遍存在**：tail_composite 已实测，geo_only 强烈怀疑类似（未测）。
- **PCA 陷阱**：非平稳序列做 PCA，第二主成分往往捕捉次强趋势而非真正正交因子。
- **fed_no_cut 反向 IC = 共因子伪相关**：加息预期升温和股市涨都是"经济好"的果，不是因果。
- **地缘尾部事件基率低**：hormuz/pandemic/iran 类因子 n 小、噪声大、样本外行为未知。

## 6. 最诚实的一句

**这个库现在的价值是"宏观预期数字化的只读仪表盘"，不是量化 α 来源。**

- 挖了 40+ 条信号变体，有一批 |IC| 数字很漂亮，但样本 1 年、单一 regime、多条前后衰减、几条最强的很可能是共因子伪相关或 PCA 陷阱。
- 唯一真正独特的东西（聪明钱链上流）**数据才刚开始积累**，本轮不能验证。
- 本轮最大产出**不是任何单条信号**，而是**"因子挖掘 SOP + 采集管道 + 检验工具"这一整套沉淀成了可复用代码**。等聪明钱数据攒够，把它接进 `run_scan.py`，就能立刻跑同样的检验、快速出下一轮结论。

### 📌 9 个有效信号 · 适用标的与最强 horizon

每信号列 top4 最强 (target × horizon) 组合，用于判断"该盯哪个资产、什么时间窗看"。

**如何读一行结果**（以 `geo_only, target=000300.SH, h=20, IC=−0.377, n=193` 为例）：
- `h`（horizon）= **信号发出后向前看多少个交易日的收益**。h=20 就是"预测未来 20 日"，也可近似当作策略的**理论持有天数**。
- `IC`（Spearman 秩相关）= 当日信号排名 vs 未来 h 日收益排名的相关性，值域 [−1, +1]。
  - **符号**：`−` = 反向（信号↑→收益↓），`+` = 正向。
  - **绝对值**：≈ 能解释未来收益排序方差的 `IC²`（如 0.377² ≈ 14%），剩下 86% 是噪声/其他因子。
  - 换算胜率：|IC|=0.10 → 约 55% 胜率；|IC|=0.30 → 约 60% 胜率；|IC|=0.80 → 几乎肯定有 bug。
- `n` = 参与相关计算的重叠交易日对数，n 越大结论越稳。

**|IC| 数值档位**（详见 §8）：
- **0.02–0.05** = 产线基线好因子（对冲基金多在此档）
- **0.05–0.10** = 强因子
- **> 0.10** = 要警惕（本轮多数信号在这，很可能样本内偏高）
- **> 0.30** = 数字"太漂亮"，须警觉共因子伪相关 / 单趋势 / PCA 陷阱

**关键提醒**：本表所有 IC 都是**样本内**且**单一 regime**（1 年，风险释放期），未做样本外/跨 regime 验证。数值只反映"这一年信号与收益的排序关系"，**不代表预测未来的能力**。使用时须叠加：跨标的一致性 ≥3、跨前后半年不衰减、经济逻辑成立——三者兼备才算 hint。

**共同模式**：**预测市场"恐慌解除"信号（BTC 崩盘↓/衰退担忧↓/Fed 意外鹰派↑，都对应"经济基本面变强")→ 未来 5 日股市有 1~3pp 超额**。方向完全一致（除 fed_no_cut 反向，但符合"经济好"共因子解读）。

**为什么这可能是"很好的信号"**：
- **方向完全统一**：3 个不同类因子在 6 组标的×方向组合上零反例
- **经济逻辑清晰**：预测市场比股市更早对"恐慌解除"定价——理论上聪明钱先动
- **可以做成明确的交易规则**：只在极值日触发（低频），避免日常噪音
- **对下轮聪明钱数据是关键验证方向**：如果 leaderboard/holders 里能看到极值日前 top wallet 净流方向一致，就是硬证据

**为什么现在还不能直接用**：
- **n = 6~13 太小**，SOP 红旗直接毙掉（要 n ≥ 30 才能声称）
- 都发生在**一年内、单一 regime**（风险释放年），下一段"风险抬升期"没验证
- 极值日本身就少（每因子 5% 分位一年才 12 天），需多年积累才有统计意义

**建议观察方式**：把这 3 条规则写成 alerts.log，从今天起每次某因子 |dchg| 突破阈值就自动记一条"事件日 + 5 日后市实际"，样本自然攒大。等 n 到 30+ 再考虑升格。

**统计**：27 个因子/组合中，**9 个进入"有效"档**（其中 4 个本轮新构造：geo_only / hormuz_pct60 / PC3 / taiwan_pct60），15 个明确无效，3 个样本不足。⚠️ 标记的（fed_no_cut 反常方向、PC2 PCA 陷阱）虽然数字达标但不敢用。

## 8. IC 数值参考档位（Spearman，日频信号 vs 前向收益）

| \|IC\| 中位数 | 档位 | 说明 |
|---|---|---|
| < 0.02 | 噪声 | 统计显著但没用 |
| **0.02–0.05** | **量化产线基线** | 顶级对冲基金单因子跑到这一档就是好因子 |
| 0.05–0.10 | 强因子 | 少见，通常靠信息优势 |
| **> 0.10** | **要警惕** | 大概率过拟合 / 未来函数 / 幸存者偏差 / 样本太小 |
| > 0.20 | 几乎肯定有问题 | 除非样本外能复现，否则先假设是 bug |

**关键**：时间序列 IC（本轮做法）比横截面 IC 更"虚"，因趋势/regime 影响大——同期两条趋势线自然高相关。**稳健性比数值更重要**：|IC|=0.05 跨 5 标的都同号 + 跨前后半年一致，比 |IC|=0.20 单标的单时段有用得多。SOP struct_flag 用**一致性**卡门槛（同号率 ≥ 0.75、|IC| 中位 ≥ 0.10），不是数值门槛。
