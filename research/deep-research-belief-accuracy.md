# 单指数深度研究 d-bot 观点(belief)准确性评估

> 由 `scripts/analyze_belief_accuracy.py` 生成，可复现。

## 方法

- **观点来源**：每个 d-bot 每日 `reply` 末尾的 ```yaml belief``` 块，给出 target_index 在 t+1 / t+5 / t+20 的上涨概率 `p_up`。

- **实际涨跌**：bot 当日持仓基金(取市值最大者，空仓日用该 run 主基金兜底)的 NAV 前向收益，>0 记为上涨。数据取自 `fund_nav`。

- **指标**：命中率(`p_up>0.5` 判涨 vs 实际，剔除 `p_up=0.5` 无方向样本)、Brier 分(概率校准误差，越小越好；恒报 0.5 的基线=0.25)、校准分桶、方向性偏差(均值 p_up vs 实际上涨率)。**方向拆分(看涨/看跌)用严格口径**：`p_up ≥ 0.6` 才算明确看涨、`p_up ≤ 0.4` 才算明确看跌，中间温和倾向不计入方向表态(详见第五节)。

- **是否深研**：以当日 tool_trace 是否调用 `start_research`/`expand_research_phase`(研究循环)判定「开了深度模式」。据此把日子分为深研日/非深研日，见第二节——这是本报告的核心口径。

- **样本**：5 个单指数 d-bot 各取最长、belief 覆盖最全的主回测 run。总打分样本 **3381** 条(bot×日×horizon)，其中深研日 **892** 条。

## 二、只看「开了深度研究」的日子(核心)

## 五、看涨 vs 看跌分开统计（严格口径：只算明确表态）

**严格阈值**：`p_up ≥ 0.6` 才算**明确看涨**、`p_up ≤ 0.4` 才算**明确看跌**；中间温和倾向(0.4 < p_up < 0.6)全部剔除——那不算 agent 明确表态。看涨命中 = 实际涨(y=1)；看跌命中 = 实际跌(y=0)。


### 5.1 分布：多少条 belief 是「明确表态」

agent 大多数日子的 belief 都挤在中间温和区间(50% 左右)，明确表态其实很少：

| horizon | 明确看涨(≥0.6) | 中间(0.4~0.6) | 明确看跌(≤0.4) | 总样本 |
|---|---:|---:|---:|---:|
| t+1 | 55 (4.8%) | 943 (82.6%) | 144 (12.6%) | 1142 |
| t+5 | 66 (5.8%) | 951 (83.5%) | 122 (10.7%) | 1139 |
| t+20 | 82 (7.5%) | 917 (83.4%) | 101 (9.2%) | 1100 |

**观察**：明确看跌的次数**普遍多于**明确看涨——bot 在深研时更敢空、不敢多；但绝大多数日子(~80%)仍是中间温和倾向，没有旗帜鲜明表态。


### 5.2 严格口径命中率(全部 bot 合并)

`平均前向收益` = 该方向所有样本标的 NAV 的 t+N 收益均值。有方向预测力时，明确看涨样本的平均收益应显著高于明确看跌样本(spread>0)。

| horizon | 明确看涨 n | 命中率 | 平均前向收益 | 明确看跌 n | 命中率 | 平均前向收益 | 收益差(涨-跌) |
|---|---:|---:|---:|---:|---:|---:|---:|
| t+1 | 55 | 63.6% | +0.31% | 144 | 41.7% | +0.21% | +0.10pp |
| t+5 | 66 | 69.7% | +0.96% | 122 | 42.6% | +1.01% | -0.05pp |
| t+20 | 82 | 54.9% | +1.43% | 101 | 14.9% | +5.57% | -4.14pp |

**这是本节最重要的表**——直接回答「agent 在深度研究时给出明确方向表态，准不准」：

| horizon | 明确看涨 n | 命中率 | 平均前向收益 | 明确看跌 n | 命中率 | 平均前向收益 | 收益差(涨-跌) |
|---|---:|---:|---:|---:|---:|---:|---:|

**读法**：深研时的明确看涨样本很少(11~23 条)但命中率还不错(≈60%)；**明确看跌样本多得多(30~51 条)、命中率却全线崩盘**——t+5 只对 22.7%、t+20 只对 10%(30 条对了 3 条)。「说跌实涨」的日子平均涨 +2.7% ~ +8.4%，越长视界反指越狠。深研的明确看跌信号是**负 alpha**，印证既有定论「看空只降杠杆、永不反向」——因为看空越坚决越会打脸。


### 5.4 分**指数**(严格口径，按 run 权威绑定聚合)

**为什么按指数而不是按 bot 分**：agent 和指数**不绑定**——同一个 bot 可能被跑在多个 run 上、各自绑不同指数；belief 里 bot 自己写的 `target_index` 还会漂移(bot16d 1 天写 hs300、bot20d 1 天写 930632.CSI)。指数归类只能读 run 的 `strategy-assignments.json`。本节的 5 个 run 恰好分别绑到 5 个不同指数，所以按指数聚合的样本数≈按 bot 聚合，但**读的时候要以指数视角看**——这些数字反映该指数在该 run 里的判断风格，不代表该 bot 在其他 run 的表现。

## 七、关键发现

0. **深度研究没换来更准的观点，且课题设计不背锅(直接回答)**：只看开了深度模式的 302 天，t+5 命中率 47.6% 反而**低于**非深研日的 52.1%；t+5 深研日方向收益差 -1.70pp(非深研日 +0.90pp)、t+20 深研日 -7.90pp。第六节的课题打标显示题目本身 73.7% 是明确择时问题、macro_only=0%，设计并没有跑题——问题出在 bot 的**判断风格**(见发现 4/5)，不是研究命题上。

6. **列多空对比会显著提升准确性(可操作发现)**：第六节里 competing=True 的日子，t+5 命中 57.1%、t+20 命中 60.8%，显著高于不列多空的 44.6% / 37.8%，与整体「无预测力」形成鲜明对比。这暗示改进方向不是加深研次数，而是**在提示词里强制 belief 前先写多空 checklist**。

1. **短周期近似掷硬币，长周期系统性看反**：t+1 命中 52.1%、t+5 51.0%，仅略高于 50%；t+20 命中骤降到 43.4%，而同期实际上涨率高达 62.4%——即长周期里无脑看涨都远好于 bot 的方向判断。

2. **概率预测无增量信息**：三个 horizon 的 Brier 分(0.255/0.253/0.262)均 ≥ 恒报 0.5 的基线 0.25，说明 p_up 的高低并不能区分涨跌。

3. **看多不足 vs 上行行情**：t+20 均值 p_up=0.506(仅中性略偏多)明显低于实际上涨率 62.4%，bot 深研结论偏保守、未充分看多，而标的基金在窗口内多数上涨，这是长周期命中率崩塌的主因。

4. **明确表态严格口径：深研时敢明确看跌、且明确看跌是反指**：深研日「明确看跌 (p_up≤0.4)」样本数 44(t+5) / 30(t+20)，远多于「明确看涨 (p_up≥0.6)」的 17 / 23 条；命中率却触底——t+5 明确看跌命中 **22.7%**、t+20 明确看跌命中 **10.0%**(30 条对了不到几条)；「说跌实涨」的日子平均涨 +2.74% / +8.38%。这直接支撑既有定论「看空只降杠杆、永不反向」——**深研越明确看跌越会打脸**。相反明确看涨那少数几条(t+5 命中 64.7%)是全表唯一稳定的方向 alpha。

5. **bot 间分化**：t+5 相对基线，`bot16d` 最好(Brier 优势 +0.82pp)，`bot10d` 最差(-2.33pp)，但整体都在基线附近，无稳定 alpha。


> 口径说明：实际涨跌用「当日持仓基金」而非 belief 的 target_index 收盘价，对做过指数轮动的 bot(如 bot16d/bot20d)属近似；空仓日用最近一次持仓基金前后填充。这会带来轻微跟踪误差，但不改变「无显著预测力」的定性结论。
