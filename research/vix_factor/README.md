# VIX 极值加仓时点因子（50ETF VIX）

研究部第 3 轮因子挖掘，照 [SOP_factor_mining.md](../SOP_factor_mining.md) 走。目标：用 simworld 的
VIX 数据，为 **沪深300 / 中证1000 / 双创50** 找一个鲁棒的**加仓时点**因子。

## 最终结论（一句话）

**VIX 给不出一个可包装的鲁棒加仓时点因子 —— 不包装。** 信号确实存在（恐慌大底是好的加仓点），但
它只集中在罕见的急性尖峰里、单次高方差、且事件太稀疏无法通过严格 OOS 验证；连续高功效版证明
VIX 的择时信息在尾部之外为零。曾误包装过 `market_vix_add_z15_h10`，严格 IS/OOS 后**已回滚**。

完整证据链见下方"三轮挖掘"。下面"结论（一句话）"及之后是**第 1 轮**的（已被推翻的）乐观记录，保留作
踩坑存档。

## 三轮挖掘小结

| 轮次 | 做法 | 脚本 | 结论 |
|---|---|---|---|
| 1 | base+add overlay，全样本 sweep vs buyhold | `vix_sweep.py` `robustness.py` `validate.py` | **假阳性**：z=1.5"内部最优"是全样本选参；"赢"实为 base=0.5 在 2018/2022 熊市半仓减暴露 + 选参偏差，非择时 |
| 2 | 稀有二元触发，严格 IS/OOS + 防接飞刀过滤 | `is_oos.py` `mine2.py` | 剥离暴露后**纯择时 alpha IS+OOS 都为正**，但 VIX 尖峰稀有，OOS 2.4 年每标的仅 6 个事件，**功效不足**；vixroll（等回落）OOS 死 |
| 3 | **连续日度暴露调节（高功效）**，两个方向 | `mine3.py` | **连续体里没有择时 alpha**（IS ΔSharpe 最高 +0.002），edge 只在尾部尖峰 → 确证 VIX 无法给连续可验证因子 |

| 4-7 | 用对镜头：两尾稀有极值 contrarian + regime 节奏 | `mine4-7.py` | **狂热尾(极低VIX→减仓)是更稳的一半**(IS+OOS+跨标的方向一致负)；恐慌尾 regime 依赖；**回弹节奏验证**：牛市恐慌前置(5日兑现74%)、熊市恐慌后置(5日仅26%、大头40-60日)→ holding 自适应(牛20/熊60)把恐慌尾 IS 从~0 拉到+4.5% |

**第 4-7 轮翻案**：第 1/3 轮的"不可包装"结论用错了镜头（拿稀有事件因子去比全策略 buyhold / 测连续 alpha）。
按"稀有两尾极值 contrarian"正确评估后：**狂热尾（z<-1.5 自满→减仓）逻辑硬、IS+OOS+跨标的一致；恐慌尾
（z>1.5）regime 依赖但节奏可建模**——牛市前置快弹、熊市后置滞后弹（已 backtest 验证，非拍脑袋），
regime 自适应持有窗口（牛市~20日/熊市~60日）显著改善。仍是单次高方差的第二意见信号。

**关键教训**（已可写入 SOP）：
0. **稀有极值因子要用对镜头**：它本就 ~85% 时间沉默，别拿"打不打得过 buyhold 全策略 / 连续 alpha"判它；
   应看"发声时方向对不对 + 跨标的一致 + 经济逻辑"。两尾都要测（恐慌加 / 狂热减）。
1. 用 base<1 的 overlay 和 buyhold 比，会把"减暴露"误当"择时"——必须比**等暴露常数仓 / 看 Sharpe 差**。
2. 稀有事件因子（VIX 尖峰、申赎极值）OOS 天生功效不足；想验证就做**连续高功效版**，连续版没 alpha = 没有可验证因子。
3. 全样本挑"最优参数"必然乐观；IS 选参后 IS 最优点会移动（这里 z 从 1.5 → 1.75）。

## 经济逻辑与事件研究

期权市场定价的系统性恐慌（VIX 尖峰）通常对应阶段性踩踏/资金恐慌，随后均值回归反弹 → 加仓时点。

[event_study2.py](event_study2.py)：**急性恐慌（z>2 或 pct>95）的 5-20 日前瞻超额收益，3 标的方向一致为正**，
幅度随 beta 放大（HS300 +0.3~0.4pp，ZZ1000 +0.9~1.6pp，SC50 +2.4~4.5pp）。但 **60 日边际全线大幅
转负（−2~−4.7pp）**——恐慌尖峰标记的是短期反弹，不是长持。"尖峰回落再进"无效，即时性才是关键。
（分位分桶 [event_study.py](event_study.py) 无单调边际——高分位在熊市里会持续接飞刀，验证了用
z-score 急性尖峰而非分位带的设计选择。）

## 因子设计与回测

加仓 overlay：`pos = base` 常态，z>thr 触发后 H 日抬到 `1.0`，T+1 进场，5bp 单边成本。
择时检验：等暴露常数仓的 Sharpe/Calmar 与 buyhold 相同，故**击败 buyhold 比率 = 择时本身有 alpha**。

[vix_sweep.py](vix_sweep.py) / [robustness.py](robustness.py)（200 配置 × 3 ETF = 600 回测）：

- **76% 配置在 3 标的上全部击败 buyhold 的 Calmar**（SOP 门槛 40%），≥2 标的 96%；600 回测 91% ΔCalmar>0
- **z 阈值内部最优**（非角落）：z1.0 +0.057 → **z1.5 +0.125（峰值，min +0.026，每个组合都赢）** → z2.0 +0.066
- 三标的方向一致；对 graded/非graded 不敏感；翻转 ~4-5 次/年（低）
- **代表配置 `z>1.5, H=10, base=0.5`**：HS300 以 ~60% 平均暴露拿到 buyhold 全部收益、回撤减半
  （−19% vs −45%），Calmar 0.25 vs 0.11；ZZ1000/SC50 让出部分收益换更小回撤，净 Calmar/Sharpe 上升

## 统计验证 [validate.py](validate.py)（HS300/ZZ1000，~10 年）

## 已知盲区（从公式可推，非回测发现）

1. **只标记短窗口反弹**——持有 >60 日边际转负，不可长持。
2. 捕捉的是 **50ETF 衡量的系统性恐慌**，对单指数特异下跌（无大盘恐慌）不灵。
3. 只加仓、不减仓——不是 de-risk 因子，下行保护需另配（如 zz1000_dd_ladder）。
4. 日度择时 alpha Sharpe CI 含 0（信号稀疏），量级温和——黄灯，权重 ≤ 主维度。
