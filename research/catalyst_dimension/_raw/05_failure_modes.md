# 第七维「催化剂/政策面」对抗审查（魔鬼代言人）

立场：我被指派论证"别建这个维度"。下面每条都尽量 steelman，再给缓解。我亲自 curl 复核了三个 load-bearing 时点（924 onset 日、924 前一日哨兵、10-08 顶部 + 2025-06-20 安静期），证据贴在各条里。结论先行：**核心机制成立但价值高度集中在少数事件日，最大真实风险不是"无效"而是"在顶部/危机被卖方叙事反向带节奏"和"组合层面同质化"。裁定黄灯——可建，但必须以"风险闸"而非"alpha 源"的姿态建，且 A/B 设默认接受 null。**

---

## 1. Already-priced：催化剂是"事后确认"还是"择时领先"？

**严重度：中（不是高）。这是唯一一条我亲自证伪了主控原始担忧的。**

主控的 KB 担忧是"等研报喊政策底确认时指数已 +20%"。我实测发现这个担忧**被 onset 取数能力部分化解**：
- 我 curl T=2024-09-24 18:00（924 当晚，研报刚出），research 通道返回 6 条全是降准降息组合拳报告，score 0.93-0.99（AP202409241640006953=0.986「人民银行降准0.5%；降7天逆回购0.2%」）。**不需要等 10-08 的"政策底确认"报告**——onset 当晚就拿得到，且此时指数尚未启动主升。
- 反向对照 T=2024-09-23（924 前一日）哨兵 query，top 仅 0.58，全是陈旧的「宏观价格信号疲软」「成交缩量后反弹」「美联储降息」，**零 924 泄漏**。门控干净。

所以"只能事后确认"这条**作为绝对论断不成立**。BUT 真正的 already-priced 风险换了个形态，更阴险（见第 2 条）：onset 当晚虽能取到，但 agent 要在"924 当晚研报已说降准"和"10-08 研报已写'前4日涨超10%'"之间**靠 INFOCODE 日期聚类 + '已涨X%'语言自己判断身处哪一段**。这是认知动作，不是数据动作——LLM 在 12 轮预算里能不能稳定做对，无回测保证。

**价值打几折**：onset 可取 → 不打到 1 折。但能吃到 onset 的只有"政策包当晚落地"这一窄类（A/C/D），且要求 bot 当天恰好在跑、query 恰好命中、读数恰好不误判 confirmation。综合打 **4-5 折**。

**缓解（可缓解）**：把 onset/confirmation 判别写成**硬读数规则**而非感觉：(a) INFOCODE 日期是否 = T 或 T-1（onset 端）vs 散布在 T-5~T-10（confirmation 端）；(b) SUMMARY 是否含「已涨/反弹X%/政策底确认/牛市启航」→ 命中即降级为"确认信号，不可作为新增仓扳机"。把这两条做成技能里的 checklist，不靠 agent 临场悟。

## 2. 卖方/perma-bull 偏差 + 危机滞后：「读方向不读结论」真能纠偏吗？

**严重度：高。这是我实测后认为最危险的一条，且 KB 现有缓解不够。**

我 curl T=2024-10-08 09:00（节后第一天，前面 +25% 暴涨，**当天就要 -7% 大反转**）的哨兵 query，返回的是：
- 0.75「政策信号明确，提振市场信心」
- 0.69「本周全A收涨15.13%…成交额破万亿」
- 0.66「正视内需是本轮行情反转的底层逻辑」
- 0.50「如何增配中国资产成为全球最热门的话题」

**在指数的局部顶、反转前一刻，整个 research 通道是清一色看多确认。** 一个把"高分政策催化 = timing_stance 上调"朴素映射的 bot，会在这里被带进顶部，次日吃 -7%。score 信号**无法区分 onset 与 late-confirmation**——0.75 既可能是 924 当晚的真领先，也可能是 melt-up 顶部的卖方大合唱。

"读方向不读结论"作为口号，在这个样本里**救不了**：方向就是"政策强、情绪热"，没错；但这个正确的方向恰恰是反向指标。券商研报的结构性偏多 + 危机滞后（卖方在崩盘前不会喊空）意味着**这个维度在最该 risk_off 的时刻给出最强的 add 信号**。这是与因子相反的失败模式：因子至少在崩盘时数值会恶化，叙事维度会逆向恶化。

唯一的真领先样本（C 类外围冲击，T=2025-04-03 关税当天 news 实时捞到利空）是少数能让 agent 主动 risk_off 的催化——但那是 news 通道的事件时效，不是 research 通道的策略观点。research 通道在危机端系统性失灵。

**可缓解？部分。**
- **缓解1（强）**：危机/利空方向**只信 news 的事件 onset（行政令/暴跌实时流水），明确禁止用 research 策略观点做 risk_off 判断**——卖方不会替你喊顶。
- **缓解2（强）**：加"涨幅闸"——若哨兵命中高分政策催化，但近 N 日指数已显著上涨（agent 自己能看到价格），则催化剂维度**只能维持 hold、不能上调到 aggressively_add**。把"高分 + 已大涨 = confirmation 顶部"写死。
- **缓解3**：明确告诉 agent research 通道的偏多是结构性的，0.75 不是"机构看多"的信息，是"事件足够大到多家券商发报告"的信息——读簇的存在性，不读簇的情绪色彩。

即便如此，残余风险仍偏高——因为它要求 agent 在最亢奋的时点做最反直觉的克制。

## 3. 同质化/羊群：100+ bot 读同一 KB → 组合层面多样性塌缩

**严重度：高。这条直接打在用户最看重的"不同人设不同 regime"上，且无法靠技能内部完全缓解。**

100+ bot 共用同一套 query 模板 + 同一个后端 + 同一套 onset/confirmation 判别规则，催化剂维度的输出会**高度收敛**：同一天大家打同一个哨兵 query，拿到同一批 INFOCODE，读出同一个"政策 onset 形成"。结果：
- **regime 判断从"六维证据各有侧重的分歧"塌缩成"第七维一票否决式的共识"**。催化剂是最"响"的维度（有具体事件、有出处、有强 score），容易盖过趋势/宽度/估值的个性化解读。用户精心设计的 bot1 偏激进、bot7 偏保守的人设差异，会被"今天有 924，全体上调"抹平。
- **羊群放大**：如果催化剂维度让 100+ bot 在 924 当晚同时上调、在关税当天同时 risk_off，组合层面就是单一 timing 信号的 100 倍下注，而不是多 agent 的去相关。这在回测 dashboard 上可能表现为"加了第七维后所有 bot 收益曲线相关性飙升"——多样性是用户要的产品价值，这会侵蚀它。

**可缓解？只能部分，且有代价。**
- **缓解1**：催化剂维度只输出**"事件 + INFOCODE + onset/confirmation 标签"这个客观层**，**把"据此该加该减"留给每个 bot 的人设/方法论去裁决**。即激进 bot 看到 924 onset 可以 aggressively_add，保守 bot 看到同一 onset 只 hold。把同质性锁在"事实发现"层，让分歧保留在"仓位响应"层。这是最关键的设计约束。
- **缓解2**：A/B 时**同时看组合层相关性指标**，不只看单 bot 收益。若加维度后 bot 间日收益相关性显著上升，即使平均收益持平也应判负——因为损害了产品核心价值。
- **残余**：只要共用 KB，发现层一定收敛。无法根除，只能把伤害限制在发现层。

## 4. 过度交易：给 agent 一个"叙事"维度，会不会追 headline 把 alpha 磨没？

**严重度：中。**

我 curl T=2025-06-20 安静期哨兵：top 仅 0.38，全是陈旧的「关税博弈政策对冲」「稀土永磁」「6月成交额环比+13.5%」relitigation，**无新催化**。这说明门控在安静期能正确读"无事发生"。**只要 agent 遵守 score 门控（top<0.4/0.5 视为无新增催化、维度静默），震荡市里它就不该产生新动作。**

但风险在于：(a) 叙事维度天然诱导 LLM"找故事"——给它一个催化剂章节，它有动机每天填出点什么，把 0.4 的弱相关 query 读成"政策暖风"；(b) news 通道每天都有盘面复盘流水，若 agent 误用 news 做主判，每天都有"叙事"可追 → 换手率上升，在震荡市把 alpha 磨成手续费。

**可缓解（强）**：
- **硬 score 门控**：top<0.5 → 第七维输出强制为"无 regime 级催化，本维度不改变仓位"。已实测 0.38 在安静期，门控有效。
- **research 禁做主判、news 仅补 onset 当天口径**（KB 已有此纪律，固化进技能）。
- **维度只能在 regime 切换方向上发言，不参与日内/小波段微调**——催化剂是 regime-level 信号，不是择股/择时小信号，明确限定它的作用域到"牛/熊/震荡/危机"切换，不下沉到仓位微调。

## 5. 与现有 ### 情绪 / ### 宏观 冗余：增量信息有多少？

**严重度：中。**

实测 T=2025-06-20 安静期，第七维读出的东西（关税对冲、成交额、稀土主题）**与 ### 情绪（成交量/换手）、### 宏观（已发布数据）大量重叠**，增量≈0。在多数 bot-day（安静期占绝大多数），第七维是冗余的，但成本（1 个 query + 阅读轮次）每天都付。

增量信息真正存在于**两个窄场景**：(a) **政策 onset 当天**——情绪/宏观维度此刻还没反应（情绪要等成交放大、宏观要等数据发布滞后 1 个月），催化剂维度能在 T 日当晚就标出"降准50bp+SFISF 落地"，这是其它六维给不了的领先量；(b) **外围冲击 onset**——比任何国内数据都早。所以增量是**真的，但稀疏**：集中在每年个位数的事件日。

**可缓解（设计取舍）**：
- 接受"维度价值稀疏"这个事实，把它定位成**"平时静默、事件日发声"的哨兵**，而不是每天都要有内容的章节。靠 score 门控自动静默，避免冗余噪声污染另六维。
- 与 ### 宏观显式分工：宏观维度走 macro_* PIT 工具读**已发布硬数据**，催化剂维度走 research_* 读**政策/事件 onset**，两者时间窗错开（一个滞后确认、一个领先发现），冗余可压到最低。

## 6. 可证伪性：A/B 测出"无显著差异"能干脆接受 null 吗？

**严重度：低（这是优点，不是缺陷）。**

这是整个提案最健康的部分。抓手现成：48080 dashboard 已按 bot 算每日/累计收益 + 最大回撤 + benchmark，runtime/runs/ 的 trading-rl-config.json 可配"带第七维 vs 不带"的 A/B。参考用户对 VIX/regime/total_score 三个因子的诚实裁定文化（三关全挂就排除、不包装），这个维度完全可以接受 null。

**但要预先定义"什么叫赢"，否则会陷入 p-hacking**：
- **不能只看平均收益**。该维度的设计价值是**降危机回撤**（C 类 risk_off）而非提收益。所以主指标应是**最大回撤 / 危机段（如 2025-04 关税周）的相对表现**，次指标才是收益。
- **必须看组合层相关性**（见第 3 条）：若收益持平但 bot 间相关性上升，判负。
- **样本稀疏问题**：OOS 只回到 2024（~2.4 年），真正的 regime 级催化事件（924、12月政治局、4月关税）个位数。**事件日太少 → A/B 几乎不可能有统计显著性**。这本身就是接受 null 的理由：如果价值集中在 3-5 个事件日，而这 3-5 天用肉眼复盘就能看清有没有用，那就别假装跑出了"统计显著"。诚实裁定 = 看事件日的逐案表现 + 全样本回撤，而不是追求一个不可能显著的 t 值。

**结论**：可证伪性强，且应预先承诺"事件日逐案复盘 + 回撤主指标 + 相关性约束"三条，任一不过即接受 null。

## 整体裁定：黄灯

**值得建，但必须重新定位，且带三道闸。**

- 不是因为它是强 alpha 源——实测它在顶部会反向带节奏（第2条）、在安静期冗余（第5条）、在组合层同质化（第3条）。
- 而是因为它在**两个其它六维结构性给不了的窄场景里有真领先量**：政策包 onset 当晚（实测 924 当晚 0.99 可取，无泄漏）、外围冲击 onset（关税当天实时）。这是 factor 永远做不到的——"政策拐点正在形成"无法编码成 IC，这句话成立。

**建的前提（缺一即转红）**：
1. **定位成"风险闸/事件哨兵"而非"加仓引擎"**：利空方向（risk_off）走 news 事件 onset 可信；利多方向必须叠"涨幅闸"防顶部追高（第2条缓解2）。
2. **发现层共享、响应层分化**：第七维只输出"事件+INFOCODE+onset/confirmation 标签"客观层，加减仓裁决交还各 bot 人设，保住多样性（第3条缓解1）。
3. **A/B 预先承诺接受 null 的标准**：主指标=危机段回撤 + 事件日逐案复盘，附加组合相关性约束；不追求不可能显著的全样本 t 值（第6条）。

若做不到 1-3（尤其做不到 2，导致 100+ bot 同步下注），则**转红灯**——那时它就是一台羊群放大器，损害大于增量。
