# S1–S8 策略最终验证报告

**日期**: 2026-06-02
**结论一句话**: 这套策略不是"坏掉了",是"不分市场环境地全程开火,把对的环境里赚的、在错的环境里全亏回去"。装上 regime 门、只在对路环境放它出来后,**S7(弱市超跌反弹)和 S2(强市龙头接力)是两个真 edge,跨样本扛成本**;其余降级或下线。

> 本报告取代 2026-06-01 的过程版(那版"全策略皆失败"的元结论已被 regime 拆解推翻)。

## 1. 方法学(怎么算的)

### 1.1 样本量(真入场 = 算 pnl 的笔数)

| 策略 | 候选信号 | 真入场 | 跨度 | 入场率 |
|---|---|---|---|---|
| S1 平台突破 | 1615 | 1309 | 2016–2026 | 81% |
| S2 龙头接力 | 218 | 118 | 2016–2026 | 54% |
| S3 首板接力 | 2030 | 1339 | 2014–2026 | 66% |
| S4 回踩 | 24701 | 23504 | 2014–2026 | 95% |
| S5 龙回头 | 4119 | 2167 | 2015–2026 | 53% |
| S6 趋势 | 4275 | 2860 | 2016–2026 | 67% |
| S7 超跌反弹 | 3326 | 3273 | 2016–2026 | 98% |

- S1/S6/S7 的 2016+ 深史 + S2 全部深史,均为本轮(2026-06-01/02)回填(`/tmp/backfill_deep.py`,mode=backtest);S3/S4/S5 原有。
- 候选≠入场:`gap_up_skip`(高开冲过入场区)/`no_data`(停牌)等记 pnl=NULL,不计。

### 1.2 回测三段流水线
1. **选股**(`select.py`):遍历历史每个交易日 T,信号检测器扫全市场 → 候选(带入场区/止损/止盈)。写 `sN_candidates`。
2. **逐笔验证**(`verify.py`):每个候选在 **T+1** 模拟"进场→出场"算 `pnl_pct`。写 `sN_verifications`。
3. **汇总**:胜率=盈利笔/总入场;均值=mean(pnl_pct)。

### 1.3 统一公式
`pnl_pct = (exit_price − entry_price) / entry_price × 100`,**原始不扣成本**(后续手动扣)。

### 1.4 统计验证套件(vibe-trading)
- **bootstrap_sharpe_ci**:日收益重采样估 Sharpe 95%CI,要 `ci_lower > 0`。
- **walk_forward**:equity 切 5 段,要 `≥4/5` 段盈利。
- **monte_carlo**:逐笔洗牌检验路径显著性。
- 判据:`CI下界>0` **且** `WF≥4/5`(可交易 edge 的最低标准)。

### 1.5 成本模型
往返 ≈ 佣金 0.025%×2 + 印花税 0.05%(卖) + 滑点。扫 **0 / 0.10 / 0.20 / 0.30%**,主结论用 **0.20%**(含 5bp 双边滑点,A股小盘现实档)。

### 1.6 IS/OOS + look-ahead 防护
- IS = <2022-01-01,OOS = ≥2022(挑参数/特征只用 IS)。
- **regime 门用"信号日前一交易日(T-1)的 regime"**——在 T+1 开盘前至少一整天已确定,杜绝"开盘拿不到当天 regime"的 look-ahead。S2/S7 用此滞后 regime 仍 OOS 过线,证明 edge 是真环境依赖、非时序假象。

### 1.7 已知局限(诚实纪律)
1. **equity 是"入场日等权"近似**——忽略持仓重叠;walk_forward 绝对收益数字不可字面读,只看 PASS/FAIL。
2. **统一口径实验的入场是简化版**(T+1 开盘 + 高开>5% 跳过),比策略真实"入场区"略松;数字是近似版。
3. **出场假设精确价位成交、日线无盘中路径**;追涨/分时打板需 tick 数据,测不了。

## 2. 核心结论链(每一步怎么收敛的)

| 步骤 | 发现 |
|---|---|
| 裸胜率 | S3/S6/S7 看着还行 |
| 深史 validation | S4/S5/S6 统计上亏钱,只 S1/S3 撑住 |
| 扣成本 | S1/S3 也跌破线,毛 edge ≈ 成本 |
| 选择性 top-K | 拉高毛 edge(S3 +70%)但只到成本边缘 |
| 强排序(S3 特征) | OOS 符号反转 = 过拟合,死路 |
| 波段/拉长持仓 | 毛收益随持仓衰减(脉冲非趋势) |
| 跨策略共振 | 共振罕见(0.5%)且不提升 |
| 追涨入场 | 对短线反而更差(追高接盘) |
| 不对称/条件出场 | 提赔率但 OOS 不确认 |
| **统一持2天出场** | **毛收益打败所有自定义出场**(尤其 S5 +1.1%);但 S2 例外(必须封板持有) |
| **regime 拆解** ★ | **S7 在熊/弱市、S2 在强牛/强市才真有 edge;之前"失败"是不分环境稀释到成本下** |

## 3. 最终逐策略判定

| 策略 | 判定 | 对路环境 | OOS净均值(扣0.2%) | WF | 备注 |

| **S2 龙头接力** | 🟢 | 强牛 / 强势震荡 | **+2.85%** | 4/5 | 低频高确信(~12笔/年);**出场必须封板持有** |

## 4. 逐策略:入场条件 / 出场条件 / 市场环境

> 入场/出场参数取自各 `signal_detector.py` 的 DEFAULTS 与 `verify.py`;市场环境为本轮回测实证(非拍脑袋)。

### S7 超跌反弹(v13)🟢🟢 — 最硬
- **入场**:近35日窗;距 MA20 ≤ **−15%**、近5日收益 ret5 ≤ **−10%**(深度超跌);T日涨幅 ≥ 0(止跌信号);成交额 ≥ 3亿;每日 ≤5只。入场=T+1开盘。
- **出场**:止损 **−5%**、止盈 **+8%**、最长持仓 **2天**;跌停延期5天。(简化"持2天"亦可,略优。)
- **市场环境**:**熊 / 弱势震荡**(用前一日 regime 门)。强牛/强势震荡里 **−0.37%/−0.09%,必须关掉**。
- **经济逻辑**:市场弱时才有真超跌;强市里"超跌"是逆势接刀。

### S2 龙头板接力 🟢 — 低频高确信
- **入场**:热门行业(涨停数 top5、行业涨停 ≥2);连板 **3–8**;炸板 ≤1;首封时间 ≤14:30;换手 3–35%;拒一字板;每日 ≤5只。
- **出场**:**封板持有 / 炸板卖 / T+2未封板退出**,最长3天,止损 ~−7%。**⚠️ 利润来自连板跟随(`limit_follow_close` 均+13%),严禁改成"持2天"——实测 +2.37%→−0.12% 崩盘。**
- **市场环境**:**强牛 / 强势震荡**(强牛里净 +4.2%)。中性/弱势熄火。
- **经济逻辑**:活跃打板环境才有龙头可接。

### S3 首板接力 🟡 — 筛选器
- **入场**:热门行业(top3、行业涨停≥3);首板(streak=1);炸板≤1;首封≤14:00;换手3–25%;拒一字;入场区 [T收盘×0.97, ×1.01];每日≤10只(建议收紧到 ≤2)。
- **出场**:封板持有到T+2 / 炸板卖,最长3天。(持2天表现相当。)
- **市场环境**:**强势震荡**(它本就只在强势震荡出票)。
- **状态**:全样本扛过成本但 OOS 差一口气,中位≈0。**当 scout 候选漏斗,不作独立 alpha。**

### S1 平台突破 🟡→🔴
- **入场**:90日窗、20日平台、平台振幅 ≤14%;突破 ≥2%;放量 ≥1.5倍;成交额≥5亿;ret20≥10%、rel20≥5%;入场区 [−3%,+2%];拒一字突破;仓位×0.5。
- **出场**:止损=max(平台下沿×0.98, 入场×0.92),最长2天。
- **市场环境**:强势震荡。**全样本过、OOS 不过 → edge 集中在 2016–2021,近年磨平。** 暂当筛选器,别加仓。

### S4 回踩战法 🔴 下线
- **入场**:60日窗;20日均线上方趋势≥3天;回踩到 MA5(距均线<1%);距高点回撤 6–10%;T日跌幅 >−4%;缩量 <0.55。
- **出场**:最长5天。
- **市场环境**:**无** —— 强势震荡/中性都净 −0.6%。`stop_hit_at_open`(回踩接刀、开盘跳空击穿)是头号亏损源。**建议下线或彻底重做入场(加反弹确认)。**

### S5 龙回头三段 🔴
- **入场**:30日龙头窗、连板≥2;冷却2–7天、阶段跌幅≥5%;T日反包≥7% 且收盘≥T-1最高。
- **出场**:止损=T日最低(常−12%深)、最长15天、封板持有。
- **市场环境**:强势震荡均值+0.68% **但是彩票**(胜率36%、中位−6.6%,赢家需9–15天发酵,换持2天即崩)。**下线或仅极小仓位 observe。**

### S6 趋势持有 🔴
- **入场**:90日窗;成交额≥5亿;ret20≥10%、rel20≥5%;距MA5 0–3.5%;MA10斜率≥0.5%;入场区[−3%,+1%];冷却20天。
- **出场**:止损−5%、最长5天、跌破MA5。
- **市场环境**:**无稳定** —— 震荡市全亏,熊/强牛样本太小(83/293)不足判。**A股小盘短线趋势延续敌不过均值回归,建议下线。**

## 5. 可落地的动作

1. **装 regime 门(用前一日 regime,防 look-ahead)**:S7 只在熊/弱势震荡放、S2 只在强牛/强势震荡放。这是把 edge 从成本线下捞回来的关键一步。
2. **出场分策略**:S7 用"−5%/+8%/2天"(或持2天);**S2 保留"封板持有"(切不可改2天)**;S3 可简化为持2天。
3. **S3 收紧出票**:max_candidates 10 → 2(top-K 提毛 edge,降换手成本)。
4. **下线 S4;S5/S6 降为 observe**(或下线)。
5. **methodology 文案诚实化**:停止宣称"已验证策略/胜率X%";S1/S3 标注为"脉冲候选筛选器,需 regime+人工二次确认"。
6. **方法固化**:把 validation 三件套 + 成本模型 + regime 门接进各 `backtest.py`,以后回测自动出"毛/净 + CI/WF",不再只看裸胜率。
7. **研究重心**:单票短持已被穷尽;低换手的 ETF 级择时因子(`index_timing`/`sr_factor`,已验证)成本压力小一个量级,是更现实的下一个 alpha 池。
