# 中证沪深港黄金产业股票指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证沪深港黄金产业股票（931238.CSI，简称 SSH黄金股票）**——从内地与香港市场选 50 只金矿采选 / 冶炼 / 销售为主业的较大市值公司，金矿股权重逾七成、黄金零售约一成。**含 A + H 两地证券（同一家公司 A、H 可分别计入），穿透时以 A 股龙头为主、H 股成分定性看。**

## 核心认知

黄金股票（931238）= **金价 × 矿企经营杠杆**的赛道。它和工业金属股**不是一套玩法**——金价的母变量不是制造业需求，而是**实际利率 + 美元 + 央行购金 + 避险**这套货币 / 金融属性逻辑；矿企再在金价之上叠一层经营 + 财务杠杆。五个特性决定怎么玩：

- **金价是母变量，但金价的驱动与工业金属完全不同（最核心认知）**：金价主要由**美债实际利率（负相关，最强）、美元指数（负相关）、全球央行购金与黄金 ETF 持仓（结构性需求）、避险 / 地缘溢价**驱动，**不吃制造业 PMI 那碗饭**。判黄金股先判金价方向，判金价先看实际利率 + 美元 + 央行购金，别套工业金属的"需求—库存"框架。
- **矿企经营杠杆放大金价波动**：盈利 = (金价 − 单位克金成本) × 销量 ± 套保损益，营业杠杆 + 财务杠杆叠加，**金价涨一成，低成本矿企利润弹性常显著放大**；金价上下行幅度都被放大，这是黄金股相对实物黄金的超额来源，也是深回撤来源。
- **套保 / 权益结构是金矿股特有的噪声**：部分矿企做金价套保，会让当期利润与现货金价脱节（金价大涨时套保头寸拖累、大跌时反向缓冲）；还有铜 / 其他金属副产收入（如权重第一的综合矿企，金 + 铜双驱动）。**别把"金价涨"直接等同"每家金矿股都涨"，要穿透到纯金矿 vs 综合矿、看套保与副产结构。**
- **量增逻辑分化龙头**：同是金矿股，有的靠金价 Beta（产量稳的老矿），有的叠加**产量增长**（并购扩产 / 新矿投产的成长型矿企）——后者在金价平台期仍可能因放量走出独立行情。穿透龙头时把"金价 Beta"和"产量 alpha"分开看。
- **高波动、深回撤、事件跳空多**：金价受 FOMC / 非农 / CPI / 地缘事件单日跳变，矿企再放大，单日 ±5% 常见。死扛买入持有的回撤可观，回撤控制全靠纪律。

驱动排序：**金价（实际利率 + 美元 + 央行购金 + 避险）≥ 矿企单位成本 / 产量趋势 > 趋势 / 动量择时 > 估值**。研究时先问三件事：

1. 金价方向如何？实际利率（10Y TIPS）在升还是降、美元强还是弱、央行购金 / ETF 持仓在增还是减？→ 决定金价中枢方向
2. 龙头单位克金成本 + 产量增速在什么趋势？金价上行有没有兑现到矿企利润（还是被套保 / 成本上升吃掉）？→ 决定景气真假
3. 趋势对不对、动量在不在？→ 决定现在加还是减

## 一、估值视角（金矿股 PE 不稳，主用 PB + 金价位置 + 成本曲线）

黄金股是**金价驱动 + 盈利受金价 / 套保 / 成本三重扰动**的赛道，**禁止把 PE 当价值锚做均值回归择时**：

- **PE 陷阱**：金价高位 → 矿企利润 E 顶 → PE 看似最低；金价跌穿成本 / 套保拖累 → 盈利坍塌 → PE 冲高甚至为负。**低 PE 未必便宜、高 PE 未必贵，PE 分位当择时扳机不可靠。**
- **主用 PB**：金矿企净资产（矿权 + 储量 + 固定资产）相对稳定，PB 比 PE 稳。历史 PB 分位（截至当日 PIT）有定性参考——但 **PB 同样不做择时扳机，只做定性预警**，且分位对金价周期滞后。
- **真正的"价值标尺"是金价位置 + 单位克金成本曲线 + 储量 / 产量增速**：①金价在历史分位的位置（截至当日 PIT）+ 是否兑现到利润；②龙头单位克金成本能否在金价回落时盈亏平衡（低成本矿穿越周期 = 重仓信心）；③成长型矿企的产量增速（量增可在金价平台期提供独立 alpha）。这三件比 PE / PB 更说明问题。
- **样本可用但分位非择时锚**：只用于"是否进入泡沫区 / 深熊区"的定性判断，不做"低 PE 抄底 / 高 PE 减仓"的机械操作。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量 + 金价框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。

估值在这里只做两件**定性预警**（不是择时扳机）：

- **极端泡沫预警（顶）**：金价创历史新高 + PB 顶部分位 + 全民进场（黄金题材出圈、研报高喊"金价破 X、黄金大牛市"）→ 配合趋势框架减仓。
- **周期反转预警（底）**：出现 **实际利率见顶回落 + 美元转弱 + 央行购金加速 + 金价止跌企稳 + PB 接近底部分位** 等反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**金价 / 实际利率 / 央行购金证据**，不是低 PB 分位（分位对金价周期滞后）。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**黄金股还要额外把金价趋势 + 实际利率 / 美元方向纳入**——板块趋势与金价 / 实际利率背离时，以后者为主参考。

- **方向锚（三层）**：
  - 板块层：指数 vs 过去 200 日均线（收盘价即可算均线 / 时序动量）+ 斜率
  - 金价层：上海金 / 伦敦金的过去 200 日均线 + 价格分位（截至当日 PIT）
  - 宏观层：美债实际利率 + 美元指数方向——**这层常领先金价与股价**
  - **三层共振时信号最强；只有股价涨而金价平、实际利率没降 → 题材脉冲或情绪推动，须谨慎。**
- **量能确认（板块代理）**：指数无量 → 用 `sector_factor` / `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量；不跟 = 可疑假突破。
- **波动率（板块代理）**：收盘价滚动波动率 + 板块乖离；波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：FOMC / 非农 / CPI / 地缘消息常造成金价跳空，要分清是**逻辑级（实际利率 / 美元方向真转向）**还是**情绪脉冲（避险一日游）**——前者可顺势，后者易回补。
- **金 vs 矿背离**：金价涨而矿企不跟（套保拖累 / 成本上升 / 量减）或矿企独立走（量增逻辑）——别把"金价涨"当全员涨，穿透到纯金矿 vs 综合矿、套保与产量结构。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）

> **重要前提：本指数尚未跑过系统的择时因子筛选，没有任何已验证的"绿灯"主因子。** 黄金 / 金矿在直觉上趋势性较强（货币属性 + 央行购金的结构性需求易形成持续趋势），但**这是定性认知、不是本系统的验证结论**——不要把任何价格类因子当作经验证的承重信号。下列指标只能作**降回撤辅助 + 未验证客观第二意见**，方向裁决权交回金价 / 实际利率 / 美元框架。读数可用收盘序列按公式自算（**信号按当日收盘计算、下一交易日 T+1 执行**）。

- **`trail_dd` 回撤止损族（通用断后，本指数当前主力机械工具）**：收盘从过去约 120 日滚动峰值回撤超一档 → 降仓 / 空仓，站回均线 → 回归；多一档梯度版（如 ≥7% 砍半、≥15% 清仓）降仓更早。**纯收盘价、无代理失真，作通用降回撤断后线相对可靠**——职责是躲深熊段、给框架犹豫时客观的"先降一档"线，**是降回撤工具不是收益增强器、更不抓顶底**。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；只看价格，对实际利率 / 央行购金 / 金价拐点零预警。**注：未经本指数专门筛选定级，先按"通用降回撤工具"用，待跑过筛选后照实定级。**
- **时序动量（仅快读，不承重）**：20 日动量可作"价格面还在不在多头"的快读数；震荡里翻转多是噪声，〇判定震荡市时默认当噪声、不据此动仓；T+1 对单日跳空滞后一天。
- **市场情绪 / VIX（系统性第二意见）**：`macro_50etf_vix` 覆盖系统性恐慌 / 自满，可与避险溢价交叉看，不对个股层面结构性风险敏感。

**共同纪律**：本指数没有经验证的绿灯因子——择时主轴是**金价 + 实际利率 + 美元 + 央行购金的宏观多维判断**，价格类因子只做降回撤断后与未验证第二意见。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。**待研究室对本指数跑完因子筛选后，再据结论更新本节定级。**

## 三、景气度视角（黄金股专属：金价 + 矿企成本 / 产量为母变量）

黄金股的景气链条清晰，按性质分四类，别用滞后指标做择时（取数见上「取数」节）：

- **领先（母变量）**：
  - **金价 + 其驱动**——上海金 / 伦敦金价格趋势，及其背后的实际利率（负相关）、美元（负相关）、央行购金 / ETF 持仓（结构性需求）
  - **矿企单位成本 / 产量**——单位克金成本方向（决定盈亏平衡）+ 产量增速（量增矿企的独立 alpha）
  - **避险 / 通胀 / 货币环境**——地缘避险溢价、通胀预期、全球流动性
  - 多档同向时信号最强（金价上行 + 实际利率下行 + 央行购金加速 + 成本可控 = 景气主升）。
- **滞后（确认而非择时）**：矿企营收 / 净利 YoY + 一致预期修正，跟随金价 1–2 季度反映，**不当择时锚**——等盈利确认转向就晚了。
- **结构 / 上限**：矿山储量 / 服务年限、单位现金成本曲线、套保比例与副产结构——决定龙头穿越周期能力与重仓信心，不决定主趋势开关。
- **事件驱动**：FOMC / 非农 / CPI / 地缘冲突 / 央行购金数据公布 / 矿企并购投产——跳空催化，事件级单独评估。

判断要点：

- **金价是母变量，实际利率 + 美元是金价的母变量**：判黄金股先判金价，判金价先看实际利率 + 美元 + 央行购金。**看金价趋势 + 实际利率方向，不看矿企当期营收**（营收滞后）。
- **央行购金 / ETF 持仓是结构性需求**：央行持续购金 + ETF 持仓回升 = 金价的长周期底盘，与短周期的实际利率波动叠加。
- **分清"金价 Beta"与"产量 alpha"**：金价驱动是全行业的 Beta；产量增长是个别成长型矿企的 alpha——行情切换时区别对待。
- **看的是趋势一致性**：金价 + 实际利率 + 美元 + 央行购金同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**。

## 四、宏观驱动视角（黄金股专属：实际利率 + 美元 + 央行购金是母变量）

这是黄金股区别于一般周期股的**专属维度**，金价几乎全被它驱动：

- **美债实际利率（10Y TIPS）= 最强负相关母变量**：黄金无息，**实际利率 = 持有黄金的机会成本**。实际利率下行 → 持金机会成本降 → 金价涨；实际利率上行 → 压金价。看到"美联储转鸽 / 实际利率见顶回落" → 对黄金股普遍利好。这是金价的第一驱动。
- **美元指数 = 负相关母变量**：黄金以美元计价，美元强压金价、美元弱抬金价；常与实际利率同向作用。
- **央行购金 + 黄金 ETF 持仓 = 结构性需求**：全球央行去美元化 / 增持黄金储备、ETF 持仓回升是金价的长周期底盘——这是近年金价与实际利率阶段性脱钩（实际利率高位金价仍强）的关键解释变量，**不能只盯实际利率，要把央行购金这条结构性需求线纳入**。
- **避险 / 地缘溢价 = 脉冲**：地缘冲突 / 系统性风险时黄金的避险买盘，单日脉冲大但持续性取决于事件级别——区分"短期避险脉冲（易回补）"vs"长期不确定性中枢上移（趋势级）"。
- **通胀预期 = 次要锚**：黄金的抗通胀属性在高通胀粘性 + 实际利率受压时强化，但单独的名义通胀不是第一驱动（要看实际利率 = 名义利率 − 通胀预期）。
- **人民币汇率（国内金价特有）**：上海金以人民币计价，**人民币兑美元贬值会抬升国内金价（相对伦敦金的溢价）**，反之压缩——判国内黄金股时把汇率这条单独看，别只看伦敦金。
- **政策 / 货币环境**：美联储货币政策路径、全球流动性松紧——通过实际利率与美元传导到金价。

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。黄金股波动大、金价跳变快、宏观事件密，纪律不可省：

- **金价兑现 / 转向**：金价创新高 + 实际利率见底回升 + 美元转强 → 主动兑现得更积极（矿企盈利顶滞后金价顶）；金价跌穿主要矿现金成本线 → 周期下行可能见底（但**别先抄底，等实际利率见顶 / 美元转弱 / 央行购金延续**）。
- **实际利率 / 美元反转预警**：实际利率从降转升、美元从弱转强 → 对黄金股是系统性逆风，不必等价格回撤就该降仓。
- **套保 / 成本证伪**：金价涨但龙头因套保 / 成本飙升利润不兑现 → 该轮 Beta 含金量打折，降低重仓信心。
- **事件前减敞口**：FOMC / 非农 / CPI / 重大地缘节点前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。
- **硬止损**：高波动品种止损纪律不可省。单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（金价上行 / 实际利率下行 / 央行购金）大概率已破。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。踏空与做错都是失分，两边都得盯。

- **金价证伪（下行，最关键）**：上海金 / 伦敦金跌破主要均线 + 实际利率持续上行 + 美元转强——金价逻辑直接被推翻，板块失去燃料。
- **实际利率 / 美元证伪（下行）**：美债实际利率确立上行趋势 / 美元确立强势——金价的最强母变量逆风。
- **结构性需求证伪（下行）**：央行购金放缓 / 转为净抛、黄金 ETF 持仓持续流出——长周期底盘松动。
- **矿企证伪（下行）**：金价涨但龙头套保 / 成本 / 产量问题导致利润不兑现；成长型矿企产量增速不及预期。
- **趋势证伪（下行）**：指数跌破过去 200 日均线且 1 月未收回，但应根据当时市场环境修正指标；`trail_dd` 回撤族触发 = 价格面确认走坏。
- **估值证伪（下行，反向）**：金价新高 + PE 看似"最低" + 全民进场 + 卖方高呼"黄金大牛市"——周期顶部最危险信号组合。
- **看空被证伪（上行 veto-watch）**：实际利率见顶回落 / 美元转弱；央行购金加速、ETF 持仓回升；金价跌穿成本后供给收缩；地缘 / 系统性风险升级抬升避险买盘；人民币贬值抬升国内金价——这些会成为"看空"判断的上行风险，看空被证伪时回补要果断，犹豫即失分。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 黄金股是**金价驱动 + 经营杠杆放大 + 高 β 深回撤**的赛道，单指数策略夏普的提升，几乎全部来自压低最大回撤。你的活儿是金价转向 / 实际利率转升 / 美元转强 / 系统性风险来时少亏，主升段在场吃足金价 Beta。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法；**但"合法"是双向的：信号不支持在场时空仓完全正常、不必愧疚，信号支持在场时却空仓 = 踏空、同样违规**。不为了在场而在场，也不为了"稳妥 / 留子弹"而缺席。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- **该在场时别缺席，这是和"别一把满仓"对等的硬约束，不是软提醒**：当 **金价多头 + 趋势多头 + 实际利率下行 / 美元转弱 / 央行购金至少一项同向**（核心共振成立、且 `trail_dd` 未触发）时，**默认目标就是重仓到满仓**；此时仍要轻仓或空仓，**必须当天写明一条具体的、命名的减仓理由**——只能取自〔震荡市已认定 / 波动骤增 / 事件窗口跳空风险 / 金价涨但矿企不兑现 / 净值回撤闸门已触发 / 某条证伪已命中〕之一。**写不出具体理由 = 该满仓而没满 = 踏空失分；"留点子弹""感觉有点高""谨慎起见"都不算理由，那是自我设限。** 在场与否只看金价 / 趋势与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（那可能是周期顶）。
- 不用硬止盈硬止损——择时交给金价、趋势、回撤说话，不交给固定数字（但**机械回撤止损 `trail_dd` 在本指数是断后命脉**）。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势、且金价 / 实际利率同向"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市）？

- **识别标准**：
  - **趋势市**：均线（过去 MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且金价 / 实际利率方向同向**。
  - **震荡市**：过去 200 日均线走平 + 价格在均线 ±10–15% 内来回 + 箱体反复假突破 + **金价也在区间内震荡**。
  - **过渡待定**：信号不清、股价与金价 / 实际利率背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（金价转跌 / 实际利率转升 / 美元转强 / `trail_dd` 触发 / 趋势破位）就降仓乃至清空。别在趋势里高抛低吸。
  - **震荡市 → 防守、轻仓**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（FOMC 转向 / 实际利率破位 / 央行购金）即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：

- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（FOMC / 非农 / 地缘最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日 + 金价同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向，**叠加金价 + 实际利率趋势**。多层共振向上 → 在场吃 Beta；任一转下（特别是金价转跌 / 实际利率转升 / `trail_dd` 触发）→ 离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：黄金股本就高波动，越平静越敢拿，振幅骤增 / 大涨大跌 / 金价单日大跳变时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **回撤族断后（`trail_dd` 辅助）**：趋势转空之外，回撤止损族给一个客观的"先降一档"线，与趋势同向时双确认。
- **事件叠加**：FOMC / 非农 / CPI / 地缘窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（实际利率确认下行 / 央行购金延续）确认后再顺势加。
- 叠加：**方向（动量 + 金价 + 实际利率）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——过去 200 日线附近 ±10–15% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：黄金股箱体随时可能因一条 FOMC 表态 / 实际利率破位 / 地缘事件向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：宏观脉冲多、避险事件易反复，假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如实际利率方向转向 / 美元破位 / 央行购金加速），震荡假设作废 → 立刻切回趋势市骨架；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 金价转向 / 实际利率转升 / 美元转强 / 趋势转空（`trail_dd` 触发）→ 一把清到位，可以直接到 0**：黄金股周期下行往往加速（盈利杠杆向下），等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。黄金股的高赔率组合是 **金价上行 + 实际利率下行 + 美元转弱 + 央行购金加速 + 价格放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）：低赔率时，带损失的下注代价高于错过，所以宁可观望**——但这只约束低赔率情形；**高赔率时正相反：踏空没有止损、错过的 Beta 不会回来，代价上不封顶，轻仓 / 犹豫才是真正的"做错"，即失分。**
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用金价、趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯三件事：**趋势破没破（含金价 / 实际利率方向、`trail_dd` 有没有触发）** + **从持仓高点回撤了多少** + **金价有没有见顶反转**。趋势还在、回撤温和 → 拿住让利润跑；趋势破位 / 回撤明显放大 / 金价见顶 → 大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且黄金股主升浪回调动辄两三成（金价波动 + 盈利杠杆），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 回撤止损**（保护线随新高只升不降，机械化即 `trail_dd`）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：−20% 需 +25%、−33% 需 +50%、−50% 需翻倍、−70% 需 +233%。黄金股单边跌起来很容易摸到深水区（盈利杠杆向下），这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关，`trail_dd` 是这条的机械化身。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"金价假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 黄金股波动大、宏观 / 地缘新闻天天有诱惑，更要克制别被脉冲诱发高频折腾。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、金价、实际利率 / 美元、央行购金 + 避险、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 周期顶 PE 最低（PE 陷阱） | 金矿股**永远看 PB + 金价位置 + 成本曲线**，不靠 PE 均值回归择时 |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 金价 + 实际利率配合看 B；趋势破位 / 金价转跌时极端读数当定性预警 |
| 实际利率高黄金该弱 | 央行购金托住金价 | 看央行购金 / ETF 持仓：结构性需求强可抵消实际利率逆风（近年脱钩逻辑）；纯实际利率主导期看 A |
| 避险买金该追 | 避险脉冲一日游 | 看事件级别 + 持续性：长期不确定性中枢上移看 A（趋势）；短期避险脉冲 + 实际利率没动看 B（回补） |
| 金价涨矿股就涨 | 套保 / 成本吃掉利润 | 穿透矿企套保 + 成本 + 产量：低成本低套保 + 量增看 A；高套保 / 成本飙升看 B（不跟） |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**金价 + 实际利率方向**：领先端仍向下看 A，领先端（金价企稳 / 实际利率见顶）回升看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但金价 / 实际利率逻辑没坏看 A，金价转跌 / 实际利率转升的单边下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A；冲高乏力 / 金价见顶 / 实际利率转升 / 量价背离看 B |

> **核心一句**：黄金股票——用 **金价 + 美债实际利率 + 美元 + 央行购金** 判景气、用 **PB + 单位克金成本曲线 + 产量增速** 判空间（**别靠 PE 均值回归**）、价格因子未经本系统验证、只用 **`trail_dd` 降回撤断后 + 时序动量快读（待筛选再定级）** 择时、用 **大开大合 + 压最大回撤** 做仓位；吃该吃的金价 Beta、躲金价转向 / 实际利率转升 / 美元转强误伤、分清金价 Beta 与产量 alpha、信号不支持空仓不愧疚 / 信号共振该满仓不手软、按优势大小下注、进出算成本，靠压回撤把高 β 矿股的大起大落做成更平的净值曲线。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（货币体系结构变化、央行购金新格局、矿企套保结构变化）。
- **优先补"择时因子定级"这块空白**：本指数尚未跑因子筛选，一旦研究室给出筛选结论（哪族因子绿 / 黄 / 证伪），应据实把择时指标节从"未验证"升级为带定级的版本——这是本框架当前最大的待补项。
- **定期 + 事件驱动**：一轮金价周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对纯金矿 / 综合矿 / 量增矿企的差异化打法、**择时因子定级（筛选结论出来后照实写入）**。
- **不轻易动（信仰与原则层）**：唯一信仰（金价上行 + 实际利率下行 + 趋势确认重仓、金价转向 + 实际利率转升降仓）、金价 = 母变量且其驱动是实际利率 / 美元 / 央行购金、PB / 成本曲线判空间不靠 PE 均值回归、风险优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空、对本金保守对 Beta 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式，不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；货币体系 / 去美元化结构、央行购金长期格局、矿企成本中枢重置是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **诚实纪律不可动**：本指数当前"无经验证绿灯因子、价格因子按未验证对待"的结论须照实保留，**不得为了让框架"更完整"而把任何未验证的趋势信号包装成进场扳机**；待筛选结论出来再据实定级。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
