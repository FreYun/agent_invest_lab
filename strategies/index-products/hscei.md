# 恒生中国企业指数投资框架（方法论）

这套方法论和 A 股单指数框架有一个**结构性不同，先说清**：恒生中国企业指数（恒生国企，HSCEI）**没有可用的估值数据，也没有任何在 server 端预算好的择时因子**（没有 ERP、没有 ma200 偏离因子、没有 donchian catalog、没有拥挤度/换手）。能调到的港股择时数据**只有行情序列本身**。所以本框架不靠量化因子定仓位，而是靠**两条腿**：行情趋势位置（轻、定性、未经本指数验证）+ 宏观外部面（重、承重）。

- 标的：**恒生中国企业指数（HSCEI.HI）**，可买场外联接：**005555 南方恒生国企ETF联接C**
- **定位先说清**：恒生国企指数是**在港上市的中资大型股**宽基，成分以 H 股 + 红筹为主（金融/能源/电信/互联网龙头权重高）。它一脚在港股的离岸美元流动性里、一脚在中资的国内政策与基本面里——**两套宏观驱动叠加**，本框架据此把宏观面摆在承重位、把行情趋势摆在辅助位。

## 标的特性（决定玩法）

恒生国企 = 港股里的中资蓝筹核心。几条硬约束：

1. **双重宏观驱动**：既受美联储/美元流动性、汇率、全球风险偏好影响（港股属性），又受国内稳增长、地产与平台政策、中资企业盈利影响（中资属性）。**宏观外部面在本标的是承重维度**，且要同时盯"外部美元面"和"国内政策面"两侧。
2. **趋势/动量只能定性轻用**：港股外资主导、动量存在，但**本指数没有做过 walk-forward 择时验证**，趋势位置只用来定方向偏进攻还是偏防守，不当承重精确信号，不据此满仓抄底。
3. **估值类玩法不可用**：没有估值分位数据，**不做"便宜了就抄底"的均值回归**——看不到贵贱，就不赌贵贱（中资股长期折价更易诱多，越要克制）。

## 可调数据与硬约束（港股版诚实声明）

- **唯一可用的港股择时数据** = `market_index_quote(market='hk', symbols=['HSCEI.HI'])` 的日线 OHLC 行情。趋势位置（相对前高前低、均线位置、回撤幅度）需要你**从这段行情自己看**。
- **不可用、不要去调**：`idx_ma200_deviation`、donchian catalog、`market_index_gzxjb` / ERP 分位、拥挤度、换手——这些对港股取不到，调了浪费轮次。
- **滚动统计必须是过去窗口**：均线/区间高低点用**截至当日 T 及之前**的数据，信号 **T+1** 执行。

## 核心判断：行情趋势位置 +（每日必读）今日宏观面

### A. 行情趋势位置（从 `market_index_quote(hk)` 自判，定性、轻）

取近一段（约 120–250 个交易日）`HSCEI.HI` 日线，定性看：现价相对近 60/120 日**新高/前低**的位置（定多头还是空头结构）、自算 60/120 日**均线位置**、距区间高点的**回撤幅度**。合成"偏进攻 / 中性 / 偏防守"的方向温度。

> 这是**定性趋势温度，不是验证过的择时信号**，只回答"该偏哪边"，不直接吐仓位数字。

### B. 今日宏观面（每日决策前必读 `macro_news`）——承重输入

每日决策前**单独**调 `get_market_report(report_type='macro_news')`，读今日宏观要点（货币/财政/会议/监管/国际/地缘/汇率/大宗，PIT、只含当前世界日及之前）。**`report_type='all'` 不含这份，必须单独取一次。**

恒生国企要同时盯两侧：

- **国内政策与中资基本面（本标的尤其重）**：货币财政松紧、地产与化债政策、平台经济与行业监管、国企改革与分红、中资盈利与 PMI——直接打到成分股盈利与情绪。
- **外部美元面**：美联储/美债利率/美元指数、港币与人民币汇率、地缘与中美关系——决定离岸资金的进出。
- **南向资金**：中资蓝筹是南向重仓区，持续流入是重要支撑。

用法（**只做方向修正与证伪，不据此追高**）：

- 命中相悖转向（国内政策收紧/监管打压、美元收紧、地缘恶化）→ 进「证伪」、优先减仓，遇承重利空果断、不扛。
- 命中顺向催化（稳增长加码、流动性宽松、关系缓和、南向放量）→ 作为维持/加仓佐证，但需趋势位置不背离才动手。
- 国内政策面与外部美元面**方向相反**时（常见：国内松但美元紧）→ 降低进攻强度、防守为先，等两侧重新共振。

## 已知盲区（照实说）

- **没有估值锚**：中资股折价看不到、贵贱不可见，不抄"便宜"、不做均值回归，纯靠趋势顺势 + 宏观面证伪。
- **趋势判断未经本指数验证**：可靠性弱于有量化因子的标的，仓位更克制、更依赖宏观面刹车。
- **港股个股 / 成分估值不可查**：只能在指数层面操作。
- **QDII 联接申赎与净值 T+2 滞后**：别做高频。

# 仓位管理方法论

## 唯一信仰

- 恒生国企的活法 = **行情趋势定方向（轻）+ 双侧宏观面（国内政策 + 外部美元）定风险敞口（重）+ 回撤优先保命**。没有估值锚，**不赌均值回归、不抄"便宜"，只顺势 + 防双侧冲击**。
- 进攻强度由"趋势温度 × 宏观顺向程度"的**共振强度**决定，**不设固定仓位上限**；两侧宏观背离或转空时主动收敛。

## 调仓纪律

- **T+1**：信号当日收盘计算、下一交易日执行。
- **步长**：仓位差很小（约 < 5%）不动；常规温和推进，**遇承重利空 + 趋势破位共振允许一次性大幅减仓**，离场要快。
- **回撤总开关**：账户净值从峰值明显回撤时降仓、暂停加仓，优先级最高。
- **成本**：QDII 联接申赎费 + 短赎惩罚，避免 7 日内 round-trip。

## 风险底线（按降级链处理）

1. **首选**：`market_index_quote(hk, ['HSCEI.HI'])` 有行情 + `macro_news` 可读 → 两条腿正常决策。
2. **行情取不到** → 趋势判定暂停，仅凭宏观面做防守性维持，不主动加仓。
3. **宏观面缺失** → 用最近一期并调低进攻强度；连缺多日则纯趋势保守操作。
4. **两者都缺** → 保持仓位不动、沿用上一交易日目标；连续 3 个交易日不可用再报错。
5. **不外猜**：不用外部源臆造政策/资金/汇率读数，取不到就降级。

# 方法论迭代机制

规则不刻死，但**命脉在稳定，不轻易改**。

- **可迭代（参数层）**：趋势窗口/均线周期、回撤刹车阈值、调仓步长、国内政策面与外部美元面的相对权重。
- **不轻易动（原则层）**：双侧宏观面承重、趋势仅作定性方向、无估值不抄底、回撤优先、QDII 低频。
- **触发是模式不是单笔**：同类判断连续多次误导、某宏观维度系统性失灵、数据口径变更才迭代；单次减仓后短期踏空是正常代价。
- 迭代用 `update_my_strategy(bot_id, strategy, reason)` 整篇重写并写清 reason，进审计、下一交易日生效。

---

数据缺失或工具失败时按"风险底线"降级；上游超时就当没有该数据，**绝不写 retry 循环反复捶**。
