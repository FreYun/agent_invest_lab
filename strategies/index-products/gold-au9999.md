# 黄金（上海金 AU9999）投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面各角度审视，自行综合判断该不该动、动多少。

- 标的：**上海金 AU9999 现货（人民币计价实物黄金）**。**取数走商品口径而非指数口径**：`commodity_market(market_type="spot", symbols=["AU9999"])`，不是 `market_index_quote`——这是黄金区别于股票指数的第一件事。
- **定位先说清**：黄金是**无现金流、无盈利、无估值**的货币 / 避险资产，它的价格不由"景气"或"业绩"驱动，而由**持有它的机会成本（实际利率）+ 货币属性（美元的镜像）+ 结构性需求（央行购金）+ 避险溢价**决定。所以本框架没有"估值视角""景气龙头视角"，取而代之的是**金价的锚（实际利率框架）+ 需求结构 + 宏观驱动**三条主线。

## 核心认知

黄金 = **实际利率的倒影 × 美元的镜像 × 央行结构性需求 × 避险溢价**，再叠一层人民币汇率（对国内金价）。五个特性决定怎么玩：

- **实际利率是最强母变量（负相关，最核心认知）**：黄金不生息，**美债实际利率（≈名义利率 − 通胀预期，看 10Y TIPS）就是持有黄金的机会成本**。实际利率下行 → 持金机会成本降 → 金价涨；实际利率上行 → 压金价。判金价，第一眼看实际利率方向。
- **美元是镜像（负相关）**：黄金以美元计价，美元强压金价、美元弱抬金价；常与实际利率同向作用（美联储鸽派 → 实际利率与美元同跌 → 金价双顺风）。
- **央行购金 / ETF 持仓是结构性需求，能让金价与实际利率阶段性脱钩**：近年全球央行去美元化、持续增持黄金储备，是金价的长周期底盘——这解释了"实际利率仍高、金价却屡创新高"的脱钩行情。**不能只盯实际利率，必须把央行购金这条结构性需求线单独纳入**，否则会在脱钩期反复看空做错。
- **避险溢价是脉冲，不是趋势**：地缘冲突 / 系统性风险时的避险买盘，单日脉冲大但持续性取决于事件级别——要区分"短期避险脉冲（易回补）"和"长期不确定性中枢上移（趋势级）"。
- **人民币计价是国内金价特有项**：上海金以人民币计价，**人民币兑美元贬值会抬升国内金价（相对伦敦金的溢价）**，反之压缩。所以国内金价 = 伦敦金（美元）× 汇率，判 AU9999 时不能只看伦敦金方向，要把汇率这条单独看。

驱动排序：**实际利率（10Y TIPS）≥ 美元指数 > 央行购金 / ETF 持仓（结构性需求）> 避险 / 地缘溢价 > 通胀预期 > 人民币汇率（国内金价特有）**。研究时先问三件事：

1. 实际利率方向如何、美元强弱？→ 决定金价的周期性中枢
2. 央行购金 / ETF 持仓在增还是减？→ 决定结构性底盘、判断是否处在"脱钩"行情
3. 趋势对不对、有没有避险脉冲、人民币汇率在动吗？→ 决定现在加还是减、国内金价相对伦敦金的偏离

## 一、金价的锚：实际利率框架（替代估值视角）

黄金没有 PE / PB——它的"贵贱"标尺是**机会成本（实际利率）+ 历史价位分位 + 结构性需求强度**，不是估值倍数：

- **实际利率框架（首要锚）**：金价与 10Y TIPS 实际利率长期负相关。实际利率处在高位且向上 = 持金机会成本高 = 金价逆风；实际利率见顶回落 = 顺风。**但这是"常态锚"，会被央行购金这条结构性需求线打破（脱钩期），别把实际利率当唯一开关。**
- **历史价位分位（截至当日 PIT，定性预警）**：金价在过去数年分位的位置——极高分位 + 投机净多头极端 + 全民进场 = 顶部泡沫定性预警；极低分位 + 实际利率见顶 + 央行购金延续 = 潜在底部观察。**分位只做定性预警，不做"高了就空、低了就满"的机械择时。**
- **结构性需求强度**：央行购金 / ETF 持仓是金价的"基本面底盘"——底盘强（持续购金）时，即便实际利率逆风，金价的下行空间也被托住；底盘弱（央行转抛 / ETF 流出）时，逆风更猛。

**在上升趋势中，"金价已经涨很多 / 价位很高"绝不构成减仓或拒绝进场的理由——"趋势 > 价位"是单向过滤器，只否决"因为高所以走 / 不进"，不是无视极端价位的通行证。** 择时主轴整个交给趋势 + 实际利率 / 美元 / 央行购金框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 价位"只支持一件事——**不靠"跌了不少 / 看着便宜"去接飞刀**；极端读数仍是要认真对待的定性信号。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**黄金还要额外把实际利率 + 美元方向纳入**——金价趋势与实际利率 / 美元背离时，以后者为主参考（宏观锚常领先金价）。

- **方向锚（双层）**：
  - 价格层：金价（AU9999）vs 过去 200 日均线 + 斜率 + 价格分位（截至当日 PIT）
  - 宏观层：美债实际利率 + 美元指数方向 + 央行购金强度——**这层常领先金价**
  - **两层共振时信号最强；只有金价涨而实际利率没降、美元没弱、央行购金没增 → 多半是避险脉冲，须谨慎、预设回补。**
- **波动率**：金价过去 N 日收盘滚动波动率；黄金常态波动低于股票，**一旦波动骤增（往往是避险脉冲或宏观冲击）即降仓信号**。
- **事件跳空甄别**：FOMC / 非农 / CPI / 地缘消息常造成金价跳空，要分清是**逻辑级（实际利率 / 美元方向真转向）**还是**情绪脉冲（避险一日游）**——前者可顺势，后者易回补。
- **内外盘背离**：AU9999（人民币）与伦敦金（美元）背离，多由**人民币汇率**造成——伦敦金平、人民币贬值时 AU9999 仍可独立走强（或反之）。判国内金价别只看外盘，把汇率这条单独看。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）

> **重要前提：本标的尚未跑过系统的择时因子筛选，没有任何已验证的"绿灯"主因子。** 黄金在直觉上是经典的趋势性资产（货币属性 + 央行结构性需求易形成持续趋势），但**这是定性认知、不是本系统的验证结论**——不要把任何价格类因子当作经验证的承重信号。下列指标只能作**降回撤辅助 + 未验证客观第二意见**，方向裁决权交回实际利率 / 美元 / 央行购金框架。读数可用金价收盘序列按公式自算（**信号按当日收盘计算、下一交易日 T+1 执行**）。

- **`trail_dd` 回撤止损族（通用断后，本标的当前主力机械工具）**：金价收盘从过去约 120 日滚动峰值回撤超一档 → 降仓 / 空仓，站回均线 → 回归。**纯收盘价、无代理失真，作通用降回撤断后线相对可靠**——职责是躲过金价深调段、给框架犹豫时客观的"先降一档"线，**是降回撤工具不是收益增强器、更不抓顶底**。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；只看价格，对实际利率 / 央行购金拐点零预警。**注：未经本标的专门筛选定级，先按"通用降回撤工具"用，待跑过筛选后照实定级。**
- **时序动量（仅快读，不承重）**：20 日 / 数月动量可作"金价趋势还在不在"的快读数；黄金趋势性相对强、动量快读参考价值或许高于多数股票指数，但**未经本系统验证前不承重**，震荡期翻转当噪声。
- **市场情绪 / VIX + 投机净多头（拥挤第二意见）**：`macro_50etf_vix` 与 CFTC 黄金非商业净多头极端值，可作"避险情绪 / 投机拥挤是否到极端"的定性第二意见——极端净多 + 全民进场是顶部拥挤预警，不单独触发交易。

**共同纪律**：本标的没有经验证的绿灯因子——择时主轴是**实际利率 + 美元 + 央行购金 + 避险的宏观多维判断**，价格类因子只做降回撤断后与未验证第二意见。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。**待研究室对本标的跑完因子筛选后，再据结论更新本节定级。**

## 三、需求结构视角（替代景气视角：央行 + 投资 + 实物三块需求）

黄金没有"景气链"，但有清晰的**需求结构**，按性质分三类：

- **结构性需求（央行，最重、最慢）**：全球央行购金 / 黄金储备占比变化——去美元化背景下的长周期底盘，**领先且持久，是金价中枢上移的结构性力量**。看央行购金的方向与持续性，不看单月波动。
- **投资需求（ETF + 投机，中频、与实际利率联动）**：全球黄金 ETF 持仓（SPDR 等）+ CFTC 投机净多头——与实际利率 / 美元方向联动，是金价的中周期放大器；ETF 持仓回升 = 投资需求确认，投机净多极端 = 拥挤预警。
- **实物需求（金饰 / 工业，低频、价格敏感）**：金饰（中印为主）、工业用金——价格高时实物需求受抑、价格低时托底，是慢变量、弱择时价值，作背景。

判断要点：

- **央行购金定中枢、投资需求定节奏、实物需求作背景**：三者方向一致（央行买 + ETF 增 + 实物稳）时金价底盘最强。
- **脱钩行情的解释变量在央行**：当金价与实际利率背离（实际利率高金价仍强），答案通常在央行购金的结构性买入——**这种时候别机械按实际利率看空**。
- **拥挤即风险**：投机净多头极端 + ETF 持仓陡升 + 全民进场 = 短期拥挤，回调风险抬升（不改长期趋势，但提示节奏上该谨慎）。

## 四、宏观驱动视角（黄金的命脉维度）

这是黄金的核心，几乎所有金价波动都从这里来：

- **美债实际利率（10Y TIPS）= 最强负相关母变量**：黄金的机会成本。实际利率下行 → 金价涨；上行 → 压金价。看美联储货币政策路径（降息 = 实际利率下行预期 = 利好黄金）。
- **美元指数 = 负相关母变量**：美元强压金价、美元弱抬金价；与实际利率常同向。
- **央行购金 = 结构性母变量**：去美元化 / 储备多元化的长周期买盘，是近年金价与实际利率脱钩的关键——**把它当独立的第三条母变量，不是实际利率的附属**。
- **通胀预期 = 实际利率的组成项**：实际利率 = 名义利率 − 通胀预期。通胀预期升而名义利率没跟上 → 实际利率降 → 利好黄金；但单看名义通胀不是第一驱动，要落到实际利率。
- **避险 / 地缘 = 脉冲项**：系统性风险 / 地缘冲突时的避险买盘，脉冲大、持续性看事件级别。
- **人民币汇率 = 国内金价特有项**：AU9999 = 伦敦金 × 汇率，人民币贬值抬升国内金价。判 AU9999 必须把汇率单独看。
- **全球流动性 / 货币政策**：宽松周期（降息 + 扩表）整体利好黄金，紧缩周期逆风——通过实际利率与美元传导。

## 五、风险管理视角

收益越大、价位越极端、投机越拥挤，仓位越保守——这是原则，不是公式。黄金常态波动低，但宏观冲击 / 避险脉冲时跳变快，纪律不可省：

- **实际利率 / 美元反转预警**：实际利率从降转升、美元从弱转强 → 金价系统性逆风，不必等价格回撤就该降仓。
- **结构性需求转向预警**：央行购金放缓 / 转为净抛、黄金 ETF 持续流出 → 长周期底盘松动，重仓信心下调。
- **拥挤预警**：投机净多头极端 + 全民进场 + 价位历史高分位 → 短期回调风险抬升，收紧浮盈管理。
- **避险脉冲回吐**：纯避险驱动的上涨，事件缓和后易回吐——避险脉冲段的浮盈兑现要更快。
- **事件前减敞口**：FOMC / 非农 / CPI / 重大地缘节点前后跳空风险大，单押方向胜率低；不明朗时降仓或观望。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（实际利率下行 / 美元转弱 / 央行购金）大概率已破。

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立。须**对称**——踏空与做错都是失分。

- **实际利率证伪（下行，最关键）**：美债实际利率确立上行趋势——金价最强母变量逆风。
- **美元证伪（下行）**：美元指数确立强势趋势——金价镜像逆风。
- **结构性需求证伪（下行）**：央行购金放缓 / 净抛、黄金 ETF 持续流出——长周期底盘被抽走。
- **趋势证伪（下行）**：金价跌破过去 200 日均线且 1 月未收回，但应根据当时市场环境修正指标；`trail_dd` 回撤族触发 = 价格面确认走坏。
- **拥挤证伪（下行，反向）**：价位历史高分位 + 投机净多头极端 + 全民进场 + 卖方高呼"金价破 X、黄金超级周期"——顶部拥挤的危险组合。
- **看空被证伪（上行 veto-watch）**：实际利率见顶回落 / 美联储转鸽；美元转弱；央行购金加速、ETF 持仓回升；地缘 / 系统性风险升级抬升避险买盘；人民币贬值抬升国内金价——这些会成为"看空"判断的上行风险，看空被证伪时回补要果断，犹豫即失分。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 黄金是**宏观驱动 + 货币 / 避险属性**的资产，常态波动低于股票，但单标的择时策略的提升仍来自**压低最大回撤 + 宏观方向判对**。你的活儿是实际利率转升 / 美元转强 / 央行购金转向 / 拥挤极端来时少亏，趋势顺风时在场吃足。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法；**但"合法"是双向的：信号不支持在场时空仓完全正常、不必愧疚，信号支持在场时却空仓 = 踏空、同样违规**。不为了在场而在场，也不为了"稳妥 / 留子弹"而缺席。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把回撤控仓的事后闸门误用成事前枷锁。
- **该在场时别缺席，这是和"别一把满仓"对等的硬约束，不是软提醒**：当 **金价趋势多头 + 实际利率下行 / 美元转弱 / 央行购金至少一项同向**（核心共振成立、且 `trail_dd` 未触发）时，**默认目标就是重仓到满仓**；此时仍要轻仓或空仓，**必须当天写明一条具体的、命名的减仓理由**——只能取自〔震荡市已认定 / 波动骤增 / 事件窗口跳空风险 / 纯避险脉冲无宏观支撑 / 投机拥挤极端 / 净值回撤闸门已触发 / 某条证伪已命中〕之一。**写不出具体理由 = 该满仓而没满 = 踏空失分；"留点子弹""感觉有点高""谨慎起见"都不算理由，那是自我设限。** 在场与否只看金价趋势 / 宏观与风险，绝不拿"价位已经很高"当离场或拒绝进场的理由。
- 不用硬止盈硬止损——择时交给趋势、宏观、回撤说话，不交给固定数字（但**机械回撤止损 `trail_dd` 是断后命脉**）。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

- **识别标准**：
  - **趋势市**：金价（过去 MA60 / MA120）单边排列、斜率明显，**且实际利率 / 美元方向同向**。
  - **震荡市**：过去 200 日均线走平 + 金价在均线 ±一定区间内来回 + 箱体反复假突破 + **实际利率 / 美元无明确方向**。
  - **过渡待定**：信号不清、金价与实际利率 / 美元背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住，方向转空（金价转跌 / 实际利率转升 / 美元转强 / `trail_dd` 触发）就降仓乃至清空。
  - **震荡市 → 防守、轻仓**：箱沿小幅动，绝不重仓赌箱体，宏观转向（FOMC / 实际利率破位 / 央行购金）有效突破即交接。

**状态要有粘性**：跨日继承昨日结论，单日跳空（FOMC / 非农 / 地缘）不算切换；切换需站稳数日 + 宏观同向。状态切换慢于价格是特性不是缺陷。每天显式记下状态标签 + 理由 + 推翻条件，让明天继承。

## 二、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合**：最小步长 20%，2%–5% 微调无意义。
- **系统性逆风 / 实际利率转升 / 美元转强 / 央行购金转向 / 趋势转空（`trail_dd` 触发）→ 一把降到位，可以到 0**：宏观逆风确立后金价下行可能加速，等"确认"就晚了。
- **趋势重新转多 → 按赔率下注**：高赔率组合是 **实际利率下行 + 美元转弱 + 央行购金加速 + 趋势放量** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分大步、轻仓或放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）：低赔率时，带损失的下注代价高于错过，所以宁可观望**——但这只约束低赔率情形；**高赔率时正相反：踏空没有止损、错过的趋势不会回来，代价上不封顶，轻仓 / 犹豫才是真正的"做错"，即失分。**
- **只在浮盈、趋势未坏的回调里加仓；绝不下跌摊薄（接飞刀）。**
- **避险脉冲专条**：纯避险驱动的浮盈，兑现节奏应快于宏观趋势驱动——避险的利润窗口天然更短。
- **离场像踩刹车（一脚到底），回场看赔率强弱。**

## 三、止盈止损：用趋势、宏观和回撤说话，不用固定数字

- **止损快、止盈慢**：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设固定点位。在场只盯三件事：**趋势破没破（含实际利率 / 美元方向、`trail_dd` 触发）** + **从持仓高点回撤多少** + **结构性需求 / 拥挤有没有反转**。趋势在、回撤温和 → 拿住；破位或回撤放大 → 大块兑现乃至清空。
- **保本线**：浮盈到位后离场线抬到成本价，浮盈不许变浮亏。
- 亏损端窄而果断、浮盈端宽而敢加，两套口径不混用。

## 四、回撤控仓（账户级总开关）

- 回撤数学不对称：−20% 要 +25%、−33% 要 +50% 才回本。黄金常态波动低，但宏观冲击下也能深调，这条照样命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤 → 机械降仓 / 停止加仓，哪怕宏观信号没转向；继续扩大 → 空仓复盘。事后闸门，**不得反着用**（不拿假想跌幅反推事前仓位天花板），`trail_dd` 是这条的机械化身。
- 状态不好就主动缩量；回撤收复、趋势重新转多再回补。

## 五、成本意识

- 7 日内赎回有早赎惩罚费率，避免同标的 7 日内 round-trip。
- 黄金常态趋势慢、波动低，**更没必要高频折腾**——宏观 / 避险新闻天天有诱惑，克制脉冲交易；该动就动，但每笔得能赚回成本。

## 六、实战判断：成对矛盾的格言，环境决定用哪条

环境抓手就是前面的趋势、实际利率 / 美元、央行购金 + 投资需求、避险脉冲性质、价位 + 拥挤极端。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 实际利率高黄金该弱 | 央行购金托住金价 | 看央行购金 / ETF：结构性需求强可抵消实际利率逆风（脱钩行情）→ B；纯实际利率主导期 → A |
| 避险买金该追 | 避险脉冲一日游 | 看事件级别 + 持续性：长期不确定性中枢上移 → A（趋势）；短期避险脉冲 + 实际利率没动 → B（回补） |
| 价位太高该减 | 趋势向上无视价位 | 实际利率下行 + 美元弱 + 央行购金的趋势看 B；投机净多极端 + 全民进场时极端价位当顶部预警 |
| 美元强金价该跌 | 人民币贬值抬国内金价 | 判 AU9999 要拆汇率：伦敦金弱但人民币贬，国内金价可独立走强 → 看汇率这条 |
| 通胀高该买金 | 看的是实际利率不是名义通胀 | 通胀升但名义利率跟涨（实际利率没降）→ 未必利好；通胀升而实际利率降才是 A |
| 让利润奔跑 | 落袋为安 | 宏观趋势 + 保本线就位看 A；避险脉冲驱动 / 拥挤极端 / 价位顶部预警看 B |

> **核心一句**：黄金（AU9999）——用 **实际利率 + 美元 + 央行购金 + 避险** 判方向、用 **实际利率框架 + 历史价位分位 + 结构性需求强度** 判位置（**没有 PE / PB**）、价格因子未经本系统验证、只用 **`trail_dd` 降回撤断后 + 时序动量快读（待筛选再定级）** 择时、用 **大开大合 + 压最大回撤** 做仓位；取数走 `commodity_market`（AU9999 现货）、判国内金价要拆汇率、脱钩行情别机械按实际利率看空、避险脉冲预设回补、信号不支持空仓不愧疚 / 信号共振该满仓不手软，靠宏观判对方向 + 压回撤把净值曲线做稳。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某锚对金价系统性失灵（如实际利率框架长期脱钩）、出现框架没覆盖的新机制（货币体系结构变化、新的结构性购金来源）。
- **优先补"择时因子定级"这块空白**：本标的尚未跑因子筛选，一旦研究室给出筛选结论，应据实把择时指标节从"未验证"升级为带定级的版本——这是本框架当前最大的待补项。
- **定期 + 事件驱动**：一轮金价周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（回撤档、均线 / 动量周期、价位分位档、拥挤极端定义）、各锚权重与排序、需求结构维度、新增失效模式与证伪条件、**择时因子定级（筛选结论出来后照实写入）**。
- **不轻易动（信仰与原则层）**：唯一信仰（实际利率下行 + 美元弱 + 趋势确认重仓、实际利率转升 + 美元强降仓）、实际利率 / 美元 / 央行购金是母变量、央行购金能让金价与实际利率脱钩、黄金无估值只有锚、风险优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空、对本金保守对趋势放纵。动这些要有极强且反复验证的证据。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：只为过程性、可重复的错误改方法论；好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式，不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，`reason` 讲清改了什么、为什么、依据是什么。
- **小步快迭代优于大改**：一次只调一两处。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；货币体系 / 去美元化结构、央行购金长期格局是结构变化（写进框架）。
- **诚实纪律不可动**：本标的当前"无经验证绿灯因子、价格因子按未验证对待"的结论须照实保留，**不得把任何未验证的趋势信号包装成进场扳机**；待筛选结论出来再据实定级。
- **保留可证伪性 + 迭代也会错**：改到"怎么走都对"就是过拟合；新版表现更差或依据被证伪，敢于回退。
