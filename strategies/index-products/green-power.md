- 数据闸门：因子 / 行情已在 simworld-data 侧按 PIT 入库；调工具传当日 `date` 即可，`simulated_datetime` 由 proxy 自动注入。

## 核心认知

绿色电力（中证绿色电力 931897）= **发电运营商**的集合，赚的是**卖电的现金流**——光伏运营、风电运营、水电运营为主，本质是**低波动、防御、类债**的公用事业板块。它**不是**制造业（中证光伏产业 931151 是组件 / 硅料 / 逆变器制造，逻辑完全不同），**不要用产能周期框架去套它**。

它的盈利公式很简单：

> **盈利 ≈ 装机增长 × 上网电价 × 利用小时数 − 财务费用**

这四个变量决定了它的全部脾性：

- **类债、低波动、防御**：电费现金流稳定、可预测、可分红，β 小、波动小，跌得浅、涨得也慢。它是**下行保护 / 底仓型**资产，**不是高弹性成长**——指望它翻倍是用错了工具。
- **高负债、重资产、利率敏感**：建电站要大量举债，财务费用是利润表上的大头。**利率下行 = 融资成本降 = 利好；利率上行 = 利空**——这是它最像债券的地方，利率方向是核心择时变量之一。
- **盈利稳、估值有中枢**：和成长股不同，绿电盈利不会因周期坍塌（分母 E 不坍塌），所以**估值（PB / 股息率 / PE）有均值回归中枢，历史分位可以用**——低估值 + 高股息 = 布局区。这是它和成长股最本质的择时差异。
- **政策驱动需求与价格**：电价市场化改革、绿证 / CCER 绿电溢价、补贴拖欠、消纳 / 弃风弃光率——这些政策与运营变量直接左右现金流质量。

驱动排序：**现金流 / 股息（价值锚）> 估值分位（均值回归）> 电价 / 运营（盈利质量）> 利率方向（类债择时）> 政策催化**。研究时问三件事：

1. 现金流稳不稳、股息够不够、估值便不便宜？→ 决定**值不值得拿、是不是布局区**
2. 电价、利用小时、消纳、补贴这些运营基本面有没有恶化？→ 决定**底仓质量是否动摇**
3. 利率方向、政策（市场化让利 / 绿证溢价）有没有变？→ 决定**加减节奏**

## 指标使用纪律：先验证、再上场

经营现金流、股息率、上网电价、利用小时数、弃风弃光率、应收账款（补贴拖欠）这些**运营经济变量**是直接因果事实，不需要统计验证——需要的是数据是否真。

但任何**派生统计指标**（动量、趋势突破、估值分位的择时阈值、情绪打分、技术指标）在被当作交易理由前，**必须先在绿电指数上验证它有没有效**：明确可证伪命题、足够长样本、方向 / 胜率 / 赔率俱全、样本外稳定、有业务解释。没工具直接回测时（常态），降级到 mem0 / 研报 / 历史样本检索过去 N 次触发后走势，至少 5 次独立样本方向一致才能用；样本不足明确标"未验证、仅观察"。

**自检**：每次用派生指标推动决策时先问"我验证过吗？依据是什么？"——答不上来就当没看见，回到运营经济变量本身找答案。

### 绿电指数特性：

1. **类债、估值会回归（与成长股相反）**：绿电盈利稳，分母 E 不坍塌，PB / 股息率 / PE 有中枢、能做历史分位均值回归。**低估值 + 高股息买、估值过热 + 股息率压缩减**——这正是成长股不能做、绿电能做的事。
2. **利率是它的影子分母**：高负债重资产让财务费用对利率极度敏感。利率下行周期是绿电的系统性顺风（融资成本降 + 类债资产相对吸引力上升），利率上行是逆风。看绿电必须同时看 10 年期国债收益率方向。
3. **现金流质量比账面利润重要**：补贴拖欠会让"账面有利润、现金收不回"。盯**经营现金流 / 应收账款**，警惕"利润好看但现金流恶化"的伪稳定。
4. **政策是双刃**：电价市场化改革（标杆电价 → 市场化交易电价，可能让利降价）、消纳红线（弃风弃光率上升直接砍发电量）、绿证 / CCER（绿电溢价是增量收益）、补贴退坡——既是 α 来源，也是杀伤来源。

## 一、现金流与股息视角（绿电的核心价值锚）

绿电是公用事业，**盈利由稳定的电费现金流主导，价值锚是现金流与分红能力，不是成长想象**。

- **经营现金流稳定性**：卖电收入可预测，经营现金流是绿电价值的地基。现金流稳 + 可持续 = 底仓资格；现金流被补贴拖欠 / 电价下行侵蚀 = 价值锚松动。
- **股息率（最重要的布局信号）**：股息率是绿电的"债券票息"。**股息率处于历史高位 = 价格相对现金流便宜 = 布局区**；股息率被价格涨上去压缩到历史低位 = 性价比变差 = 减仓提示。
- **分红能力与持续性**：自由现金流能不能覆盖分红、负债率会不会逼停分红——分红的可持续性比当期股息率数字更重要。

成长性（装机增长空间）只用来判断**底仓能不能略加重**，不用来当高弹性成长股炒——绿电的超额来自"便宜时买稳定现金流"，不是"赌装机爆发"。

## 二、估值视角（用 PB / 股息率 / PE，可做历史分位均值回归）

绿电是**盈利稳定的公用事业，可以用 PE / PB 历史分位做均值回归择时**——这是它和成长制造（光伏 931151 禁用 PE 分位）的根本区别：绿电盈利不坍塌，分母不缩水，估值有中枢、会回归。

- **PB / PE 历史分位**：低分位 = 便宜 = 布局区，高分位 = 贵 = 减仓预警。绿电的均值回归是有效的，因为盈利锚稳定。
- **股息率分位（反向用）**：股息率高分位 = 便宜，股息率低分位 = 贵。和 PB / PE 分位交叉验证，方向一致信号更强。
- **极端高估的定性预警**：当绿电被当成"稳健避险"资金疯涌、股息率压到历史最低、估值脱离现金流锚时，当顶部提示——哪怕基本面没坏，性价比已差。

**低估值 + 高股息 = 最强布局信号**；**高估值 + 低股息率 = 减仓信号**。估值分位是绿电择时的主力，不是辅助。

## 三、电价与运营视角（盈利质量的来源）

绿电盈利 = 装机 × 电价 × 利用小时 − 财务费用，电价与运营决定"赚不赚得到、赚得稳不稳"。

| 维度 | 代表变量 | 性质 |
|---|---|---|
| 上网电价 | 标杆 / 燃煤基准电价、市场化交易电价、电价市场化改革进度 | 核心（直接定价收入） |
| 绿电溢价 | 绿证价格、CCER 重启 / 交易、绿电交易溢价 | 增量收益（政策驱动） |
| 利用小时 | 风 / 光 / 水的利用小时数、资源条件（来水 / 风资源） | 决定发电量 |
| 消纳 | 弃风率 / 弃光率、消纳红线、特高压外送、储能配套 | 砍发电量的风险闸门 |
| 补贴 | 可再生能源补贴拖欠、应收账款、补贴核查发放进度 | 现金流质量 |

**电价市场化改革是绿电最大的中期变量**：从固定标杆电价转向市场化交易，可能意味着让利降价（利空），也可能在电力紧缺地区量价齐升（利好）——要看具体省份与电源结构。绿证 / CCER 是绿电溢价的增量。消纳恶化（弃风弃光率上升）直接砍发电量，是运营端的核心风险。补贴拖欠不影响账面利润但侵蚀现金流。

## 四、利率与趋势视角（类债择时锚 + 诚实的趋势无效结论）

绿电高负债重资产，**利率方向是它最像债券的择时变量**：

- **利率下行 = 融资成本降 + 类债资产相对吸引力上升 = 系统性利好**；利率上行反之。看绿电必须盯 10 年期国债收益率方向（`macro_data`），这是公用事业的"影子分母"。
- 利率方向不是单日波动，看的是趋势性的降息 / 加息周期、国债收益率的中期方向。

**关于量化趋势择时——诚实纪律，必须照实写：**

绿电的趋势择时**经回测验证为无效**，不使用。在 931897 绿色电力指数上：

- **donchian_60 趋势突破 ❌ 跑输 buyhold**：因子 Calmar 0.05 vs buyhold 0.09，跑输。
- **trail_dd15 回撤止损 ❌ 跑输 buyhold**：因子 Calmar −0.11 vs buyhold 0.09，跑输（为负）。

**原因（从回测与业务可推，照实说）**：绿电是低波动公用事业，趋势性弱、没有可被趋势系统捕捉的持续单边行情，趋势突破在它的窄幅震荡里被反复 whipsaw（假突破），止损线被来回打穿。这恰恰印证了一条规律：**低波动公用事业只能用估值 / 股息价值锚择时，不能用趋势择时**。

所以绿电的择时**主要靠**：**估值分位（低估买）+ 股息率（高息买、低息减）+ 利率方向（下行友好）+ 电价 / 政策（市场化让利 / 绿证溢价）**。趋势**只用 200 日均线做定性辅助**——用来感知"现在是不是整体走弱、要不要更谨慎执行"，绝不作为加减仓的主因，更不用 donchian / trail_dd 这类量化趋势信号机械触发。

## 五、风险管理视角

绿电的杀伤来自现金流质量恶化与利率 / 政策逆风，不是产能周期，也不是高波动踩踏（它本就低波动）。主要风险：

- **电价下行 / 市场化让利**：电价市场化改革落地为降价让利，直接砍收入与现金流——绿电最核心的中期风险。
- **消纳恶化 / 弃电率上升**：装机过快、电网消纳跟不上，弃风弃光率上升直接砍发电量，量价双杀。
- **补贴拖欠 / 现金流恶化**：可再生能源补贴拖欠加剧、应收账款膨胀，账面利润收不回现金，分红能力受损。
- **利率上行**：融资成本上升 + 类债资产相对吸引力下降，对高负债的绿电是系统性逆风。
- **来水偏枯（含水电时）**：水电运营占权重时，枯水年来水偏少直接砍水电发电量与利润。
- **极端高估**：避险资金疯涌把绿电股息率压到历史低位、估值脱离现金流锚时，性价比变差，任何边际利空都可能回调。

原则：**电价在下行、消纳在恶化、补贴拖欠加剧、利率在上行、估值在高位股息率被压缩时，仓位越保守**。但绿电是底仓型资产，降仓的幅度与频率都应远低于成长制造——它的价值是"稳稳拿着收现金流 + 等便宜了加"，不是大开大合。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（低估值 + 高股息 + 电价稳 + 利率友好）的破坏**。下列任一发生，应严肃重评持仓而非死扛；触发不等于必须立刻清仓，但意味着此前布局论据已不成立，需要新论据才能继续持有。

- **现金流证伪**：经营现金流持续恶化、补贴拖欠加剧、应收账款大幅膨胀，"稳定现金流"前提被打破。
- **股息证伪**：股息率被价格涨上去压缩到历史低位、或分红能力因负债 / 现金流问题下降，"高股息"布局理由消失。
- **估值证伪**：PB / PE 升到历史高分位、估值脱离现金流锚，"低估值"理由作废。
- **电价证伪**：电价市场化改革落地为系统性降价让利、绿电溢价（绿证 / CCER）证伪，收入端逻辑破坏。
- **运营证伪**：弃风弃光率持续上升、消纳红线收紧、利用小时数趋势性下滑。
- **利率证伪**：进入明确的加息 / 利率上行周期，类债顺风逆转。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作：先识别绿电当前由哪个子板块主导，再判断现金流 / 估值 / 电价 / 利率是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导子板块，再定强弱

绿电指数由水电运营 / 风电运营 / 光伏运营等子板块构成，逻辑常不同步。每天先问两件事：

1. **谁在主导指数**：看成分权重、领涨领跌成分、成交额集中在哪个子板块（水电、风电、光伏运营），判断当前定价的是来水 / 电价、消纳、还是补贴 / 利率。
2. **主导子板块信号强不强**：主导子板块的现金流、股息、电价、消纳、利率是否同向。不能用水电的来水改善去解释光伏运营的补贴拖欠问题。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 估值分位、股息率、电价 / 现金流、利率方向至少三项同向，且无重大证伪 | 可做底仓上的中等动作，10%-20% 步长 |
| 中信号 | 两项同向、一项待确认 | 小幅调整、持有、等确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线波动 | 只记录，不交易或极小动作 |

研报观点本身不是交易信号，只提供假设与数据线索，必须被估值、股息、电价、现金流、行情共同验证。

3. 关键数据至少两源交叉验证（研报、行业协会、公司财报、行情、宏观），任意两类相互印证才算中信号以上。

## 四、交易决策矩阵

| 估值 / 股息 | 电价 / 现金流 | 利率方向 | 消纳 / 补贴 | 动作 |
|---|---|---|---|---|
| PB / PE 低分位 + 股息率高 | 电价稳、现金流好 | 利率下行 / 友好 | 消纳健康、补贴正常 | 加仓到中高底仓 |
| 估值中性 + 股息中性 | 电价稳、现金流稳 | 利率平稳 | 健康 | 持有底仓不动 |
| 估值偏低但有瑕疵 | 现金流稳但补贴有拖欠 | 利率平稳 | 补贴拖欠但可控 | 维持底仓、不追加 |
| 估值高分位 + 股息率被压缩 | 电价 / 现金流尚可 | 利率平稳 | 健康 | 减仓回底仓中枢 |
| 任意 | 电价市场化系统性让利 / 现金流恶化 | 利率上行 | 弃电率上升 / 补贴拖欠加剧 | 降仓，逻辑证伪则清到低位 |

**矩阵使用约束**：要**多列共振**才触发动作；单列变化（尤其短线行情）= 信号不足 = HOLD。绿电是底仓型，决策矩阵的默认重心是"持有底仓 + 便宜了加 + 贵了 / 逻辑坏了减"，不是空仓 / 满仓大切换。

## 五、研报到交易动作的转换

读研报五步走：

1. **提炼结论**：研报在看多什么——低估值修复、高股息、电价改革红利、绿证溢价，还是装机成长。
2. **拆假设**：拆成可验证假设，如股息率处于历史高位、电价市场化未让利、补贴拖欠改善、利率进入下行。
3. **找证据**：用行情、成分股估值 / 现金流、宏观利率和其他研报交叉验证，不接受单一卖方口径。
4. **映射矩阵**：把验证后的信号放进决策矩阵，证据不够就停在持有底仓或观察。
5. **写反证**：每次动作写一句"什么发生就说明我错了"，便于证伪与复盘。

研报只讲装机成长、不讲现金流和电价；只讲长期空间、不讲补贴拖欠与消纳；只讲股息率数字、不讲分红可持续性的，降级为弱信号。

# 仓位管理方法论

## 唯一信仰

- 绿电的超额，来自**在低估值 + 高股息 + 电价稳 + 利率友好时逆向加底仓，在估值过热 / 股息率被压缩 / 电价下行 / 利率上行 / 现金流证伪时减仓**——不是靠大开大合吃 β，更不是靠趋势追涨杀跌（趋势在绿电上回测无效）。
- 绿电是**下行保护 / 底仓型公用事业**，玩法是**稳健底仓 + 逆向布局**：波动小、换手低、防御优先。它的价值是"稳稳拿着收现金流，便宜了加、过热了减"。
- 仓位由**现金流 / 估值 / 股息（价值锚）+ 利率方向（类债锚）**共同决定，**不用趋势锚**（趋势择时已验证无效）。200 日均线只做定性辅助。
- 不用硬止盈硬止损，用估值分位 / 股息率 / 电价现金流 / 利率方向 / 回撤说话。
- **对本金稳健、对现金流耐心**：绿电的回撤本就浅，最大的错误是把底仓型资产当成长股频繁折腾，被摩擦成本吃掉股息收益。

## 一、仓位步长：稳健底仓，逆向小步加减

- 绿电是底仓型，**默认有一个常态底仓**（如净资产的 40%-50%），不轻易空仓、也不轻易满仓 all-in。
- 加减以**逆向布局**为主：低估值 + 高股息时小步加（每次 10%-20%），估值过热 / 逻辑证伪时小步减回中枢。
- 换手要低：绿电波动小，频繁进出会被申赎成本吃掉本就不高的弹性。**默认动作是 HOLD 底仓**。

## 二、先识状态：估值 / 股息分位 + 现金流 / 利率环境

先定**估值 / 股息分位**（便宜 / 中性 / 贵），再看**现金流与利率环境**（友好 / 中性 / 逆风），两锚叠加定打法：

- **低估值 + 高股息 + 利率友好 + 现金流稳** → 逆向加底仓到中高位，最好的布局区。
- **估值中性 + 现金流稳 + 利率平稳** → 持有底仓不动，收现金流。
- **估值高分位 + 股息率被压缩** → 减回底仓中枢，落袋部分浮盈。
- **电价市场化让利 / 现金流恶化 / 利率上行 / 消纳恶化** → 降仓，逻辑证伪则降到低位。
- 信息不明、判断不清时 → 守住底仓不动，不空仓也不追加。

## 三、双锚骨架：价值锚（现金流 / 估值 / 股息）+ 类债锚（利率方向）

- **价值锚**：决定"值不值得拿、是不是便宜"。低估值 + 高股息 + 现金流稳 = 布局区，高估值 + 低股息率 = 减仓区。**用 PB / PE / 股息率历史分位（绿电盈利稳、可均值回归）。**
- **类债锚（利率方向）**：决定"系统性顺风还是逆风"。利率下行加分、利率上行减分。绿电高负债重资产，利率是它的影子分母。
- **叠加**：价值锚决定底仓中枢能开多高，利率方向决定在中枢上方还是下方微调。**两锚共振（便宜 + 利率友好）才加重底仓；两锚背离就守中枢。**
- **不用趋势锚**：donchian / trail_dd 在绿电回测跑输 buyhold，趋势择时无效，不纳入仓位决策；200 日均线仅做"整体强弱"的定性参考。

## 四、非对称操作：逆向布局，证伪才降仓

- **便宜时逆向加（左侧）**：低估值 + 高股息是绿电的安全边际，可以在价格回调、股息率走高时分批左侧加底仓——绿电盈利稳，不会像成长股那样越跌分母越坍塌，左侧布局风险可控。
- **证伪才降仓**：电价系统性让利、现金流 / 补贴恶化、利率转上行、估值过热 + 股息率压缩——这些**基本面 / 价值锚的破坏**才是降仓理由，不是看价格短线跌了多少。
- **不追涨**：绿电涨上去 = 股息率被压缩 = 性价比变差，追高买的是更差的现金流回报。涨多了该想的是减，不是追。

## 五、止盈止损：用估值、股息、现金流、利率和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档，也不用趋势止损（趴 dd 在绿电无效）。
- 持仓盯五件事：**估值分位是否过热、股息率是否被压缩到低位、电价 / 现金流有没有恶化、利率方向有没有转上行、从持仓高点回撤了多少**。便宜 + 现金流稳 + 利率友好 → 拿住收现金流；估值过热 / 股息率压缩 / 现金流恶化 / 利率上行 → 减回中枢乃至降到低位。
- **移动减仓线**：浮盈到一定程度把减仓线抬到成本价附近——绿电波动小，浮盈来之不易，不让它变浮亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 绿电本就低回撤，最大的回撤风险来自利率上行周期 + 估值过热的双杀，或电价 / 现金流证伪。
- **你自己账户**从峰值明显回撤、且伴随价值锚 / 现金流恶化时，降仓乃至降到低底仓——哪怕"长期还是要配公用事业"。
- 回撤的另一面：绿电回撤浅是它作为底仓的价值，不要因为短期不涨就嫌弃它把仓位砍光——它的角色是**下行保护**，不是冲锋陷阵。

## 七、成本意识

- 绿电波动小、弹性低，**摩擦成本对它的伤害比对成长股更致命**：一次来回申赎可能就吃掉大半年的股息超额。
- **指增 / 场外基金 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。一笔进出得能赚回成本才值。
- 做的是估值 / 股息的低频逆向布局，频率天然该很低——绿电最忌讳被当成短线工具折腾。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金 / 指增组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD 底仓**；只有研究状态发生足够大的变化才允许交易。短线行情只能作验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清、证据不够时，**守住常态底仓**，不空仓也不追加。
- 当估值分位、股息率、电价 / 现金流、利率方向形成清晰共振（便宜 + 高息 + 利率友好）时，敢于逆向加底仓，仓位可提到 **60%-80%**。
- 进攻前先确认自己在"价值锚明确便宜"而非"情绪冲动追涨"；没有价值锚迁移，就算短线好看也不放大仓位。
- 回撤一旦因价值锚恶化而扩大，先保命再谈进攻：减仓回中枢、暂停加仓。
- 原则：模糊期守底仓，便宜期逆向加，证伪期收缩。

### 1. 交易触发闸门

交易前必须回答：**今天的研究结论相对上次持仓决策，发生了什么状态变化？** 只有下面几类变化可触发交易：

- **估值 / 股息变了**：PB / PE 分位进入低位（便宜）或高位（贵），股息率走到历史高位（便宜）或被压缩到低位（贵）。
- **电价 / 现金流变了**：上网电价 / 市场化交易电价、经营现金流、补贴拖欠（应收账款）改变此前判断。
- **利率方向变了**：进入明确的利率下行（利好）或上行（利空）周期。
- **运营 / 政策变了**：消纳 / 弃电率、利用小时、绿证 / CCER、电价市场化改革落地改变中期盈利假设。
- **风险状态变了**：核心逻辑证伪、账户回撤明显扩大。

只是 MA5/MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化而无上述研究状态变化，**不得交易**，只记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买卖加减的主因。
- 200 日均线只做**整体强弱的定性参考**，不能作为加减仓主因；**donchian / trail_dd 等量化趋势信号在绿电回测无效，禁止用于触发交易**。
- 连续涨跌、单日涨跌幅、短线趋势计数只能影响"今天是否更适合执行已成立的研究动作"，不能创造新交易理由。
- 交易理由若主要由均线、阳线数量、趋势计数构成，自动降级为 **不交易 / 继续观察**。

### 3. 最短持有期与反向交易冷静期

- 新加仓位原则上至少持有 **20 个交易日**，除非核心价值锚证伪、组合回撤风控、重大政策冲击。
- 减仓后原则上 **10 个交易日内不得反向买回**，除非明确估值 / 股息状态反转且至少两类数据交叉验证。
- 7 个自然日内禁止同一标的 round-trip，除非灾难性证伪；早赎惩罚会直接吞掉本就微薄的弹性。
- 同一周最多一次主动仓位调整；连续调整必须说明前一次判断为何失效。

### 4. 费用与预期收益门槛

- 交易前估计本次动作能否覆盖申购 / 赎回 / 早赎成本，覆盖不了不做——绿电弹性低，这条尤其卡得严。
- 预期持有期低于 20 个交易日的交易，必须有强研究证据和明确风险收益比，否则默认放弃。
- 为躲一天波动而交易通常不值得；为应对估值过热或价值锚证伪而交易才值得。

### 5. 仓位状态机

仓位在 **20% / 40% / 50% / 60% / 80%** 之间切换（**保留常态底仓，不轻易到 0% 或 100%**），每次切换对应研究状态变化：

| 研究状态 | 允许仓位 | 行动 |
|---|---:|---|
| 估值过热 + 股息率压缩，或电价 / 现金流证伪 + 利率上行 | 20%-40% | 降到低底仓，保留防御角色 |
| 估值中性 + 现金流稳 + 利率平稳 | 40%-50% | 持有常态底仓，收现金流 |
| 估值偏低 + 股息率走高 + 利率友好 | 50%-60% | 逆向小步加 |
| 低估值 + 高股息 + 电价稳 + 利率下行（强共振） | 60%-80% | 逆向加到中高位 |

仓位调整优先看"价值锚迁移"（估值 / 股息 / 现金流 / 利率），不是看当天涨跌，也不看趋势信号。没有价值锚迁移，短线信号再好看也不动。**绿电是底仓型，状态机的重心是"守底仓 + 便宜加 + 贵了减"，不是空仓 / 满仓切换。**

### 6. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**，顺序固定：

1. 当前估值 / 股息分位是什么档（便宜 / 中性 / 贵），和上次相比有没有变化。
2. 电价 / 现金流、利率方向、消纳 / 补贴、政策是否支持状态变化。
3. 是否触发交易闸门；若没有，明确写"研究状态未变，场外基金默认持有底仓"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是"低估值 + 高股息逆向布局 + 稳定现金流"的中期回报，不是 MA5/MA20 的短线抖动，更不是趋势追涨（趋势在绿电无效）。

> **核心一句**：绿电是**下行保护 / 底仓型公用事业**——在低估值 + 高股息 + 电价稳 + 利率友好时逆向加稳健底仓，在估值过热 / 股息率压缩 / 电价下行 / 利率上行 / 现金流证伪时减回中枢；靠"现金流 / 估值 / 股息定价值锚、利率方向定顺逆风"收稳定现金流，**不靠趋势择时（donchian / trail_dd 已验证跑输 buyhold），不把它当高弹性成长炒**。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（电价市场化新规、绿证 / CCER 新政策、补贴清算新方式）。
- **定期 + 事件驱动**：月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB / PE / 股息率分位档、回撤档、底仓中枢）、视角权重与排序、电价 / 运营表维度、新增失效模式与证伪条件、对各子板块（水电 / 风电 / 光伏运营）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（低估高息逆向加、过热证伪减）、价值锚 + 类债锚双锚结构、**趋势择时无效（不用 donchian / trail_dd）**、绿电是下行保护 / 底仓型公用事业（不是高弹性成长）、稳健底仓 + 低换手 + 防御优先。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；电价市场化机制重置、绿证 / CCER 制度落地、补贴清算方式变更是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **趋势无效是已验证结论，别反复重挖**：donchian_60 / trail_dd15 在绿电跑输 buyhold 是回测定论，不要因为某段行情趋势"看起来有用"就把趋势择时重新写回信仰层——那是被一段行情带偏。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。

## 回测数据可得性（已校准）

这是场外基金时点回测，数据按"有没有结构化时点源"分三类，缺失必须标注、不得当确认：

- **有结构化时点源（优先用）**：指数行情用 `market_index_quote(market="cn", symbols=["931897.CSI"])` 自取（每日预取快照只含五个宽基的 MA / 趋势，不含 931897、也不含 PE/PB）；成分股行情 / 估值（PE/PB）用 `stock_market`、财务 / 现金流 / 分红 / 负债率用 `stock_financial_quality`、一致预期用 `stock_alpha`、资金（个股级）用 `stock_capital_flow`；宏观 / 利率（10 年期国债收益率，绿电的影子分母）用 `macro_data`；基金净值 / 费率用 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
- **要自行聚合或口径有限**：指数级 PB / PE / 股息率分位需用成分股估值 / 分红按权重聚合近似；资金只有个股级。
- **无结构化源，只能文本兜底**：上网电价 / 市场化交易电价、利用小时数、弃风弃光率 / 消纳、可再生能源补贴拖欠 / 应收账款、绿证 / CCER 价格、来水 / 蓄水——用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 兜底；搜索窗口相对上游当前时间、时点下可能稀疏甚至为空，更长历史靠公司公告、财报、行业协会数据、历史底稿或本地归档补证。
