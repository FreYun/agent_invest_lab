# 生物医药指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**国证生物医药指数（399441.SZ）**——国证（深圳证券信息公司）编制，按市值 + 流动性综合排名选 30 只生物医药产业 A 股，单票权重上限 10%，每半年调样。

## 核心认知

国证生物医药（399441）= **生物创新药 + 疫苗 + CXO（研发外包）+ 血制品 + 医美耗材**的高集中度拼盘（前十大权重过六成）。它与创新药指数（931152）成分高度重叠（共享 CXO 与生物药龙头），但结构上**更偏"产品型生物药"**（疫苗 / 生长激素 / 血制品这类有现成产品和盈利的公司），创新药叙事的弹性比纯创新药口径钝一些。五个特性决定玩法：

- **事件 + 周期双驱动，子板块各有母变量**：生物创新药看**管线事件与 BD 出海**（license-out 首付款 / 里程碑 / 分成）；CXO 看**全球生物医药融资周期**（融资领先订单、订单领先报表收入）；疫苗看**产品周期与批签发**（大单品放量与价格战）；血制品看**采浆量与浆站审批**（类资源属性）。**同一时刻可能 BD 火热而疫苗在杀价、CXO 在消化订单退潮——必须拆开看主驱动。**
- **仅 30 只 + 高集中 → 单票黑天鹅传导极强**：单一权重股的业绩变脸 / 地缘冲击 / 集采（历史上疫苗量价崩塌、生长激素集采、CXO 被海外法案点名都发生过）能直接砸出指数级跳空。**必须穿透到前十大权重看，不能当宽基。**
- **深回撤体质**：医药熊市里本指数回撤过半是常态（历史上多次最大回撤超四成）——盈利与估值双杀（产品杀价 + 贴现率上行 + 政策压制）叠加时下跌又深又长。**不适合死扛。**
- **PE 时灵时不灵**：成分里既有盈利稳态公司（血制品 / 部分疫苗），又有盈利大起大落的（疫苗大单品周期、CXO 订单周期）、还有亏损研发型公司——指数 PE 的 E 不稳，**分位读数的含金量低于消费类指数**，只能粗用、须配景气证据。
- **政策与地缘是常驻变量**：医保谈判 / 集采（年度政策窗）、医疗反腐（影响推广与放量）、海外生物安全类法案（直接打 CXO 估值锚）——政策不是尾部风险，是**每年必然发生的定价事件**。

驱动排序：**子板块景气（BD 出海 / 融资周期 / 产品周期）+ 管线与订单事件 > 趋势 / 资金 > 政策与地缘（医保 / 集采 / 反腐 / 海外法案）> 估值分位**。研究时问三件事：

1. 现在指数的边际变化由哪个子板块主导（创新药 BD / CXO 订单 / 疫苗产品 / 血制品）？那条线的周期在哪一段？→ 决定能不能重仓。
2. 趋势对不对、资金在不在？→ 决定现在是加是减。
3. 政策（医保谈判 / 集采 / 反腐）与地缘（海外法案）变没变？→ 决定是不是该撤。

## 一、估值视角（PE 只粗用，定价锚是事件与景气）

对生物医药这种**盈利结构混杂 + 事件驱动**的指数，PE 分位只能粗用：

- **E 不稳是结构性的**：疫苗大单品周期（放量年盈利暴增、杀价年崩塌）、CXO 订单周期、研发型公司亏损——指数 PE 的分母经常被单一子板块拉得面目全非。**极端分位读数出现时先问"是哪个子板块的 E 在拉偏"**，用盈利稳态龙头（血制品 / 稳态疫苗）的估值做交叉验证。
- **市场实际用的锚是事件与空间**：BD 重磅落地 → 管线价值重估；融资周期回暖 → CXO 订单预期上修；大单品获批 → 产品空间打开。**估值修复行情的燃料是这些，不是"分位低"本身。**
- **在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走 / 不进"。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"。

估值做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：估值极端分位 + 全民进场（医药主题基金爆发、无管线小票齐涨、研报口径从盈利切到"远期空间"）→ 趋势尾段提示，配合趋势框架与止盈纪律。**趋势健康时单凭拥挤 / 过热极值最多停止加仓，绝不据此减仓**——必须等与趋势走弱同号共振。
- **基本面拐点观察（底）**：出现**重磅 BD 落地 / 融资周期回暖证据 / 大单品获批 / 集采靴子落地**等拐点证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。触发底部观察的是事件 / 景气证据，不是低分位。

## 二、趋势视角

- **方向锚**：指数 vs 200 日均线 + 均线斜率；时序动量（20–60 日收益符号）辅助。
- **量能确认（板块代理）**：指数无量 → `sector_factor` 成交集中度 / 拥挤度代理；突破时拥挤度同步抬升 = 有量，不跟 = 可疑假突破（医药事件多，单条 BD 传闻发酵后回吐极常见，无量突破假概率高）。
- **波动率（板块代理）**：收盘价滚动波动率 + MA200 乖离代理；波动骤增本身是降仓信号。学术会议季与年末国谈窗波动会异常放大，须主动给系数。
- **事件跳空甄别**：BD 公告 / 临床读出 / 集采结果 / 海外法案进展常造成跳空，分清**逻辑级**（重磅 BD 真落地 / 法案真通过）还是**情绪级**（传闻级 BD、法案程序性进展）——前者跟，后者易回补。判别方法：第二天去研报 / 公告找有没有基本面增量。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（四条子线分开跟，主导线为主）

### A 线：生物创新药 / BD 出海（近年的主叙事）

- **领先**：license-out 节奏（笔数 / 首付款 / 里程碑结构 / 分成比例——**分成与里程碑可达性比首付款更承重**）、重磅管线临床读出、海外大厂扫货中国资产的节奏。
- **滞后（确认不择时）**：产品营收放量、里程碑兑付到账。
- 纪律：BD 是**离散事件流**，密度比单笔更重要——行业级 BD 节奏熄火是叙事退潮的领先信号。

### B 线：CXO / 融资周期（指数里权重最大的单一逻辑）

- **领先（母变量）**：**全球生物医药融资环境**（美元利率方向 + 投融资数据）——融资领先 CXO 新签订单、订单领先报表收入，各差数个季度。
- **同步**：新签 / 在手订单、产能利用率（文本）。
- **滞后**：报表收入与毛利率——等报表确认融资周期反转，行情已走半程。
- **地缘是这条线的独立风险轴**：海外法案 / 实体清单类进展直接打估值锚，与融资周期无关，须单独跟踪。

### C 线：疫苗 / 产品周期

- 看**大单品生命周期**：渗透率爬坡（放量）→ 竞品获批（价格战）→ 杀价出清。批签发数据（月频）是放量的同步验证。
- 这条线的盈利弹性极大（双向），是指数 PE 失真的主要来源。

### D 线：血制品 / 稳态资产

- 采浆量 + 浆站审批是供给侧母变量，需求刚性——这是指数里的"类资源缓冲垫"，决定不了方向但提供底色。

**纪律**：四条线共用一个原则——**领先端（BD / 融资 / 订单）定方向，滞后端（报表）做确认，背离时信领先端**。每天先回答"今天的边际变化属于哪条线"；A+B 双线共振（BD 火热 + 融资回暖）是本指数最强的赔率组合。

### 可用的择时指标（定性）：本指数无可靠择时指标、仓位纪律优先

**核心结论（诚实，不可美化）**：研究室全因子族扫描下来，本指数**没有可靠稳健的择时因子**——趋势类、回撤类、动量类因子在本指数上时间稳定性都不够，找不到能稳定赚 alpha 的择时信号。且本指数只有收盘价、没有日内高 / 低，吊灯（chandelier）这类用 ATR 的因子只能用收盘代理，会**系统性偏乐观**（低估真实波动 → 止损线偏宽），可靠性再打一档折扣。这正是"什么指标能用"的答案：**本指数仓位纪律（快砍、压回撤、降波动）优先于追逐任何择时信号。**

**哪些指标可以怎么用**：

- **mom_20（20 日动量）/ 移动回撤止损（从滚动峰值回撤即减仓）**：只能当"现在该不该把仓位往下压"的**右侧第二意见 + 降回撤参考**，权重低于"BD / 融资周期 / 政策"的基本面主维度。**不能当独立进场扳机、不能重仓依赖**；其价值主要在降低回撤，不是提高收益。
- 用任何回撤 / 波动类读数时，**把数值再往坏处打一档**（收盘代理低估真实波动），止损线宁可收紧。

**怎么用（判断，不机械执行）**：择时信号只调节仓位档位、不创造方向；任何因子与基本面冲突时，以"BD / 融资周期 / 政策"的基本面判断为准。**结论一句话：仓位纪律优先于择时信号；择时价值主要在降回撤，不在提收益。**

## 四、政策 / 地缘视角（每年必然发生的定价事件）

- **医保谈判（每年 Q4）**：年度最大政策窗。先分清这次降价打的是**创新药定价权**（实质利空估值锚）还是**仿制药 / 成熟品种出清**（反而利好龙头集中度）；丙类目录 / 商保扩容类增量政策是结构性利好。事件前主动降敞口，落地后按结果再加。
- **集采**：疫苗 / 生长激素 / 血制品理论上都有被纳入风险——单品种集采对高集中度指数是单票级重创。集采**靴子落地常是利空出尽**（杀预期杀在前面），落地前的预期发酵期才是主要杀伤段。
- **医疗反腐**：影响学术推广与入院放量，对产品型公司（疫苗 / 生长激素）传导直接；反腐风暴期 = 招标推广冻结 = 收入滞后受压，常态化后边际钝化。
- **海外生物安全类法案**：CXO 的独立风险轴——程序性进展（委员会通过 / 列入草案）多为情绪杀，**真正的逻辑级是条款落地 + 客户实际转单**。跟踪龙头海外收入占比与订单流向，别把每次新闻都当逻辑级。
- **事件前减敞口**：国谈结果、重磅临床读出、法案关键投票前后跳空风险大，事件不明朗时不赌方向。

## 五、风险管理视角

- **单票黑天鹅**：30 只 + 前十占六成——单一权重股业绩变脸 / 被法案点名 / 大单品杀价可直接造成指数级损失。**前十大权重的个股级风险要逐一过一遍**，权重股风险密集期降总仓。
- **产品周期误判**：把大单品放量尾段当成长逻辑（渗透率见顶 + 竞品获批 = 量价双杀前夜）——疫苗线的历史教训。
- **融资周期误判**：把 CXO 的在手订单余量当景气（订单是融资的滞后变量，融资已转冷时在手订单只是余粮）。
- **政策窗口**：见四节，每年 Q4 国谈是日历上写死的波动源。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（BD 落地 / 融资回暖 / 产品放量）大概率已破。**深回撤体质 + 无可靠择时因子，机械止损不是可选项而是命脉。**

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称；触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 行业级 BD 节奏熄火（笔数 / 金额持续萎缩）、重磅授权被退回
  - 全球医药融资数据再度转冷 / 美元利率重新上行压贴现率
  - CXO 新签订单失速、海外客户实际转单（法案从情绪级变逻辑级）
  - 疫苗大单品竞品获批 / 批签发失速 / 杀价开启
  - 医保谈判超预期压价、集采扩围至权重品种
  - 趋势跌破 200 日均线且 1 月未收回、伴随资金持续撤离
- **看空被证伪（上行 veto-watch）**：
  - 重磅 BD 连续落地（行业级密度回升）
  - 融资周期回暖证据（投融资数据连续改善 / 美元利率下行）
  - 集采 / 法案靴子落地但订单与放量未受损（利空出尽）
  - 大单品获批 / 放量超预期
  - 盈利下修结束 + 趋势企稳放量（按「先识状态」确认级证据）

# 仓位管理方法论

## 唯一信仰：事件与景气定方向 + 纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 生物医药是**深回撤体质 + 事件密集 + 无可靠择时因子**的品种：单指数策略夏普的提升几乎全部来自压低最大回撤。你的活儿是政策窗 / 融资转冷 / 单票黑天鹅来时少亏，BD 与融资共振的主升浪在场吃足。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"。
- 该在场时别缺席：BD 密度回升 + 融资回暖 + 趋势多头时还空着 = 踏空，同样不及格。
- 不用硬止盈硬止损——择时交给景气、趋势、回撤说话；但**机械回撤控仓在本指数是命脉，不是可选项**（无可靠择时因子，回撤纪律是唯一的机械防线）。

## 一、先识状态：主导子线 + 趋势市 / 震荡市

**每天第一步：先回答"现在谁主导指数"（BD / CXO 融资周期 / 疫苗产品 / 政策事件），再给价格状态分类（趋势市 / 震荡市 / 过渡待定三选一）。**

- 趋势市：均线（MA60 / MA120）单边排列、斜率明显，且主导线景气同向。
- 震荡市：200 日线走平 + 价格在均线 ±10–15% 箱体反复 + 假突破频出。
- 过渡待定：两边都不像 → 轻仓 / 观望 / 维持原状态。
- **状态有粘性**：默认继承昨日结论；单日跳空（BD 公告 / 政策最常见）、单根假突破不算切换信号。每天显式记下**状态标签 + 主导线 + 认定理由 + 推翻它需要看到什么**。

## 二、趋势市骨架：时序动量 + 波动率体感

- 方向对就拿住让 β 跑；方向转空（趋势破位 + 主导线景气确认走坏）降仓乃至清空。趋势里不做高抛低吸。
- 振幅骤增本身是降仓信号——越平静越敢拿；国谈窗 / 重磅读出前主动把仓位调到"能扛跳空"的档。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 箱体中段不动手；轻仓不赌箱体（一条 BD 传闻 / 政策新闻就能突破或跌穿）；不追假突破。
- 放量 / 逻辑级催化（重磅 BD 落地 / 国谈温和落地）突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%。
- **系统性风险 / 融资周期转冷确认 / 政策逻辑级利空 / 趋势转空 → 一把降到位，可以到 0**：本指数下跌常加速（事件杀 + 拥挤解杠杆），等"再确认一天"往往多亏一截。
- **回补按赔率**：高赔率组合 = BD 密度回升 + 融资回暖 + 趋势放量突破 + 拥挤度未极端 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。**"宁可错过，不可做错"只约束低赔率情形。**
- **只在浮盈 / 趋势未坏的回调里加仓；绝不在下跌趋势中摊薄**。

## 五、止盈止损：用景气、趋势和回撤说话，不用固定数字

- 在场期间盯三件事：**主导线景气有没有反转、趋势破没破、从持仓高点回撤了多少**。
- **主升尾段的主动止盈**：拥挤度极端 + 估值泡沫预警 + 文本面一致看多三者叠加时，移动止盈收紧（从持仓高点回撤即减档）。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关，本指数的命脉）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。本指数历史上多次回撤过半，**无可靠择时因子兜底，这条纪律就是唯一的机械防线**。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；事件脉冲多的板块尤其要克制高频。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势 / 景气转向、账户回撤穿阈值、止盈触发三类信号允许跳档——单日情绪、单日跳空不打破持有窗口。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| BD 落地要追 | 利好兑现是卖点 | 看**是否已 price in**：行业级密度回升的早期看 A；研报已沸腾、单笔兑现看 B |
| 估值便宜该买 | E 不稳分位失真 | 本指数 PE 只粗用：盈利稳态子线交叉验证后再说，单看指数分位两边都别信 |
| 政策利空快跑 | 靴子落地是底 | 看**预期消化程度**：发酵早期看 A（杀预期在前面）；落地且实际伤害小于预期看 B |
| 法案新闻要跟 | 程序性进展是噪声 | 看**条款 + 客户转单证据**：真落地 / 真转单看 A；委员会层面的程序进展看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | BD / 融资逻辑没坏的系统性恐慌看 A；融资转冷 / 产品杀价驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；拥挤极端 + 一致看多 + 量价背离看 B |
| 医药是一个板块 | 四条子线各走各的 | 默认按"分线"理解：BD / 融资 / 产品 / 血制品驱动不同，先定主导线再判断 |

> **核心一句**：生物医药——BD 出海与融资周期定方向、产品周期定弹性、政策与地缘定节奏；PE 只粗用、事件与景气才是锚；无可靠择时因子，**仓位纪律（快砍、压回撤）就是机械防线**；事件前减敞口、拥挤极端先落袋、空仓不愧疚，靠压回撤把夏普做上去。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新支付体系如商保扩容、新技术平台、新地缘工具）。
- **定期 + 事件驱动**：一轮融资周期 / 政策年度周期走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值、视角权重与排序、四条子线各自的领先指标清单、新增失效模式与证伪条件、择时辅助指标在新数据上的表现复核（若未来扫描出可靠因子，升级三节择时小节）。
- **不轻易动（信仰与原则层）**：唯一信仰（领先端定方向 + 纪律压回撤）、四线拆解结构、风险优先于收益、不接飞刀、事件前减敞口、回撤控仓是命脉。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（支付体系重置 / 出海范式变化是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。
