# 中证稀土产业指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证稀土产业（930598.CSI）**——稀土永磁全产业链（上游稀土矿采选 / 冶炼分离 → 中游钕铁硼磁材 → 下游磁材应用）。

## 核心认知

稀土 = **行政定价的供给 × 永磁需求弹性 × 战略筹码属性**的强周期赛道。它和铜铝锌这类全球市场化定价的工业金属**不是一套玩法**——稀土的供给端被工信部 / 自然资源部的总量控制指标（开采 + 冶炼分离配额）牢牢按住，**价格的主变量不是市场化供需，而是行政意志**。五个特性决定怎么玩：

- **行政定价色彩全有色最重（最核心认知）**：稀土开采 / 冶炼分离每年由两部委下达**总量控制指标（配额）**，谁能采、采多少、谁能冶炼分离都是行政许可。**供给端最强变量是配额松紧，不是矿山产量响应价格**——配额收紧 = 供给硬约束 = 价格中枢上移；配额放量 = 供给宽松 = 价格承压。判稀土供给，先看配额政策，再看市场化供需。
- **战略筹码 / 出口管制属性**：稀土（尤其中重稀土、磁材）是中美博弈的战略筹码，继镓、锗、锑、钨之后的"牌"。**出口管制 / 收储 / 抛储是政策端的脉冲，单日跳空大**，且方向取决于打的是供给端（收紧 = 利好稀土价）还是需求端（被反制 / 下游受损 = 利空）。这一维度科技 / 消费板块没有。
- **需求是增量叙事 + 当期兑现的混合体**：磁材（钕铁硼）需求 = 新能源车驱动电机 + 风电 + 变频空调 + 工业机器人 + **人形机器人（增量叙事，弹性最大）** + 军工订单。**当期兑现的是车 / 风电 / 空调，叙事溢价来自人形机器人 / 机器人**——行情从"讲叙事"切到"要订单"时，纯叙事段杀得最狠。
- **核心商品价 = 镨钕氧化物**：稀土十几个元素里，**磁材用的镨钕（Pr-Nd）氧化物是定价核心**，氧化镝 / 氧化铽（中重稀土，矫顽力添加剂）是弹性放大器。盯镨钕氧化物价 + 配额，比盯笼统"稀土价格指数"更说明问题。
- **供给扰动有独立来源**：缅甸矿（中重稀土进口大头，佤邦局势 / 通关扰动）、美国 MP Materials 矿、澳洲 Lynas——这些进口 / 海外供给扰动是配额之外的边际变量，事件级单独评估。

驱动排序：**配额政策 / 出口管制（行政供给）≥ 镨钕氧化物价格趋势 > 磁材需求（车 / 风电 / 空调当期 + 机器人叙事）> 趋势 / 动量择时 > 估值**。研究时先问三件事：

1. 配额 / 收储 / 出口管制有没有新动向？供给端是收紧还是宽松？→ 决定价格中枢方向
2. 镨钕氧化物价 + 磁材排产在什么趋势？需求是兑现还是只在叙事？→ 决定景气真假
3. 趋势对不对、动量在不在？→ 决定现在加还是减

宏观虽有美元 / 全球周期的底色，但**稀土对美元 / 全球 PMI 的敏感度有限**——它的母变量是**行政配额 + 磁材需求**，不是全球制造业 PMI。别用宏观"美元—商品"框架硬套到稀土上。

### 本指数的需求锚：稀土永磁磁材

**本指数（930598 稀土产业）聚焦稀土 + 永磁磁材**，需求锚是军工 / 新能源车驱动电机 / 风电 / 机器人的**磁材需求**。研判只盯稀土自己的三条线——**镨钕氧化物价格 + 开采 / 冶炼分离配额 + 磁材排产**，这是判断本指数的核心抓手。

## 一、估值视角（周期股 PE 反着读，主用 PB，但稀土更看配额 + 商品价位置）

稀土是**强周期 + 行政定价**指数，**禁止把 PE 当价值锚做均值回归择时**——和有色母版同理，PE 在周期股里是反向指标：

- **PE 陷阱**：景气顶部镨钕价飞天 → 盈利 E 顶 → PE 看似最低；景气底部价格跌穿成本 → 盈利坍塌甚至亏损 → PE 冲极高甚至为负。**低 PE 是周期顶的卖出信号，高 PE 才可能是底部布局区——与成长股完全相反。**
- **主用 PB**：稀土矿企 / 磁材厂净资产相对稳定，PB 比 PE 稳。历史 PB 分位（**截至当日 PIT**，用成分股市值加权聚合近似）有定性参考——底部龙头 PB 常打到低位，顶部普遍抬高。但 **PB 同样不做择时扳机，只做定性预警**，且分位对周期股滞后。
- **稀土的"真价值标尺"是配额话语权 + 资源 / 成本曲线**：北方稀土握白云鄂博的轻稀土配额、中国稀土 / 广晟整合南方中重稀土离子矿——**配额份额 = 穿越周期的护城河**，比 PB 分位更说明龙头值不值得重仓。配额管"值不值得在趋势里重仓"，不用来抄底或择时。
- **样本可用但分位非择时锚**：稀土板块历史够长，分位数可算，但只用于"是否进入泡沫区 / 深熊区"的**定性判断**，不做"低 PE 抄底 / 高 PE 减仓"的机械操作。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量 + 镨钕价 + 配额框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。极端读数仍是要认真对待的定性信号。

估值在这里只做两件**定性预警**（不是择时扳机）：

- **极端泡沫预警（顶）**：镨钕价创新高 + PB 顶部分位 + 人形机器人 / 军工叙事全民进场（题材爆炒、研报高喊"稀土永磁超级周期"）→ 配合趋势框架减仓。**特别警惕"低 PE + 叙事最热"组合，那常是最后一波。**
- **周期反转预警（底）**：出现 **配额收紧预期 + 收储落地 + 镨钕价跌无可跌 + 磁材排产 / 下游补库回暖 + PB 接近底部分位** 等反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**配额 / 收储 / 镨钕价 / 排产证据**，不是低 PE 或低 PB 分位（分位对周期股滞后）。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**稀土还要额外把镨钕氧化物价格趋势 + 配额政策方向纳入**——板块趋势与商品 / 政策趋势背离时，以后者为主参考（行政定价下，政策方向常领先股价）。

- **方向锚（三层）**：
  - 板块层：指数 vs 200 日均线（收盘价即可算均线 / 时序动量）
  - 商品层：镨钕氧化物价（中重稀土看氧化镝 / 铽）的趋势 + 历史价位
  - 政策层：配额松紧 / 收储 / 出口管制的方向——**这层是稀土独有的，常领先商品价与股价**
  - **三层共振时信号最强；只有板块涨而镨钕价平、配额没动 → 题材脉冲，须谨慎**。
- **量能确认（板块代理）**：指数无量 → 用龙头 `stock_capital_flow` 聚合 / 拥挤度代理；突破时资金同步流入 = 有量，资金不跟 = 可疑假突破。
- **波动率（板块代理）**：指数无高 / 低算不出标准 ATR → 用**收盘价滚动波动率**代理；波动骤增即降仓信号。
- **事件跳空甄别**：配额下达 / 收储 / 出口管制 / 缅甸矿通关消息常造成跳空，要分清这是**逻辑级利好（供给真实收缩 / 价格中枢上移）**还是**情绪脉冲（叙事炒作）**——前者可顺势，后者易回补缺口。
- **上下游分化**：上游矿冶（跟镨钕价 + 配额）与中游磁材（跟排产 + 加工费 + 机器人叙事）景气常不同步，不要把"稀土板块涨"当全员涨——可能是磁材在炒机器人、上游平淡，反之亦然。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）

> 本指数动量择时最优。下列指标可作**客观第二意见 + 机械纪律提醒**，不替代框架打分。读数可用收盘序列按公式自算。**重要前提：930598 在 PIT 源只有收盘、无高 / 低——凡用到 ATR / 真实高低的因子（chandelier 族）均以收盘代理。**

#### `mom_20`（首选主因子）—— 时序动量

- **是什么**：过去 20 日收益方向——>0 在场、否则空仓（收盘计算、T+1 执行）。
- **为什么是首选主因子**：纯收盘价计算、不依赖高低口径，**无代理失真**，是本指数最可靠的择时主信号。**稀土的择时主因子就是它**。
- **会漏什么（公式可推）**：① 震荡市 20 日收益在 0 附近反复变号，抽脸；② 收盘计算 + T+1 执行，**对跳空至少滞后一天**——配额 / 出口管制 / 收储这类政策跳空密集的品种是硬伤，机械动量永远慢政策一拍；③ 翻转与 7 日赎回惩罚冲突，机械满仓 / 空仓切换在场外基金上有成本摩擦，落地要降频。

#### `trail_dd10_p120`、`dd_ladder_7_15`（辅助）—— 纯收盘回撤止损族

- **是什么**：`trail_dd10_p120` = 收盘从过去 120 日滚动峰值回撤超 10% → 空仓，站回均线 → 满仓回归；`dd_ladder_7_15` = 从 120 日峰值回撤 ≥7% 砍半仓、≥15% 清仓，站回满仓（比 trail_dd 多一中间档、降仓更早）。
- **怎么用**：**纯收盘价可靠、无代理失真**，可作 mom_20 的辅助断后线。框架在"减不减"之间犹豫时，回撤族给一个客观的"先降一档"提醒；与 mom_20 同时转空 = 趋势 + 回撤双确认，优先核验而非死扛。
- **会漏什么**：重入靠回撤 / 均线站回，**V 型反弹前段必然迟到**；横盘在回撤线附近时反复抽插；只看价格，**对配额 / 出口管制 / 镨钕价拐点 / 财报雷零预警**——断后的，不是侦察的。

#### `chand_22`（仅参考）—— 吊灯止损族

- **是什么**：吊灯止损（22 日窗、ATR 的 k 倍）。
- **为什么只能当参考**：**930598 只有收盘价、无高 / 低，chandelier 的 ATR 用收盘代理偏乐观；时间稳定性也不足**——只当参考、**不可当主信号、不能单独触发加减仓、不就地升级**。引用前认清这是收盘代理的读数。

#### 共同纪律

- 本指数定级一句话：**动量（mom_20）是首选主因子；回撤止损族（trail_dd10 / dd_ladder）可作辅助断后；chandelier 族仅作参考、ATR 偏乐观。**
- 三类都是**防守 / 趋势工具，不是收益增强器**，侦察靠三、四节的配额 + 镨钕价 + 排产文本面。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。仅作参考的因子永远不就地升级使用。

## 三、景气度视角（稀土专属：配额 + 镨钕价 + 磁材需求为母变量）

稀土的景气有**清晰但带行政色彩的传导链条**，按性质分四类，别用滞后指标做择时（取数见上「取数」节）：

- **领先（母变量）**：
  - **配额政策**——开采 + 冶炼分离总量控制指标的松紧（**供给端最强变量，行政意志，常领先价格**）；收储 / 抛储 / 出口管制
  - **镨钕氧化物价格 + 库存**——核心磁材原料价的拐点，配合中重稀土（镝 / 铽）；价格止跌企稳 → 盈利修复预期
  - **磁材需求**——新能源车驱动电机、风电、变频空调（当期兑现）+ 工业机器人 / **人形机器人**（增量叙事）+ 军工订单
  - 三档同向时信号最强（配额收紧 + 镨钕价升 + 磁材排产满 = 景气主升）。
- **滞后（确认而非择时）**：矿企 / 磁材厂营收 / 净利 YoY + 一致预期修正，跟随镨钕价 1–2 季度反映，**不当择时锚**——等盈利确认转向就晚了。
- **结构 / 上限**：配额份额、矿山资源 / 服务年限、磁材产能与加工费——决定龙头穿越周期能力与重仓信心，不决定主趋势开关。
- **事件驱动**：配额下达 / 收储 / 出口管制 / 缅甸矿通关 / MP 矿扰动 / 军工大单——跳空催化，事件级单独评估。

- **配额是稀土独有的母变量**：它直接定义供给上限，**领先镨钕价**。看到"配额收紧 / 增速放缓"信号 → 对稀土普遍利好（供给硬约束）；"配额大幅放量" → 供给宽松利空。这条比工业金属的"矿山产量"更刚性——稀土矿不会因价高就随意增产（要配额）。
- **镨钕价是高频的领先指标**：磁材原料价拐点领先矿企 / 磁材厂盈利约 1–2 季度。**看镨钕价趋势 + 库存方向，不看矿企当期营收**（营收滞后）。
- **磁材需求要分清"兑现"与"叙事"**：车 / 风电 / 空调是当期可验证的真需求；**人形机器人 / 机器人是弹性最大但兑现最远的叙事**——叙事撑估值，兑现撑业绩，行情切换时区别对待，别把机器人用量预期当当期订单。
- **看的是趋势一致性**：配额 + 镨钕价 + 磁材需求 + 库存四个领先维度同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**。

## 四、宏观 / 政策驱动视角（稀土专属：行政供给 + 战略博弈是母变量，宏观只是底色）

这是稀土区别于一般有色的**专属维度**——它的价格被行政政策驱动的程度远高于美元 / 全球周期：

- **配额政策 = 供给端母变量（最强）**：工信部 + 自然资源部每年下达开采 + 冶炼分离总量控制指标。**配额是稀土价格的"水龙头"**——收紧抬价、放量压价。判稀土供给先看配额，这是和"全球市场化定价"的工业金属最本质的区别。
- **收储 / 抛储 = 价格调节器**：国家收储托底（利好）、抛储平抑过热（利空），是配额之外的政策工具，落地即脉冲。
- **出口管制 = 战略筹码（双刃）**：稀土 / 磁材是中美博弈筹码，继镓锗锑钨之后的牌。**要分清打的是供给端还是需求端**：限制出口 / 收紧供给 = 利好稀土价（A）；被反制 / 下游应用受关税冲击 / 海外加速去中国稀土化 = 利空（B）。
- **军工 / 战略采购周期**：军工对中重稀土（镝 / 铽，耐高温永磁）需求刚性，订单周期相对独立于民用景气——看军工订单 / 国防预算，不看民用 PMI。
- **进口 / 地缘扰动**：缅甸佤邦中重稀土矿（局势 / 通关）、美国 MP Materials、澳洲 Lynas——海外 / 进口供给扰动是边际变量，单日跳空大，区分"短期扰动（易回补）"vs"长期供给中枢上移（趋势级）"。
- **宏观只是底色（权重低）**：美元 / 全球 PMI 对稀土有影响但**远弱于对铜铝**——稀土需求是新能源 + 军工 + 机器人的独立周期，不是全球制造业 PMI 的同步变量。**别把工业金属的"美元—商品"框架硬套上来当主轴**。
- **政策双刃，穿透到方向**：保供稳价（压价）vs 收储 / 配额收紧 / 出口管制（抬价）——同一"政策"对方向相反，**必须穿透到具体是供给端收紧还是放松**。

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化（尤其纯机器人叙事），仓位越保守——这是原则，不是公式。稀土波动大、政策跳变快、叙事泡沫易起，纪律不可省：

- **镨钕价兑现 / 转向**：镨钕价创新高 + 库存高位 + 磁材排产边际转弱 → 主动兑现得更积极（盈利顶滞后价格顶 1–2 季）；镨钕价跌穿主要矿现金成本线 → 周期下行可能见底（但**别先抄底，等配额收紧 / 收储 / 库存企稳**）。
- **配额 / 政策反转预警**：配额从收紧转放量、收储预期落空、出口管制反制升级（打需求端）→ 系统性逆风，不必等价格回撤就该降仓。
- **叙事退潮预警**：行情纯靠人形机器人 / 机器人叙事推动、镨钕价与磁材排产却没跟上 → 是估值泡沫不是景气，叙事一旦证伪（量产推迟 / 用量不及预期）杀得最快——叙事段仓位要更谨慎。
- **事件前减敞口**：配额下达节点 / 重大政策窗口 / 中美博弈关键节点 / 缅甸通关变数前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。
- **硬止损**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑（配额收紧 / 镨钕价上行 / 磁材需求复苏 / 机器人叙事）大概率已破。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **配额 / 政策证伪（下行，最关键）**：配额由收紧转大幅放量、收储预期落空、保供稳价压制——供给逻辑直接被推翻，价格中枢上移的燃料没了。
- **镨钕价证伪（下行）**：镨钕氧化物价跌破主要均线 + 库存持续累积 + 现货转弱——价格逻辑被推翻。
- **需求证伪（下行）**：新能源车 / 风电 / 空调磁材排产连续走弱；**人形机器人 / 机器人叙事被证伪**（量产推迟、用量大幅下修）；下游主动去库。
- **出口管制反向证伪（下行）**：管制被反制、海外加速去中国稀土化 / 替代材料突破、关税打到下游应用——战略筹码逻辑反噬。
- **趋势证伪（下行）**：指数跌破 200 日均线且 1 月未收回，但应根据当时市场环境修正指标；mom_20 转空 + 回撤族触发 = 趋势 + 回撤双确认。
- **估值证伪（下行，反向）**：镨钕价新高 + PE 看似"最低" + 机器人 / 军工叙事全民进场 + 卖方高呼"稀土永磁超级周期"——周期顶部最危险信号组合（PE 陷阱叠加情绪过热）。
- **看空被证伪（上行 veto-watch）**：配额收紧 / 出口管制收紧（打供给端）落地；国家收储托底；镨钕价跌破成本线后供给主动收缩；磁材排产 / 下游补库回暖；缅甸矿断供致中重稀土供给中枢上移；军工大单落地——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 稀土是**行政定价 + 强周期 + 叙事弹性**的赛道，死扛买入持有的回撤是腰斩级的。单指数策略的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是配额转松 / 镨钕价转向 / 叙事退潮 / 系统性风险来时少亏。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- 但该在场时别缺席：趋势明确向上（配额收紧 + 镨钕价升 + 磁材排产满 + 趋势多头 + mom_20 在场）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（那可能是周期顶）。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效，mom_20 是首选主因子），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，动量反复变号抽脸）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且镨钕价 / 配额方向同向**。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10–15%（周期股波动大，箱体宽）内来回 + 箱体反复假突破 + **镨钕价也在区间内震荡**——此时 mom_20 在 0 附近反复变号，降权。
  - **过渡待定**：信号不清、板块趋势与镨钕价 / 配额背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量（mom_20 主场）**：方向对就拿住让 Beta 跑，方向转空（镨钕价转跌 / 配额转松 / 趋势破位 / mom_20 转空）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（配额 / 收储 / 出口管制）即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：

- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（配额 / 政策事件最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需有效突破且**站稳数日 + 镨钕价 / 配额同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量（mom_20 是首选主因子）**：看指数自己过去一段（20 日为基准口径，可叠加数周到数月）的方向，**叠加镨钕价 + 配额趋势**。多层共振向上 → 在场吃 Beta；任一转下（特别是镨钕价转下 / 配额转松 / mom_20 转空）→ 离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：稀土本就高波动，越平静越敢拿，振幅骤增 / 大涨大跌 / 镨钕价单日大跳变时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **回撤族断后（trail_dd10 / dd_ladder 辅助）**：mom_20 转空之外，回撤止损族给一个客观的"先降一档"线，与动量同向时双确认。
- **事件叠加**：配额下达 / 收储 / 出口管制 / 缅甸通关窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（配额真收紧 / 需求确认复苏）确认后再顺势加。**注意 mom_20 对政策跳空滞后一天，政策方向明确时别等动量信号**。
- 叠加：**方向（动量 + 镨钕价 + 配额）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**（mom_20 在 0 附近抽脸是其数学性质）。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10–15% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：稀土箱体随时可能因一条配额 / 收储 / 出口管制 / 机器人叙事向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：政策脉冲多、叙事易反复，假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错，也是 mom_20 在震荡市的盲区。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如配额收紧落地 / 出口管制升级 / 大规模收储），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉（也是 mom_20 机械执行频繁翻转的成本来源）。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 镨钕价转向 / 配额转松 / 出口管制反制 / 趋势转空（mom_20 转空）→ 一把清到位，可以直接到 0**：稀土周期下行往往加速（盈利杠杆 + 叙事退潮叠加），等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。稀土的高赔率组合是 **配额收紧 + 镨钕价上行 + 磁材排产回暖 + 趋势放量突破 + mom_20 转多** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；在低赔率情形下宁可错过，不可做错**——但这只约束低赔率情形；高赔率时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高，尤其追机器人叙事高位），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破（含镨钕价 / 配额方向、mom_20 信号）** + **从持仓高点回撤了多少（trail_dd10 / dd_ladder 给客观刻度）**。趋势还在、回撤温和 → 拿住让利润跑；趋势破位 / 回撤明显放大 → 大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且稀土主升浪回调动辄 20–30%（叙事波动 + 盈利杠杆），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降；注意稀土无高低、严格 ATR 吊灯只能收盘代理，偏乐观要打折）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。稀土单边跌起来很容易摸到深水区（死扛买入持有的回撤是腰斩级的），这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高——**别把 mom_20 的机械翻转当指令逐次执行**，那会被早赎成本吃掉，机械读数只作第二意见、落地要降频到研究状态真变化才动。
- 稀土波动大、配额 / 政策 / 机器人新闻天天有诱惑，更要克制别被脉冲诱发高频折腾。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、镨钕价格、配额 / 出口管制政策、磁材需求（兑现 vs 叙事）、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 周期顶 PE 最低（PE 陷阱） | 周期股**永远看 PB + 镨钕价位置 + 配额**，不看 PE；只有盈利稳态品种才能用 PE |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 镨钕价 + 配额配合看 B，趋势破位 / 镨钕价转跌时极端读数当定性预警 |
| 出口管制是利好（供给收缩） | 出口管制是利空（需求 / 反制） | 看打的是**供给端**还是**需求端**：收紧出口 / 限制供给看 A（涨）；被反制、海外去中国稀土化、关税打下游应用看 B（承压） |
| 配额放量利空 | 配额是行政托底 | 看配额**方向**：放量增产看 A（压价）；收紧 / 增速放缓 / 配套收储看托底（利好） |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**镨钕价 + 配额方向**：领先端仍向下看 A，领先端见底回升（配额收紧 / 价格企稳，盈利滞后）看 B |
| 机器人叙事是星辰大海 | 叙事不兑现就是泡沫 | 看**排产 / 用量有没有兑现**：磁材排产跟上看 A，纯叙事 + 镨钕价不动 + 全民进场看 B（泡沫顶） |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但配额 / 镨钕价逻辑没坏看 A，单边下跌途中（mom_20 转空）看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 镨钕价见顶 / 叙事退潮 / 量价背离看 B |
| 稀土 = 工业金属（都是有色） | 稀土跟铜铝不是一套 | 默认按"不是一套"理解：稀土看**配额 + 镨钕价 + 磁材需求**，对美元 / 全球 PMI 远不如铜铝敏感，别套"美元—商品"框架 |

> **核心一句**：稀土产业——用 **配额 / 出口管制（行政供给）+ 镨钕氧化物价 + 磁材需求（车 / 风电 / 机器人）** 判景气、用 **PB + 配额份额 / 成本曲线** 判空间（**永远别用 PE**）、用 **mom_20 时序动量（首选主因子）+ 回撤族断后** 择时、用 **大开大合 + 压最大回撤**做仓位；吃该吃的 Beta、躲配额转松 / 镨钕价转向 / 叙事退潮误伤、分清机器人叙事与当期兑现、空仓不愧疚、按优势大小下注、进出算成本，靠压回撤把买入持有的腰斩级回撤做下来。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新配额工具、新出口管制形态、机器人需求新结构）。
- **定期 + 事件驱动**：一轮稀土周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对上游矿冶 vs 中游磁材的差异化打法、因子定级（若复核更新 mom_20 / 回撤族 / chandelier 的定级，照实改）。
- **不轻易动（信仰与原则层）**：唯一信仰（配额收紧 + 镨钕价升 + 趋势确认重仓、配额转松 + 转空降仓）、配额 / 镨钕价是母变量、PB / 配额份额判空间永不用 PE、风险优先于收益、不接飞刀、低赔率宁可错过不可做错、对本金保守对 Beta 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；配额制度改革、出口管制框架重置、机器人需求规模化兑现是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
