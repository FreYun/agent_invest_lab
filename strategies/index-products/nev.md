# 国证新能源汽车产业投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**国证新能源汽车指数（CS新能车，399976.SZ）**。

## 核心认知

新能源汽车（国证新能车 399976）= **渗透率 S 曲线成长**叠加**价格战盈利周期**的成长制造贝塔，覆盖整车 / 动力电池 / 零部件（电控、热管理、一体压铸、智能化）/ 充电换电全产业链。它是 A 股「既有渗透率成长底盘、又被车企价格战反复杀毛利」演绎得最典型的板块（龙头整车降价可引爆全行业价格战、销量持续增长而整车与电池毛利被压制，就是教科书级的"增收不增利"）。三个特性决定玩法：

- **高弹性 + 高波动**：β 大，上行能翻倍、下行能腰斩，不适合死扛。
- **渗透率成长 + 价格战盈利周期**：销量有长期渗透底盘，但盈利由价格战强度主导——销量高增但价格战杀毛利（增收不增利）→ 价格战缓和 + 盈利修复 → 渗透率见顶、增速放缓。**单车盈利（终端折扣 / 单车毛利 / 电池成本传导）才是盈利拐点，不是销量增速。**
- **渗透率 S 曲线 + 技术 / 格局迭代**：国内新能源渗透率有长期底盘，但越过中段后增速放缓；同时纯电 vs 插混 vs 增程的路线之争、智能化（智驾 / 城市 NOA）、一体压铸、车企集中度提升，会让押错的环节 / 车企被颠覆。

驱动排序：**销量 / 渗透率 + 价格战盈利周期 > 价格链（终端折扣 / 单车毛利 / 电池成本）> 趋势 / 资金 > 政策 / 技术路线 > 估值**。研究时问三件事：

1. 盈利周期在哪个阶段（价格战杀毛利 / 价格战缓和盈利修复 / 渗透率见顶增速放缓）？→ 决定能不能重仓、是不是底部
2. 趋势对不对、资金在不在？→ 决定现在是加是减
3. 价格链（终端折扣 / 电池成本）/ 政策（购置税、以旧换新、出口关税）/ 技术路线变没变？→ 决定是不是该撤

### 新能车指数特性：

1. **量增不等于利增**：NEV 月度销量、渗透率年年创新高，但价格战让"量增、价跌、利压"。看销量的同时**必须看盈利**（终端折扣强度、单车毛利、电池成本传导）。需求好 ≠ 能赚钱，**价格战缓和 + 单车盈利修复才是盈利拐点**。
2. **价格战烈期 PE 被压、甚至看着不贵也别急**：价格战杀毛利时盈利下修，估值容易显得便宜——但盈利还在恶化时便宜是陷阱。要找"终端折扣收敛、单车毛利触底回升、电池成本（碳酸锂）企稳"的拐点信号，不能见 PE 低就抄。
3. **价格链（终端折扣 / 电池成本）是先行指标**：终端折扣强度、单车毛利、碳酸锂 / 电池成本的拐点，**领先**股价和盈利。折扣收敛、成本企稳 → 盈利修复预期 → 股价启动；盯价格链比等财报及时。
4. **政策与技术路线是双刃**：国内（购置税减免退坡、以旧换新、智驾政策）和出口（欧盟反补贴关税、各国本地化壁垒）直接左右销量与盈利；技术 / 格局（纯电 vs 插混 vs 增程、智能化 / 城市 NOA、一体压铸、车企集中度）让押错的环节 / 车企被颠覆。既是 α 来源，也是杀伤来源。电池环节绑定全球装机与储能、相对独立于整车价格战，景气与整车常不同步。

## 一、渗透率成长 + 价格战盈利周期视角（新能车的核心价值锚）

新能车是成长制造，**盈利由价格战 / 单车盈利周期主导，不由销量增速主导**。把盈利周期分三阶段定位（销量底盘始终在涨，关键看盈利能不能赚到）：

- **销量高增但价格战杀毛利（增收不增利）**：车企以价换量、终端折扣加深、单车毛利压到盈亏线、电池厂被压价——销量再好股价也涨不动，戴维斯双杀里的"杀利"主场。**少碰，趋势转空就清。**
- **价格战缓和 + 盈利修复（反转前夜 / 上行）**：终端折扣收敛、新车型涨价或减配保利、碳酸锂 / 电池成本企稳回落、单车毛利触底回升、格局向龙头集中——盈利估值共振向上，**主升段，重仓吃 β**。
- **渗透率见顶 + 增速放缓（成熟 / 过热）**：渗透率越过高位、销量增速台阶式下移、新玩家蜂拥、产能过剩隐现——成长溢价收缩，**趋势走坏即减**。

判断阶段看三件事：**终端折扣 / 价格战强度（在不在收敛）、单车毛利（拐点在哪）、电池成本（碳酸锂传导，企稳还是再跌带崩电池厂）**。月度销量 / 渗透率是成长底盘与滞后验证，不是盈利先行信号。

## 二、估值视角（用 PB 与盈利周期，不用 PE 分位均值回归）

新能车是强周期成长指数，**禁止用 PE 历史分位简单做均值回归择时**：价格战烈期盈利下修，E 缩水让 PE 表现失真——在盈利最差时显得贵、在盈利最肥时显得便宜，方向容易反。

估值换一套锚：

- **PB + 单车盈利 / ROE**：低 PB + 单车毛利触底回升 + ROE 即将修复 = 底部布局信号；高 PB + 价格战再起 / 毛利见顶 = 顶部预警。PB 必须配合盈利周期阶段用。
- **价格链隐含的盈利预期**：终端折扣收敛、电池成本企稳 → 未来盈利修复，比当下 PE 更能反映"贵不贵"。
- **极端泡沫的定性预警**：全民进场（新基金爆发、研报一致"新能车无敌"、龙头估值脱离任何盈利锚）时当顶部提示，配合趋势减仓——而不是单看一个估值数字。

成长性（渗透率空间、智能化领先度）只用来判断**值不值得在盈利修复里重仓**，不用来在价格战杀毛利的下行里抄底。

## 三、销量与盈利景气视角（盯销量—价格—盈利的趋势一致性）

新能车产业链分环节，单一指标失真。看六个维度的趋势一致性：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 销量 / 渗透 | NEV 月度销量、渗透率、车企交付、出口量 | 成长底盘 |
| 价格链 | 终端折扣 / 价格战强度、单车毛利、碳酸锂 / 电池成本 | 先行（领先盈利与股价） |
| 盈利 | 成分股毛利率 / ROE、整车与电池单位盈利 | 核心（决定能不能赚钱） |
| 格局 / 技术 | 纯电 / 插混 / 增程结构、智驾 / 城市 NOA 渗透、一体压铸、车企集中度 | 格局变量 |
| 资金 | 北向、ETF 份额、融资余额、产业资本动向 | 情绪 / 边际 |
| 政策 / 出口 | 购置税退坡、以旧换新、欧盟反补贴关税、智驾政策 | 催化 / 双刃 |

**价格链（折扣 / 成本）与盈利是赚钱拐点的主导，销量 / 渗透是成长底盘，技术 / 格局是变量**，共振时信号最强。看趋势一致性（多维同向），不是加权打分。销量增长是底色，但**价格战缓和与单车盈利修复才决定这一轮能不能赚钱**。

## 四、趋势与资金视角（择时主轴）

盈利周期定"值不值得拿"，趋势 / 资金定"现在动不动"。新能车弹性大、踩踏狠，趋势是避开大跌段的主力。

- **方向锚**：指数 vs 200 日均线，配合量能确认突破 / 跌破的强度——只做**定性方向**判断，不做机械规则。
- **资金面**：北向、ETF 份额、融资余额、产业资本动向——增量资金是主升燃料，资金撤离 + 价格走弱是顶部信号。
- **波动率**：振幅骤增、急涨急跌 = 环境恶化信号，本身就是降仓理由。

研究时不问"涨没涨"，问"趋势和资金的方向，配不配合盈利周期的判断"。**盈利拐点（左侧）+ 趋势定性确认（右侧）共振，是最强的进场点。**

### 量化择时辅助：donchian 失效，但熊市规避 + DD 止损族是绿灯

**donchian 趋势突破在新能车上失效，不作进场信号；熊市规避（均线下方空仓，dl_bearonly_150）+ 回撤止损族（trail_dd10 / dd_ladder）是经验证的右侧择时有效。**

**经济逻辑**：新能车"高波动 + 趋势反复、但有大级别回撤"——追突破（donchian）被价格战/政策消息打回，但"**熊市规避 + 回撤止损**"能避开大级别下跌段，既压回撤又改善收益，是真 alpha。

**怎么用（判断，不机械执行）**：把 dl_bearonly_150 / trail_dd10 当"现在动不动"的右侧择时第二意见，**权重 ≤ 盈利周期主维度**。先看销量/价格战/毛利定方向，再用熊市规避 + DD 止损族确认进出节奏；冲突时以产业基本面为准。donchian 不用作进场信号。下行保护仍以"盈利周期 + 价格链 + 证伪"为主，DD 止损族是经验证的右侧补刀。

## 五、风险管理视角

新能车的杀伤来自方向性逻辑破坏与高波动叠加，不是日常震荡。主要风险：

- **价格战 / 戴维斯双杀**：车企以价换量 → 终端折扣加深 → 整车与电池毛利和估值一起杀。新能车最大的杀伤，常在"销量仍创新高"时发生，最具迷惑性。
- **技术 / 格局颠覆**：押错路线（纯电 vs 插混 vs 增程）、智能化（智驾 / 城市 NOA）掉队、一体压铸 / 平台迭代落后、车企集中度提升挤掉二三线——基本面永久受损，不是周期回调，是逻辑作废。
- **出口 / 贸易**：欧盟反补贴关税、各国本地化与准入壁垒落地，直接砍出口需求与海外溢价。
- **拥挤度**：赛道交易过度拥挤、一致预期太强，任何边际利空引发踩踏式回调。
- **流动性**：高 β 在系统性流动性收紧时跌得最快最深。

原则：**价格战在加剧、单车毛利在下行、趋势定性已破、拥挤度高时，仓位越保守**。止损纪律不能省，但杀伤主要靠"盈利周期 + 价格链 + 定性趋势"提前离场，不能只等价格止损。绝不在价格战杀毛利的下行趋势里越跌越买。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（盈利修复 / 价格战缓和 + 趋势定性在场 + 路线没押错）的破坏**。下列任一发生，应严肃重评持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **盈利证伪**：终端折扣再度加深、单车毛利二次走低、价格战重燃，"价格战缓和带动盈利修复"的预期落空。
- **成本证伪**：碳酸锂 / 电池成本异常波动击穿电池厂盈利，或成本下行被整车厂以折扣全部吃掉、传导不到毛利。
- **趋势证伪**：跌破 200 日均线且 1 月未收回，伴随量能放大（仅作定性方向参考，不机械触发）。
- **技术 / 格局证伪**：重仓环节 / 车企主流路线被颠覆、智能化掉队、份额快速流失（格局逻辑作废）。
- **政策证伪**：购置税退坡 / 补贴退出、出口关税落地，砍掉重要需求或盈利假设。
- **拥挤证伪**：估值脱离任何盈利锚 + 拥挤度极高 + 资金爆量流入（非理性繁荣顶部）。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作：先识别指数当前由哪个环节主导，再判断盈利周期阶段、价格链、趋势资金是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导环节，再定强弱

新能车指数由整车 / 动力电池 / 零部件 / 充电换电等环节构成，常不同步。每天先问两件事：

1. **谁在主导指数**：看成分权重、领涨领跌成分、成交额集中在哪个环节（整车、电池、零部件、充电换电），判断当前交易的是整车价格战、电池装机 / 成本，还是纯指数 beta。
2. **主导环节信号强不强**：主导环节的销量、价格、盈利、格局、趋势、资金是否同向。不能用电池的全球装机利好去解释整车价格战导致的下跌。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 销量 / 价格链、盈利、趋势、资金至少三项同向，且无重大证伪 | 可做大动作，20%-40% 步长 |
| 中信号 | 两项同向、一项待确认，或产业信号强但趋势未确认 | 轻仓试、持有、等右侧确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线反弹但盈利周期未变 | 只记录，不交易或极小动作 |

研报观点本身不是交易信号，只提供假设与数据线索，必须被价格链、销量、单车毛利、财务和行情共同验证。

## 二、环节主导矛盾

| 环节 | 核心矛盾 | 重点指标 | 典型证伪 |
|---|---|---|---|
| 整车 | 销量 / 价格战 / 毛利的三角拉扯 | NEV 销量、终端折扣强度、单车毛利、新车型周期、车企集中度 | 折扣再加深、价格战重燃、单车毛利二次下行 |
| 动力电池 | 装机增长与成本传导（碳酸锂） | 电池装机量、碳酸锂价、单位盈利、海外储能订单、产能利用率 | 被整车压价、碳酸锂异动、海外需求放缓 |
| 零部件 | 智能化 / 一体压铸渗透与降本压力 | 智驾 / 城市 NOA 渗透、一体压铸订单、热管理 / 电控份额、毛利 | 智能化掉队、降价压力传导、份额流失 |
| 充电换电 | 桩车比缺口与换电模式商业化 | 公桩 / 私桩增量、桩车比、换电站投运、运营盈利 | 桩车比改善停滞、换电模式商业化证伪 |

子环节分化时按权重与边际排序：**权重大且边际改善 > 权重大但继续恶化 > 权重小但高景气**。只有权重大环节或多环节共振，才允许指数层面重仓。

| 层级 | 必看数据 | 数据可得性与工具（回测已校准） |
|---|---|---|
| 指数层 | 399976 收盘 / 均线 / 趋势、成交额、主要成分涨跌贡献 | 行情用 `market_index_quote(market="cn", symbols=["399976.SZ"])` **自取**——每日预取快照只含五个宽基，不含 399976，也不含 PE/PB；指数级 PB / PB 分位无直接源，用 `stock_market` 取成分股估值聚合近似或当缺失 |

工具优先级（已按回测可用工具校准）：

1. 行情 / 估值 / 财务 / 资金优先用时点工具：指数 `market_index_quote`、成分股 `stock_market`（含 PE/PB）、`stock_financial_quality`、`stock_alpha`、`stock_capital_flow`、商品 `commodity_market`、宏观 `macro_data`、基金 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
2. 终端折扣、销量、渗透率、电池装机这类**无结构化源**的数据，用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 文本兜底；搜索窗口相对上游当前时间、时点下可能稀疏甚至为空，缺失必须标注。关键词：`新能源车 销量 渗透率`、`新能车 价格战 折扣 毛利`、`碳酸锂 电池 成本`、`新能车 出口 欧盟 关税`、`智驾 城市NOA 一体压铸`。
3. 关键数据至少两源交叉验证（研报、行业协会 / 乘联会、公司财报、行情、新闻），任意两类相互印证才算中信号以上。

## 四、交易决策矩阵

| 盈利周期 | 价格链 | 趋势 / 资金 | 估值 / 盈利 | 动作 |
|---|---|---|---|---|
| 价格战杀毛利 | 折扣持续加深或二次走低 | 跌破 200 日线（且 ≥1 月未收回），资金趋势性流出 | 盈利继续下修 | 清仓 / 不参与 |
| 价格战杀毛利 | 短暂缓和但未企稳 | 弱反弹，无资金趋势性流入 | PB 低但 ROE 仍恶化 | 观察，不抄底 |
| 价格战缓和（早期） | 折扣收敛 / 成本企稳但未确认 | 趋势未确认，量能一般 | PB 低，盈利仍差 | 左侧轻仓试探 |
| 价格战缓和（确认） | 单车毛利企稳回升、成本传导改善 | 站上 200 日线，资金趋势性回流 | ROE 修复预期出现 | 加仓到中高仓 |
| 盈利修复扩张 | 折扣收敛、单车毛利上行 | 200 日线之上，资金持续流入 | 盈利上修 | 重仓持有 / 回调加仓 |
| 渗透见顶 / 过热 | 价格战再起或销量增速台阶下移 | 跌破 200 日线 + 量能背离 | 估值拥挤，盈利预期过满 | 分批减仓 |
| 逻辑证伪 | 价格、成本、政策或技术路线破坏买入逻辑 | 200 日线破位且资金撤离 | 盈利验证失败 | 快速降仓乃至清空 |

**矩阵使用约束**：四列要**共振**才触发动作；只有一两列变化（尤其趋势 / 资金单独变化）= 信号不足 = HOLD。趋势 / 资金看方向性变化，不是单日抖动；donchian 趋势突破已证伪，右侧择时用熊市规避 / DD 止损族（验证过的绿灯）。

## 五、研报到交易动作的转换

读研报五步走：

1. **提炼结论**：研报在看多什么——销量 / 渗透率、价格战缓和、单车毛利修复、智能化 / 出口，还是估值修复。
2. **拆假设**：拆成可验证假设，如终端折扣收敛、碳酸锂企稳、电池装机超预期、智驾渗透加速。
3. **找证据**：用行情、价格链、财务、销量数据和其他研报交叉验证，不接受单一卖方口径。
4. **映射矩阵**：把验证后的信号放进决策矩阵，证据不够就停在观察或轻仓。
5. **写反证**：每次动作写一句"什么发生就说明我错了"，便于证伪与复盘。

研报只讲销量增长、不讲价格战和单车盈利；只讲长期渗透空间、不讲短期盈利；只讲技术路线、不讲商业化与降本节奏的，降级为弱信号。

# 仓位管理方法论

## 唯一信仰

- 新能车的超额，来自**在价格战缓和 / 单车毛利触底 + 趋势定性确认时重仓吃产业上行 β，在价格战加剧 + 趋势转空时果断降仓躲开戴维斯双杀**——不是靠见低 PE 抄底，也不是靠死扛"销量年年增长"。
- 仓位由**盈利周期阶段（价值锚）+ 趋势 / 资金（择时锚）双锚**共同决定，没有固定上下限——空仓、满仓都合法。**空仓躲过价格战 + 杀盈利的大跌，是这个策略最值钱的动作。**
- **允许左侧、但要纪律**：盈利周期底部（折扣收敛 + 单车毛利 / 成本企稳信号）可分批左侧布局；右侧趋势定性确认才上重仓。绝不在价格战杀毛利的下行趋势中越跌越买摊薄——那是接戴维斯双杀的飞刀。
- 不用硬止盈硬止损，用盈利周期 / 趋势 / 价格链 / 回撤说话。
- **对本金极度保守，对产业 β 适度放纵**：亏损端要窄、要果断；盈利修复主升的浮盈端给空间、让 β 跑。

## 一、仓位步长：大开大合，不做微调

- 账户灵活，能快速空仓、也能快速满仓。每次动手都是有意义的大动作，最小步长 20%，2%–5% 的微调没意义。
- 离场可以一把到 0；进场看确认强弱，一把到位或分 2–3 个大步。

## 二、先识状态：盈利周期阶段 + 趋势市 / 震荡市

先定**盈利周期阶段**（价格战杀毛利 / 价格战缓和盈利修复 / 渗透见顶过热），再看**价格是趋势市还是震荡市**，两锚叠加定打法：

- **价格战缓和（底部）+ 趋势开始转多** → 左侧轻仓试 + 右侧确认加重，最好的赔率区。
- **盈利修复扩张 + 趋势向上** → 顺势重仓拿住让 β 跑，回调不破趋势就加。
- **价格战加剧 + 趋势向下** → 降仓乃至清空，绝不抄底摊薄。
- **渗透见顶 / 过热 + 趋势走坏** → 果断兑现，别恋战。
- 震荡市（盈利周期未明、均线缠绕）→ 转箱体思维，箱底买、箱顶减，别在趋势里被甩下车。

## 三、双锚骨架：盈利周期（价值锚）+ 趋势 / 动量（择时锚）

- **盈利周期锚**：决定"值不值得拿、是不是底部"。价格战缓和 + 单车毛利触底 = 价值底，盈利修复扩张 = 主升，价格战加剧 = 别碰。**用 PB + 单车盈利 / ROE，不用 PE 分位。**
- **趋势 / 动量锚**：决定"现在在不在场"。向上吃 β，转下降仓，避开大单边下跌段——压回撤的主力是**熊市规避（150/200 日均线下方空仓）+ DD 止损族（验证过的绿灯）；donchian 趋势突破失效不用**。
- **叠加**：盈利周期决定仓位中枢能开多高，趋势 / 资金决定现在往中枢上方还是下方走。**两锚共振（盈利拐点 + 趋势定性确认）才上重仓；两锚背离就留一手。**

## 四、非对称操作：离场要快、回补看盈利拐点 + 趋势确认

- **戴维斯双杀 / 趋势转空 → 一把清到位，可以直接到 0**。新能车跌起来又快又狠（杀盈利叠加杀估值），等"确认"就晚了，宁可错杀。
- **重新进场 → 看盈利拐点 + 趋势定性确认**：终端折扣收敛 / 单车毛利企稳、电池成本（碳酸锂）止跌、趋势定性重新转多——三者越齐加得越重；信号不齐就轻仓或放弃。**宁可错过，不可做错。**
- **只在盈利向上 / 趋势没走坏的回调里加仓，绝不在价格战杀毛利的下行趋势中补仓摊薄（接飞刀）**。底部价格战缓和的左侧试仓（小、分批、有价格支撑）可以接；盈利仍恶化的下跌不能接。

## 五、止盈止损：用盈利周期、趋势、价格链和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓盯四件事：**价格链 / 单车毛利有没有见顶反转、趋势定性破没破、资金撤没撤、从持仓高点回撤了多少**。盈利向上 + 趋势在场 + 回撤温和 → 拿住让 β 跑；价格链见顶 / 趋势破位 / 资金撤离 / 回撤放大 → 大块兑现乃至清空。
- **移动止盈**：利润越厚越用"从高点回撤"保护，而非看绝对涨幅。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定程度把减仓线抬到成本价——这笔从此最差打平，绝不让赚钱的高 β 仓位因周期反转重新变亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 回撤数学不对称：亏 50% 要翻倍才回本。先保证不大亏比博大赚更决定长期复利——新能车深跌幅度大，回撤控制尤其要紧。
- **你自己账户**从峰值明显回撤、且伴随盈利 / 趋势恶化时，大幅降仓乃至清空、暂停加仓——哪怕"渗透率长期空间还在"。长期空间不是死扛短期戴维斯双杀的理由。
- 回撤收复、盈利 / 趋势重新转友好，再按第四条回补。

## 七、成本意识

- 新能车波动大、机会多，但每次进出都要掂量摩擦：**指增 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。做的是盈利周期 + 趋势的大波段，频率天然不该太高——别做成高频。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金 / 指增组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD**；只有研究状态发生足够大的变化才允许交易。短线行情只能作验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清、证据不够时，默认不参与，或只用 **40%** 小仓位试探。
- 当盈利周期、价格链、销量库存、政策 / 路线、资金和趋势形成清晰共振时，敢于大胆干，仓位可提到 **50%–100%**。
- 进攻前先确认自己在"状态明确"而非"情绪冲动"；没有状态迁移，就算短线好看也不放大仓位。
- 回撤一旦恶化，先保命再谈进攻：减仓、暂停加仓、必要时回防守档。
- 原则：模糊期求稳，确认期进攻，回撤期收缩。

### 1. 交易触发闸门

交易前必须回答：**今天的研究结论相对上次持仓决策，发生了什么状态变化？** 只有下面几类变化可触发交易：

- **盈利周期变了**：价格战杀毛利 → 价格战缓和 / 盈利修复，或盈利修复 → 渗透见顶 / 价格战重燃。
- **价格链变了**：终端折扣、单车毛利、碳酸锂 / 电池成本等关键价格连续企稳 / 回升，或二次走低。
- **销量库存变了**：NEV 月度销量、渗透率、车企交付、出口量、电池装机改变此前判断。
- **政策 / 路线变了**：购置税退坡、以旧换新、欧盟反补贴关税、智驾政策、技术路线替代改变中期盈利假设。
- **风险状态变了**：核心逻辑证伪、账户回撤明显扩大，或系统性流动性恶化。

只是 MA5/MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化而无上述研究状态变化，**不得交易**，只记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买卖加减的主因。
- 200 日均线 / dl_bearonly / trail_dd10 / dd_ladder 可作中期趋势确认或风险线（donchian 趋势突破失效不用；熊市规避 + DD 止损族是验证过的绿灯），但必须与盈利周期、价格链、资金、证伪一起用。
- 连续涨跌、单日涨跌幅、短线趋势计数只能影响"今天是否更适合执行已成立的研究动作"，不能创造新交易理由。
- 交易理由若主要由均线、阳线数量、趋势计数构成，自动降级为 **不交易 / 继续观察**。

### 3. 费用与预期收益门槛

- 交易前估计本次动作能否覆盖申购 / 赎回 / 早赎成本，覆盖不了不做。
- 为躲一天波动而交易通常不值得；为应对中期逻辑证伪而交易才值得。

### 4. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**，顺序固定：

1. 当前盈利周期阶段是什么，和上次相比有没有变化。
2. 价格链、销量库存、政策 / 路线、资金趋势是否支持状态变化。
3. 是否触发交易闸门；若没有，明确写"研究状态未变，场外基金默认持有 / 空仓观察"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是研究确认后的中期波段，不是 MA5/MA20 的短线抖动。

> **核心一句**：在价格战缓和 / 单车毛利触底 + 趋势定性确认时重仓吃新能车上行 β，在价格战加剧 / 趋势转空时果断降仓躲戴维斯双杀——靠"盈利周期定底、价格链 + 200 日均线定性定时（donchian / trail_dd 在新能车上回测失效、不用）、量价背离时不贪"赚渗透成长，不靠死扛销量增长。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新技术路线、新政策工具、新供需 / 竞争结构）。
- **定期 + 事件驱动**：一轮盈利周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各环节（整车 / 电池 / 零部件 / 充电换电）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（缓和 + 趋势确认重仓、价格战 + 转空降仓）、双锚结构（盈利周期 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀、宁可错过不可做错、对本金保守对 β 放纵，以及**新能车上量化趋势因子（donchian / trail_dd）已证伪、趋势只作定性方向**这一结论。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；盈利周期切换、技术路线颠覆、政策框架重置是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
