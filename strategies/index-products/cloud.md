# 云计算与大数据指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，**先判市场环境（〇节，永远的第一步，且在本指数权重全框架最高）**，再从下面几个角度审视，自行综合判断该不该动、动多少。

> 云计算与大数据是 A 股**最典型的长久期主题资产**：成分以软件/SaaS 为主、算力硬件为辅，没有当期盈利支撑，行情几乎全部由**流动性环境 + 主题催化**驱动。它的玩法核心是：**先判流动性与风险偏好（第一定价因子），再分清这轮由谁定价（信创 / AI 叙事 / 企业 IT 支出周期），用文本面给方向、趋势给进出、回撤纪律机械断后**。估值在这里几乎帮不上忙，环境判断才是承重墙。

## 核心认知

中证云计算与大数据主题指数（930851.CSI，2012-07 起 13.9 年长样本）成分四块：**云软件/SaaS（用友、金山办公、广联达类）+ 安全与 IT 服务（深信服类）+ IDC/算力基础设施 + 大数据应用（宝信软件类）**——软件成分为主、算力硬件混合。五个特性决定玩法：

- **软件商业模式决定估值逻辑**：利润薄、费用前置、收入偏订阅/项目制，市场用 PS 与远期空间定价，盈利分母常年失真——**PE 分位在本指数基本不可用**，估值锚退化为"PS 分位 + 风格环境"，且只做定性（见一节）。
- **长久期资产，对流动性/利率/风险偏好极度敏感**：现金流都在远期，贴现率与风险偏好的边际变化直接重定价整个指数。风险偏好收缩期它是**最先被抛弃的资产之一**；流动性宽松 + 主题催化叠加时弹性又极大。所以**全市场环境判断（〇节）在本指数的权重比任何硬件指数都高**——环境读错，后面全部白做。
- **三条驱动线，主驱动会切换**：①**信创/国产化**——政府与行业 IT 替代的招标节奏，政策驱动；②**AI 双刃**——AI 应用拉动 IDC/算力需求是利好，但"AI 颠覆 SaaS"叙事会阶段性杀软件估值，**同一主题对成分内部方向相反，必须先分结构再定方向**（见四节）；③**企业 IT 支出周期**——跟宏观景气、企业盈利相关，属滞后修复。看错主驱动，所有信号都会读错。
- **国内 SaaS 盈利兑现慢**：订阅质量（云化率/续费率，研报口径）才是真成长标尺，报表利润长期给不了答案。行情常呈"**主题脉冲 + 长期阴跌**"形态——历史上回撤过半的深熊反复发生、裸持有长期体验极差，**择时价值大**：少亏比多赚承重。
- **事件密集**：大模型应用进展、数据要素政策、信创招标、海外 SaaS 映射（美股软件股波动传导）都能造脉冲，但多数脉冲不改变中期方向，要分级处理。

### 云计算指数的估值特性（先记住再看一节）
1. **PE 分位不可用**：成分利润薄且波动大，分母失真——景气差时利润趋零甚至为负，PE 飙到没有意义的高位；少数年份利润集中释放，PE 又显得"便宜"。在这种分母上做分位回归，方向和幅度都不可信。
2. **PS 分位只做定性**：收入比利润稳定，PS 分位能粗略标记"贵/便宜的区间"，但软件公司收入结构（项目制 vs 订阅）变化也会让 PS 口径漂移——**只做极端区间的定性预警，不做择时扳机，更不给仓位数字**。
3. 估值只做两件事：极端泡沫的**定性预警**（配合全民进场信号），和极端便宜处**触发去文本里找环境/驱动反转证据**——其余时间让位给〇节的环境判断。

## 〇、先判市场环境（永远的第一步；本指数这一节权重全框架最高）

**为什么权重最高**：长久期、无当期盈利支撑的资产，**流动性与风险偏好就是第一定价因子**——不是背景板，而是行情本身。同样的信创订单、同样的 AI 催化，在宽松扩张期是主升燃料，在收缩期连一个脉冲都撑不起来。任何信号读取之前，先回答三个问题并**显式留痕**（写进当日复盘，明天直接继承）：

**1）全市场环境：现在的流动性与风险偏好，养得起长久期资产吗？**
用 `macro_50etf_vix`、市场情绪指数（按累计与 z 读，不读单日）、大盘与成长风格指数趋势粗判：**风险偏好扩张 / 收缩 / 中性**。利率与流动性边际方向（宽松/收紧，文本面读政策与资金面措辞）一并记一句。收缩期里：后面所有看多信号自动降一档，脉冲一律按"反弹"处理不按"反转"；扩张期里：才允许把主题催化读成趋势起点。**这一问的答案错了，后面全部作废**。

**2）板块自身状态：趋势市 / 震荡市 / 过渡待定（三选一）**
- 趋势市：均线（MA60/MA120）单边排列、斜率明显，价格沿一侧运行 → 用趋势骨架。
- 震荡市：长均线走平 + 价格围绕均线宽幅反复、假突破频出 → 用防守骨架。本指数阴跌段常以"阴跌 + 间歇脉冲"出现，**脉冲不等于状态切换**。
- 过渡待定：两边都不像 → 轻仓/维持原状态/观望。
**状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日跳空、单根假突破不算切换信号。

**3）主驱动识别：现在这轮行情谁在定价？（信创 / AI 叙事 / IT 支出周期）**
- **信创/国产化主导**：信号源 = 政策文件、招标公告密度、订单落地——政策节奏定价，看三节 A 线。
- **AI 叙事主导**：信号源 = 大模型进展、应用落地、海外 AI 行情映射——情绪与叙事定价，波动最大，**必须同时判断叙事对软件成分是利好还是利空**（见四节双刃）。
- **企业 IT 支出周期主导**：信号源 = 宏观景气、企业盈利、龙头收入增速拐点——最慢的一条，多出现在修复期。
主驱动判断写一句话留痕。**环境错判，再好的纪律也会用反**——这一节没做完，不允许进入任何加减仓决策。

## 一、估值视角（PE 不可用，PS 仅定性）

按"核心认知-估值特性"执行，补充操作含义：

- **禁止用 PE 分位做任何方向判断**——不是"弱信号"，是"坏信号"，分母失真会把方向整个带反。复盘与决策文本里不引用 PE 分位作为论据。
- **PS 分位极端高 + 全民进场信号**（云计算成为全民词汇、主题基金发行爆量、研报口径全面切到"远期空间/市梦率"）→ 当成趋势可能进入尾段的提示，配合趋势框架与止盈纪律处理，不单独触发减仓。
- **PS 分位极端低 + 风险偏好已收缩很久** → 不抄底，但**触发去文本里找反转证据**（流动性转向、信创订单重启、AI 叙事转向利好软件、IT 支出回暖），证据出现且趋势企稳，按骨架快速回补。
- **收入预期斜率比任何分位承重**：用 `stock_alpha` 看龙头收入一致预期变动率——软件公司利润可以为零，但收入上修在加速 = 行情有燃料；收入预期转下修 = 估值故事失去地基。

## 二、趋势视角

- **方向锚**：收盘价 vs MA120/MA200 + 均线斜率；时序动量（20–60 日收益符号）做辅助。本指数动量族在量化扫描中是最强信号（见量化辅助节），趋势视角的读数与 mom_20 天然同源，**注意别把同一个信号数两遍**。
- **量能/拥挤确认**：指数无量 → 用板块拥挤度代理。突破时拥挤度同步抬升 = 有量；不跟 = 可疑假突破。**拥挤度极端高位 + 价格加速 = 主升尾段特征**，对照止盈纪律。
- **跳空甄别**：消息跳空分**逻辑级**（政策文件落地、招标放量、流动性转向 → 可顺势）与**情绪级**（美股软件夜盘映射、大模型发布会、概念传闻 → 易回补）。判别方法：第二天去研报/纪要找有没有基本面增量；没有增量的跳空一律当情绪脉冲。
- 阴跌段里均线信号会反复小幅打脸，转防守思维（见仓位管理）。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（三条线分层跟，主驱动线为主；本节大半 `[仅文本]`）

### A 线：信创/国产化（政策驱动，节奏脉冲式）
- **领先**：政策文件与试点范围扩大、招标公告密度与金额 `[仅文本]`——招标节奏就是这条线的 capex 指引。
- **同步**：龙头订单与中标公告、渠道反馈 `[仅文本]`。
- **滞后（确认不择时）**：龙头收入确认——政企项目制收入确认慢，财报兑现常滞后行情数个季度，**等报表确认再动通常已走完半程**。

### B 线：AI / 算力需求（指数内部分裂的一条线）
- **算力侧（IDC/算力基础设施成分）**：AI 推理与训练需求 → IDC 上架率、算力租赁价格、智算中心建设 `[仅文本]`——AI 落地越实，这一侧越受益。
- **软件侧（SaaS/应用成分）**：AI 是产品化机会（产品提价/续费率提升的证据，`[仅文本]`）还是颠覆威胁（"AI 颠覆 SaaS"叙事压估值）——**两侧方向可能相反，读这条线必须先标注"在说哪一侧"**（详见四节）。

### C 线：企业 IT 支出周期（最慢的底色）
- 宏观景气与企业盈利 → IT 预算 → 软件公司收入，链条长、滞后深 `[仅文本]` + 龙头 `stock_alpha` 收入预期互证。
- **订阅质量是这条线上的真成长标尺**：云化率、续费率（研报口径，半年/年报季更新）持续改善 = 商业模式在变好，给"长期能不能配"定调；恶化 = 主题脉冲再热也只做波段。

**纪律**：三条线共用一个原则——**领先端（政策/招标/需求文本）定方向，滞后端（财报收入）做确认**；领先与滞后背离时信领先端。但三条线给的都是"方向与故事"，**仓位级别永远先过〇-1 的流动性闸门**。

## 四、事件/政策视角（与景气正交的独立信号）

- **AI 双刃（本指数最特殊的一条，专门处理）**：同一条 AI 消息，对算力/IDC 成分与 SaaS 成分**方向可能相反**。大模型能力跃迁：利好算力需求，但若叙事走向"通用模型替代应用软件"，软件估值反而被杀；AI 应用落地放量：利好有产品卡位的软件公司，同时坐实算力需求。**处理顺序硬性规定：先分结构（消息打在算力侧还是软件侧、利好还是利空各自多少），再看指数成分以软件为主的事实，最后才定指数级方向**——跳过分结构直接定方向，是这个指数上最常见的读错方式。
- **数据要素政策**：数据资产入表、公共数据运营类政策对大数据应用成分是逻辑级催化，但兑现路径长，**当日按情绪脉冲处理，文本面核实商业模式落点后再定性**。
- **信创招标事件**：招标放量/暂停的传闻先核公告 `[仅文本]`；确认级的量价信息才升级为 A 线景气证据。
- **海外 SaaS 映射**：美股软件/云大波动传导到 A 股软件是常态。分级：海外因利率/流动性下杀 → 同为长久期资产，**逻辑级，要跟**；海外因个股财报或本土事件波动 → 情绪级，看〇-1 环境决定跟不跟。
- **事件前减敞口**：重大政策窗口、海外大科技财报夜前后跳空风险大，事件不明朗时不赌方向。

## 五、文本视角（zsxq 调研纪要 + 新闻 + 研报，**每日必读、最高优先级信息源**）

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（机构调研纪要，PIT 截断到当日）+ `research_search` / `research_view`（新闻/研报）。**每个交易日必须执行，不允许跳过**——哪怕当天决定不动仓位。其他视角缺数据可降级，这个视角不读完不许收工。
>
> **为什么在这个指数上文本面权重必须高**：本框架的母变量（流动性与政策措辞、信创招标、AI 叙事方向、订阅质量、IDC 需求）**没有一个是结构化数据**，全部活在研报、新闻、调研纪要里。丢掉文本面，框架退化成纯价格量化——纯价格因子在本指数能给不错的风险管理（见量化辅助节），但**给不了方向切换的领先性，更看不见 AI 叙事的正负反转**。

### 每日固定动作（3–5 次调用内完成，不许刷库）
1. **扫当日纪要流**：`zsxq_topics`（count=20）过当日新增纪要标题/摘要——云计算/软件/信创/IDC 相关的标记下来；机构密集调研某环节，密度本身就是信号。
2. **主题词检索**：`zsxq_search` 用 1–2 个当日主线词（如 '信创'、'大模型'、'IDC'；搜 0 条先看 `query_used` 换词重试）。需要正文再 `zsxq_topic_detail`，**最多 1–2 篇**。
3. **新闻/研报面**：`research_search`（search_type='all'）查当日政策 / 招标 / AI 进展 / 数据要素增量；财报季加扫龙头云化率/续费率口径。
4. **海外映射**：美股软件/云夜盘大波动时，专项检索原因并分级：流动性级（要跟）还是个股级（情绪脉冲）。

### 怎么读（纪律——文本是信息也是毒药）
- **读事实与方向，不抄结论**：纪要 = "机构在看什么 + 公司说了什么"，是关注度代理 + 基本面事实源，不是买卖建议。
- **AI 叙事必须标注方向落点**：任何 AI 相关文本，记录时写明"利好算力侧 / 利好软件侧 / 杀软件估值"，不许只写"AI 利好云计算"。
- **一致性观点逆向读**：文本流一致看多（研报集体喊"远期空间"、措辞密度高）在趋势成熟期是反向信号、在行情 onset 期是领先信号——属于哪种，回到〇节环境判断当场定，不给机械线。
- **证据落链（硬性）**：当日 belief/复盘 evidence 至少 1 条文本类条目（带 topic_id 或 INFOCODE + 一句话摘要）；没读到就如实写"今日文本面无增量"。**没有检索记录不许引用任何"听说/市场传言"**。
- **留痕（硬性）**：每日复盘固定一行 `文本增量: 无|低|中|高 —— <今天读到了什么、有没有改变判断或动作>`。
- **权重边界**：文本面给**方向与证伪**，不直接给仓位数字；任何文本信息都不得突破回撤控仓与仓位步长纪律。

## 六、证伪视角（对称化）

证伪是**论据的破坏**，必须对称——看多与看空的证伪都要列，触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 流动性/风险偏好转向收缩（〇-1 降档）——本指数最重的一条，单独成立即可压低所有仓位上限
  - "AI 颠覆 SaaS"叙事升温且文本面出现实际证据（客户用 AI 替代软件采购的案例级信息）
  - 信创招标节奏放缓/预算收紧的确认级文本
  - 龙头收入一致预期变动率由上修转下修（最早的硬信号）
  - 订阅质量恶化（续费率/云化率口径下行）——长期论据失效
  - 拥挤度极端 + 一致看多 + 价格加速（尾段组合）
- **看空被证伪（上行 veto-watch）**：
  - 流动性明确转向宽松 + 成长风格整体修复（〇-1 升档）
  - 信创招标重启放量 / 数据要素政策出现可落地的商业模式
  - AI 叙事转向利好软件（产品提价/续费率提升的实证出现）
  - 龙头收入预期止跌回升 + 趋势企稳（按〇-2 确认级证据）

# 仓位管理方法论

## 唯一信仰：环境定生死 + 文本定方向 + 纪律压回撤

- 本指数是**长久期 + 主题脉冲 + 长期阴跌**品种，裸持有体验极差（历史上回撤过半的深熊反复发生），单指数策略的全部价值在**避开阴跌段、吃住脉冲段**。少亏是第一位的。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。本指数空仓时间可以很长，这是特性不是失误。不知道怎么办时按「过渡待定」处理，不是习惯性下半注。
- 该在场时别缺席：流动性扩张 + 主驱动明确 + 趋势多头时还空着 = 踏空，同样不及格。

## 一、骨架选择（承接〇-2 的状态分类）
- **趋势市 → 时序动量为骨**：方向对就拿住让 β 跑；趋势破位 + 环境/驱动确认转向 → 降仓乃至清空。趋势里不做高抛低吸。
- **震荡/阴跌市 → 防守、少动、低仓**：阴跌段的间歇脉冲不追（多数回补）；轻仓或空仓等环境信号；放量 + 逻辑级催化（政策/流动性级别）突破并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- **过渡待定 → 维持原状态/轻仓**，等确认。

## 二、不对称操作：离场快、回补看赔率
- **大开大合，不做微调**：最小步长 20%；2–5% 微调无意义。
- **风险偏好收缩确认 / 趋势转空 / AI 叙事转向杀软件 → 一把降到位，可以到 0**：长久期资产下跌时流动性溢价消失，等"再确认一天"代价高。
- **回补按赔率**：高赔率组合 = 流动性转宽 + 主驱动明确（信创放量或 AI 利好软件侧坐实）+ 趋势放量突破 + 拥挤度未极端 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。
- **只在浮盈/趋势未坏的回调里加仓；绝不在阴跌趋势中摊薄**——"便宜了再买点"在本指数是历史上最贵的习惯。

## 三、止盈止损：趋势 + 回撤说话，不用固定数字
- 在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势在、回撤温和 → 拿住；趋势破位/回撤明显放大 → 大块兑现乃至清空。
- **主升尾段的主动止盈**：拥挤度极端 + PS 极端分位预警 + 文本面一致看多三者叠加时，吊灯线收紧，别等流动性反转才反应——本指数顶部由流动性决定，等价格确认必然晚。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 四、回撤控仓（账户级总开关）
- 账户净值从峰值明显回撤 → 机械降仓/暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。本指数历史回撤深度（约 −52% 量级）意味着没有断后纪律就没有复利。

## 五、成本意识
- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip。注意：主因子 mom_20 翻转约 21 次/年，频率不低，**执行时把因子翻转与 7 日窗口对照，宁可迟一天换档也别吃惩罚费率**。
- 每个仓位档**至少持有 3 个交易日**（thesis 持续性窗口）；期间只有趋势因子转空、账户回撤穿阈值、止盈触发三类信号允许跳档——单日情绪、单日跳空不打破持有窗口。

## 六、量化择时辅助（已验证因子）

> 研究室离线全因子族扫描（长样本、含费率与 T+1）验证：本指数**动量族 + 熊市规避族 + 深回撤族三族绿灯**（族级鲁棒，非单因子幸存）。当作**客观第二意见 + 机械纪律提醒**，不替代框架打分。**已注册进 `quant_factor` 工具**：主因子 `cloud_mom_20`、辅因子 `cloud_bearonly_150` / `cloud_deepdd15_p120`。

### `mom_20`（主，多族中最强）—— 短动量
- **是什么**：20 日收益 > 0 → 满仓，否则空仓。验证结论：三族中改善幅度最大、时间稳定性最好——相对裸持有大幅压低回撤、显著改善收益回撤比；翻转偏频繁（约每月一两次），摩擦成本要记在心里。
- **会漏什么（公式可推）**：①震荡市反复抽脸（20 日窗口在无趋势段频繁变号）；②按收盘计算，跳空行情滞后一天；③只看价格，**对政策转向、AI 叙事切换无预警能力**。
- **怎么用**：= 0 而框架还看多 → 优先逐项核验是不是环境/文本面漏了什么；= 1 且框架看多 → 同号确认，可放大倾斜步长；框架看空而它还 = 1 → 不构成"再等等"的理由，框架主导。

### `dl_bearonly_150`（辅）—— 熊市双确认规避
- **是什么**：默认满仓；close < MA150 **且** MA150 的 20 日斜率向下（熊市双确认）→ 空仓。低翻转（一年只动手几次）的"熊市底色"信号，同族绿灯。
- **会漏什么（公式可推）**：均线上方的快速下杀初段无防护——它只认"已成型的熊"，对熊的第一段必然在场。
- **怎么用**：给〇-2 的状态判断当客观底色：它 = 0 时大概率处在阴跌段，框架的看多信号自动多一道质疑。

### `dl_deepdd15_p120`（辅）—— 深回撤断后
- **是什么**：默认满仓；（10 日跌幅 ≤ −10% 触发 crash 旗标、10 日冷却）或（从 120 日峰值回撤 > 15%）→ 空仓。同族绿灯，时间稳定性好。
- **会漏什么（公式可推）**：要等回撤走出 15%（或 10 日 −10% 的急跌）才反应，**断后不侦察**；对缓慢阴跌的前段无感。
- **怎么用**：账户级断后线的客观参照；它触发而框架还满仓时，优先核验而非死扛。

### 共同纪律
- **三者同号置信度高**：短动量给进出、熊市规避给底色、深回撤断后——三族同时看空时，任何看多论据都要按最高标准核验；三族同多 + 框架看多，是本指数最高置信的在场状态。
- 三个因子都是价格系，**都看不到政策/AI 叙事切换**——方向领先性永远在文本面，因子只负责风险管理与纪律提醒。
- **不要写也不要执行"因子 = X 且 YY 时必须 ZZ"的未回测组合规则**；冲突本身是信号，逐项核验冲突来源再决策。

## 七、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 流动性收紧就该跑 | 好赛道穿越周期 | 本指数没有"穿越"：〇-1 收缩确认看 A；只有订阅质量持续改善 + 估值已极端低才容许 B 的耐心 |
| AI 是云计算最大利好 | AI 正在颠覆软件 | **先分结构**：消息打在算力侧看 A；叙事指向"模型替代应用"且有案例级证据看 B |
| 政策利好要追 | 利好兑现是卖点 | 看招标/预算有没有**量价级**跟进：有确认级落地看 A；只有文件没有订单、研报已沸腾看 B |
| 跌深了就有反弹 | 阴跌不言底 | 流动性转向 + 三因子转多看 A；环境未变的"便宜"看 B——本指数阴跌段长于直觉 |
| 美股软件跌了要跟 | A 股有自己的节奏 | 海外因利率/流动性下杀（逻辑级）看 A；个股财报情绪波动看 B，再过〇-1 环境 |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；拥挤极端 + PS 预警 + 一致看多叠加看 B |

> **核心一句**：云计算与大数据——**流动性与风险偏好是第一定价因子**，先判环境（全市场 + 板块状态 + 信创/AI/IT 支出谁在定价），AI 消息先分结构再定方向，用**文本面**给方向、**mom_20**给进出、**bearonly/deepdd + 回撤控仓**机械断后；脉冲不追、阴跌不摊、空仓不愧疚，靠避开长阴跌把夏普做上去。
