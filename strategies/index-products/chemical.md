# 细分化工指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证细分化工产业主题（000813.CSI）**，覆盖基础化工 + 新材料的一篮子龙头。

## 核心认知

细分化工（000813）= **成本端（油 / 煤）× 产能周期 × 库存周期 × 产品价差**四重叠加的强周期赛道，盈利由价差驱动、不由销量驱动。它是 A 股里产能周期和大宗成本传导都演绎得极致的板块——上一轮油煤价上行 + 反内卷限产把 MDI / 制冷剂 / 有机硅价差打开、又被新增产能集中投产压垮，是教科书级的"价差扩张—资本开支—投产过剩—价差坍塌"中周期。五个特性决定玩法：

- **价差驱动，不是绝对价驱动**：化工盈利 = (产品价 − 原料价) × 销量。**原料和产品常同涨同跌，绝对价格说明不了盈利——价差才是。** 油价涨炼化未必赚（产品端跟不跟得上是关键），煤价跌煤化工才舒服（成本端松了价差自然张）。看绝对价是被表象骗，看价差才看到盈利。
- **成本端被油 / 煤两条母变量锁定**：炼化 / 烯烃 / 涤纶链的成本母变量是**布伦特油价**；煤化工（合成气、甲醇、烯烃、尿素）的成本母变量是**煤价**。成本端是化工最上游的扰动源，油煤一动，整条产业链价差重排。
- **产能周期是最核心的中周期变量**：化工是重资产，资本开支 → 2–3 年投产 → 产能集中释放 → 过剩 → 价差战 → 出清。**在建工程 / 资本开支领先盈利约 2–3 年**，这是判断"现在是周期哪一段"的第一抓手，比当期盈利重要得多。
- **库存周期是高频的盈利放大器**：主动补库（需求好 + 涨价预期）放大价差和盈利，主动去库（需求弱 + 跌价预期）压价差。化工品库存周转、社会库存、企业库存是周度 / 月度可得的领先信号。
- **子行业严重分化，指数是一篮子**：同叫"化工"，驱动逻辑完全不同——
  - **MDI / 聚氨酯（万华）**：全球寡头格局，价差由龙头报价 + 地产 / 家电需求 + 海外开工决定，**格局比成本更重要**。
  - **三代制冷剂（巨化、东岳）**：配额制下的政策性景气，**配额收紧 = 价格中枢上移**，独立于油煤周期。
  - **煤化工（华鲁恒升）**：成本母变量是煤价，煤价跌 = 价差张。
  - **炼化（恒力、荣盛）**：成本母变量是油价，赚的是炼油 + 化工品的加工价差。
  - **电解液 / POE / 隔膜（天赐、卫星）**：随锂电 / 光伏新能源周期，脱离传统化工周期。
  - **钾肥 / 锂（盐湖）**：农化 + 资源属性，钾肥看农产品 + 进口，锂随能源金属周期。
  - **改性塑料（金发）**：成本（树脂）+ 汽车 / 家电下游。
  - 同一时刻可能 MDI 价差张、制冷剂景气、但煤化工被煤价压、电解液随锂电跌——**互相抵消，必须穿透到子行业和龙头看，不能用一个故事解释整个指数的涨跌。**

驱动排序：**产能周期 / 供给格局 + 产品价差 > 成本端（油 / 煤）+ 下游需求 > 趋势 / 资金 > 库存周期 > 估值（PE 永远靠后且反着读）。** 研究时问三件事：

1. 主导指数的是哪个子行业 / 龙头？它的产能周期在哪一段、价差在扩还是缩？→ 决定能不能重仓、是不是底部。
2. 趋势对不对、资金在不在？→ 决定现在是加是减。
3. 油 / 煤成本、下游需求（地产 / 纺服 / 汽车 / 新能源）、库存方向、政策（配额 / 反内卷 / 限产）变没变？→ 决定是不是该撤。

宏观成本（油 / 煤）与产品价差趋势 > 仓位择时 > 选子行业；**产能周期 + 库存 + 价差 + 子行业结构**思维 > 长期持有（**裸持有这个指数长期不赚钱，所以择时价值大，见下「景气度」节**）。

## 一、估值视角（周期股 PE 反着读，主用 PB + 价差 + 资本开支位置）

对细分化工这种**强周期 + 成本 / 价差驱动**的指数，**禁止把 PE 当价值锚做均值回归择时**——PE 在周期股里是**反向指标**。具体陷阱：

- **PE 陷阱（最关键认知）**：周期顶部，油 / 煤价差扩张 + 库存补到位 → 价差和盈利 E 见顶 → PE 看起来**最低**；周期底部，产能过剩 + 价差跌穿现金成本 → 盈利 E 坍塌甚至亏损 → PE 冲到**最高甚至为负**。**低 PE 是周期顶的卖出信号，高 PE 才可能是周期底的买入信号——和成长股完全相反。**
- **主用 PB**：化工龙头净资产相对稳定（装置 + 资源 + 固定资产），**PB 比 PE 稳得多**。历史 PB 分位（**截至当日 PIT**）有参考价值——周期底部龙头 PB 常打到 1–1.5x，周期顶部 2.5–3x+。但**PB 同样不做择时扳机，只做定性预警**。
- **真正的价值标尺是产品价差 + 现金成本曲线 + 资本开支周期位置**：①价差在历史 5 / 10 年分位（截至当日 PIT）的位置 + 是否已兑现到盈利；②龙头单位现金成本是否能在周期下行盈亏平衡（低成本龙头穿越周期 = 重仓信心）；③**在建工程 / 资本开支处在扩张还是收缩**——资本开支高峰 = 2–3 年后过剩的种子，资本开支收缩 + 落后产能退出 = 反转前夜。这三件比 PE / PB 更说明问题。
- **样本足够长，但分位仍非择时锚**：化工板块上市公司多、历史长，分位数本身可用，但**只用于"是否进入泡沫区 / 深熊区"的定性判断**，不用于"低 PE 抄底 / 高 PE 减仓"的机械操作。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量 + 价差 + 产能周期框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。极端读数仍是要认真对待的定性信号。

估值在这里只做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：价差创历史新高 + PB 顶部分位 + 资本开支疯涌（人人扩产）+ 全民进场（研报高呼"超级周期 / 涨价潮"）→ 配合趋势框架减仓。**特别警惕周期顶部"低 PE + 高价差 + 在建工程飙升"组合，那常是最后一波——投产潮就在 2–3 年后。**
- **周期反转预警（底）**：出现 **价差跌穿现金成本 + 资本开支收缩 + 落后产能退出 / 反内卷限产 + 库存见底回升 + 下游补库 + PB 接近 1–1.5x** 等周期反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**价差 / 产能 / 库存证据**，不是低 PE 或低 PB 分位（分位对周期股是**滞后**的）。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**化工还要额外把成本端（油 / 煤）和产品价差趋势纳入**——板块趋势与价差趋势背离时，以价差趋势为主参考。

- **方向锚（双层）**：
  - 板块层：指数 vs 200 日均线（收盘价即可算均线 / 时序动量）
  - 价差 / 成本层：主导子行业的核心价差（MDI / 制冷剂 / 有机硅 / 煤化工价差）+ 油 / 煤价的方向和分位
  - **两层共振时信号最强；只有指数涨而价差平甚至缩 → 题材脉冲或成本端下跌的"伪利润"，须谨慎。**
- **量能确认（板块代理）**：指数取不到量 → 用 `sector_factor` 成交集中度 / `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破。
- **波动率（板块代理）**：指数算不出真 ATR（无高 / 低）→ 用**收盘价过去 N 日滚动波动率** + `sector_factor_detail` 的 **MA200 乖离率**代理；波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：油价跳变（OPEC 减产 / 地缘）、限产 / 安监 / 环保停产、配额政策、龙头检修 / 投产消息常造成跳空，要分清这是**逻辑级（价差中枢上移 / 供给真实收缩）**还是**情绪脉冲**——前者可顺势，后者易回补缺口。
- **子行业轮动**：油价涨利好上游成本传导顺畅的环节、利空成本端被动的环节；同样一条油价新闻，对炼化、煤化工、制冷剂方向可能相反——**不要把"化工板块跌"当成全员跌**，可能是煤化工因煤价涨被砸、制冷剂因配额在涨。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

## 三、景气度视角（化工专属：产能 + 库存 + 价差为核心母变量）

化工的景气有**清晰的产业链传导链条**，按性质分四类，别用滞后指标做择时（具体取数见上「取数」节）：

- **领先（母变量）**：
  - **产品价差 + 价格**——MDI / 制冷剂 / 有机硅 / 煤化工 / 涤纶各链价差（产品价 − 原料价），**价差拐点领先盈利约 1–2 个季度**，比绝对价更说明盈利。
  - **库存周期**——化工品社会库存 / 企业库存周转，**库存见底回升 + 主动补库**常领先价差和价格。
  - **产能 / 供给端**——在建工程 / 资本开支（领先 2–3 年）、开工率 / 产能利用率、落后产能退出 / 反内卷限产、龙头检修 / 投产节奏。
  - **下游需求**——地产竣工（MDI / 钛白粉 / 管材）、纺服（涤纶 / PTA）、汽车（改性塑料）、新能源（电解液 / POE / 隔膜）。
  - 多档同向时信号最强（价差扩 + 库存补 + 产能收缩 + 需求升 = 主升）。
- **滞后（确认而非择时）**：化工企业营收 / 净利 YoY + 一致预期修正，跟随价差 1–2 季度反映，**不当择时锚**——等盈利确认转向就晚了。
- **结构 / 上限**：龙头单位现金成本曲线、资源 / 配额 / 一体化壁垒（万华成本、巨化配额、华鲁煤化工一体化）——决定龙头穿越周期能力与重仓信心，不决定主趋势开关。
- **事件驱动**：安监 / 环保停产、配额调整、出口退税、油煤跳价、龙头投产 / 爆炸事故——跳空催化，事件级单独评估。

判断要点：

- **价差是母变量，绝对价是表象**：油价涨炼化未必赚（看产品端能否跟涨）、煤价跌煤化工受益（成本松了价差自然张）。**看价差趋势 + 库存方向，不看当期营收**（营收滞后）。
- **产能周期定"能不能赚这一轮"**：需求年年增长，但产能集中投产会让"量增、价跌、利崩"。**资本开支 / 在建工程在收缩 + 落后产能退出 + 反内卷限产，才是盈利拐点**，不是下游需求增长。
- **库存是最高频的领先指标**：库存见底回升 = 早期反转，库存高位累积 + 主动去库 = 价差承压。
- **看的是趋势一致性**：价差 + 库存 + 产能 + 下游需求四个领先维度同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**（盈利会跟上）。

### 可用的择时指标（定性）

> **细分化工的特殊性：裸持有长期不赚钱**——这个指数的全部价值几乎都来自择时，是四个资源子板块（化工 / 有色 / 稀土 / 工业金属）里择时价值最大的一个。所以这族指标虽以降回撤为主，但避开大坑本身就有收益意义。把它们当作**客观第二意见 + 机械纪律提醒**，不替代框架打分；读数用收盘序列按公式自算。

- **`trail_dd10_p120`（首选）** —— 移动回撤止损：收盘价从**过去约 120 日滚动峰值**回撤约一成 → 离场，站回均线 → 回归。**纯收盘价计算，无高 / 低依赖，可靠性最高，作首选择时止损。**
- **`vt15_x_trend200`（降回撤最强，但换手高）** —— 波动率目标 × 200 日趋势过滤，纯收盘可靠。**降回撤最强，但换手很高**——场外基金里会被 7 日内早赎 + 申购费严重侵蚀，频繁进出可能把这部分超额吃掉。核心权衡：降回撤一流，只在摩擦成本可控（或用低费率 / 可 T+0 标的）时才划算；用前先把摩擦算进收益，划不来就降一档用 `trail_dd10_p120`。
- **`chand_22`（吊灯族，仅参考）** —— 吊灯止损（22 日 ATR），方向与回撤止损族一致。**但本指数只有收盘价、无高 / 低，chandelier 的 ATR 用收盘价代理会偏乐观（真实波动更大）**——方向可信、幅度要打折，待接入高 / 低频数据后复核，当前仅作参考、不单独触发。
- **次级辅助（参考）**：`mom_20`（20 日动量）、`trail_dd10_p60`（60 日峰值口径的移动止损）、`dd_ladder_7_15`（7% 减半仓 / 15% 清仓两档梯度）。

**怎么用（判断，不机械执行）**：把择时因子当"现在动不动"的右侧第二意见，**权重 ≤ 产能周期 / 价差主维度**。先看产能周期 + 价差定方向，再用 `trail_dd10_p120` 确认进出节奏；两锚共振确信度最高，冲突时**逐项核验冲突来源**再决策、以基本面为准。`vt15_x_trend200` 在你能接受高换手时优先用它压回撤，否则退回 `trail_dd10_p120`。下行保护仍以"产能周期 + 价差 + 证伪"为主，因子是右侧补刀。

**共同纪律**：①这族因子主要是**降回撤工具**——但因为本指数裸持有就亏，它们这里**兼有收益增强**意义（避开大坑本身就是 alpha）；②**不要写也不要执行"因子 = X 且 Y 时必须 Z"的组合规则**，冲突本身是信号；③`chandelier` 族的 ATR 偏乐观，幅度别照搬。

## 四、宏观 / 成本驱动视角（化工专属：油 / 煤 + 下游需求的母变量）

这是细分化工区别于科技 / 消费板块的**专属维度**，成本端和需求端共同决定价差能不能张：

- **油价（布伦特）= 炼化 / 烯烃 / 涤纶链的成本母变量**：油价是这些环节的原料端。**关键不是油涨油跌，而是产品端能否跟涨——价差才决定盈利。** 油价温和上行 + 下游接受涨价 = 价差扩张（受益）；油价暴涨但下游疲弱传导不动 = 价差被压（受损）；油价暴跌则炼化库存跌价损失 + 价差短期错杀。看油价时同步看下游接受度。
- **煤价 = 煤化工（合成气 / 甲醇 / 烯烃 / 尿素）的成本母变量**：与油价相反方向——**煤价下行 = 煤化工成本松 = 价差张（华鲁恒升受益）**；煤价飙升压煤化工价差。油链和煤链对成本的方向诉求相反，是化工内部分化的根源之一。
- **下游需求 = 价差的真锚**：①**地产链**（MDI / 钛白粉 / 管材 / 纯碱）——竣工 / 新开工 / 家电，地产是基础化工最大的下游母变量之一；②**纺服链**（涤纶 / PTA）——纺织服装内需 + 出口；③**汽车**（改性塑料 / 轮胎）；④**新能源**（电解液 / POE / 隔膜）——随光伏装机 + 新能源车，**部分脱离传统化工周期**。需求拐点早于价差。
- **政策双刃**：①**配额制**（三代制冷剂）——配额收紧 = 价格中枢上移（巨化受益），是独立于油煤的政策性景气；②**反内卷 / 限产 / 能耗双控 / 环保安监**——压缩供给 = 利好价差（供给端出清），但执行反复；③**出口退税 / 关税**——影响外需占比高的品种（如农化 / 部分新材料）。**同一条政策对不同子行业方向相反，必须穿透到对应子行业判断。**
- **新能源 / 农化独立周期**：电解液 / POE 随锂电光伏，钾肥 / 锂随农产品 / 能源金属，**部分脱离油煤主链**——可能出现"传统化工跌、新能源材料涨"的分化。看新能源车 / 装机 / 农产品价，而不是油煤。

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。化工波动大、价差跳变快、油煤 / 政策事件密、产能投产潮杀伤大，纪律不可省：

- **价差兑现 / 转向**：价差创新高 + 库存高位 + 下游需求边际转弱 + 在建工程集中投产临近 → 主动兑现得更积极（盈利顶通常滞后价差 1–2 季）；价差跌穿龙头现金成本线 → 周期下行可能见底（但**别先抄底，等供给端真减产 / 落后产能退出 + 库存企稳**）。
- **产能投产潮预警**：这是化工最具迷惑性的杀伤——**常在"价差仍高、盈利最肥"时，新增产能集中投产就在 1–2 年后**。在建工程 / 资本开支处于历史高位时，越涨越要警惕，不能被当期高盈利麻痹。
- **成本端反转预警**：油价从涨转跌（炼化库存跌价损失）、煤价从跌转涨（煤化工成本抬升）→ 对应子行业是逆风，不必等价格回撤就该降对应敞口。
- **子行业分化预警**：指数靠单一子行业（如万华一只 9.7% 权重）独自撑着、其余子行业普跌 → 结构脆弱，单点证伪即系统性回撤，要降仓。
- **事件前减敞口**：OPEC 会议 / 重大政策窗口（配额 / 反内卷 / 能耗）/ 龙头投产节点 / 安监环保检查前后跳空风险大，单押方向胜率低；不明朗时降仓或观望，别赌跳空方向。
- **硬止损**：高波动品种止损纪律不可省。单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（价差扩张 / 成本松动 / 供给收缩 / 需求复苏）大概率已破。**尤其本指数裸持有就亏，机械止损不是可选项而是命脉。**

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **价差证伪（下行，最关键）**：核心子行业价差（MDI / 制冷剂 / 有机硅 / 煤化工）从扩张转持续收缩、跌穿现金成本——盈利逻辑直接被推翻，板块行情失去燃料。
- **产能证伪（下行）**：在建工程 / 资本开支再度扩张、新增产能集中释放压垮价差、反内卷 / 限产落空、落后产能快速复产。
- **库存证伪（下行）**：库存高位持续累积 + 下游主动去库——补库逻辑作废。
- **需求证伪（下行）**：地产竣工 / 纺服 / 汽车 / 新能源装机等下游指标连续走弱。
- **成本证伪（下行）**：油价暴涨但产品端传导不动（炼化 / 烯烃价差被压）、煤价飙升压煤化工——成本端单边恶化价差。
- **趋势证伪（下行）**：指数跌破 200 日均线且 1 月未收回——但应根据当时市场环境修正该指标。
- **估值证伪（下行，反向）**：价差新高 + PE 看似"最低" + 在建工程飙升 + 全民进场 + 卖方高呼"超级周期 / 涨价潮"——周期顶部最危险信号组合（PE 陷阱叠加投产潮种子叠加情绪过热）。
- **看空被证伪（上行 veto-watch）**：价差跌穿现金成本后供给端主动减产 / 落后产能退出 / 反内卷限产落地；库存见底回升；油价回落松开炼化成本 / 煤价回落松开煤化工成本；下游补库启动；配额收紧；龙头投产推迟——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 细分化工是**成本（油 / 煤）× 产能周期 × 库存 × 价差**四重叠加的强周期赛道，而且**裸持有长期不赚钱**——这意味着择时不是锦上添花，而是这个指数全部价值的来源。你的活儿是价差转向 / 成本反转 / 产能投产潮 / 系统性风险来时少亏，靠压最大回撤把负收益的裸持有翻成正夏普。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- 但该在场时别缺席：趋势明确向上（价差扩张 + 成本松动 + 库存去化 + 需求复苏 + 产能收缩 + 价格多头）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（那可能是周期顶）。
- 不用硬止盈硬止损——择时交给趋势、价差、回撤说话，不交给固定数字（但**机械回撤止损 trail_dd10_p120 在本指数是命脉，不是可选项**）。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且核心价差 / 成本同向运动**。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10–15%（周期股波动大，箱体宽）内来回 + 箱体反复假突破 + **价差也在区间内震荡**。
  - **过渡待定**：信号不清、板块趋势与价差趋势背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（价差转缩 / 成本反转 / 趋势破位 / `trail_dd10_p120` 触发）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（配额 / 反内卷 / 油煤跳价）即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：
- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（油煤跳价 / 政策最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日 + 价差同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标（含已验证因子）

- **时序动量**：看指数自己过去一段（数周到数月）的方向，**叠加核心价差 / 成本趋势**。两层共振向上→在场吃 Beta；任一转下（特别是价差转缩）→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。**机械锚用 `trail_dd10_p120`（120 日峰值回撤约一成离场）作右侧第二意见**；想更狠压回撤、且摩擦成本可控时用 `vt15_x_trend200`（降回撤最强，但换手高，先算申赎成本）。
- **波动率目标（体感纪律）**：化工本就高波动，越平静越敢拿，振幅骤增 / 大涨大跌 / 油煤单日大跳变 / 价差单日大变时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **事件叠加**：OPEC / 重大政策（配额 / 反内卷）/ 龙头投产 / 安监环保窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（供给真实收缩 / 价差确认扩张）确认后再顺势加。
- 叠加：**方向（动量 + 价差）决定在不在场，波动决定在场时待在哪一档；`trail_dd10_p120` 在方向走坏时机械断后。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10–15% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：化工箱体随时可能因一条配额 / 反内卷 / 油煤跳价 / 龙头投产向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：油煤脉冲多、政策易反复，假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错。**`vt15_x_trend200` 换手高的代价正集中在这种箱体里，震荡市更要克制。**
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如油煤方向转向 / 配额落地 / 反内卷限产 / 大规模减产），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 价差转缩 / 成本反转 / 趋势转空 / `trail_dd10_p120` 触发 → 一把清到位，可以直接到 0**：化工周期下行往往加速（产能投产潮 + 价差坍塌），且裸持有本就负收益，等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。化工的高赔率组合是 **价差扩张 + 成本松动 + 库存去化 + 下游补库 + 产能收缩 + 价格放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；宁可错过，不可做错**——但"宁可错过，不可做错"只约束**低赔率情形**；高赔率时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势、价差和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯三件事：**趋势破没破（含价差趋势）** + **从持仓高点回撤了多少（机械锚 `trail_dd10_p120`）** + **价差 / 库存有没有见顶反转**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大 / 价差见顶→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且化工主升浪回调动辄 20–30%（价差波动 + 盈利杠杆），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降，机械化即 `trail_dd10_p120`；`chandelier` 族方向一致但 ATR 偏乐观，幅度打折）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。化工单边跌起来很容易摸到深水区（价差坍塌 + 盈利杠杆向下，**裸持有这个指数本就负收益**），这条对本指数尤其命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关。`trail_dd10_p120` 正是这条的机械化身。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 化工波动大、油煤 / 政策新闻天天有诱惑，更要克制别被脉冲诱发高频折腾。**特别提醒：`vt15_x_trend200` 虽降回撤最强，但换手很高，在场外基金里会被早赎 + 申购费严重侵蚀——用它前先把这部分摩擦算进收益，划不来就退用 `trail_dd10_p120`。**

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、产品价差、油 / 煤成本、库存 + 产能 + 下游需求、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 周期顶 PE 最低（PE 陷阱） | 周期股**永远看 PB + 价差 + 资本开支位置**，不看 PE；只有盈利稳态子行业才能用 PE |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 价差扩张 + 成本配合看 B；趋势破位 / 价差转缩时极端读数当定性预警 |
| 油价涨利好化工 | 油价涨利空化工 | 看**价差**：产品端跟得上涨价看 A（炼化受益），跟不上 / 库存跌价损失看 B；煤化工对煤价反着读（煤跌才好） |
| 量增就该买 | 量增不等于利增 | 看**产能 + 价差**：需求增 + 供给收缩 + 价差扩看 A；需求增但投产潮 + 价差跌看 B（最具迷惑性） |
| 限产 / 反内卷是利好（供给收缩） | 限产落空是利空 | 看是否**真落地 + 持续**：配额收紧 / 落后产能真退出看 A；政策喊话但执行反复、复产快看 B |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**价差 + 库存方向**：领先端仍向下看 A，领先端（价差 / 库存）见底回升（盈利滞后）看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但价差 / 成本逻辑没坏看 A，价差坍塌的单边下跌途中看 B |
| 强者恒强 | 物极必反 | 趋势中段 + 库存去化 + 价差加速看 A，极端情绪 + 价差创新高 + 在建工程飙升 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损 / `trail_dd10` 已就位看 A，冲高乏力 / 价差见顶 / 库存累积 / 投产临近 / 量价背离看 B |
| 化工是一个板块 | 子行业各走各的 | 默认按"分化"理解：MDI / 制冷剂 / 煤化工 / 炼化 / 电解液驱动不同，穿透到主导子行业判断，别用一个故事解释整个指数 |

> **核心一句**：细分化工——裸持有不赚钱，全部价值在择时；用 **产品价差 + 油 / 煤成本 + 库存 + 产能周期 + 下游需求** 判景气、用 **PB + 现金成本曲线 + 资本开支位置** 判空间（**永远别用 PE**）、用 **趋势 / 动量 + `trail_dd10_p120`（首选）/ `vt15_x_trend200`（降回撤最强但换手高、先算成本）** 择时、用 **大开大合 + 压最大回撤** 做仓位；吃该吃的 Beta、躲价差转向与成本反转误伤、空仓不愧疚、按优势大小下注、进出算成本，靠压回撤把负收益的裸持有翻成正夏普。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新成本结构、新政策工具、新供需 / 新材料路线）。
- **定期 + 事件驱动**：一轮产能周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各子行业（聚氨酯 / 制冷剂 / 煤化工 / 炼化 / 电解液 / 农化）的差异化打法；**已验证因子的用法（trail_dd / vt15 / chandelier 在新数据上的表现复核，尤其 chandelier 待高 / 低频数据接入后的 ATR 校准）。**
- **不轻易动（信仰与原则层）**：唯一信仰（裸持有不赚钱、价值全在择时、价差扩张 + 趋势确认重仓、价差转缩 + 转空降仓）、双锚结构（产能周期 / 价差 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀、宁可错过不可做错（仅约束低赔率）、对本金保守对 β 放纵、PE 永远反着读。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；产能周期切换、成本结构重置（油煤定价机制变）、政策框架重置（配额 / 反内卷常态化）是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
