# 通信技术主题指数投资框架（方法论）

这是研究视角，不是执行手册。拿到当日数据后，**先做〇节的环境三问（永远的第一步）**，再依次过各视角，自行综合判断该不该动、动多少——框架给坐标系，不给触发器。

> 通信技术主题（931144）是 A 股"新兴通信技术"的**全口径主题敞口**：光通信/算力链是主梁，旁边挂着通信半导体、物联网/5G 应用、量子通信与卫星互联网题材。玩法核心一句话：**每天先回答"今天这根 K 线是谁画的"——算力主线、题材脉冲、还是半导体周期跟随——主驱动认对了，其余视角才有意义**。跨行业口径 = 信号源杂、题材噪声多，这既是它比纯设备指数难做的地方，也是文本面权重必须拉满的原因。

## 核心认知

中证通信技术主题指数（931144.CSI）：51 只样本，基日 2015-12-31，2019-05-30 发布。选样为"产品/业务与 5G、物联网、光通信、量子通信、卫星通信等新兴通信技术相关"，成分**跨行业**：通信设备及技术服务为主体，叠加通信半导体、电子、计算机。

- **主驱动已切到全球 AI 算力 capex**：北美云厂商 capex 指引、英伟达节奏是母变量，与 931160 同源。
- **但信号源多两路**：通信半导体成分跟全球半导体周期与国产替代；量子/卫星/物联网在本指数有**真实成分敞口**，政策与发射事件能直接打出脉冲，不只是外溢情绪。
- **三类行情形态轮换**：算力主线（与 931160 同步）/ 题材脉冲（多回补）/ 半导体跟随（独立于 931160 的走法）。**看错形态，所有信号都会读反**——所以主驱动识别是每天第一问。
- **高 β、深回撤、事件跳空多**：OOS 区间 buyhold 最大回撤约 −39%；海外映射强，题材源又多，单日跳空与大阳回吐是常态——不能死扛，更不能追脉冲。51 只样本的主题指数没有分散保护，回撤控制全靠纪律。

### 与 931160 框架（telecom-equipment.md）的分工

- 931160 = 纯设备口径、光模块浓度最高，是"算力 capex 纯度敞口"；931144 = 宽主题口径，多了通信半导体与计算机成分、量子/卫星题材敞口更大。
- 两者高相关、同涨同跌，算力主线行情里是同一个故事；差异在 931144 **信号源更杂、题材噪声更多、脉冲更频繁**。
- 分工：算力主线的景气判断**直接复用 telecom-equipment.md 的 A 链方法**，不重复造轮子；本框架的增量 = 〇-3 主驱动三分法 + 四节题材事件评估 + 半导体跟随形态识别。
- 两框架结论分歧时，先查是不是题材噪声/半导体成分造成的口径差；若算力主线本身分歧，回母变量证据链重判，不许各说各话。

### 估值特性（先记住再进一节）

1. 本指数 PE 是**三种估值逻辑的混合物**：光通信是订单周期股（景气上行 PE 反而显得便宜）、题材成分靠叙事定价、通信半导体跟自身周期。指数级分位糅在一起，**当择时扳机比在 931160 上更不可靠**。
2. 估值只剩两个用途：极端高分位 + 全民进场迹象 = 定性顶部预警；极端低分位 + 盈利下修多季 = 触发去文本找反转证据。其余时间不投票。

## 〇、先判市场环境（永远的第一步）

三问答完并**显式留痕**（写进当日复盘，次日继承），才允许进入任何加减仓决策。

**1）全市场风险偏好：A 股现在给不给高 β 科技成长活路？**
本指数是风险偏好放大器，题材成分对偏好**更**敏感——收缩期题材脉冲几乎没有持续性，预设一日游。用 `macro_50etf_vix`、市场情绪因子（看累计与相对位置，不看单日）、大盘趋势判：**扩张/收缩/中性**；收缩期所有看多信号自动降档。

**2）板块状态：趋势市 / 震荡市 / 过渡待定（三选一）**
长均线排列与箱体识别常规判法。两条专属提醒：**题材脉冲的单日大阳不算状态切换证据**（本指数"大阳后回吐"比 931160 更勤）；状态有粘性，默认继承昨日结论，只问"有没有确认级证据推翻它"。

**3）主驱动识别（本指数最要紧的一问）：今天谁在定价？三分法：**
- **算力主线**：通信/设备板块同强、光通信龙头领涨、海外算力链共振 → 信号源整套切到 telecom-equipment.md 的 A 链。
- **题材脉冲**：量子/卫星/6G 政策或发射事件驱动、题材标的领涨而业绩龙头不跟、文本面无基本面增量 → 不入景气，按四节单独评估，预设回补。
- **半导体跟随**：半导体路明显强于通信路 → 信号源切到半导体周期与国产替代；由部分成分驱动，对指数拉动取决于扩散度，用板块代理交叉验证而非外推。
判据 = 三路板块强弱 + 领涨成分类型 + 文本增量归类，一句话留痕。

## 一、估值视角（定性预警，绝非择时扳机）

- **禁止拿指数 PE 分位做低吸高抛**——混合口径连"贵贱"都说不清。"趋势 > 估值"作单向过滤器：只否决"因为贵所以卖/因为便宜所以接"，不给反向授权。
- **顶部预警**：极端分位 + 全民进场迹象（题材词出圈、主题基金发行火爆、研报口径切到"远期空间"）→ 提示趋势尾段，交给止盈纪律。
- **底部触发器**：极低分位 + 龙头盈利下修多季 → 不抄底，但触发去文本找反转证据；证据出现且趋势企稳，按骨架回补。
- **上修斜率比分位承重**：`stock_alpha` 龙头一致预期变动率月度跟踪，转下修是比破位更早的顶部信号。

## 二、趋势视角

- **方向锚**：收盘 vs MA120/MA200 + 均线斜率；20–60 日时序动量辅助（正式读数按量化辅助节公式算）。
- **量能/拥挤确认**：用两路板块拥挤度代理。**题材脉冲日的放量不等于趋势量**——看次日承接与业绩龙头是否跟随；拥挤极端 + 价格加速 = 主升尾段特征。
- **跳空甄别**：本指数事件跳空比 931160 更频繁，**默认情绪级**，次日去研报纪要找基本面增量，找到才升级为逻辑级顺势；找不到一律当脉冲，不追价。
- 震荡市均线信号反复打脸，转箱体思维。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（先认链，再读链）

- **A 链：全球算力 capex（当前主驱动）**。传导与 931160 同源：北美 capex 指引 → GPU/网络平台节奏 → 光模块订单排产 → 龙头业绩。读法整套复用 telecom-equipment.md 三-A（领先端定方向、财报只做确认、代际切换重洗量价），不重复展开。补一条口径提醒：931144 对这条链的弹性被非光通信成分稀释或放大，幅度不臆测——**要算力纯度判断用 931160 口径去想，本指数承接的是全口径主题仓位**。
- **B 链：通信半导体/半导体周期**。通信芯片、射频、光芯片类成分跟全球半导体周期（库存/量价）与国产替代叙事，节奏与 A 链可能错位——半导体强、设备平时本指数走独立行情，正是〇-3 要抓的形态。信号源：半导体路 `sector_*` + `research_search` 周期位置与政策订单文本。只在判定"半导体跟随"时升为主读，平时作背景。
- **C 链：物联网/5G 应用侧**。政策催化型，落地慢，行情多为政策脉冲 + 缓慢兑现；`research_search` 跟政策原文，不入打分，作题材背景温度计。

**纪律**：多链并行时，以〇-3 认定的主驱动链为主读，其余降为背景；领先端定方向、滞后端（财报）做确认，背离时信领先端。

## 四、事件/政策视角（本指数权重高于 931160 的一节）

- **量子通信/卫星互联网（特色敞口）**：跟政策文件（试验网、星座组网规划、牌照）与发射/组网事件，会打出可观单日脉冲。评估三问：**有无订单/收入兑现路径？时间表多远？涨的是基本面还是纯叙事？** 兑现路径出现前一律按情绪脉冲：已持仓顺势交给止盈纪律，空仓不追。出现真实订单收入 = 题材升格为景气，转入景气链跟踪。
- **技术路线之争（CPO/硅光等）**：作用于光通信成分，判法同 931160——替代还是共存、龙头有无卡位、时间表多远；有卡位的替代叙事多为虚惊。
- **制裁/关税/出口管制**：先分清打哪一环。限中国厂商供海外 = 逻辑级利空；限海外器件输入 = 利好国产替代——**本指数含半导体成分，国产替代受益敞口比 931160 大，同一条制裁新闻在两个指数上可能不同号**，这是两框架最易分歧处。
- **5G/物联网政策**：单条不足为凭，密集出台期抬升主题关注度，作背景计入。
- **事件前管敞口**：英伟达/北美云厂商财报夜前后跳空风险大，方向不明不赌。

## 五、文本视角（zsxq 纪要 + 新闻研报，每日必读、最高优先级）

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（调研纪要，PIT 截断到当日）+ `research_search` / `research_view`。**每个交易日必须执行，不许跳过**——哪怕当天不动仓位；其他视角缺数据可降级，这个视角不读完不收工。
>
> **为什么文本面是本指数超额的全部来源**：把母变量排一遍——capex 指引、订单排产、量子/卫星政策与发射、半导体周期位置、制裁条款——**没有一个是结构化数据**，全活在新闻研报纪要里。结构化口径只剩价格和板块代理，而纯价格因子在本指数的验证结论是"改善回撤形态、给不了方向领先性"（见量化辅助节）。丢掉文本面，这套框架剩下的部分一台回测脚本就能替代。

### 每日固定动作（3–5 次调用内完成，不许刷库）

1. `zsxq_topics`（count=20）扫当日纪要流，标记光通信/主设备/通信芯片/卫星/量子相关条目；**调研密度本身是关注度信号**。
2. `zsxq_search` 用 1–2 个当日主线词，选词跟〇-3 主驱动走（'光模块'/'算力'/'卫星互联网'/'量子'/'通信芯片'）；搜 0 条先看 `query_used` 换词。正文 `zsxq_topic_detail` 最多 1–2 篇。
3. `research_search`（search_type='all'）查当日 capex/订单/政策/发射/制裁增量；季报季加扫海外大厂 capex 表态。
4. 海外映射专项：算力链夜盘大波动时检索原因并分级（逻辑级/情绪级）。

### 读法纪律（文本是信息也是毒药）

- **读事实与方向，不抄结论**：纪要是事实源 + 关注度代理，不是买卖建议。
- **领先性分层**：capex 指引、政策原文、订单合同 = 领先信号，承重；研报观点/目标价 = 滞后情绪代理，只做密度统计。
- **题材文本专项纪律**：量子/卫星类文本叙事浓度高、可证伪点少，只认三类硬事实——**政策原文、发射/组网完成、签了字的订单**；"空间测算/产业链梳理"一律记作情绪密度，不进证据链。
- **一致看多逆向读**：趋势成熟期是反向信号、行情起点是领先信号——属于哪种，回〇节当场定，不设机械线。
- **证据落链（硬性）**：当日 belief/复盘 evidence 至少 1 条文本条目（topic_id 或 INFOCODE + 一句话摘要）；没增量如实写"今日文本面无增量"。**没有检索记录不许引用"听说/市场传言"**。
- **留痕（硬性）**：复盘固定一行 `文本增量: 无|低|中|高 —— <读到什么、有没有改变主驱动判断或动作>`。
- **权重边界**：文本给方向与证伪，不直接给仓位数字，不得突破回撤控仓与最小步长纪律。

## 六、证伪视角（对称化）

证伪是论据的破坏，看多看空都要列；触发不等于清仓，但原论据作废，需新论据才能维持原仓位。

- **看多被证伪**：北美 capex 指引集体下修或措辞转谨慎；英伟达数据中心收入/平台节奏低预期；光模块"提价停止→砍单传闻→排产下修"三连逐级加重；龙头一致预期变动率转下修（最早的硬信号）；半导体周期重新下行拖累通信半导体成分；题材叙事退潮（规划落空、时间表一再后移）；制裁直接限制对海外大客户供货。
- **看空被证伪**：capex 重新上修/新代际产品超预期起量；半导体周期确认上行 + 国产替代签约订单；卫星/量子出现真实订单与收入路径（题材升格信号）；利空靴子落地订单未损；龙头盈利下修结束 + 趋势企稳（按〇-2 确认级标准）。

# 仓位管理方法论

## 唯一信仰：环境定骨架 + 主驱动定方向 + 纪律压回撤

- 高 β + 题材脉冲密集 + 深回撤品种（OOS buyhold 最大回撤约 −39%），夏普提升几乎全靠压回撤：主驱动逆转、系统性风险来时少亏，主升浪在场吃足，脉冲日不被勾引。
- 仓位完全由信号赔率决定，**没有常态中枢**——空仓满仓都合法，空仓不愧疚；不知道怎么办按"过渡待定"处理，不是习惯性下半注。
- 该在场别缺席：算力主线确认 + 趋势多头 + 文本面订单饱满时还空着，与追脉冲被回补一样不及格。

## 一、骨架选择（承接〇-2）

- **趋势市 → 时序动量 + 波动率体感**：方向对就拿住让 β 跑，不做高抛低吸；振幅骤增本身是降仓信号；趋势破位 + 主驱动链确认转空 → 降仓乃至清零。
- **震荡市 → 防守、少动、守箱沿**：箱体中段不动手，轻仓不赌方向。**题材脉冲假突破是本指数震荡市头号陷阱**——单日大阳不算突破确认，看次日承接与龙头跟随；逻辑级催化突破并站稳数日 → 立即交接回趋势骨架，不反向 fade。
- **过渡待定 → 维持原状态/轻仓**，等确认级证据。

## 二、不对称操作：离场快、回补看赔率

- **大开大合**：最小步长 20%，2–5% 微调无意义。
- **系统性风险/主驱动逆转确认/趋势转空 → 一把降到位，可以到 0**：本指数下跌常加速（夜盘传导 + 拥挤解杠杆 + 题材资金踩踏），"再等一天"经常多亏一段。
- **回补按赔率**：主驱动明确 + 趋势确认 + 文本面硬事实 + 拥挤未极端共振才配大步上仓；论据不扎实分 2–3 个大步或放弃。
- **只在浮盈、趋势未坏的回调里加仓；绝不下跌摊薄。**
- **脉冲专条**：题材脉冲不构成回补理由；题材驱动的浮盈，兑现节奏应快于主线驱动——题材的利润窗口天然更短。

## 三、止盈止损：趋势 + 回撤说话，不用固定点位

- 在场只盯两件事：**趋势破没破** + **从持仓高点回撤多少**。趋势在、回撤温和 → 拿住；破位或回撤放大 → 大块兑现乃至清零。
- **主升尾段主动止盈**：拥挤极端 + 估值顶部预警 + 文本面一致看多三者叠加 → 收紧离场线，不等流动性反转。
- **保本线**：浮盈 ≥ 10% 后离场线抬到成本价，浮盈不许变浮亏。
- 亏损端窄而果断、浮盈端宽而敢加，两套口径不混用。

## 四、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓/停止加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 要 +25%、−33% 要 +50% 才回本；本指数单边下行很容易进深水区。

## 五、成本意识

- 7 日内赎回有惩罚费率，避免同标的 7 日内 round-trip；**脉冲日的冲动单最容易撞上这条**。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势转空、账户回撤穿阈值、止盈触发三类信号允许跳档，单日情绪与跳空不打破持有窗口。

## 六、量化择时辅助（研究室 2026-06-11 全 44 因子族扫描，验证于 931144 全周期）

> IS 2015–2021 / OOS 2022–2026.06，5bp 单边、T+1。两族绿灯：**慢趋势突破 + 短动量**，互相正交。定位是客观第二意见，不替代框架打分。两因子尚未注册进 `quant_factor` 工具，读数用 `market_index_quote` 收盘序列按公式自算，已列入包装待办。

### `donchian_60`（主）—— 60 日通道突破

- **是什么**：收盘突破前 60 日最高收盘 → 满仓；跌破前 60 日最低收盘 → 空仓；区间内沿用上一状态。IS_dCal +0.19；OOS Calmar 1.07 vs buyhold 1.01（dCal +0.06），OOS 最大回撤 −30% vs −39%；4.4 年 OOS 仅翻转 10 次；bootstrap CI[0.15,1.32]、walk-forward 4/5。低翻转慢趋势，职责是吃主升段、躲深熊段。
- **会漏什么（公式可推）**：① 通道收窄时反复无效突破；② 重入要等创 60 日新高，**V 型反弹前段必然缺席**；③ 纯价格，对 capex 拐点、题材事件、财报雷零预警——它走在行情后面。
- **怎么用**：与框架同号 → 置信度加档；它在场而框架转空 → 框架主导（它无事件预警，不构成"再等等"的理由）；它离场而框架仍看多 → 先逐项核验框架论据是否过期，尤其文本面有没有漏读利空。

### `mom_20`（辅）—— 20 日动量

- **是什么**：近 20 日收益 > 0 → 满仓，否则空仓。OOS Calmar 1.31（dCal +0.30），OOS 最大回撤 −27%；CI[0.15,1.25]、walk-forward 5/5；OOS 翻转 89 次（约 20 次/年，5bp 下可接受但偏高）。
- **会漏什么（公式可推）**：① 震荡市高频抽脸（翻转数摆在那）；② T+1 执行对单日跳空必然滞后一天——事件跳空多的本指数尤其要记得；③ 同样零事件预警。
- **怎么用**：比 donchian 灵敏，作"趋势还在不在"的快读数；〇-2 判定震荡市时它的翻转默认当噪声，不据此动仓。

### 两族互为确认

- **同号** = 价格面有共识，置信度高；**反号** = 大概率处在拐点或震荡——不是谁对谁错，是"价格面没有共识"的信号，方向裁决权交回框架（主驱动 + 文本面）。
- 两族的回撤改善来自空仓段躲避，不是止损机制；账户级回撤控仓照常独立运行。
- **不要写也不要执行"因子 = X 且 YY 时必须 ZZ"之类未回测的组合规则**；冲突本身是信号，核验来源再决策。
