# 中证白酒投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

## 投资底线：保住本金是第一位

任何研究视角、任何信号、任何"长期空间"，都凌驾不了一个铁律：**保住本金第一，赚钱第二**。

- **回撤数学不对称**：亏 50% 要翻倍才回本；亏 70% 要涨 233% 才回本。一次失控的回撤要靠未来无数次正确补回，长期复利就此被吃掉一截。
- **白酒不是债**：高端品牌看着像收租，但戴维斯双杀（去库存 + 杀估值）能在 1-2 年里把指数砍掉一半（历史上的三公限制 + 塑化剂风波、以及随后一轮深度调整，两轮教训摆在那里）。"喝酒永远涨"是死扛的借口，不是策略。
- **本金保护优先于一切**：批价崩、库存崩、趋势破、账户回撤明显——任何一个先行信号亮红灯，先降仓保命，再回头复盘对错。**宁可错过 β，不让本金折在双杀里。**
- **不接飞刀、不重仓搏底**：去库存下行 + 趋势向下的环境，不试探、不抄底；底部企稳的左侧只允许小仓位试探，单次不超过一个最小步长。
- **冲突即让位**：若任何规则、任何视角的结论与"保住本金"冲突，以保住本金为准——包括"唯一信仰"中的进攻条款。

这一条是凌驾于六视角、双锚、仓位状态机之上的最高准则。下文所有规则均在此约束下运行。

## 核心认知

白酒（中证白酒 399997）= 强品牌消费 + 中周期景气贝塔，从高端（茅台 / 五粮液 / 泸州老窖）到次高端（汾酒 / 水井坊 / 酒鬼酒 / 舍得）到区域龙头（古井贡 / 今世缘 / 迎驾 / 口子窖）。它的灵魂是**品牌定价权**叠加**商务 / 宴席消费景气周期**——既有消费股的高 ROE、高现金流、强护城河，又有跟着经济与渠道库存走的中周期波动。三个特性决定玩法：

- **强品牌护城河 + 高确定性现金流**：高端三家定价权极强、毛利 80%-90%、现金流像收租，长期 α 来自品牌而非赛道扩张。不是典型产能周期品，风险更多来自需求走弱、渠道压货和价盘倒挂，而不是传统制造业式扩产价格战。
- **中周期景气波动**：核心是"商务 / 宴席消费景气 + 渠道库存周期"——景气向上（消费升级 + 财富效应）→ 提价顺畅、动销旺、库存低、批价涨；景气向下（经济走弱 + 商务收缩）→ 动销疲、压货、库存高、批价崩，常呈现数年级别的景气循环（历史上经历过"限制三公消费 + 塑化剂"的戴维斯双杀、随后的消费升级大牛市、以及再之后的深度调整，循环往复）。
- **量价双轮 + 结构升级**：高端靠**提价**（价），次高端靠**放量 + 升级**（量价齐升弹性最大），区域龙头靠**地产链 + 区域消费升级**。吨价提升（产品结构升级）是穿越周期的慢变量。

驱动排序：**渠道景气（批价 / 库存 / 动销 / 回款）> 品牌定价权与格局 > 趋势 / 资金 > 宏观与政策（经济、消费税、三公）> 估值分位**。研究时问三件事：

1. 渠道景气在哪个阶段（去库存下行 / 底部企稳 / 景气扩张 / 高位压货）？→ 决定能不能重仓、是不是底部
2. 趋势对不对、资金在不在？→ 决定现在是加是减
3. 品牌格局 / 政策 / 宏观消费力变没变？→ 决定是不是该撤

## 指标使用纪律：先验证、再上场

方法论里提到的批价、渠道库存、动销、回款 / 合同负债、毛利、销售收入这些**渠道与基本面变量**是直接因果事实，不需要统计验证——需要的是数据是否真。

但任何**派生统计指标**（资金流强度、动量类、估值分位、情绪打分、技术指标、衍生比率）在被作为交易理由之前，**必须先在白酒指数上验证它有没有效**。这是底线，不是建议。

**怎么叫"验证"**：

1. **明确的可证伪命题**：把指标做成可被数据回答的判断，例如"指标 X 达到某状态后第 N 个交易日的指数收益方向稳定"。
2. **足够样本**：至少覆盖一轮完整的渠道景气周期（3-5 年），不能只看一段牛市或一段熊市。
3. **方向、胜率、赔率俱全**：胜率接近 50% 或赔率接近 1 的指标就是噪声，扔掉。
4. **样本外稳定**：在不同年份 / 不同子层（高端 / 次高端 / 区域）主导阶段都能保持一致方向，不只在某段过拟合。
5. **有产业链解释**：能讲清为什么它在白酒上有效，不能只有数学相关性。

没工具或时点不允许直接跑回测时（常态），允许降级验证：在 mem0 / 研报 / 历史样本中检索过去 N 次触发后指数走势，至少 5 次独立样本方向一致才能用；样本不足就明确标注"未验证、仅观察"。

**自检规则**：每次用一个派生指标推动决策时，先问"我验证过吗？验证依据是什么？"——答不上来就当没看见这个指标，回到批价 / 库存 / 动销 / 回款这些基本面变量本身找答案。

### 白酒指数特性：

1. **批价是白酒的"产业链价格"**：飞天茅台批价通常是全行业景气最重要的先行锚，批价企稳回升 → 渠道有利润 → 经销商敢打款进货 → 动销与报表跟上；批价阴跌 → 渠道倒挂亏钱 → 压货去库存 → 业绩坍塌。**盯批价通常比等财报及时得多。**
2. **库存是放大器，回款是蓄水池**：渠道库存高（需按价位带和旺淡季比较，3 个月以上可作为偏高预警而非硬阈值）= 顺周期时被掩盖、逆周期时引爆价盘的定时炸弹；合同负债 / 预收款（蓄水池）反映经销商打款意愿，但也会受直营占比、代售模式和控货节奏影响。**报表收入可以被蓄水池调节，批价和库存更难长期伪装。**
3. **白酒能用 PE，但要防戴维斯双杀**：与强周期股相反，白酒盈利稳定、可 DCF，**PE 历史分位的均值回归是有意义的**。但最大杀伤是"EPS 下修 + 杀估值"同时发生（景气顶 60x PE 见过、景气底 20x 也见过）。高 PE 分位 + 批价 / 库存恶化 = 顶部双杀预警；低 PE 分位 + 批价 / 库存触底回升 = 底部双击信号。
4. **政策与宏观是双刃**：经济与商务消费景气（地产财富效应、商务活动、宴席场景）直接决定需求；政策端三公消费限制（历史上有过深刻教训）、消费税改革（征收环节后移传言）、禁酒令、塑化剂式黑天鹅，都能在短期重创估值与情绪。它既是周期催化，也是杀伤来源。

## 一、渠道景气周期视角（白酒的核心价值锚）

白酒盈利由**商务 / 宴席消费景气 + 渠道库存周期**主导，短中期不由产量决定（基酒产能通常不是主约束，需求与渠道才是）。渠道景气周期才是这个指数的价值锚，把它分四个阶段定位：

- **景气下行 / 去库存（下行）**：经济走弱、商务宴席收缩、动销疲软、渠道被动累库、批价阴跌甚至倒挂、经销商打款意愿差——业绩还在下修，戴维斯双杀（杀盈利 + 杀估值）的主场。**少碰，趋势转空就清。**
- **底部企稳（反转前夜）**：库存去化到健康水位、批价跌无可跌并止跌、动销边际改善、回款 / 合同负债回暖、龙头主动控货挺价——这是左侧布局区，但要批价 / 库存信号确认，不是见跌就抄。
- **景气扩张（上行）**：消费升级 + 财富效应共振、动销旺、库存低位、提价顺畅、产品结构升级、合同负债饱满——盈利和估值共振向上（戴维斯双击），**主升段，重仓吃 β**。
- **高位压货 / 过热（过热）**：批价冲高、渠道疯狂囤货、全民看好、估值脱离盈利锚、厂家向渠道大幅压货透支——下一轮去库存的种子已埋下，**警惕，趋势走坏即减**。

判断阶段看三件事：**批价（在不在企稳回升）、渠道库存（高位还是去化到位）、动销 / 回款（边际在改善还是恶化）**。报表收入 / 利润是滞后且可被蓄水池调节的验证，不是先行信号。

## 二、估值视角（白酒可以用 PE 分位，但必须配批价 / 库存防双杀）

白酒龙头长期现金流相对可预测，**与强周期股相反，PE 历史分位的均值回归在这里是有意义的择时辅助**——但不能单用：

- **PE 分位 + 渠道景气双重确认**：低 PE 分位本身不是买入信号，要叠加"批价止跌 + 库存去化 + 动销回暖"才成立；高 PE 分位也不是卖出信号，要叠加"批价见顶 + 库存累积 + 动销转弱"才危险。**估值分位定赔率，渠道景气定方向。**
- **警惕戴维斯双杀的分母陷阱**：景气下行时 EPS 会下修，单看静态 PE 会"显得便宜"（E 还没降完），实际是双杀途中。底部要等 EPS 下修接近尾声 + 批价库存反转，才是真便宜。
- **高端 / 次高端 / 区域分层看**：高端（茅台类债属性）可给更高 PE 中枢、用 DCF 锚；次高端弹性大、PE 波动最剧烈，景气顶杀得最狠；区域龙头看地产链与区域消费力。不能用一个统一分位套全指数。
- **极端泡沫的定性预警**：全民囤酒、新基金扎堆、研报一致"喝酒永远涨"、龙头估值脱离任何盈利锚时，把它当顶部提示，配合趋势减仓——而不是单看一个估值数字。

成长性（次高端放量空间、结构升级斜率、全国化进度）只用来判断**值不值得在景气里重仓**，不用来在去库存下行里抄底。

## 三、需求与景气视角（盯批价—库存—动销—回款的趋势一致性）

白酒跨高端 / 次高端 / 区域多层，单一指标失真。看七个维度的趋势一致性：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 批价 | 飞天茅台批价、五粮液 / 国窖批价、次高端单品批价 | 先行（领先盈利与股价的总闸门） |
| 渠道库存 | 经销商库存月数、动销 / 进货比 | 核心（高库存是价盘崩塌前兆） |
| 动销 | 终端动销、开瓶率、宴席 / 商务 / 礼品场景景气 | 真实需求 |
| 回款 / 蓄水池 | 合同负债 / 预收款、经销商打款进度、收现比 | 领先报表但需结合渠道模式变化校正 |
| 盈利 / 结构 | 成分股营收 / 净利增速、吨价、毛利率、产品结构升级 | 滞后验证 |
| 资金 | 北向、ETF 份额、融资余额、机构持仓集中度 | 情绪 / 边际 |
| 宏观 / 政策 | 经济景气、地产财富效应、消费税 / 三公 / 禁酒令 | 催化 / 双刃 |

**批价与渠道库存是景气拐点的主导，动销 / 回款是真实需求验证，宏观消费力是底层变量**，共振时信号最强。看的是趋势一致性（多维同向），不是加权打分。报表增速年年有是底色，但**批价和库存才决定这一轮景气是真扩张还是渠道压货透支**。

## 四、趋势与资金视角（择时主轴）

渠道景气定"值不值得拿"，趋势 / 资金定"现在动不动"。白酒在景气拐点弹性大、机构抱团踩踏狠，趋势是避开大跌段的主力。

- **方向锚**：指数 vs 200 日均线，配合量能确认突破 / 跌破的强度。
- **资金面**：北向、ETF 份额、融资余额、机构抱团集中度——白酒是机构重仓核心资产，抱团瓦解 + 批价走弱是顶部信号，外资与机构回流 + 批价企稳是底部确认。
- **波动率**：振幅骤增、急涨急跌 = 环境恶化信号，本身就是降仓理由。

研究时不问"涨没涨"，问"趋势和资金的方向，配不配合渠道景气的判断"。**景气拐点（左侧）+ 趋势确认（右侧）共振，是最强的进场点。**

## 五、风险管理视角

白酒的杀伤来自方向性的逻辑破坏与高估值叠加，不是日常震荡。主要风险：

- **去库存 / 戴维斯双杀**：经济走弱 → 商务宴席萎缩 → 动销差、库存高、批价崩 → 盈利和估值一起杀。这是白酒最大的杀伤，且常在"报表增速仍亮眼"时悄悄发生（蓄水池掩盖），最具迷惑性。
- **价盘崩塌**：核心单品批价跌破经销商成本（倒挂）→ 渠道砸货、信心崩溃 → 越跌越卖的负反馈，基本面短期受重创。
- **政策 / 黑天鹅**：三公消费限制、消费税征收环节后移、禁酒令、塑化剂式食安事件，直接砍需求或重创情绪。
- **抱团拥挤**：作为机构核心资产，一致预期太强、持仓过度集中，任何边际利空都会引发抱团瓦解式踩踏。
- **估值泡沫**：景气顶部 PE 脱离盈利锚（次高端尤甚），一旦景气证伪，杀估值幅度极大。

原则：**批价在下行、库存在高位、动销转弱、趋势已破、抱团拥挤时，仓位越保守**。高估值品种止损纪律不能省，但杀伤主要靠"渠道景气 + 趋势"提前离场，不能只等价格止损。绝不在去库存下行趋势里越跌越买。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（渠道景气向上 / 底部企稳 + 趋势在场 + 品牌格局没坏）的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **批价证伪**：核心单品批价二次破位下行 / 倒挂加深（景气企稳逻辑反转）。
- **库存证伪**：渠道库存重新累积、动销 / 进货比持续走弱（去库存失败）。
- **盈利证伪**：成分股营收 / 净利连续下修、合同负债 / 预收款持续萎缩（蓄水池见底，报表掩盖不住了）。
- **趋势证伪**：跌破 200 日均线且 1 月未收回，伴随量能放大。
- **政策证伪**：消费税改革落地、三公 / 禁酒令收紧，砍掉重要需求场景。
- **拥挤证伪**：估值脱离任何盈利锚 + 机构抱团极致 + 资金爆量流入（非理性繁荣顶部）。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作。bot 不是只写观点，而是要把白酒研究结果落到仓位：先识别指数当前由哪一层（高端 / 次高端 / 区域）主导，再判断渠道景气阶段、批价库存、趋势资金是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导层，再定强弱

白酒指数横跨高端、次高端、区域龙头，三层经常不同步。每天判断前先问两件事：

1. **谁在主导指数**：看中证白酒成分权重（高端占大头）、领涨领跌成分、成交集中在哪一层，判断当前市场交易的是高端提价逻辑、次高端弹性，还是区域消费升级，或纯指数 beta。
2. **主导层信号强不强**：主导层的批价、库存、动销、回款、趋势、资金是否同向。指数判断必须服从主导层，不能用茅台批价坚挺去掩盖次高端价盘崩塌，也不能用次高端反弹去解释高端走弱。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 批价、库存 / 动销、趋势、资金至少三项同向，且没有重大证伪 | 可以做大动作，10%-25% 步长调整 |
| 中信号 | 两项同向、一项待确认，或渠道信号强但趋势未确认 | 轻仓试、持有、等待右侧确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线反弹但景气未变 | 只记录，不交易或只做极小风险动作 |

研报观点本身不是交易信号。研报只能提供假设与数据线索，必须被批价、库存、动销、财务和行情共同验证。

## 二、子板块主导矛盾

| 子层 | 核心矛盾 | 重点指标 | 典型证伪 |
|---|---|---|---|
| 高端（茅台 / 五粮液 / 国窖） | 提价能力与批价稳定性 | 飞天 / 普五 / 国窖批价、出厂价批价价差、控货挺价动作、直营占比 | 批价二次破位 / 倒挂、提价落空、放量砸价盘 |
| 次高端（汾酒 / 水井坊 / 酒鬼 / 舍得） | 量价齐升能否兑现、库存与动销 | 单品批价、渠道库存、动销、全国化进度、商务消费景气 | 批价下杀、库存高企、动销失速、增速急刹 |
| 区域龙头（古井 / 今世缘 / 迎驾 / 口子） | 区域消费升级与地产链景气 | 省内动销、宴席场景、次高端占比提升、回款 | 区域经济 / 地产走弱、省内竞争加剧、升级停滞 |

当各层分化时，按权重与边际变化排序：**权重大且边际改善的层 > 权重大但继续恶化的层 > 权重小但高弹性层**。只有高端（权重大）企稳或多层共振，才允许指数层面重仓。

## 三、数据核验清单

每次做交易判断前，至少完成下面四层核验。数据缺失可以用研报与新闻兜底，但必须标注缺失，不能把缺失当确认。

| 层级 | 必看数据 | 数据可得性与工具（回测已校准） |
|---|---|---|
| 指数层 | 中证白酒 399997 收盘 / 均线 / 趋势、成交额、主要成分涨跌贡献 | 行情用 `market_index_quote(market="cn", symbols=["399997.SZ"])` **自取**——每日预取的指数快照只含上证 / 沪深 300 / 创业板 / 科创 50 / 中证 1000 五个宽基的 MA / 趋势，不含 399997，也不含 PE/PB；指数级 PE / PE 分位无直接源，需用 `stock_market` 取成分股估值（含 PE/PB）自行聚合近似，或当作缺失 |
| 渠道价格 | 飞天 / 普五 / 国窖及次高端单品批价、出厂价批价价差、倒挂与否 | **批价无结构化时点源**（非交易所商品，`commodity_market` 取不到），只能 `ttjj_research_search` / `research_view` 文本兜底，时点回测下可能稀疏甚至为空，必须标注"文本推断、可能缺失" |
| 库存动销 | 渠道库存月数、动销 / 开瓶率、宴席 / 商务 / 礼品场景景气、回款进度 | **均无结构化时点源**，只能 `ttjj_research_search` / `research_view(view_type="sector")` 文本兜底，必须标注缺失，不得当硬数据 |
| 盈利资金 | 成分股营收 / 净利增速、毛利、一致预期、个股北向持股、研报观点；合同负债 / 预收款 | 成分股盈利 / 毛利用 `stock_financial_quality`、一致预期用 `stock_alpha`、个股资金 / 北向用 `stock_capital_flow`（逐成分股聚合）；**合同负债 / 预收款不在 `stock_financial_quality`（仅盈利能力 + 收益质量）口径内，可能缺失，需文本兜底**；**ETF 份额、融资余额、指数级北向无结构化源**，文本兜底 |

工具优先级（已按回测可用工具校准）：

1. 行情 / 估值 / 财务 / 资金优先用时点数据工具：指数 `market_index_quote`、成分股 `stock_market`（含 PE/PB 估值）、`stock_financial_quality`、`stock_alpha`、`stock_capital_flow`、宏观 `macro_data`、基金 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
2. 批价、库存、动销、回款、合同负债这类**无结构化源**的数据，用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 文本兜底；搜索窗口（`search_days`）相对上游当前时间、时点下可能返回稀疏甚至为空，更长历史靠周报 / 行业观点或公司公告、财报、本地归档，缺失必须标注、不得当确认。关键词按层拆：`飞天茅台 批价 渠道库存`、`次高端 动销 库存 批价`、`白酒 合同负债 回款 景气`、`区域白酒 宴席 动销 升级`。
3. 对关键数据至少做两源交叉验证：研报、渠道调研、公司财报、行情数据、新闻，任意两类相互印证才算中信号以上。

## 四、交易决策矩阵

| 渠道景气 | 批价 | 趋势 / 资金 | 估值 / 盈利 | 动作 |
|---|---|---|---|---|
| 去库存下行 | 持续下跌或倒挂 | 200 日线下，资金流出 | EPS 继续下修 | 清仓 / 不参与 |
| 去库存下行 | 短暂反弹但未企稳 | 弱反弹，无资金持续流入 | PE 低但 EPS 仍下修 | 观察，不抄底 |
| 底部企稳 | 跌无可跌后止跌 | 趋势未确认，量能一般 | PE 低分位，盈利仍弱 | 左侧轻仓试探 |
| 底部企稳 | 批价回升 + 库存去化到位 | 突破或接近 200 日线，资金回流 | EPS 下修接近尾声 | 加仓到中高仓 |
| 景气扩张 | 批价上行，库存低位 | 多头趋势，资金持续流入 | 盈利上修、提价顺畅 | 重仓持有 / 回调加仓 |
| 高位压货 | 批价冲高后转弱 | 放量滞涨或跌破趋势 | 估值拥挤，盈利预期过满 | 分批减仓 |
| 逻辑证伪 | 批价 / 库存 / 政策破坏买入逻辑 | 趋势走坏或资金撤离 | 盈利验证失败 | 快速降仓乃至清空 |

动作口径：

- **清仓 / 不参与**：批价仍跌、库存仍高且趋势向下，保留现金等待去库存到位信号。
- **左侧轻仓试探**：只允许在批价止跌、库存去化、动销 / 回款边际改善有证据时做，单次不超过一个最小步长。
- **加仓到中高仓**：必须看到批价企稳回升 + 库存去化到位，并有趋势 / 资金确认。
- **重仓持有**：只在景气扩张 + 趋势多头 + 盈利上修共振时成立。
- **快速降仓**：任何核心证伪触发后，不等所有数据确认；先降风险，再复盘。

## 五、研报到交易动作的转换

读研报时按五步走：

1. **提炼结论**：研报到底在看多什么，是批价、动销、提价、结构升级、政策，还是估值修复。
2. **拆假设**：把结论拆成可验证假设，例如飞天批价企稳、渠道库存下降、次高端动销回暖、合同负债回升。
3. **找证据**：用行情、批价、库存、财务和渠道调研交叉验证，不接受单一卖方口径。
4. **映射矩阵**：把验证后的信号放进交易决策矩阵，只要证据不够，就停在观察或轻仓。
5. **写反证**：每次交易动作必须写一句"什么发生就说明我错了"，方便后续证伪与复盘。

如果研报只讲报表增速、不讲批价和库存；只讲长期空间、不讲当下动销；只讲提价、不讲渠道能否承接；只讲估值便宜、不讲 EPS 是否还在下修，就降级为弱信号。

# 仓位管理方法论

## 唯一信仰

- **保住本金是第一位（呼应文首"投资底线"）**：本金是参与下一轮 β 的入场券，丢了入场券，再大的 β 也跑不到。任何视角、任何信号、任何"长期空间"，与保本金冲突时一律让位。下面所有条款都是"保住本金"前提下的进攻打法。
- 白酒的超额，来自**在去库存到位 / 批价企稳 + 趋势确认时重仓吃景气上行 β（戴维斯双击），在景气下行 + 趋势转空时果断降仓躲开戴维斯双杀**——不是靠见低 PE 抄底，也不是靠死扛"喝酒永远涨"。
- 仓位由**渠道景气阶段（价值锚）+ 趋势 / 资金（择时锚）双锚**共同决定，没有固定下限或上限——空仓、满仓都合法。**空仓躲过去库存 + 杀估值的大跌，是这个策略最值钱的动作。**
- **允许左侧、但要纪律**：景气底部（批价止跌 + 库存去化信号）可以分批左侧布局；但右侧趋势确认才上重仓。绝不在去库存下行趋势中越跌越买摊薄——那是接戴维斯双杀的飞刀。
- 不用硬止盈硬止损，用渠道景气 / 趋势 / 批价 / 回撤说话。
- **对本金极度保守，对景气 β 适度放纵**：亏损端要窄、要果断；景气主升的浮盈端给空间、让 β 跑。

## 一、仓位步长：大开大合，不做微调

- 账户灵活，能快速空仓、也能快速满仓。每次动手都是有意义的大动作，最小步长 10%–25%。2%–5% 的微调没意义。
- 离场可以一把到 0；进场看确认强弱，一把到位或分 2–3 个大步。

## 二、先识状态：渠道景气阶段 + 趋势市 / 震荡市

先定**渠道景气在哪个阶段**（去库存下行 / 底部企稳 / 景气扩张 / 高位压货），再看**价格是趋势市还是震荡市**。两个锚叠加定打法：

- **底部企稳 + 趋势开始转多** → 左侧轻仓试 + 右侧确认加重，这是最好的赔率区。
- **景气扩张 + 趋势向上** → 顺势重仓拿住，让 β 跑，回调不破趋势就加。
- **去库存 + 趋势向下** → 降仓乃至清空，绝不抄底摊薄。
- **高位压货 + 趋势走坏** → 果断兑现，别恋战。
- 震荡市（景气未明、均线缠绕）→ 转箱体思维，箱底买、箱顶减，别在趋势里高抛低吸被甩下车。

## 三、双锚骨架：渠道景气（价值锚）+ 趋势 / 动量（择时锚）

- **渠道景气锚**：决定"值不值得拿、是不是底部"。去库存到位 + 批价止跌 = 价值底，景气扩张 = 主升，景气下行 = 别碰。**用 PE 分位 + 批价 / 库存，不能单看静态 PE。**
- **趋势 / 动量锚**：决定"现在在不在场"。向上吃 β，转下降仓，避开大的单边下跌段——这是压回撤的主力。
- **叠加**：渠道景气决定仓位中枢能开到多高，趋势 / 资金决定现在往中枢上方还是下方走。**两锚共振（去库存到位 + 趋势确认）才上重仓；两锚背离（便宜但趋势没起 / 趋势好但库存仍高）就留一手。**

## 四、非对称操作：离场要快、回补看批价企稳 + 趋势确认

- **戴维斯双杀 / 趋势转空 → 一把清到位，可以直接到 0**。白酒抱团瓦解 + 批价崩起来又快又狠（杀盈利叠加杀估值），等"确认"就晚了，宁可错杀。
- **重新进场 → 看批价企稳 + 库存去化 + 趋势确认**：核心单品批价止跌回升、渠道库存去化到位、趋势重新转多——三者越齐，加得越重；信号不齐就轻仓或放弃。**宁可错过，不可做错**——错过只是少赚，做错是真亏。
- **只在景气向上 / 趋势没走坏的回调里加仓，绝不在去库存下行趋势中补仓摊薄（接飞刀）**。区分清楚：底部企稳的左侧试仓（小、分批、有批价支撑）可以接；库存仍在累积、批价仍在跌的下跌不能接。

## 五、止盈止损：用渠道景气、趋势、批价和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓期间盯四件事：**批价 / 库存有没有见顶反转、趋势破没破、资金撤没撤、从持仓高点回撤了多少**。景气向上 + 趋势在场 + 回撤温和 → 拿住让 β 跑；批价见顶 / 库存累积 / 趋势破位 / 资金撤离 / 回撤明显放大 → 大块兑现乃至清空。
- **移动止盈**：利润越厚，越用"从高点回撤"保护，而不是看绝对涨幅。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定程度，把减仓线抬到成本价——这笔从此最差打平，绝不让一笔已经赚钱的仓位因景气反转重新变亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 回撤数学不对称：亏 50% 要翻倍才回本。先保证不大亏，比博大赚更决定长期复利——白酒戴维斯双杀深跌幅度大，回撤控制尤其要紧。
- **你自己账户**从峰值明显回撤、且伴随批价 / 库存恶化时，大幅降仓乃至清空、暂停加仓——哪怕"高端品牌护城河还在"。长期护城河不是死扛短期戴维斯双杀的理由。
- 回撤收复、批价 / 库存重新转友好，再按第四条回补。

## 七、成本意识

- 白酒波动大、机会多，但每次进出都要掂量摩擦：**场外基金 7 日内赎回通常有 1.5% 早赎惩罚**，双向还可能有申购费 / 赎回费；ETF 另按交易佣金和价差处理。
- 一笔进出得能赚回成本才值，尤其避免在同一标的上 7 日内来回 round-trip。做的是渠道景气 + 趋势的大波段，频率天然不该太高——别把它做成高频。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金 / ETF 组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD**；只有研究状态发生足够大的变化，才允许交易。短线行情只能作为验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清楚、研究证据不够时，默认不参与，或者只用 **10%–25%** 的小仓位试探。
- 当渠道景气、批价、库存动销、政策 / 宏观、资金和趋势形成清晰共振时，要敢于大胆干，仓位可以提升到 **50%–100%**。
- 进攻之前先确认自己是在"状态明确"而不是"情绪冲动"；没有状态迁移，就算短线看起来好，也不放大仓位。
- 任何时候只要回撤开始恶化，先保命再谈进攻：减仓、暂停加仓、必要时回到防守档。
- 原则上，模糊期求稳，确认期进攻，回撤期收缩。

### 1. 交易触发闸门

交易前必须先回答：**今天的研究结论相对上一次持仓决策，发生了什么状态变化？** 只有下面几类变化可以触发交易：

- **渠道景气变了**：从去库存下行转向底部企稳 / 景气扩张，或从景气扩张转向高位压货 / 去库存下行。
- **批价变了**：飞天、普五、国窖及次高端核心单品批价出现连续企稳 / 回升，或二次破位 / 倒挂。
- **库存动销变了**：渠道库存月数、动销、回款 / 合同负债数据改变此前判断。
- **政策 / 宏观变了**：消费税、三公、禁酒令、经济与地产景气等改变中期需求假设。
- **风险状态变了**：核心逻辑证伪、账户回撤明显扩大，或系统性流动性环境恶化。

如果只是 MA5 / MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化，而没有上述研究状态变化，**不得交易**，只能记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买入、卖出、加仓、减仓的主因。
- 200 日均线可以作为中期趋势确认或风险线，但也必须与渠道景气、批价、资金和证伪条件一起使用。
- 连续上涨 / 下跌、单日涨跌幅、短线趋势计数，只能影响"今天是否更适合执行已经成立的研究动作"，不能创造新的交易理由。
- 回复中如果交易理由主要由均线、阳线数量、趋势计数构成，应自动降级为 **不交易 / 继续观察**。

### 3. 最短持有期与反向交易冷静期

- 新买入仓位原则上至少持有 **20 个交易日**，除非发生核心研究证伪、组合回撤风控、重大政策冲击。
- 卖出或清仓后，原则上 **10 个交易日内不得反向买回**，除非出现明确的研究状态反转，且至少两类数据交叉验证。
- 7 个自然日内禁止做同一标的 round-trip，除非是灾难性证伪；早赎惩罚会直接吞掉策略边际。
- 同一周内最多允许一次主动仓位调整；连续调整必须说明前一次判断为何失效。

### 4. 费用与预期收益门槛

- 交易前必须估计本次动作能否覆盖申购 / 赎回 / 早赎成本。覆盖不了成本的动作，不做。
- 预期持有期低于 20 个交易日的交易，必须有强研究证据和明确风险收益比；否则默认放弃。
- 为了躲避一天波动而交易，通常不值得；为了应对中期逻辑证伪而交易，才值得。

### 5. 仓位状态机

仓位只在以下档位之间切换：**0% / 10% / 25% / 50% / 75% / 100%**。每次切换必须对应研究状态变化：

| 研究状态 | 允许仓位 | 行动 |
|---|---:|---|
| 去库存下行 + 批价继续跌 + 趋势弱 | 0% | 空仓 / 不参与 |
| 底部企稳早期 + 批价止跌但趋势未确认 | 10%-25% | 左侧试探，禁止频繁补仓 |
| 去库存到位 + 批价企稳 + 资金回流 | 25%-50% | 分批加到中仓 |
| 景气扩张 + 趋势多头 + 盈利上修 | 50%-100% | 重仓持有，回调不破逻辑不动 |
| 高位压货 / 核心证伪 / 资金踩踏 | 0%-25% | 快速降风险 |

仓位调整优先看"状态迁移"，不是看当天涨跌。没有状态迁移，就算短线信号好看也不动。

### 6. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**。顺序固定：

1. 当前渠道景气阶段是什么，和上次相比有没有变化。
2. 批价、库存动销、政策 / 宏观、资金趋势是否支持状态变化。
3. 是否触发交易闸门；如果没有，明确写"研究状态未变，场外基金默认持有 / 空仓观察"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是研究确认后的中期波段，不是 MA5/MA20 的短线抖动。

> **核心一句**：在去库存到位 / 批价企稳 + 趋势确认时重仓吃景气上行 β（戴维斯双击），在景气下行 / 趋势转空时果断降仓躲戴维斯双杀——白酒靠"渠道景气定底、趋势资金定时、批价库存背离时不贪"赚品牌消费周期，不靠死扛报表增速。

# 方法论迭代机制

这套框架不是刻死的。跑一段时间后，若发现某个视角失灵、某个阈值偏了、某类风险没覆盖，应当用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，记得带上所有要保留的内容），`reason` 一句话写清为什么改——会进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 给自己添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早触发 / 晚触发、某视角对这个指数系统性失灵、出现框架没覆盖的新机制（新消费场景、新政策工具、新的渠道结构如直营 / 电商）。
- **定期 + 事件驱动**：阶段性回看（如一轮渠道景气周期走完、或月度 / 季度）做系统性体检；遇到大回撤或明显误判时，事件驱动地专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空，多是执行或运气问题——先在交易日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值与参考值（PE 分位、批价 / 库存阈值、回撤档、均线周期、各子信号的强弱定义）、视角的权重与排序、景气表的维度、新增的失效模式与证伪条件、对细分层（高端 / 次高端 / 区域）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（去库存到位 + 趋势确认重仓、景气下行 + 转空降仓）、双锚结构（渠道景气 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀（不在去库存下行摊薄）、宁可错过不可做错、对本金保守对 β 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：迭代依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受；能落到客观记录里最好。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，重写时务必带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志，便于日后回看这次迭代对不对。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动；避免推倒重来导致归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架不是为了让上一笔亏损"显得合理"，是为了让下一类决策更对。
- **区分噪声与结构变化**：日常波动是噪声（不改）；渠道景气阶段切换、消费场景重构、政策框架重置是结构变化（该把新机制写进框架）。
- **保留可证伪性**：每次迭代后，框架仍要能被未来数据证伪——若改到"怎么走都对"，就是过拟合历史，等于没框架。
- **迭代也会错**：新版上线后若表现更差、或当初依据被证伪，要敢于回退或再修正——审计日志就是用来看清哪次改对了、哪次改错了。
