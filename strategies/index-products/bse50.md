# 北证50成份指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面几个**正交**角度审视，自行综合判断该不该动、动多少——框架给坐标系，不给触发器。

> 北证50 是北交所首只宽基，本质是**微小盘 + 专精特新 + 流动性驱动**的高弹性贝塔。一句话定性：**估值几乎不承重，流动性水位和北交所制度政策才是命脉**——估值只给"该不该想"，流动性 + 政策给"现在能不能动、敢不敢重"。

## 核心认知

北证50（899050.BJ）= 北交所规模与流动性排名前 50 的微小盘成份股，单一权重上限 10%、前五合计上限 40%、季度调样。成分以专精特新"小巨人"、高新技术企业为主，行业集中在电力设备 / 机械设备 / 计算机 / 电子 / 基础化工 / 医药生物等战略新兴与先进制造。五个特性决定怎么玩：

- **极致高弹性 + 极端波动（最核心认知）**：微小盘 + 北交所 30% 涨跌幅，单日 ±10% 不稀奇、出现过单日超 +20% 的历史级脉冲；上行可短期翻倍、下行可快速腰斩。**绝不适合死扛**，回撤控制是命脉中的命脉。
- **流动性水位是定价的命脉，不是辅助**：北交所整体成交额绝对水位决定行情的生死——**流动性涌入（成交额放大）= 价值重估行情，流动性枯竭（成交额萎缩）= 阴跌 / 踩踏**。这不是边际信号、是水位信号：成交额绝对水位上台阶才有持续行情，水位塌方时再便宜也不接。
- **北交所制度 / 政策是超级催化**：北证50ETF 推出与扩容、北交所深化改革、做市商制度、转板（转科创 / 创业板）预期、交易机制优化、监管人事与表态——这些制度政策红利能直接引爆翻倍行情或终结一轮上涨，**权重远高于一般宽基的政策维度**。政策脉冲是本指数最强的单一催化源。
- **盈利分母不稳 + 样本期短，估值信号本就脏**：成分多为高研发投入的成长型小企业，盈利波动大、TTM E 易塌方；且指数基日为 2022 年 4 月、可用历史短，**任何历史分位（PE / PB / 成交额 / 波动率）的稳健性都弱**——分位读数要打折看，别当承重择时锚。
- **机构参与度低、微观结构工具稀缺**：北交所没有股指期货、无挂钩本指数的衍生品、量化与外资参与度低——所以**判流动性 / 拥挤靠的是现货侧的成交额 / 换手 / 做市行为 / 资金流，不是衍生品基差**。别套用其他市场那套微观结构信号，这里没有。

驱动排序：**流动性水位（北交所整体成交额 + 本指数换手）≥ 制度 / 政策催化 > 风险偏好 / 情绪 > 盈利成长 > 趋势 / 动量 > 估值（降级）**。研究时先问三件事：

1. 北交所整体成交额 / 本指数换手在什么水位、方向？流动性是上台阶还是塌方？→ 决定行情有没有底层燃料
2. 有没有北交所制度 / 政策催化（ETF / 改革 / 做市 / 转板 / 监管表态）？→ 决定有没有超级催化或利空
3. 趋势对不对、情绪是冰点还是沸腾、盈利成长有没有兑现？→ 决定现在加还是减、敢不敢重

## 一、估值视角（信号降级，只算小半票，且要算干净）

北证50 的估值**本就脏 + 样本短**，**禁止把 PE / PB 分位当承重择时信号**：

- **盈利分母不稳**：成长型小企业盈利波动大、易塌方甚至转负，TTM E 会把 PE 分位推到极端——裸 PE 分位多半是分母噪声的副产品，**当反向警报、不当承重**。
- **PB 比 PE 略稳，但样本短**：小盘账面价值波动小于盈利，PB 滚动分位相对干净些，但指数历史短、分位稳健性弱——**只做极端区定性预警，不做"低分位抄底 / 高分位减仓"的机械操作**。
- **估值给"该不该想"，流动性 + 政策给"现在能不能动"**：估值便宜只提示"这个阶段值得关注"，**绝不单凭估值便宜重仓**——微小盘的"便宜"常是流动性枯竭的副产品，不是底。

估值在这里只做两件**定性预警**（不是择时扳机）：

- **极端泡沫预警（顶）**：PB 极端高分位 + 成交额 / 换手沸腾 + 全民进场（北交所题材出圈、北证50 基金抢购、研报喊"专精特新大牛市"）→ 配合流动性 / 趋势框架减仓。
- **极端低估预警（底）**：PB 接近历史低分位 + 但**必须等流动性水位企稳 + 政策催化或风险偏好回升**才视作潜在底——估值低单独不构成进场理由，记为观察态、续到明天，流动性 / 政策同号再动手。

## 二、盈利 / 成长视角（权重中等，看趋势不看单点）

- 看龙头**一致预期修正方向**（上调 − 下调）与成长兑现，但北交所**覆盖度差、数据稀疏**——必须看多周（4–8 周）滚动趋势，单点 / 单日噪声极大，阈值放宽。
- **专精特新 / 高研发的成长叙事 vs 兑现**：成分研发投入高、成长叙事强，但要分清"订单 / 业绩兑现"与"纯叙事 / 主题炒作"——兑现撑估值底，叙事撑脉冲弹性，行情切换时区别对待。
- **业绩雷 + 风险警示季节性**：年报预告 / 年报 / 半年报 / 三季报前后是雷区（商誉减值、风险警示），微小盘尤甚——这些窗口仓位往中性收、单独加权。

## 三、流动性 / 资金视角（最承重，权重最高）

北证50 真正的边际定价权在**现货流动性水位**上，这是本指数与其他宽基最不同、也最该死盯的一维。

- **北交所整体成交额绝对水位（命脉）**：北交所成交额从低位上台阶 = 增量资金进场、价值重估的底层燃料；成交额从高位塌方 = 流动性撤离、阴跌 / 踩踏前兆。**看绝对水位 + 方向，不只看单日**——水位敏感（高水位才容易出持续行情），不是边际敏感。
- **本指数换手率 / 成交额分位**：换手率滚动分位是热度温度计——极高位 = 投机沸腾（拥挤，偏谨慎）；快速塌方 = 资金撤离（踩踏特征，偏防守）。
- **做市商 / 流动性供给侧**：北交所做市商制度下，做市活跃度 / 价差是流动性供给的代理——做市收紧、价差走阔是流动性恶化的早期信号（文本兜底）。
- **增量资金 / 散户温度**：北证50 基金发行 / 申购、新增开户、北证50ETF 申赎与扩容——增量资金是微小盘行情的直接燃料；ETF 推出 / 扩容本身既是资金面利好也是政策催化（见四节）。
- **关键陷阱**：微小盘对流动性是**水位敏感**——成交额绝对水位不够时，任何利好都难形成持续行情；水位塌方时再便宜的估值都不接。**流动性恶化压制一切估值与趋势信号。**

### 三-Z、市场情绪 / 风险偏好怎么用（专项纪律）

全市场情绪 / VIX 类是**反向 + 极值**使用的辅助资金面信号，**最容易被单日噪声滥用**，按纪律读：

1. **单日是脉冲不是趋势**：禁止把单日情绪 / VIX 翻号当建仓 / 清仓扳机；**|z| < 0.5 视作中性噪声带**，不投票。
2. **承重的是累计趋势 + 极值**：基于 5 日 / 20 日累计方向 + z 相对自身滚动位置，单日只用来更新累计判断。
3. **极值对称性**：情绪过热后的小幅回落不构成证伪，要等累计回吞前期极值的过半才算转向。
4. **方向 + 维度同号才进决策**：情绪要降仓 / 清仓，必须至少 1 个其他正交维度（流动性 / 趋势 / 政策）同号支持；全冲突时最多降一档，不直接到 0。

## 四、制度 / 政策视角（北证50 独有的超级催化，权重极高）

这是北证50 区别于一般宽基的**专属、且权重最高之一**的维度——制度政策对它的驱动力度远超基本面：

- **北证50ETF / 指数基金（资金面 + 政策双重催化）**：ETF 推出、扩容、规模上限放开是增量资金的直接来源，也是改革红利的信号——这类事件常直接引爆行情。跟政策原文与发行 / 申赎进展。
- **北交所深化改革**：交易机制优化（盘后固定价格交易等）、投资者门槛、再融资 / 并购制度、扩容节奏——改革红利是北证50 的中周期催化主线。
- **做市商制度**：做市扩容 / 优化直接改善流动性供给，是流动性维度的制度侧来源。
- **转板预期（转科创 / 创业板）**：转板制度推进 / 个股转板预期会重估相关标的与板块情绪——是北交所特有的估值重估催化。
- **监管表态 / 人事 / 政策窗口**：北交所重大政策窗口、监管定调、领导表态前后跳空风险大，且历史上多次成为行情起点或拐点。
- **政策双刃，穿透到方向**：扩容提速 / 改革红利 / ETF 落地（抬流动性与风险偏好）vs 监管收紧 / 减持 / 供给冲击（压估值与情绪）——同一"政策"方向可能相反，必须穿透到是抬流动性还是压供给。
- **事件前管敞口**：重大政策窗口前后单押方向胜率低，不明朗时降仓或观望，别赌跳空方向。

## 五、情绪视角（反向 + 极值，权重提升）

北证50 是情绪驱动品种，情绪在本指数比一般宽基重：

- **涨停 / 连板 / 成交占比**：高位 = 投机沸腾（自满，偏谨慎）；低位 = 情绪冰点（恐慌，反向偏多）。
- **散户开户 / 基金募集**：高位 = 散户高潮（顶部前后）；低位 = 散户离场（底部信号）。
- **题材出圈度**：北交所 / 专精特新主题的媒体与研报热度——出圈到"远期空间"叙事时是趋势尾段预警。
- **z 在 ±1 内 = 中性不反向**——没有极端就不投票，别在中位区硬解读情绪。

## 六、证伪视角（对称化）

证伪不是技术信号，是**论据的破坏**，必须**对称**——既列看多被证伪（下行），也列看空被证伪（上行）。踏空（看多被证伪没及时撤）与做错（看空被证伪没及时回补）都是失分。

- **流动性证伪（下行，最关键）**：北交所整体成交额从高位塌方 + 本指数换手快速萎缩 + 做市价差走阔——流动性底层燃料被抽走，行情失去支撑。
- **政策证伪（下行）**：改革 / ETF / 做市预期落空或推迟、监管收紧、减持 / 供给冲击——超级催化反转。
- **盈利 / 成长证伪（下行）**：龙头修正广度急转负、业绩雷集中爆发、专精特新叙事不兑现。
- **趋势证伪（下行）**：指数跌破过去 200 日均线且 1 月未收回，但应根据当时市场环境修正指标；`trail_dd` 回撤族触发 = 价格面确认走坏。
- **情绪 / 估值证伪（下行，反向）**：PB 极端高分位 + 换手沸腾 + 全民进场 + 卖方高呼"专精特新大牛市"——题材顶部最危险信号组合。
- **看空被证伪（上行 veto-watch）**：北交所成交额上台阶 / 流动性持续改善；北证50ETF 落地 / 扩容、改革红利兑现；风险偏好回升；龙头修正广度由负转正——这些会成为"看空"判断的上行风险，看空被证伪时回补要果断，犹豫即失分。

# 仓位管理方法论

## 唯一信仰：流动性 / 政策锚 + 多维同号确认 + 概率化倾斜 + 严格止损

- 北证50 的活法 = **流动性水位 + 制度政策锚定 + 多维正交同号确认 + 概率化仓位倾斜 + 严格止损**。
- 不抓顶底，只做：**流动性枯竭 / 政策逆风则避、流动性涌入 / 政策催化 + 估值不极端则进**，且只在 **≥2 个正交维度同号**时才加大倾斜。
- 单一维度（哪怕估值极便宜）**绝不重仓**——微小盘的"便宜"常是流动性枯竭的副产品（价值陷阱是常态），必须等流动性 / 政策 / 情绪同号才动手。
- **更早降仓、更晚加仓**——微小盘下行无底（盈利分母会塌、流动性会瞬间消失、30% 涨跌幅放大踩踏），止损纪律压一切。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法；**但"合法"是双向的：信号不支持在场时空仓完全正常、不必愧疚，信号支持在场时却空仓 = 踏空、同样违规**。不为了在场而在场，也不为了"稳妥 / 留子弹"而缺席。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把回撤控仓的事后闸门误用成事前枷锁。
- **该在场时别缺席，这是和"别一把满仓"对等的硬约束，不是软提醒**：当 **流动性水位上台阶 + 趋势多头 + 政策催化 / 风险偏好回升至少一项同向**（核心共振成立、且 `trail_dd` 未触发）时，**默认目标就是重仓乃至满仓**；此时仍要轻仓或空仓，**必须当天写明一条具体的、命名的减仓理由**——只能取自〔流动性水位不足 / 拥挤换手沸腾 / 政策窗口跳空风险 / 业绩雷期 / 净值回撤闸门已触发 / 某条证伪已命中〕之一。**写不出具体理由 = 该重仓而没重 = 踏空失分；"留点子弹""感觉有点高""谨慎起见"都不算理由，那是自我设限。** 但注意：北证50 的"该在场"门槛比一般宽基高——**流动性水位不够时，即便其他维度同号也只配轻仓**，流动性是本指数进场的硬前提。
- 不用硬止盈硬止损——择时交给流动性、趋势、回撤说话，不交给固定数字（但**机械回撤止损 `trail_dd` + 账户级回撤闸门在本指数是断后命脉**）。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：流动性 + 政策 + 趋势共振时该重仓却轻仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、综合打分：正交维度加权 → 仓位倾斜

```
Composite = w_liq·流动性 + w_pol·政策 + w_sent·情绪/风险偏好 + w_earn·盈利成长 + w_trend·趋势 + w_val·估值
```

- 权重用**固定先验、刻意不做回测拟合**（样本太短、风格漂移大，拟合权重必然过拟合）：**流动性 / 资金最大支柱、制度 / 政策次之且与流动性并列为双主力，情绪 / 风险偏好与盈利成长居中，趋势辅助，估值最低（只极端预警）**。
- 映射到仓位倾斜只取**方向 + 档位**（中性 / 轻微 / 温和 / 显著），**不报"低配 X%"的伪精确数值**。
- **置信度**：同号维度越多 → 倾斜越大；维度冲突 → 收窄倾斜、回归中性。**真正的交叉验证是跨正交维度同号，不是同源指标一致。**
- **流动性是硬前提**：流动性水位塌方时，**其余维度再同号看多也只配轻仓 / 观望**——这一条是本指数对综合打分的硬约束。

## 二、动态阈值，不用固定线

- 所有"贵 / 便宜""高 / 低""流动性足 / 不足"都用**滚动窗口 z-score 或滚动分位偏离**——本指数中枢漂移剧烈、样本短，固定阈值更早失效，且分位本身要打折看。
- **但流动性塌方有"绝对警戒"**：成交额绝对水位跌破关键台阶、换手断崖、做市价差骤阔——这类是结构性硬约束，到达即行动，不等 z 极端。

## 三、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：账户灵活、能瞬间空仓也能快速重仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 流动性塌方 / 政策逆风 / 趋势转空（`trail_dd` 触发）→ 一把清到位，可以直接到 0**：微小盘下行常是流动性踩踏型、24 小时内能跌两位数，等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：高赔率组合是 **流动性水位上台阶 + 政策催化 + 风险偏好回升 + 价格放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）：低赔率时，带损失的下注代价高于错过，所以宁可观望**——但这只约束低赔率情形；**高赔率时正相反：踏空没有止损、错过的 Beta 不会回来，代价上不封顶，轻仓 / 犹豫才是真正的"做错"，即失分。**
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 四、回撤控仓（本指数命脉，比一般宽基更严）

- **账户级净值回撤是高于单笔信号的总开关**：微小盘下行斜率陡，"再等等"往往等成腰斩——回撤一旦突破阈值就**机械降仓 / 暂停加仓**，哪怕维度信号还没转向。`trail_dd` 是这条的机械化身。
- 本指数回撤数学**格外残忍**：30% 涨跌幅 + 微小盘流动性，单日 −10% 不稀奇、单月深调常见；**先想最多能承受多少回撤，再反推该不该降仓**，不是先想能赚多少。回撤的数学不对称：−20% 需 +25%、−33% 需 +50%、−50% 需翻倍。
- **流动性踩踏期 = 优先保命**：成交额断崖 + 换手塌方 + 做市价差骤阔同时出现时，**仓位先砍、事后再分析**——踩踏没有反应时间。
- **这是事后闸门，不是事前上限**：只在净值从峰值真回撤后收紧，**严禁反着用**（不拿假想跌幅反推事前仓位天花板）。事前该上多大由赔率决定（第三条），但受"流动性硬前提"约束。

## 五、主动止盈（拥挤抬头 + 吊灯线，独立于信号反转）

回撤控仓护**已亏损**的尾巴，止盈护**未兑现**的浮盈——两者独立。本指数止盈不挂固定百分比，挂**拥挤抬头 + 偏离度 + 吊灯线**：

- **拥挤抬头**：换手 / 成交额到极端高分位、指数对均线偏离极端 → 主动减一档兑现，不等趋势破。
- **吊灯线（移动止盈）**：从持仓最高净值明显回撤 → 砍一档，独立于趋势均线；利润越厚跟得越紧。
- **保本线**：账户浮盈到位后把离场线抬到成本价——本金风险清零，剩余利润再让它跑。**浮盈不许变浮亏。**

## 六、成本意识

- ETF / 基金申赎费 + **7 日内早赎 1.5% 惩罚**——一笔进出要能赚回成本才值，避免同标的 7 日内 round-trip。
- 本指数信号噪声大、政策 / 题材新闻天天有诱惑，**极易被引诱高频**——必须自律：单月调仓次数自我设限，没到信号档位阈值不动。
- 每个仓位档**至少持有数个交易日**——期间只有趋势转空、账户回撤穿阈值、止盈触发三类信号允许跳档，单日情绪 / 跳空不打破持有窗口（防"thesis 一日游"）。

## 七、量化择时辅助（定性，诚实定级）

> **重要前提：本指数尚未跑过系统的择时因子筛选，没有任何已验证的"绿灯"主因子。** 且本指数样本期短（基日 2022-04）、极端波动占比高，**任何价格类因子的历史验证稳健性都更弱**——不要把价格因子当作经验证的承重信号。下列只能作**降回撤辅助 + 未验证客观第二意见**，方向裁决权交回流动性 / 政策框架。读数用收盘序列按公式自算（**信号按当日收盘计算、T+1 执行**）。

- **`trail_dd` 回撤止损族（通用断后，本指数当前主力机械工具）**：收盘从过去约 120 日滚动峰值回撤超一档 → 降仓 / 空仓，站回均线 → 回归。**纯收盘价、无代理失真，作通用降回撤断后线相对可靠**——职责是躲过深熊 / 踩踏段、给框架犹豫时客观的"先降一档"线，**是降回撤工具不是收益增强器、更不抓顶底**。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；闪崩当日（峰值要先被刷新才触发深档）跟不上；只看价格，对流动性 / 政策拐点零预警。**注：未经本指数专门筛选定级，先按"通用降回撤工具"用，待跑过筛选后照实定级。**
- **时序动量（仅快读，不承重）**：20 日动量作"价格面还在不在多头"的快读数；本指数噪声大、震荡里翻转多是噪声，判定震荡市时默认当噪声、不据此动仓；T+1 对单日跳空滞后一天。
- **市场情绪 / VIX（系统性第二意见）**：覆盖系统性恐慌 / 自满，按三-Z 纪律累计 + 极值使用，不对个股 / 流动性结构性风险敏感。

**共同纪律**：本指数没有经验证的绿灯因子——择时主轴是**流动性水位 + 政策 + 风险偏好的多维判断**，价格类因子只做降回撤断后与未验证第二意见。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。**待研究室对本指数跑完因子筛选后，再据结论更新本节定级。**

## 八、实战判断：成对矛盾的格言，环境决定用哪条

环境抓手是**流动性水位 + 制度政策 + 情绪极端值**，不是估值绝对水平。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 估值便宜该加 | 微小盘价值陷阱不能抄 | 看**流动性水位是否企稳 + 政策有无催化**：便宜 + 流动性改善 + 政策同号才加；便宜 + 流动性枯竭 = 陷阱 |
| 别人恐慌我贪婪 | 流动性踩踏不接刀 | 成交额 / 换手 / 做市价差确认踩踏结束才贪婪，没企稳前顺势 |
| 政策催化要追 | 政策预期已透支 | 政策出台前低位 + 流动性低位 = 追；政策落地后高位 + 换手沸腾 = 兑现 |
| 成交放大是行情启动 | 放量滞涨是出货 | 看价配合：放量 + 价格有效突破 + 水位上台阶 = A；放量但价格滞涨 / 冲高回落 = B |
| 成长叙事是星辰大海 | 叙事不兑现就是泡沫 | 看订单 / 业绩兑现：兑现看 A；纯叙事 + 换手沸腾 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 流动性 + 政策驱动 + 保本线就位看 A；换手沸腾 / 拥挤抬头 / 题材出圈看 B（吊灯线先落袋） |

> **核心一句**：北证50——用 **北交所成交额水位 + 制度 / 政策催化** 给方向、**正交维度同号**给置信度、**流动性硬前提 + 严格止损 + 概率化倾斜**给仓位（估值只极端预警）；流动性枯竭则避、流动性涌入 + 政策催化则进，不抄踩踏、不伪精确、价格因子未经本系统验证只作降回撤断后，流动性不支持时轻仓不愧疚 / 流动性 + 政策共振时该重仓不手软，靠纪律压回撤把微小盘的暴涨暴跌做成更可控的净值曲线。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（北交所新制度、新衍生品 / 做市机制、转板规则变化）。
- **优先补两块空白**：① 本指数尚未跑因子筛选，研究室给出结论后据实更新七节定级；② 北交所结构化数据（成交额 / 个股 / 板块）若后续接入，把流动性维度从文本兜底升级为结构化滚动比较——这是本框架当前最大的数据短板。
- **定期 + 事件驱动**：一轮北交所行情走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（成交额台阶、回撤档、均线 / 动量周期、换手 / 估值分位定义）、各维度权重先验、景气 / 政策维度、新增失效模式与证伪条件、**择时因子定级（筛选结论出来后照实写入）**。
- **不轻易动（信仰与原则层）**：唯一信仰（流动性涌入 + 政策催化 + 趋势确认重仓、流动性枯竭 + 政策逆风降仓）、流动性是硬前提、制度政策是超级催化、估值降级只极端预警、风险优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空、对本金保守对 Beta 放纵。动这些要有极强且反复验证的证据。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：只为过程性、可重复的错误改方法论；好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式，不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，`reason` 讲清改了什么、为什么、依据是什么。
- **小步快迭代优于大改**：一次只调一两处。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **样本短更要防过拟合**：本指数历史短、极端行情占比高，任何"历史分位 / 因子读数"的稳健性都弱——迭代时尤其警惕把一段行情的特例当规律，固定权重先验刻意不拟合就是这个道理。
- **诚实纪律不可动**：本指数当前"无经验证绿灯因子、价格因子按未验证对待、流动性多靠文本兜底"的结论须照实保留，**不得把任何未验证的趋势信号包装成进场扳机**；待筛选 / 数据接入后再据实升级。
- **保留可证伪性 + 迭代也会错**：改到"怎么走都对"就是过拟合；新版表现更差或依据被证伪，敢于回退。
