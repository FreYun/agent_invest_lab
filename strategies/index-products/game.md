# 动漫游戏指数投资框架（方法论）

这是研究视角，不是执行手册。**先判市场环境（〇节，永远的第一步）**，再逐视角综合判断。

> 动漫游戏是 A 股**政策敏感度最高、情绪驱动最重**的题材板块之一。玩法核心：**监管周期定生死、产品周期与文本流水给方向、回撤纪律断后**。长期 buyhold 是灾难（OOS Calmar **-0.02**、最大回撤约 -58%）——**"不持有就是胜利"的时段很长，空仓是完全正常的常态**，择时纪律的价值在全部指数里最大。

## 核心认知

中证动漫游戏（930901.CSI，2013 年起约 13.4 年样本）≈ 游戏研发/发行龙头（三七互娱、吉比特、完美世界、恺英网络、巨人网络等）+ 动漫 IP 衍生。五个特性：

- **政策（版号）是第一变量，且是黑天鹅型**：版号节奏直接决定供给端。历史上版号停发、未成年人新规、行业定性言论都造成过指数级暴跌或长期压制。**政策事件无法从价格与财务数据预判，只能文本面盯监管+事件前敞口管理**——这是与硬件指数最大的不同：硬件母变量有产业链可跟，这里是一纸公文。
- **爆款产品周期**：单款流水可以再造也能证伪一家公司；新游档期/首日流水/畅销榜直接驱动情绪——全部 `[仅文本]`。
- **AI 双刃**：降本是利润率逻辑、AI 原生玩法是叙事逻辑、"AI 冲击长尾游戏"是反叙事——先分清市场在用哪种定价。
- **出海是结构成长线**：海外流水占比、买量成本、汇率。
- **轻资产高毛利、盈利随流水大幅波动；散户重、情绪重、题材属性强**（元宇宙/AI+游戏叙事轮流附体）——追脉冲与死扛都是输法。

## 〇、先判市场环境（永远的第一步）

四问，**显式留痕**（写进复盘，明天继承）：

**1）全市场：A 股欢迎高 β 题材成长吗？** `macro_50etf_vix` + 大盘趋势判**扩张/收缩/中性**；收缩期所有看多信号降一档。

**2）板块状态三分**：趋势市（均线单边斜率明显→趋势骨架）/ 震荡市（长均线走平假突破频出→防守骨架）/ 过渡待定（轻仓观望）。状态有粘性，单日跳空不算切换。

**3）主驱动识别：监管周期 / 产品周期 / 题材叙事，谁在定价？** 监管线定价时其他信号降权；题材叙事不入打分、按脉冲管理。**看错主驱动，所有信号都会读错。**

**4）独有的第四问：监管收紧期还是宽松期？** 判据全文本面：版号是否按月常态化（放缓/中断=收紧前兆）、官方措辞（"支持/精品化"=暖，"整治/防沉迷"=冷）、新规在草案还是已落地。**收紧期：看多信号降档、敞口设上限、不碰题材脉冲；宽松期才允许把产品周期与叙事当主逻辑做多。**没答完不允许进入加减仓决策。

## 一、估值视角（定性预警，绝非择时扳机）

- 盈利随流水大起大落+题材定价→PE 会骗人，压制期"便宜"可以便宜很多年。**禁止用 PE 分位低吸高抛；分位只做极端预警，流水/利润上修斜率比分位承重**——`stock_alpha` 龙头一致预期转下修=顶部领先信号（常早于破位）。
- **泡沫预警（顶）**：极端分位+全民题材化→趋势尾段提示，止盈收紧。
- **冰点（底）**：极低分位+监管压制→不抄底，但**触发去文本找监管转向证据**；证据出现且趋势企稳，按骨架回补。

## 二、趋势视角

- **方向锚**：收盘 vs MA120/MA200 + 斜率；20–60 日动量辅助。指数无量 → 板块拥挤度代理；拥挤极端+价格加速=主升尾段。
- **跳空甄别**：政策级（版号/新规/定性言论 → 逻辑级，必须跟）vs 题材级（→情绪级，易回补）。次日找事实增量，无增量当脉冲。

## 三、景气视角（产品周期主轴，几乎全 `[仅文本]`）

传导链：**版号（供给闸门）→ 新游档期 → 首日流水/畅销榜 → 季报营收/递延收入**。

- **领先**：版号节奏——每批数量、间隔、是否含进口、**龙头有没有拿到**；可自建滚动记数（看节奏不看绝对数），同时是监管温度计（喂〇-4）；次看新游储备与档期密度。
- **同步**：首日流水、畅销榜排名、买量投放强度。**榜单高波动，看周级持续性不看单日；首月流水定预期，留存定兑现。**
- **滞后（确认不择时）**：季报营收/递延收入/毛利率。递延收入比营收先动；财报只做确认。
- **结构线**：出海看收入费用两端（流水占比 vs 买量、汇率）；AI 降本去毛利率找验证，"AI 冲击长尾"反叙事先看龙头受损还是受益。

**纪律**：领先定方向、同步定强度、滞后只确认，背离信领先；但**任何景气结论都越不过〇-4——收紧期里产品周期再好也只配低敞口**。

## 四、监管/政策视角（独立成节，第一变量）

- **黑天鹅属性，先认命再管理**：版号停发、防沉迷新规、定性言论**事前在价格/财务/估值里没有痕迹**，量化因子防不了。能做的只有文本面每日盯（五节）+ 事件前敞口管理。
- **事件前敞口管理**：政策窗口期、新规征求意见截止前后、官媒批评措辞出现后、版号间隔拉长时→降敞口、不赌方向。**"错过反弹"是可接受的成本，"吃满政策跳空"不是。**
- **"利空出尽"判别三问（缺一不可）**：① **靴子真落地了吗**——终稿生效还是仍在草案；② **措辞是定性打击还是规范化管理**——"整治"=压制未完，"健康发展/规范"=收编不是消灭；③ **供给端恢复了吗**——版号常态化、龙头新品重新获批。三问齐备+趋势企稳才算出尽；只占一两条按情绪脉冲处理。历史上"第二只靴子"反复出现——**回补永远分步，不一把梭**。

## 五、文本视角（zsxq+news+研报，**每日必读，硬性**）

> 工具：`zsxq_topics`/`zsxq_search`/`zsxq_topic_detail` + `research_search`/`research_view`。**每个交易日必须执行，不许跳过，不读完不许收工**——版号/监管/流水全是文本，**本指数丢文本面等于裸奔**。

每日固定动作（3–5 次调用，不许刷库）：
1. **监管面第一优先**：`research_search`（search_type='all'）查版号/监管/新规当日增量。
2. **纪要流**：`zsxq_topics`（count=20）过当日新增，相关即标记。
3. **主题词**：`zsxq_search` 1–2 个主线词（0 条看 `query_used` 换词）；需正文再 `zsxq_topic_detail` / `research_view`，最多 1–2 篇。

怎么读：
- **事实承重，观点只做密度统计**：版号数量、获批名单、流水=事实；研报观点/目标价=滞后情绪代理。
- **一致性逆向读**：一致看多在趋势成熟期是反向信号、监管转暖初期是领先信号——属于哪种回〇节当场定。
- **证据落链 + 留痕（硬性）**：当日 evidence 至少 1 条文本条目（topic_id/INFOCODE+摘要）；没读到就写"今日文本面无增量"；无检索记录不许引用"听说/传言"。复盘固定一行 `文本增量: 无|低|中|高 —— <读到什么/改了什么>`。
- **权重边界**：文本给方向与证伪，不直接给仓位，不得突破回撤与步长纪律。

## 六、证伪视角（对称化）

对称列出；触发=原论据失效，需新论据维持仓位。

- **看多被证伪**：版号间隔拉长/某批未按惯例发放；官方批评性措辞/新规草案启动；新游流水不及预期/畅销榜快速滑落；买量成本上行、出海放缓；龙头一致预期转下修；AI 降本无毛利率验证。
- **看空被证伪**：版号常态化恢复/龙头新品获批；定调转暖、落地条款弱于草案；新游流水超预期且留存稳；出海占比提升、买量成本回落；利空出尽三问齐备+趋势企稳。

# 仓位管理方法论

## 唯一信仰：监管定生死+产品周期给方向+纪律压回撤，**空仓是常态**

- **930901 "不持有就是胜利"的时段很长**，这个基调要比所有别的框架都重。空仓不是防守失败，是**默认状态**；需要论证的永远是"为什么进场"，不是"为什么空仓"。
- 仓位完全由赔率决定，没有常态中枢。监管收紧期（〇-4）敞口有硬上限；三线共振的窗口才吃 β——**别缺席**。

**骨架（承〇-2）**：趋势市动量+回撤纪律拿住让 β 跑、破位一把降仓；震荡市防守少动不追脉冲，逻辑级催化放量突破站稳才交回。

**不对称操作**：最小步长 20%，不微调。政策利空确认/趋势破位/爆款证伪→一把降到位、可以到 0。回补按赔率：共振才大步上；**监管方向不明时任何回补只配小步**。只在浮盈/趋势未坏的回调里加仓，绝不下跌趋势中摊薄。

**止盈止损与回撤控仓**：在场只盯趋势破没破+持仓高点回撤多少，不用固定数字；主升尾段（拥挤极端+估值预警+文本刷屏）止盈收紧；保本线：浮盈 ≥ 10% 后离场线抬到成本价。账户级总开关：净值峰值明显回撤→机械降仓/停加，继续扩大→空仓复盘；回撤数学不对称（−20% 需 +25%）。

**成本意识**：7 日内赎回有 1.5% 惩罚；每档至少持有 3 个交易日，只有趋势/回撤因子转空、账户回撤穿阈、止盈触发、**政策黑天鹅落地**四类允许跳档。

## 量化择时辅助（2026-06-11 全 44 因子族扫描）

> IS 2013–2021 / OOS 2022–2026.06，5bp 单边、T+1，**DD-止损整族绿灯**（族级鲁棒，非单因子幸存）。族级结论：**这个指数上价格因子的使命就是断后离场，不是找买点**。当第二意见，不替代框架打分。读数用收盘序列按公式自算（尚未包进 `quant_factor`，已列待办）。

### `dl_deepdd15_p120`（主）——深回撤+闪崩旗标双保险
- **是什么**：默认满仓；（10 日跌幅 ≤ -10% 触发 crash 旗标、10 日冷却）或（从 120 日峰值回撤 >15%）→ 空仓。OOS Calmar 0.55 vs buyhold **-0.02**（dCal+0.57）、OOS 最大回撤 −26% vs −58%、CI[0.05,1.14]、wf 4/5、exposure 0.39——**约六成时间空仓，对本指数这是特性不是缺陷**。
- **会漏什么（公式可推）**：① **政策黑天鹅防不了**——crash 旗标对单日政策跳空（一天 −10%）是**事后触发**，T+1 执行还要再吃一天，事前防御只能靠文本面+四节事件前敞口管理；② 缓慢阴跌不到 15% 不触发；③ 重入靠回撤修复，V 型反弹前段必然迟到。
- **怎么用**：=0 而框架看多→先核验文本面漏了什么；同向 =1→可放大步长；框架看空而 =1→不构成"再等等"的理由。

### `trail_dd10_p60`（辅）
- 从 60 日滚动峰值回撤 >10% → 空仓；收盘站回 MA40 → 满仓。OOS Calmar 0.46（dCal+0.48）、CI[0.17,1.25]、wf 4/5、IS_dCal+0.14。比 deepdd 灵敏、重入更快。盲区：MA40 附近横盘反复抽插；同样防不了政策跳空。与主因子双 0 → **优先核验而非死扛**。

### `dl_deepdd20_p120`（变体）
- 同 deepdd15 但阈值 20%（OOS dCal+0.48、CI[0.17,1.21]、wf 4/5）。存在价值=证明**族级鲁棒**：阈值梯度全绿，赚的是结构的钱不是参数运气。

### 共同纪律
- 这族是**降回撤工具，不是收益增强器**。**不写也不执行"因子=X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。

## 成对格言（环境决定用哪条）

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 利空出尽是利好 | 政策底后还有第二只靴子 | 四节三问齐备 → A；草案期反弹 → B |
| 爆款上线要追 | 流水见顶是卖点 | 首月超预期+留存稳 → A；冲高快落、研报已沸腾 → B |
| 题材附体要吃 | 叙事退潮快跑 | 〇-1 扩张+趋势多头 A 可轻仓；拥挤极端+文本刷屏 → B |
| 别人恐惧我贪婪 | 监管面前不接飞刀 | 系统性恐慌、监管逻辑没变 → A；监管收紧驱动的下跌**永远 B** |
| 空仓会踏空 | 空仓是常态 | 三线共振才有 A 的资格；**其余时候 B 是默认答案** |

> **核心一句**：动漫游戏——先判环境（〇节四问，尤其**监管松紧**），**版号与监管文本**定生死、**爆款流水文本**给方向、**趋势/回撤**给离场，deepdd/trail_dd 机械断后但**防不了政策黑天鹅**（只能文本面+事件前降敞口）；空仓是常态、不愧疚，进场才需要理由。
