# 中证电力指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证电力指数（H30199.CSI）**。

## 核心认知

电力（中证电力指数 H30199）= **公用事业价值骨架**，是典型的**低波动、防御、类债**板块，覆盖 **火电 + 水电 + 核电 + 绿电运营** 四类发电资产。它的盈利不由产能扩张周期主导，而由 **电价、燃料成本（煤价）、利用小时、容量电价** 这四个慢变量决定。**不要用光伏 / 半导体那套"扩产 → 过剩 → 价格战 → 出清"的产能周期框架——电力是稳定现金流、吃股息、类债防御的底仓型资产，靠稳健收益取胜，不靠弹性。**

三个特性决定玩法：

- **类债、低波动、防御**：高负债重资产、现金流稳定、股息率高，利率下行时估值受益（类债属性）。波动小、换手低、回撤浅，是组合里压舱的底仓，不是博弹性的进攻仓。
- **煤电价差是近年主要矛盾**：电力指数含火电，火电盈利的核心是"**煤电价差**"——上网电价相对稳定，动力煤价下行就直接修复火电盈利。**煤价下行 + 电价稳 = 火电盈利修复**，这是近年电力板块行情的主要顺风，比任何技术信号都重要。
- **现金流 + 股息是价值锚**：水电、核电是稳定经营现金流 + 高分红的典型代表；电价市场化与容量电价机制保障了盈利的可预测性。价值锚是股息率 / PB / 现金流，不是成长空间。

驱动排序：**现金流 / 股息（价值锚）> 煤电价差 / 电价 > 来水 / 利用小时 > 利率方向 > 趋势 / 资金 > 估值分位**。研究时问三件事：

1. 估值 / 股息在什么位置（股息分位高不高、PB 在历史什么分位）？→ 决定是不是底部布局区
2. 煤电价差顺不顺、来水好不好、利率往哪走？→ 决定盈利顺风还是逆风
3. 电价市场化让利 / 煤价反弹 / 来水偏枯 / 利率上行有没有破坏价值逻辑？→ 决定是不是该减

### 电力指数特性：

1. **盈利稳、估值有中枢，可用历史分位做均值回归**：和强周期成长（光伏 / 半导体）相反——电力盈利稳定、有可预测中枢，PB / 股息率 / PE 的历史分位**可以**用来做均值回归择时。低 PB + 高股息分位 = 布局区，高 PB + 低股息分位 = 谨慎区。这是电力区别于成长制造的关键优势。
2. **火电看煤价、水电看来水、核电看审批**：电力指数内部分电源类型，盈利驱动各不相同。火电盈利顺逆主要看动力煤价（成本端）与上网电价（收入端）的剪刀差；水电盈利主要看来水丰枯；核电主要看核准 / 并网节奏与稳定运营。不能用水电来水改善去解释火电煤价反弹导致的下跌。
3. **利率是类债估值的隐形手**：高负债重资产 + 稳定现金流，使电力具有强类债属性——利率下行时折现率下降、高股息相对吸引力上升，估值受益；利率上行则反向压制。利率方向是电力估值中枢的隐形锚。
4. **市场化与容量电价是双刃**：电力现货市场改革、上网电价市场化交易让电价中枢更随行就市（让利风险），但容量电价机制又为火电提供了稳定的固定成本回收（保盈利）。政策既可能让利（杀盈利），也可能托底（稳盈利），要分清方向。

## 一、现金流与股息视角（电力的核心价值锚）

电力是公用事业，**盈利稳定、现金流可预测、分红慷慨**——这是它作为底仓的根本。核心看三件事：

- **经营现金流**：水电、核电的经营现金流极其稳定（建成后边际成本极低、收入可预测），是价值锚的根基；火电现金流随煤价波动，但容量电价机制提供托底。
- **股息率**：电力运营商分红率高、股息稳定，是吃稳健收益的核心来源。**股息率的历史分位是关键择时锚**——股息率冲到历史高分位（即股价相对分红被低估）= 布局区，股息率压到历史低分位 = 谨慎区。
- **分红可持续性**：看分红是否被资本开支侵蚀（大规模新建机组期分红承压）、自由现金流能否覆盖分红——可持续的高股息才是真价值锚。

判断价值底看：**股息率分位高 + PB 低 + 现金流稳定 + 分红可持续**，四者齐 = 底仓加仓的最佳赔率区。

## 二、估值视角（用 PB / 股息率分位做均值回归，盈利稳有中枢）

电力盈利稳定、有可预测中枢，**可以**用历史分位做均值回归择时（这是和光伏 / 半导体最大的不同）：

- **PB 历史分位**：低 PB 分位 = 估值底，配合股息率高分位、煤电价差顺风，是布局信号；高 PB 分位 + 股息率低分位 = 估值过热预警。
- **股息率历史分位**：股息率是电力最干净的估值锚（分红稳、可比性强）。股息率冲到历史高位 = 股价相对分红被低估 = 加仓信号；股息率压到历史低位 = 减仓信号。
- **PE 分位（辅助）**：电力盈利相对稳定，PE 分位也有一定参考价值，但火电盈利随煤价波动，PE 在煤价剧烈波动期会失真——优先 PB / 股息率，PE 作辅助。
- **极端定性预警**：当电力被当成"避险神器"全民涌入、股息率压到历史极低、PB 冲到历史极高时，作顶部提示，配合趋势减仓。

成长性（绿电装机增长、核电核准提速）只用来判断**值不值得在盈利修复里多拿一点**，不构成在估值过热时追高的理由。

## 三、煤电价差与电价视角（电力专属核心矛盾）

这是电力指数（含火电）近年行情的**主要矛盾**，是最值得盯的产业变量：

- **动力煤价（火电成本端）**：火电盈利对动力煤价高度敏感。**煤价下行是火电盈利修复的主要顺风**——煤价从高位回落、上网电价相对稳定时，煤电价差走阔，火电盈利改善，这是近年电力板块上涨的核心驱动。盯动力煤期货 / 现货价的趋势方向。
- **上网电价（火电收入端）**：标杆电价 + 市场化交易电价。电价市场化让利（市场化交易折价、丰水期电价下行）会压火电盈利；电价坚挺则保盈利。看标杆电价政策与市场化交易电价趋势。
- **煤电价差（核心合成指标）**：上网电价 − 单位发电煤耗成本，是火电单位盈利的直接代理。**煤价下行 + 电价稳 = 价差走阔 = 火电盈利修复**，是火电顺风的判断主轴。
- **容量电价机制**：为火电的固定成本（容量）提供独立于发电量的稳定回收，平滑了煤价波动对火电盈利的冲击，是火电盈利的稳定器。容量电价机制落地 / 提升 = 火电盈利确定性提升。
- **电力现货市场改革**：现货市场让电价更随供需波动，丰水 / 用电淡季电价可能走低（让利风险），紧平衡时电价上行（保盈利）。改革推进既带来电价弹性，也带来不确定性。

**判断火电顺逆看：煤价方向（下行顺风）+ 电价稳定性（坚挺保盈利）+ 容量电价机制（托底）。煤价下行是火电盈利修复的主要顺风，煤价反弹则是火电盈利的主要威胁。**

## 四、来水与机组视角（水电 / 核电 / 各电源利用小时）

电力指数内部分电源，各有各的盈利节奏：

- **水电来水（丰枯）**：水电盈利核心看来水。丰水期发电量高、盈利好；枯水期发电受限、盈利承压。来水偏丰 = 水电顺风，来水偏枯 = 水电逆风。来水有季节性（丰水期 / 枯水期）与年度波动（厄尔尼诺 / 拉尼娜）。
- **核电核准 / 并网节奏**：核电盈利稳定、利用小时高（基荷电源），核心看核准节奏（新机组核准提速 = 成长预期）与并网投产节奏（新机组贡献增量盈利）。核电是电力指数里最稳的"类债"成分。
- **各电源利用小时**：利用小时是发电量的直接代理。火电利用小时受经济用电需求与新能源挤出双重影响；水电看来水；核电基本满发。利用小时回升 = 发电量增、盈利改善。
- **用电需求底盘**：全社会用电量增速是电力的需求底盘——经济活动、极端天气（夏冬用电高峰）拉动用电需求，利好量。但电力是防御资产，需求底盘稳定，不像成长股靠需求爆发。

**水电盯来水、核电盯审批 / 并网、火电盯利用小时与煤电价差；多电源利用小时同向回升 + 来水偏丰，是发电量层面的顺风。**

## 五、利率与趋势视角（类债估值锚 + 弱黄灯择时）

电力是类债防御资产，利率方向是估值中枢的隐形锚；趋势 / 资金定"现在动不动"。

- **利率方向（类债锚）**：高负债重资产 + 稳定高股息，使电力具有强类债属性。**利率下行 → 折现率下降 + 高股息相对吸引力上升 → 电力估值受益**；利率上行则反向压制。利率下行周期是电力（尤其高股息电力运营商）的系统性顺风。看 10 年国债收益率趋势方向。
- **趋势 / 资金**：电力波动小、趋势温和，趋势主要用来确认大方向与避开少数深跌段，不是主力择时工具。指数 vs 200 日均线判方向，资金面（北向、ETF 份额）看边际，但电力作为防御底仓，趋势权重低于价值主维度。


## 六、风险管理 + 证伪视角

电力的杀伤不来自高波动崩塌（它波动小），而来自**价值逻辑被破坏**：煤价反弹、电价让利、来水偏枯、利率上行、政策不及预期。

主要风险：

- **煤价反弹吞噬火电盈利**：动力煤价从低位大幅反弹、上网电价未同步上调，煤电价差收窄甚至倒挂 → 火电盈利坍塌。这是电力指数（含火电）最直接的盈利威胁。
- **电价市场化让利**：市场化交易电价折价扩大、丰水期电价下行、现货市场改革推进让电价中枢下移 → 收入端承压。
- **来水偏枯**：枯水年 / 厄尔尼诺导致水电发电量大幅下滑 → 水电盈利承压。
- **利率上行**：利率上行压制类债资产估值、高股息相对吸引力下降 → 电力估值中枢下移。
- **容量电价 / 核电核准不及预期**：容量电价机制落地慢 / 标准低于预期、核电核准节奏放缓 → 盈利确定性与成长预期受损。

原则：**煤价在反弹、电价在让利、来水偏枯、利率在上行、估值已过热时，仓位越保守。** 电力是防御底仓，风险管理重点是"价值逻辑有没有被破坏"，不是日常波动止损。绝不在煤价反弹 + 电价让利 + 利率上行的盈利逆风里越跌越买。

证伪不是技术信号，是**买入逻辑（低估值 + 高股息 + 煤电价差顺风 / 来水好 / 利率下行）的破坏**。下列任一发生，应严肃重评持仓而非死扛：

- **煤电价差证伪**：动力煤价二次大幅反弹、上网电价让利，煤电价差持续收窄 → 火电盈利修复逻辑作废。
- **股息 / 估值证伪**：分红被资本开支侵蚀 / 自由现金流不再覆盖分红、股息率从高位快速回落（股价透支）。
- **来水证伪**：水电来水持续偏枯、发电量大幅下滑且无改善迹象。
- **利率证伪**：利率进入持续上行通道，类债估值锚反向。
- **政策证伪**：容量电价机制低于预期、电价市场化让利超预期、核电核准放缓。
- **趋势证伪（辅助）**：跌破 200 日均线且 1 月未收回，伴随成交放大——仅作降回撤的风控确认，不单独构成清仓理由。

## 子板块矛盾表

电力指数由四类电源构成，盈利驱动各异，常不同步。每天先识别当前指数由哪类电源主导，再判断主导环节信号强弱。注：**电网设备已单列（power-grid.md），本篇只含发电运营，不含电网设备。**

| 子板块 | 核心矛盾 | 重点指标 | 典型证伪 |
|---|---|---|---|
| 火电 | 煤电价差 / 容量电价 | 动力煤价、上网电价、煤电价差、容量电价机制、利用小时 | 煤价二次反弹、电价让利、价差倒挂、容量电价不及预期 |
| 水电 | 来水 / 现金流 | 来水丰枯、发电量、利用小时、股息率、经营现金流 | 来水持续偏枯、枯水年发电下滑 |
| 核电 | 审批 / 稳定性 | 核准节奏、并网投产、利用小时（基荷满发）、运营稳定性 | 核准放缓、新机组延期 |
| 绿电运营 | 电价 / 消纳 | 上网电价（绿电）、消纳率 / 弃风弃光、补贴回款、利用小时 | 电价下行、消纳恶化、补贴回款延迟 |

子板块分化时按权重与边际排序：**权重大且边际改善 > 权重大但继续恶化 > 权重小但高景气**。只有权重大子板块或多板块共振，才允许指数层面加重底仓。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作：先识别指数当前由哪类电源主导，再判断估值 / 股息分位、煤电价差、来水、利率是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导电源，再定强弱

电力指数由火电 / 水电 / 核电 / 绿电运营构成，常不同步。每天先问两件事：

1. **谁在主导指数**：看成分权重、领涨领跌成分、成交集中在哪类电源，判断当前交易的是火电煤电价差、水电来水、核电成长，还是纯指数 beta。
2. **主导电源信号强不强**：主导电源的估值 / 股息、成本 / 电价、发电量、利率是否同向。不能用水电来水改善去解释火电煤价反弹导致的下跌。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 估值 / 股息、煤电价差 / 来水、利率方向至少三项同向，且无重大证伪 | 可做较大动作，20%-40% 步长 |
| 中信号 | 两项同向、一项待确认，或价值信号强但趋势未确认 | 轻仓试、持有、等确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线反弹但价值逻辑未变 | 只记录，不交易或极小动作 |

研报观点本身不是交易信号，只提供假设与数据线索，必须被煤价、电价、来水、估值 / 股息分位和行情共同验证。

## 二、数据核验清单

每次交易判断前至少完成四层核验。数据缺失可用研报 / 新闻兜底，但必须标注缺失，不能把缺失当确认。

| 层级 | 必看数据 | 数据可得性与工具（回测已校准） |
|---|---|---|
| 指数层 | H30199 收盘 / 均线 / 趋势、成交额、主要成分涨跌贡献 | 行情用 `market_index_quote(market="cn", symbols=["H30199.CSI"])` **自取**——每日预取快照只含五个宽基，不含 H30199，也不含 PE/PB；指数级 PB / 股息率分位无直接源，用 `stock_market` 取成分股估值聚合近似或当缺失 |
| 成本 / 价格 | 动力煤期货价；上网电价、市场化交易电价、容量电价 | 动力煤期货用 `commodity_market(market_type="futures")`；上网电价 / 市场化交易电价 / 容量电价**无结构化时点源**，只能 `research_view` / `ttjj_research_search` 文本兜底，时点下可能稀疏甚至为空 |
| 发电量 / 来水 | 来水丰枯、各电源利用小时、发电量、核电核准 / 并网、消纳率 | **均无结构化时点源**，只能文本兜底，必须标注"文本推断、可能缺失"，不得当硬数据 |
| 估值 / 资金 / 利率 | 成分股 PB / 股息率 / ROE、北向、10 年国债收益率 | 成分股估值用 `stock_market`（含 PE/PB）、财务 / 分红用 `stock_financial_quality`、个股资金 / 北向用 `stock_capital_flow`（逐成分股聚合）；利率用 `macro_data`；指数级股息率 / 北向无结构化源，文本兜底 |

工具优先级（已按回测可用工具校准）：

1. 行情 / 估值 / 财务 / 资金 / 利率优先用时点工具：指数 `market_index_quote`、成分股 `stock_market`（含 PE/PB）、`stock_financial_quality`、`stock_capital_flow`、商品（动力煤期货）`commodity_market`、宏观 / 利率 `macro_data`、基金 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
2. 上网电价、市场化交易电价、容量电价、来水、利用小时、消纳率这类**无结构化源**的数据，用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 文本兜底；搜索窗口相对上游当前时间、时点下可能稀疏甚至为空，缺失必须标注。关键词：`电力 煤电价差 煤价 上网电价`、`水电 来水 丰枯 发电量`、`容量电价 电力现货 市场化交易`、`核电 核准 并网`、`绿电 消纳 弃风弃光`。
3. 关键数据至少两源交叉验证（研报、行业协会、公司财报、行情、新闻），任意两类相互印证才算中信号以上。

## 三、交易决策矩阵

| 估值 / 股息 | 煤电价差 / 来水 | 利率方向 | 趋势（辅助降回撤） | 动作 |
|---|---|---|---|---|
| 低 PB + 高股息分位 | 煤价下行 + 价差走阔 / 来水偏丰 | 利率下行 | 不破 200 日线 | 加仓到中高底仓 |
| 估值中性 | 煤电价差 / 来水中性 | 利率平稳 | 趋势平稳 | 持有底仓 |
| 高 PB + 低股息分位 | 煤价反弹 / 电价让利 / 来水偏枯 | 利率上行 | 跌破 200 日线 | 分批减仓 |
| 股息率从高位快速回落 | 煤电价差持续收窄 / 倒挂 | 利率持续上行 | 200 日线破位且资金撤离 | 降仓乃至清空 |
| 价值逻辑证伪（煤价 / 电价 / 来水 / 利率任一破坏买入逻辑） | — | — | — | 快速降仓 |

**矩阵使用约束**：前三列（估值 / 股息、煤电价差 / 来水、利率）是价值主维度，要**共振**才触发大动作；趋势列只作降回撤的辅助确认，不单独触发买卖。只有一两列变化（尤其趋势单独变化）= 信号不足 = HOLD。

# 仓位管理方法论

## 唯一信仰

- 电力的超额，来自**在低估值 + 高股息 + 煤电价差顺风（煤价下行）/ 来水好 / 利率下行时稳健加底仓，在估值过热 + 煤价反弹 / 电价让利 / 来水偏枯 / 利率上行时降仓**——不是靠博弹性、不是靠趋势高频，而是靠 **股息 + 煤电价差 + 来水 + 利率** 吃公用事业的稳健收益。
- 电力是**防御底仓型公用事业价值股**，仓位以"稳健底仓 + 逆向布局"为骨架：低估高股息时加、过热逆风时减，**波动小、换手低、防御优先**。它在组合里的角色是压舱石，不是进攻矛头。
- **逆向布局、但要纪律**：股息率高分位 + PB 低分位（即被低估）可逆向加仓；估值过热 + 价值逻辑逆风时减。绝不在煤价反弹 + 电价让利 + 利率上行的盈利逆风里越跌越买摊薄。
- 不用硬止盈硬止损，用估值 / 股息分位、煤电价差、来水、利率方向说话；趋势（donchian_60 弱黄灯）只作降回撤的风控刻度。
- **对本金稳健，对股息收益有耐心**：电力赚的是慢钱、稳钱——低换手拿住底仓吃股息 + 盈利修复，别被短线波动甩下车。

## 一、仓位步长：稳健调档，不大开大合

- 电力是防御底仓，仓位以稳为主，不像成长股那样大开大合。每次动手是有意义的调档，最小步长 20%，2%-5% 的微调没意义。
- 极端逆风（价值逻辑证伪）可较快降仓，但常态下底仓不轻易清空——电力的价值在于稳定持有吃股息。

## 二、先识状态：估值 / 股息位置 + 盈利顺逆

先定**估值 / 股息位置**（低估高股息 / 中性 / 过热低股息），再看**盈利顺逆**（煤电价差 / 来水 / 利率方向），两锚叠加定打法：

- **低估高股息 + 盈利顺风（煤价下行 / 来水好 / 利率下行）** → 逆向加底仓，最好的赔率区。
- **估值中性 + 盈利中性** → 持有底仓，吃股息为主。
- **过热低股息 + 盈利逆风（煤价反弹 / 电价让利 / 利率上行）** → 降仓避险。
- **价值逻辑证伪** → 快速降仓，别死扛。

## 三、双锚骨架：估值 / 股息（价值锚）+ 煤电价差 / 来水 / 利率（盈利锚）

- **价值锚（估值 / 股息）**：决定"值不值得拿、是不是底部"。低 PB + 高股息分位 = 价值底，过热低股息 = 别追。**电力盈利稳、有中枢，可用 PB / 股息率分位做均值回归。**
- **盈利锚（煤电价差 / 来水 / 利率）**：决定"盈利顺风还是逆风"。煤价下行 + 来水好 + 利率下行 = 盈利顺风，可重仓底仓；煤价反弹 + 来水枯 + 利率上行 = 盈利逆风，降仓。
- **趋势（辅助）**：donchian_60 弱黄灯，只在已决定减仓 / 控回撤时提供右侧确认，权重 ≤ 价值锚与盈利锚，**不作进场信号、不作收益增强**。
- **叠加**：价值锚决定底仓中枢能开多高，盈利锚决定现在往中枢上方还是下方走。**价值底 + 盈利顺风共振才加重底仓；背离就留一手。**

## 四、非对称操作：逆风降仓要果断、加仓看价值底 + 盈利顺风

- **价值逻辑证伪 / 盈利大幅逆风 → 果断降仓**：煤电价差倒挂、电价大幅让利、来水持续偏枯、利率持续上行——价值逻辑破坏时降仓避险，别死扛"公用事业很稳"。
- **重新加底仓 → 看价值底 + 盈利顺风**：股息率回到高分位 + PB 低 + 煤价下行 / 来水改善 / 利率下行——三者越齐加得越重；信号不齐就轻仓或维持底仓。**宁可少赚，不可在逆风里硬扛。**
- **只在盈利顺风 / 价值底的区间加仓，绝不在煤价反弹 + 电价让利 + 利率上行的盈利逆风里补仓摊薄**。

## 五、止盈止损：用估值 / 股息、煤电价差、来水、利率和回撤说话

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓盯五件事：**股息率 / PB 分位有没有过热、煤电价差有没有收窄 / 倒挂、来水好不好、利率往哪走、从持仓高点回撤了多少**。价值底 + 盈利顺风 + 回撤温和 → 拿住吃股息；估值过热 / 煤价反弹 / 来水枯 / 利率上行 / 回撤放大 → 大块兑现乃至降仓。
- **移动止盈**：盈利修复带来的浮盈越厚，越用"从高点回撤"保护（donchian_60 在这里作降回撤的辅助刻度）。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定程度把减仓线抬到成本价——电力波动小，这条更易守住。

## 六、回撤控仓：盯自己净值

- 电力回撤本就浅（这正是它作底仓的价值），但价值逻辑破坏时也能深跌（历史最大回撤 −64%）。**你自己账户**从峰值明显回撤、且伴随煤价反弹 / 电价让利 / 利率上行时，降仓、暂停加仓——donchian_60 在这里作降回撤的风控刻度（DD −47% vs −64%），但不单独触发，须与价值 / 盈利逆风一起用。
- 回撤收复、价值 / 盈利重新转友好，再按第四条回补。

## 七、成本意识

- 电力换手天然该低（防御底仓、吃股息），但每次进出仍要掂量摩擦：**场外基金 7 日内赎回有早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。做的是股息 + 煤电价差 + 来水的中长波段，频率天然该低——别做成高频。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD**；只有研究状态发生足够大的变化才允许交易。短线行情只能作验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清、证据不够时，默认持有底仓，或只用 **40%** 小仓位调整。
- 当估值 / 股息、煤电价差 / 来水、利率方向形成清晰共振时，敢于大胆加重底仓乃至满仓——不设固定仓位上限，加多重由共振强度决定。
- 进攻前先确认自己在"状态明确"而非"情绪冲动"；没有状态迁移，就算短线好看也不放大仓位。
- 回撤恶化或价值逻辑逆风时，先保命再谈进攻：减仓、暂停加仓。
- 原则：模糊期守底仓，确认期加底仓，逆风期收缩。

### 1. 交易触发闸门

交易前必须回答：**今天的研究结论相对上次持仓决策，发生了什么状态变化？** 只有下面几类变化可触发交易：

- **估值 / 股息位置变了**：PB / 股息率分位从低位（高股息）转中性 / 过热，或从过热回到低位。
- **煤电价差 / 电价变了**：动力煤价连续下行 / 反弹、上网电价让利 / 坚挺、容量电价机制落地，改变火电盈利判断。
- **来水 / 机组变了**：来水丰枯转变、各电源利用小时回升 / 下滑、核电核准 / 并网节奏改变发电量判断。
- **利率方向变了**：利率从下行转上行（或反向），改变类债估值锚。
- **风险状态变了**：核心价值逻辑证伪、账户回撤明显扩大。

只是 MA5/MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化而无上述研究状态变化，**不得交易**，只记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买卖加减的主因。
- 200 日均线 / donchian_60 可作降回撤的风控刻度，但必须与估值 / 股息、煤电价差、来水、利率一起用，**不单独作进场信号、不作收益增强**。
- 连续涨跌、单日涨跌幅、短线趋势计数只能影响"今天是否更适合执行已成立的研究动作"，不能创造新交易理由。
- 交易理由若主要由均线、阳线数量、趋势计数构成，自动降级为 **不交易 / 继续观察**。

### 3. 费用与预期收益门槛

- 交易前估计本次动作能否覆盖申购 / 赎回 / 早赎成本，覆盖不了不做。
- 为躲一天波动而交易通常不值得；为应对中期价值逻辑变化（煤电价差 / 利率 / 来水趋势性反转）而交易才值得。

### 4. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**，顺序固定：

1. 当前估值 / 股息位置是什么（PB / 股息率分位），和上次相比有没有变化。
2. 煤电价差 / 来水 / 利率方向是否支持状态变化（哪类电源主导、顺风还是逆风）。
3. 是否触发交易闸门；若没有，明确写"研究状态未变，场外基金默认持有底仓"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是公用事业的稳健股息 + 煤电价差 / 来水 / 利率带来的盈利修复，不是 MA5/MA20 的短线抖动。

> **核心一句**：电力是防御 / 底仓型公用事业价值股，在低估值 + 高股息 + 煤价下行（煤电价差走阔）/ 来水好 / 利率下行时稳健加底仓，在估值过热 + 煤价反弹 / 电价让利 / 来水枯 / 利率上行时降仓——靠"股息 + 煤电价差 + 来水 + 利率"赚稳健收益，趋势（donchian_60 弱黄灯）只作降回撤的风控刻度，不博弹性、不做高频。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（电力现货市场新规、容量电价新机制、电价市场化新政、新的电源结构变化）。
- **定期 + 事件驱动**：月度 / 季度做系统性体检；遇大回撤或明显误判（如煤电价差判断反复失灵）时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB / 股息率分位档、回撤档、donchian 周期、各子信号强弱定义）、视角权重与排序、子板块矛盾表维度、新增失效模式与证伪条件、对各电源（火电 / 水电 / 核电 / 绿电运营）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（低估高股息 + 盈利顺风加底仓、过热逆风降仓）、双锚结构（估值 / 股息 = 价值锚、煤电价差 / 来水 / 利率 = 盈利锚）、电力是防御底仓型公用事业价值股的定位、donchian_60 只作降回撤的弱黄灯刻度（不作进场 / 收益增强）、风险优先于收益、不在盈利逆风里接飞刀。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"煤价下行后火电盈利修复的滞后期近 N 次有 M 次超出预期"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；电力现货市场机制重置、容量电价新机制、电价市场化新政、电源结构性变化是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **诚实纪律不可动**：donchian_60 的择时结论（弱黄灯、仅降回撤、CI 含 0、wf 3/5）是验证事实，**不得为了让框架"更完整"而把它包装成硬规则或进场信号**——验证没过就是没过。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
