# 800消费指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证主要消费指数（000932.SH，简称 800消费）**——从中证 800 中切出"主要消费（必需消费）"一级行业的全部证券（约 38–40 只，单票权重上限 10%，每半年调样）。

## 核心认知

800消费 = **必需消费拼盘**：白酒约三四成 × 渠道库存周期 + 食品饮料（乳品 / 调味品 / 软饮）约三成 × 成本-提价周期 + 农牧养殖约一两成 × 猪周期。它不是一个故事，是**三条互不同步的周期叠加**。五个特性决定玩法：

- **三条周期各走各的，主驱动会轮动**：白酒看批价库存的渠道周期；养殖看猪周期（能繁母猪存栏 → 约 10 个月后的生猪供给 → 猪价 → 养殖盈利）；大众品（乳品 / 调味品 / 饮料）看"原料成本 + 提价能力 + 社零需求"的慢周期。**同一时刻可能白酒在去库存、猪价在反转、乳品在成本红利——互相抵消或共振，必须拆开看主驱动，不能用一个故事解释整个指数。**
- **白酒是最大单一暴露**：白酒龙头合计约三四成权重，白酒的渠道周期（批价 / 库存 / 动销）依然是指数最大的方向变量——但茅台被 10% 权重上限压住，白酒纯度远低于白酒指数，**它是"被稀释的白酒 + 必需消费缓冲"**。
- **猪周期是独立的强周期插件**：养殖股盈利 = (猪价 − 成本) × 出栏量，PE 在猪周期里**反着读**（周期顶盈利暴增 PE 最低、周期底亏损 PE 失真）——指数级 PE 分位被这部分扰动，读估值时要心里有数。能繁母猪存栏是猪价的硬领先指标（公开月频数据）。
- **必需消费的"防御性"是相对的**：盈利确实稳（食品乳品调味需求刚性），但**估值不防御**——核心资产抱团泡沫破灭那轮，指数照样被杀掉一半上下，且持续数年。防御的是盈利，不是股价。
- **盈利稳定 + 样本长，是少数估值分位有意义的行业指数**：成分以盈利稳态公司为主（除养殖外），PE 分位 + 股息率的均值回归参考价值比科技 / 周期指数高得多——但同样只做赔率定位，不做择时扳机。

驱动排序：**主导子板块景气（白酒渠道周期 / 猪周期 / 大众品成本-提价）> 趋势 / 资金 > 宏观消费力（社零 / 收入 / 消费政策）> 估值分位**。研究时问三件事：

1. 现在指数的边际变化由哪条线主导（白酒 / 猪 / 大众品）？那条线的周期在哪一段？→ 决定能不能重仓、是不是底部。
2. 趋势对不对、资金在不在？→ 决定现在是加是减。
3. 宏观消费力（社零、收入预期、消费刺激政策）与政策（消费税 / 食安 / 疫病）变没变？→ 决定是不是该撤。

## 一、估值视角（盈利稳态部分 PE 分位有意义，但要剔掉猪周期的扰动）

800消费是少数**估值分位有参考意义**的行业指数——成分以盈利稳定、现金流可预测的必需消费龙头为主，PE 历史分位 + 股息率的均值回归是有意义的赔率标尺。但三条纪律：

- **猪周期部分 PE 反着读**：养殖股周期顶盈利暴增（拉低指数 PE）、周期底亏损（抬高甚至失真）。指数 PE 分位读数被这一两成权重扰动——**极端读数出现时先问一句"是不是猪周期在拉偏分母"**，必要时用白酒 + 大众品龙头的 PE 分位做交叉验证。
- **防"盈利新高 + 估值新低"的剪刀差误读**：必需消费可以出现盈利持续创新高而估值持续杀的长期背离（杀的是增长预期和资金偏好，不是当期盈利）。低分位是赔率信号不是反转信号——**反转要等主导子板块的景气证据**（白酒渠道反转 / 猪周期反转 / 社零回暖），分位只决定那时敢下多大注。
- **在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走 / 不进"。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"，极端读数仍是要认真对待的定性信号。

估值做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：PE 顶部分位 + 全民进场（消费主题基金爆发、"核心资产永远涨"叙事、外资机构超配拥挤）→ 趋势尾段提示，配合趋势框架与止盈纪律。
- **深价值底部观察（底）**：PE 底部分位 + 股息率高过长债 + 盈利仍在增长 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；去三条线里找景气反转证据，趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证：

- **方向锚**：指数 vs 200 日均线 + 均线斜率；时序动量（20–60 日收益符号）辅助。
- **量能确认（板块代理）**：指数无量 → `sector_factor` 成交集中度 / 拥挤度代理；突破时拥挤度同步抬升 = 有量，不跟 = 可疑假突破。
- **波动率（板块代理）**：收盘价滚动波动率 + MA200 乖离代理；波动骤增本身是降仓信号。
- **资金面**：消费是北向 / 机构的传统重仓方向，**外资回流 + 主导子板块景气改善共振**是底部确认的强组合；抱团瓦解 + 景气走弱是顶部组合。
- **事件跳空甄别**：消费刺激政策、消费税传闻、食安事件、猪瘟疫情常造成跳空，分清**逻辑级**（需求 / 盈利中枢被真实改变）还是**情绪级**（传闻、预期抢跑）。
- **子板块轮动**：白酒跌不等于指数跌——可能养殖在猪价反转里走牛。**先看指数层趋势，再拆是哪条线贡献的**，别把单线叙事当全指数判断。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（三条线分开跟，主导线为主）

### A 线：白酒渠道周期（最大权重，方向变量）

- **领先**：核心单品批价（飞天为锚）、渠道库存方向、龙头控货 / 提价动作。
- **同步**：动销（春节 / 中秋旺季验证窗）、回款。
- **滞后（确认不择时）**：报表营收 / 净利、合同负债——报表可被打款蓄水池调节，批价库存更难伪装。
- 阶段四分法：去库存下行 / 底部企稳 / 景气扩张 / 高位压货——判断与纪律同白酒类框架，此处主导指数方向。

### B 线：猪周期（独立强周期插件，数据最硬）

- **领先（硬指标）**：**能繁母猪存栏**（领先生猪供给约 10 个月，公开月频）——存栏深度去化 = 未来供给收缩 = 猪价反转的种子；存栏持续回补 = 下一轮下行的种子。
- **同步**：猪价（周频公开）、自繁自养盈亏线（深亏期越长去化越彻底）。
- **滞后**：养殖股报表盈利——**股价常领先猪价见底**（市场交易的是存栏去化，不是当期猪价），等猪价确认再动就晚了。
- 纪律：这条线**用存栏数据说话**，是全指数最可量化的景气维度，不要用情绪化的"猪周期叙事"替代月度数据。

### C 线：大众品成本-提价周期（慢变量，定底色）

- **领先**：原料成本（原奶价 / 大豆 / 包材 / PPI 食品）——成本下行 = 毛利率红利窗口；龙头提价动作（提价落地且动销不受损 = 定价权验证）。
- **同步**：社零粮油食品 / 饮料类同比、渠道库存（大众品库存周期浅但存在）。
- **滞后**：报表毛利率 / 净利——确认用。
- 结构慢变量：人口与消费习惯迁移（乳品量减价增、软饮功能化、调味品复合化）、新渠道（即时零售 / 折扣店）对传统渠道的侵蚀——决定长期空间，不决定当期方向。

**纪律**：三条线共用一个原则——**领先端定方向、滞后端做确认、背离时信领先端**。每天先回答"今天的边际变化属于哪条线"，再去对应的链条里核验；三线共振（白酒渠道反转 + 猪价反转 + 社零回暖）是本指数最强的赔率组合。

### 可用的择时指标（定性）

> 研究室离线全因子族扫描（长样本、含费率与 T+1）验证：本指数有一个通过验证的**趋势 + 波动门控**族，两组参数都过验证（族级佐证）。读数用收盘序列按公式自算。

- **`regime_lever`（趋势 + 波动门控，已验证，首选）** —— 规则：收盘价在 200 日均线**上方**且均线近一个月**向上** → 在场；其中近 20 日波动异常放大时降到半仓档；收盘价在 200 日均线**下方或均线走平向下** → 一律空仓。纯收盘价计算，可靠性高。
  - **它的本质（诚实）**：这是"**别在熊市里**"的机械化——深熊里它让你长期空仓（验证期里它大部分时间不在场），牛市里基本满仓。它承担的是**避坑**，不是收益增强；别指望它帮你抓反弹。
  - **已知盲区（从公式可推）**：① 200 日均线重入慢，**V 型反转前段必然迟到**；② 价格在 200 日线附近反复穿越时来回打脸；③ 只看价格，对批价反转、存栏去化、政策拐点**无预警能力**——它是断后的，不是侦察的。
- **次级辅助（参考）**：20 日动量（`mom_20`）方向参考；崩盘急刹（短期暴跌即离场冷却）作极端行情下的纪律提醒。

**怎么用（判断，不机械执行）**：`regime_lever` 当"现在该不该在场"的右侧第二意见，权重 ≤ 三条线的景气主维度。= 0（离场状态）而框架看多 → 优先逐项核验是不是基本面读漏了；= 1 且框架看多 → 同号确认，可放大倾斜步长；框架看空而它还 = 1 → 不构成"再等等"的理由，框架主导。**不要写也不要执行"因子 = X 且 Y 时必须 Z"的未回测组合规则**——冲突本身是信号，逐项核验冲突来源再决策。

## 四、宏观消费力 / 政策视角（必需消费的底层水位）

- **社零与收入预期**：必需消费的需求刚性使社零弹性小，但**估值由消费力预期定**——居民收入预期、消费者信心的趋势变化是估值中枢的慢变量。社零粮油食品 / 饮料 / 烟酒类同比是月频可量化的验证。
- **消费刺激政策**：以旧换新、育儿补贴、消费券类政策对必需消费多是间接利好（情绪 + 水位），对个别子线（乳品-生育、餐饮链-调味品）有直接传导——评估时分清**直接受益线**和**情绪外溢**。
- **消费税 / 食安 / 疫病三类政策风险**：消费税后移传闻砸白酒线；食品安全黑天鹅（乳品 / 调味品历史上都发生过）单点引爆但传染情绪；非洲猪瘟类疫病改变猪周期节奏（供给端突然出清反而催化猪价反转——**方向可能与直觉相反，先分析供需再定方向**）。
- **外资定价权**：必需消费龙头是北向传统重仓，美元利率与外资风险偏好通过资金面影响估值中枢——这是消费指数与全球流动性的隐性连接。

## 五、风险管理视角

- **三线同杀是最大回撤来源**：白酒去库存 + 猪价下行 + 消费力疲弱叠加时，"防御板块"防不住——识别三线状态，**三线皆逆风时不要因为"必需消费防御"而留仓**。
- **抱团瓦解**：核心资产属性，机构 / 外资持仓拥挤时，任何增长预期的边际恶化都会引发踩踏；拥挤度极端 + 景气走弱 = 减仓组合。
- **猪周期误判**：把猪价反弹当反转（存栏未去化到位的反弹都是反弹）——以能繁存栏为准，不以猪价短期波动为准。
- **食安黑天鹅**：单一龙头的食安事件会传染整个板块情绪，事件当日先按情绪脉冲处理，评估是否动摇品类信任再定性。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑大概率已破。绝不在三线逆风的下跌趋势中摊薄。

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称——看多与看空的证伪都要列；触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 白酒线：批价二次破位 / 渠道库存重新累积（渠道反转逻辑作废）
  - 猪线：能繁母猪存栏重新回补、猪价反转夭折（供给收缩逻辑作废）
  - 大众品线：提价失败（提价后动销受损）、成本红利结束（原料价格反转向上）
  - 宏观：社零持续走弱、消费刺激政策落空
  - 趋势：跌破 200 日均线且 1 月未收回、北向 / 机构资金持续撤离
- **看空被证伪（上行 veto-watch）**：
  - 白酒批价企稳回升 + 库存去化到位
  - 能繁存栏深度去化 + 自繁自养深亏持续（下一轮猪价反转的种子）
  - 龙头提价落地且动销无损（定价权验证）
  - 社零回暖 / 重磅消费刺激落地
  - 盈利持续增长 + 估值底部分位 + 趋势企稳放量（深价值 + 右侧确认）

# 仓位管理方法论

## 唯一信仰：主导线定方向 + 趋势定节奏 + 纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 800消费是三条周期的拼盘：超额来自**识别当前主导线并在它的景气反转 + 趋势确认时重仓，在三线逆风 + 趋势转空时果断离场**——"必需消费防御"防的是盈利不是股价，**不能当留仓的借口**。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"。
- 该在场时别缺席：三线共振 + 趋势多头时还空着 = 踏空，同样不及格。
- 不用硬止盈硬止损——择时交给主导线景气、趋势、回撤说话（`regime_lever` 作机械第二意见）。

## 一、先识状态：主导线 + 趋势市 / 震荡市

**每天第一步：先回答"现在谁主导指数"（白酒 / 猪 / 大众品 / 纯 β），再给价格状态分类（趋势市 / 震荡市 / 过渡待定三选一）。**

- 趋势市：均线（MA60 / MA120）单边排列、斜率明显，且主导线景气同向。
- 震荡市：200 日线走平 + 价格在均线 ±10% 箱体反复 + 假突破频出（必需消费波动小于科技，箱体略窄）。
- 过渡待定：两边都不像、或指数与主导线景气背离 → 轻仓 / 观望 / 维持原状态。
- **状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日跳空、单根假突破不算切换信号。每天显式记下**状态标签 + 主导线 + 认定理由 + 推翻它需要看到什么**。

## 二、趋势市骨架：时序动量 + 主导线确认 + regime_lever 断后

- **时序动量**：指数过去数周到数月的方向，叠加主导线景气趋势。共振向上 → 在场吃 β；任一转下 → 降仓。
- **`regime_lever` 作机械锚**：趋势骨架的客观第二意见——它转 0 而你还想留仓时，先逐项核验主导线证据是否还成立；它在高波动期压到半仓档的提醒，正是"波动放大本身是降仓信号"的机械化。
- **波动率体感**：越平静越敢拿；振幅骤增（政策 / 食安 / 疫病跳空）本身是降仓信号。
- 趋势里不做高抛低吸。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 先划箱（200 日线 ±10% + 近数月高低点）；划不出清晰箱体 = 观望。
- 箱体中段不动手；轻仓不赌箱体；不追假突破。
- 放量 / 逻辑级催化（猪价反转确认 / 批价反转 / 重磅消费政策）突破箱体并站稳数日 → **立即交接回趋势骨架**。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%。
- **三线逆风确认 / 趋势转空 / `regime_lever` 翻 0 且核验后基本面确实走坏 → 一把降到位，可以到 0**。
- **回补按赔率**：高赔率组合 = 主导线景气反转证据 + 估值底部分位 + 趋势放量确认 + 外资回流 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。**"宁可错过，不可做错"只约束低赔率情形**，高赔率时真正的"做错"恰恰是轻仓。
- **只在浮盈 / 趋势未坏的回调里加仓；绝不在三线逆风的下跌中摊薄**（深价值底部观察期的左侧试仓——小、分批、有景气证据——可以接；证据不齐的下跌不能接）。

## 五、止盈止损：用主导线、趋势和回撤说话，不用固定数字

- 在场期间盯三件事：**主导线景气有没有见顶反转、趋势破没破、从持仓高点回撤了多少**。
- **主升尾段的主动止盈**：估值泡沫预警 + 拥挤极端 + 一致看多叠加时，移动止盈收紧。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。"防御板块"的深熊照样过半，别被名字麻痹。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势 / 主导线转向、账户回撤穿阈值、止盈触发三类信号允许跳档。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 必需消费防御该拿住 | 防御的是盈利不是股价 | 三线中有一线以上顺风看 A；三线逆风 + 趋势转空看 B（杀估值不看盈利脸色） |
| 低 PE 分位该买 | 盈利新高估值新低能磨数年 | 主导线景气反转证据齐看 A，只有"便宜"没有催化看 B（分位定赔率不定时点） |
| 猪价涨了养殖该追 | 没去化的反弹都是反弹 | 看**能繁存栏**：深度去化后的反转看 A，存栏未去化的脉冲看 B |
| 提价是利好 | 提价是需求疲软的遮羞布 | 看**提价后动销**：动销无损 = 定价权验证看 A；动销受损 = 量价双杀前兆看 B |
| 估值太贵该减 | 趋势向上无视估值 | 景气扩张 + 趋势多头看 B；拥挤极端 + 景气见顶时极端读数当顶部预警 |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 主导线逻辑没坏的系统性恐慌看 A；三线逆风驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；泡沫预警 + 拥挤极端 + 量价背离看 B |
| 消费是一个板块 | 白酒猪大众品各走各的 | 默认按"分线"理解：先定主导线再判断，别用一个故事解释整个指数 |

> **核心一句**：800消费——白酒渠道周期 × 猪周期 × 大众品成本-提价的三线拼盘；先定**主导线**、用**领先端**（批价库存 / 能繁存栏 / 成本提价）定方向、**趋势 + `regime_lever`**定节奏、**估值分位 + 股息率**定赔率；防御的是盈利不是股价，三线逆风不留仓，空仓不愧疚，靠压回撤把夏普做上去。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新消费渠道、新政策工具、猪周期结构变化如规模化养殖拉长周期）。
- **定期 + 事件驱动**：一轮主导线周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PE 分位、回撤档、均线 / 动量周期）、视角权重与排序、三条线各自的领先指标清单、新增失效模式与证伪条件、`regime_lever` 在新数据上的表现复核。
- **不轻易动（信仰与原则层）**：唯一信仰（主导线反转 + 趋势确认重仓、三线逆风 + 转空离场）、三线拆解结构、风险优先于收益、不接飞刀、对本金保守对 β 放纵、领先端优先于报表。动这些要有极强且反复验证的证据。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式，不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖；`reason` 讲清"改了什么、为什么、依据是什么"。
- **小步快迭代优于大改**：一次只调一两处。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**。
- **区分噪声与结构变化**：日常波动是噪声；消费习惯迁移、猪周期结构重置、政策框架重置是结构变化。
- **保留可证伪性**：若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
