# 中证500指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面几个**正交**角度审视，自行综合判断该不该动、动多少。

> 中证500 是中盘成长贝塔，**估值与流动性 / 微观结构并重**——估值信号能用（分母不易塌方），但更脏、要配周期读；拥挤度（雪球 / IC / 量化中性）是真实边际买卖盘、必须盯。**两个择时引擎都得开，缺一会偏。**

## 核心认知

中证500 = A 股沪深两市剔除大盘蓝筹后、总市值排序居中（约 301–800 名）的中盘贝塔（电子 / 医药 / 基础化工 / 有色 / 计算机 / 电力设备 / 机械 / 国防军工权重高，金融消费权重偏轻），是 A 股中盘风格的主流宽基。四个特性决定玩法：

- **中弹性 + 中波动**：β≈1.1–1.2、近年年化波动 ~21%——**攻守兼备**，既不能当压舱石死拿，也不必随时准备逃命。
- **盈利偏周期、但分母不塌**：成分股以成长期 / 顺周期中盘为主，亏损股权重低，TTM E 不会系统性坍塌或转负——但顺周期行业（有色 / 化工 / 机械 / 部分电子）盈利周期性明显，**估值信号能用，但必须配周期位置读**。
- **雪球 / IC 主流标的（500 的特色维度）**：中证500 长期是雪球产品最主流挂钩标的（波动率 + 基差双优），IC 股指期货 + 雪球敲入 + 量化中性 / 指增是真实的边际买卖盘——**拥挤度 / 微观结构信号是 500 择时的承重维度**。
- **资金结构多元**：北向、两融、量化中性、公募指增、雪球对冲、ETF 共同定价，无单一资金主导。

### 中证500 估值特性：
1. 裸 PE/PB 分位基本可读（亏损股权重低、TTM E 不易塌方）；但顺周期行业占比高——**周期顶的低 PE 是盈利高点的"假便宜"，周期底的高 PE 是盈利低点的"假贵"**，必须配合周期位置 / ROE 读，不能裸看分位。
2. **PE 与 PB 都承重，行业中性 + 看周期**：行业分布较均衡（无单一行业绝对独大），行业中性化要修的 mix 假象小；周期股要 PB–ROE 一起看——低 PB + ROE 未塌 = 真便宜，低 PB + ROE 下行 = **周期陷阱**。
3. **股债性价比（ERP）可用但降级**：ERP / dv−10y gap 信噪比中等——作辅助锚，做滚动 z，不作唯一承重。
4. **估值给方向，流动性 / 拥挤度给择时**：估值定方向，但必须叠加拥挤度确认（雪球 / IC / 量化中性）才动手——**两个择时引擎都要用，缺一会偏**。

## 一、估值视角（承重，约一票）

- **PE + PB 合一票**：行业中性后用，配 ROE + 周期位置判断真假便宜（见核心认知）。两者同源，塞进同一维度算一票，确认要靠别的维度同号。
- **ERP / 股息 gap**：辅助锚，做滚动 z，只在偏离明显时投票。
- **方向**：估值 z 越负（贵）→ 偏低配；越正（便宜）→ 偏超配。**但顺周期段先确认盈利不在周期高点**——周期股"便宜"常是盈利顶的幻觉。

## 二、盈利 / 景气视角（与估值并列承重——中盘盈利弹性大）

- 看**一致预期修正广度**（上调家数 − 下调家数）/ 覆盖股数，和**前向盈利斜率**（FY2/FY1），看 4–6 周滚动趋势。
- **顺周期景气是 500 的核心盈利驱动**：有色 / 化工 / 机械 / 电子的量价、PPI、出口、制造业资本开支——这些景气拐点对 500 盈利的边际影响大。顺周期景气广度转正，是 500 走强的关键确认。
- **业绩雷期**（年报预告 1 月、年报 3–4 月、半年报 8 月、三季报 10 月）：中盘有一定商誉 / 减值风险，这几个窗口情绪与盈利信号单独加权。
- **口径**：用 FY1 一致预期（TTM 受单次性损益污染）；前向斜率取**等权中位**。

## 三、资金 / 流动性 / 微观结构视角（承重，500 的特色维度）

- **M1 − PPI 剪刀差**（名义流动性环境）+ 社融 / 信贷脉冲。剪刀差**必看分解**：M1 减速（偏空）vs PPI 反弹（reflation，利好 500 顺周期盈利，反而是上行风险）。
- **IC 基差 + 雪球敲入（500 特色信号）**：500 是雪球主流标的——
  - **IC 年化贴水水位 / 变化**：深贴水 = 对冲拥挤、做空成本上升，常是反弹前夜的反向信号；贴水快速收敛 = 对冲解除、风险偏好回升。
  - **雪球敲入水位**：标 IC 的雪球敲入区接近 → 对手盘从被动多头转空头，**结构性下跌加速器**（2024-01 IC 基差受雪球集中敲入冲击）。
  - **这是 500 择时的核心拥挤度维度。**
- **量化中性 / 公募指增拥挤度**：500 是中性策略 + 公募指增主战场——指增规模 / 超额拥挤、中性策略集中砍仓 = 流动性踩踏信号。
- **两融余额 + 融资买入占比**：融资余额 / 自由流通市值滚动分位是杠杆温度计。
- **北向 / 外资（中等参与）**：可作**辅助**资金信号，别当承重，也别完全忽略。

### 三-Z、市场情绪指数怎么用（`quant_factor` 的 `market_sentiment_*` 专项纪律）

市场情绪指数是 `quant_factor` 里加工好的**反向择时因子**（z > +0.5 情绪过热 → 偏空、z < −0.5 情绪冰点 → 偏多），是**全市场情绪打包**、不绑定标的。它**最容易被滥用**——单日 z 噪声极大、信噪比低、月度自相关弱——必须按纪律读：

1. **单日 z 是脉冲，不是趋势**：禁止把单日（或前后两天）z 翻号当建仓 / 清仓扳机。**|z| < 0.5 一律视作中性噪声带**，不投票；看的是它相对自身的滚动位置，不是单日跳动。
2. **承重的是累计趋势 + 极值，不是单日**：决策基于 5 日累计方向、20 日累计方向、z 相对自身的滚动位置（极值程度）。单日读数只用来**更新**累计判断，不直接进决策。**不要把"连续 N 日同号"当累计的替代**——计数符号 ≠ 信号强度。
3. **极值对称性铁律（最常踩的坑）**：情绪过热（z 高正）之后的**小幅回落不构成证伪**——必须等 z **累计回吞前期极值的 50%+** 才算情绪面真转向。短暂的单日回落仍在原情绪窗口内，不是反转。
4. **方向 + 维度同号才进决策**：情绪指数权重高不等于一票否决。它要降仓 / 清仓，**必须至少 1 个其他正交维度（估值分位 / 雪球·IC 拥挤度 / 盈利景气 / 信用利差）同号**；全冲突时最多降一档，不允许直接到 0%。
5. **情绪指数 ≠ 即时拥挤度**：它滞后于价格，500 的即时拥挤度看**雪球敲入 / IC 基差 / 量化中性砍仓**。**没有拥挤度数据时，情绪指数只能当辅助资金面信号、权重内部上限 1/2**——别把单一情绪代理当"流动性"全部。
6. **业绩雷期 / 跨月 / 季报窗口**：情绪指数在月末 / 年末 / 季报披露窗口有结构性扰动，单日异常值优先归因结构性，扩窗到 10 日累计读。

## 四、情绪视角（反向 + 极值）

- **GVIX / 隐含波动率**：历史分位 / z，极高 = 恐慌（反向偏多），极低 = 自满（偏空）；可参考 IC 隐含波动。
- **涨停板 / 连板高度 / 龙虎榜成交占比**：中盘投机情绪，高位偏空、低位偏多。
- **z 在 ±1 内 = 中性、不反向**，没有极端就不投票。

## 五、宏观视角

- **汇率 / 实际利率** 做环境定性，权重低。
- **信用利差 / 低评级债 spread**：风险偏好核心——spread 走阔 → 500 承压。
- **顺周期宏观**（PPI / 出口 / 制造业 PMI / 工业品价格）对 500 盈利承重（已并入盈利视角，宏观这里只做环境）。
- **政策**：制造业升级 / 专精特新 / 出口 / 设备更新政策催化中盘；过拟合纪律——因子数 ≤ √样本量（500 历史长 ~18 年，仍要克制）。

## 六、证伪视角（对称化）

证伪是**论据的破坏**，必须**对称**——既列上行风险，也列下行风险。

- **看空（偏低配）被证伪 / 上行 veto-watch**：
  - 信用利差收敛 + 社融 / M2 加速 → 风险偏好回升
  - 修正广度由负转正 + 顺周期景气回升（PPI / 工业品价格触底回升）
  - IC 深贴水快速收敛 → 对冲解除
- **看多（偏超配）被证伪 / 下行 veto-watch**：
  - 量化中性 / 雪球拥挤度突破前高、IC 深贴水 → 拥挤度风险高于估值便宜
  - 雪球敲入区临近且对冲盘转空 → 结构性下跌加速器
  - 信用利差快速走阔 + 低评级债出问题
  - 顺周期景气见顶（PPI / 有色 / 化工价格回落）+ 业绩雷期修正广度急转负
  - **情绪指数累计转向**：5 日 / 20 日累计 z 转负且 |累计 z| ≥ 1.5σ，且回吞前期 ≥1.5σ 情绪过热峰值的 50%+（单日 / 两日小幅回落不算证伪，见三-Z）

# 仓位管理方法论
## 唯一信仰：估值锚 + 流动性 / 拥挤度确认 + 正交确认 + 概率化倾斜 + 回撤控仓

- 中证500 是**估值与流动性双锚**的中盘择时——估值可信（分母不塌），但必须叠加拥挤度确认（雪球 / IC / 量化中性）。
- 不抓顶底，只做：**贵且拥挤则少配、便宜且出清则多配**，且只在 **≥2 个正交维度同号**时才加大倾斜。
- ⚠ **"≥2 同号"管的是"加大倾斜"（往显著超配/显著低配走），不是"持有任何仓位"的前置条件**。信号冲突 / 灰区 = 回归中性档（基准仓位附近），**不是回归 0%**。把"凑不齐 2 票"执行成"空仓等待"是对本条最常见、代价最大的误读——一轮趋势市里分位/温度类指标会持续投反对票，机械等共振 = 永不进场（2025 年 bot5 踏空 +30% 的实证教训）。
- 单一维度（哪怕估值极便宜）不重仓——顺周期"便宜"常是盈利顶的幻觉，必须盈利 / 流动性 / 拥挤度同号才动手。
- **中盘下行斜率**：500 单年 −30% 级别在 2018 / 2022 出现过，要及时止损，但有一定反应时间，不必草木皆兵。
- **⚠ 无 edge 品种的默认仓位（500 的定盘星，最高优先级）**：多族因子（价格趋势 / 动量 / 突破、股债性价比 erp_vix）离线筛选反复确认——**中证500 上没有任何机械择时锚能稳过买入持有**。这句话的正确推论不是"择时没用、随便做"，而是：**没有 edge 去预测时，正确的先验是吃下这个宽基的长期正漂移（持有 beta）——"看不清 / 凑不齐共振" = 持有偏高 baseline 仓位（中性档上沿及以上、贴近 beta），不是回一半、更不是空仓**。价格类只有短窗动量 / erp_vix 够格用，且**唯一职责是从高 baseline 上削尾部回撤**（确认性下行 / 拥挤踩踏时往下削一档），**绝不用来 gate 入场**——它们被验证的能力是"砍回撤"、不是"抓入场时点"。把"没有择时信号"执行成"离场等信号"，就是本品种踏空的唯一来源（负担是"要不要往下削一档"，不是"要不要进场"）。baseline 到底多高由 `USER.md` 风险性格定（机会导向 → 贴近满 beta、薄削；保本 → 低些、勤削）；研究层只锁死"无 edge 就持 beta、🟡 工具 trim-only、不 gate 入场"这个方向。

## 一、综合打分：正交维度加权 → 仓位倾斜

```
Composite_z = w_val·z_val + w_earn·z_earn + w_liq·z_liq + w_sent·z_sent + w_macro·z_macro
```

- 权重用**固定先验**（**估值 0.25 / 盈利景气 0.25 / 流动性·拥挤 0.25 三根支柱并列**，情绪 0.15、宏观 0.10）——体现 500 "估值 / 盈利 / 流动性三支柱并列"的中盘双引擎特征。**刻意不做回测拟合**：样本虽长，但每轮牛熊风格 / 雪球生态都在漂移，拟合 5 个权重必然过拟合。
- 映射到仓位倾斜（**滚动标准化后**）：

| Composite_z | 仓位倾斜 | 对应仓位区间（基准 50%） | 含义 |
|---|---|---|---|
| > +1.5σ | 显著超配 | 80–100% | 多维同号偏低估 + 拥挤度低位 + 景气改善 |
| +0.5 ~ +1.5σ | 温和超配 | 60–80% | |
| −0.5 ~ +0.5σ | 中性 | **40–60%** | 信号冲突或灰区 |
| −1.5 ~ −0.5σ | 温和低配 | 20–40% | |
| < −1.5σ | 显著低配 | 0–20% | 多维同号偏高估 / 拥挤过热 / 景气见顶 |

- **仓位语义铁律：0% 不是中性，是对"下跌"的满仓押注**。中性档 = 基准仓位 50% 附近——"看不清"的诚实表达是持有基准贝塔，而不是空仓。只有"显著低配 + 账户回撤总开关 / 拥挤硬线触发"才允许去到 0–20%，且每次复盘都要重新论证为什么还停在那。
- **单维度不可一票否决**：任何单一维度（含估值分位、温度/拥挤度）最多把档位推一档，不能单独把仓位钉死在最低档。某维度数据缺失 → 该维度权重归零、其余权重重归一化，**缺数据 ≠ 投反对票**。
- **分位类指标的趋势市自相关警告**：PE 历史分位、市场温度、"创新高"类读数在上行趋势里**必然**走高——"涨了所以贵、贵所以不买、继续涨所以更贵"是死循环。趋势市里估值维度的反对票要打折（配合盈利景气交叉验证），右侧趋势确认（站稳 MA60 + 放量）本身就是一票偏多，不能再用"跟涨非独立突破"之类的临时加戏把它否决掉。
- **置信度**：同号维度越多 → 倾斜越大；维度冲突 → 收窄倾斜、回归中性（基准仓位，非 0%）。**真正的交叉验证是跨正交维度同号，不是同源指标一致。**
- **诚实纪律**：输出只取**方向 + 档位**（中性 / 轻微 / 温和 / 显著），**不报"低配 X%"的伪精确数值**——区间内取整即可。

## 二、动态阈值，不用固定线

- 所有"贵 / 便宜""高 / 低"都用**滚动窗口 z-score 或滚动分位偏离**——中盘风格中枢漂移，固定阈值迟早失效。
- **但拥挤度有"绝对警戒线"**：雪球敲入水位、IC 深贴水某些阈值是结构性硬约束（敲入 = 机械卖盘触发），到达硬线后不要等 z 极端才行动。

## 三、估值给方向，流动性 / 拥挤度 + 趋势给择时

中证500 趋势属性中等（机械趋势不承重，见后节），估值 / 拥挤度是主锚：

- 估值便宜 + 流动性改善 + 拥挤低 + 趋势转强：**较好的加仓窗口**，分批建仓。
- 估值便宜 + 雪球敲入临近 / IC 深贴水 / 量化砍仓：**别抄**——等拥挤出清，中盘踩踏虽不及小盘但仍会超调。
- 估值与拥挤打架：拥挤度到极端硬线时拥挤优先。

## 四、回撤控仓（中盘命脉）

- **账户级净值回撤是高于单笔信号的总开关**：从峰值明显回撤就降仓 / 暂停加仓，哪怕维度信号还没转向。
- 500 的回撤数学：单月 −10% 不稀奇、单年 −30% 级别历史多次（2018 / 2022）；**先想最多能承受多少回撤，再反推该不该降仓**。
- **雪球敲入踩踏期 = 优先保命**：当 IC 深贴水 + 量化中性砍仓 + 两融去杠杆同时出现，仓位先砍、事后再分析（2024-01 IC 也受敲入冲击）。
- **踏空对称条款（与回撤控仓同等地位）**：回撤控仓护的是已有仓位，它的对称面是**空仓拖延**。处于低配/空仓时，每次周期决策必须写明"今天不进场的论据 + 什么数据会证伪它"；**同一条论据（如"等站稳 MA60"）最多沿用 2 个决策周期**——第三次还在用它，要么拿出新数据换论据，要么按档位表回到中性基准仓位。论据到期不续 = 必须行动，"继续等"不是合法选项。账户连续跑输买入持有且仓位长期 <20%，与"持仓回撤穿阈值"同级别触发方法论复审。

## 四-B、主动止盈（拥挤抬头 + 吊灯线，独立于信号反转）

回撤控仓护**已亏损**的尾巴，止盈护**未兑现**的浮盈——两者独立。500 的止盈触发器挂**拥挤抬头 + 偏离度 + 吊灯线**：

- **拥挤抬头**：指数 vs MA60 偏离 ≥ +15% → 主动减一档（20%）兑现。
- **吊灯线（移动止盈）**：从**持仓最高净值**回撤 ≥ 5% → 砍一档，独立于趋势均线。利润越厚跟得越紧。
- **保本线**：账户浮盈 ≥ 10% 后，把离场线抬到成本价——本金风险清零，剩余利润再跑。

## 五、成本意识

- ETF / 基金的申赎费 + **7 日内早赎 1.5% 惩罚**——一笔进出要赚回成本才值，避免同标的 7 日内 round-trip。
- 500 信号噪声中等——单月调仓次数设硬上限，没到信号档位不动。

## 五-B、thesis 持续性窗口（最少持有 3 个交易日）

- 每个仓位档**至少持有 3 个交易日**——期间只有 ① 趋势转空 ② 账户回撤穿阈值 ③ 四-B 止盈触发 三类信号才允许跳档。
- 单日情绪指数 z 翻号、单日量化拥挤抖动**不打破持有窗口**——昨日 thesis 不该被单日噪声证伪。

## 六、防过拟合 / 数据诚实纪律

- 维度数压到 **≤ √样本量**；样本不足时诚实退回固定先验 / 等权，不硬拟合。
- 🔴 来源（散户回测、无署名"资料"）只能**提假设，不作结论承重**。
- 所有数字标 **source / as-of / 口径**；矛盾处标 `{{待核}}`，核验前不进决策。

## 七、实战判断：环境决定用哪条

格言大多成对矛盾。中证500 的环境抓手是**动态估值 + 顺周期景气 + 雪球 / IC 拥挤度**。

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 估值便宜该加 | 周期顶的便宜是假便宜 | 看 **ROE / PPI 是否同步见顶**，盈利不在周期高点才加 |
| 别人恐慌我贪婪 | 雪球敲入不接刀 | **IC 基差 + 雪球敲入 + 量化中性**确认踩踏结束才贪婪 |
| 雪球 / 量化拥挤是顶部信号 | 量化是新增买盘利好 | 看**增速 vs 水位**：水位高 + 增速放缓 = 危险 |
| 顺周期景气要追 | 景气已透支 | 看修正广度**方向** + 工业品价格是否见顶 |
| 情绪指数信流动性铁律 | 情绪指数单日噪声不能硬触发 | **看累计、不看单日**：5/20 日累计 + 极值 z 才进决策；情绪过热后的小幅回落默认是噪声，要等回吞≥前期极值的 50% 才算反转（见三-Z） |
| 宁可踏空不接飞刀 | 踏空也是真实亏损 | 看**论据时效**：暴跌进行中（趋势破位 + 拥挤踩踏未出清）才适用"不接飞刀"；趋势已确认转强（站稳 MA60 + 多维企稳）还在喊"不追高"= 拿熊市格言套牛市，按四的踏空对称条款强制回中性档 |

### 关于 `quant_factor`（诚实说明）

研究室目前**未注册中证500 专属择时因子**。可用的客观第二意见：

- **`market_sentiment_15_90` / `_20_90`（市场情绪指数，反向择时）**：`quant_factor` 里加工好的全市场情绪反向因子（非 500 独有），可作弱第二意见——z 为正（情绪过热）反向偏空、z 为负（情绪冰点）反向偏多；|z|<0.5 视作噪声，需连续 2 日同侧才进决策，读法见上「三-Z」。
- **价格类择时锚（donchian / dd_ladder / 突破）在 500 上跑不赢买入持有——无绿灯、不作择时承重**：500 杀跌偏温和、降仓省得少却错过反弹，机械趋势在均值回归的中盘宽基上反复 whipsaw。**唯一够格的价格工具是短窗动量（约 10–20 日）与 erp_vix，且只作 🟡 降回撤辅助**——它们能明显压低回撤、大体不牺牲收益，但时间一致性不足、稳不成绿灯，**只用于从高 baseline 往下削尾部风险，不承重、不 gate 入场**（用法见仓位节「无 edge 品种的默认仓位」定盘星）。**总纲：500 的方向重心放估值 / 盈利景气 / 拥挤度，价格工具只削回撤、不定入场。**

> **核心一句**：中证500 靠**动态估值 + 顺周期景气**给方向、**雪球 / IC 拥挤度 + 正交维度同号**给置信度、**固定先验 + 概率化倾斜 + 回撤控仓**给仓位——两个择时引擎都要开：能信估值（分母不塌），但必须盯拥挤（雪球 / IC / 量化中性）。贵且拥挤则避、便宜且出清则进，不抄踩踏、不伪精确、靠纪律压回撤。**择时无绿灯 → 默认持 beta：看不清就在场（偏高 baseline），短窗动量 / erp_vix 只 trim 尾部回撤、绝不 gate 入场——把"没信号"执行成"离场"就是 500 踏空的唯一来源。**
