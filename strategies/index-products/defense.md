# 中证军工指数投资框架（方法论）

这是研究视角，不是执行手册。拿到当日数据后，**先做〇节的环境三问（永远的第一步）**，再依次过各视角，自行综合判断该不该动、动多少——框架给坐标系，不给触发器。

- 标的：**中证军工（399967.SZ）**——从十大军工集团控股 + 主营军工的代表性公司里选样，70–80 只成分、前十大权重合计不足三成，是 A 股军工行业的**全口径、分散化敞口**（航空 / 船舶 / 兵器 / 军工电子 / 导弹航天多链并存）。

## 核心认知

军工 = **国防预算（行政订单）× 装备列装周期 × 事件 / 地缘催化 × 叙事弹性**的题材—周期混合赛道。它和市场化定价的工业品**不是一套玩法**——军工的需求端是**国家国防开支与装备采购计划**，下游高度集中（军方）、定价受管制、订单以多年期合同分批确认。五个特性决定怎么玩：

- **需求是行政订单，不是市场化供需（最核心认知）**：军费预算增速（年度两会公布）、五年规划（十四五收官 / 十五五开局的装备放量节奏）、装备列装与换装周期，是需求端最强变量。**判军工景气先看预算 + 规划 + 订单，不看下游民用 PMI。**
- **订单的财务映射是合同负债 / 预收款 — 军工独有的领先信号**：军工大额订单在财报上先体现为**合同负债、预收账款、存货 / 在产品**的抬升，远早于营收 / 利润确认。**合同负债 / 预收款的同比拐点，是本指数最可靠的景气领先指标**，比当期净利重要得多。
- **子板块严重分化，指数是一篮子**：航空（主机厂 / 航发 / 机载）跟列装与航发换发周期；船舶跟海军造舰与民船周期叠加；军工电子（元器件 / 雷达 / 芯片）跟信息化渗透率 + 国产替代；导弹 / 兵器 / 航天各有独立订单节奏。**同一时刻可能航空在炒列装、军工电子被国产替代驱动、船舶平淡——不能用一个故事解释整个指数。**
- **事件 / 地缘是脉冲源，单日跳空大**：地缘冲突（台海 / 俄乌 / 中东）、大型阅兵、军贸出口落地、低空经济 / 无人化作战 / 商业航天等新叙事——是政策 / 事件端的脉冲，方向跳空密集，且多为"先涨叙事、后等订单兑现"，纯叙事段杀得最狠。
- **高 β、深回撤、趋势不持续**：军工由政策 / 事件驱动、缺乏持续的产业趋势，**行情多是脉冲 + 回吐的箱体级波动**，单边趋势段短而少。这一条直接决定择时打法（见二节）——**机械趋势 / 突破因子在本指数无效**，回撤控制全靠纪律。

驱动排序：**国防预算 / 五年规划（行政需求）≥ 订单 / 合同负债拐点 > 子板块景气（列装 / 国产替代 / 造舰）> 事件 / 地缘催化 > 估值**。研究时先问三件事：

1. 预算 / 规划有没有新动向？装备采购是放量还是收敛？→ 决定需求中枢方向
2. 龙头合同负债 / 预收款 + 在手订单在什么趋势？景气是兑现还是只在叙事？→ 决定景气真假
3. 当前是哪个子板块在定价、是事件脉冲还是订单驱动？→ 决定现在加还是减、追不追

宏观利率 / 风格虽是底色，但**军工对宏观经济周期的敏感度有限**——它的母变量是**国防开支 + 装备周期**，不是社会总需求。别用"经济复苏—顺周期"框架硬套军工。

## 〇、先判市场环境（永远的第一步）

三问答完并**显式留痕**（写进当日复盘，次日继承），才允许进任何加减仓决策。

**1）全市场风险偏好：A 股现在给不给高 β 题材活路？**
军工是风险偏好放大器，事件脉冲对偏好**更**敏感——收缩期脉冲几乎没有持续性，预设一日游。用 `macro_50etf_vix`、市场情绪因子（看累计与相对位置、不看单日）、大盘趋势判：**扩张 / 收缩 / 中性**；收缩期所有看多信号自动降档。

**2）板块状态：趋势市 / 震荡市 / 过渡待定（三选一）**
长均线排列与箱体识别常规判法。两条专属提醒：**事件脉冲的单日大阳不算状态切换证据**（军工"大阳后回吐"是常态）；状态有粘性，默认继承昨日结论，只问"有没有确认级证据推翻它"。**注意军工天然偏震荡，趋势市认定门槛要更高——需放量有效突破 + 订单 / 预算基本面同向，否则按震荡 / 过渡处理。**

**3）主驱动识别（军工最要紧的一问）：今天谁在定价？三分法：**
- **订单 / 景气驱动**：合同负债 / 预收款抬升、列装 / 造舰 / 国产替代有兑现、龙头业绩跟上 → 入景气链、可承重。
- **事件 / 地缘脉冲**：地缘冲突 / 阅兵 / 军贸 / 新叙事驱动、题材标的领涨而业绩龙头不跟、无订单增量 → 不入景气，按四节单独评估，预设回补。
- **风格 / 资金驱动**：无基本面与事件增量，纯属大盘风格切换 / 主题资金轮动带动 → 跟大盘风险偏好走，独立性弱，谨慎追。
判据 = 子板块强弱 + 领涨成分类型 + 文本增量归类，一句话留痕。

## 一、估值视角（禁 PE 均值回归，用订单可见度 + PB）

军工是**订单驱动 + 盈利 lumpy（合同分批确认）**的行业，**禁止把 PE 当价值锚做均值回归择时**：

- **PE 陷阱**：军工净利随订单确认节奏跳变——交付大年盈利 E 顶、PE 看似低；订单空窗 / 研发投入期盈利坍塌、PE 冲高甚至为负。**低 PE 未必便宜、高 PE 未必贵，PE 分位在本指数当择时扳机不可靠。**
- **主用 PB + 订单可见度**：PB 比 PE 稳；但军工真正的"价值标尺"是**在手订单 / 合同负债 / 预收款给出的未来收入可见度**——可见度高 = 重仓信心足，可见度枯竭 = 再低的 PB 也不接。PB 与订单可见度都**只做定性预警，不做择时扳机**，且分位对订单周期滞后。
- **样本可用但分位非择时锚**：军工历史够长、分位可算，但只用于"是否进入泡沫区 / 深熊区"的**定性判断**，不做"低 PE 抄底 / 高 PE 减仓"的机械操作。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给订单 / 预算 / 事件 + 状态框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。极端读数仍是要认真对待的定性信号。

估值在这里只做两件**定性预警**（不是择时扳机）：

- **极端泡沫预警（顶）**：PB 顶部分位 + 地缘 / 阅兵 / 新叙事全民进场（题材出圈、主题基金发行火爆、研报高喊"军工大周期 / 万亿空间"）+ 订单兑现却跟不上叙事 → 配合状态框架减仓。**特别警惕"纯事件脉冲推到顶 + 业绩龙头不跟"组合，那常是最后一波。**
- **周期反转预警（底）**：出现 **预算 / 规划放量预期 + 龙头合同负债 / 预收款同比回升 + 列装 / 造舰订单落地 + PB 接近底部分位** 等反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**预算 / 订单 / 合同负债证据**，不是低 PE 或低 PB 分位（分位对订单周期滞后）。

## 二、趋势视角（关键：机械趋势 / 突破因子在本指数无效）

趋势研判别只看一根均线，多角度交叉验证。**军工还要额外把预算 / 订单方向纳入**——板块趋势与订单 / 预算趋势背离时，以后者为主参考（行政订单常领先股价）。

- **方向锚（双层）**：
  - 板块层：指数 vs 200 日均线（收盘价即可算均线 / 时序动量）+ 均线斜率
  - 订单 / 政策层：预算 / 规划方向 + 龙头合同负债 / 预收款拐点——**这层是军工独有的，常领先股价**
  - **两层共振时信号最强；只有指数涨而订单 / 合同负债平、预算没动 → 题材脉冲，须谨慎。**
- **量能确认（板块代理）**：指数无量 → 用 `sector_factor` / `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破。
- **波动率（板块代理）**：收盘价滚动波动率 + 板块乖离；波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：地缘 / 阅兵 / 军贸 / 新叙事消息常造成跳空，**默认情绪级**——次日去研报纪要找订单 / 基本面增量，找到才升级为逻辑级顺势；找不到一律当脉冲，不追价。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）

> **本指数的择时定级要点：机械趋势 / 突破类因子在这里不承重。** 研究室已验证**机械趋势 / 突破类因子（donchian 通道突破等）在本指数无效**——军工由政策 / 事件驱动、缺乏持续趋势，趋势系统会被脉冲假突破反复打脸（whipsaw），收益不优于裸持有。**这是已证伪的结论，不要把趋势突破因子当主信号，也不要重挖。** 下列指标只能作**降回撤辅助 + 客观第二意见**，方向裁决权交回订单 / 预算 / 事件框架。读数可用收盘序列按公式自算（**信号按当日收盘计算、下一交易日 T+1 执行，不偷看当日盘后即时成交**）。

- **`trail_dd` 回撤止损族（辅助断后，本指数的主力机械工具）**：收盘从过去约 120 日滚动峰值回撤超一档 → 降仓 / 空仓，站回均线 → 回归；多一档梯度的版本（如回撤 ≥7% 砍半、≥15% 清仓）降仓更早。**纯收盘价可靠、无代理失真**，在本指数职责是"框架犹豫时给一个客观的先降一档线" + 躲过深熊段——**是降回撤工具，不是收益增强器，更不抓顶底**。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；只看价格，对订单 / 预算 / 地缘拐点零预警。
- **`erp_vix` 估值锚（弱二意见）**：股债性价比 + VIX 极值是震荡品种缺乏趋势信号时的退路；但**军工盈利 lumpy、ERP 的盈利分母不稳，估值锚在本指数远不如在大盘价值上可靠**——只作极端区（极度便宜 + 系统性恐慌 / 极度贵 + 全民自满）的定性第二意见，不当承重信号、不据此机械加减仓。
- **时序动量（仅快读，不承重）**：20 日动量可作"价格面还在不在多头"的快读数；但本指数趋势不持续，动量翻转在震荡里多是噪声，**〇-2 判定震荡市时默认当噪声，不据此动仓**。

**共同纪律**：本指数没有"绿灯主因子"——择时主轴是**订单 / 预算 / 事件的定性多维判断**，价格类因子只做降回撤断后与客观第二意见。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。

## 三、景气度视角（军工专属：预算 + 订单 / 合同负债 + 子板块为母变量）

军工的景气有**清晰但带行政色彩的传导链条**，按性质分四类，别用滞后指标做择时（取数见上「取数映射」节）：

- **领先（母变量）**：
  - **国防预算 / 五年规划**——军费增速、装备采购计划、列装 / 换装节奏（**需求端最强变量，行政意志，常领先订单**）
  - **订单 / 合同负债 / 预收款**——龙头合同负债 / 预收款 / 存货同比拐点，是订单的财务前瞻，**领先营收利润数个季度**
  - **子板块景气**——航空（列装 / 航发换发）、船舶（造舰）、军工电子（信息化渗透 + 国产替代）、导弹兵器航天各自的订单节奏
  - 多档同向时信号最强（预算放量 + 合同负债回升 + 列装提速 = 景气主升）。
- **滞后（确认而非择时）**：军工企业营收 / 净利 YoY + 一致预期修正，跟随订单确认 1–数季反映，**不当择时锚**——等盈利确认转向就晚了。
- **结构 / 上限**：龙头在产业链的卡位（主机厂 / 航发 / 核心元器件的稀缺性）、产能与交付能力——决定龙头穿越周期能力与重仓信心，不决定主趋势开关。
- **事件驱动**：地缘冲突 / 阅兵 / 军贸大单 / 重大列装 / 新叙事（低空 / 无人化 / 商业航天）——跳空催化，事件级单独评估。

判断要点：

- **预算 + 规划是母变量**：看军费增速与五年规划的装备放量节奏，定需求中枢；规划落地节点（开局放量 / 收官冲刺）常领先订单。
- **合同负债 / 预收款是高频领先指标**：订单先进合同负债，再转营收利润。**看合同负债 / 预收款同比方向，不看当期营收**（营收滞后）。
- **分清"订单兑现"与"事件叙事"**：列装 / 造舰 / 国产替代是可验证的真景气；**地缘 / 阅兵 / 新作战概念是弹性最大但兑现最远的叙事**——叙事撑估值，订单撑业绩，行情切换时区别对待。
- **看的是趋势一致性**：预算 + 订单 + 子板块景气同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**。

## 四、事件 / 政策驱动视角（军工权重最高的一节）

这是军工区别于一般行业的**专属维度**——它的定价被政策 / 事件驱动的程度远高于一般景气逻辑：

- **国防预算 = 需求端母变量（最强）**：年度军费增速、五年规划装备采购指标。**预算是军工需求的"水龙头"**——放量抬需求、收敛压预期。判军工需求先看预算 / 规划。
- **列装 / 换装周期 = 中周期景气器**：航发换发、新型号列装、海军造舰节奏——决定多年期订单的释放速度，是配额之外的结构性放量来源。
- **地缘 / 军贸 = 脉冲催化（双刃）**：台海 / 俄乌 / 中东等地缘冲突、军贸出口落地——**单日跳空大**，要分清是**逻辑级（提升实际订单 / 出口预期）**还是**情绪级（避险脉冲、无订单兑现）**：前者可顺势，后者易回补。
- **新叙事 = 弹性最大但兑现最远**：低空经济、无人化 / 智能化作战、商业航天 / 卫星互联网——题材出圈能打出大脉冲，但兑现路径远；评估三问：**有无订单 / 收入兑现路径？时间表多远？涨的是基本面还是纯叙事？** 兑现路径出现前按情绪脉冲处理（已持仓顺势交给止盈，空仓不追）。
- **政策双刃，穿透到方向**：改革 / 反腐 / 降本（短期压预期）vs 预算放量 / 规划落地 / 资产注入（抬预期）——同一"政策"对方向相反，**必须穿透到具体是抬需求还是压预期**。
- **事件前管敞口**：两会预算节点 / 重大阅兵 / 地缘关键窗口前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。

## 五、文本视角（研报 + 纪要，每日必读、最高优先级）

> 工具：`research_search` / `research_view` + `zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（纪要 PIT 截断到当日）。**每个交易日必须执行，不许跳过**——哪怕当天不动仓位；其他视角缺数据可降级，这个视角不读完不收工。
>
> **为什么文本面是本指数超额的主要来源**：把母变量排一遍——预算 / 规划、订单 / 合同负债动向、列装 / 造舰节奏、地缘 / 军贸、新叙事——**几乎没有一个是高频结构化数据**，全活在研报 / 纪要 / 政策原文里。结构化口径只剩价格、板块代理和季度财报，而纯价格因子在本指数的结论是"只能降回撤、给不了方向领先性"（见择时指标节）。丢掉文本面，这套框架就只剩一台跟在行情后面的回测脚本。

### 读法纪律（文本是信息也是毒药）

- **读事实与方向，不抄结论**：纪要 / 研报是事实源 + 关注度代理，不是买卖建议。
- **领先性分层**：预算原文、规划文件、中标 / 订单合同、合同负债财报科目 = 领先信号，承重；研报观点 / 目标价 = 滞后情绪代理，只做密度统计。
- **题材文本专项纪律**：地缘 / 新叙事类文本叙事浓度高、可证伪点少，只认三类硬事实——**政策 / 预算原文、签了字的订单 / 中标、列装 / 交付落地**；"空间测算 / 产业链梳理"一律记作情绪密度，不进证据链。
- **一致看多逆向读**：趋势成熟期是反向信号、行情起点是领先信号——属于哪种，回〇节当场定，不设机械线。
- **证据落链（硬性）**：当日 belief / 复盘 evidence 至少 1 条文本条目（INFOCODE / topic_id + 一句话摘要）；没增量如实写"今日文本面无增量"。没有检索记录不许引用"听说 / 市场传言"。
- **权重边界**：文本给方向与证伪，不直接给仓位数字，不得突破回撤控仓与最小步长纪律。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **预算 / 规划证伪（下行，最关键）**：军费增速大幅放缓、装备采购计划收敛 / 推迟、改革降本压制——需求逻辑被推翻。
- **订单 / 合同负债证伪（下行）**：龙头合同负债 / 预收款同比连续转降、在手订单消化无新单接续——景气前瞻被推翻。
- **子板块景气证伪（下行）**：列装 / 造舰 / 国产替代节奏连续不及预期；新叙事被证伪（时间表后移、用量大幅下修）。
- **趋势证伪（下行）**：指数跌破 200 日均线且 1 月未收回，但应根据当时市场环境修正指标；`trail_dd` 回撤族触发 = 价格面确认走坏。
- **估值证伪（下行，反向）**：PB 顶部分位 + 纯事件脉冲推到顶 + 业绩龙头不跟 + 卖方高呼"军工大周期"——题材顶部最危险信号组合。
- **看空被证伪（上行 veto-watch）**：预算 / 规划超预期放量；龙头合同负债 / 预收款同比回升；列装 / 造舰 / 军贸大单落地；地缘升级提升实际订单 / 出口预期；龙头盈利下修结束 + 趋势企稳——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 军工是**行政订单 + 事件驱动 + 高 β 深回撤**的题材—周期赛道，趋势不持续、脉冲后回吐凶。单指数策略的提升，几乎全部来自**压低最大回撤 + 主驱动识别的正确率**，不是靠趋势预测。你的活儿是订单 / 预算转向、事件脉冲退潮、系统性风险来时少亏，主升段在场吃足，脉冲日不被勾引。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法；**但"合法"是双向的：信号不支持在场时空仓完全正常、不必愧疚，信号支持在场时却空仓 = 踏空、同样违规**。不为了在场而在场，也不为了"稳妥 / 留子弹"而缺席。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把回撤控仓的事后闸门误用成事前枷锁。
- **该在场时别缺席，这是和"别一把满仓"对等的硬约束，不是软提醒**：当 **主驱动 = 订单 / 景气驱动 + 趋势多头 + 预算 / 合同负债至少一项同向**（核心共振成立、且 `trail_dd` 未触发）时，**默认目标就是重仓到满仓**；此时仍要轻仓或空仓，**必须当天写明一条具体的、命名的减仓理由**——只能取自〔震荡市已认定 / 波动骤增 / 事件窗口跳空风险 / 纯叙事脉冲无订单兑现 / 净值回撤闸门已触发 / 某条证伪已命中〕之一。**写不出具体理由 = 该满仓而没满 = 踏空失分；"留点子弹""感觉有点高""谨慎起见"都不算理由，那是自我设限。** 在场与否只看订单 / 景气 / 趋势与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（订单空窗期的低 PE 是陷阱）。
- 不用硬止盈硬止损——择时交给订单、趋势、回撤说话，不交给固定数字（但**机械回撤止损 `trail_dd` 在本指数是断后命脉，不是可选项**）。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源——尤其军工天然偏震荡，错把脉冲当趋势是头号坑。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势、且订单 / 预算同向"**（趋势市），还是**"涨上去就回来、跌下去又弹、事件脉冲后回吐"**（震荡市，军工的常态）？

- **识别标准**：
  - **趋势市（门槛要高）**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且订单 / 合同负债 / 预算方向同向、放量有效突破**。军工单纯价格突破不够，必须有基本面同向才认趋势。
  - **震荡市（默认状态）**：200 日均线走平 + 价格在均线 ±10–15% 内来回 + 箱体反复假突破 + **订单 / 景气无新增量**——脉冲驱动、无持续趋势，按防守打。
  - **过渡待定**：信号不清、板块趋势与订单 / 预算背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（订单转弱 / 预算收敛 / 趋势破位 / `trail_dd` 触发）就降仓乃至清空。别在趋势里高抛低吸。
  - **震荡市 → 防守、轻仓**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（订单落地 / 预算放量）即交接给趋势骨架。**事件脉冲的单日大阳不算突破确认**——看次日承接与业绩龙头是否跟随。

**状态要有粘性——不是一天震荡、一天趋势地翻**：

- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（地缘 / 事件最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日 + 订单 / 预算同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 订单转弱 / 主驱动逆转确认 / 趋势转空 / `trail_dd` 触发 → 一把清到位，可以直接到 0**：军工下跌常加速（脉冲资金踩踏 + 叙事退潮叠加），等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。军工的高赔率组合是 **预算 / 规划放量 + 合同负债回升 + 列装 / 订单落地 + 趋势放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）：低赔率时，带损失的下注代价高于错过，所以宁可观望**——但这只约束低赔率情形；**高赔率时正相反：踏空没有止损、错过的 Beta 不会回来，代价上不封顶，轻仓 / 犹豫才是真正的"做错"，即失分。**
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高，尤其追事件脉冲高位），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。
- **脉冲专条**：事件 / 地缘脉冲不构成回补理由；脉冲驱动的浮盈，兑现节奏应快于订单驱动——脉冲的利润窗口天然更短。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 三、止盈止损：用订单、趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯三件事：**趋势破没破（含订单 / 预算方向）** + **从持仓高点回撤了多少（`trail_dd` 给客观刻度）** + **订单 / 景气有没有见顶反转**。趋势还在、回撤温和 → 拿住让利润跑；趋势破位 / 回撤明显放大 / 订单转弱 → 大块兑现乃至清空。
- **主升尾段主动止盈**：拥挤极端 + 估值顶部预警 + 文本面一致看多三者叠加 → 收紧离场线，不等流动性反转。
- **三个桥梁工具**：**保本止损**（浮盈 ≥ 10% 后把离场线抬到成本价，本金风险清零）、**移动止盈**（保护线随新高只升不降，机械化即 `trail_dd`）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。** 亏损端窄而果断、浮盈端宽而敢加，两套口径别混用。

## 四、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。军工单边跌起来很容易摸到深水区（脉冲退潮 + 高 β），这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关，`trail_dd` 正是这条的机械化身。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第二条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第二条回补。

## 五、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有早赎惩罚费率**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高——**别把震荡里的脉冲诱惑当指令逐次执行**，那会被早赎成本吃掉。
- 每个仓位档**至少持有数个交易日**；期间只有趋势转空、账户回撤穿阈值、止盈触发三类信号允许跳档，单日情绪与跳空不打破持有窗口。

## 六、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的状态、订单 / 合同负债、预算 / 规划方向、事件 / 地缘性质（兑现 vs 叙事）、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 订单空窗 PE 最低（PE 陷阱） | 军工**永远看 PB + 订单可见度 + 合同负债**，不靠 PE 均值回归择时 |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 订单 / 合同负债配合看 B；趋势破位 / 订单转弱时极端读数当定性预警 |
| 地缘冲突是利好 | 地缘脉冲不兑现就是泡沫 | 看**有无订单 / 出口兑现路径**：提升实际订单看 A（顺势）；纯避险脉冲 + 业绩不跟看 B（回补） |
| 预算放量该乐观 | 改革降本要谨慎 | 看政策**方向**：军费增速 + 装备采购放量看 A；改革 / 反腐 / 降本压预期看 B |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**合同负债 / 订单方向**：领先端仍向下看 A，领先端（合同负债 / 预收款）回升（盈利滞后）看 B |
| 新叙事是星辰大海 | 叙事不兑现就是泡沫 | 看**订单 / 时间表有没有兑现**：订单落地看 A，纯叙事 + 业绩不跟 + 全民进场看 B（泡沫顶） |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但订单 / 预算逻辑没坏看 A，订单转弱 / 趋势破位的单边下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A；冲高乏力 / 订单见顶 / 叙事退潮 / 量价背离看 B |

> **核心一句**：中证军工——先判环境与主驱动（订单 / 景气驱动 / 事件脉冲 / 风格资金，每天第一问），用 **国防预算 + 订单 / 合同负债 + 子板块景气** 判景气、用 **PB + 订单可见度** 判空间（**别靠 PE 均值回归**）、机械趋势 / 突破因子已证伪不当主信号、只用 **`trail_dd` 降回撤断后 + `erp_vix` 极端区弱二意见**、用 **大开大合 + 压最大回撤** 做仓位；事件脉冲只认政策原文 / 订单 / 列装三类硬事实、不追脉冲、信号不支持空仓不愧疚 / 信号共振该满仓不手软，夏普靠主驱动识别正确率和压回撤做上去，不靠预测的勇气。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新作战概念、新军贸形态、资产注入 / 改革新结构）。
- **定期 + 事件驱动**：一轮装备周期或五年规划节点做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对航空 / 船舶 / 军工电子 / 导弹兵器的差异化打法、择时因子定级（若复核更新 trail_dd / erp_vix 的定级，照实改）。
- **不轻易动（信仰与原则层）**：唯一信仰（预算 / 订单放量 + 趋势确认重仓、订单转弱 + 转空降仓）、预算 / 订单 / 合同负债是母变量、机械趋势 / 突破因子在本指数无效、PB / 订单可见度判空间不靠 PE 均值回归、风险优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空、对本金保守对 Beta 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；预算体制改革、装备采购模式重构、重大资产注入是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
