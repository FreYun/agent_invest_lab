# 保险主题指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证方正富邦保险主题指数（399809.SZ）**——保险行业 + 参股保险类公司里选约 18–20 只，保险主业单票上限 30%、参股类上限 3%，每半年调样。**五大上市险企合计约八成权重，中国平安长期顶格约 30%**——这是一个高度寡头集中、由 3–5 家头部险企主导方向的指数。

## 核心认知

保险主题（399809）= **长久期利率敏感 × 权益市场弹性 × 寿险负债周期**的三重耦合。它是 A 股里基本面**最复杂、最反直觉**的板块——利率对它的影响是双向的、权益对它的利润是放大的、负债端的价值要看几年后才兑现。五个特性决定玩法：

- **利率影响是双向的、容易看反**：长端国债收益率下行，**短期**压制保险（再投资收益率下降 + 利差损担忧加重，这是压制保险估值多年的主线），但**对存量债券是浮盈、对当期投资收益是利好**；利率上行则相反（利好新增配置 / 缓解利差损，但存量债浮亏）。**不能简单说"降息利好/利空保险"——要分清打的是利差损担忧（情绪 / 估值）还是当期投资收益（利润），方向可能相反。** 这是本指数最容易判断错的地方。
- **权益市场是利润的放大器**：保险资金有相当比例配置权益，**牛市里投资收益暴增、利润高弹性**（保险股大涨年份的利润超高增主因几乎都是投资端）；熊市里投资收益拖累。所以保险既是"利率板块"，又是"权益 β 的二阶放大器"——权益市场好的时候它跟着涨且弹性更大。
- **新业务价值（NBV）是负债端的领先指标**：寿险的长期价值看 NBV（新签保单的利润现值），NBV 增长 = 负债端健康、未来利润有源；NBV 是半年 / 季频数据，**领先于报表利润**，但口径复杂（内含价值 EV、剩余边际等），可得性低、专业度高。
- **极高寡头集中，方向看平安 + 太保 + 国寿**：五大险企（平安 30% / 太保 23% / 国寿 12% / 新华 10% / 人保 5%）合计约八成，**中国平安单家顶格 30% 就能左右指数方向**。这不是宽基，是"几家头部险企的加权"——必须穿透到平安 / 太保 / 国寿看（综合金融 / 寿险 / 财险结构不同）。
- **预定利率 / 负债成本是利差损的另一半**：利差损 = 投资收益率 − 负债成本。监管下调预定利率、险企重塑产品（分红险替代传统险）是从负债端缓解利差损的关键——**负债成本下行和投资收益率企稳，是利差损担忧解除的双重证据**。

驱动排序：**长端利率（双向，需辨方向）+ 权益市场表现 + 利差损预期（NBV / 预定利率 / 负债成本）> 趋势 / 资金 > 估值（PB / PEV 分位）**。研究时问三件事：

1. 利率在往哪走、打的是利差损担忧（估值）还是当期投资收益（利润）？权益市场什么状态？→ 决定方向。
2. 利差损预期在缓解还是加重（NBV / 预定利率下调 / 负债成本）？→ 决定能不能重仓、是不是估值修复起点。
3. 趋势 / 资金对不对？→ 决定现在是加是减。

## 一、估值视角（PB / PEV 分位，PE 受投资收益失真）

保险盈利里投资收益占比大、波动剧烈（权益市场好坏直接放大 / 拖累利润），**PE 在保险身上严重失真**——权益牛市利润暴增 PE 显低、熊市利润坍塌 PE 飙高。主用两个锚：

- **PB 分位**：保险净资产相对稳定，PB 分位是基础赔率标尺；保险股长期 PB 在一个区间震荡，龙头平安的 PB 常处五家中偏低位（综合金融折价）。
- **PEV（P / 内含价值）**：保险专属估值锚，内含价值 = 调整净资产 + 有效业务价值；PEV < 1 常被视为低估。**但 EV 口径依赖精算假设（投资收益率假设、贴现率），利差损担忧重时市场会怀疑 EV 的含金量、给折价**——所以低 PEV 不等于便宜，要看市场信不信这个 EV。
- **利差损担忧是估值的总闸门**：保险多年估值压制的核心不是当期盈利，而是市场担忧"长期投资收益率覆盖不了负债成本"（利差损）。**利差损担忧不解除，低 PB / 低 PEV 可以持续；担忧缓解（投资端企稳 + 负债成本下行），估值才修复。** 这条比任何分位都承重。

估值做两件**定性判断**的事：

- **估值修复起点（底）**：低 PB / 低 PEV + 利差损担忧出现缓解证据（长端利率企稳 / 权益市场回暖带动投资收益 / 预定利率下调降负债成本 / NBV 增长）→ 记为**潜在修复观察**（持久观察态，写进记忆续到明天），趋势企稳就按骨架回补。
- **上行收敛预警（顶）**：PB / PEV 修复到中高位 + 权益市场过热 + 利率风险（上行压存量债浮盈 / 或下行重燃利差损）→ 安全垫变薄，逐步兑现。
- **在上升趋势中，高估值绝不构成减仓理由——"趋势 > 估值"是单向过滤器**；保险估值修复行情（利差损担忧解除 + 权益放大利润）里 PB 修复仍能继续，别用估值高去 fade。

## 二、趋势视角

- **方向锚**：指数 vs 200 日均线 + 均线斜率；时序动量辅助。**但本指数趋势性弱于券商**（见三节量化辅助），趋势权重低于利率 + 权益 + 利差损判断。
- **与利率 / 权益的关系**：保险趋势常跟随两条外部线——长端利率方向（利差损情绪）+ 权益市场方向（投资收益）。**指数自身趋势与这两条背离时，以利率 + 权益的母变量为准。**
- **量能 / 拥挤度（板块代理）**：指数无量 → `sector_factor` 拥挤度代理；保险拥挤度极端 + 权益过热是顶部组合。
- **事件跳空甄别**：利率大幅波动、预定利率调整、权益市场大涨大跌、龙头业绩 / 监管事件常造成跳空，分清**逻辑级**（利差损预期 / 负债成本被真实改变）还是**情绪级**。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、基本面景气视角（保险专属：利率 + 权益 + 利差损为母变量）

保险的"景气"是三条耦合线，按性质分层：

- **领先 / 同步（母变量）**：
  - **长端国债收益率**——双向影响（见核心认知），是利差损情绪与投资收益的总开关；**判断时先定方向含义**：利率下行重燃利差损担忧（估值利空）但利好存量债浮盈（利润利好），利率企稳 / 温和上行缓解利差损（估值利好）。
  - **权益市场表现**——保险资金权益敞口的放大器，权益涨 → 投资收益暴增 → 利润高弹性（同步）。
  - **预定利率下调 / 负债成本**——从负债端缓解利差损的领先政策信号（预定利率下调 → 新单负债成本降 → 利差损压力减）。
- **滞后（确认不择时）**：
  - **新业务价值 NBV**——负债端长期价值，领先报表利润但本身半年频；NBV 增长确认负债端健康。
  - 报表净利润——投资端主导、波动大，等它确认方向已走一段。
- **结构（决定弹性）**：平安（综合金融 + 科技 + 银行，逻辑最杂）/ 太保（寿险 + 财险均衡）/ 国寿（纯寿险，最纯利率 + 权益敏感）/ 新华（高弹性）/ 人保（财险为主，逻辑偏车险 + 非车）——同一时刻五家弹性 / 逻辑不同，指数方向看平安 + 太保 + 国寿加权。

**纪律**：保险研究的核心是判断**利率方向的含义（利差损 vs 投资收益）+ 权益市场状态 + 利差损预期（NBV / 预定利率）**，三者比价格趋势承重。三线共振（利差损缓解 + 权益回暖 + NBV 增长）= 保险估值修复的最强赔率组合。

### 可用的择时指标（定性）：无干净绿灯，仓位纪律优先

**核心结论（诚实，不可美化）**：研究室对本指数做过完整全因子族扫描——**没有干净的绿灯择时因子**。趋势类（donchian）只到黄灯（统计置信不足）；波动率目标类虽数值接近达标，但**翻转极其频繁（远超可执行范围）**，在场外基金里会被 7 日内早赎 + 申购费彻底吃掉，**不可执行**。保险趋势性弱于券商、又不像银行那样靠纯估值，价格择时在它身上找不到稳健 edge。且本指数只有收盘价、没有日内高 / 低，吊灯类因子的 ATR 用收盘代理偏乐观，可靠性再打折。

**怎么用（判断，不机械执行）**：

- **不依赖价格择时因子**——保险的"择时"主要靠**利率方向 + 权益状态 + 利差损预期**的基本面判断，价格趋势 / 动量只作"现在该不该动"的弱右侧参考，权重低于基本面三线。
- 用任何波动率目标类思路时记得：它们的高换手在场外基金里成本上不可行，别照搬。
- **仓位纪律（快砍、压回撤）优先于追逐任何择时信号**；保险弹性大（权益放大 + 利率波动），回撤控制比找进场点更重要。

## 四、利率 / 政策视角（保险的核心重定价器）

- **长端利率（最核心、最易判错）**：再强调一遍方向——利率下行**短期**压制（利差损担忧 + 再投资收益降，估值利空）但**对存量债是浮盈、对当期投资收益是利好**（利润利好）；判断时要明确市场当下在交易哪一面。利率企稳 / 触底回升常是保险估值修复的发令枪（利差损担忧解除）。
- **预定利率下调**：监管下调人身险预定利率 + 险企推分红险替代传统险，从负债端降成本、缓解利差损——是近年保险的核心政策利好主线。
- **权益市场政策**：保险资金权益投资比例放松、长期资金入市政策 → 放大保险的权益弹性。
- **会计准则（新准则 I9 / I17）**：改变利润与净资产的波动性（权益资产公允价值变动直接入利润表），使保险利润对权益市场更敏感——理解报表波动来源。
- **事件前减敞口**：利率大幅波动窗口、预定利率调整、龙头业绩 / 监管事件前跳空风险大，不明朗时不赌方向。

## 五、风险管理视角

保险的杀伤来自利率 + 权益的双向放大 + 利差损的长期压制：

- **利差损实质化**：长期低利率 + 投资收益率持续覆盖不了负债成本 → 利差损从担忧变现实，是保险最深的结构性风险（日本险企的历史教训）。利差损担忧重燃时降仓。
- **权益市场大跌**：保险资金权益敞口在熊市里放大投资亏损 + 拖累利润 + 新准则下利润表波动更大——权益深跌时保险跟跌且弹性大。
- **利率方向误判**：把利率下行简单当利好（存量债浮盈）而忽略利差损担忧（估值压制）→ 在估值杀的时候逆势加仓。**这是保险最贵的错误，务必先辨利率方向的当下含义。**
- **寡头集中风险**：平安顶格 30%，平安自身的事件（综合金融 / 科技 / 银行板块拖累、管理层 / 战略变化）能直接砸指数——穿透看平安。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界。保险弹性大，机械止损不可省。

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称——触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 利差损担忧重燃（长端利率创新低 + 投资收益率持续下行）
  - 权益市场转入熊市（投资收益拖累 + 新准则放大利润波动）
  - NBV 增长失速 / 转负（负债端恶化）
  - 预定利率下调红利出尽 / 负债成本未能有效下降
  - 平安等龙头自身重大利空（综合金融板块拖累）
  - 趋势跌破 200 日均线且 1 月未收回
- **看空被证伪（上行 veto-watch）**：
  - 长端利率企稳 / 触底回升（利差损担忧解除）
  - 权益市场回暖带动投资收益暴增（利润高弹性）
  - NBV 持续高增（负债端健康）
  - 预定利率下调 + 负债成本实质下行（利差损缓解的双重证据）
  - 低 PB / 低 PEV + 趋势企稳放量

# 仓位管理方法论

## 唯一信仰：辨利率方向、判权益与利差损、纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 保险的超额来自**在利差损担忧缓解（利率企稳 + 权益回暖 + 负债成本下行）+ 估值低位时配置，吃估值修复 + 权益弹性放大的利润**——它是利率 + 权益的二阶放大器，方向判对了弹性很大，判错了（尤其利率方向看反）杀伤也大。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"。
- 该在场时别缺席：利差损缓解 + 权益回暖 + 估值低位 + 趋势企稳共振时还空着 = 踏空。
- 不用硬止盈硬止损——择时交给利率 + 权益 + 利差损 + 趋势 + 回撤说话；**价格择时无干净 edge，回撤控仓是机械防线**。

## 一、先识状态：利率方向含义 + 权益状态 + 趋势市 / 震荡市

**每天第一步：先回答两个母变量问题，再给价格状态分类。**

1. **利率方向的当下含义**：长端利率在往哪走、市场当下在交易利差损担忧（估值）还是当期投资收益（利润）？——这是保险的〇号判断，判错方向后面全错。
2. **权益市场状态**：大盘多 / 空 / 震荡（保险投资收益的放大器）。
3. **价格状态**（三选一）：趋势市（均线单边 + 斜率明显）/ 震荡市（200 日线走平 + 箱体反复）/ 过渡待定（轻仓 / 观望）。
- **状态有粘性**：默认继承昨日结论；单日跳空（利率 / 权益 / 政策最常见）不算切换信号。每天显式记下**状态标签 + 利率方向含义 + 权益状态 + 推翻它需要看到什么**。

## 二、趋势市骨架：跟随利率 + 权益母变量，趋势作辅助

- 保险趋势常跟随利率 + 权益两条外部线——方向对（利差损缓解 + 权益回暖）就拿住让弹性跑；母变量转向（利率重燃利差损 / 权益转熊）降仓。
- **趋势 / 动量在本指数只作弱辅助**（无干净绿灯），权重低于利率 + 权益 + 利差损判断。
- 波动率体感：保险弹性大、振幅骤增到极端是降仓信号。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 箱体中段不动手；轻仓不赌箱体（一条利率 / 权益 / 预定利率新闻就能突破或跌穿）；不追假突破。
- 逻辑级催化（利差损担忧解除 / 权益放量回暖 / 预定利率下调落地）突破箱体并站稳数日 → **立即交接回趋势骨架**。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%。
- **利差损重燃 / 权益转熊 / 趋势转空 → 一把降到位，可以到 0**：保险弹性大、下跌时权益与利率双杀加速。
- **回补按赔率**：高赔率组合 = 利差损缓解证据 + 权益回暖 + 低 PB/PEV + 趋势企稳 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。**"宁可错过，不可做错"只约束低赔率情形。**
- **只在浮盈 / 趋势未坏的回调里加仓；绝不在利差损担忧加重的下跌中摊薄**（这是保险最贵的接飞刀）。

## 五、止盈止损：用利率、权益、利差损和回撤说话，不用固定数字

- 在场期间盯四件事：**利率方向含义变没变、权益市场状态、利差损预期（NBV / 负债成本）、从持仓高点回撤了多少**。
- **主升尾段的主动止盈**：PB/PEV 高位 + 权益过热 + 利率风险叠加时，移动止盈收紧。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏（保险回吐快）。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关，本指数的机械防线）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。保险弹性大、无干净择时因子兜底，这条回撤纪律是机械防线。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；注意 399809 跟踪品稀少（主要是 LOF），流动性与费率要算进去。
- 每个仓位档**至少持有 3 个交易日**；期间只有利率 / 权益 / 趋势转向、账户回撤穿阈值、止盈触发三类信号允许跳档——单日跳空不打破持有窗口。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 降息利好保险（存量债浮盈） | 降息利空保险（利差损担忧） | **看市场当下交易哪一面**：利率企稳 / 触底回升 + 利差损缓解看 A 侧逻辑；利率创新低重燃利差损看 B（这是最易判错处） |
| 低 PEV 该买 | 低 PEV 是 EV 被打折 | 看**利差损担忧是否缓解**：缓解证据出现看 A，担忧重时市场不信 EV 看 B |
| 权益牛市保险弹性大要追 | 利好兑现是卖点 | 权益主升 + 利差损缓解看 A；权益过热 + 拥挤极端看 B |
| 估值太贵该减 | 估值修复行情无视估值 | 利差损缓解 + 权益回暖看 B；利差损重燃 / 权益转熊时极端读数当顶部预警 |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 利差损 / 权益逻辑没坏的系统性恐慌看 A；利差损加重驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；PB/PEV 高位 + 权益过热 + 利率风险看 B |
| 保险是一个板块 | 平安/太保/国寿各走各的 | 默认穿透到龙头：平安综合金融逻辑最杂、国寿最纯利率+权益敏感，别用一家掩盖另一家 |

> **核心一句**：保险主题——长久期利率敏感 × 权益弹性 × 寿险负债周期的三重耦合，基本面最复杂；**先辨利率方向的当下含义（利差损 vs 投资收益，最易判错）**，用**权益状态 + 利差损预期（NBV / 预定利率 / 负债成本）**定方向、**PB/PEV 分位**定赔率；无干净择时因子，价格趋势只作弱辅助、**回撤控仓是机械防线**；穿透到平安 + 太保 + 国寿看，利差损缓解 + 权益回暖时吃弹性，利率看反是最贵的错误。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新会计准则影响、利率体系重构、负债端产品范式变化）。
- **定期 + 事件驱动**：一轮利率 / 权益周期走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB/PEV 分位、回撤档、均线 / 动量周期）、视角权重与排序、五家龙头差异化打法、新增失效模式与证伪条件。**若未来扫描出对保险有效的择时因子，再升级三节（目前无干净绿灯）。**
- **不轻易动（信仰与原则层）**：唯一信仰（辨利率方向、判权益 + 利差损、纪律压回撤）、利率双向影响需辨方向的认知、保险是利率 + 权益二阶放大器的定位、无干净择时因子 + 回撤控仓是机械防线、穿透到龙头看、风险优先于收益。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（会计准则 / 利率体系 / 负债端范式变化是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。
