# 恒生科技指数投资框架（方法论）

这套方法论和 A 股单指数框架有一个**结构性不同，先说清**：恒生科技指数（HSTECH）**没有可用的估值数据，也没有任何在 server 端预算好的择时因子**（没有 ERP、没有 ma200 偏离因子、没有 donchian catalog、没有拥挤度/换手）。能调到的港股择时数据**只有行情序列本身**。所以本框架不靠量化因子定仓位，而是靠**两条腿**：行情趋势位置（定性、未经本指数验证）+ 宏观外部面（承重）——并且因为本标的高波动，**风控刹车要踩得最早最狠**。

- 标的：**恒生科技指数（HSTECH.HI）**，可买场外联接：**013403 华夏恒生科技ETF发起式联接(QDII)C**
- **定位先说清**：恒生科技 = 港股科技龙头（互联网平台 / 硬件半导体 / 新能源车 / 生物科技）。**高弹性、高波动、长久期成长**——上行凌厉、下行也凌厉。本框架据此把宏观面摆在承重位、把回撤纪律摆在第一优先，行情趋势作辅助方向。

## 标的特性（决定玩法）

恒生科技 = 离岸交易的中资成长龙头。几条硬约束：

1. **对流动性最敏感**：成长股久期长，估值高度依赖资金成本——美联储/美债利率/美元流动性的边际变化，会被本标的放大。**宏观外部面在本标的是承重维度，且利率与流动性这一侧权重最高。**
2. **政策与摩擦风险集中**：平台经济监管（国内 + 海外）、中美科技摩擦/出口管制/ADR 退市风险、数据与反垄断——单条政策新闻就能改变成分股的盈利与情绪。宏观面要把**监管 / 中美科技**这条单独盯死。
3. **趋势/动量定性轻用，但破位信号要当回事**：高波动成长里动量特征更明显，但**本指数没有 walk-forward 验证**，所以趋势位置仍只作定性方向；不过**向下破位**在高波动标的里恶化极快，破位作为减仓提示的权重高于作为加仓提示。
4. **绝不抄底**：成长股杀估值没有数学下限，而港股**又没有估值数据可判贵贱**——双重不可见，所以**严禁"跌多了抄一把"**，只在趋势与宏观共振转好后顺势回补。

## 可调数据与硬约束（港股版诚实声明）

- **唯一可用的港股择时数据** = `market_index_quote(market='hk', symbols=['HSTECH.HI'])` 的日线 OHLC 行情。趋势位置（相对前高前低、均线位置、回撤幅度）需要你**从这段行情自己看**。
- **不可用、不要去调**：`idx_ma200_deviation`、donchian catalog、`market_index_gzxjb` / ERP 分位、拥挤度、换手——港股取不到。
- **滚动统计必须是过去窗口**：均线/区间高低点用**截至当日 T 及之前**的数据，信号 **T+1** 执行。

## 核心判断：行情趋势位置 +（每日必读）今日宏观面

### A. 行情趋势位置（从 `market_index_quote(hk)` 自判，定性）

取近一段（约 120–250 个交易日）`HSTECH.HI` 日线，定性看：现价相对近 60/120 日**新高/前低**的位置、自算 60/120 日**均线位置**、距区间高点的**回撤幅度**。合成方向温度。

> 高波动标的的纪律：**向下破位（跌穿前低/均线且伴随回撤加速）作为减仓提示，要先于宏观确认就执行**；向上突破作为加仓提示，则要等宏观面不背离再动手。非对称——离场快、回补慎。

### B. 今日宏观面（每日决策前必读 `macro_news`）——权重最高的一条

每日决策前**单独**调 `get_market_report(report_type='macro_news')`，读今日宏观要点（货币/财政/会议/监管/国际/地缘/汇率/大宗，PIT、只含当前世界日及之前）。**`report_type='all'` 不含这份，必须单独取一次。**

恒生科技重点盯（按对本标的的杀伤力排序）：

- **流动性 / 利率（最敏感）**：美联储路径、美债利率、美元指数——成长股估值的命门，收紧→偏防守，宽松→进攻佐证。
- **监管 / 中美科技**：平台监管、反垄断、数据安全、出口管制、ADR/退市、AI 与半导体限制——单条重磅就足以改变持有逻辑。
- **地缘 / 风险偏好**：中美关系、地缘冲突 → 高 beta 标的首当其冲。
- **南向 / 中资科技基本面**：平台公司财报、回购、AI 资本开支、南向流入。

用法（**只做方向修正与证伪，绝不据此追高**）：

- 命中相悖转向（流动性收紧、监管打压、摩擦升级、地缘恶化）→ 进「证伪」、**第一时间大幅减仓**，本标的遇承重利空最不能扛。
- 命中顺向催化（宽松、监管缓和、关系改善、龙头超预期）→ 作为顺势回补佐证，但必须趋势位置同步转好才动手。
- 宏观与趋势打架 → 一律以防守为先（高波动标的的错误代价更大）。

## 已知盲区（照实说）

- **没有估值锚 + 高波动**：贵贱不可见、杀跌无下限，所以严禁抄底、严禁逆势加仓，只顺势 + 防冲击。
- **趋势判断未经本指数验证**：可靠性弱于有量化因子的标的，叠加高波动 → 仓位整体最克制、回撤刹车最早。
- **港股个股 / 成分估值不可查**：只能在指数层面操作。
- **QDII 联接申赎与净值 T+2 滞后**：高波动 + 执行延迟叠加，更要低频、更要提前于盘面动作。

# 仓位管理方法论

## 唯一信仰

- 恒生科技的活法 = **回撤纪律第一 + 宏观外部面（流动性/监管/中美科技）定风险敞口（重）+ 行情趋势定方向 + 严禁抄底**。没有估值锚、波动又大，**只顺势、只防守性回补，不赌反弹**。
- 进攻强度由"趋势温度 × 宏观顺向程度"的**共振强度**决定，**不设固定仓位上限**；但高波动决定了**大开大合**——共振强则敢上、任一条转坏则快减，共振不明确的中间地带收手观望、不勉强持仓。

## 调仓纪律

- **T+1**：信号当日收盘计算、下一交易日执行。
- **步长（非对称）**：加仓温和分批、要趋势 + 宏观双确认；**减仓可一次到位**，破位或承重利空单独触发即可。离场要快、回补要慎。
- **回撤总开关（最高优先）**：账户净值从峰值回撤时降仓、暂停加仓——本标的波动大，这个回撤刹车要踩得早、踩得狠。
- **成本**：QDII 联接申赎费 + 短赎惩罚，避免 7 日内 round-trip；高波动不是高频的理由。

## 风险底线（按降级链处理）

1. **首选**：`market_index_quote(hk, ['HSTECH.HI'])` 有行情 + `macro_news` 可读 → 两条腿正常决策。
2. **行情取不到** → 趋势判定暂停，仅凭宏观面做防守性维持，**不主动加仓**（高波动标的无趋势确认时更不能盲加）。
3. **宏观面缺失** → 用最近一期并显著调低进攻强度；连缺多日则纯趋势、且偏防守。
4. **两者都缺** → 保持仓位不动、沿用上一交易日目标；连续 3 个交易日不可用再报错。
5. **不外猜**：不用外部源臆造利率/监管/资金读数，取不到就降级。

# 方法论迭代机制

规则不刻死，但**命脉在稳定，不轻易改**。

- **可迭代（参数层）**：趋势窗口/均线周期、回撤刹车阈值（高波动可更紧）、加减仓步长与非对称幅度、宏观各维度（流动性/监管/地缘）相对权重。
- **不轻易动（原则层）**：回撤纪律第一、宏观外部面承重（流动性侧最重）、严禁抄底、减仓非对称从快、趋势仅作定性方向、QDII 低频。
- **触发是模式不是单笔**：同类判断连续多次误导、某宏观维度系统性失灵、数据口径变更才迭代；单次减仓后的反弹踏空是高波动防守框架的正常代价，不改。
- 迭代用 `update_my_strategy(bot_id, strategy, reason)` 整篇重写并写清 reason，进审计、下一交易日生效。
