# 证券公司指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证全指证券公司指数（399975.SZ，内部代码 931052，同一条指数）**——中证全指里"证券公司"行业的全部券商（约 50 只，调整市值加权、单票上限 15%，每半年调样）。

## 核心认知

证券公司（399975）= **牛市旗手 × 高 β × 市场情绪的纯放大器**。它没有自己独立的产业周期——券商的收入（经纪 / 两融 / 自营 / 投行）几乎全部是市场活跃度与权益方向的派生函数，所以它是 A 股里**最纯粹的"市场 β 杠杆"**。五个特性决定玩法：

- **没有独立基本面，行情即基本面**：成交额涨 → 经纪 + 两融收入涨；权益涨 → 自营盘赚钱；情绪热 → IPO / 再融资放量。**券商的"景气"就是市场本身的活跃度与方向**，几乎没有领先于大盘的独立信号。这意味着研究重心不是"挖券商的独立逻辑"，而是"判断市场 β 的方向与强度"。
- **高 β + 强趋势性 + 脉冲式爆发**：典型走势是长期阴跌磨底 + 牛市启动时单月暴涨（历史上券商单月涨幅冠绝全市场的情况反复发生），回撤同样凶猛。**它涨起来又快又猛、跌起来又深又急**——这是少数趋势 / 动量因子真正有效的金融板块（见三节量化辅助）。
- **"旗手"属性 = 领先大盘的情绪信号**：券商常在牛市启动初期最先异动（资金借道券商表达"看多全市场"的意图），它自己的走强反过来是大盘情绪的领先指标。**别只把它当一个板块，它还是全市场风险偏好的温度计。**
- **东方财富是高 β 放大器**：指数权重里东方财富（互联网券商 + 金融数据）+ 中信证券两强占大头，东财的散户活跃度敞口让指数比传统券商更"散户情绪化"——成交额脉冲期它弹性最大。
- **政策与事件密集**：注册制深化、费率改革（压经纪佣金）、并购重组松绑（券商合并潮）、两融 / 场外配资监管——政策对券商是直接的盈利与估值重定价器，且方向可正可负。

驱动排序：**市场活跃度（成交额 / 两融）+ 权益方向（牛熊）> 趋势 / 动量 > 政策（注册制 / 费率 / 并购）> 估值（PB 分位）**。研究时问三件事：

1. 市场 β 现在是什么状态（成交额在放量还是缩量、两融在加还是去、大盘趋势多还是空）？→ 决定能不能重仓、是不是底部。
2. 券商自身的趋势 / 动量对不对、有没有领先大盘异动？→ 决定现在是加是减。
3. 政策（并购、注册制、费率、监管）变没变？→ 决定是不是该撤或该加。

## 取数

> 券商的核心驱动**大半是结构化高频数据**（成交额、两融余额日频公开）——这是它区别于消费 / 医药等"母变量活在文本里"板块的关键优势：方向判断可以高度量化。能定量的有：价格系（趋势 / 回撤 / 动量）+ 成交额 / 两融 + 估值分位 + 板块资金。**所有历史分位均以"截至当日 PIT"口径。**

- **指数（行情 + 估值）**：`market_index_quote / market_index_val 399975.SZ`（仅收盘 + 涨跌幅，无量与高低）。
- **市场活跃度（券商的"景气"母变量）**：全市场日均成交额、两融余额——`macro_data` 或 `research_search "两市成交额 两融余额"`；这是判断券商方向的第一抓手，**优先用结构化口径并标注 as-of**。

## 一、估值视角（PB 分位 + 成交额双确认，PE 受自营失真）

券商盈利里自营占比大、波动剧烈（牛市暴赚熊市亏损），**PE 在券商身上严重失真**——熊市自营亏损时 E 坍塌 PE 飙高，牛市自营暴赚时 PE 显低。**主用 PB 分位**：券商净资产相对稳定，历史 PB 分位（截至当日 PIT）是有意义的赔率标尺，历史上券商 PB 在一个相对清晰的箱体里震荡，底部区与顶部区有参考价值。但三条纪律：

- **PB 分位 + 成交额双确认**：低 PB 分位本身不是买入信号，要叠加"成交额放量 / 两融回升 / 大盘趋势转多"才成立；高 PB 分位也不是卖出信号，要叠加"成交额见顶缩量 / 情绪过热"才危险。**PB 定赔率，市场活跃度定方向。**
- **券商是赔率游戏，不是估值回归游戏**：它的超额几乎全部来自"在牛市启动时重仓吃 β 暴涨"，而不是"低 PB 买入等回归"——低 PB 可以在熊市里磨很久（市场不活跃，券商就没有催化）。**别把低 PB 当抄底理由，要等市场 β 转向的证据。**
- **在上升趋势中，高 PB 绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走 / 不进"。券商牛市里 PB 冲到顶部分位仍能继续涨（情绪驱动），**别用 PB 高去 fade 一轮主升浪**。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"。

估值做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：PB 顶部分位 + 成交额天量 + 两融极速膨胀 + 全民进场（券商成全民词汇、新基金爆发）→ 牛市尾段提示，配合趋势框架与止盈纪律。**券商往往是牛市最后一棒的领跌者，顶部信号要格外警惕。**
- **深熊底部观察（底）**：PB 底部分位 + 成交额地量 + 情绪冰点 → 记为**潜在底部观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；等成交额 / 两融 / 大盘趋势出现转向证据，趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**——券商启动极快，犹豫一两天就是踏空一大段。

## 二、趋势视角

券商是趋势 / 动量因子真正有效的金融板块（见三节），趋势研判权重高：

- **方向锚**：指数 vs 200 日均线 + 均线斜率；**时序动量（20–60 日收益符号）在本指数承重**（不是辅助）。
- **成交额确认**：券商上涨必须有成交额放量配合——**无量上涨的券商反弹大概率是诱多**；放量突破才是真启动。成交额是券商趋势的"燃料表"。
- **两融确认**：两融余额回升 = 杠杆资金进场 = 趋势有续航；两融见顶回落 = 杠杆退潮 = 顶部预警。
- **波动率（板块代理）**：收盘价滚动波动率 + MA200 乖离代理；券商波动天然大，振幅骤增到极端是顶部特征。
- **领先性甄别**：券商先于大盘异动（放量大涨）常是牛市启动的领先信号——**这种领先级的异动值得顺势跟（赔率好），但要和成交额 / 两融共振确认，单日脉冲不算**。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、市场活跃度视角（券商专属：成交额 / 两融 / IPO 是母变量）

券商没有独立产业景气，它的"景气"就是市场活跃度——按性质分层跟：

- **领先 / 同步（母变量）**：
  - **全市场日均成交额（ADT）**——经纪 + 两融收入的直接来源，放量 = 券商收入与情绪同步走强。成交额从地量回升常领先券商行情。
  - **两融余额**——杠杆资金的温度计，加杠杆 = 风险偏好扩张 = 券商趋势续航；去杠杆 = 退潮。
  - **大盘方向与情绪**——自营盘权益敞口让券商盈利与权益市场同向。
- **滞后（确认不择时）**：券商季报营收 / 净利——跟随成交额与权益方向，**等财报确认市场转向已走完半程**。
- **事件驱动**：IPO / 再融资节奏（投行收入，领先）、并购重组（券商合并潮重估格局）、注册制深化（扩容投行业务）、费率改革（压经纪佣金，利空）、两融 / 配资监管（情绪冲击）。

**纪律**：券商研究的核心动作是**判断市场 β 的方向与强度**，而不是挖券商独立逻辑（它几乎没有）。成交额 + 两融 + 大盘趋势三者共振向上 = 券商主升的最强赔率组合；三者背离时以成交额 / 两融的资金面为准。

### 可用的择时指标（已验证因子）

> 研究室离线全因子族扫描（长样本、含费率与 T+1）验证：本指数 **`mom_20` 动量绿灯**——这是金融三子板块（券商 / 银行 / 保险）里**唯一**通过验证的择时因子，根源就是券商的强趋势性 + 高 β。当作**客观第二意见 + 趋势确认**，权重可以比其他板块高一些（因为它真的有效），但仍不替代市场活跃度的方向判断。读数用收盘序列按公式自算。

- **`mom_20`（20 日动量，已验证，承重度高于其他板块）** —— 规则：近 20 日收益 > 0 → 满仓，否则空仓。验证结论：把裸持有的负收益翻成正的收益回撤比、大幅压低最大回撤，时间稳定性好（这是券商强趋势性的直接体现）。
  - **为什么在券商身上特别有效**：券商涨跌的趋势性、连续性强（情绪驱动的脉冲式行情），20 日动量能吃住主升、躲开深熊段——这是它在其他防御性金融板块（银行）上完全失效、在券商上却绿灯的根本原因。
  - **已知盲区（从公式可推）**：① 震荡市里 20 日收益在 0 附近反复变号、抽脸；② 收盘计算、T+1 执行，对单日跳空滞后一天；③ 只看价格，对政策黑天鹅（监管突袭）、并购事件无预警；④ 翻转偏频繁（约每月一两次），场外基金要把申赎成本算进去。
- **次级辅助（参考）**：长周期唐奇安拖尾止损在验证里也接近达标但在场时间过短、不实用；吊灯类因 ATR 用收盘代理偏乐观，只作参考。

**怎么用（判断，不机械执行）**：`mom_20` 当趋势确认的承重第二意见——与成交额 / 两融的资金面同号 → 高置信度进场 / 加仓；冲突 → 逐项核验（动量在场而资金面缩量 = 可疑反弹，资金面放量而动量未确认 = 等突破）。**不要写也不要执行"因子 = X 且 Y 时必须 Z"的未回测组合规则**——冲突本身是信号。

## 四、政策 / 事件视角（券商的盈利与估值重定价器）

- **并购重组松绑**：券商合并潮（头部券商整合）直接重估行业格局与个股，是近年券商最强的事件催化之一——涉及指数权重股的合并能带来指数级跳空。跟踪监管对券商并购的表态与具体案例进度。
- **注册制深化 / IPO 节奏**：扩容投行业务（利好），但 IPO 大扩容也可能压制市场情绪（抽血效应，间接利空 β）——**要分清对券商盈利的直接利好和对市场情绪的间接影响**。
- **费率改革**：经纪佣金 / 公募费率下调压制经纪与代销收入，是结构性利空，但市场常 price in 后边际钝化。
- **两融 / 场外配资监管**：收紧 = 去杠杆 = 情绪冲击（历史上股灾后的去杠杆是券商深跌的加速器）；放松 = 加杠杆 = 情绪助燃。
- **事件前减敞口**：重大监管窗口、并购传闻未定时跳空风险大，事件不明朗时不赌方向。

## 五、风险管理视角

券商的杀伤来自高 β 的双向放大 + 杠杆退潮：

- **牛市最后一棒**：券商常是牛市里最先见顶、跌得最狠的板块（情绪退潮 + 两融去杠杆 + 自营回吐三杀）——PB 顶部 + 成交额见顶 + 两融见顶时要格外警惕，**别在券商身上恋战最后一段**。
- **杠杆踩踏**：两融快速去杠杆 + 场外配资清查时，券商下跌加速（自身杠杆资金 + 自营盘双杀），历史上有过深水区先例。
- **成交额坍塌**：市场转入地量时券商失去燃料、长期阴跌磨底——这种磨人的下行段没有催化，不要因为"PB 便宜"在里面耗仓位。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（市场 β 转向）大概率已破。**券商高波动，机械止损不可省。**

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称——触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 成交额从放量转持续缩量（券商失去燃料）
  - 两融余额见顶回落 / 加速去杠杆（杠杆退潮）
  - 大盘趋势转空、情绪从过热转冰点
  - `mom_20` 转 0 且成交额同步走弱（趋势 + 资金双确认走坏）
  - 监管收紧（两融 / 配资 / 费率）砍掉情绪或盈利
  - 趋势跌破 200 日均线且 1 月未收回
- **看空被证伪（上行 veto-watch）**：
  - 成交额从地量持续放量回升 + 两融回升（市场 β 转向的硬证据）
  - 券商先于大盘放量异动（牛市启动的领先信号）
  - 并购重组 / 政策利好重估格局
  - `mom_20` 转 1 且成交额放量确认
  - PB 底部分位 + 大盘趋势企稳放量

# 仓位管理方法论

## 唯一信仰：判市场 β、顺券商趋势、纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 券商的超额来自**在市场 β 转向（成交额放量 + 两融回升 + 趋势转多）时重仓吃高 β 暴涨，在情绪退潮 + 杠杆去化时果断离场**——它是赔率游戏（牛市暴赚、熊市躲开），不是估值回归游戏。**空仓躲过磨人的地量阴跌段，是这个策略的常态。**
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"。
- 该在场时别缺席：成交额放量 + 两融回升 + `mom_20` 确认 + 趋势多头共振时还空着 = 踏空——**券商启动极快，踏空一两天就是一大段，这是它最贵的错误。**
- 不用硬止盈硬止损——择时交给市场活跃度、趋势、`mom_20`、回撤说话。

## 一、先识状态：市场 β 状态 + 趋势市 / 震荡市

**每天第一步：先回答"市场 β 现在什么状态"（成交额放量 / 缩量、两融加 / 去、大盘趋势多 / 空），再给券商价格状态分类（趋势市 / 震荡市 / 过渡待定三选一）。**

- 趋势市：均线（MA60 / MA120）单边排列、斜率明显，且成交额 / 两融同向。
- 震荡市：200 日线走平 + 价格在均线 ±15% 箱体反复（券商波动大、箱体宽）+ 假突破频出。
- 过渡待定：两边都不像、或趋势与资金面背离 → 轻仓 / 观望 / 维持原状态。
- **状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日脉冲不算切换信号。每天显式记下**状态标签 + 市场 β 状态 + 推翻它需要看到什么**。

## 二、趋势市骨架：时序动量 + 成交额确认（mom_20 承重）

- **时序动量**：券商趋势性强，方向对就拿住让高 β 跑；**`mom_20` 在本指数承重**（不是辅助），与成交额 / 两融同号时高置信度在场。
- **成交额是燃料表**：放量上涨拿住，缩量上涨警惕（诱多），放量下跌快走。
- **波动率体感**：振幅骤增到极端是顶部特征；牛市尾段的加速暴涨要用移动止盈收紧。
- 趋势里不做高抛低吸——券商主升浪一旦下车很难再上。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 箱体中段不动手；轻仓不赌箱体；不追假突破（券商震荡市假突破极凶）。
- 放量 / 逻辑级催化（成交额持续放量 / 并购利好）突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade——券商的真突破往往就是主升起点。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%。
- **情绪退潮 / 杠杆去化 / 趋势转空 → 一把降到位，可以到 0**：券商顶部下跌加速（三杀叠加），等"再确认一天"往往多亏一大截。
- **回补按赔率**：高赔率组合 = 成交额放量 + 两融回升 + 趋势放量突破 + `mom_20` 确认 多因素共振 → 大步上仓位（券商赔率好时要敢重仓，这是它全部超额的来源）；信号不扎实就分 2–3 个大步或放弃。**"宁可错过，不可做错"只约束低赔率情形**，券商高赔率时真正的"做错"恰恰是轻仓踏空。
- **只在浮盈 / 趋势未坏的回调里加仓；绝不在地量阴跌的下跌趋势中摊薄**。

## 五、止盈止损：用市场活跃度、趋势和回撤说话，不用固定数字

- 在场期间盯三件事：**成交额 / 两融有没有见顶、趋势破没破、从持仓高点回撤了多少**。
- **牛市尾段的主动止盈**：PB 顶部 + 成交额天量 + 两融极端 + 全民进场叠加时，移动止盈收紧——**券商是牛市最后一棒，宁可早走一步**。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏（券商回吐极快）。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。券商单边下跌很容易摸到深水区，这条尤其命。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；`mom_20` 翻转偏频繁，机械执行要把申赎成本算进去，划不来时降一档用更慢的趋势锚。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势 / 资金面转向、账户回撤穿阈值、止盈触发三类信号允许跳档——单日脉冲不打破持有窗口。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PB 该买 | 低 PB 能在地量里磨很久 | 看**成交额 / 两融**：资金面转向看 A，市场仍地量看 B（券商没催化就没行情） |
| 估值太贵该减 | 牛市券商无视估值 | 成交额放量 + 趋势多头看 B；成交额见顶 + 两融极端时极端读数当顶部预警 |
| 券商异动要跟 | 单日脉冲是诱多 | 看**成交额配合**：放量领先大盘异动看 A；无量单日脉冲看 B |
| 并购利好要追 | 利好兑现是卖点 | 看**是否已 price in**：传闻未定 + 资金进场看 A；落地 + 情绪沸腾看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 市场 β 转向证据已现的系统性恐慌看 A；杠杆去化途中的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；牛市尾段（PB 顶 + 天量 + 全民进场）看 B |

> **核心一句**：证券公司——没有独立基本面、行情即基本面，是最纯的市场 β 杠杆；用**成交额 / 两融**判市场活跃度方向、**趋势 + `mom_20`（唯一绿灯、承重）**择时、**PB 分位**定赔率；牛市重仓吃高 β 暴涨、情绪退潮一把走、地量阴跌空仓等催化，靠"敢在赔率好时重仓 + 顶部果断离场"赚牛市旗手的钱。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新业务模式、新监管框架、券商格局重大整合）。
- **定期 + 事件驱动**：一轮牛熊周期走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 动量周期）、视角权重与排序、成交额 / 两融的解读、新增失效模式与证伪条件、`mom_20` 在新数据上的表现复核。
- **不轻易动（信仰与原则层）**：唯一信仰（市场 β 转向重仓、情绪退潮离场）、"行情即基本面"的定位、风险优先于收益、不接飞刀、对本金保守对高 β 放纵、PE 失真主用 PB、`mom_20` 是承重绿灯。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（监管框架重置 / 券商格局整合是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。
