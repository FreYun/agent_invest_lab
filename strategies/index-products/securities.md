# 证券公司指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证全指证券公司指数（399975.SZ，内部代码 931052，同一条指数）**——中证全指里"证券公司"行业的全部券商（约 50 只，调整市值加权、单票上限 15%，每半年调样）。

## 核心认知

证券公司（399975）= **牛市旗手 × 高 β × 市场情绪的纯放大器**。它没有自己独立的产业周期——券商的收入（经纪 / 两融 / 自营 / 投行）几乎全部是市场活跃度与权益方向的派生函数，所以它是 A 股里**最纯粹的"市场 β 杠杆"**。五个特性决定玩法：

- **没有独立基本面，行情即基本面**：成交额涨 → 经纪 + 两融收入涨；权益涨 → 自营盘赚钱；情绪热 → IPO / 再融资放量。**券商的"景气"就是市场本身的活跃度与方向**，几乎没有领先于大盘的独立信号。这意味着研究重心不是"挖券商的独立逻辑"，而是"判断市场 β 的方向与强度"。
- **高 β + 强趋势性 + 脉冲式爆发**：典型走势是长期阴跌磨底 + 牛市启动时单月暴涨（历史上券商单月涨幅冠绝全市场的情况反复发生），回撤同样凶猛。**它涨起来又快又猛、跌起来又深又急**——这是少数趋势 / 动量因子真正有效的金融板块（见三节量化辅助）。
- **"旗手"属性 = 领先大盘的情绪信号**：券商常在牛市启动初期最先异动（资金借道券商表达"看多全市场"的意图），它自己的走强反过来是大盘情绪的领先指标。**别只把它当一个板块，它还是全市场风险偏好的温度计。**
- **东方财富是高 β 放大器**：指数权重里东方财富（互联网券商 + 金融数据）+ 中信证券两强占大头，东财的散户活跃度敞口让指数比传统券商更"散户情绪化"——成交额脉冲期它弹性最大。
- **政策与事件密集**：注册制深化、费率改革（压经纪佣金）、并购重组松绑（券商合并潮）、两融 / 场外配资监管——政策对券商是直接的盈利与估值重定价器，且方向可正可负。

参考权重排序：**`mom_20`（已验证的高权重趋势参考）> VIX 3y 分位极值（逆向增益参考）> 市场活跃度定性研判（成交额 / 两融文本推断）> 政策事件 > PE 分位极值（定性预警 + 深熊 baseline 兜底）> 交易成本 / 持有期约束**。这些是输入，不是自动下单指令；最终仓位由 agent 在当日 PIT 信息下综合判断。研究时问三件事：

1. **今天三个数是多少**：`mom_20`（正负与离 0 轴距离）、`VIX 3y 分位`（是否 > 90%）、`PE 分位`（是否 < 10% 或 > 90%）？→ 给出仓位倾向和风险提示。
2. 券商趋势 / 情绪 / 龙头动作有没有让 mom_20 快要翻转？持仓是否仍在 7 日短赎窗口内？→ 决定要不要动、动多少、是否值得支付交易成本。
3. 政策（并购、注册制、费率、监管）变没变？→ 决定是不是该撤或该加。

## 取数

> 券商方向判断**主用价格系（mom_20 高权重参考）+ VIX 情绪极值 + PE 分位定性 + 交易成本约束**——这三类当前 MCP 数据源里全部日频可得。**所有历史分位均以"截至当日 PIT"口径。**
>
> ⚠️ **数据源实况说明**：本方法论过去把"日均成交额 ADT + 两融余额"写成券商母变量，但**当前 simworld-data MCP 无日频结构化 ADT / 两融口径**（`macro_indicator_search "两市成交额|两融"` 均空）——只能通过 `research_search` 文本定性推断，**不得写成硬扳机 / 硬否决**。方法论保留成交额 / 两融的**定性视角**（研判方向），但**不当量化闸门用**。

- **指数（行情 + 估值）**：`market_index_quote / market_index_val 399975.SZ`（仅收盘 + 涨跌幅，无量与高低）。
- **市场活跃度（定性推断）**：`research_search "两市成交额 两融余额 日均"` 文本兜底，用于**定性描述方向**（放量 vs 缩量 / 加杠杆 vs 去杠杆），**不当硬扳机**。

## 一、估值视角（PE 分位极值做预警 + 深熊 baseline，不做择时）

券商盈利里自营占比大、波动剧烈（牛市暴赚熊市亏损），**PE 在券商身上严重失真**——熊市自营亏损时 E 坍塌 PE 飙高，牛市自营暴赚时 PE 显低。当前 MCP 数据源只提供 PE + PE 历史百分位（无 PB），因此估值只做**定性预警 + 深熊 baseline 兜底**，**不做择时扳机**。三条纪律：

- **中间段全是噪声**：PE 分位 20%–80% 之间基本无信号价值（券商 PE 分位跟大盘活跃度高度绑定，方向主要看价格趋势、市场活跃度与 agent 综合判断）。
- **极端读数才有参考**：PE 分位<10% = 极端赔率区、PE 分位>90% = 顶部预警区，中间段不上桌。
- **"趋势 > 估值"是单向过滤器**：上升趋势中，高 PE 分位绝不构成减仓或拒绝进场的理由，只否决"因为贵所以走 / 不进"。券商牛市里估值冲到顶部分位仍能继续涨（情绪驱动），**别用估值高去 fade 一轮主升浪**。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"。

估值做两件事，都是**定性动作、不是择时扳机**：

- **极端泡沫预警（顶）**：PE 分位>90% + VIX 极低 + 全民进场（券商成全民词汇、新基金爆发）→ 牛市尾段提示，配合趋势框架与止盈纪律。**券商往往是牛市最后一棒的领跌者，顶部信号要格外警惕。**
- **深熊底部试探 baseline（底，🟡黄灯量化落地）**：**PE 分位<10% 且 mom_20≤0** 时，agent 可保留一档 baseline 底仓（比例由 `USER.md` 风险性格锚定，保守 → 更低、进攻 → 更高），不必因 mom_20 空头信号完全空仓。这是破"低估+趋势破位死结"的兜底纪律——避免深熊里长期 0 仓踏空 V 反。趋势一企稳（mom_20 转正）可提高仓位；PE 分位回到 10% 以上 baseline 自动解除。**这条 baseline 是辅助纪律，不是自动交易规则**。

## 二、趋势视角

券商是趋势 / 动量因子真正有效的金融板块（见三节），趋势研判权重高：

- **高权重趋势参考**：**`mom_20`（近 20 日收益符号）是本指数验证效果最好的价格信号**——mom_20 > 0 倾向提高仓位，mom_20 ≤ 0 倾向降低仓位；但不再把它写成"必须满仓 / 必须空仓"的硬开关。方向锚（MA60 / MA120 / MA200）与斜率作为**上下文描述**，帮助识别状态市 vs 趋势市（见仓位管理 §一）；**方向锚本身不当硬扳机**——过去把"跌破 MA60"焊成硬否决闸门是长期空仓踏空的根源之一。
- **成交额 / 两融 = 定性描述**：⚠️ 结构化日频数据不可得，**不当量化扳机**。研判时可以用文本兜底做定性推断（"放量"vs"缩量"），但不得写"必须放量确认"、"缩量必减仓"这类 AND 门规则。
- **波动率（板块代理）**：收盘价滚动波动率 + MA200 乖离代理；券商波动天然大，振幅骤增到极端是顶部特征（描述用）。
- **领先性甄别**：券商先于大盘异动（放量大涨）常是牛市启动的领先信号——**这种领先级的异动值得顺势跟（赔率好），单日脉冲不算，需要连续几日站稳或叠加 mom_20 由负转正确认**。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、量化择时因子（回测验证过的三层结构）

券商没有独立产业景气，它的"景气"就是市场活跃度。

### ✅ 高权重趋势参考：`mom_20`

**用法**：近 20 日收益 > 0 → 倾向在场 / 提高仓位；近 20 日收益 ≤ 0 → 倾向防守 / 降低仓位。它是强参考，不是自动下单指令；agent 必须结合趋势状态、VIX、PE 极值、政策事件、账户回撤、持有期和申赎成本做最终判断。

- **为什么在券商身上特别有效**：券商行情情绪驱动、脉冲式爆发，趋势 / 连续性强，短窗时序动量能吃住主升、躲开深熊段——**在本指数动量因子稳定有效**，因此给它最高参考权重。
- **已知盲区**：① 震荡市里 20 日收益在 0 附近反复变号、抽脸；② 收盘计算、T+1 执行，对单日跳空滞后一天；③ 只看价格，对政策黑天鹅（监管突袭）、并购事件无预警；④ 翻转偏频繁（约每月一两次），场外基金要把申赎成本算进去。

### 🟢 增益信号：VIX 极值逆向持仓参考

**用法**：`macro_50etf_vix` 突破过去 **3 年滚动 90% 分位** → 从触发日起 **20 交易日内显著提高做多优先级**，可覆盖 mom_20 的空头倾向；窗口结束后重新综合评估。

- **直觉**：券商 = 情绪放大器 + 高 β，恐慌极值是均值回归的最强触发；20 日窗口正好吃住反弹再交回 mom_20。
- **纪律**：VIX 分位算法用过去 3 年（约 750 交易日）滚动、以当日收盘 VIX 与前 750 日历史比排位。分位≥90% 才触发；触发后 20 交易日窗口是重要参考期，原则上不要用弱确认条件把它过滤掉，但 agent 仍需结合账户风险和交易成本写出最终动作。

### 🟡 辅助纪律：深熊底部 baseline 试探

**规则**：`market_index_val` 返回的 PE 历史百分位 < 10% 且 mom_20 ≤ 0 时，可保留一档 baseline 底仓（不完全空仓）。mom_20 转正后可提高仓位；PE 分位回到 10% 以上 baseline 解除。

- **性质**：辅助纪律，只保命不追求超额；单独跑打不赢裸 mom_20，价值在于破"低估+趋势破位"死结、避免历史极值 PE 分位区间的长期 0 仓踏空 V 反。

### ❌ 已证伪、明令禁用的组合规则

以下规则**回测证伪、不得作为择时扳机 / 硬否决闸门**——只能作为"上下文描述"（记录在决策日志里但不影响仓位）：

- **`sector_factor` 板块风险分做 gate**：风险分 AND / OR / gated 系列变体全部劣于裸 mom_20；风险分是 mom_20 的**负 alpha 稀释器**，不是独立 alpha 源。
- **`sector_factor` 板块动量做 mom_20 确认**：与 mom_20 共线且滞后，加进来只稀释不增益。
- **"跌破 MA60 / 站上 MA60" 做入场 / 清仓的硬闸门**：均线是**上下文**，不能焊成"跌破必清仓、未站上不进场"。
- **"mom_20 + 成交额放量 + 两融回升 + 趋势突破" 四条件 AND 回补门**：结构化 ADT / 两融数据不可得（回测不可验证），且四条件 AND 门本身就是踏空制造机——现实里等四条件同时成立、主升浪已走完。回补可优先参考 **mom_20 改善 + VIX 逆向增益**，但最终由 agent 综合判断，不叠加未验证的硬 AND 门。

**怎么用（判断，不机械执行）**：

- 骨架：`mom_20` 给出仓位倾向（>0 偏进攻、≤0 偏防守）
- 增益：VIX 3y>90% 触发时 20 日窗提高做多优先级（可覆盖 mom_20 空头倾向）
- 兜底：PE 分位<10% 且 mom_20≤0 时可保留 baseline 底仓（不全空）
- 顶部纪律与状态市／震荡市裁决见下方仓位管理方法论。

**不要写也不要执行"因子 = X 且 Y 时必须 Z"的未回测组合规则**——冲突是信号，不是让你叠更多 AND。

## 四、政策 / 事件视角（券商的盈利与估值重定价器）

- **并购重组松绑**：券商合并潮（头部券商整合）直接重估行业格局与个股，是近年券商最强的事件催化之一——涉及指数权重股的合并能带来指数级跳空。跟踪监管对券商并购的表态与具体案例进度。
- **注册制深化 / IPO 节奏**：扩容投行业务（利好），但 IPO 大扩容也可能压制市场情绪（抽血效应，间接利空 β）——**要分清对券商盈利的直接利好和对市场情绪的间接影响**。
- **费率改革**：经纪佣金 / 公募费率下调压制经纪与代销收入，是结构性利空，但市场常 price in 后边际钝化。
- **两融 / 场外配资监管**：收紧 = 去杠杆 = 情绪冲击（历史上股灾后的去杠杆是券商深跌的加速器）；放松 = 加杠杆 = 情绪助燃。
- **事件前减敞口**：重大监管窗口、并购传闻未定时跳空风险大，事件不明朗时不赌方向。

## 五、风险管理视角

券商的杀伤来自高 β 的双向放大 + 杠杆退潮：

- **牛市最后一棒**：券商常是牛市里最先见顶、跌得最狠的板块（情绪退潮 + 杠杆去化 + 自营回吐三杀）——PE 分位 > 90% + VIX 极低 + 全民进场（定性组合）叠加时要格外警惕，**别在券商身上恋战最后一段**。
- **杠杆踩踏**：两融快速去杠杆 + 场外配资清查时，券商下跌加速（自身杠杆资金 + 自营盘双杀），历史上有过深水区先例。
- **成交额坍塌**：市场转入地量时券商失去燃料、长期阴跌磨底——这种磨人的下行段没有催化，不要因为"PB 便宜"在里面耗仓位。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（市场 β 转向）大概率已破。**券商高波动，机械止损不可省。**

## 六、证伪视角（对称化）

证伪是**买入 / 卖出逻辑的破坏**，须对称——触发不等于立刻反向操作，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - **`mom_20` 转 0**（高权重趋势参考转弱，第一优先级观察项）
  - VIX 逆向 20 日窗结束且 mom_20 仍弱（增益期结束、重新综合评估）
  - PE 分位 > 90% + VIX 极低 + 全民进场（顶部预警定性组合）
  - 监管收紧（两融 / 配资 / 费率）砍掉情绪或盈利（事件驱动）
  - 定性研判：成交额从放量转持续缩量、两融见顶回落（研报文本兜底，**不当硬扳机**）
- **看空被证伪（上行 veto-watch）**：
  - **`mom_20` 转 1**（高权重趋势参考转强，第一优先级观察项）
  - VIX 3y 分位 > 90% 触发（逆向增益参考，20 日窗口内提高做多优先级）
  - PE 分位 < 10% 且 mom_20 转 0→1（深熊底部 baseline 可升级为更高仓位）
  - 定性研判：券商先于大盘放量异动、并购重组 / 政策利好、成交额从地量持续放量回升（研报文本兜底，**不当硬扳机**）

# 仓位管理方法论

## 核心框架：`mom_20` 高权重参考 + VIX 逆向增益 + 深熊 baseline 兜底 + agent 裁量

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 券商的超额通常来自**在 mom_20 转强时敢于提高仓位吃高 β 暴涨、在趋势证伪时及时降风险、在 VIX 极值恐慌里逆向抢反弹**——它是赔率游戏（牛市暴赚、熊市躲开），不是估值回归游戏。
- **建议态明确，但允许有理由偏离**：
  - `mom_20 > 0` → 倾向在场，可在 40%–100% 间选择；信号越强、趋势越顺、成本越低，仓位越高。
  - `mom_20 ≤ 0` 且 `PE 分位 < 10%` → 倾向保留 baseline 底仓（深熊底部试探）。
  - `mom_20 ≤ 0` 且 `PE 分位 ≥ 10%` → 倾向防守，可降至 0%，但不是机械清仓指令。
  - VIX 3y 分位 > 90% 触发时，20 交易日窗口内显著提高做多优先级，可覆盖 mom_20 空头倾向。
  - 若持仓仍在 7 日短赎窗口内，`mom_20` 贴近 0 轴的单次翻转通常不足以强制交易；必须比较预期避损与确定费用。
- **无静态天花板、也无 default-to-cash**：仓位由上述建议态、状态识别、账户风险和交易成本共同决定，不因"看不清"就默认空仓；但也不能因为单个信号翻转就忽略短赎费和震荡市假信号。**任何把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"的操作都是违规**（回撤控仓在 §六，走独立触发机制）。
- 该在场时别缺席：`mom_20` 转强仍长期空着可能踏空——**券商启动极快，踏空一两天就是一大段，这是它很贵的错误**。
- 不用把任何单一信号机械化——择时交给 mom_20、VIX、回撤、状态、成本和 agent 判断共同决定。

## 一、先算三个数、再识状态

**每天第一步：先算三个数**，然后再讨论状态市 / 震荡市。

1. **`mom_20`**（近 20 日收益符号）——给出最重要的仓位倾向。
2. **VIX 3y 滚动分位**（当日 `macro_50etf_vix` vs 过去 750 交易日）——是否触发逆向增益开关。
3. **PE 分位**（`market_index_val` 返回值）——是否触发深熊 baseline 兜底。

**这三个数是"仓位决策必读值"**，缺一不可（如任一数据源当日缺失，标明为"数据缺失"、并按上一个可用值处理，但**不得因此转为默认空仓或默认满仓**）。

然后再给券商价格状态分类（趋势市 / 震荡市 / 过渡待定三选一）——状态分类是**关键上下文**，影响执行节奏（震荡市少动、趋势市敢加），也可以让 agent 有理由偏离单个信号给出的倾向：

- 趋势市：均线（MA60 / MA120）单边排列、斜率明显（**描述用**）。
- 震荡市：200 日线走平 + 价格在均线 ±15% 箱体反复（券商波动大、箱体宽）+ 假突破频出。
- 过渡待定：两边都不像 → **不代表转空仓**，而是执行上少动，维持或小幅调整，并写清等待什么证据。
- **状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日脉冲不算切换信号。每天显式记下**三个数值 + 状态标签 + 推翻它需要看到什么**。

## 二、趋势市骨架：mom_20 高权重参考 + VIX 逆向增益

- **mom_20 高权重参考**：`mom_20 > 0` 倾向提高仓位，方向对就拿住让高 β 跑；`mom_20 ≤ 0` 倾向降低仓位，但最终看趋势状态、风险收益和交易成本。
- **VIX 逆向增益**：VIX 3y 分位 > 90% 触发日起 20 交易日窗口内显著提高做多优先级，可覆盖 mom_20 空头倾向；不叠加"必须放量"这类硬 AND 门。
- **波动率体感（描述用，不当扳机）**：振幅骤增到极端是顶部特征；牛市尾段的加速暴涨要用移动止盈收紧（见 §五）。
- **趋势里不做高抛低吸**——券商主升浪一旦下车很难再上。

## 三、震荡市骨架（防守型）：少动、mom_20 参考、突破即交接

- 箱体中段不动手；如果 mom_20 在 0 附近反复变号，允许 agent 容忍 1–2 次翻转不追，尤其在 7 日短赎窗口内更应先算成本（券商震荡市假突破极凶），叠加 §七"最少持有 3 交易日"纪律。
- 放量 / 逻辑级催化（定性研报兜底、并购利好）突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade——券商的真突破往往就是主升起点。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：趋势破坏时快，震荡噪声中慢，回补参考 mom_20 + VIX 增益

- **大开大合，不做微调**：最小步长 20%。
- **mom_20 转弱 / 顶部预警组合触发 → 优先降风险，可以到 0**：券商顶部下跌加速（情绪退潮 + 杠杆去化 + 自营回吐三杀），但在震荡市、0 轴附近、短赎窗口内，agent 可选择观望一天、部分降仓或维持，前提是明确比较预期避损与交易成本。
- **回补机制（两层）**：
    - **回到 baseline 底仓**：mom_20 ≤ 0 且 PE 分位 < 10% —— 深熊底部试探底仓，破长期空仓死结（辅助纪律；具体比例由 `USER.md` 风险性格锚定）。
    - **提高仓位 / 回到高仓位**：mom_20 由负转正 **或** VIX 3y 分位 > 90% 触发（20 日窗口）——两条 OR 都是强参考，具体仓位由 agent 根据信号质量、状态和成本决定。**明令禁用"必须叠加成交额放量 + 两融回升 + 趋势突破"这类未回测的 4 条件 AND 门**（长期空仓踏空的根源）。
- **"宁可错过，不可做错"只约束低赔率情形**——券商高赔率时真正的"做错"恰恰是轻仓踏空。
- **只在浮盈 / mom_20 仍偏多或趋势证据改善的回调里加仓；不要在明确下跌趋势中机械摊薄**。

## 五、止盈止损：mom_20 转向 / VIX 回落 / 回撤三层

- 在场期间盯三件事：**mom_20 有没有转向、VIX 逆向窗口有没有到期、从持仓高点回撤了多少**。
- **牛市尾段的主动止盈**：PE 分位 > 90% + VIX 极低 + 全民进场（定性组合）叠加时，移动止盈收紧——**券商是牛市最后一棒，宁可早走一步**。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏（券商回吐极快）。
- 亏损端要窄而果断，但不是被单一 `mom_20` 读数绑架；浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。券商单边下跌很容易摸到深水区，这条尤其命。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；`mom_20` 翻转偏频繁，机械执行会被短赎费收割。若持仓未满 7 日且 `mom_20` 仅在 0 轴附近小幅翻转，agent 应优先比较"预期避损"与"确定费用"，可以选择不动、部分降仓或等下一日确认。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势 / 资金面转向、账户回撤穿阈值、止盈触发三类信号允许跳档。若跳档会触发 1.5% 短赎费，必须在决策日志里量化费用和不卖的风险，不能只写"mom_20 翻转所以卖"。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 分位该买 | 低 PE 能在地量里磨很久 | 看 **mom_20**：mom_20>0 看 A（趋势企稳，PE 分位<10% 可提高仓位）；mom_20≤0 看 B，但可保留 PE<10% 的 baseline 底仓兜底 |
| 估值太贵该减 | 牛市券商无视估值 | mom_20>0 看 B（趋势里不 fade 估值）；PE 分位>90% + VIX 极低 + 全民进场（顶部定性组合）看 A |
| 券商异动要跟 | 单日脉冲是诱多 | 看 **mom_20 有没有由负转正**：连续几日站稳把 mom_20 转正看 A；单日脉冲但 mom_20 未翻看 B |
| 并购利好要追 | 利好兑现是卖点 | 看**是否已 price in**：传闻未定 + mom_20 未见顶看 A；落地 + PE 分位>90% + 情绪沸腾看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | **VIX 3y 分位 > 90% 且触发窗口内**看 A（强逆向增益参考）；未触发但下跌途中 mom_20 转弱看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；牛市尾段（PE 分位顶 + VIX 极低 + 全民进场）看 B |

> **核心一句**：证券公司——没有独立基本面、行情即基本面，是最纯的市场 β 杠杆；用 **mom_20（高权重趋势参考）** 定方向倾向、**VIX 3y 分位>90% 逆向 hold20（强增益参考）** 抓恐慌反弹、**PE 分位<10% baseline 底仓（辅助兜底）** 破空仓死结；牛市敢于提高仓位吃高 β 暴涨，趋势证伪时及时降风险，震荡和短赎窗口里保留 agent 裁量，靠"赔率好时敢上 + 风险坏时敢退 + 成本不划算时少动"赚牛市旗手的钱。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新业务模式、新监管框架、券商格局重大整合）。
- **定期 + 事件驱动**：一轮牛熊周期走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PE 分位极值门槛、baseline 比例、回撤档、VIX 逆向窗口长度）、视角权重与排序、成交额 / 两融的定性解读、新增失效模式与证伪条件、`mom_20` 在新数据上的表现复核。
- **不轻易动（信仰与原则层，改动须有回测证据）**：
  - "行情即基本面"的定位、风险优先于收益、不接飞刀、对本金保守对高 β 放纵；
  - **`mom_20` 是已验证的高权重趋势参考**（离线扫描端到端验证过），但不是必须满仓 / 必须空仓的自动开关；
  - **VIX 3y 分位>90% 逆向 hold20 是重要增益参考**（别加"再确认一天"叠 AND 稀释）；
  - **PE 分位<10% 的深熊 baseline 是辅助兜底纪律**（破长期空仓死结）；
  - **禁用清单不许悄悄改回来**：sector_factor 风险分 / 板块动量 / "跌破 MA60 硬否决" / "回补必须叠 4 条件 AND 门" —— 这些回测证伪过、加回来必将复现历史踏空。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（监管框架重置 / 券商格局整合是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。

数据缺失时：mom_20 / VIX 3y 分位 / PE 分位这三个仓位决策必读值缺失，按上一个可用值处理并明确标注"数据缺失"——**不得因为缺数据就默认转空仓或满仓**（这条纪律是从长期空仓踏空和机械交易成本里学的）。政策 / 并购走 `research_search` / `research_view` 文本兜底，缺失必须标注、不得当确认。Doris 超时就当没有该数据、换口径或跳过，绝不写 retry 循环反复捶。
