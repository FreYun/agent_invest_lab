# 恒生指数投资框架（方法论）

这套方法论和 A 股单指数框架有一个**结构性不同，先说清**：恒生指数**没有可用的估值数据，也没有任何在 server 端预算好的择时因子**（没有 ERP、没有 ma200 偏离因子、没有 donchian catalog、没有拥挤度/换手）。能调到的港股择时数据**只有行情序列本身**。所以本框架不靠量化因子定仓位，而是靠**两条腿**：行情趋势位置（轻、定性、未经本指数验证）+ 宏观外部面（重、承重）。

- 标的：**恒生指数（HSI.HI）**，可买场外联接：**005659 南方恒生ETF联接C** / **005734 华夏沪港通恒生ETF联接C**
- **定位先说清**：恒生是港股大盘宽基底仓料，外资定价权大、南向资金边际影响在升、与美元流动性强相关。它的回报和风险大头来自**外部宏观环境**，不来自自下而上的成分挖掘——本框架据此把宏观面摆在承重位、把行情趋势摆在辅助位。

## 标的特性（决定玩法）

恒生指数 = 在港上市的大型股宽基（金融/地产/能源 + 部分科技与消费龙头权重高）。几条由此而来的硬约束：

1. **外部流动性是主驱动**：港股是离岸美元定价的市场，美联储/美元指数、港币与人民币汇率、全球风险偏好是它的第一位驱动——这套离岸资金逻辑决定了**宏观外部面在本标的是承重维度，不是点缀。**
2. **趋势/动量只能定性轻用**：港股外资主导、动量特征存在，但**本指数没有做过 walk-forward 择时验证**，所以趋势位置只用来定"方向偏进攻还是偏防守"，不当承重的精确仓位信号，更不允许据此满仓抄底。
3. **估值类玩法在本标的不可用**：没有估值分位数据，所以**不做"便宜了就抄底"的均值回归**——看不到贵贱，就不赌贵贱。

## 可调数据与硬约束（港股版诚实声明）

- **唯一可用的港股择时数据** = `market_index_quote(market='hk', symbols=['HSI.HI'])` 返回的日线 OHLC 行情序列。趋势位置（相对前高前低、均线位置、回撤幅度）需要你**从这段行情自己看**，没有工具替你算好。
- **不可用、不要去调**：`idx_ma200_deviation`（A 股代码格式 + A 股因子库，港股取不到）、donchian catalog（无港股条目）、`market_index_gzxjb` / ERP 分位、拥挤度、换手——这些对港股要么报错要么空，调了是浪费轮次、还容易误判。
- **滚动统计必须是过去窗口**：算均线/区间高低点一律用**截至当日 T 及之前**的数据，信号 **T+1** 执行，不偷看当日收盘后即时成交。

## 核心判断：行情趋势位置 +（每日必读）今日宏观面

### A. 行情趋势位置（从 `market_index_quote(hk)` 自判，定性、轻）

取近一段（约 120–250 个交易日）`HSI.HI` 日线，定性看三件事，合成"偏进攻 / 中性 / 偏防守"的方向温度：

- **相对位置**：现价靠近近 60/120 日**新高** → 趋势在上（偏进攻）；跌破近 60/120 日**前低** → 趋势转弱（偏防守）。
- **均线位置**：自算 60 日 / 120 日均线，价格稳在均线上方=多头结构，跌穿且均线走平向下=空头结构。
- **回撤**：现价距区间高点的回落幅度——回撤快速放大是减仓的早期提示。

> 这是**定性的趋势温度，不是验证过的择时信号**。它只回答"该偏哪边"，不直接吐出仓位数字；最终仓位由趋势温度 × 宏观面共振强度共同决定。

### B. 今日宏观面（每日决策前必读 `macro_news`）——港股权重最高的一条

每日做决策前，**单独**调 `get_market_report(report_type='macro_news')`，读 res7 资讯研究室预生成的今日宏观要点（货币/财政/会议/监管/国际/地缘/汇率/大宗，PIT、只含当前世界日及之前）。**注意 `report_type='all'` 不含这份，必须单独取一次。**

港股对外部面尤其敏感，这一步在恒生不是辅助、是承重输入，重点盯：

- **美元流动性 / 美联储**：加息缩表、美债利率、美元指数走强 → 港股离岸资金压力，偏防守；宽松转向 → 偏进攻佐证。
- **汇率**：港币触及弱方保证、人民币大幅波动 → 资金面警报。
- **地缘 / 中美关系**：关系恶化、制裁、地缘冲突 → 风险偏好压制；缓和 → 修复动力。
- **南向资金 / 中资政策**：南向持续流入、国内稳增长与地产政策松动 → 中资权重股支撑。

用法（**只做方向修正与证伪，不据此追高**）：

- 命中与持有逻辑**相悖**的宏观转向（美元收紧、地缘恶化、监管打压）→ 进「证伪」、优先减仓，**港股遇外部利空要果断减仓、不扛**（外部冲击对离岸市场传导快）。
- 命中**顺向**催化（流动性宽松、关系缓和、南向放量）→ 作为维持/加仓的承重佐证，但仍要趋势位置不背离才动手。
- 宏观面与趋势位置**打架**时（如行情新高但宏观转空）→ 降低进攻强度、以防守为先，等两者重新共振。

## 已知盲区（照实说）

- **没有估值锚**：贵贱不可见，所以本框架不抄"便宜"、不做均值回归，纯靠趋势顺势 + 宏观面证伪；牛市单边普涨时若趋势确认偏慢，会让出一段涨幅，这是无估值数据下的取舍。
- **趋势判断未经本指数验证**：可靠性弱于有量化因子的标的，所以仓位整体更克制、更依赖宏观面做风控刹车。
- **港股个股 / 成分估值不可查**：无法自下而上拆成分，只能在指数层面操作。
- **QDII 联接申赎与净值 T+2 滞后**：执行有延迟，别做高频进出。

# 仓位管理方法论

## 唯一信仰

- 恒生的活法 = **行情趋势定方向（轻）+ 宏观外部面定风险敞口（重）+ 回撤优先保命**。没有估值锚，所以**不赌均值回归、不抄"便宜"，只顺势 + 防外部冲击**。
- 进攻强度由"趋势温度 × 宏观顺向程度"的**共振强度**决定，**不设固定仓位上限**；两者背离或宏观转空时，主动收敛。

## 调仓纪律

- **T+1**：信号按当日收盘计算、下一交易日执行。
- **步长**：目标与当前仓位差很小（约 < 5%）时不动，省摩擦；常规一次调仓幅度温和推进，**遇明确外部冲击（宏观面承重利空 + 趋势破位共振）允许一次性大幅减仓**——离场要快。
- **回撤总开关**：账户级净值从峰值明显回撤时降仓、暂停加仓，优先级高于上面任何信号，防一错再错。港股波动大，这个刹车要敢踩。
- **成本**：QDII 联接申赎费 + 短期赎回惩罚，避免 7 日内同标的 round-trip；本是底仓，不该高频折腾。

## 风险底线（信号体系之外，按降级链处理）

1. **首选**：`market_index_quote(hk, ['HSI.HI'])` 有行情 + `macro_news` 可读 → 两条腿正常决策。
2. **行情取不到**：`market_index_quote` 失败 → 趋势位置判定暂停，**仅凭宏观面做防守性维持**，不主动加仓。
3. **宏观面缺失**：`macro_news` 暂无当前世界日报告（backfill 未覆盖）→ 用最近一期、并自动调低进攻强度（信息变旧就更保守）；连缺多日则按纯趋势位置保守操作。
4. **两者都缺**：**保持仓位不动**，沿用上一交易日目标仓位；连续 3 个交易日不可用再向 HQ 报错。
5. **不外猜**：不要用 `research_search` 等外部源臆造汇率/资金/政策读数；取不到就按上面降级，不编。

# 方法论迭代机制

规则不刻死，但**命脉在稳定，不轻易改**。

- **可迭代（参数层）**：趋势窗口长度（60/120/250 的取舍）、均线周期、回撤刹车阈值、调仓步长、宏观面各维度的相对权重。
- **不轻易动（原则层）**：宏观外部面承重、趋势仅作定性方向、无估值不抄底、回撤优先保命、QDII 低频。动这些要有反复验证的证据，否则就是被一段行情带偏。
- **触发是模式不是单笔**：同一类判断连续多次误导、某宏观维度系统性失灵、数据口径变更才迭代；单次减仓后短期踏空是顺势-防守框架的正常代价，不改。
- 迭代用 `update_my_strategy(bot_id, strategy, reason)` 整篇重写并写清 reason，进审计、下一交易日生效。

---

数据缺失或工具失败时按"风险底线"降级；上游超时就当没有该数据、降级或跳过，**绝不写 retry 循环反复捶**。
