# 通信设备指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，**先判市场环境（〇节，永远的第一步）**，再从下面几个角度审视，自行综合判断该不该动、动多少。

> 通信设备是 A 股**对全球 AI 算力资本开支最直接的敞口**——光模块是英伟达链在 A 股的"真·卖铲人"。它的玩法核心是：**认清当前行情由哪条 capex 周期驱动（云厂商算力 vs 运营商网络），用景气与文本面给方向，用趋势与回撤纪律给仓位**。估值分位在这里是弱信号，capex 指引与订单才是承重墙。

## 核心认知

中证全指通信设备（931160）≈ 50 只通信设备制造商：**光模块/光器件（中际旭创、新易盛、天孚通信等）+ 主设备（中兴通讯）+ ICT/交换机（紫光股份、锐捷网络）+ 光纤光缆与配套**。四个特性决定玩法：

- **双 capex 周期叠加，主驱动会切换**：指数历史上由**运营商 capex**（4G/5G 建设潮）定价，2023 年起切换为**全球云厂商/智算 capex**（AI 算力）定价。两条周期节奏、信号源完全不同——**看错主驱动，后面所有信号都会读错**。判断当前主驱动是每天的第一个问题（见〇节）。
- **全球链直连，海外映射极强**：头部光模块厂商供货北美云厂商，北美四大（微软/谷歌/亚马逊/Meta）capex 指引、英伟达财报与平台节奏（GPU 代际、网络方案）直接决定订单与情绪；美股算力链夜盘大波动 → 指数次日跳空是常态。**这是少数"先看海外、再看 A 股"的板块**。
- **高弹性 + 题材脉冲 + 深回撤**：高 β 成长，单边主升可一年翻倍，回撤 −40% 量级在样本内反复发生；事件（海外财报/技术路线传闻/制裁）造成的单日 ±7% 跳空频繁，**不适合死扛，也不适合追脉冲**。
- **权重高度集中于光模块**：指数走势高度由少数光模块/设备龙头的订单与业绩驱动，**必须穿透到龙头看**（排产、提价、份额、毛利率），不能当宽基。

### 通信设备的估值特性（先记住再看一节）：
1. **硬件订单周期股的 PE 会"骗人"**：景气上行时盈利暴增、PE 反而显得便宜（"便宜"是顶部特征之一）；景气下行时盈利坍塌、PE 飙高（"贵"反而可能在底部）。裸 PE 分位做均值回归择时**方向容易整个反掉**。
2. 真正的估值锚是 **一致预期斜率 + 订单可见度**：盈利上修周期里高 PE 可持续，盈利下修开始后低 PE 也接不住。
3. 估值只做两件事：极端泡沫的**定性预警**（配合全民进场信号），和极端便宜处**触发你去文本里找周期反转证据**——不是择时扳机。

## 〇、先判市场环境（永远的第一步）

任何信号读取之前，先回答三个问题并**显式留痕**（写进当日复盘，明天直接继承）：

**1）全市场环境：现在的 A 股欢迎高 β 科技成长吗？**
通信设备是全市场风险偏好的放大器。风险偏好收缩期（VIX 高位、信用利差走阔、市场情绪冰点、成长风格整体被压）它跌得比大盘深一倍；大盘价值/红利主导的风格窗口里它基本没行情。用 `macro_50etf_vix`、市场情绪指数（按累计与 z 读，不读单日）、大盘指数趋势粗判：**风险偏好扩张 / 收缩 / 中性**。收缩期里，后面所有看多信号自动降一档。

**2）板块自身状态：趋势市 / 震荡市 / 过渡待定（三选一）**
- 趋势市：均线（MA60/MA120）单边排列、斜率明显，价格沿一侧运行 → 用趋势骨架。
- 震荡市：长均线走平 + 价格在均线 ±10–15% 箱体反复、假突破频出 → 用防守骨架。
- 过渡待定：两边都不像 → 轻仓/维持原状态/观望。
**状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日跳空、单根假突破不算切换信号。宁可慢一拍，不在分类层来回翻。

**3）主驱动识别：现在这轮行情谁在定价？**
- **云厂商/算力 capex 主导**：信号源 = 北美 capex 指引、英伟达节奏、光模块订单——看三节 A 链。
- **运营商 capex 主导**：信号源 = 三大运营商资本开支指引、集采招标量价——看三节 B 链。
- **题材/事件脉冲**（卫星、量子、6G、某技术路线传闻）：不入景气打分，按事件单独评估，提防脉冲回补。
主驱动判断写一句话留痕。**环境错判，再好的纪律也会用反**——这一节没做完，不允许进入任何加减仓决策。

## 一、估值视角（定性预警，绝非择时扳机）

按"核心认知-估值特性"执行，要点重复一遍并补充操作含义：

- **禁止用 PE 分位对它做低吸高抛**。上升趋势 + 盈利上修周期里，"贵"不构成减仓理由；下行趋势里，"便宜"不构成接飞刀理由——**"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走/因为便宜所以接"，不是无视估值的通行证。
- **极端泡沫预警（顶）**：估值极端分位 + 全民进场信号（光模块成为全民词汇、新发主题基金爆量、研报口径从盈利切到"远期空间"）→ 当成趋势可能进入尾段的提示，配合趋势框架与止盈纪律处理。
- **极端便宜（底）**：极低分位 + 盈利下修已持续多季 → 不抄底，但**触发去文本里找周期反转证据**（capex 指引重新上修、订单回暖、新一代产品起量），证据出现且趋势企稳，按骨架快速回补。
- **盈利上修斜率比分位承重**：用 `stock_alpha` 龙头一致预期变动率做月度跟踪——上修在加速 = 行情燃料还在；上修放缓/转下修 = 顶部最可靠的领先信号之一（比价格破位早）。

## 二、趋势视角

- **方向锚**：收盘价 vs MA120/MA200 + 均线斜率；时序动量（20–60 日收益符号）做辅助。
- **量能/拥挤确认**：指数无量 → 用板块拥挤度代理。突破时拥挤度同步抬升 = 有量；不跟 = 可疑假突破。**拥挤度极端高位 + 价格加速 = 主升尾段特征**，对照止盈纪律。
- **跳空甄别**：海外消息跳空要分清**逻辑级**（capex 上修/订单落地 → 可顺势）还是**情绪级**（映射美股单日波动、技术路线传闻 → 易回补）。判别方法：第二天去研报/纪要里找有没有基本面增量；没有增量的跳空一律当情绪脉冲。
- 震荡市里均线信号反复打脸，转箱体思维（见仓位管理）。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（双链分开跟，主驱动链为主）

### A 链：云厂商/算力 capex（2023 起的主驱动）

传导：**北美云厂商 capex 指引 → GPU/网络平台出货节奏 → 光模块订单与排产 → 龙头营收/毛利率**。按领先滞后分层：

- **领先（母变量）**：北美四大 + 国内大厂的 capex 指引（季报季逐家扫，方向比金额重要）；英伟达数据中心收入与下一代平台节奏（新平台放量 = 高速率光模块代际切换 = 量价齐升窗口）。
- **同步**：光模块排产/提价/交期、新代际产品（更高速率）份额与价格——`[仅文本]`，靠研报与调研纪要。
- **滞后（确认不择时）**：龙头季报营收/毛利率。**等财报确认再动，通常已走完半程**——财报的价值是证实/证伪此前文本面读到的方向。
- **结构/上限**：代际切换（800G→1.6T→…）每一代都重新洗牌量价与份额；竞争格局（新进入者、海外友商）决定毛利率天花板。

### B 链：运营商 capex（退潮但会脉冲）

- 三大运营商年度资本开支指引（年报/中报季）、集采招标的**量与价**——量缩价跌 = 主设备/光纤光缆承压。
- 这条链当前不是主驱动，但**算力相关的运营商投资（智算中心、骨干网升级）**是结构亮点，注意区分"传统网络 capex 退潮"与"算力 capex 增量"。

**纪律**：两条链共用一个原则——**领先端（capex 指引/订单）定方向，滞后端（财报）做确认**；领先与滞后背离时信领先端。文本里"上调指引/订单饱满/提价"密度骤增本身也是情绪信号，按五节一致性纪律对照着读。

## 四、事件/政策视角（与景气正交的独立信号）

- **技术路线之争（CPO/硅光/LPO 等）**：市场周期性拿"新方案取代可插拔模块"砸盘。判断要点：**替代还是共存、时间表多远、现有龙头在新路线里有没有卡位**。有卡位的"替代叙事"对龙头常是虚惊；真替代且龙头缺位才是逻辑级利空。这类消息当日先按情绪脉冲处理，文本面核实后再定性。
- **制裁/关税/出口管制**：打的是哪一环？限制中国厂商供货海外（直接砍订单，逻辑级利空）vs 限制海外器件供中国（利好国产替代环节）——**方向可能相反，先分清再动**。海外产能（东南亚建厂）进度是对冲关税风险的关键观察项。
- **题材事件**（卫星互联网、量子通信、6G 路标）：对 931160 多是情绪外溢，不改变主逻辑，不入景气打分。
- **事件前减敞口**：重大海外财报夜（英伟达/北美云厂商）前后跳空风险大，事件不明朗时不赌方向。

## 五、文本视角（zsxq 调研纪要 + 新闻 + 研报，**每日必读、最高优先级信息源**）

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（机构调研纪要，PIT 截断到当日）+ `research_search`（新闻/研报）。**每个交易日必须执行，不允许跳过**——哪怕当天决定不动仓位。其他视角缺数据可降级，这个视角不读完不许收工。
>
> **为什么在这个指数上文本面权重必须高**：通信设备的母变量（capex 指引、订单、排产、技术路线、制裁）**没有一个是结构化数据**，全部活在研报、新闻、调研纪要里。丢掉文本面，这套框架就退化成纯价格量化——而纯价格因子在本指数只能做风险管理（见量化辅助节），**给不了方向与领先性**。文本面是这个框架相对纯量化的全部超额来源。

### 每日固定动作（3–5 次调用内完成，不许刷库）

1. **扫当日纪要流**：`zsxq_topics`（count=20）过当日新增调研纪要标题/摘要——光模块/交换机/主设备相关的标记下来；密度本身就是信号（机构密集调研某环节 = 关注度升温）。
2. **主题词检索**：`zsxq_search` 用 1–2 个当日主线词（如 '光模块'、'算力'、'CPO'；搜 0 条先看 `query_used` 换词重试）。需要正文再 `zsxq_topic_detail`，**最多 1–2 篇**。
3. **新闻/研报面**：`research_search`（search_type='all'）查当日 capex / 订单 / 制裁 / 技术路线增量；季报季加扫海外大厂 capex 表态。
4. **海外映射**：有夜盘大波动时，专项检索原因并分类：逻辑级（capex/订单/代际）还是情绪级。

### 怎么读（纪律——文本是信息也是毒药）

- **读事实与方向，不抄结论**：纪要 = "机构在看什么 + 公司说了什么"，是关注度代理 + 基本面事实源，不是买卖建议。
- **领先性分层**：capex 指引/订单类事实 = 领先信号，承重；研报观点/目标价 = 滞后的情绪代理，只做密度统计。
- **一致性观点逆向读**：文本流一致看多（研报集体上调、"星辰大海"措辞密度高）在趋势成熟期是反向信号、在行情 onset 期是领先信号——属于哪种，回到〇节的环境判断当场定，不给机械线。
- **证据落链（硬性）**：当日 belief/复盘 evidence 至少 1 条文本类条目（带 topic_id 或 INFOCODE + 一句话摘要）；没读到就如实写"今日文本面无增量"。**没有检索记录不许引用任何"听说/市场传言"**。
- **留痕（硬性）**：每日复盘固定一行 `文本增量: 无|低|中|高 —— <今天读到了什么、有没有改变判断或动作>`。
- **权重边界**：文本面给**方向与证伪**，不直接给仓位数字；任何文本信息都不得突破回撤控仓与仓位步长纪律。

## 六、证伪视角（对称化）

证伪是**论据的破坏**，必须对称——看多与看空的证伪都要列，触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 北美云厂商 capex 指引集体下修 / 首次出现"放缓数字化资本开支"措辞
  - 英伟达数据中心收入或指引低预期、下一代平台推迟
  - 光模块提价停止→砍单传闻→排产下修（文本面三连，逐级加重）
  - 龙头一致预期变动率由上修转下修（最早的硬信号）
  - 技术路线真替代证据：新方案放量 + 现有龙头无卡位
  - 制裁直接限制中国厂商供货海外大客户
- **看空被证伪（上行 veto-watch）**：
  - capex 指引重新上修 / 新增大客户或新代际产品超预期起量
  - 运营商算力侧投资超预期（B 链结构亮点放大）
  - 制裁靴子落地但订单未受损（利空出尽）
  - 盈利下修结束 + 趋势企稳（按〇-2 确认级证据）

# 仓位管理方法论

## 唯一信仰：环境定骨架 + 景气定方向 + 纪律压回撤

- 通信设备是**高弹性 + 事件密集 + 深回撤**品种，单指数策略夏普的提升几乎全部来自压低最大回撤。你的活儿是 capex 转向、技术路线冲击、系统性风险来时少亏；主升浪在场吃足。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理（轻仓/观望/维持原状态），不是习惯性下半注。
- 该在场时别缺席：capex 上行 + 趋势多头 + 文本面订单饱满时还空着 = 踏空，同样不及格。

## 一、骨架选择（承接〇-2 的状态分类）

- **趋势市 → 时序动量 + 波动率体感**：方向对就拿住让 β 跑；方向转空（趋势破位 + 景气链确认）降仓乃至清空。趋势里不做高抛低吸。振幅骤增本身是降仓信号——越平静越敢拿。
- **震荡市 → 防守、少动、守箱沿**：箱体中段不动手；轻仓不赌箱体（一条海外消息就能突破或跌穿）；不追假突破；放量/逻辑级催化突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- **过渡待定 → 维持原状态/轻仓**，等确认。

## 二、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%；2–5% 微调无意义。
- **系统性风险 / capex 转向确认 / 趋势转空 → 一把降到位，可以到 0**：本指数下跌常加速（海外消息夜盘传导 + 拥挤交易解杠杆），等"再确认一天"往往多亏 7%。
- **回补按赔率**：高赔率组合 = capex 上修 + 趋势放量突破 + 文本面订单饱满 + 拥挤度未极端 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。优势小却重仓 = 把数学优势送回去。
- **只在浮盈/趋势未坏的回调里加仓；绝不在下跌趋势中摊薄**（箱体有支撑的回踩可小幅低吸，趋势已破的下跌不能接）。

## 三、止盈止损：趋势 + 回撤说话，不用固定数字

- 在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势在、回撤温和 → 拿住；趋势破位/回撤明显放大 → 大块兑现乃至清空。
- **主升尾段的主动止盈**：拥挤度极端 + 估值泡沫预警 + 文本面一致看多三者叠加时，吊灯线收紧（从持仓高点回撤即减档），别等流动性反转才反应。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 四、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓/暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**（不得拿假想回撤反推事前仓位天花板）。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。本指数单边下跌很容易摸到深水区，这条更命。

## 五、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；事件脉冲多的板块尤其要克制高频。
- 每个仓位档**至少持有 3 个交易日**（thesis 持续性窗口）；期间只有趋势因子转空、账户回撤穿阈值、止盈触发三类信号允许跳档——单日情绪、单日跳空不打破持有窗口。

## 六、量化择时辅助（研究室 2026-06-11 全因子族扫描，验证于 931160 全周期）

> 离线扫描 44 因子（IS 2014–2021 / OOS 2022–2026.06，5bp 单边、T+1），**DD-止损整族绿灯**（族级鲁棒，非单因子幸存）。当作**客观第二意见 + 机械纪律提醒**，不替代框架打分。读数可用收盘序列按公式自算（尚未包进 `quant_factor`，已列待办）。

### `trail_dd10_p120`（主）—— 移动回撤止损
- **是什么**：收盘价从 120 日滚动峰值回撤超 10% → 空仓；收盘站回 MA60 → 满仓回归。OOS Calmar 1.74 vs buyhold 1.04，最大回撤 −22% vs −39%，CI[0.09,1.23]、wf 4/5。
- **会漏什么（公式可推）**：① 重入靠 MA60，**V 型反弹前段必然迟到**；② 价格在 MA60 与回撤线之间横盘时反复抽插；③ 只看价格，**对 capex 拐点、技术路线冲击、财报雷无预警能力**——它是断后的，不是侦察的。
- **怎么用**：= 0（触发离场）而框架还看多 → 优先逐项核验是不是文本面漏了什么；= 1 且框架看多 → 同号确认，可放大倾斜步长；框架看空而它还 = 1 → 不构成"再等等"的理由，框架主导。

### `dd_ladder_7_15`（辅）—— 两档回撤梯度
- **是什么**：从 120 日峰值回撤 ≥7% 砍半仓，≥15% 清仓，站回 MA60 满仓。比 trail_dd 多一个中间档（OOS Cal 1.49，CI[0.07,1.21]、wf4/5），翻转更多（83 次）但降仓更早。
- **怎么用**：当框架在"减不减"之间犹豫时，它的半仓档是个客观的"先减一半"提醒；两因子同时 = 0 是趋势 + 回撤双确认，**优先核验而非死扛**。

### 共同纪律
- 这族因子是**降回撤工具，不是收益增强器**——牛市里它的价值是让你拿得住（exp≈0.6 说明它大部分时间在场），熊市里替你机械断后。
- **不要写也不要执行"因子 = X 且 YY 时必须 ZZ"的未回测组合规则**；冲突本身是信号，逐项核验冲突来源再决策。

## 七、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 海外映射跌了要跟 | A 股有自己的节奏 | 分清**逻辑级**（capex/订单/代际变化 → 跟）还是**情绪级**（单日波动映射 → 看〇-1 环境，收缩期跟、扩张期当回调） |
| 估值太贵该减 | 趋势向上无视估值 | 盈利上修周期 + 趋势多头看 B；上修放缓 + 拥挤极端时极端读数当顶部预警 |
| 财报超预期要追 | 利好兑现是卖点 | 看**文本面是否早已 price in**：纪要/研报密度已沸腾的"超预期"看 B，市场仍将信将疑的看 A |
| 技术路线冲击快跑 | 替代叙事是虚惊 | 看龙头**有没有卡位新路线** + 替代时间表；有卡位 + 时间表远看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | capex 逻辑没坏的系统性恐慌看 A；capex 下修驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；拥挤极端 + 一致看多 + 量价背离看 B |

> **核心一句**：通信设备——先判环境（全市场风险偏好 + 板块状态 + 主驱动），用 **capex 指引与订单文本**给方向、**趋势/动量**给择时、**trail_dd/dd_ladder + 回撤控仓**机械断后；海外映射先分级再反应，拥挤极端先落袋，空仓不愧疚，靠压回撤把夏普做上去。
