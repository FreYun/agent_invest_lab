# 中证电网设备主题投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证电网设备主题（931994.CSI）**。

## 核心认知

电网设备（中证电网设备主题 931994）= **电网投资周期 + 招标驱动**的成长制造贝塔，覆盖特高压 / 配电网 / 一次设备（变压器、开关、组合电器）/ 二次设备（继电保护、智能电表、调度自动化）全产业链。它本质是**电网资本开支的下游兑现**：国网 / 南网的投资规划、特高压核准节奏、配网改造投资、新型电力系统建设决定了招标的量与价。三个特性决定玩法：

- **有稳定投资底盘**：电网投资是刚性公共开支，国网 / 南网年度投资额有底，比纯产能过剩周期（如光伏）的周期性弱、下行有支撑——不会出现全行业归零式的崩盘。
- **招标驱动、节奏强**：盈利兑现靠招标落地——核准 → 招标放量 → 中标确认 → 收入结算，有明确的"投资上行 / 平稳 / 招标下行"节奏。**招标量价（而非装机或终端用电量）才是盈利先行信号。**
- **出海是新增长极**：变压器、开关等一次设备出海（欧美电网更新换代 + 新兴市场电气化）打开了第二条增长曲线，相对独立于国内招标节奏、对原材料成本和海外订单更敏感。

驱动排序：**电网投资周期 / 招标节奏 > 招标量价 / 原材料成本（铜、电工钢、铝）> 趋势 / 资金 > 政策 / 出口 > 估值**。研究时问三件事：

1. 电网投资周期在哪个阶段（投资上行 / 投资平稳 / 招标下行）？→ 决定能不能重仓、招标底盘稳不稳
2. 趋势对不对、资金在不在？→ 决定现在是加是减
3. 招标量价 / 政策（特高压核准、配网规划、出口）变没变？→ 决定是不是该撤

### 电网设备指数特性：

1. **招标量增不等于利增**：电网投资额年年有底，但招标价格（电表、保护、变压器招标）的竞争烈度决定毛利，"投资上行、招标价杀、利薄"是常态。看投资额的同时**必须看招标价与原材料成本**（铜、电工钢、硅钢、铝）。投资放量 ≠ 能赚钱，**招标价企稳 + 成本可控才是盈利兑现的关键**。
2. **投资底盘提供下行支撑**：与纯过剩周期不同，电网投资是刚性公共开支，行业利润很少坍塌到全面亏损——估值 / PB 在悲观期被压低时，往往是配置区，因为投资底盘还在。要找"招标量价企稳、核准 / 规划兑现、原材料成本回落"的修复信号。
3. **招标量价 + 核准节奏是先行指标**：特高压核准条数、配网招标量、电表 / 保护招标价的拐点，**领先**收入与盈利。核准放量 → 招标放量预期 → 股价启动；盯招标和核准比等财报及时。
4. **政策与出口是双驱动**：国内（特高压核准、配网投资规划、新型电力系统、电力市场化改革）和出口（变压器出海——欧美电网更新 + 新兴市场电气化、海外关税 / 认证）直接左右需求与订单；变压器出海绑定海外电网投资、相对独立于国内招标节奏，景气与主链常不同步。既是 α 来源，也是杀伤来源。

## 一、电网投资周期视角（电网设备的核心价值锚）

电网设备是招标驱动的成长制造，**盈利由电网投资周期与招标节奏主导，不由终端用电量增速主导**。把投资周期分三阶段定位：

- **投资上行（特高压 + 配网开工密集、招标放量）**：国网 / 南网资本开支加速、特高压密集核准、配网改造投资兑现、招标量放量——盈利估值共振向上，**主升段，重仓吃 β**。
- **投资平稳（招标按计划节奏推进）**：投资额维持高位但增速放缓、招标按既定规划匀速落地、量稳价稳——震荡为主，看结构（哪个环节边际改善）选环节，指数层面不轻易重仓。
- **招标下行（核准 / 招标节奏放缓、价格内卷）**：核准放缓、招标量收缩或招标价持续下杀、原材料成本上行挤毛利——盈利承压，**趋势转空就降仓**；但有投资底盘，通常不会戴维斯双杀式坍塌，更多是杀估值 + 杀盈利节奏放缓。

判断阶段看三件事：**电网投资额 / 资本开支（在不在加速）、特高压核准 + 配网招标量（拐点在哪）、招标价 + 原材料成本（量价利能不能兑现）**。成分股毛利 / ROE 是滞后验证，不是先行信号。

## 二、估值视角（用 PB 与招标景气，不用 PE 分位均值回归）

电网设备是成长制造指数，**禁止用 PE 历史分位简单做均值回归择时**：招标下行期盈利节奏放缓让 E 缩水，PE 容易冲到偏高分位——方向可能误导。

估值换一套锚：

- **PB + 招标景气 / ROE**：低 PB + 招标量价触底回升 + ROE 即将修复 = 底部布局信号；高 PB + 招标见顶 / 原材料成本失控 = 顶部预警。PB 必须配合投资周期阶段用。注意电网设备有投资底盘，PB 下行空间通常比光伏窄。
- **招标量价隐含的盈利预期**：招标价企稳 + 核准 / 规划放量 → 未来收入与盈利修复，比当下 PE 更能反映"贵不贵"。
- **极端泡沫的定性预警**：全民进场（新基金爆发、研报一致"特高压 / 出海无敌"、龙头估值脱离任何盈利锚）时当顶部提示，配合趋势减仓——而不是单看一个估值数字。

成长性（特高压空间、出海订单空间、新型电力系统投资底盘）只用来判断**值不值得在景气里重仓**，不用来在招标下行里盲目抄底。

## 三、供需与景气视角（盯投资—招标—成本的趋势一致性）

电网设备单一主题但分环节，单一指标失真。看六个维度的趋势一致性：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 投资 / 招标 | 国网 / 南网投资额、特高压核准条数、配网改造投资、各环节招标量 | 核心（决定盈利兑现节奏） |
| 价格 / 成本 | 招标价（电表 / 保护 / 变压器）、铜 / 电工钢（硅钢）/ 铝成本 | 先行 / 挤压（领先毛利与股价） |
| 需求 / 出口 | 变压器出口订单、海外电网投资、新兴市场电气化、电表招标量 | 成长底盘 + 第二曲线 |
| 盈利 | 成分股毛利率 / ROE、订单兑现节奏 | 滞后验证 |
| 资金 | 北向、ETF 份额、融资余额、产业资本动向 | 情绪 / 边际 |
| 政策 / 出口 | 特高压核准、配网规划、新型电力系统、电力市场化、出口关税 / 认证 | 催化 / 双刃 |

**投资 / 招标节奏与价格成本是盈利兑现的主导，出口是第二曲线底盘，政策核准是格局变量**，共振时信号最强。看趋势一致性（多维同向），不是加权打分。投资底盘是底色，但**招标量价和成本才决定这一轮能不能赚钱**。

## 四、趋势与资金视角（择时主轴）

电网投资周期定"值不值得拿"，趋势 / 资金定"现在动不动"。电网设备受投资周期驱动、趋势持续性强，趋势是吃住主升段、避开招标下行段的主力。

- **方向锚**：指数 vs 200 日均线，配合量能确认突破 / 跌破的强度。
- **资金面**：北向、ETF 份额、融资余额、产业资本动向——增量资金是主升燃料，资金撤离 + 价格走弱是顶部信号。
- **波动率**：振幅骤增、急涨急跌 = 环境恶化信号，本身就是降仓理由。

研究时不问"涨没涨"，问"趋势和资金的方向，配不配合电网投资周期的判断"。**投资 / 招标拐点（左侧）+ 趋势确认（右侧）共振，是最强的进场点。**

### 量化趋势择时辅助：donchian_60

**donchian_60 趋势突破是经全周期验证的绿灯**，可作右侧择时；trail_dd15 亦为绿灯，但优先 donchian_60。

**经济逻辑**：电网设备受电网投资周期驱动、招标节奏带来的趋势持续性强、突破有效——低翻转拿住投资上行的主升段，跌破离场避开招标下行的杀盈利杀估值段。

**怎么用（判断，不机械执行）**：把 donchian_60 当"现在动不动"的右侧择时第二意见，**权重 ≤ 投资周期主维度**。先看电网投资周期定方向，再用趋势确认进出节奏；两锚共振确信度最高，冲突时以投资周期 / 招标逻辑为准。突破在无趋势震荡区（投资平稳期）会反复假动作、有成本，下行保护仍以"投资周期 + 招标量价 + 证伪"为主，趋势因子只是右侧补刀。

## 五、风险管理视角

电网设备的杀伤来自招标节奏放缓与原材料成本失控叠加，不是日常震荡。主要风险：

- **招标下行 / 量价双杀**：核准放缓 + 招标价内卷 + 原材料涨价 → 收入与毛利一起承压。电网设备最大的杀伤，常在"投资额仍有底盘"时悄悄发生（量在、价杀、利薄），最具迷惑性。
- **原材料成本冲击**：铜、电工钢（硅钢）、铝大幅上涨且无法向招标价转嫁，直接吞噬毛利——尤其变压器、组合电器等重材料环节。
- **出口 / 贸易**：海外关税、认证壁垒、地缘扰动落地，直接砍变压器出海订单与海外溢价（出海是这一轮的关键 α，反向就是关键风险）。
- **拥挤度**：赛道交易过度拥挤、一致预期（特高压 / 出海）太强，任何边际利空引发踩踏式回调。
- **流动性**：成长制造在系统性流动性收紧时跌得快、深。

原则：**投资在招标下行、招标价在内卷、原材料在上行、趋势已破、拥挤度高时，仓位越保守**。止损纪律不能省，但杀伤主要靠"投资周期 + 趋势"提前离场，不能只等价格止损。绝不在招标下行 + 成本恶化的下跌趋势里越跌越买。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（投资上行 / 招标回暖 + 趋势在场 + 出海没证伪）的破坏**。下列任一发生，应严肃重评持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **投资 / 招标证伪**：电网投资额增速持续回落、特高压核准放缓、配网招标量收缩、招标价二次破位下行。
- **成本证伪**：铜 / 电工钢 / 铝成本持续上行且无法向招标价转嫁，成分股毛利率连续恶化。
- **趋势证伪**：跌破 200 日均线且 1 月未收回，伴随量能放大。
- **出口证伪**：变压器出海订单不及预期、海外关税 / 认证壁垒落地（第二曲线逻辑作废）。
- **政策证伪**：特高压核准 / 配网规划反复、新型电力系统推进节奏放缓，砍掉重要需求底盘。
- **拥挤证伪**：估值脱离任何盈利锚 + 拥挤度极高 + 资金爆量流入（非理性繁荣顶部）。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作：先识别指数当前由哪个环节主导，再判断投资周期阶段、招标量价、趋势资金是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导环节，再定强弱

电网设备指数由特高压 / 配电网 / 一次设备 / 二次设备等环节构成，常不同步。每天先问两件事：

1. **谁在主导指数**：看成分权重、领涨领跌成分、成交额集中在哪个环节（特高压、配网、变压器 / 一次设备、电表 / 保护 / 二次设备），判断当前交易的是特高压核准、配网投资兑现、变压器出海，还是纯指数 beta。
2. **主导环节信号强不强**：主导环节的投资 / 招标、价格成本、需求出口、盈利、趋势、资金是否同向。不能用变压器出海的利好去解释二次设备招标价内卷导致的下跌。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 投资 / 招标、价格成本、趋势、资金至少三项同向，且无重大证伪 | 可做大动作，20%-40% 步长 |
| 中信号 | 两项同向、一项待确认，或产业信号强但趋势未确认 | 轻仓试、持有、等右侧确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线反弹但投资周期未变 | 只记录，不交易或极小动作 |

研报观点本身不是交易信号，只提供假设与数据线索，必须被招标量价、核准节奏、原材料成本、财务和行情共同验证。

## 二、环节主导矛盾

| 环节 | 核心矛盾 | 重点指标 | 典型证伪 |
|---|---|---|---|
| 特高压 | 核准节奏（直流 / 柔直放量） | 特高压核准条数、开工 / 招标进度、直流 / 柔直占比 | 核准放缓、招标推迟、线路规划缩水 |
| 配电网 | 改造投资兑现（一二次融合） | 配网改造投资额、招标量、一二次融合渗透 | 配网投资不及规划、招标兑现滞后 |
| 一次设备（变压器 / 开关 / GIS） | 出海订单 + 原材料成本 | 变压器出口订单、海外电网投资、铜 / 电工钢 / 铝成本、毛利 | 出口订单不及预期、原材料失控、海外关税 |
| 二次设备（继保 / 电表 / 调度） | 招标量价（招标驱动） | 电表招标量价、继电保护招标、调度自动化订单 | 招标价内卷、电表招标量下滑、保护招标推迟 |

子环节分化时按权重与边际排序：**权重大且边际改善 > 权重大但继续恶化 > 权重小但高景气**。只有权重大环节或多环节共振，才允许指数层面重仓。

## 三、数据核验清单

每次交易判断前至少完成四层核验。数据缺失可用研报 / 新闻兜底，但必须标注缺失，不能把缺失当确认。

| 层级 | 必看数据 | 数据可得性与工具（回测已校准） |
|---|---|---|
| 指数层 | 931994 收盘 / 均线 / 趋势、成交额、主要成分涨跌贡献 | 行情用 `market_index_quote(market="cn", symbols=["931994.CSI"])` **自取**——每日预取快照只含五个宽基，不含 931994，也不含 PE/PB；指数级 PB / PB 分位无直接源，用 `stock_market` 取成分股估值聚合近似或当缺失 |
| 原材料价格 | 铜 / 铝期货价；电工钢（硅钢）调研报价 | 铜 / 铝期货用 `commodity_market(market_type="futures")`；电工钢 / 硅钢**调研报价**无结构化时点源，只能 `ttjj_research_search` / `research_view` 文本兜底，时点下可能稀疏甚至为空 |
| 投资招标 | 电网投资额、特高压核准条数、配网招标量、电表 / 保护招标量价、变压器出口订单 | **均无结构化时点源**，只能文本兜底，必须标注"文本推断、可能缺失"，不得当硬数据 |
| 盈利资金 | 成分股毛利率 / ROE、一致预期、个股北向、研报观点 | 成分股财务用 `stock_financial_quality`、一致预期用 `stock_alpha`、个股资金 / 北向用 `stock_capital_flow`（逐成分股聚合）；ETF 份额、融资余额、指数级北向无结构化源，文本兜底 |

工具优先级（已按回测可用工具校准）：

1. 行情 / 估值 / 财务 / 资金优先用时点工具：指数 `market_index_quote`、成分股 `stock_market`（含 PE/PB）、`stock_financial_quality`、`stock_alpha`、`stock_capital_flow`、商品 `commodity_market`、宏观 `macro_data`、基金 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
2. 招标量价、核准节奏、电网投资额、出口订单这类**无结构化源**的数据，用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 文本兜底；搜索窗口相对上游当前时间、时点下可能稀疏甚至为空，缺失必须标注。关键词：`电网 投资 特高压 核准`、`配网 改造 招标 一二次融合`、`变压器 出口 出海 订单`、`电表 继电保护 招标 中标`。
3. 关键数据至少两源交叉验证（研报、行业协会、公司财报、行情、新闻），任意两类相互印证才算中信号以上。

## 四、交易决策矩阵

| 投资周期 | 招标量价 | 趋势 / 资金 | 估值 / 盈利 | 动作 |
|---|---|---|---|---|
| 招标下行 | 招标价持续内卷或核准放缓 | 跌破 200 日线（且 ≥1 月未收回），资金趋势性流出 | 盈利继续下修 | 清仓 / 不参与 |
| 招标下行 | 短暂回暖但未企稳 | 弱反弹，无资金趋势性流入 | PB 低但 ROE 仍恶化 | 观察，不抄底 |
| 投资平稳 | 招标量价企稳 + 成本可控 | 趋势未确认，量能一般 | PB 低，盈利仍待修复 | 左侧轻仓试探 |
| 投资上行早期 | 多环节招标企稳回升 | 站上 200 日线，资金趋势性回流 | ROE 修复预期出现 | 加仓到中高仓 |
| 投资上行 | 核准放量、招标量价齐升 | 200 日线之上，资金持续流入 | 盈利上修 | 重仓持有 / 回调加仓 |
| 高位见顶 | 招标价 / 出海订单冲高后明显见顶（连续 1+ 月） | 跌破 200 日线 + 量能背离 | 估值拥挤，盈利预期过满 | 分批减仓 |
| 逻辑证伪 | 招标、核准、成本或出口破坏买入逻辑 | 200 日线破位且资金撤离 | 盈利验证失败 | 快速降仓乃至清空 |

**矩阵使用约束**：四列要**共振**才触发动作；只有一两列变化（尤其趋势 / 资金单独变化）= 信号不足 = HOLD。趋势 / 资金看方向性变化，不是单日抖动。

## 五、研报到交易动作的转换

读研报五步走：

1. **提炼结论**：研报在看多什么——特高压核准、配网投资、变压器出海、电表 / 保护招标，还是估值修复。
2. **拆假设**：拆成可验证假设，如特高压核准放量、配网招标兑现、变压器出口订单超预期、原材料成本回落。
3. **找证据**：用行情、招标量价、原材料成本、财务、行业数据和其他研报交叉验证，不接受单一卖方口径。
4. **映射矩阵**：把验证后的信号放进决策矩阵，证据不够就停在观察或轻仓。
5. **写反证**：每次动作写一句"什么发生就说明我错了"，便于证伪与复盘。

研报只讲投资底盘、不讲招标价和成本；只讲长期空间、不讲短期盈利兑现；只讲出海故事、不讲订单落地节奏的，降级为弱信号。

# 仓位管理方法论

## 唯一信仰

- 电网设备的超额，来自**在招标回暖 / 投资上行 + 趋势确认时重仓吃产业上行 β，在招标下行 / 成本失控 + 趋势转空时果断降仓躲开杀盈利杀估值**——不是靠见低 PE 抄底，也不是靠死扛"电网投资有底盘"。
- 仓位由**投资周期阶段（价值锚）+ 趋势 / 资金（择时锚）双锚**共同决定，没有固定上下限——空仓、满仓都合法。**空仓躲过招标下行 + 杀估值的大跌，是这个策略最值钱的动作。**
- **允许左侧、但要纪律**：投资周期底部（招标量价企稳 + 核准 / 成本回暖信号）可分批左侧布局；右侧趋势确认才上重仓。绝不在招标下行 + 成本恶化的下跌趋势中越跌越买摊薄——那是接量价双杀的飞刀。
- 不用硬止盈硬止损，用投资周期 / 趋势 / 招标量价 / 回撤说话。
- **对本金极度保守，对产业 β 适度放纵**：亏损端要窄、要果断；景气主升的浮盈端给空间、让 β 跑。

## 一、仓位步长：大开大合，不做微调

- 账户灵活，能快速空仓、也能快速满仓。每次动手都是有意义的大动作，最小步长 20%。
- 离场可以一把到 0；进场看确认强弱，一把到位或分 2–3 个大步。

## 二、先识状态：投资周期阶段 + 趋势市 / 震荡市

先定**投资周期阶段**（招标下行 / 投资平稳 / 投资上行 / 高位见顶），再看**价格是趋势市还是震荡市**，两锚叠加定打法：

- **投资平稳 / 底部回暖 + 趋势开始转多** → 左侧轻仓试 + 右侧确认加重，最好的赔率区。
- **投资上行 + 趋势向上** → 顺势重仓拿住让 β 跑，回调不破趋势就加。
- **招标下行 + 趋势向下** → 降仓乃至清空，绝不抄底摊薄。
- **高位见顶 + 趋势走坏** → 果断兑现，别恋战。
- 震荡市（投资周期未明、均线缠绕、招标平稳期）→ 转箱体思维，箱底买、箱顶减，别在趋势里被甩下车。

## 三、双锚骨架：投资周期（价值锚）+ 趋势 / 动量（择时锚）

- **投资周期锚**：决定"值不值得拿、招标底盘稳不稳"。招标回暖 + 量价企稳 = 价值底，投资上行 = 主升，招标下行 + 成本失控 = 别碰。**用 PB + 招标景气，不用 PE 分位。**
- **趋势 / 动量锚**：决定"现在在不在场"。向上吃 β，转下降仓，避开招标下行的杀估值段——压回撤的主力，量化上用 donchian_60 辅助确认。
- **叠加**：投资周期决定仓位中枢能开多高，趋势 / 资金决定现在往中枢上方还是下方走。**两锚共振（招标回暖拐点 + 趋势确认）才上重仓；两锚背离就留一手。**

## 四、非对称操作：离场要快、回补看投资拐点 + 趋势确认

- **招标下行 / 成本失控 / 趋势转空 → 一把清到位，可以直接到 0**。电网设备虽有投资底盘，但杀起盈利和估值来仍快，等"确认"就晚了，宁可错杀。
- **重新进场 → 看投资拐点 + 趋势确认**：招标价止跌企稳、核准 / 配网招标放量、原材料成本回落、趋势重新转多——四者越齐加得越重；信号不齐就轻仓或放弃。**宁可错过，不可做错。**
- **只在投资上行 / 趋势没走坏的回调里加仓，绝不在招标下行 + 成本恶化的下跌趋势中补仓摊薄（接飞刀）**。底部招标回暖的左侧试仓（小、分批、有量价支撑）可以接；招标仍恶化的下跌不能接。

## 五、止盈止损：用投资周期、趋势、招标量价和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓盯四件事：**招标量价 / 投资有没有见顶反转、趋势破没破、资金撤没撤、从持仓高点回撤了多少**。投资上行 + 趋势在场 + 回撤温和 → 拿住让 β 跑；招标见顶 / 趋势破位 / 资金撤离 / 回撤放大 → 大块兑现乃至清空。
- **移动止盈**：利润越厚越用"从高点回撤"保护，而非看绝对涨幅。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定程度把减仓线抬到成本价——这笔从此最差打平，绝不让赚钱的高 β 仓位因投资周期反转重新变亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 回撤数学不对称：亏 50% 要翻倍才回本。先保证不大亏比博大赚更决定长期复利——电网设备虽有底盘但波动仍大，回撤控制尤其要紧。
- **你自己账户**从峰值明显回撤、且伴随招标 / 趋势恶化时，大幅降仓乃至清空、暂停加仓——哪怕"电网投资长期空间还在"。长期空间不是死扛短期杀盈利的理由。
- 回撤收复、招标 / 趋势重新转友好，再按第四条回补。

## 七、成本意识

- 电网设备波动大、机会多，但每次进出都要掂量摩擦：**指增 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。做的是投资周期 + 趋势的大波段，频率天然不该太高——别做成高频。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金 / 指增组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD**；只有研究状态发生足够大的变化才允许交易。短线行情只能作验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清、证据不够时，默认不参与，或只用 **40%** 小仓位试探。
- 当投资周期、招标量价、原材料成本、政策 / 出口、资金和趋势形成清晰共振时，敢于大胆干，仓位可提到 **50%–100%**。
- 进攻前先确认自己在"状态明确"而非"情绪冲动"；没有状态迁移，就算短线好看也不放大仓位。
- 回撤一旦恶化，先保命再谈进攻：减仓、暂停加仓、必要时回防守档。
- 原则：模糊期求稳，确认期进攻，回撤期收缩。

### 1. 交易触发闸门

交易前必须回答：**今天的研究结论相对上次持仓决策，发生了什么状态变化？** 只有下面几类变化可触发交易：

- **投资周期变了**：招标下行 → 投资平稳 / 投资上行，或投资上行 → 高位见顶 / 招标下行。
- **招标量价变了**：电表 / 保护 / 变压器招标价、招标量连续企稳 / 回升，或二次破位。
- **投资 / 出口变了**：电网投资额、特高压核准、配网招标、变压器出口订单数据改变此前判断。
- **政策 / 成本变了**：特高压核准、配网规划、电力市场化、出口关税，或铜 / 电工钢 / 铝成本改变中期盈利假设。
- **风险状态变了**：核心逻辑证伪、账户回撤明显扩大，或系统性流动性恶化。

只是 MA5/MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化而无上述研究状态变化，**不得交易**，只记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买卖加减的主因。
- 200 日均线 / donchian_60 可作中期趋势确认或风险线，但必须与投资周期、招标量价、资金、证伪一起用。
- 连续涨跌、单日涨跌幅、短线趋势计数只能影响"今天是否更适合执行已成立的研究动作"，不能创造新交易理由。
- 交易理由若主要由均线、阳线数量、趋势计数构成，自动降级为 **不交易 / 继续观察**。

### 3. 费用与预期收益门槛

- 交易前估计本次动作能否覆盖申购 / 赎回 / 早赎成本，覆盖不了不做。
- 为躲一天波动而交易通常不值得；为应对中期逻辑证伪而交易才值得。

### 4. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**，顺序固定：

1. 当前投资周期阶段是什么，和上次相比有没有变化。
2. 招标量价、投资 / 出口、政策 / 成本、资金趋势是否支持状态变化。
3. 是否触发交易闸门；若没有，明确写"研究状态未变，场外基金默认持有 / 空仓观察"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是研究确认后的中期波段，不是 MA5/MA20 的短线抖动。

> **核心一句**：在招标回暖 / 投资上行 + 趋势确认时重仓吃电网设备上行 β，在招标下行 / 成本失控 + 趋势转空时果断降仓躲杀盈利杀估值——靠"投资周期定底、趋势资金定时（donchian_60 辅助）、量价背离时不贪"赚周期成长，不靠死扛电网投资底盘。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新政策工具、新招标规则、新出海格局、新供需结构）。
- **定期 + 事件驱动**：一轮电网投资周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / donchian 周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各环节（特高压 / 配网 / 一次设备 / 二次设备）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（招标回暖 + 趋势确认重仓、招标下行 + 转空降仓）、双锚结构（投资周期 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀、宁可错过不可做错、对本金保守对 β 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；投资周期切换、出海格局重置、政策框架重置是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
