# 创新药指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少，每次操作至少是20%仓位。


## 核心认知

创新药 = 把**未来研发管线 + 政策环境**折现到今天的**贴现游戏**，业绩与价格都靠"未来事件兑现"驱动。四个特性决定玩法：

- **二元事件驱动**：单一临床读出 / NMPA-FDA 批准 / 海外授权（License-out）/ 国谈结果，单日可大幅波动，且方向常与短期 K 线无关。
- **超长 R&D 周期 + 现金流即生命线**：管线从 IND 到上市常 8–10 年量级，期间持续烧钱；Biotech 类公司**现金跑道**短于 18 个月时估值会被压到谷底，跑道 < 12 个月直接对应"被动稀释"风险。
- **管线即估值**：相当一部分龙头长期亏损或微利，PE 失效；市场用 **rNPV / 管线分布 / 重磅候选药潜力 / PS·EV**估值，看的是未来现金流贴现路径，不是当期报表。
- **极致分化与龙头穿透**：指数 ≈ 少数龙头（恒瑞 / 百济 / 信达 / 君实 / 翰森 / 中国生物制药 / 复宏汉霖 / 康方 / 荣昌 / 艾力斯等）+ 一长串小票的篮子，**龙头管线节奏与 BD 节奏左右指数方向**，必须穿透到龙头管线看，不能只当宽基。

催化兑现 + 管线进度 > 仓位择时 > 选品；**事件驱动 + 现金流安全边际**思维 > 长期持有不看牌。

## 一、估值视角（定性预警，绝非择时扳机）

对创新药这种**长期亏损 + 管线贴现 + 事件驱动**的成长指数，**禁止用 PE 历史分位做均值回归（低吸高抛）择时**，原因比一般成长股更硬：

- **分母大面积失效**：指数里相当一部分龙头长期亏损或微利，PE 要么是负、要么是天文数字；E 一变号分位完全失真，常在底部对你大喊"贵"，在管线兑现期对你大喊"该跑"。
- **市场用 rNPV / PS / 在管线估值**：创新药牛市本质是**贴现率下行 + 重磅管线兑现概率上修**带来的 re-rating，市场会切到 PS、EV/Sales、TAM × 渗透率、单管线 rNPV 加总等口径，静态 PE 分位无效。
- **样本太短**：港股通创新药指数发布几年，A 股科创板龙头多数 2019 年后才上市，"分位"接近全样本，没有稳定"正常区间"。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端估值读数一票否决。极端读数仍是要认真对待的定性信号。

所以估值在这里只做两件**定性预警**的事（不是择时扳机）：
- **极端泡沫预警（顶）· froth 信号按"软 / 硬"分级，别一刀切**：
  - **软极值（常响 → 只停加仓）**：全民进场信号（散户开户创新高、创新药主题新基金爆发、研报"非理性繁荣"、所有概念股不看管线齐涨、连无管线的"贴牌创新药"都被爆炒），或量化因子转向（拥挤度三件套冲高、`market_sentiment` 市场情绪过热、ERP×VIX 偏贵 + 自满）→ 当成"趋势可能见顶"的提示。**这些是逃顶辅助，不是 fade 扳机**：趋势健康（动量未转头、量价未背离、未跌破关键均线）时，单凭拥挤 / 过热极值**最多停止加仓，绝不据此减仓 / 清仓**；必须等它与趋势 / 动量走弱**同号共振**（动量转头 + 量价背离 + 破位）才配合趋势框架减仓。趋势里把软极值单独当卖出信号，会被一整段主升浪甩下车——这是上一轮 run 把创新药主升浪整段踏空的根因。
  - **硬极值（罕响 → 可削 froth 顶层一小片）**：唯独 **`sector_factor_detail` 的 MA200 乖离率冲到极端高位**（价格大幅脱离 200 日均线、进入本指数极少出现的过热区）这一档，性质和上面的软极值不同——**用绝对乖离率，不要用乖离分位**（分位在熊市底部因相对窗口失真，会在便宜区给出假高读数，方向会反）。它**极罕见**，所以即便动量还没转头，也允许**把 core 之上的进攻 / froth 顶层减掉一小片**（**不清仓、不动 core 底仓**），乖离回落到常态档再把这一层补回。逻辑：froth 顶层骑着极端乖离一路坐回去的代价，大过这一小片少跑的那点 Beta；**但 core 始终由基本面 thesis 决定去留，绝不拿"范式 / 基本面还在"当扛 froth 顶层的理由**——基本面只为 core 背书，不为最尖那一片 froth 背书。
  - **可靠性**：硬极值是**单一维度、且本指数可用历史不长**的预警，作"froth 顶部该削一刀"的提示用，**不是精确抓顶扳机**；它与软极值同号、或与动量走弱共振时，才升级为更大的减仓动作。
- **基本面拐点预警（底）**：出现**重磅 BD 授权落地 / 关键 III 期阳性读出 / 国谈底价确认温和 / Biotech 现金跑道延长 / 龙头研发费用拐头**等基本面拐点证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是事件 / 管线证据，不是低 PE 分位（分位对它是噪音）。

**真正的"价值标尺"是管线兑现概率 × 市场空间**：重磅候选药 III 期阳性读出 + 海外授权打开海外市场 + 国谈以温和让利换医保放量 → 管线 rNPV 整体上修，趋势里值得重仓；管线核心品种屡屡失败、海外授权悬空、医保谈判超预期压价 → 该方向估值天花板下移，重仓需更谨慎。这条决定"值不值得在趋势里重仓"，不用来抄底或择时。


## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。

- **方向锚**：指数 vs 200 日均线（收盘价即可算均线 / 时序动量，足够）。
- **量能确认（板块代理）**：指数取不到量 → 用 `sector_factor` 风险分（成交集中度）/ `sector_factor_detail` 拥挤度代理"有没有量配合"：突破时板块拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破（创新药事件多，单条 BD 传闻 / 学术会议 abstract 发酵后回吐极常见，无量突破假概率高）。
- **波动率（板块代理）**：指数算不出 ATR（无高 / 低）→ 用**收盘价滚动波动率** + `sector_factor_detail` 的 **MA200 乖离率**代理；波动 / 乖离骤增即降仓信号。学术会议季（4 月 AACR、6 月 ASCO、9 月 ESMO、12 月 ASH、1 月 JPM）波动会异常放大，须主动给系数。
- **事件跳空甄别**：临床读出 / 监管批文 / BD 公告 / 国谈结果常造成跳空，要分清这是**逻辑级利好（关键管线兑现 / 海外授权重定价 / 加速审批授予）**还是**情绪脉冲**（小适应症扩展、不重要的中间数据、传闻级 BD）——前者可顺势，后者易回补缺口。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。


## 三、景气度视角（创新药专属：管线 + BD + 政策为母变量）

创新药的景气有**清晰的事件传导链条**，按性质分四类，别用滞后指标做择时（具体取数见上「取数」节）：

- **领先（母变量）**：临床管线进度（IND → I/II/III 入组 → 读出节奏）→ 学术会议数据曝光（ASCO/ESMO/AACR/ASH/JPM 等）→ 海外授权 / BD 节奏（首付款 + 里程碑 + 销售分成）→ 监管受理 / 批准（NMPA 优先审评、FDA BTD / PDUFA）——这四档同向时信号最强。
- **滞后（确认而非择时）**：上市产品营收 YoY / 进入医保后的放量数据 / 一致预期修正，跟随领先端，不当择时锚。Biotech 类亏损公司则改盯**现金跑道 + 经营性现金流**作为生存性确认。
- **结构 / 上限**：医保覆盖、适应症广度、TAM × 渗透率、海外可及市场——决定空间天花板与重仓信心，不决定主趋势的开关。
- **事件驱动**：国谈、集采、加速审批通道、ICH 互认、DRG / DIP 推进、突破性疗法 / 优先审评授予——跳空催化，事件级单独评估。

- **管线 + BD 是母变量**：临床读出和海外授权领先营收数个季度乃至数年（biotech 甚至先于营收存在）。**看管线节奏与 BD 落地的方向，不看当期营收**（营收是滞后确认，等它转向就晚了，对未上市品种甚至根本没营收可看）。
- **现金跑道是 Biotech 最好用的生存性指标**：理想上现金 / 季均烧钱比反映"还能撑多久走到关键读出或上市"；实际财报披露口径分散，需结合 `financial_quality` 现金 + 研发费用 + `research_search` 融资公告（定增 / 配股 / BD 首付款回血）综合估算 → 跑道 < 12 个月须警惕融资稀释或断链；> 24 个月给充分耐心。
- **医保 / 集采是结构 / 上限指标**：进医保（国谈降价）短期 EPS 受挫但**以价换量**打开放量空间，是双刃；进集采（多为仿制药）则是估值上限警报；这条不决定主趋势，但决定"这一品种 / 这家公司空间还有多少"。
- **看的是趋势一致性**：管线、BD、监管批文几个领先维度同向运动信号最强；与滞后的营收 / 利润背离时，**以领先端为准**（营收会跟上，biotech 营收甚至滞后多年）。


## 四、催化逻辑 / 政策视角（创新药的事件主引擎）

这是创新药的**专属母引擎**——脱离了催化与政策环境，单看 K 线就是瞎做：

- **License-out / 海外授权 = 重磅催化**：中国创新药出海拿到大额首付款 + 里程碑 + 销售分成，是这条赛道近年最强的估值重定价器（单笔重磅 BD 可让市值翻倍）。要跟踪三件事：**首付款金额、里程碑结构（开发 / 监管 / 销售三段）、销售分成比例**——分成比例和里程碑可达性比首付款更承重；只看首付不看分成 = 被估值脉冲牵着走。
- **临床读出 = 二元跳空**：III 期 OS / PFS / ORR 阳性 vs 阴性，单日 ±30–70%。读出前**不押方向**（赔率本就 ~50/50，且公司端常有信息不对称），读出后按结果重新评估管线 rNPV 再决定加 / 减。
- **监管节点 = 时间窗信号**：NMPA 受理 → 优先审评 → 批准；FDA IND → BTD（突破性疗法）→ PDUFA → 批准。关键节点临近**主动降敞口**，落地后按结果加 / 减。
- **国谈 / 集采 = 年度政策窗**：每年 Q4 国谈结果是创新药板块年度最大政策跳空；集采扩面（即便创新药为主体的指数也会被联动情绪砸盘）需提前减仓。**先分清这次降价打的是"创新药定价权"还是"仿制药出清"**——前者实质利空创新药估值锚，后者反而利好龙头集中度。
- **学术会议 = 数据曝光窗**：AACR（4 月）、ASCO（6 月）、ESMO（9 月）、ASH（12 月）、JPM healthcare（1 月）。会前看公司 abstract 入选情况预热，会中看口头报告 / 海报数据质量，会后看赛道再定价。会议前**单押方向胜率低**，要么少仓位赌赔率好的标的，要么用板块层面承接 Beta。
- **政策双刃**：医保鼓励创新（创新药谈判规则倾斜、加速审批扩面、ICH 协调降低出海门槛、罕见病 / 儿童药专项）是长期顺风；但医保盘子有限，单品种降价压力始终在，**单押"政策利好"不看降价幅度 = 单边赌博**。


## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。创新药事件密、波动陡，纪律不可省：

- **临床失败 / BD 撕单 = 一笔砍透**：单一品种 III 期失败可让公司跌 30–70%，BD 合作方撤回授权同等量级。重仓押单一管线的标的，**默认不在重仓档**；指数级也要避免在关键读出 / BD 关键里程碑窗口前满仓。
- **现金流断裂 = Biotech 生死线**：现金跑道 < 12 个月 + 二级市场低迷 + 一级融资关闸 → 强制定增 / 配股稀释甚至退市，是 Biotech 板块单边下跌期"地板下面还有地下室"的信号。指数层面若多家龙头同时进入跑道告急，须直接降仓。
- **国谈 / 集采意外**：每年 Q4 国谈窗口、年中集采公告，单品种降价超预期或被纳入意外集采，可瞬间打掉板块情绪。**事件前主动降仓**，事件落地按结果再加。
- **监管收紧 / 信号转向**：FDA 收紧加速审批门槛、NMPA 改严 IND 标准、对中国数据接受度下降、出海路径被拉长——这些是结构性变量，发生时整个赛道估值锚要重定。
- **硬止损（更严）**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑（管线兑现 / BD 落地 / 国谈让利换量）大概率已破。


## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **管线证伪（下行）**：龙头核心管线 III 期主要终点未达 / 安全性问题撤回 / 关键适应症被否；下一档候选药接力失败，管线进入空窗期。
- **BD 证伪（下行）**：海外授权遇阻 / 合作方退回权利 / 关键里程碑兑付失败 / 销售分成被压低；行业 license-out 节奏整体熄火、卖方"出海"叙事开始失声。
- **政策证伪（下行，最关键）**：国谈降价幅度大幅超预期、集采扩面到创新药主体品种、FDA 收紧加速审批 / 对中国数据接受度下降、DRG / DIP 改革挤压创新药支付空间——估值锚被实质性下移。
- **趋势证伪（下行）**：跌破 200 日均线且 1 月未收回，但是你应该根据当时的市场环境修正你的指标。
- **估值证伪（下行）**：极端泡沫读数 + 全民进场信号 + 关键管线无新增 / 临床进展停滞 / BD 节奏熄火。
- **现金证伪（下行，Biotech 专属）**：龙头 / 一线 biotech 现金跑道 < 12 个月且融资窗关闭，板块进入"被动稀释"循环。
- **看空被证伪（上行 veto-watch）**：重磅 BD 落地（大额首付 + 高分成）；关键 III 期阳性读出；国谈以温和降幅换医保放量；FDA 给出 BTD / 加速审批 / 批准；Biotech 现金跑道延长（融资到账 / BD 回血）——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 创新药是**事件密集 + 二元跳空 + 政策窗口集中**的赛道，单指数策略夏普的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是临床失败 / 国谈意外 / 现金链断裂 / 监管转向时少亏。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。**同理，绝不许把 PE / 估值分位、拥挤度分位当成仓位上限**（如"PE 极贵锁死上限 60%""拥挤度高封顶"）——估值贵、拥挤高只是逃顶预警（见估值视角），不是事前封顶；趋势市高赔率共振该上 80%–100% 就上。
- 但该在场时别缺席：趋势明确向上（管线兑现 + BD 加速 + 政策友好 + 价格多头）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由。**每日复盘已有踏空自检 hook**：若当前空仓 / 轻仓而趋势市成立且未破位，你必须能把离场理由归到"趋势破位"或"持仓从高点回撤"之一；归不出 = 踏空违规，当日按骨架回补，**别用"拥挤 / 过热 / 估值贵"搪塞**。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10–20%（创新药事件多、波动大，箱体可较宽）内来回 + 箱体反复假突破。
  - **过渡待定**：信号不清、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（管线塌方 / 政策转严 / 趋势破位）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：
- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（创新药最常见，BD / 临床读出 / 国谈消息都能脉冲）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向。向上→在场吃 Beta；转下→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：创新药本就高波动（学术会议季 / 国谈季 / FDA 重大节点季波动会异常放大），越平静越敢拿，振幅骤增 / 大涨大跌时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **事件叠加**：临床读出 / BD 公告 / 国谈 / 监管批文 / 学术会议窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（重磅 BD 落地 / III 期阳性 / 加速审批授予）确认后再顺势加。
- 叠加：**方向（动量）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10–20% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：创新药箱体随时可能因一条 BD / 临床读出 / 国谈结果向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：事件脉冲多、传闻 / 卖方"潜在 BD"文章发酵后回吐凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如重磅 BD 落地 / 关键 III 期阳性 / 国谈降价大幅低于预期），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 管线塌方 / 政策转严 / 趋势转空 → 一把清到位，可以直接到 0**：创新药事件砸盘下跌往往加速（一条 III 期失败 / 国谈意外可在 1–2 个交易日把板块拉走 15%+），等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。创新药的高赔率组合是 **重磅 BD 落地 + 关键临床阳性 + 国谈温和降幅 + 价格放量突破 + 龙头管线节奏密集** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；宁可错过，不可做错**——但"宁可错过，不可做错"只约束低赔率情形；高赔率时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且创新药主升浪回调动辄 20–30%（重磅 BD 后的兑现性回调、学术会议季的"事实兑现"回吐都很深），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。创新药单边跌起来很容易摸到深水区（管线塌方 + 政策黑天鹅 + 现金链断裂叠加），这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 创新药事件多、传闻密（每天都有"潜在 BD"、"重磅读出"、"突破性疗法即将获批"的卖方文章），更要克制别被脉冲诱发高频折腾。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、管线节奏、BD 与监管节点、政策窗口、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 国谈降价快跑 | 国谈以价换量是利好 | 先分清这次降价打的是**单品种定价权**还是**仿制药出清**：核心创新药品种被砍 30%+ 看 A，温和降幅 + 显著扩量看 B |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 管线兑现进行中看 B，趋势破位 / 管线塌方时极端读数当定性预警 |
| 临床读出在即该减 | 读出前布局赔率好 | 公司端**有信息不对称迹象 + 同类靶点历史成功率低**看 A，**早期数据强 + 同类靶点已被验证 PoC**看 B（但单押单品种永远不能重仓） |
| BD 传闻该追 | 传闻不落地白搭 | 已有公司公告 / 双方一致披露 + 首付款规模实质看 A，仅卖方文章 / 单边传闻看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但管线 / BD 主线没坏看 A，单边下跌途中看 B |
| 强者恒强 | 物极必反 | 趋势中段 + BD 节奏密集 + 学术会议季前看 A，极端情绪 + 量价背离 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 量价背离 / 管线进入空窗期 / 国谈窗口临近看 B |

> **核心一句**：创新药—用 **管线兑现 + BD 授权 + 政策窗口** 判景气与空间、用**趋势 / 动量**择时、用**大开大合 + 压最大回撤**做仓位；吃该吃的 Beta、躲管线塌方与国谈黑天鹅、空仓不愧疚、按优势大小下注、进出算成本，靠压回撤把夏普做上去。
