# 中证银行指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证银行指数（399986.SZ）**——中证全指里"银行"行业的全部银行股（约 40+ 只，调整市值加权、单票上限 15%，每半年调样）。

## 核心认知

中证银行（399986）= **低估值 × 高股息 × 低波动的防御型价值资产**。它是 A 股里**回撤最浅、最像"类债"的权益板块之一**——盈利稳定、现金流可预测、股息率长期高于无风险利率，靠的是估值修复 + 股息再投的"慢钱"，而不是趋势爆发。五个特性决定玩法，**其中第一条是这份方法论与其他所有指数最大的不同**：

- **价格趋势择时在这个指数上无效——这是经过验证的硬结论**：研究室对本指数做过完整的全因子族扫描（趋势、动量、回撤、波动率目标各族），**没有任何一个价格择时因子能稳定击败买入持有**。根本原因：银行波动太低、趋势性太弱（裸持有的最大回撤本就是金融三子板块里最浅的），趋势 / DD 择时在它身上只会反复磨损收益、被假信号甩进甩出。**所以对银行不要做价格趋势择时，重心放估值 / 股息 / 基本面（见三节量化辅助的诚实结论）。**
- **靠 PB + 股息率定价，长期破净是常态**：银行长期 PB < 1（破净），市场用 PB 分位 + 股息率 vs 无风险利率来定价，而不是 PE 或成长。**股息率相对 10 年国债的利差是银行最核心的配置锚**——利差够厚（股息率显著高于长债）时，配置盘（保险 / 理财 / 被动资金）会持续买入,这是 2024 以来银行慢牛的资金面根基。
- **净息差（NIM）是盈利的命脉**：银行盈利 = 生息资产 × 净息差 − 信用成本。NIM 连续多年下行是压制估值的主线；NIM 见底企稳（降幅收窄）是估值修复的关键确认——市场会提前交易"息差筑底"预期。
- **资产质量（地产 / 城投风险）是悲观预期的集中地**：压制银行估值的不是盈利本身，而是市场对地产 / 城投坏账的担忧。**化债政策推进、地产风险缓释是银行 PB 修复的领先催化**——预期改善比报表改善早。
- **结构分层：国有大行 / 股份行 / 城商行逻辑不同**：国有大行（工农交）= 最纯的高股息防御 + 中特估；股份行（招行 / 兴业，指数权重前二）= 零售 / 对公质量分化，弹性中等；优质城商行（江苏 / 上海 / 宁波）= 区域信贷景气 + 成长性，弹性最高。指数权重以股份行 + 大行为主体，**方向看大行 + 股份行，弹性看城商行**。

驱动排序：**净息差 + 资产质量（基本面）+ 股息率 vs 无风险利率（配置锚）> 化债 / 地产政策 > 估值 PB 分位 > 价格趋势（最弱，几乎不用）**。研究时问三件事：

1. 基本面在改善还是恶化（NIM 在筑底还是下行、资产质量预期在缓释还是恶化）？→ 决定能不能加。
2. 股息率 vs 无风险利率的利差够不够厚、配置盘在不在买？→ 决定底仓的安全垫。
3. 化债 / 地产 / 利率政策变没变？→ 决定估值修复的催化或风险。

## 一、估值视角（银行的主战场：PB 分位 + 股息率利差）

银行是少数**估值视角承重最高**的指数——它没有趋势爆发，超额几乎全部来自"在低 PB + 高股息利差时买入、吃估值修复 + 股息"。三条纪律：

- **主用 PB，不用 PE**：银行盈利稳定但 PE 会因拨备计提节奏失真；**PB 分位才是银行的估值标尺**。历史上银行 PB 长期在破净区震荡，PB 底部分位 + 股息率高利差 = 安全垫厚，PB 修复到历史中高位 = 安全垫变薄。
- **股息率 vs 无风险利率是配置锚**：银行的"慢牛"本质是配置盘行为——当银行股息率显著高于 10 年国债、且基本面（NIM / 资产质量）不再恶化时，保险 / 理财 / 被动资金会持续配置，推动 PB 缓慢修复。**利差越厚、底仓越安全；利差收窄（股息率被买低 / 长债收益率上行）= 配置吸引力下降 = 上行空间收敛。**
- **银行的"贵"很难形成泡沫，"便宜"可以持续修复**：与成长股不同，银行 PB 修复是缓慢的(配置盘慢慢买)，PB 到历史中高位不代表立刻见顶（只要利差还在、基本面还稳）；但 PB 修复到历史极高位 + 利差收窄到无吸引力时，上行空间确实有限。**别用"涨多了"去 fade 一轮估值修复慢牛，要看利差和基本面。**

估值做两件**定性判断**的事：

- **加仓窗口（底）**：PB 底部分位 + 股息率利差厚 + 基本面不再恶化（NIM 筑底 / 化债推进）→ 这是银行最好的配置窗口，可以稳步加底仓（银行回撤浅，左侧布局风险可控）。
- **减仓 / 止盈预警（顶）**：PB 修复到历史中高位 + 股息率利差收窄到无吸引力 + 基本面再度走弱（NIM 重新下行 / 资产质量恶化）→ 安全垫变薄、上行有限，逐步兑现。

## 二、趋势与资金视角（弱化使用：只作风控刻度，不作进场信号）

**这一节对银行是次要的**——价格趋势择时在本指数无 edge（见三节）。趋势 / 均线只承担一个有限职能：

- **方向锚（仅风控）**：指数 vs 200 日均线——跌破且伴随基本面 / 利差恶化时作降仓的右侧确认之一，**但绝不单独作进场或加仓信号**。银行的进场理由永远是估值 + 股息 + 基本面，不是趋势突破。
- **配置盘资金动向**：被动资金 / 保险配置的持续流入是银行慢牛的资金面根基，比价格趋势更有意义——关注 ETF 份额、北向、保险举牌类信息。
- **不要在银行身上做动量 / 突破择时**：它波动太低、趋势太弱，趋势系统会被假信号反复甩进甩出，磨损收益。这是验证过的结论，不是经验之谈。

## 三、基本面景气视角（银行专属：NIM + 资产质量 + 化债是母变量）

银行的"景气"是基本面三件套，按性质分层：

- **领先**：
  - **社融 / 信贷增速**——规模扩张的领先指标（量），月频公开。
  - **化债 / 地产政策推进**——资产质量预期改善的领先催化，**预期改善早于报表改善**，是 PB 修复的发令枪。
  - **LPR / 存款利率调整**——存款降息释放 NIM 利好（领先于息差企稳）。
- **同步 / 滞后（确认不择时）**：
  - **净息差 NIM**——盈利命脉，季频滞后，但市场提前交易"筑底"预期；**等 NIM 报表确认企稳，估值修复已走一段**。
  - **不良率 / 拨备覆盖**——资产质量的滞后确认。
- **结构（决定弹性）**：国有大行（防御 + 中特估）/ 股份行（零售对公分化）/ 城商行（区域信贷景气 + 成长）——同一时刻三层弹性不同，指数方向看大行 + 股份行，弹性看城商行。

**纪律**：银行研究的核心是判断**基本面拐点（NIM 筑底 + 资产质量预期缓释）+ 配置锚（股息利差）**，而不是择时价格。基本面改善 + 利差厚 = 加底仓的最强组合；基本面恶化（NIM 重新下行 + 地产风险升级）= 减仓信号。

### 可用的择时指标（诚实结论：价格择时对本指数无效）

**核心结论（诚实，不可美化）**：研究室对本指数做过完整全因子族扫描（趋势、动量、回撤、波动率目标各族），**没有任何一个价格择时因子能稳定击败买入持有**——这在金融三子板块里是独一份（券商的动量是绿灯、保险弱信号，唯独银行整族无 edge）。原因是银行**波动太低、趋势性太弱**：裸持有的最大回撤本就是三者最浅，趋势 / DD 择时在它身上只会被低波动里的假信号反复甩进甩出，磨损收益还不如不动。

**怎么用（判断）**：

- **不要对银行做价格趋势 / 动量择时**。均线 / 趋势只作"基本面已经走坏时"的降仓右侧确认之一，**绝不单独作进场、加仓、收益增强的信号**。
- 银行的"择时"应该是**估值 / 股息 / 基本面择时**：低 PB + 厚利差 + 基本面企稳时加，高 PB + 薄利差 + 基本面走弱时减——这是慢钱逻辑，不是趋势逻辑。
- **结论一句话**：银行靠估值 / 股息 / 基本面，不靠价格趋势；把对其他高 β 板块那套趋势打法套到银行上，是这个指数最典型的错误。

## 四、政策 / 利率视角（银行的估值重定价器）

- **化债政策**：地方化债推进直接缓释城投坏账预期，是银行（尤其重仓城投敞口的银行）PB 修复的核心催化——跟踪化债额度、节奏、覆盖范围。
- **地产风险**：地产链坏账是压制银行估值的另一只靴子；地产政策放松 / 风险出清是估值修复的领先信号。
- **利率双刃**：降息（LPR 下调）短期压 NIM（资产端重定价快于负债端，偏空盈利），但存款利率下调 + 降准能对冲（释放息差）；**要分清是"贷款降息压息差"还是"存款降息护息差"，方向相反**。长债收益率下行还会压低银行股息率的相对吸引力（配置锚收窄）。
- **中特估 / 国企估值重塑**：国有大行的政策性估值修复主题（破净修复、市值管理）是大行慢牛的政策面助力。
- **资本新规 / 分红政策**：影响银行的资本充足与分红能力，间接影响股息率配置锚。

## 五、风险管理视角

银行回撤浅，但不是没有风险——它的杀伤来自基本面逻辑破坏，不是日常波动：

- **资产质量黑天鹅**：地产 / 城投风险超预期暴露、区域性银行风险事件——这是银行少数能深跌的情景，资产质量证伪时要降仓。
- **NIM 加速下行**：息差跌破市场预期、盈利持续下修——配置逻辑（高股息）的根基动摇。
- **利差收窄陷阱**：PB 修复到高位 + 长债收益率上行使股息利差收窄到无吸引力 → 配置盘流出，上行空间耗尽。
- **别用高 β 板块的止损纪律**：银行波动小，−15% / −25% 的硬止损阈值对它过宽（很少触及）——银行的"止损"主要靠基本面证伪（NIM / 资产质量 / 利差）而非价格，价格止损是兜底。

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称——触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 净息差 NIM 重新加速下行（盈利命脉恶化）
  - 资产质量恶化（不良率上行 / 地产城投风险升级）
  - 股息率利差收窄到无吸引力（PB 修复到高位 + 长债收益率上行）
  - 社融 / 信贷增速持续走弱（规模扩张乏力）
  - 化债 / 地产政策落空或风险重新发酵
- **看空被证伪（上行 veto-watch）**：
  - NIM 降幅收窄 / 筑底企稳（息差拐点）
  - 化债推进 + 地产风险缓释（资产质量预期改善）
  - 股息率利差重新走厚 + 配置盘持续流入
  - 社融 / 信贷回暖（规模扩张）
  - 中特估 / 国企估值重塑政策加码

# 仓位管理方法论

## 唯一信仰：估值 + 股息 + 基本面定底仓，不做价格趋势择时

- 一句话：**对本金极度保守，对利润适度放纵。** 但银行的"利润"是慢钱（估值修复 + 股息再投），不是趋势暴利——对它的纪律重心是"在便宜 + 利差厚 + 基本面稳时拿住底仓"，而不是高频择时。
- 银行的超额来自**在低 PB + 厚股息利差 + 基本面企稳时配置底仓，吃估值修复 + 股息再投**——它是金融三子板块里唯一的"底仓型防御资产"，回撤浅、波动低，**适合作为组合的压舱石而非进攻仓**。
- 仓位由**估值 / 股息利差（价值锚）+ 基本面（NIM / 资产质量）**决定，**不由价格趋势决定**（趋势择时无 edge）。可以有相对稳定的底仓中枢——这是银行与券商 / 保险最大的不同（后两者无中枢、由信号赔率定）。
- 该在场时别缺席：低 PB + 厚利差 + 基本面企稳时还空着 = 错过最安全的配置窗口；但银行不追求满仓搏弹性，它的价值在"稳"。
- **不要把高 β 板块的趋势打法套到银行上**——这是最典型的错误。

## 一、先识状态：估值 + 利差 + 基本面三态

**每天第一步：先回答三个问题（不是分趋势市 / 震荡市，那对银行意义小）。**

1. **估值**：PB 在历史分位的什么位置（底部 / 中位 / 高位）？
2. **股息利差**：股息率 vs 10 年国债的利差厚不厚（配置吸引力强 / 中 / 弱）？
3. **基本面**：NIM 在筑底还是下行、资产质量预期在缓释还是恶化？

三者共振（低 PB + 厚利差 + 基本面企稳）= 加底仓的最强窗口；三者背离（如 PB 已修复但利差还厚）= 维持底仓不追高；三者皆逆（高 PB + 薄利差 + 基本面恶化）= 减仓。

## 二、底仓骨架：估值 + 股息利差定中枢

- **低 PB + 厚利差 + 基本面企稳** → 配置中高底仓，稳步吃估值修复 + 股息。
- **PB 中位 + 利差中等 + 基本面稳** → 维持底仓，不追高也不轻易减。
- **高 PB + 薄利差 + 基本面走弱** → 逐步兑现，降到低底仓或空仓。
- 银行底仓可以左侧布局（回撤浅，左侧风险可控），不必等右侧趋势确认——这与券商 / 保险的"等趋势确认"不同。

## 三、加减仓：慢钱逻辑，步长可以比高 β 板块小

- **银行允许比券商 / 保险更平滑的仓位操作**：它波动低、是底仓资产，不需要"大开大合一把到 0"——除非基本面逻辑被证伪（NIM / 资产质量 / 利差三杀），否则以维持底仓为主。
- **加仓**：低 PB + 厚利差 + 基本面改善证据出现时稳步加。
- **减仓**：基本面证伪（NIM 加速下行 / 资产质量恶化）或利差收窄到无吸引力时减；**单纯价格回调不构成减仓理由**（银行回调常是配置盘上车机会，不是趋势破位）。
- **绝不在基本面恶化的下跌中摊薄**（资产质量黑天鹅时例外快走），但基本面没坏的价格回调可以低吸。

## 四、止盈止损：用估值、利差、基本面说话，价格止损兜底

- 在场期间盯三件事：**PB 修复到什么位置、股息利差还厚不厚、基本面（NIM / 资产质量）有没有恶化**。
- **止盈**：PB 高位 + 利差收窄 + 基本面走弱叠加时兑现——银行不会暴涨见顶，是慢慢失去上行空间，逐步减。
- **止损**：主要靠基本面证伪（资产质量黑天鹅、NIM 崩塌），价格 −15% / −25% 是兜底（银行很少触及）。
- **保本线**：浮盈到位后离场线抬到成本价。

## 五、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 降仓 / 暂停加仓；继续扩大 → 复盘。事后闸门，**不得反着用**。
- 银行回撤浅，这条对它触发频率低——但资产质量黑天鹅时（少数深跌情景）照常执行。

## 六、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——银行是底仓资产，本就低频，避免在它身上做无谓的 round-trip。
- 银行的正确打法天然低频：估值 / 基本面是慢变量，仓位变动应该是季度级的，不是日级的。

## 七、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 跌破均线该减 | 银行价格择时无效 | **默认 B**：银行不做趋势择时；只有价格破位 + 基本面 / 利差同步恶化才看 A（趋势仅作确认） |
| 低 PB 该买 | 便宜要配基本面 | 低 PB + 厚利差 + 基本面企稳看 A；低 PB 但 NIM 仍在崩 / 资产质量恶化看 B（等基本面证据） |
| 涨多了该减 | 估值修复慢牛能走很久 | 利差还厚 + 基本面稳看 B（别 fade 慢牛）；利差收窄 + 基本面走弱看 A |
| 降息利好银行 | 降息压息差 | 看**是贷款降息还是存款降息**：存款降息护息差看 A；贷款 LPR 单边下调压 NIM 看 B |
| 高股息能扛 | 利差收窄就该走 | 股息率显著高过长债看 A；利差被买到无吸引力 + 长债收益率上行看 B |
| 银行是压舱石 | 资产质量黑天鹅也能深跌 | 基本面稳的常态看 A（底仓拿住）；地产 / 城投风险超预期暴露看 B（快走） |

> **核心一句**：中证银行——低估值高股息的底仓型防御资产，**价格趋势择时对它无效（验证结论）**；用 **PB 分位 + 股息率 vs 无风险利率利差**定底仓、**NIM 筑底 + 资产质量预期（化债 / 地产）**定基本面拐点；低 PB + 厚利差 + 基本面企稳时稳步配置吃估值修复 + 股息，基本面证伪时减——靠慢钱逻辑做压舱石，不靠趋势暴利，别把高 β 板块那套趋势打法套上来。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新监管框架、利率体系重构、银行盈利模式变化）。
- **定期 + 事件驱动**：一轮利率 / 信用周期走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、利差阈值、底仓档）、视角权重与排序、三层（大行 / 股份行 / 城商行）差异化打法、新增失效模式与证伪条件。**若未来扫描出对银行有效的择时因子，再升级三节（目前的诚实结论是无 edge）。**
- **不轻易动（信仰与原则层）**：唯一信仰（估值 + 股息 + 基本面定底仓、不做价格趋势择时）、银行是底仓型防御资产的定位、PB + 股息利差是主锚、价格择时对本指数无 edge 的结论、风险优先于收益。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（利率体系重构 / 银行盈利模式变化是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。
