# 国证商用卫星通信产业指数投资框架（方法论）

这是研究视角，不是执行手册。拿到当日数据后，**先做〇节的环境三问（永远的第一步）**，再依次过各视角，自行综合判断该不该动、动多少——框架给坐标系，不给触发器。

> 商用卫星通信（980018）是 A 股**商业航天 / 卫星互联网产业链的全口径主题敞口**：从火箭与卫星制造、卫星发射，到地面设备 / 终端、卫星运营与通信服务一条链打满。玩法核心一句话：**每天先回答"今天这根 K 线是谁画的"——商业航天叙事、国防订单、还是通信制造跟随——主驱动认对了，其余视角才有意义**。跨环节 + 含国防敞口 = 信号源杂、题材噪声多，这既是它难做的地方，也是文本面权重必须拉满的原因。

## 核心认知

国证商用卫星通信产业指数（980018.SZ）：选取商用卫星制造 / 发射 / 运营、卫星地面设备与卫星通信服务相关公司，近半年市值前 50 名为样本，自由流通市值加权、单一权重上限 15%、前五合计不超 60%，半年调样一次。**编制要求"商用卫星制造 + 发射"环节权重合计不低于 50%**——制造 / 发射端是指数的承重梁。

- **主驱动是商业航天 / 卫星互联网叙事**：低轨星座（国网 / 星网、千帆 G60、鸿鹄等）的组网与发射节奏、可回收火箭进展、卫星互联网频率 / 牌照 / 政策，是当前最大的母变量——**多为政策与事件脉冲，弹性极大、兑现路径偏远**。
- **含高国防军工敞口**：成分里国防军工占比近半、军工电子权重最大，航天央企（卫星 / 火箭制造）同时受**国防订单 / 预算 / 装备采购**驱动。这意味着本指数有**两套并行的母变量**：商业航天叙事（题材弹性）+ 国防订单（景气兑现），看错是哪一套在定价，信号就会读反。
- **产业链分段、驱动不同步**：上游卫星 / 火箭制造（弹性大、叙事敏感）、地面设备 / 终端（跟组网进度与放量）、运营 / 通信服务（收入可预测、抗周期，但弹性低）、卫星载荷 / 通信芯片（跟自身周期 + 国产替代）。**同一时刻可能制造端炒发射、运营端平淡——不能用一个故事解释整个指数。**
- **高 β、深回撤、事件跳空极多**：本指数是风险偏好与题材情绪的强放大器，发射 / 组网 / 政策事件能打出可观单日脉冲，"大阳后回吐"是常态。样本集中（前五≤60% 但仍集中）、无分散保护，回撤控制全靠纪律。
- **指数与跟踪产品都偏新、样本偏短**：指数发布与商业航天行情的主升集中在近年，跟踪的公募产品成立时间晚、净值历史短。**做滚动统计 / 分位时要意识到样本期短、极端行情占比高，分位与历史读数的稳健性弱于老指数**——这是结构性弱点，不是 bug，落地时对任何"历史分位"读数都打折看。

驱动排序：**商业航天政策 / 星座组网 / 发射事件（题材弹性）＋ 国防订单 / 预算（景气兑现）> 子环节景气（制造 / 地面 / 运营）> 通信芯片周期 / 国产替代 > 估值**。研究时先问三件事：

1. 当前是商业航天叙事在定价，还是国防订单在定价，还是纯风格 / 资金？→ 决定用哪套母变量
2. 星座组网 / 发射 / 政策有没有兑现路径？航天央企订单 / 合同负债在什么趋势？→ 决定景气真假
3. 当前是哪个子环节在领涨、是事件脉冲还是订单驱动？→ 决定现在加还是减、追不追

## 〇、先判市场环境（永远的第一步）

三问答完并**显式留痕**（写进当日复盘，次日继承），才允许进任何加减仓决策。

**1）全市场风险偏好：A 股现在给不给高 β 题材活路？**
本指数是风险偏好放大器，题材成分对偏好**更**敏感——收缩期题材脉冲几乎没有持续性，预设一日游。用 `macro_50etf_vix`、市场情绪因子（看累计与相对位置、不看单日）、大盘趋势判：**扩张 / 收缩 / 中性**；收缩期所有看多信号自动降档。

**2）板块状态：趋势市 / 震荡市 / 过渡待定（三选一）**
长均线排列与箱体识别常规判法。两条专属提醒：**事件脉冲的单日大阳不算状态切换证据**（本指数"大阳后回吐"比一般主题更勤）；状态有粘性，默认继承昨日结论，只问"有没有确认级证据推翻它"。

**3）主驱动识别（本指数最要紧的一问）：今天谁在定价？三分法：**
- **商业航天叙事**：卫星互联网 / 组网 / 发射 / 政策事件驱动、制造端题材标的领涨而业绩龙头不跟、文本面无订单增量 → 不入景气，按四节单独评估，预设回补。
- **国防订单驱动**：航天央企合同负债 / 预收款抬升、国防预算 / 装备采购有兑现、业绩龙头跟上 → 入景气链、可承重。
- **通信制造 / 风格跟随**：通信芯片 / 载荷成分跟自身周期或国产替代、或纯属大盘风格切换带动 → 信号源切到对应链，独立性弱时跟大盘风险偏好走，谨慎追。
判据 = 两三路板块强弱 + 领涨成分类型 + 文本增量归类，一句话留痕。

## 一、估值视角（定性预警，绝非择时扳机）

- **禁止拿指数 PE 分位做低吸高抛**——本指数是题材定价 + 国防订单 lumpy + 短样本，"贵贱"连口径都说不清。"趋势 > 估值"作单向过滤器：只否决"因为贵所以卖 / 因为便宜所以接"，不给反向授权。
- **顶部预警**：极端分位 + 全民进场迹象（卫星 / 商业航天词出圈、主题基金发行火爆、研报口径切到"万亿远期空间"）+ 订单 / 组网兑现却跟不上叙事 → 提示趋势尾段，交给止盈纪律。**纯叙事推到顶 + 业绩龙头不跟，是最危险组合。**
- **底部触发器**：极低分位 + 龙头盈利下修多季 → 不抄底，但触发去文本找反转证据（组网提速 / 国防订单回升 / 发射密度上升）；证据出现且趋势企稳，按骨架回补。
- **上修斜率比分位承重**：`stock_alpha` 龙头一致预期变动率月度跟踪，转下修是比破位更早的顶部信号。

### 可用的择时指标（定性）

> **重要前提：本指数尚未跑过系统的择时因子筛选，没有任何已验证的"绿灯"主因子。** 不要把任何价格类因子（趋势突破 / 动量等）当作经验证的承重信号——它们对本指数只能作**未验证的客观第二意见**，方向裁决权完全交回主驱动（商业航天叙事 / 国防订单）+ 文本面。读数可用收盘序列按公式自算。

- **`trail_dd` 回撤止损族（本指数当前的主力机械工具）**：收盘从过去约 120 日滚动峰值回撤超一档 = **价格面走坏的客观证伪信号**，给出"回撤已到第几档"的客观刻度（**到档降多少仓、何时清，是投资层按 USER 风险偏好定，研究层只报刻度、不写死档位**）。**纯收盘价、无代理失真，作回撤刻度相对可靠**——职责是标记深熊段、给框架犹豫时一个客观刻度，**是回撤刻度不是收益增强器，更不抓顶底**。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；只看价格，对政策 / 发射 / 订单拐点零预警。**注：该族在本指数未经专门筛选定级，先按通用回撤刻度使用，待跑过因子筛选后照实定级。**
- **时序动量（仅快读，不承重）**：20 日动量可作"价格面还在不在多头"的快读数；但本指数事件跳空多、趋势不一定持续，动量翻转在震荡里多是噪声，**〇-2 判定震荡市时默认当噪声，不据此动仓**；且 T+1 执行对单日跳空必然滞后一天。
- **市场情绪 / VIX（系统性第二意见）**：`macro_50etf_vix` + 市场情绪因子覆盖系统性恐慌 / 自满，作〇-1 风险偏好判断的输入，不对个股 / 题材层面的结构性风险敏感。

**共同纪律**：本指数没有经验证的绿灯因子——择时主轴是**商业航天政策 / 组网发射 / 国防订单的定性多维判断**，价格类因子只做降回撤断后与未验证第二意见。**不写也不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。**待研究室对本指数跑完因子筛选后，再据结论更新本节定级。**

## 三、景气度视角（先认链，再读链）

本指数有**两套并行母变量**，先认是哪套在驱动，再读对应链：

- **A 链：商业航天 / 卫星互联网（题材弹性主线）**。母变量是低轨星座组网与发射节奏、卫星互联网政策 / 频率 / 牌照、可回收火箭进展。传导：政策 / 规划 → 星座招标 / 发射密度 → 卫星 / 火箭制造订单 → 地面终端放量。**领先端是政策原文 + 发射 / 组网事件 + 招标订单**，财报只做确认。这条链弹性最大、兑现最远，纯叙事段杀得最狠。
- **B 链：国防订单 / 预算（景气兑现）**。航天央企（卫星 / 火箭制造）受国防预算 / 装备采购驱动，订单先体现为**合同负债 / 预收款**，领先营收利润数个季度。**看合同负债 / 预收款同比方向，不看当期营收。** 这条链兑现更实、节奏更慢，是叙事退潮时的景气底盘。
- **C 链：通信芯片 / 载荷周期**。卫星载荷、通信芯片类成分跟自身周期与国产替代叙事，节奏可能与 A / B 错位；只在判定"通信制造跟随"时升为主读，平时作背景。

**纪律**：多链并行时，以〇-3 认定的主驱动链为主读，其余降为背景；领先端定方向、滞后端（财报）做确认，背离时信领先端。**分清"组网 / 发射叙事"与"订单兑现"**：星座规划 / 发射事件撑估值，国防订单 / 终端放量撑业绩，行情切换时区别对待，别把组网规划当当期收入。

## 四、事件 / 政策驱动视角（本指数权重最高的一节）

这是本指数的命脉维度——它的定价被政策 / 事件驱动的程度极高：

- **商业航天 / 卫星互联网政策（A 链母变量）**：星座组网规划、频率 / 轨道资源分配、卫星互联网牌照、商业航天写入政府工作报告 / 五年规划——政策落地即抬主题中枢。跟政策原文，分清是"规划 / 表态"还是"招标 / 资金落地"。
- **发射 / 组网事件（脉冲催化）**：批量发射、一箭多星、星座组网里程碑、可回收火箭试验——**单日跳空大**，评估三问：**有无订单 / 收入兑现路径？时间表多远？涨的是基本面还是纯叙事？** 兑现路径出现前一律按情绪脉冲（已持仓顺势交给止盈，空仓不追）；出现真实招标 / 订单 / 终端放量 = 题材升格为景气，转入景气链跟踪。
- **国防 / 航天采购（B 链母变量）**：国防预算增速、装备采购计划、航天工程节点——驱动航天央企订单，跟预算原文与龙头合同负债。
- **技术路线 / 频率之争**：低轨 vs 中高轨、不同星座体系的卡位——作用于制造与运营成分，判替代还是共存、龙头有无卡位、时间表多远。
- **事件前管敞口**：重大发射节点 / 政策窗口 / 组网里程碑前后跳空风险大，方向不明不赌。

### 读法纪律（文本是信息也是毒药）

- **读事实与方向，不抄结论**：纪要 / 研报是事实源 + 关注度代理，不是买卖建议。
- **领先性分层**：政策 / 规划原文、招标 / 订单合同、合同负债财报科目、发射 / 组网完成 = 领先信号，承重；研报观点 / 目标价 = 滞后情绪代理，只做密度统计。
- **题材文本专项纪律**：卫星 / 商业航天类文本叙事浓度高、可证伪点少，只认三类硬事实——**政策 / 规划原文、发射 / 组网完成、签了字的招标 / 订单**；"空间测算 / 产业链梳理"一律记作情绪密度，不进证据链。
- **一致看多逆向读**：趋势成熟期是反向信号、行情起点是领先信号——属于哪种，回〇节当场定，不设机械线。
- **证据落链（硬性）**：当日 belief / 复盘 evidence 至少 1 条文本条目（INFOCODE / topic_id + 一句话摘要）；没增量如实写"今日文本面无增量"。没有检索记录不许引用"听说 / 市场传言"。
- **权重边界**：文本给方向与证伪，不直接给仓位数字，不得突破回撤控仓与最小步长纪律。

## 六、证伪视角（对称化）

证伪是论据的破坏，看多看空都要列；触发不等于清仓，但原论据作废，需新论据才能维持原仓位。须**对称**。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新星座体系、新发射模式、商业化收入新结构）。
- **优先补"择时因子定级"这块空白**：本指数尚未跑因子筛选，一旦研究室给出筛选结论（哪族因子绿 / 黄 / 证伪），应据实把择时指标节从"未验证"升级为带定级的版本——这是本框架当前最大的待补项。
- **定期 + 事件驱动**：一轮商业航天行情或重大组网节点做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对制造 / 地面 / 运营 / 载荷各环节的差异化打法、**择时因子定级（筛选结论出来后照实写入）**。
- **不轻易动（信仰与原则层）**：唯一信仰（环境定骨架 + 主驱动定方向 + 纪律压回撤）、两套母变量（商业航天叙事 = 弹性、国防订单 = 兑现底盘）、叙事只认硬事实、风险优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空、对本金保守对 β 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式，不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；星座体系成型、商业化收入规模化兑现、政策框架重置是结构变化（写进框架）。
- **样本短更要防过拟合**：本指数样本期短、极端行情占比高，任何"历史分位 / 因子读数"的稳健性都弱——迭代时尤其警惕把一段行情的特例当规律。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
