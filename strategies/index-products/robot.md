# 中证机器人指数投资框架（方法论）

这是研究视角，不是执行手册。拿到当日数据后，**先做〇节的环境三问（永远的第一步）**，再依次过各视角，自行综合判断该不该动、动多少——框架给坐标系，不给触发器。

- 标的：**中证机器人（H30590.CSI，2015 起，约 11 年样本）**——从机器人产业链（减速器 / 丝杠 / 伺服电机 / 控制器 / 传感器 / 机器视觉 / 工业与服务机器人本体）里选样的主题指数，本质是「**物理 AI / 具身智能**」在 A 股的可交易敞口。**人形机器人 / 具身智能是这条指数里弹性最大、兑现最远的主线**，工业自动化是当下变现的压舱石——一条指数里同时装着「远期空间」与「当期业绩」两套估值逻辑。

## 核心认知

机器人 = **物理 AI 的硬件落点**：让 AI 从「屏幕里的智能」走进「物理世界的执行」。任何物理 AI 实体（人形机器人 / 工业机器人 / 智能汽车 / eVTOL）都可拆成**大脑（决策 / 世界模型 / AI 芯片）— 小脑（运动控制 / 运控算法）— 本体（执行器 + 传感器 + 结构件）**三层，**A 股最大的价值量与利润弹性在「本体—执行器 / 传感器」这一层**（产业链口径：工业机器人成本里减速器约占三分之一、且是毛利最高的环节，国产替代主战场在这里）。五个特性决定怎么玩：

- **主题 / 成长属性是第一特性，传统 PE 框架大面积失真**：本指数是事件 / 渗透率驱动的成长主题，**不能看当期 PE 贵不贵择时**——弹性主线（人形 / 具身）多处「有空间、无盈利」阶段，PE 几百倍是纯空间定价；当下变现链（工业自动化）才有 PEG 意义。指数级 PE 是这两套逻辑 + 亏损成分的混合噪声。
- **五条子链节奏不同、严重分化（每天第一问：今天谁在定价）**：①**人形 / 具身**（最高弹性、最晚兑现，主题 / 订单驱动）②**工业自动化 / 智能制造 / 工业母机**（当下有真实营收利润，受制造业 capex 周期影响，且人形量产会反向拉动这一层）③**智能驾驶**（轮式具身，渗透率曲线最清晰，L3 节奏）④**端侧 AI / 算力 / 感知硬件**（大脑 + 感官，横向通用）⑤**低空经济 / 无人系统**（政策驱动早期）。**同一时刻可能人形在炒量产催化、工业自动化跟着 PMI、智驾等 L3——不能用一个故事解释整个指数。**
- **价值量在本体层、节奏看渗透率曲线**：人形单台对谐波减速器需求十余台并向上抬，灵巧手（含微型丝杠 / 腱绳 / 触觉传感）是难度与价值量新高地。判景气不是「景气高不高」拍脑袋，而是**量产节点 → 价值量兑现比例 → 瓶颈环节**的推导（见三节）。
- **底层供应链高度共享（指数内在集中风险）**：多条子链共用同一批本体零部件龙头（减速器 / 丝杠 / 电机 / 伺服 / 机器视觉反复出现在不同主题里）。**指数表面分散，底层却高度集中在「机器人本体零部件」这一条链上**——单一龙头或单一环节被证伪时，多只成分股会同步受损。这是品种内在风险，不是配置失误，但择时与回撤纪律上要认知到位。
- **高 β、深回撤、价格因子弱**：主题成长 + 事件密集 → 跳空常态、振幅大、回撤深；机械趋势 / 突破因子在本指数难以稳定承重（见二节）。夏普的提升几乎全靠**压回撤 + 在主升浪在场**，不靠预测顶底。

驱动排序：**子链景气与渗透率节点（量产 / 订单 / capex）≥ 量产催化 / 政策事件 > 海外映射（特斯拉 / 英伟达机器人链）> 风险偏好底色 > 估值**。研究时先问三件事：

1. 当前是哪条子链在定价？人形主题脉冲、工业自动化业绩兑现、还是智驾 / 题材轮动？→ 决定追不追、承不承重
2. 弹性主线的渗透率走到哪一段？量产节点 / 价值量兑现 / 瓶颈环节有没有新证据？→ 决定景气真假
3. 全市场给不给高 β 成长主题活路？→ 决定看多信号要不要降档

宏观利率 / 风格是底色：机器人是**风险偏好最尖的放大器之一**，risk-off 阶段即便基本面催化不断也会杀估值——别用「经济复苏顺周期」硬套，它的母变量是**渗透率曲线 + 价值量兑现**，不是社会总需求。

## 〇、先判市场环境（永远的第一步）

三问答完并**显式留痕**（写进当日复盘，次日继承），才允许进任何加减仓决策。

**1）全市场风险偏好：A 股现在给不给高 β 成长主题活路？**
机器人是风险偏好放大器，对偏好比一般行业**更**敏感——收缩期即便催化不断，主题股也会杀估值。用 `macro_50etf_vix`、市场情绪因子（看累计与相对位置、不看单日）、大盘趋势判：**扩张 / 收缩 / 中性**；收缩期所有看多信号自动降一档。

**2）板块状态：趋势市 / 震荡市 / 过渡待定（三选一）**
长均线排列与箱体识别常规判法。两条专属提醒：**子链换挡期（人形 ↔ 工业自动化 ↔ 智驾）指数常呈震荡——内部换挡 ≠ 趋势终结**；状态有粘性，默认继承昨日结论，单日跳空不算切换证据。主题成长品种趋势段可以很凌厉但也脆，趋势市认定要有**放量有效突破 + 子链催化同向**，否则按震荡 / 过渡处理。

**3）主驱动识别（机器人最要紧的一问）：今天谁在定价？三分法：**
- **弹性主线驱动（人形 / 具身）**：催化在量产指引 / 产线投产 / 大会 / 政策，主题标的领涨、业绩龙头未必跟 → 弹性最大但兑现最远，**警惕「叙事 → 要业绩」切换时杀得最狠**；按四节单独评估，已持仓顺势交给止盈、空仓不盲目追高。
- **兑现链驱动（工业自动化 / 智驾）**：制造业 capex 回暖 / 伺服 + 机器人出货加速 / L3 推进，有订单与业绩锚 → 入景气链、可承重。
- **题材脉冲 / 风格资金**：无基本面与催化增量，纯属大盘风险偏好切换或主题资金轮动 → 独立性弱，跟大盘走，谨慎追。
判据 = 强弱子链 + 领涨成分类型 + 文本增量归类，一句话留痕。

**环境错判，所有信号都会读错**——没做完不进入任何加减仓决策。

## 一、估值视角（按生命周期段位适配，禁 PE 均值回归）

机器人是主题 / 成长赛道，**禁止把指数级 PE 当价值锚做均值回归择时**。正确做法是先认主线处在生命周期哪一段，再选对应的估值锚：

| 段位 | 特征 | 估值锚 |
|---|---|---|
| ① 主题催化 | 政策 / 巨头事件点燃、无业绩 | 市值空间 / PS，**PE 无意义** |
| ② 订单兑现 | 龙头拿到定点 / 小批量订单 | 在手订单 / 产能、单台价值量 × 渗透台数 |
| ③ 业绩兑现 | 放量、营收利润高增 | **PEG**（PE 开始有意义） |
| ④ 退潮 / 分化 | 渗透见顶 / 价格战 | PB、利润中枢 |

- **弹性主线（人形 / 具身、低空）多在 ①②段 → 禁用 PE**：用「全球空间 × 份额、单台价值量 × 渗透台数」定空间，PE 几百倍只是纯空间定价、不是贵的证据。
- **兑现链（工业自动化 / 智驾 / 端侧）多在 ③段 → 用 PEG**：看增速能否消化估值。
- **指数级 PE 分位只做极端预警，不做择时扳机**：它是两套逻辑 + 亏损成分的混合噪声，对子链结构变化滞后。样本够长、分位可算，但只用于「是否进入泡沫区 / 深熊区」的定性判断。
- **横向比较只在同段位、同子链内做**——拿 ①②段的人形 PE 去比 ③段的工业自动化 PE 是常见错误。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——「趋势 > 估值」是单向过滤器，只否决「因为贵所以走 / 不进」，不是无视估值的通行证。** 别把它反过来用：下跌 / 破位时，「趋势 > 估值」只支持「不靠便宜接飞刀」，不能拿来把极端读数一票否决。

估值在这里只做两件**定性预警**：

- **极端泡沫预警（顶）**：PE 顶部分位 + 全民进场（主题出圈、机器人基金发行火爆、研报集体高喊「星辰大海 / 万亿空间」）+ 量产催化不断但订单 / 业绩跟不上叙事 → 配合状态框架减仓。**特别警惕「纯主题脉冲推到顶 + 业绩龙头不跟」，那常是最后一波。**
- **深熊 / 反转预警（底）**：极低分位 + 情绪冰点 + 预期下修多季 → **不抄底**，触发去文本找反转证据（量产节点重启 / 产线投产 / 订单落地），证据 + 趋势企稳再回补；**右侧价格企稳（连续数日停止创新低 + 资金回流 + 风险偏好不收缩）即使量产硬证未到，也是方向转多的早期证据**——量产硬证是把置信度从「中」升到「高」的确认，不是方向转多的必要前提（下游怎么据此定仓位是投资层的事）。

## 二、趋势视角（关键：机械趋势 / 突破因子在本指数难承重）

趋势研判别只看一根均线，多角度交叉验证。**机器人还要额外把子链催化方向纳入**——指数趋势与渗透率 / 量产节奏背离时，留意基本面常领先 / 滞后于价格的不同情形。

- **方向锚**：指数收盘 vs MA120 / MA200 + 均线斜率，20–60 日时序动量辅助，全部用收盘序列自算；突破需拥挤度同步抬升确认，**拥挤极端 + 价格加速 = 主升尾段**。
- **量能确认（板块代理）**：指数无量价细节 → 用 `sector_factor` / `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量，拥挤度不跟 = 可疑假突破。
- **跳空甄别（日常课）**：量产指引 / 大额订单 / 资金级政策 / 产线投产 = **逻辑级**（可顺势）；映射海外波动 / 传闻 / 纯题材 = **情绪级**（易回补）。次日去研报找增量，无增量当情绪脉冲；再问**打在哪条子链**——人形利空别当工业自动化利空，错层利空别当全指数利空。
- **震荡市转箱体思维**：均线信号在震荡里反复假突破，子链换挡期尤其不重仓赌哪条接棒——双确认新主线才交还趋势骨架。

研究时不问「能不能买」，问「信号强到什么程度」——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）

> **本指数的择时定级要点：机械趋势 / 突破类（donchian、均线交叉）在本指数难稳定承重**——事件密集 + 跳空常态会把突破反复打成假信号；**但有一个例外：短窗时序动量方向，在人形 / 具身成为主线后的当前 regime 下，经检验是本指数可承重的在场 / 防踏空价格锚（见下）**。除它以外，价格因子仍只作**降回撤辅助 + 客观第二意见**，方向质量的最终裁决交回子链景气 / 量产 / 事件与文本面——**文本面仍是方向的承重墙**。读数用收盘序列按公式自算（**信号按当日收盘计算、下一交易日 T+1 执行，不偷看当日盘后即时成交**）。

- **`trail_dd` 回撤止损族（本指数主力机械工具）**：收盘从过去约 120 日滚动峰值回撤超一档 = **价格面走坏的客观证伪信号**，给「回撤已到第几档」的客观刻度（**到档降多少仓、何时清，是投资层按 USER 风险偏好定，研究层只报刻度、不写死档位**）。纯收盘价可靠、无代理失真，职责是给框架一个客观回撤刻度 + 标记深熊段——是回撤刻度不是收益增强器，更不抓顶底。会漏什么：重入靠回撤 / 均线站回，V 型反弹前段必然迟到；只看价格，对量产 / 政策拐点零预警。深回撤品种上「回撤数学不对称」（跌幅越深、回本所需涨幅越高）格外要命，这条断后纪律任何风险档都不能关。
- **市场情绪类因子（弱二意见，非本指数 specific）**：全市场情绪的累计 z-score 反向信号（情绪过热反向减、冰点反向加）可作**客观第二意见**，但它是全市场口径、不是机器人专属，权重 ≤ 主维度，且敏感 / 平滑两版二选一、不叠加。
- **短窗时序动量方向（当前 regime 下可承重的在场 / 防踏空锚）**：20 日（及 10–15 日邻窗）收盘涨幅的**正负号**，是价格面「趋势还在不在多头」的客观读数。**在人形 / 具身成为主线后的当前 regime 下，这条不再是噪声、而是本指数经检验最稳的价格择时锚**——
  - **涨幅为正 = 价格面确认多头，是在上升段保持在场、不踏空主升浪的客观依据**：哪怕 PE 分位很高也不因贵而空仓（在场与否看动量方向，不看估值分位，呼应一节「趋势 > 估值」单向过滤器）。
  - **涨幅转负 = 价格面走坏的早期客观证伪**：早于跌破 MA200，是减 / 离场的价格触发。它同时压回撤（下行段自动离场）又防踏空（转正即回补、不靠猜底），弥补 `trail_dd` 重入必然迟到的缺口。
  - **边界与证伪**：① 区间震荡 / 子链换挡期动量会来回翻转产生小噪声——孤立翻转先当噪声观察，要与子链催化 / 文本面方向**同向**才升为承重信号；② 这条结论**绑定当前「事件 / 渗透率驱动」的品种性质**，若本指数退回以工业自动化业绩为锚的慢趋势性质，须复核动量是否仍承重（见方法论迭代机制）。读数用当日及之前收盘自算、**信号 T+1 执行**。

**共同纪律**：择时主轴仍是**子链景气 / 量产 / 事件 + 文本面的定性多维判断**；价格因子里只有**短窗时序动量方向**够格做承重的在场 / 防踏空锚，其余（donchian / 均线交叉 / 市场情绪）只做降回撤断后与客观第二意见。**除已被检验的短窗动量外，不自造也不执行「因子 = X 且 YY 必须 ZZ」的未回测硬规则**——**尤其别把 PE 分位 / 市场温度私自升级成「贵了 / 过热了就必须空仓」的一票否决**：那是未经回测的自造规则，正是本指数把自己焊在低仓、系统性踏空主升浪的最典型来源。冲突本身是信号，核验来源再决策。

## 三、景气度视角（机器人专属：五子链渗透率曲线为母变量）

机器人是主题 / 成长赛道，**传统当期景气指标在这里大面积失真**——必须用渗透率曲线 + 价值量兑现节奏判断（取数见上「取数映射」节）。按性质分类，别用滞后指标做择时：

- **领先（母变量，按子链）**：
  - **人形 / 具身（弹性主线）**：量产节点（龙头出货 / 产线投产 / 巨头量产指引）+ 价值量兑现（单台谐波减速器需求十余台向上抬 × 渗透台数 = 空间，现在兑现了百分之几）+ 瓶颈环节（关节模组 / 灵巧手 / 丝杠良率——瓶颈突破就是最强催化）。
  - **工业自动化（兑现链）**：制造业 PMI、伺服 / 工业机器人出货、国产替代份额——这层既享当期景气、又是人形量产的「卖铲人」，人形量产会反向拉动订单。
  - **智驾 / 端侧 / 低空**：L3 法规与智驾标配率、端侧大模型 + AIoT SoC 出货、空域改革 + eVTOL 适航。
  - 多条子链同向时信号最强（人形量产提速 + 工业自动化订单回暖 = 景气主升）。
- **滞后（确认而非择时）**：龙头营收 / 净利 YoY + 一致预期修正（`stock_alpha` 变动率是最早的硬信号，但等财报确认通常已走完半程）——不当择时锚。
- **结构 / 上限**：龙头在本体层的卡位（减速器 / 丝杠 / 谐波 / 视觉的稀缺性与良率）、产能与交付能力——决定龙头穿越周期能力与重仓信心，不决定主趋势开关。

判断要点：

- **结论必须是推导，不是拍脑袋**：不是「人形景气高」，而是「瓶颈在 X 环节，Y 公司良率突破 / 产线投产 → 价值量向 Z 环节兑现 → 卡 Z 的龙头利润弹性最大」。
- **分清「订单兑现」与「主题叙事」**：工业自动化出货 / 智驾渗透是可验证的真景气；人形量产指引 / 新作战 / 新具身概念是弹性最大但兑现最远的叙事——叙事撑空间，订单撑业绩，行情切换时区别对待。
- **看趋势一致性**：渗透率 / 量产 / capex 同向运动信号最强；与滞后的盈利端背离时，以领先端为准。

## 四、事件 / 政策驱动视角（机器人权重很高的一节）

机器人定价被政策 / 事件驱动的程度远高于一般景气逻辑：

- **量产催化 = 弹性主线的核心扳机**：巨头量产指引上修、核心零部件产线投产、车厂 / 工厂订单 / 定点——**单日跳空大**，是把人形从 ①段推向 ②段的关键，要分清逻辑级（真订单 / 产线）还是情绪级（传闻 / 海外映射）。
- **海外映射（双刃）**：特斯拉 Optimus 进展、英伟达机器人 / 具身平台、海外人形量产节奏——映射情绪 + 叙事；先拆是逻辑级（带动实际供应链订单）还是情绪级（纯情绪脉冲），再问打在哪条子链。
- **政策 / 大会催化**：具身智能 / 人形机器人专项政策、「人工智能 +」、世界机器人大会类事件——**提法级**（规划 / 表态）按脉冲对待；**资金级**（专项资金 / 招标 / 订单落地）才进景气链、才改变景气判断。
- **技术路线替代风险（机器人专属证伪源）**：本体方案在快速演进——直驱 / 一体化关节是否替代减速器、丝杠路线之争、灵巧手方案迭代——**价值量可能从一个环节迁移到另一个环节**，押错环节的龙头会被证伪。这是事件 / 景气层都要盯的结构性变量。
- **事件前管敞口**：大会 / 巨头发布会 / 重大量产节点前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。

## 五、文本视角（研报 + 纪要，每日必读、最高优先级）

> 工具：`research_search` / `research_view` + `zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（纪要 PIT 截断到当日）。**每个交易日必须执行，不许跳过**——哪怕当天不动仓位；其他视角缺数据可降级，这个视角不读完不收工。
>
> **为什么文本面是本指数超额的主要来源**：把母变量排一遍——量产节点、价值量兑现、瓶颈环节、政策 / 大会、海外映射、技术路线替代——**几乎没有一个是高频结构化数据**，全活在研报 / 纪要 / 政策原文里。结构化口径只剩价格、板块代理和季度财报，而纯价格因子在本指数给不了方向领先性。丢掉文本面，这套框架就只剩一台跟在行情后面的回测脚本。

### 读法纪律（文本是信息也是毒药）

- **时效铁律（最关键）**：机器人事件驱动、一周一变，催化 / 景气**必须每次现拉最新研报**（按日期倒序取最新），不能用旧记录或凭印象。**相关性排序的检索会混入旧闻，不可用于判时效**；过时的基本面 = 错的择时。
- **读事实与方向，不抄结论**：量产 / 产线 / 订单 / 招标 / capex 类事实 = 领先承重；研报观点 / 目标价 / 空间测算 = 滞后情绪代理，只做密度统计。
- **叙事温度计**：「星辰大海 / 远期空间」类措辞密度，行情起点抬升是领先信号、成熟期一致沸腾是反向信号；属哪种，回〇节当场定，不设机械线。
- **证据落链（硬性）**：当日 belief / 复盘 evidence 至少 1 条文本条目（INFOCODE / topic_id + 一句话摘要）；没增量如实写「今日文本面无增量」。没有检索记录不许引用「听说 / 市场传言」。
- **权重边界**：文本给方向与证伪，不直接给仓位数字，不得突破回撤控仓与最小步长纪律。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **量产 / 渗透证伪（下行，最关键）**：人形量产时点反复推迟、出货 / 产线节奏连续不及预期、瓶颈环节迟迟不突破——弹性主线逻辑被推翻。
- **技术路线证伪（下行，机器人专属）**：核心环节价值量被新方案替代（如直驱 / 一体化替代减速器、丝杠路线被颠覆）、押注环节的龙头被边缘化。
- **景气 / 盈利证伪（下行）**：工业自动化 capex 收缩、伺服 / 机器人出货转弱；龙头毛利率下行、一致预期上修转下修（最早硬信号）；研报集体切向「兑现质疑」。
- **趋势证伪（下行）**：指数跌破 200 日均线且约一个月未收回（应结合当时市场环境修正）；`trail_dd` 回撤族触发 = 价格面确认走坏。
- **估值证伪（下行，反向）**：PE 顶部分位 + 纯主题脉冲推到顶 + 业绩龙头不跟 + 卖方高喊「机器人大周期 / 万亿空间」——主题顶部最危险信号组合。
- **看空被证伪（上行 veto-watch）**：巨头量产指引上修、核心零部件产线投产、车厂 / 工厂订单落地；工业自动化订单 / 出货加速；L3 法规落地；端侧大模型 / AIoT 出货高增。**另：价格右侧企稳（连续数日停止创新低 + 资金连续净回流 + 风险偏好不收缩）即使量产硬证未到，也是方向转多的早期证据——它常先于订单出现；量产硬证是把置信度从「中」升到「高」的确认，不是方向转多的必要前提。** 区别于单日脉冲：要数日企稳 + 资金持续回流，不是事件大阳一根（脉冲日方向不变，见〇-3）。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是「可重复的失效模式」，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新本体技术路线、新具身形态、新政策结构）。
- **定期 + 事件驱动**：一轮渗透率 / 量产周期节点做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PE 极端分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、五子链景气表维度、新增失效模式与证伪条件、对人形 / 工业自动化 / 智驾 / 端侧 / 低空的差异化打法、择时因子定级（若复核更新 `trail_dd` / 情绪因子定级，照实改）。
- **不轻易动（信仰与原则层）**：渗透率曲线 + 价值量兑现是母变量（不靠 PE 均值回归）、五子链节奏分化必须先认主线、价值量在本体层、底层供应链高度共享是指数内在集中风险、机器人是风险偏好放大器、机械趋势 / 突破类难承重（短窗时序动量是当前 regime 的例外）、回撤优先于收益、不接飞刀、低赔率观望 / 高赔率不踏空。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断「决策过程对不对」，再看「结果好不好」。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（「这个信号近 N 次有 M 次反向」），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清「改了什么、为什么、依据是什么」，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损「显得合理」。
- **区分噪声与结构变化**：日常波动是噪声（不改）；本体技术路线重构、量产模式跃迁、政策体制变化是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到「怎么走都对」就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
