# 中证光伏产业投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证光伏产业（931151.CSI）**。

## 核心认知

光伏（中证光伏产业 931151）= **重资产制造业产能周期**叠加**装机渗透率成长**的强周期成长贝塔，覆盖硅料 / 硅片 / 电池片 / 组件 / 逆变器 / 辅材（玻璃、胶膜、银浆）全产业链。它是 A 股产能周期演绎得最极致、最典型的板块（产能严重过剩时硅料等环节价格可断崖式下跌、全产业链由高盈利转向集体亏损，是教科书级的"过剩—价格战—出清"周期）。三个特性决定玩法：

- **高弹性 + 高波动**：β 大，上行能翻倍、下行能腰斩，不适合死扛。
- **强产能周期**：资本开支周期主导盈利——扩产 → 产能过剩 → 价格战 → 盈利坍塌 → 出清 / 反内卷 → 涨价 → 盈利修复，3-4 年一轮。**供给侧（产能利用率 / 价格）才是盈利拐点，不是装机量。**
- **渗透率 S 曲线 + 技术路线迭代**：全球装机有长期渗透底盘，但增速在越过中段后放缓；同时 PERC → TOPCon → BC → 钙钛矿 的路线迭代会让押错的环节龙头被颠覆。

驱动排序：**产能周期 / 供给格局 > 产业链价格（硅料 / 组件）> 趋势 / 资金 > 政策 / 技术路线 > 估值**。研究时问三件事：

1. 产能周期在哪个阶段（过剩出清 / 底部反转 / 景气扩张 / 高位见顶）？→ 决定能不能重仓、是不是底部
2. 趋势对不对、资金在不在？→ 决定现在是加是减
3. 价格链 / 政策（反内卷、出口）/ 技术路线变没变？→ 决定是不是该撤

### 光伏指数特性：

1. **量增不等于利增**：全球装机年年创新高，但产能过剩 + 价格战让"量增、价跌、利崩"。看装机的同时**必须看供给**（名义产能 / 产能利用率 / 库存）。需求好 ≠ 能赚钱，**供给出清（落后产能退出 + 反内卷限产）才是盈利拐点**。
2. **周期底部 PE 极高甚至为负是常态**：过剩底部盈利坍塌，PE 冲到极高分位——这恰恰可能是布局区。要找"产能出清、硅料 / 组件价触底、库存见底"的反转信号，不能见 PE 高就跑。
3. **产业链价格是先行指标**：硅料（致密料）、硅片、电池片、组件、光伏玻璃价的拐点，**领先**股价和盈利。价格止跌企稳 → 盈利修复预期 → 股价启动；盯价格链比等财报及时。
4. **政策与技术路线是双刃**：国内（整县推进、大基地、能耗 / 反内卷限产）和出口（美国双反 / UFLPA、欧洲、东南亚转口关税）直接左右需求与价格；技术路线（TOPCon → BC、钙钛矿叠层）让押错的环节被颠覆。既是 α 来源，也是杀伤来源。逆变器环节绑定海外储能、相对独立于硅料价格战，景气与主链常不同步。

## 一、产能周期视角（光伏的核心价值锚）

光伏是重资产制造业，**盈利由供给周期主导，不由装机增速主导**。把产能周期分四阶段定位：

- **产能过剩 / 价格战（下行）**：在建产能集中投产、产能利用率下滑、硅料 / 组件价阴跌破现金成本、毛利压到盈亏线甚至全行业亏损——戴维斯双杀主场。**少碰，趋势转空就清。**
- **底部出清（反转前夜）**：资本开支收缩、落后产能停产 / 退出、行业自律限产（反内卷）、价格跌无可跌、库存见底——左侧布局区，但要价格 / 供给信号确认，不是见跌就抄。
- **景气扩张（上行）**：价格企稳回升、产能利用率回升、单瓦盈利修复、格局优化——盈利估值共振向上，**主升段，重仓吃 β**。
- **高位见顶（过热）**：人人扩产、新玩家蜂拥、价格冲高、资本疯涌——下一轮过剩的种子已埋，**趋势走坏即减**。

判断阶段看三件事：**产能利用率（在不在回升）、硅料 / 组件价（拐点在哪）、资本开支 / 在建产能（还在扩还是在收，含反内卷限产政策）**。毛利 / 单瓦净利是滞后验证，不是先行信号。

## 二、估值视角（用 PB 与产能利用率，不用 PE 分位均值回归）

光伏是强周期成长指数，**禁止用 PE 历史分位简单做均值回归择时**：周期底部盈利坍塌甚至为负，E 缩水让 PE 冲到极高分位——在底部喊你跑、在顶部（盈利最肥）显得便宜，方向是反的。

估值换一套锚：

- **PB + 产能利用率 / ROE**：低 PB + 产能利用率触底回升 + ROE 即将修复 = 底部布局信号；高 PB + 利用率见顶 = 顶部预警。PB 必须配合周期阶段用。
- **产业链价格隐含的盈利预期**：硅料 / 组件价触底 → 未来盈利修复，比当下 PE 更能反映"贵不贵"。
- **极端泡沫的定性预警**：全民进场（新基金爆发、研报一致"光伏无敌"、龙头估值脱离任何盈利锚）时当顶部提示，配合趋势减仓——而不是单看一个估值数字。

成长性（装机空间、技术路线领先度）只用来判断**值不值得在景气里重仓**，不用来在产能过剩下行里抄底。

## 三、供需与价格景气视角（盯供给—价格—需求的趋势一致性）

光伏单一产业链但分环节，单一指标失真。看六个维度的趋势一致性：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 供给 / 产能 | 各环节名义产能、产能利用率 / 开工率、在建产能、库存 | 核心（决定盈利拐点） |
| 价格链 | 硅料（致密料）/ 硅片 / 电池片 / 组件 / 光伏玻璃价 | 先行（领先盈利与股价） |
| 需求 / 装机 | 国内新增装机、出口组件量、全球装机预期 | 成长底盘 |
| 盈利 | 成分股毛利率 / ROE、单瓦净利 | 滞后验证 |
| 资金 | 北向、ETF 份额、融资余额、产业资本动向 | 情绪 / 边际 |
| 政策 / 路线 | 反内卷限产、出口关税（双反 / UFLPA）、TOPCon/BC/钙钛矿渗透 | 催化 / 双刃 |

**供给（产能 / 限产）与价格链是盈利拐点的主导，装机是成长底盘，技术路线是格局变量**，共振时信号最强。看趋势一致性（多维同向），不是加权打分。装机增长是底色，但**供给出清和价格才决定这一轮能不能赚钱**。

## 四、趋势与资金视角（择时主轴）

产能周期定"值不值得拿"，趋势 / 资金定"现在动不动"。光伏弹性大、踩踏狠，趋势是避开大跌段的主力。

- **方向锚**：指数 vs 200 日均线，配合量能确认突破 / 跌破的强度。
- **资金面**：北向、ETF 份额、融资余额、产业资本动向——增量资金是主升燃料，资金撤离 + 价格走弱是顶部信号。
- **波动率**：振幅骤增、急涨急跌 = 环境恶化信号，本身就是降仓理由。

研究时不问"涨没涨"，问"趋势和资金的方向，配不配合产能周期的判断"。**产能拐点（左侧）+ 趋势确认（右侧）共振，是最强的进场点。**

### 量化择时辅助：donchian_60 趋势突破有效

**donchian_60 趋势突破在光伏上验证有效；trail_dd 同向有效，但翻转远高于 donchian，优先 donchian。**

**经济逻辑**：光伏是高波动、强趋势的成长制造，技术 / 产能驱动的单边行情持续性强、突破有效——低翻转拿住主升段、跌破离场避开戴维斯双杀的下行段。

**怎么用（判断，不机械执行）**：把 donchian_60 当"现在动不动"的右侧择时第二意见，**权重 ≤ 产能周期主维度**。先看产能周期定方向，再用趋势确认进出节奏；两锚共振确信度最高，冲突时以产能周期为准、趋势只调节仓位档位。下行保护仍以"产能周期 + 价格链 + 证伪"为主，趋势因子是经验证的右侧补刀。窄区间震荡会有假突破，别在箱体里追突破；突破确认在右侧，底部出清的第一笔左侧仓仍靠产能 / 价格信号。

## 五、风险管理视角

光伏的杀伤来自方向性逻辑破坏与高波动叠加，不是日常震荡。主要风险：

- **产能过剩 / 戴维斯双杀**：扩产过度 → 价格战 → 盈利和估值一起杀。光伏最大的杀伤，常在"装机仍创新高"时发生，最具迷惑性。
- **技术路线颠覆**：押错路线（如 PERC 被 TOPCon 替代）的环节龙头被淘汰，基本面永久受损——不是周期回调，是逻辑作废。
- **出口 / 贸易**：美国双反 / UFLPA、欧洲、东南亚转口关税落地，直接砍出口需求与海外溢价。
- **拥挤度**：赛道交易过度拥挤、一致预期太强，任何边际利空引发踩踏式回调。
- **流动性**：高 β 在系统性流动性收紧时跌得最快最深。

原则：**产能在过剩端、价格在下行、趋势已破、拥挤度高时，仓位越保守**。止损纪律不能省，但杀伤主要靠"产能周期 + 趋势"提前离场，不能只等价格止损。绝不在产能过剩下行趋势里越跌越买。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（产能出清 / 景气向上 + 趋势在场 + 路线没押错）的破坏**。下列任一发生，应严肃重评持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **产能证伪**：产能利用率持续回落、在建产能再度扩张、反内卷限产落空、硅料 / 组件价二次破位下行。
- **盈利证伪**：成分股毛利率 / 单瓦净利连续恶化，"价格修复带动盈利"的预期落空。
- **趋势证伪**：跌破 200 日均线且 1 月未收回，伴随量能放大。
- **技术路线证伪**：重仓环节主流路线被颠覆 / 份额快速流失（格局逻辑作废）。
- **政策证伪**：出口关税落地、能耗 / 反内卷政策反复，砍掉重要需求或限产证伪。
- **拥挤证伪**：估值脱离任何盈利锚 + 拥挤度极高 + 资金爆量流入（非理性繁荣顶部）。

# 研究到交易的执行层

这一层负责把研究结论翻译成可执行动作：先识别指数当前由哪个环节主导，再判断周期阶段、价格链、趋势资金是否共振，最后给出加仓、持有、减仓、清仓或继续观察。

## 一、信号分级：先定主导环节，再定强弱

光伏指数由硅料 / 一体化组件 / 逆变器 / 辅材等环节构成，常不同步。每天先问两件事：

1. **谁在主导指数**：看成分权重、领涨领跌成分、成交额集中在哪个环节（硅料、一体化组件、逆变器、辅材），判断当前交易的是主链价格战、逆变器海外景气，还是纯指数 beta。
2. **主导环节信号强不强**：主导环节的供给、价格、需求、盈利、趋势、资金是否同向。不能用逆变器的海外利好去解释主链价格战导致的下跌。

信号分三级：

| 等级 | 定义 | 操作含义 |
|---|---|---|
| 强信号 | 产能、价格链、趋势、资金至少三项同向，且无重大证伪 | 可做大动作，20%-40% 步长 |
| 中信号 | 两项同向、一项待确认，或产业信号强但趋势未确认 | 轻仓试、持有、等右侧确认 |
| 弱信号 | 单点数据改善、研报情绪变化、短线反弹但周期未变 | 只记录，不交易或极小动作 |

研报观点本身不是交易信号，只提供假设与数据线索，必须被价格链、产能利用率、库存、财务和行情共同验证。

## 二、环节主导矛盾

| 环节 | 核心矛盾 | 重点指标 | 典型证伪 |
|---|---|---|---|
| 硅料 / 硅片 | 成本曲线出清与复产节奏 | 致密料价、开工率、检修 / 复产、库存、能耗政策 | 价格二次破位、停产产能快速复产、限产落空 |
| 电池片 / 组件 | 价格战与海外溢价、技术路线 | 组件价（国内 / 海外）、排产、一体化毛利、TOPCon/BC 份额 | 组件价再下杀、海外关税、押错路线份额流失 |
| 逆变器 | 海外储能配套景气（相对独立） | 出口量、海外大储订单、欧洲 / 新兴市场需求、毛利 | 海外需求放缓、价格战蔓延到逆变器 |
| 辅材（玻璃 / 胶膜） | 供给周期与成本传导 | 光伏玻璃价、冷修产能、纯碱成本、胶膜粒子价 | 玻璃点火过快、成本端失控 |

子环节分化时按权重与边际排序：**权重大且边际改善 > 权重大但继续恶化 > 权重小但高景气**。只有权重大环节或多环节共振，才允许指数层面重仓。

## 三、数据核验清单

每次交易判断前至少完成四层核验。数据缺失可用研报 / 新闻兜底，但必须标注缺失，不能把缺失当确认。

| 层级 | 必看数据 | 数据可得性与工具（回测已校准） |
|---|---|---|
| 指数层 | 931151 收盘 / 均线 / 趋势、成交额、主要成分涨跌贡献 | 行情用 `market_index_quote(market="cn", symbols=["931151.CSI"])` **自取**——每日预取快照只含五个宽基，不含 931151，也不含 PE/PB；指数级 PB / PB 分位无直接源，用 `stock_market` 取成分股估值聚合近似或当缺失 |
| 产业价格 | 工业硅期货价；硅料 / 硅片 / 电池片 / 组件 / 光伏玻璃调研报价 | 工业硅期货用 `commodity_market(market_type="futures")`；硅料 / 组件 / 玻璃**调研报价**无结构化时点源，只能 `ttjj_research_search` / `research_view` 文本兜底，时点下可能稀疏甚至为空 |
| 供需库存 | 产能利用率 / 开工率、排产、库存、在建 / 复产产能、国内装机、出口量 | **均无结构化时点源**，只能文本兜底，必须标注"文本推断、可能缺失"，不得当硬数据 |
| 盈利资金 | 成分股毛利率 / ROE / 单瓦净利、一致预期、个股北向、研报观点 | 成分股财务用 `stock_financial_quality`、一致预期用 `stock_alpha`、个股资金 / 北向用 `stock_capital_flow`（逐成分股聚合）；ETF 份额、融资余额、指数级北向无结构化源，文本兜底 |

工具优先级（已按回测可用工具校准）：

1. 行情 / 估值 / 财务 / 资金优先用时点工具：指数 `market_index_quote`、成分股 `stock_market`（含 PE/PB）、`stock_financial_quality`、`stock_alpha`、`stock_capital_flow`、商品 `commodity_market`、宏观 `macro_data`、基金 `fund_nav` / `fund_basic_info`。**没有名为 `research-mcp` 的工具。**
2. 调研价、排产、产能利用率、库存这类**无结构化源**的数据，用 `research_view(view_type="sector", labels=[...])` 或 `ttjj_research_search` 文本兜底；搜索窗口相对上游当前时间、时点下可能稀疏甚至为空，缺失必须标注。关键词：`光伏 产能 出清 组件价格`、`硅料 价格 复产 库存`、`光伏 出口 关税 装机`、`TOPCon BC 钙钛矿 路线`。
3. 关键数据至少两源交叉验证（研报、行业协会、公司财报、行情、新闻），任意两类相互印证才算中信号以上。

## 四、交易决策矩阵

| 产能周期 | 价格链 | 趋势 / 资金 | 估值 / 盈利 | 动作 |
|---|---|---|---|---|
| 过剩下行 | 持续下跌或二次破位 | 跌破 200 日线（且 ≥1 月未收回），资金趋势性流出 | 盈利继续下修 | 清仓 / 不参与 |
| 过剩下行 | 短暂反弹但未企稳 | 弱反弹，无资金趋势性流入 | PB 低但 ROE 仍恶化 | 观察，不抄底 |
| 底部出清 | 跌破现金成本后止跌 + 限产 | 趋势未确认，量能一般 | PB 低，盈利仍差 | 左侧轻仓试探 |
| 底部出清 | 多环节企稳回升 | 站上 200 日线，资金趋势性回流 | ROE 修复预期出现 | 加仓到中高仓 |
| 景气扩张 | 价格回升，利用率上行 | 200 日线之上，资金持续流入 | 盈利上修 | 重仓持有 / 回调加仓 |
| 高位见顶 | 价格冲高后明显见顶（连续 1+ 月） | 跌破 200 日线 + 量能背离 | 估值拥挤，盈利预期过满 | 分批减仓 |
| 逻辑证伪 | 价格、产能、政策或技术路线破坏买入逻辑 | 200 日线破位且资金撤离 | 盈利验证失败 | 快速降仓乃至清空 |

**矩阵使用约束**：四列要**共振**才触发动作；只有一两列变化（尤其趋势 / 资金单独变化）= 信号不足 = HOLD。趋势 / 资金看方向性变化，不是单日抖动。

## 五、研报到交易动作的转换

读研报五步走：

1. **提炼结论**：研报在看多什么——装机需求、价格出清、反内卷、技术路线，还是估值修复。
2. **拆假设**：拆成可验证假设，如组件价止跌、硅料复产受限、逆变器海外订单超预期。
3. **找证据**：用行情、价格链、财务、行业数据和其他研报交叉验证，不接受单一卖方口径。
4. **映射矩阵**：把验证后的信号放进决策矩阵，证据不够就停在观察或轻仓。
5. **写反证**：每次动作写一句"什么发生就说明我错了"，便于证伪与复盘。

研报只讲装机增长、不讲供给和价格；只讲长期空间、不讲短期盈利；只讲技术路线、不讲商业化节奏的，降级为弱信号。

# 仓位管理方法论

## 唯一信仰

- 光伏的超额，来自**在产能出清 / 价格触底 + 趋势确认时重仓吃产业上行 β，在产能过剩扩张 + 趋势转空时果断降仓躲开戴维斯双杀**——不是靠见低 PE 抄底，也不是靠死扛"装机年年增长"。
- 仓位由**产能周期阶段（价值锚）+ 趋势 / 资金（择时锚）双锚**共同决定，没有固定上下限——空仓、满仓都合法。**空仓躲过产能过剩 + 杀估值的大跌，是这个策略最值钱的动作。**
- **允许左侧、但要纪律**：产能周期底部（价格触底 + 供给出清 / 限产信号）可分批左侧布局；右侧趋势确认才上重仓。绝不在产能过剩下行趋势中越跌越买摊薄——那是接戴维斯双杀的飞刀。
- 不用硬止盈硬止损，用产能周期 / 趋势 / 价格链 / 回撤说话。
- **对本金极度保守，对产业 β 适度放纵**：亏损端要窄、要果断；景气主升的浮盈端给空间、让 β 跑。

## 一、仓位步长：大开大合，不做微调

- 账户灵活，能快速空仓、也能快速满仓。每次动手都是有意义的大动作，最小步长 20%，2%–5% 的微调没意义。
- 离场可以一把到 0；进场看确认强弱，一把到位或分 2–3 个大步。

## 二、先识状态：产能周期阶段 + 趋势市 / 震荡市

先定**产能周期阶段**（过剩下行 / 底部出清 / 景气扩张 / 高位见顶），再看**价格是趋势市还是震荡市**，两锚叠加定打法：

- **底部出清 + 趋势开始转多** → 左侧轻仓试 + 右侧确认加重，最好的赔率区。
- **景气扩张 + 趋势向上** → 顺势重仓拿住让 β 跑，回调不破趋势就加。
- **产能过剩 + 趋势向下** → 降仓乃至清空，绝不抄底摊薄。
- **高位见顶 + 趋势走坏** → 果断兑现，别恋战。
- 震荡市（产能周期未明、均线缠绕）→ 转箱体思维，箱底买、箱顶减，别在趋势里被甩下车。

## 三、双锚骨架：产能周期（价值锚）+ 趋势 / 动量（择时锚）

- **产能周期锚**：决定"值不值得拿、是不是底部"。出清 + 价格触底 = 价值底，景气扩张 = 主升，过剩扩张 = 别碰。**用 PB + 产能利用率，不用 PE 分位。**
- **趋势 / 动量锚**：决定"现在在不在场"。向上吃 β，转下降仓，避开大单边下跌段——压回撤的主力，量化上用 donchian_60 辅助确认。
- **叠加**：产能周期决定仓位中枢能开多高，趋势 / 资金决定现在往中枢上方还是下方走。**两锚共振（出清拐点 + 趋势确认）才上重仓；两锚背离就留一手。**

## 四、非对称操作：离场要快、回补看产能拐点 + 趋势确认

- **戴维斯双杀 / 趋势转空 → 一把清到位，可以直接到 0**。光伏跌起来又快又狠（杀盈利叠加杀估值），等"确认"就晚了，宁可错杀。
- **重新进场 → 看产能拐点 + 趋势确认**：硅料 / 组件价止跌企稳、产能利用率回升 / 限产落地、趋势重新转多——三者越齐加得越重；信号不齐就轻仓或放弃。**宁可错过，不可做错。**
- **只在景气向上 / 趋势没走坏的回调里加仓，绝不在产能过剩下行趋势中补仓摊薄（接飞刀）**。底部出清的左侧试仓（小、分批、有价格支撑）可以接；产能仍恶化的下跌不能接。

## 五、止盈止损：用产能周期、趋势、价格链和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓盯四件事：**价格链 / 产能有没有见顶反转、趋势破没破、资金撤没撤、从持仓高点回撤了多少**。景气向上 + 趋势在场 + 回撤温和 → 拿住让 β 跑；价格链见顶 / 趋势破位 / 资金撤离 / 回撤放大 → 大块兑现乃至清空。
- **移动止盈**：利润越厚越用"从高点回撤"保护，而非看绝对涨幅。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定程度把减仓线抬到成本价——这笔从此最差打平，绝不让赚钱的高 β 仓位因周期反转重新变亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 回撤数学不对称：亏 50% 要翻倍才回本。先保证不大亏比博大赚更决定长期复利——光伏深跌幅度大，回撤控制尤其要紧。
- **你自己账户**从峰值明显回撤、且伴随产能 / 趋势恶化时，大幅降仓乃至清空、暂停加仓——哪怕"装机长期空间还在"。长期空间不是死扛短期戴维斯双杀的理由。
- 回撤收复、产能 / 趋势重新转友好，再按第四条回补。

## 七、成本意识

- 光伏波动大、机会多，但每次进出都要掂量摩擦：**指增 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。做的是产能周期 + 趋势的大波段，频率天然不该太高——别做成高频。

## 八、场外基金低频交易硬约束（必须执行）

这是场外基金 / 指增组合，不是股票日内盘，也不是均线高频系统。每天都要研究，但**默认动作是 HOLD**；只有研究状态发生足够大的变化才允许交易。短线行情只能作验证或风控线索，不能越过研究框架直接触发买卖。

### 0. 进攻 / 防守总原则

- 行情不明确、判断不清、证据不够时，默认不参与，或只用 **40%** 小仓位试探。
- 当产能周期、价格链、供需库存、政策 / 路线、资金和趋势形成清晰共振时，敢于大胆干，仓位可提到 **50%–100%**。
- 进攻前先确认自己在"状态明确"而非"情绪冲动"；没有状态迁移，就算短线好看也不放大仓位。
- 回撤一旦恶化，先保命再谈进攻：减仓、暂停加仓、必要时回防守档。
- 原则：模糊期求稳，确认期进攻，回撤期收缩。

### 1. 交易触发闸门

交易前必须回答：**今天的研究结论相对上次持仓决策，发生了什么状态变化？** 只有下面几类变化可触发交易：

- **产能周期变了**：过剩下行 → 底部出清 / 景气扩张，或景气扩张 → 高位见顶 / 过剩下行。
- **价格链变了**：硅料、组件、玻璃等关键价格连续企稳 / 回升，或二次破位。
- **供需库存变了**：排产、库存、产能利用率、复产 / 在建产能、装机 / 出口数据改变此前判断。
- **政策 / 路线变了**：出口关税、反内卷限产、能耗政策、技术路线替代改变中期盈利假设。
- **风险状态变了**：核心逻辑证伪、账户回撤明显扩大，或系统性流动性恶化。

只是 MA5/MA20 金叉死叉、连续三日收阳、单日涨跌幅、趋势计数变化而无上述研究状态变化，**不得交易**，只记录为观察项。

### 2. 均线与短线信号的权限

- MA5、MA20 只用于观察短期噪声和执行时点，不能作为买卖加减的主因。
- 200 日均线 / donchian_60 可作中期趋势确认或风险线，但必须与产能周期、价格链、资金、证伪一起用。
- 连续涨跌、单日涨跌幅、短线趋势计数只能影响"今天是否更适合执行已成立的研究动作"，不能创造新交易理由。
- 交易理由若主要由均线、阳线数量、趋势计数构成，自动降级为 **不交易 / 继续观察**。

### 3. 费用与预期收益门槛

- 交易前估计本次动作能否覆盖申购 / 赎回 / 早赎成本，覆盖不了不做。
- 为躲一天波动而交易通常不值得；为应对中期逻辑证伪而交易才值得。

### 4. 每日输出格式要求

每天结论先写 **研究状态**，再写 **交易动作**，顺序固定：

1. 当前产能周期阶段是什么，和上次相比有没有变化。
2. 价格链、供需库存、政策 / 路线、资金趋势是否支持状态变化。
3. 是否触发交易闸门；若没有，明确写"研究状态未变，场外基金默认持有 / 空仓观察"。
4. 若交易，写清最短持有期、冷静期、费用门槛、证伪条件。

研究可以每天更新，但交易不需要每天发生。这个策略要赚的是研究确认后的中期波段，不是 MA5/MA20 的短线抖动。

> **核心一句**：在产能出清 / 价格触底 + 趋势确认时重仓吃光伏上行 β，在产能过剩 / 趋势转空时果断降仓躲戴维斯双杀——靠"产能周期定底、趋势资金定时（donchian_60 辅助）、量价背离时不贪"赚周期成长，不靠死扛装机增长。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新技术路线、新政策工具、新供需结构）。
- **定期 + 事件驱动**：一轮产能周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / donchian 周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各环节（硅料 / 组件 / 逆变器 / 辅材）的差异化打法。
- **不轻易动（信仰与原则层）**：唯一信仰（出清 + 趋势确认重仓、过剩 + 转空降仓）、双锚结构（产能周期 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀、宁可错过不可做错、对本金保守对 β 放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；产能周期切换、技术路线颠覆、政策框架重置是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
