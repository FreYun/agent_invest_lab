# 中证1000指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面几个**正交**角度审视，自行综合判断该不该动、动多少。

> 中证1000 是小盘成长贝塔，**估值不再是承重信号，流动性 / 拥挤度 / 情绪才是**——估值给"该不该想"，流动性 + 微观结构给"现在能不能动"。

## 核心认知

中证1000 = 剔除沪深300、中证500 之后市值排序 501–1500 的小盘成长贝塔（先进制造 / 医药 / 电子 / 计算机 / 国防军工 / 新材料权重高，金融消费很轻），是 A 股中小盘风格的主流宽基。四个特性决定玩法，**和沪深300 几乎反着来**：

- **高弹性 + 高波动**：β 显著大于 1，月度波动是沪深300 的 1.5–2 倍，单年回撤 −40% 不稀奇——上行可一年翻倍，下行可半年腰斩，**不适合死扛**。
- **盈利分母不稳**：成分股盈利波动大、亏损公司常年 10–20%，TTM E 在底部会**坍塌甚至转负**，PE 分位会被极少数巨亏股拉爆——估值信号**本身就脏**。
- **股息率低、缺乏现金奶牛**：股息率长期 < 1.5%，ERP / dv−10y gap 信号信噪比远低于沪深300——相对债券锚**几乎失灵**。
- **量化 / 微观结构主导边际定价**：DMA / 中性策略 / 雪球敲入 / IM 基差 / 两融 / ETF 申赎 / 公募小票仓位才是真正的边际买卖盘，外资 / 北向参与度低；2024 年初微盘雪崩、2024Q3 量化集体砍仓都证明了——**拥挤度风险高于估值风险**。

### 中证1000 估值特性（与沪深300 反着读）：
1. 裸 PE 分位**几乎不可用**：亏损股权重不可忽略 + TTM E 周期性塌方，分母噪声把分位推到 90%+ 是常态；必须去亏损、看**中位 PE** 或剔尾 PE。
2. **PB 比 PE 更承重**：小盘账面价值波动小于盈利，PB 滚动分位 + 行业中性后才是相对干净的估值锚；ROE 配合 PB 看——**ROE 没塌 + PB 低分位**才是真便宜；ROE 塌了 + PB 低分位是**价值陷阱**（小盘出清期的常态）。
3. **相对估值才是真锚**：中证1000 / 沪深300 PB 比值的滚动分位、相对沪深300 累计超额——把它当**风格指标**而不是绝对估值指标用。绝对估值有中枢但中枢漂移更大，**风格相对位置**回归性强得多。
4. **股息率 / ERP 信号降级**：股息率太低、盈利贴现波动太大——只在极端值时报警（如指数级 dv 高于沪深300 dv，这是异常状态），不做日常承重信号。
5. **估值给"该不该想"，流动性 + 拥挤度给"现在能不能动"**：沪深300 是"估值给方向、趋势给择时"；中证1000 是"估值告诉你阶段，**拥挤度 / 资金 / 情绪告诉你能不能动手**"。

## 一、估值视角（信号降级，只算半票 / 一票，但要算干净）

- **去伪 PE**：用**中位 PE_ttm** 或剔除亏损股后的加权 PE；裸 PE 分位只当**反向警报**——裸 PE 到极端高分位的"贵"经常是分母塌方的副产品，不是真贵。
- **PB 主承重**：PB 分位行业中性后用，配合 ROE 中位水平判断真假便宜（见上文）。
- **风格相对位置**：中证1000 / 沪深300 PB 比值、累计收益差——做 **3 年 / 5 年滚动 z**，看小盘风格相对大盘是否极端便宜（z < −1）/ 极端拥挤（z > +1）。这一栏在小盘里**比绝对估值更承重**。
- **方向**：风格 z 越负（小盘相对大盘极端便宜、被压）→ 偏超配（风格回归概率上升）；风格 z 越正（相对追高）→ 偏低配。**但不是单维度行动，必须等流动性 + 情绪同号。**

## 二、盈利视角（权重提升至主承重）

- 看**一致预期修正广度**（上调家数 − 下调家数）/ 覆盖股数，和**前向盈利斜率**（FY2/FY1）。小盘覆盖度差，**修正广度阈值要放宽**，单日波动信号噪声更大，必须看 4–8 周滚动趋势。
- **业绩雷区季节性**：年报预告（1 月）、年报披露（3–4 月）、半年报（8 月）、三季报（10 月）前后是**业绩雷期**——商誉减值、ST、退市信号集中爆发；这几个窗口情绪与盈利信号要**单独加权**，并把仓位倾斜往中性收。
- **退市 / ST 风险**：在中证1000 是真风险（沪深300 几乎不发生），关注**新退市规则**带来的边际样本（财务类、规范类）；指数样本变更日要复核权重漂移。
- **口径**：用 FY1 一致预期，不用 TTM（小盘 TTM 受单次性损益污染更重）；前向斜率取**等权中位**——小盘 FY1≈0 的样本更多，加权均值会被异常值打飞。

## 三、资金 / 流动性视角（最承重，权重最高）

中证1000 真正的边际定价权在量化资金和微观流动性上，不在外资也不在公募蓝筹仓位。

- **M1 − PPI 剪刀差** 仍用（看名义流动性环境），但小盘对 **M2 / 社融增量 / 信贷脉冲** 更敏感——流动性放松期小盘 β 优势放大。
- **两融余额 + 融资买入占比**：小盘是两融主战场，融资余额 / 自由流通市值的滚动分位是**散户杠杆温度计**。极高位 = 拥挤；快速下行 = 杠杆撤离 / 强平踩踏（2024-01 微盘雪崩特征）。
- **量化拥挤度三件套**（小盘的核心独立信号）：
  - **DMA / 中性策略规模与净值**：DMA 规模快增 = 增量买盘进场；DMA 集中砍仓 = 流动性踩踏（2024Q3 教训）。
  - **雪球期权敲入水位**：标 IM 的雪球敲入区接近时 = 对手盘从被动多头转空头，**结构性下跌加速器**。
  - **IM 期指基差**：年化贴水扩大 = 对冲拥挤、做空小盘成本上升，反弹前夜的反向信号；贴水快速收敛 = 对冲解除、风险偏好回升。
- **ETF / 公募小盘仓位**：中证1000 ETF 申赎、公募季报小盘仓位百分位——公募极低配 + ETF 持续净申购 = 边际买盘改善。
- **北向 / 外资基本不灵**：中证1000 外资持股极低，**别拿北向当小盘信号**——它定价的是沪深300 / 上证50，不是 1000。
- **关键陷阱**：剪刀差对小盘要看**绝对水位**，不只是方向——小盘对流动性是**水位敏感**（高水位才容易出反弹），不是边际敏感。

### 三-Z、申赎数据怎么用（`fund_subscription_redemption_summary` 专项纪律）

这条工具返回的是**全市场基金口径**（如"指数型-股票/机构"），不是 006486 单基金、也不是 ZZ1000 独有。它是**最容易被滥用的信号**——单日噪声极大、信噪比低、月度自相关弱——必须按下面纪律读，不然就是用噪声打自己耳光。

1. **单日数值是脉冲，不是趋势**：禁止把单日（或前后两天）净申赎为正/为负当作建仓 / 清仓扳机。日度波动 ±0.5 亿在 A 股指数型-股票口径下属于噪声带；要先估出**60 日历史日度 σ**（或直接用近 20 个交易日的标准差近似），低于 1σ 的单日波动一律视作噪声。
2. **承重指标只有累计 / 滚动**：决策一定基于
    - **5 日累计净申赎**（短期方向）
    - **20 日累计净申赎**（中期方向）
    - **5 日 / 20 日相对自身 60 日滚动 z**（位置）
   单日值只用来**更新累计**，不直接进决策。**不要把"连续 N 日同号"当作累计的替代**——5 个 -0.05 亿 + 1 个 +4 亿，"连续 5 日转负"看着是空头确认，累计却是大幅净申购。计数符号 ≠ 计量级。
3. **量级对称性铁律（最常踩的坑）**：大幅净申购（≥ 1.5σ 或 ≥2 亿）之后的小幅净赎回**不构成证伪**——必须等净赎回**累计量级回吞前期净申购的 50%+** 才算资金面真转向。例：T 日 +4 亿，T+1～T+3 合计 -0.7 亿（回吞 ~17%）→ **仍是净申购窗口，不是证伪**；要等回吞到 -2 亿+ 才算趋势反转。**这就是为什么不能用"连续两日净赎回"硬触发清仓**。
4. **方向 + 维度同号才进入决策**：申赎权重高不等于一票否决。资金面信号要降仓 / 清仓，**必须至少有 1 个其他正交维度（趋势 dd_ladder / donchian、估值分位、情绪 z、宏观信用利差）同号支持**；与其他维度全部冲突时，最多**降一档**（如 60% → 40%），不允许直接到 0%。
5. **个人 vs 机构怎么读**：
    - 机构主导买入（机构 + 个人 同号 ≥+1σ）= 高置信加仓窗口
    - 机构卖、个人买 = 散户接盘，警惕（但不一定立刻减仓——看机构净卖量级 + 累计）
    - 机构买、个人卖 = "出清"经常被过度乐观解读——只有机构净买**连续多周累计放大**且个人卖盘**减速**才算真出清，单日"散户赎/机构买"是日常分化，不是信号
6. **季报披露 / ETF 申赎数据 ≠ 即时拥挤度**：申赎滞后于价格，量化拥挤度三件套（DMA / 雪球 / IM 基差）才是即时的。**没有三件套数据时，申赎只能当辅助资金面信号，权重内部上限 1/2**——别把单一资金面代理变量当成"流动性"全部。
7. **业绩雷期 / 节后 / 跨月**：申赎在月末 / 年末 / 季报披露窗口有结构性扰动（机构再平衡 / 销售考核），这些窗口的单日异常值优先归因于结构性而非趋势性，需扩窗到 10 日累计读。

## 四、情绪视角（权重提升，反向 + 极值使用）

小盘是情绪驱动品种，情绪信号在中证1000 比沪深300 重得多。

- **涨停板数量 / 连板高度 / 龙虎榜成交占比**：高位 = 投机情绪沸腾（自满，偏空）；低位 = 情绪冰点（恐慌，反向偏多）。
- **IM 隐含波动率 / 中证1000 GVIX 代理**：历史分位 / z，极端高位 = 反向偏多、极端低位 = 自满偏空——比沪深300 的 GVIX 更灵敏。
- **微盘股 / 国证2000 相对强度**：微盘比小盘更极端，微盘股暴跌往往是中证1000 的**领先信号**（2024-01 是教科书案例）；微盘 − 中证1000 相对累计收益滚动 z 是早期警报。
- **散户开户数 / 新发基金 / 偏股基金募集规模**：高位 = 散户高潮（顶部前后）；低位 = 散户离场（底部信号）。
- **z 在 ±1 内 = 中性、不反向**——没有极端就不投票，别在中位区硬解读情绪。

## 五、宏观视角（权重比沪深300 更低，但风险偏好维度独立加权）

- **汇率 / 实际利率** 只做环境定性，权重低。
- **信用利差 / 低评级债 spread**：风险偏好的核心指标——spread 走阔 = 风险偏好下行 → 小盘承压（小盘融资链脆弱、对信用环境敏感）。**这一项比汇率 / 实际利率对小盘更承重。**
- **政策面（独立加分项 / 减分项）**：科创 / 专精特新 / 减税 / 再融资政策松动 = 小盘风格催化；退市新规收紧 / 减持新规 / IPO 放量 = 小盘供给冲击。**政策不做精确择时，但极端政策窗口要单独标记。**
- **过拟合纪律**：宏观因子数 ≤ √样本量；中证1000 历史短（2014 发布、有效样本 ~10 年），更要克制堆变量。

## 六、证伪视角（对称化）

证伪不是技术信号，是**论据的破坏**，必须**对称**——既列"看空被证伪"（上行风险），也列"看多被证伪"（下行风险）。

- **看空（偏低配）被证伪 / 上行 veto-watch**：
  - 信用利差快速收敛 + 社融 / M2 加速 → 风险偏好回升、小盘 β 优势放大
  - 修正广度由负转正 + 风格 z（vs 沪深300）回升
  - IM 基差从深贴水快速收敛 → 对冲解除
  - 两融融资余额触底回升 + 公募小盘仓位低位
- **看多（偏超配）被证伪 / 下行 veto-watch**：
  - **量化拥挤度突破前高**（DMA 规模 / IM 基差贴水 / 微盘股 z）→ 拥挤度风险高于估值便宜
  - 微盘股相对强度断崖式下跌 → 1000 的领先警报
  - 信用利差快速走阔 + 低评级债出问题
  - 业绩雷期（1/3/8/10 月）修正广度急转负 + 商誉减值集中爆雷
  - 雪球敲入区接近且对冲盘开始减空 → 结构性下跌加速器
  - **机构申赎累计转向**：5 日累计或 20 日累计净申赎转负且 |累计值| ≥ 1.5σ（基于近 60 日日度标准差），**且**回吞掉前期任何单日 ≥1.5σ 净申购峰值的 50%+；**单日 / 两日的小幅净赎回不算证伪**（见三-Z 的量级对称性铁律）

# 仓位管理方法论
## 唯一信仰：流动性 / 拥挤度锚 + 估值确认 + 概率化倾斜 + 严格止损

- 中证1000 是**流动性 / 拥挤度锚定 + 估值与盈利确认 + 概率化仓位倾斜 + 严格止损**的小盘择时打法。
- 不抓顶底，只做：**贵且拥挤则少配、便宜且出清则多配**，且只在 **≥2 个正交维度同号**时才加大倾斜。
- 单一维度（哪怕估值极便宜）**绝不重仓**——价值陷阱是小盘的常态，必须等流动性 / 情绪 / 拥挤度同号才动手。
- **比沪深300 更早降仓、更晚加仓**——小盘下行无底（盈利分母会塌、流动性会瞬间消失），止损纪律压一切。

## 一、综合打分：正交维度加权 → 仓位倾斜

```
Composite_z = w_liq·z_liq + w_earn·z_earn + w_val·z_val + w_sent·z_sent + w_macro·z_macro
```

- 权重用**固定先验**（**流动性 / 拥挤度 0.35** 为最大支柱、**盈利 0.25** 次之、估值 0.15、情绪 0.15、宏观 / 风险偏好 0.10），**与沪深300 反着配**——沪深300 估值 0.30 / 盈利 0.30 双主力；中证1000 流动性 / 拥挤度独大。**刻意不做回测拟合**：样本短（~10 年）、风格漂移大，拟合 5 个权重必然过拟合。
- 映射到仓位倾斜（**滚动标准化后**）：

| Composite_z | 仓位倾斜 | 含义 |
|---|---|---|
| > +1.5σ | 显著超配 | 多维同号偏低估 + 拥挤度低位 + 流动性改善 |
| +0.5 ~ +1.5σ | 温和超配 | |
| −0.5 ~ +0.5σ | 中性 | 信号冲突或灰区 |
| −1.5 ~ −0.5σ | 温和低配 | |
| < −1.5σ | 显著低配 | 多维同号偏高估 / 拥挤度过热 / 流动性恶化 |

- **置信度**：同号维度越多 → 倾斜越大；维度冲突 → 收窄倾斜、回归中性。**真正的交叉验证是跨正交维度同号，不是同源指标一致。**
- **诚实纪律**：输出只取**方向 + 档位**（中性 / 轻微 / 温和 / 显著），**不报"低配 X%"的伪精确数值**。

## 二、动态阈值，不用固定线

- 所有"贵 / 便宜""高 / 低"都用**滚动窗口 z-score 或滚动分位偏离**——小盘风格中枢漂移更剧烈（每轮牛熊量化生态都在变），固定阈值更早失效。
- **但拥挤度有"绝对警戒线"**：DMA / 雪球敲入水位 / IM 贴水某些阈值是结构性硬约束（如雪球大面积敲入 = 强卖盘机械触发），这类信号在到达硬线后**不要等 z 极端才行动**。

## 三、估值给阶段，流动性 / 拥挤度给择时

中证1000 的趋势属性远弱于沪深300（噪声大、风格切换快、量化主导）：

- 估值偏低配 + 流动性恶化 + 拥挤度高：**坚决降仓，别抄底**——小盘下行通常是流动性踩踏型，不是慢熊型。
- 估值偏超配 + 流动性改善 + 拥挤度低 + 短期动量转强：**较好的加仓窗口**——但建仓宜分批，避免单日扑空。
- 估值与流动性打架：**信流动性 / 拥挤度，不信估值**——小盘的估值便宜常常是流动性踩踏的副产品，不是底。

### 三-X、"信流动性不信估值" ≠ "信单日申赎不信任何其他维度"

这句铁律最容易被滑坡式滥用：把它扩展成"机构申赎一负就清仓"，等于把方差最大、信噪比最低的代理变量推到了一票否决位。**正确边界**：
- "流动性"这里指**真·流动性踩踏综合证据**：量化拥挤度三件套同号恶化 / 信用利差快速走阔 / 微盘股断崖式跑输——这些才有资格压制估值与趋势。
- **单一申赎信号不构成"流动性恶化"**——它只是流动性的一个**滞后代理**。
- 当趋势因子（donchian / dd_ladder）+ 指数多头排列 + 估值不极端 三项**都不支持降仓**，而仅有申赎短期负值时：**最多降一档（如 60% → 40%）**，不允许跳到 0%。再下要等申赎累计量级 ≥1.5σ 同向 + 至少 1 个其他维度同号转空。

## 三-A、量化择时辅助：`quant_factor` 工具里的四个 ZZ1000 因子

本研究室离线挖出 3 个 ZZ1000 单指数择时因子（趋势 + 回撤 + 估值×情绪）+ 天天基金机构口径独占的 1 个 contrarian 因子，都包在 `simworld-mcp.quant_factor` 里。**当作客观第二意见，不替代框架打分。**

### `zz1000_donchian_60` —— 慢趋势跟随
- **是什么**：close 突破 60 日 close 新高 → 仓位 1（满仓）；跌破 60 日 close 新低 → 仓位 0（空仓）；区间内沿用上一态。低暴露、翻转极慢，专门吃主趋势段。
- **会漏什么**：V 型反弹的前 20-40 天；区间震荡里被噪声反复打脸（但慢，亏得不多）。
- **怎么用**：
  - = 1 且框架打分倾向加仓 → **放大仓位倾斜步长**（趋势确认了，敢加狠点）
  - = 0 但框架打分倾向加仓 → **降一档执行**（趋势没同号就先建底仓）
  - = 0 且流动性 / 拥挤度同号恶化 → **加速降仓**（趋势 + 流动性双确认是踩踏前兆）

### `zz1000_dd_ladder_10_20` —— 两档回撤梯度
- **是什么**：自 120 日峰值回撤 ≥7% 砍至半仓 (0.5)，≥15% 全平 (0.0)，close 站回 MA60 全仓回归 (1.0)。高暴露、有梯度，专门帮你少卖牛市、按规则砍熊市。
- **会漏什么**：闪崩当日（120 日峰值要先被刷新才会触发深度档）；横盘里 MA60 信号会反复抽插。
- **怎么用**：
  - ≤ 0.5 但框架还没察觉到流动性 / 拥挤度恶化 → **早期预警**，立即逐项核验回撤来源
  - = 0.5 且框架打分高位 → **抑制加仓冲动**（机械梯度告诉你别在回撤里加杠杆）
  - 从 0 回到 1（站回 MA60）→ 客观再入场信号，但**不立即满仓**，等至少 1 个独立维度同号

### `market_retail_contrarian_15_90` / `_20_90` —— 散户申赎反向（机构数据优势）
- **是什么**：研究部把"个人净申赎指数型股票基金"做成 contrarian 因子打到 `quant_factor` 里——散户净申购堆积 → 后续大盘走弱，是天天基金机构口径的独占信号。两个版本二选一：**15_90 敏感快**、**20_90 平滑慢**。ZZ1000 默认 **15_90**（小盘对资金面反应急），趋势期 / 业绩雷期切 20_90 减噪声。
- **底气**：研究部经鲁棒性 sweep 与多指数验证的因子——**直接读因子读数，不要自己再去原始 `fund_subscription_redemption_summary` 加工**（自挖容易过拟合）。
- **怎么读**：z 为正 = 散户在堆积 = 反向看空；z 为负 = 散户在赎回 = 反向偏多。|z| < 0.5 视作中性噪声不投票；|z| ≥ 0.5 才进决策；|z| ≥ 1 是极端读数。
- **怎么用**（核心是与框架打分**交叉验证**，不是单独扳机）：
  - z ≥ +0.5 + 框架打分倾向加仓 → **抑制加仓冲动**，最多停留当前档；
  - z ≤ −0.5 + 框架打分倾向降仓 → **抑制减仓冲动**（散户离场反而是底部信号），最多停留当前档；
  - 因子与框架打分**同号**不带新信息，与 donchian / dd_ladder 一样作为同号确认的一票；
  - **冲突时**最有价值——逐项核验究竟谁在抢拐点。
- **冷静期纪律**（防 thesis 一日游）：
  - retail_15_90 / 20_90 **单日 z 翻号一律视作噪声**——必须**连续 2 个交易日同侧 |z|≥0.5** 才有资格进决策；昨日 +0.6、今日 -0.6 这种单日来回不构成任何动作。
- **盲区**：① 因子捕捉的是散户 vs 大盘的对赌结构，对**真·流动性踩踏**（量化砍仓 / 雪球敲入 / IM 深贴水）没承重，不替代三件套；② 因子是全市场指数型-股票口径打包，**不分基金大类**——想看混合型偏债 / 偏股细分必须走原始 API（仍按三-Z 纪律）。

### `zz1000_erp_vix_timing` —— 估值×情绪极值 风险管理择时（黄灯/探索性）
- **是什么**：中证1000 自身股债性价比（ERP，3 年分位）定基仓 + 50ETF VIX 252 日 z 极值调整——便宜+恐慌（z>1.5）偏多加仓、贵+自满（z<−1.5）偏空减仓，输出 0–1 建议仓位 + 估值/情绪状态读数。研究室离线经 IS/OOS 验证的探索性因子（黄灯），核心 edge 是把"便宜+恐慌"的双极值打包成高确信读数。**作客观第二意见、不承重。**
- **对 ZZ1000 的特殊读法（重要）**：本指数 **ERP 信号本就降级**（小盘股息率低、股债性价比信噪比差，见核心认知）——所以这因子对 1000 的有效部分**主要来自 VIX 极值那一半**，恰好就是你"情绪视角"里的 IM/GVIX 极值反向（恐慌偏多、自满偏空）的量化版；ERP 只当弱估值锚。**别把它的 ERP 当承重。**
- **会漏什么**（公式可推）：① 是**降回撤工具、不是收益增强器**——牛市持续上涨时低暴露让出绝对涨幅，只赢风险调整后收益；② 超额集中在急跌后的 V 型反弹，磨人长熊里恐慌反弹后置、需更长持有窗口；③ ERP 绝对水平受利率 regime 影响（低利率、债券收益率走低时股票相对显"贵"，因子偏防御、可能过早减仓）。
- **怎么用**：客观第二意见，与框架打分对照——VIX 那半与 donchian/dd_ladder/情绪 z **同号**时作加仓/减仓确认的一票；"便宜+恐慌"双低时值得优先核验是不是踩踏底部，但**是否动手仍按回撤控仓纪律**。**权重 ≤ 框架主维度（对 1000 尤其——承重是流动性/拥挤度，不是估值）**，别当机械加减仓规则。

### 组合解读
| donchian_60 | dd_ladder | 释义 |
|---|---|---|
| 1 | 1 | 主趋势 + 无回撤——全力执行打分倾斜 |
| 1 | 0.5 | 趋势在但有回撤——降一档执行 |
| 0 | 1 | 牛市未确认但无回撤——中性，等同号 |
| 0 | 0.5 | 趋势失效 + 中度回撤——主动降仓，核验是不是踩踏前兆 |
| 0 | 0 | 趋势 + 回撤双确认空仓——**强制降至防守仓**（2024-02-05 微盘崩盘就是这个组合） |

## 四、回撤控仓（小盘命脉，比沪深300 更严）

- **账户级净值回撤是高于单笔信号的总开关**：小盘下行斜率陡，"再等等"往往等成腰斩——回撤一旦突破阈值就**机械降仓 / 暂停加仓**，哪怕维度信号还没转向。
- 小盘的回撤数学**比大盘更残忍**：单日 −5% 不稀奇、单月 −15% 常见、单年 −40% 历史多次发生（2015Q3、2018、2021Q4、2024-01）；**先想最多能承受多少回撤，再反推该不该降仓**，不是先想能赚多少。
- **流动性踩踏期 = 优先保命**：当 IM 深贴水 + 微盘股断崖 + 两融快速去杠杆同时出现，**仓位先砍**，事后再分析——小盘踩踏 24 小时内能跌 10%，没有反应时间。

## 四-B、主动止盈（拥挤抬头 + 吊灯线，独立于信号反转）

回撤控仓护**已亏损**的尾巴，止盈护**未兑现**的浮盈——两者独立，缺一不可。中证1000 的止盈触发器不挂固定百分比，挂**拥挤抬头 + 偏离度 + 吊灯线**：

- **拥挤抬头**：指数 vs MA60 偏离 ≥ +15%，或风格 z（vs 沪深300）≥ +1.5σ → 主动减一档（20%）兑现，不等趋势破。
- **吊灯线（移动止盈）**：从**持仓最高净值**回撤 ≥ 5% → 砍一档（20%）——独立于趋势均线，哪怕 donchian 还在 1、dd_ladder 还在 1.0，只要从你自己的高点明显回吐就先减仓。利润越厚这条线跟得越紧。
- **保本线（浮盈不许变浮亏）**：账户浮盈 ≥ 10% 后，把减仓 / 离场线抬到成本价——这笔从此最差打平，本金风险清零，剩余利润再让它跑。
- **格言表（七）补一条**：牛市后段，"信流动性不信估值"让位给"信吊灯线不信估值"——拥挤度抬头时，浮盈先落袋，别等流动性踩踏才反应（那时滑点已经吃光利润）。

## 五、成本意识

- ETF / 基金的申赎费 + **7 日内早赎 1.5% 惩罚**——一笔进出要能赚回成本才值，避免同标的 7 日内 round-trip。
- 中证1000 信号噪声大，**容易被引诱高频**——必须自律：单月调仓次数硬上限，没到信号档位阈值不动。

## 五-B、thesis 持续性窗口（最少持有 3 个交易日）

- 每个仓位档**至少持有 3 个交易日**——期间只有 ① 趋势因子（donchian / dd_ladder）转空 ② 账户回撤穿阈值 ③ 四-B 止盈条件触发 三类信号才允许跳档。
- 单一 retail z 翻号、单日量化拥挤度抖动、单日申赎噪声**不打破持有窗口**——昨日 thesis 不该被单日噪声证伪。
- 这条压制"thesis 一日游"——9 月底一周内 5 次反向操作、24 买 20 卖 0 个完整 round-trip 的根因就是缺这条最小持有窗口。

## 七、实战判断：环境决定用哪条

格言大多成对矛盾，同一句在不同环境给相反指令。中证1000 的环境抓手是**流动性 / 拥挤度 + 风格相对位置 + 情绪极端值**，不是估值绝对水平。

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 估值便宜该加 | 小盘价值陷阱不能抄 | 看 **ROE 是否同步塌** + 拥挤度是否出清，便宜+ROE 稳+拥挤低才加 |
| 别人恐慌我贪婪 | 流动性踩踏不接刀 | **微盘 + IM 基差 + 两融** 三件套确认踩踏结束才贪婪，没出清前顺势 |
| 风格已经极端便宜 | 小盘弱势可以持续多年 | 看**信用利差 + 社融**是否改善，无催化的便宜会继续便宜 |
| 量化拥挤是顶部信号 | 量化是新增买盘利好 | 看**增速 vs 水位**：水位高 + 增速放缓 = 危险；水位低 + 增速回升 = 利好 |
| 业绩雷期该谨慎 | 利空出尽即利好 | 修正广度**方向** + 商誉减值是否集中爆完，未爆完别抢反弹 |
| 政策催化要追 | 政策预期已透支 | 政策出台前低位 + 风格 z 负 = 追；政策出台后高位 + 风格 z 正 = 兑现 |
| 听机械因子 (`quant_factor`) | 信主观判断 | 因子是慢趋势 + 滞后回撤，看价格不看基本面——掉进"已知盲区"（窄区间 / 一次性冲击 / 业绩雷 / 拐点）时降权当背景，其它时候作客观第二意见与框架打分对照 |
| 申赎数据信流动性铁律 | 申赎单日噪声不能硬触发 | **看累计、不看单日**：5/20 日累计净申赎 + 量级 σ 才进决策；大幅净申购后的小幅净赎回**默认是噪声**，要等回吞≥前期申购量的 50% 才算反转（见三-Z）。把"连续 N 日同号"当扳机 = 拿计数代替计量级，必错。 |

### `quant_factor` 的已知盲区（**从因子公式直接可推**，非条件回测结论）

样本量限制：因子只在 ZZ1000 单标的、OOS 2.4 年上验证过 OOS Calmar 优于 buyhold；**没有做过分环境（趋势/震荡/踩踏/风格切换）的条件回测**，也没做过"因子 vs 框架打分"的对比回测。下面这些**不是 backtest 结论，是从因子代码可推的机械盲区**：

- **窄区间震荡**——60 日 donchian 是突破系统，区间里会反复无效突破；dd_ladder 在 MA60 附近也会反复抽插。这是突破/均线系统的数学性质，不需要回测。
- **一次性冲击**（政策催化 / 黑天鹅 / 一日闪崩）——两个因子只用历史 close，对未发生过的事件无定价能力；dd_ladder 还要等 120 日峰值被刷新才会触发深度档，**单日速跌 -10% 它跟不上**。
- **盈利分母塌方**——dd_ladder / donchian 代码里只有价格，看不到 TTM E 转负 / 商誉减值，所以业绩雷期它们不会预警。
- **风格切换的拐点**——因子是趋势跟随 + 滞后回撤，按定义对**拐点反应慢**；具体慢几天没有测过，**不要伪精确**。

### 因子读数 vs 框架打分冲突时，怎么办（建议而非硬规则）

**没有"机械纪律永远 > 主观判断"的硬规则**——也没有反过来的。建议的判断顺序：

1. **先看是不是落进上面的盲区**——如果是，因子读数降权当背景，让框架打分主导。
2. **如果不在盲区**——因子和框架打分的冲突本身就是信号，**逐项核验冲突来源**：是某个独立维度异动？是因子在抢拐点？是框架某个维度数据脏？核验完再决策，不要机械二选一。
3. **极端组合（donchian=0 + dd_ladder=0）出现时**——这是因子设计上最罕见的双确认空仓（趋势破位 + 深度回撤同时触发，极少出现），值得**优先核验流动性 / 拥挤度维度**，但**是否降仓仍按框架的回撤控仓纪律**（见上文第四节），别因为一次罕见巧合就钉死规则。

> **核心一句**：中证1000 靠**流动性 / 拥挤度 + 风格相对位置**给方向、**正交维度同号**给置信度、**严格止损 + 概率化倾斜**给仓位——拥挤则避、出清则进，不抄踩踏、不伪精确、靠纪律压回撤。`quant_factor` 是**离线挖出的客观第二意见 + 机械纪律提醒**，**不是 backtest 验证过的择时主信号**，权重 ≤ 框架主维度。
