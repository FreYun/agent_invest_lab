# 芯片指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，**先判市场环境（〇节，永远的第一步）**，再从下面几个角度审视，自行综合判断该不该动、动多少。

> 芯片是 A 股科技成长里**周期最完整、叙事最密集**的赛道——三重周期叠加：**全球半导体销售周期**（周期之锚）×**国产替代结构线**×**AI 算力国产化事件线**。它的玩法核心是：**先认清当下哪条线在定价，用库存周期与文本面给方向，用趋势与回撤纪律给仓位**。且主口径在科创板：±20% 涨跌幅与脆弱的流动性结构，要求仓位纪律比任何主板指数框架都更严。

## 核心认知

主口径**上证科创板芯片指数（000685，科创芯片）**：科创板上市的芯片设计/制造/设备/材料公司，中芯国际、海光信息、寒武纪、中微公司类龙头集中。五个特性决定玩法：

- **三重周期叠加，主驱动会切换**：①**全球半导体销售周期**（SIA 销售额 YoY、存储价格、费城半导体指数映射）是周期之锚，定大方向；②**国产替代/自主可控**是穿越全球周期的结构线；③**AI 算力国产化**是事件线——海光/寒武纪类算力芯片权重上升，使指数与 AI 主题联动显著加强，一条算力订单/管制新闻能定价数日。**看错主驱动，后面所有信号都会读错**——判断当前主驱动是每天的第一个问题（见〇节）。
- **科创板微观结构特殊**：±20% 涨跌幅、机构定价为主、流动性结构脆弱——**下跌时买盘消失得比主板快**，跌停连板、流动性瞬间蒸发的尾部风险比全市场芯片指数大。弹性更锐是双向的：主升更陡，崩得也更快。
- **制裁的反直觉读法（与设备框架共用的承重认知）**：同一条制裁新闻方向可能相反。卡国内晶圆厂/算力芯片获取（断供高端 GPU、限制先进代工）→ 把需求逼向国产，常是国产芯片的**上行催化**；但断国产厂自身的设备/材料/零部件/IP/EDA 供应是**真利空**。先分清打的是"全球景气"还是"国产份额"，再定方向，两面都要评估。
- **库存周期是景气主轴**：主动去库 → 被动去库（底部区）→ 主动补库（主升）→ 被动补库（顶部区），四阶段循环；数据散在研报里（`[仅文本]`），但它决定"在不在场"这个最大的问题。
- **权重高度集中**：指数走势高度由制造（中芯国际）+ 算力（海光、寒武纪）少数龙头驱动，**必须穿透到龙头看**（订单、稼动率、新品、预期修正），不能当宽基。

### 芯片指数的估值特性（先记住再看一节）
1. **周期成长股的 PE 会"骗人"**：景气下行盈利坍塌 → PE 飙到天上甚至转负（"贵"反而可能在底部）；景气上行盈利暴增 → PE 显得便宜（"便宜"常是顶部特征）。裸 PE 分位做均值回归择时，方向容易整个反掉。
2. **科创板估值没有主板的"地心引力"**：机构按远期空间/PS/国产化率定价，算力芯片类标的常年"贵到看不懂"——用主板估值常识做空它是亏损来源；但这也意味着杀估值时没有"便宜"接盘垫。
3. 估值只做两件事：极端泡沫的**定性预警**（配合全民进场信号），和极端便宜处**触发去文本里找库存周期反转证据**——不是择时扳机。

| 口径 | 角色 | 说明 |
|---|---|---|
| **000685 科创芯片（主）** | **交易标的** | 2019-12-31 基日、6.4 年样本；更锐、AI 算力国产化浓度更高，所有仓位决策落在它身上 |
| **980017 国证芯片（副）** | **长样本研究锚** | 2012 年起 14.4 年样本；全市场 30 只芯片龙头（设计为主+设备制造，北方华创、中芯、韦尔、澜起、兆易类）；**周期规律、因子验证都在它身上做**——000685 样本太短，任何"历史规律"先到 980017 上验真再用 |
| **931743 半导体设备材料** | 相邻框架（semiconductor.md） | 纯"卖铲人"口径，母变量是晶圆厂 capex；本框架是铲子的下游——芯片设计/制造，母变量是终端需求与库存周期。两框架共享制裁反直觉读法与国产化率标尺，但**景气链不同**：设备看 capex 指引与订单，芯片看销售周期与库存阶段，别互相串台 |

## 〇、先判市场环境（永远的第一步）

任何信号读取之前，先回答三个问题并**显式留痕**（写进当日复盘，明天直接继承）：

**1）全市场环境：现在的 A 股欢迎高 β 科技成长吗？**
科创芯片是全市场风险偏好的**放大器中的放大器**（科创板 + 芯片双重 β）。风险偏好收缩期它跌得比大盘深得多；价值/红利风格窗口里基本没行情。用 `macro_50etf_vix`、市场情绪指数（按累计与 z 读，不读单日）、大盘趋势粗判：**扩张 / 收缩 / 中性**。收缩期里所有看多信号自动降一档，且科创板流动性蒸发风险（见仓位管理一节）权重自动上调。

**2）板块自身状态：趋势市 / 震荡市 / 过渡待定（三选一）**
- 趋势市：均线（MA60/MA120）单边排列、斜率明显，价格沿一侧运行 → 趋势骨架。
- 震荡市：长均线走平 + 价格在均线 ±15–20% 箱体反复（科创板波动大，箱体更宽）、假突破频出 → 防守骨架。
- 过渡待定：两边都不像 → 轻仓/维持原状态/观望。
**状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日大阳大阴、单根假突破不算切换信号。**980017 同步判一遍做交叉验证**——长样本口径的状态更稳，可当 000685 状态判断的第二意见。

**3）主驱动识别：三条线谁在边际定价？**
- **全球半导体销售周期主导**：信号源 = SIA YoY、存储价格、稼动率、库存阶段、费半趋势——看三节。此时海外映射权重高，夜盘费半大波动次日大概率传导。
- **国产替代/自主可控主导**：信号源 = 制裁事件、国产化率叙事、政策与产业基金——看四节。此时与全球周期可能**反向**（全球景气差但国产份额逻辑强化）。
- **AI 算力国产化主导**：信号源 = 国产算力订单/新品/生态适配、海外算力管制松紧、大模型事件——文本面密度最高的一条线，脉冲与反转都最快，提防事件回补。
三条线常常并存，问的是**边际上谁在定价**，写一句话留痕。**环境错判，再好的纪律也会用反**——这一节没做完，不允许进入任何加减仓决策。

## 一、估值视角（定性预警，绝非择时扳机）

按"核心认知-估值特性"执行，补充操作含义：

- **禁止用 PE 分位对它做低吸高抛**。周期底部盈利坍塌会把 PE 顶到天上（在底部喊你跑），景气高点 PE 反而"合理"（在顶部劝你留）。**"趋势 > 估值"是单向过滤器**：只否决"因为贵所以走/因为便宜所以接"，不是无视估值的通行证。
- **科创板天花板预警要换尺子**：对远期空间定价的算力标的，与其盯 PE 分位，不如盯**定价口径切换**——研报集体从盈利切到"远期空间/星辰大海"是泡沫化特征；市场从"空间"切回"当期盈利"讨论，本身就是降温信号。
- **极端泡沫预警（顶）**：估值极端分位 + 全民进场信号（芯片成为全民词汇、主题基金爆量发行、涨幅榜被边缘小票接管）→ 当成趋势可能进入尾段的提示，配合趋势框架与止盈纪律处理。
- **极端便宜（底）**：深跌 + 盈利下修持续多季 → 不抄底，但**触发去文本里找库存周期反转证据**（被动去库特征、存储价格企稳回涨、稼动率回升、砍单结束），证据出现且趋势企稳，按骨架快速回补。
- **盈利上修斜率比分位承重**：`stock_alpha` 龙头一致预期变动率月度跟踪——上修加速 = 燃料还在；上修放缓/转下修 = 顶部最可靠的领先信号之一（比价格破位早）。

## 二、趋势视角

- **方向锚**：收盘价 vs MA120/MA200 + 均线斜率；时序动量（20–60 日收益符号）辅助。**双口径都算：000685 给交易信号，980017 给周期位置参照**——000685 的均线系统只有 6.4 年历史，参考深度有限；两口径趋势背离时多一分谨慎。
- **量能/拥挤确认**：指数无量 → 板块拥挤度代理。突破时拥挤度同步抬升 = 有量；不跟 = 可疑假突破。**拥挤度极端高位 + 价格加速 = 主升尾段特征**，对照止盈纪律。
- **跳空甄别**：芯片跳空多由三类引发——费半夜盘映射、制裁/政策、AI 算力事件。分清**逻辑级**（制裁逼转单、订单落地、库存拐点 → 可顺势）还是**情绪级**（映射单日波动、无增量传闻 → 易回补）。判别方法：第二天去研报/纪要里找基本面增量，没有增量的跳空一律当情绪脉冲。
- **科创板特有**：±20% 制度下，**不要把一根大阳/大阴当趋势确认**——单日波动本身不构成状态切换证据；震荡市里均线信号抽脸比主板更凶，转箱体思维（见仓位管理）。

## 三、景气视角（库存周期为主轴，分层领先滞后）

芯片景气有清晰的领先滞后结构，别用滞后指标做择时：

| 层 | 指标 | 性质 | 取数 |
|---|---|---|---|
| 领先 | 存储价格方向（DRAM/NAND）、下游砍单/拉货传闻 | 价格是周期最敏感的体温计 | `[仅文本]` |
| 领先~同步 | SIA 全球销售额 YoY、晶圆厂稼动率、费半趋势 | 周期之锚 | `[仅文本]` |
| 同步 | 库存周期阶段认定、龙头存货周转率变化 | 主轴 | `[仅文本]` + `[结构化·龙头]` |
| 滞后 | 龙头营收/净利 YoY、一致预期修正 | 确认不择时 | `[结构化·龙头]` |

- **库存周期四阶段是主轴**：主动去库（量价齐跌，最痛段）→ **被动去库（出货回升、库存还在降——底部区，最佳布局窗口）** → 主动补库（量价齐升，主升段）→ **被动补库（出货放缓、库存回堆——顶部区，兑现窗口）**。阶段认定靠研报口径 + 龙头存货周转率交叉，宁可粗判不可不判，结论写进留痕、明天继承。
- **存储价格是最好用的高频体温计**：存储是大宗化最彻底的芯片品类，价格方向近乎实时反映供需——涨价周期启动常领先板块行情，跌价加速是周期下行的确认。
- **稼动率读法**：晶圆厂稼动率回升 = 下游真实拉货（比设计公司"指引"硬）；稼动率高位 + 各家宣布扩产 = 周期成熟，开始警惕供给释放。
- **AI 算力国产化与全球周期可能脱钩**：国产算力需求由"可获得性"（管制卡脖子程度）与国产化意志驱动，不全跟全球周期——〇-3 判定这条线主导时，本节权重让位于四节与文本面。
- **纪律**：领先端定方向，滞后端做确认；背离时信领先端。**等财报确认再动，通常已走完半程**——财报的价值是证实/证伪此前文本面读到的方向。

## 四、国产替代/制裁/政策视角（结构线，与全球周期半解耦）

- **结构性 alpha**：国产替代是穿越全球周期的独立动力——全球景气平淡时，国产份额提升（切国产代工、整机切国产芯片）也能撑业绩。国产化率离天花板的距离管"这轮渗透还有多少空间"、管"值不值得在趋势里重仓"，不管择时。
- **制裁的两面评估（每条消息必做的拆解）**：
  - **利好面**：限制国内厂商获取海外先进制程/算力芯片 → 需求被逼向国产（国产算力、成熟制程代工受益）→ 上行催化，AI 国产化线直接受益。
  - **利空面**：断国产厂自身的设备/材料/零部件/IP/EDA 供应 → 卡国产产能与迭代 → 真利空，制造环节首当其冲。
  - 同一揽子制裁常两面都有，**逐条拆打到哪一环再合成方向**；拆不清楚时按事件前减敞口处理（见仓位管理）。
- **管制放松同样反直觉**：海外算力芯片对华供应松动，对全市场是情绪利好，但对**国产算力线是利空**（替代紧迫性下降）——AI 国产化主导定价时，这条要反着读。
- **政策/产业基金**：产业基金投向、政府与运营商算力采购、信创节奏是真金白银的需求注入；跟踪资金与订单落地节奏，不停留在消息面。

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（机构调研纪要，PIT 截断到当日）+ `research_search` / `research_view`（新闻/研报）。**每个交易日必须执行，不允许跳过**——哪怕当天决定不动仓位。其他视角缺数据可降级，这个视角不读完不许收工。

> **为什么权重必须高**：本框架的母变量——库存周期阶段、存储价格、稼动率、制裁条款细节、国产算力订单——**没有一个是结构化数据**，全部活在研报、新闻、调研纪要里。且 000685 口径价格类择时因子无统计学支持（见量化辅助节），丢掉文本面，这套框架就没有方向与领先性来源。

### 每日固定动作（3–5 次调用内完成，不许刷库）

1. **扫当日纪要流**：`zsxq_topics`（count=20）过当日新增纪要标题/摘要——芯片设计/制造/算力/存储相关标记下来；机构密集调研某环节，密度本身是信号。
2. **主题词检索**：`zsxq_search` 用 1–2 个当日主线词（如 '国产算力'、'存储'、'晶圆'；搜 0 条先看 `query_used` 换词重试）。需要正文再 `zsxq_topic_detail`，**最多 1–2 篇**。
3. **新闻/研报面**：`research_search`（search_type='all'）查当日库存/价格/制裁/订单增量；季报季加扫龙头业绩与稼动率表述。
4. **海外映射**：费半/海外算力链夜盘大波动时，专项检索原因并分类：逻辑级还是情绪级；制裁新闻必须当天完成"打到哪一环"的拆解。

### 怎么读（纪律——文本是信息也是毒药）

- **读事实与方向，不抄结论**：纪要 = "机构在看什么 + 公司说了什么"，是关注度代理 + 基本面事实源，不是买卖建议。
- **领先性分层**：存储报价、砍单/拉货、稼动率、订单类**事实** = 领先信号，承重；研报观点/目标价 = 滞后的情绪代理，只做密度统计。
- **一致性观点逆向读**：文本流一致看多在趋势成熟期是反向信号、在行情 onset 期是领先信号——属于哪种，回到〇节的环境判断当场定，不给机械线。
- **证据落链（硬性）**：当日 belief/复盘 evidence 至少 1 条文本类条目（带 topic_id 或 INFOCODE + 一句话摘要）；没读到就如实写"今日文本面无增量"。**没有检索记录不许引用任何"听说/市场传言"**。
- **留痕（硬性）**：每日复盘固定一行 `文本增量: 无|低|中|高 —— <今天读到了什么、有没有改变判断或动作>`。
- **权重边界**：文本面给**方向与证伪**，不直接给仓位数字；任何文本信息都不得突破回撤控仓与仓位步长纪律。

## 六、证伪视角（对称化）

证伪是**论据的破坏**，必须对称——看多与看空的证伪都要列；触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 存储价格涨势停滞转跌 / 跌价加速（周期体温计转向）
  - 库存阶段出现被动补库特征（出货放缓、库存回堆、稼动率见顶回落）
  - 龙头一致预期变动率由上修转下修（最早的硬信号）
  - 制裁实质打到国产厂自身供应链（设备/材料/IP/EDA 断供落地）
  - AI 国产化线：国产算力订单不及预期 / 海外管制实质放松（替代紧迫性下降）
  - 980017 长口径趋势先行转弱（结构性退潮预警，科创口径通常更晚但更猛）
- **看空被证伪（上行 veto-watch）**：
  - 存储价格企稳回涨 + 稼动率回升（被动去库 → 主动补库的切换证据）
  - 制裁收紧但打的是"获取端" → 转单/国产算力需求被逼出（利空读反了）
  - 政策/采购资金实质落地、龙头盈利下修结束 + 趋势企稳（按〇-2 确认级证据）
  - 系统性恐慌但库存周期位置仍在底部区（错杀）

# 仓位管理方法论

## 唯一信仰：环境定骨架 + 库存周期定方向 + 科创板纪律压回撤

- 科创芯片是**超高弹性 + 事件密集 + 流动性结构脆弱**品种，单指数策略夏普的提升几乎全部来自压低最大回撤。你的活儿是周期顶部、制裁误伤、流动性踩踏来时少亏；主升浪在场吃足。
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理（轻仓/观望/维持原状态），不是习惯性下半注。
- 该在场时别缺席：库存周期上行 + 趋势多头 + 文本面订单饱满时还空着 = 踏空，同样不及格。

## 一、科创板流动性纪律（比主板框架更严的三条）

这是本框架与其他指数框架在仓位上的**最大差异点**，单列：

- **下跌加速假设**：±20% 制度 + 机构定价 + 买盘脆弱 → 下跌时流动性瞬间蒸发、跌停连板的尾部风险真实存在。**凡趋势转空/系统性风险，离场动作要比主板框架更快更大**——"再确认一天"在科创板的代价是主板的再上一档。
- **事件前减敞口更严格**：重大制裁窗口、海外算力链财报夜、重要政策窗口前，不赌方向是底线；仓位重时主动降到"能扛一个深度跳空"的档位。
- **回撤控仓阈值前移**：账户级回撤闸门（见四）在本框架触发更早、降仓更狠——回撤数学不对称（−20% 需 +25%、−33% 需 +50%），本指数单边下跌极易摸到深水区。

## 二、骨架选择（承接〇-2 的状态分类）

- **趋势市 → 时序动量 + 波动率体感**：方向对就拿住让 β 跑；方向转空（趋势破位 + 景气链确认）降仓乃至清空。趋势里不做高抛低吸。振幅骤增本身是降仓信号——越平静越敢拿。
- **震荡市 → 防守、少动、守箱沿**：箱体中段不动手；轻仓不赌箱体（一条制裁消息就能突破或跌穿）；不追假突破；放量/逻辑级催化突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- **过渡待定 → 维持原状态/轻仓**，等确认。

## 三、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%；2–5% 微调无意义。
- **系统性风险 / 周期顶部确认 / 趋势转空 → 一把降到位，可以到 0**：按"下跌加速假设"执行，等"再确认一天"在本指数上代价最大。
- **回补按赔率**：高赔率组合 = 库存周期底部区证据 + 存储价格回涨 + 趋势放量突破 + 文本面订单饱满 + 拥挤度未极端 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。优势小却重仓 = 把数学优势送回去。
- **只在浮盈/趋势未坏的回调里加仓；绝不在下跌趋势中摊薄**（箱体有支撑的回踩可小幅低吸，趋势已破的下跌不能接）。

## 四、止盈止损与回撤控仓：趋势 + 回撤说话，不用固定数字

- 在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势在、回撤温和 → 拿住；趋势破位/回撤明显放大 → 大块兑现乃至清空。
- **主升尾段的主动止盈**：拥挤度极端 + 定价口径切到"远期空间" + 文本面一致看多三者叠加时，吊灯线收紧（从持仓高点回撤即减档）——科创板的流动性反转没有缓冲带，别等它反转才反应。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。
- **账户级回撤闸门**：净值从峰值明显回撤 → 机械降仓/暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**（不得拿假想回撤反推事前仓位天花板）。

## 五、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；事件脉冲密集的板块尤其要克制高频。
- 每个仓位档**至少持有 3 个交易日**（thesis 持续性窗口）；期间只有趋势转空、账户回撤穿阈值、止盈触发三类信号允许跳档——单日情绪、单日大阳大阴不打破持有窗口。

## 六、量化择时辅助（研究室 2026-06-11 全 44 因子族扫描，5bp 单边、T+1）

> **000685 科创芯片（主口径）：无可包装因子，本框架是纯定性框架。** IS 段（2020–2021）是单边牛市（buyhold IS Calmar 0.90），任何择时因子都跑输 IS；且样本 IS<3 年属探索性。诚实结论：**价格类择时因子在本口径暂无统计学支持**。探索性记录（不作建议，仅存档）：regime_lever（趋势向上+低波动满仓 / 高波动降杠杆 / 趋势向下空仓）OOS dCal +0.41 但 IS 大幅跑输。
>
> **980017 国证芯片（长样本验证，✅绿灯）——但注意：验证于 980017，外推到 000685 未验证，对科创芯片只能当背景第二意见**，永远不直接变成 000685 的仓位动作，中间必须经过本框架的定性判断。

### `mom_20`（980017）—— 20 日动量
- **是什么**：20 日收益 >0 → 满仓，否则空仓。IS_dCal +0.48、OOS Calmar 0.36 vs buyhold 0.17（dCal +0.20）、CI[0.39,1.47]、wf 4/5、翻转 ≈23 次/年。
- **会漏什么（公式可推）**：震荡市反复抽脸（翻转频繁是它的代价）；只认 20 日价格方向，**对制裁、库存周期、财报一概看不到**。
- **怎么用**：当 980017 口径的"周期方向第二意见"。与本框架同向 → 信心加分；它在 980017 转空而你在 000685 还满仓 → 优先逐项核验是不是漏了什么，不是机械跟随。

### `rsi_panic_re_entry`（980017）—— 恐慌躲避
- **是什么**：默认满仓；RSI14<30 且 close<MA200（恐慌+破位双确认）→ 空仓；RSI 回到 >50 → 满仓。OOS Calmar 0.36（dCal +0.19）、CI[0.20,1.25]、**wf 5/5**、exposure 0.73、4.4 年翻转 30 次。本质是"只躲恐慌尾部、绝大多数时间在场"的防守因子。
- **会漏什么（公式可推）**：缓跌阴跌不触发（RSI 到不了 30）；单日闪崩滞后（RSI14 是 14 日口径）；同样看不到制裁/库存周期/财报。
- **怎么用**：它在 980017 触发恐慌离场，是给 000685 的一个客观"系统性恐慌"提示——结合〇-1 环境判断核验，科创板流动性纪律此时自动收紧一档。

## 七、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 制裁是利空快跑 | 制裁逼出国产替代是利好 | 拆打到哪一环：卡获取端（算力/代工）逼转单看 B，断国产厂自身设备/材料/IP 看 A |
| 估值太贵该减 | 科创板按远期空间定价 | 盈利上修 + 趋势多头看 B；定价口径切回"当期盈利"、拥挤极端时极端读数当顶部预警 |
| 全球周期向下要躲 | 国产替代穿越周期 | 看〇-3 主驱动：全球周期定价期看 A；国产份额/AI 国产化定价期看 B，但别拿 B 当熊市死扛的借口 |
| 费半大跌要跟 | A 股芯片有自己的节奏 | 分逻辑级（全球景气/管制变化 → 跟）还是情绪级（单日波动映射 → 看〇-1，收缩期跟、扩张期当回调） |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 库存周期底部区 + 逻辑没坏的恐慌看 A；主动去库未完、周期下行中段看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；被动补库特征 + 拥挤极端 + 一致看多看 B |

> **核心一句**：科创芯片——先判环境（全市场风险偏好 + 板块状态 + 三线主驱动），用**库存周期与文本面**给方向、**趋势/动量**给择时、**科创板流动性纪律 + 回撤控仓**压尾部；制裁先拆环节再定方向，980017 当长样本周期锚与第二意见，空仓不愧疚，靠压回撤把夏普做上去。
