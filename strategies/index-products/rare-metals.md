# CS稀金属指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证稀有金属主题（CS稀金属 930632.CSI）**。

## 核心认知

CS稀金属（930632）= **能源金属周期 × 矿企 / 盐湖经营杠杆**的极致高波动赛道。它是一篮子稀有 / 能源金属，**以锂、钴为主，叠加稀土、钨、钼**，整体偏新能源上游电池金属——前十大权重里盐湖股份、华友钴业、赣锋锂业、天齐锂业等锂钴标的占了大头，洛阳钼业（钼 / 钴）、北方稀土、厦门钨业、中钨高新补全稀土钨钼一翼。五个特性决定玩法：

- **能源金属周期，自成一条供需**：锂 / 钴的需求母变量是**新能源车 + 储能 + 三元正极**，不是全球 PMI / 基建 / 地产。锂钴常单边大涨大跌、与宏观工业品节奏错位，美元 / PMI 对它解释力有限，别用宏观周期框架硬套。
- **极致波动 + 双重杠杆**：盈利 = (锂 / 钴价 − 单位成本) × 销量，营业杠杆 + 财务杠杆叠加；商品价跳变常对应矿企 / 盐湖利润 50%+ 的跳变。**碳酸锂 2021–2022 从几万元/吨暴涨到约 60 万/吨，2023–2024 又崩到 10 万以下**——这种数量级的价格摆动，使裸持有本指数历史上经历过极深的回撤。这条决定：仓位纪律（快砍、压回撤、降波动）的优先级，高于追逐任何择时信号。
- **锂源三分天下、成本曲线分化是核心壁垒**：盐湖（盐湖股份、藏格）、锂辉石（天齐、赣锋的澳矿）、云母（宜春一带）三种锂源的开采成本、扩产周期、品位完全不同——盐湖成本最低、最能穿越周期；高成本云母 / 外采辉石矿在锂价底部先停产。看龙头能不能穿越周期，看的是它在**成本曲线**的哪一档，不是 PE。
- **钴有独立供给逻辑**：钴价由**刚果金（DRC）供给 + 消费电子 + 三元正极路线**驱动，与锂不完全同步——三元 / 磷酸铁锂的路线之争直接改变钴需求弹性（磷酸铁锂上量 = 钴需求被挤压）。华友钴业、洛阳钼业（铜钴伴生）是钴权重主力。
- **钨钼是另一条相对独立的支线**：钨（军工 / 硬质合金 / 光伏钨丝）、钼（不锈钢 / 合金钢 / 军工）有配额 + 军工 + 高端制造的行政 / 国防色彩，周期与锂钴不同步——厦门钨业、中钨高新、洛阳钼业（钼）承载这一翼。指数大涨大跌主要由锂钴主导，但钨钼在锂钴熊市里偶尔能形成局部对冲。

驱动排序：**锂 / 钴等能源金属价格趋势 + 新能源需求 > 仓位择时（压回撤为主）> 子板块结构（锂源 / 钴 / 钨钼穿透）> 选品**；**能源金属周期 + 价格 + 库存 + 子板块结构**思维 > 长期持有。研究时问三件事：

1. 锂 / 钴价在周期哪个阶段（暴涨过热 / 崩跌出清 / 底部企稳 / 修复扩张）？→ 决定能不能重仓、是不是底部。
2. 趋势对不对、波动大不大？→ 决定现在是加是减、压几档仓。
3. 新能源需求（车 + 储能）、三元 / 磷铁路线、供给（盐湖 / 辉石 / 云母新增产能）、配额政策变没变？→ 决定是不是该撤。

## 一、估值视角（能源金属周期 PE 反着读，主用 PB + 锂钴价位置）

对 CS稀金属这种**极致周期 + 锂钴价格驱动**的指数，**禁止把 PE 当价值锚做均值回归择时**——PE 在能源金属周期里是**反向指标**，且因锂钴价摆动数量级极大，失真尤其夸张。具体陷阱：

- **PE 陷阱（最关键认知）**：周期顶部（碳酸锂飞到 60 万/吨）→ 盐湖 / 锂矿企盈利顶 → PE 看起来**最低**；周期底部（锂价崩到 10 万以下、高成本矿亏损）→ 盈利坍塌甚至为负 → PE 冲到**最高甚至无意义**。**低 PE 是周期顶的卖出信号，高 PE 才可能是周期底的买入信号——和成长股完全相反。**
- **主用 PB，但同样不做扳机**：矿企 / 盐湖净资产相对盈利稳，PB 比 PE 稳得多，历史 PB 分位（截至当日 PIT）可做"是否进入泡沫区 / 深熊区"的**定性预警**——周期底部龙头 PB 常打到低位甚至破净，顶部 PB 高位普遍。但 PB 对锂钴这种暴涨暴跌品种**滞后明显**，只做定性预警，不做"低 PB 抄底 / 高 PB 减仓"的机械操作。
- **真正的标尺是锂 / 钴价历史分位 + 成本曲线位置**：锂价（碳酸锂 / 氢氧化锂）、钴价在历史 5 / 10 年分位的位置（截至当日 PIT）+ 当前价格相对**主要锂源现金成本线**（盐湖最低、外采辉石 / 云母最高）的位置，比 PE / PB 更说明问题。锂价跌穿高成本矿现金成本 = 周期下行接近供给出清区，但**别先抄底**（见下）。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量 + 锂钴价框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。极端读数仍是要认真对待的定性信号。

估值在这里只做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：锂 / 钴价创历史新高 + PB 顶部分位 + 全民进场（"锂矿茅"非理性繁荣、卖方高呼"锂电超级周期 / 资源为王"、盐湖 / 锂矿 IPO 与定增爆发）→ 配合趋势框架减仓。**特别警惕周期顶部"低 PE + 高分红"组合，那常是锂钴最后一波。**
- **周期反转预警（底）**：出现 **锂 / 钴价跌穿高成本矿现金成本 + 高成本产能（云母 / 外采辉石）实际停减产 + 盐湖龙头喊话减产保价 + 锂盐库存见底回升 + 下游正极厂补库**等周期反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**锂钴价 / 库存 / 供给证据**，不是低 PE 或低 PB 分位（分位对能源金属周期是**滞后**的）。

**值不值得重仓看成本曲线穿越能力**：盐湖低成本龙头在锂价腰斩时仍能盈亏平衡甚至盈利、高成本云母 / 外采辉石先停产 → 低成本龙头穿越周期能力 = 重仓信心；同时关注锂资源储量 / 自给率（盐湖股份、赣锋 / 天齐的海外锂矿、北方稀土的配额壁垒）。成本曲线管"值不值得在趋势里重仓"，不用来抄底或择时。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**CS稀金属还要额外把锂 / 钴价格趋势纳入**——板块趋势与商品趋势背离时，以锂钴趋势为主参考。

- **方向锚（双层）**：
  - 板块层：指数 vs 200 日均线（过去 200 个交易日收盘价滚动均线，截至当日 PIT；信号 T+1 执行）
  - 商品层：核心商品（碳酸锂 / 钴）的 200 日均线 + 价格分位（截至当日 PIT）
  - **两层共振时信号最强；只有板块涨而锂钴价平 → 题材脉冲（如固态电池 / 钠电池 / 锂矿涨价传闻），须谨慎。**
- **量能确认（板块代理）**：指数取不到量 → 用 `sector_factor` 成交集中度 / `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破。
- **波动率（板块代理，且要打折读）**：指数无高 / 低算不出真 ATR → 用**过去 N 日收盘价滚动波动率** + `sector_factor_detail` 的 **MA200 乖离率**代理；**注意：用 close 代理本指数的波动会系统性偏低估**（缺日内振幅），实际波动比读数更凶，宁可把降仓阈值收得更紧。波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：锂矿涨价 / 减产消息、配额政策、刚果金供给扰动、固态 / 钠电池路线传闻常造成跳空，要分清这是**逻辑级利好（供给真实收缩 / 锂钴价中枢上移 / 需求实质放量）**还是**情绪脉冲（题材爆炒）**——前者可顺势，后者易回补缺口。
- **子翼分化**：锂、钴、稀土、钨钼四翼驱动各异——锂砸盘时钨钼 / 稀土可能稳，不要把"指数跌"当成全员跌；同理指数涨可能只是某一翼脉冲。穿透看是哪一翼在主导。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

### 可用的择时指标（定性）：本指数无可靠择时指标、仓位纪律优先

**核心结论（诚实，不可美化）**：CS稀金属**没有可靠稳健的择时指标**——趋势类、回撤类、动量类因子在本指数上**时间稳定性都不够、不够稳健**，找不到能稳定赚 alpha 的择时信号。而且本指数只有收盘价、没有日内高 / 低，吊灯（chandelier）这类用 ATR 的因子只能用收盘价代理，会**系统性偏乐观**（低估真实波动 → 止损线偏宽 → 看着比实盘漂亮），**可靠性还要再打一档折扣**。这一点正是"什么指标能用"的答案：**本指数仓位纪律（快砍、压回撤、降波动）优先于追逐任何择时信号。**

**哪些指标可以怎么用**：

- **chand_22（吊灯止损）/ mom_20（20 日动量）/ donch120_trail（唐奇安 + 拖尾止损）**：这几类只能当"现在该不该把仓位往下压"的**右侧第二意见 + 降回撤参考**，**权重低于"锂钴价 + 新能源需求 + 证伪"的基本面主维度**。它们时间稳定性不足、不够稳健，**不能当独立进场扳机、不能重仓**；其价值主要在**降低回撤**，不是提高收益。
- **吊灯 / 拖尾止损这类工具**：因本指数只有收盘价、ATR 用收盘代理偏乐观，用时要**把回撤 / 波动读数再往坏处打一档**，止损线宁可收紧。

**怎么用（判断，不机械执行）**：

- 择时信号在本指数上只调节仓位档位、不创造方向；任何因子与基本面冲突时，以"锂钴价 + 新能源需求 + 供给 / 库存"的基本面判断为准。
- 结论一句话：**本指数仓位纪律（快砍、压回撤、降波动）优先于追逐任何择时信号；择时价值主要在降回撤，不在提收益。**

## 三、景气度视角（能源金属专属：锂钴价 + 库存 + 新能源需求为母变量）

CS稀金属的景气有**清晰的产业链传导链条**，母变量是**新能源需求 + 锂钴价**（不是宏观 PMI / 基建那套）。按性质分四类，别用滞后指标做择时（具体取数见上「取数」节）：

- **领先（母变量）**：
  - **锂 / 钴价格 + 库存**——碳酸锂 / 氢氧化锂、电钴 / 硫酸钴的现货 + 期货价 + 冶炼厂 / 社会库存，**库存见底回升常领先价格 1–3 个月**。
  - **下游需求**——新能源车销量（国内 + 出口）、储能装机、三元 / 磷酸铁锂装机占比（路线之争直接改变钴 / 镍需求）。
  - **供给端**——盐湖 / 锂辉石 / 云母三种锂源的新增产能投放节奏与停减产、刚果金钴供给、稀土 / 钨钼配额。
  - 三档同向时信号最强（新能源需求升 + 供给紧 / 出清 + 库存降 = 锂钴价主升）。
- **滞后（确认而非择时）**：矿企 / 盐湖营收 / 净利 YoY + 一致预期修正，跟随锂钴价 1–2 季度反映，**不当择时锚**——等盈利确认转向就晚了，且锂钴盈利杠杆极大、滞后期里数字最唬人。
- **结构 / 上限**：锂源成本曲线、盐湖 / 锂矿资源储量与自给率、稀土 / 钨配额——决定龙头穿越周期的能力与重仓信心，不决定主趋势开关。
- **事件驱动**：锂矿涨价联盟 / 减产、配额公告、刚果金政策、固态 / 钠电池路线突破、新能源补贴退坡 / 储能强制配套——跳空催化，事件级单独评估。

- **锂 / 钴价是母变量**：领先矿企盈利约 1–2 个季度。**看锂钴价趋势 + 库存方向，不看矿企当期营收**（营收是滞后确认，且锂钴盈利杠杆让滞后期数字极端失真）。
- **库存是最高频的领先指标**：锂盐冶炼厂 / 社会库存、钴库存，**库存见底回升 + 下游正极厂补库**是早期反转信号；但要区分"显性库存（冶炼厂 / 贸易商）"与"隐性囤货"——显性降但隐性囤货释放，价格未必走强。
- **下游需求是真锚**：锂看**新能源车 + 储能**；钴看**三元正极占比 + 消费电子**（磷酸铁锂上量挤压钴需求）；钨看军工 / 硬质合金 / 光伏钨丝；钼看军工 / 合金钢。需求拐点早于价格——**新能源车销量与储能装机的边际变化，比 PMI 重要得多。**
- **看的是趋势一致性**：锂钴价 + 库存 + 新能源需求 + 供给四个领先维度同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**（盈利会跟上）。

## 四、宏观 / 需求驱动视角（能源金属专属：新能源需求为母变量，美元次之）

本指数的宏观驱动**专属于新能源需求**——**驱动锂钴的不是美元 + 全球 PMI，而是新能源需求周期**：

- **新能源需求 = 第一母变量**：新能源车销量（国内渗透率 + 出口 + 欧美政策）、储能装机（强制配储 / 大储经济性）、三元 / 磷酸铁锂路线占比——这些直接决定锂、钴、镍的需求弹性。看到"新能源车销量超预期 / 储能装机放量" → 对锂钴普遍利好；"补贴退坡 / 车企价格战压成本 / 磷铁挤压三元" → 对锂、特别是钴利空。
- **三元 / 磷酸铁锂路线之争 = 钴 / 镍的命门**：磷酸铁锂（不含钴镍）份额上升会**结构性压制钴需求**；高镍三元回潮则利好镍 / 钴。这是本指数内部"锂强钴弱"或反之分化的根源，必须穿透到路线占比看。
- **锂源供给周期 = 中期价格中枢**：盐湖（低成本、扩产慢）、锂辉石（澳矿 / 非洲矿，扩产快但成本中高）、云母（国内、成本高、环保受限）三种锂源的新增产能投放节奏，决定锂价中期是过剩还是紧平衡。**集中投放 = 过剩压价（如 2023–2024 多个辉石 / 盐湖项目集中达产压垮锂价）。**
- **美元 / 实际利率 = 次要变量**：锂钴是美元计价，美元强弱有边际影响，但**远不如新能源需求重要**——别把美元 / 全球 PMI 当本指数的母变量去做主判断。美元只在系统性风险时通过风险偏好间接作用。
- **稀土 / 钨钼的行政 + 军工独立周期**：稀土配额 / 收储、钨配额、军工订单、出口管制（稀土 / 钨对外管制）——这一翼是**行政定价 + 国防需求**，与锂钴的市场化周期完全不同步，可能在锂钴熊市里形成局部对冲。
- **政策双刃**：新能源补贴退坡（压锂钴）vs 储能强制配套 / 以旧换新（撑锂钴）；锂矿涨价联盟 / 收储（抬价）vs 保供稳价（压价）；稀土 / 钨出口管制（抬价 + 资源溢价）。**同一条政策对锂钴和稀土钨钼方向可能相反，别只看一面。**

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。**CS稀金属波动极大、裸持有历史回撤极深，纪律绝不可省**：

- **锂 / 钴价兑现 / 转向**：锂钴价创新高 + 库存高位 + 新能源需求边际转弱（销量增速放缓 / 磷铁挤压三元）→ 主动兑现得更积极（盈利顶滞后价格顶 1–2 季，等盈利就晚了）；锂价跌穿高成本矿现金成本 → 周期下行可能接近见底（但**别先抄底，等高成本产能真停减产 + 库存企稳**）。
- **波动放大就降仓（本指数尤其）**：锂钴价单日大幅跳变、指数振幅骤增时降仓——且因 close 代理低估真实波动，要把降仓阈值收得比一般板块更紧。**这是本指数压回撤的主力动作，优先级高于任何择时因子。**
- **子翼分化预警**：锂钴与稀土钨钼共振大涨（罕见）= 警惕全板块资源题材过热；锂崩盘时只盯锂，别被稀土 / 钨的局部强势误导成"板块还行"。
- **事件前减敞口**：新能源补贴 / 配额政策窗口、车企价格战节点、刚果金 / 锂矿谈判、固态 / 钠电池技术发布会前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。
- **硬止损（高波动品种不可省）**：本指数波动极凶，止损纪律是生命线。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑（锂钴价上行 / 新能源需求放量 / 供给出清）大概率已破。**别拿"成本曲线穿越能力"当死扛的借口**——那只决定值不值得在趋势里重仓，不是趋势已破后接飞刀的理由。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **锂 / 钴价证伪（下行，最关键）**：碳酸锂 / 钴价跌破主要均线 + 库存持续累积 + 现货升水转贴水——价格逻辑直接被推翻，板块行情失去燃料。
- **需求证伪（下行）**：新能源车销量增速持续放缓 / 出口受阻；储能装机不及预期；三元被磷酸铁锂进一步挤压（钴需求结构性下台阶）。
- **供给证伪（下行）**：盐湖 / 锂辉石 / 云母新增产能集中释放压垮锂价（如多个项目同期达产）；刚果金钴供给放量；高成本产能未如预期停减产（出清证伪）。
- **路线证伪（下行，钴专属）**：磷酸铁锂份额加速上升、钠电池 / 固态电池路线削弱锂钴需求预期——结构性需求逻辑作废。
- **趋势证伪（下行）**：指数跌破 200 日均线且 1 月未收回，但应根据当时市场环境修正指标。
- **估值证伪（下行，反向）**：锂钴价新高 + PE 看似"最低" + 全民进场（"锂矿茅"爆炒）+ 卖方高呼"锂电超级周期 / 资源为王"——周期顶部最危险信号组合（PE 陷阱叠加情绪过热）。
- **看空被证伪（上行 veto-watch）**：锂钴价跌穿高成本矿现金成本后高成本产能（云母 / 外采辉石）实际停减产 / 矿山关停；锂盐库存见底回升 + 下游正极厂补库；锂矿涨价联盟 / 收储落地；新能源车销量 / 储能装机超预期放量；稀土 / 钨出口管制抬升资源溢价——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- CS稀金属是**极致周期 + 双重杠杆 + 锂钴价格驱动**的高波动赛道，**裸持有历史回撤极深**，而且**本指数没有可靠稳健的择时指标**——所以这个指数上，单指数策略的价值**几乎全部来自压低最大回撤，不是抬高收益**。你的活儿是锂钴价反转 / 新能源需求转弱 / 波动失控时**少亏、快撤**。仓位纪律（快砍、压回撤、降波动）的优先级，高于追逐任何择时信号。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- 但该在场时别缺席：趋势明确向上（锂钴价上行 + 新能源需求放量 + 库存去化 + 供给出清 + 价格多头）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（那可能是周期顶）。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。本指数极深的裸持有回撤就是"为什么活着第一"的活教材。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且锂 / 钴价同向运动**。
  - **震荡市**：200 日均线走平 + 价格在均线 ±15–20%（锂钴波动极大，箱体很宽）内来回 + 箱体反复假突破 + **锂钴价也在区间内震荡**。
  - **过渡待定**：信号不清、板块趋势与锂钴趋势背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（锂钴价转跌 / 趋势破位 / 波动失控）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（锂矿减产 / 配额 / 路线突破）即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：
- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（锂矿涨价 / 减产消息最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日 + 锂钴价同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。本指数假突破极多（题材脉冲密），分类层尤其要稳。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向，**叠加锂 / 钴价格趋势**。两层共振向上→在场吃 Beta；任一转下（特别是锂钴价转下）→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。**但记住：动量 / 趋势这类因子在本指数上时间稳定性不够、不够稳健（且只有收盘价、close 代理偏乐观），它降回撤的作用大于提收益的作用，别把它当能稳定赚 alpha 的依据去重仓。**
- **波动率目标（体感纪律，本指数尤其重）**：CS稀金属本就极高波动，越平静越敢拿，振幅骤增 / 大涨大跌 / 锂钴价单日跳变时降仓，等波动收敛、方向重新清晰再加回。**因 close 代理低估真实波动，降仓阈值要收得比一般板块更紧**；波动放大本身就是降仓信号。
- **事件叠加**：新能源补贴 / 配额政策、车企价格战、锂矿减产 / 涨价联盟、刚果金 / 路线发布窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（供给真实出清 / 需求确认放量）确认后再顺势加。
- 叠加：**方向（动量 + 锂钴价）决定在不在场，波动决定在场时待在哪一档。** 本指数上"波动决定档位"比"动量决定方向"更值钱。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±15–20%（锂钴箱体很宽）+ 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：本指数箱体随时可能因一条锂矿减产 / 配额 / 补贴 / 路线消息向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：锂钴脉冲多、题材事件易反复，假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错，本指数尤其。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如锂矿大规模减产 / 补贴落地 / 路线突破），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 锂钴价转向 / 趋势转空 / 波动失控 → 一把清到位，可以直接到 0**：本指数周期下行往往加速（盈利杠杆向下、锂钴价腰斩级别），等"确认"就晚了，宁可错杀。**这条在历史回撤极深的指数上不是口号，是生死线。**
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。本指数的高赔率组合是 **锂钴价上行 + 新能源需求放量 + 库存去化 + 高成本产能出清 + 价格放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）**——在低赔率、信号不齐时，宁可错过，不可做错；但高赔率、共振齐时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接——锂钴下跌往往是趋势级（产能集中投放压价），接飞刀代价极大。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破（含锂钴价趋势）** + **从持仓高点回撤了多少**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且本指数主升浪回调动辄 30%+（锂钴价波动 + 盈利杠杆，极凶），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降——注意本指数 close 代理的吊灯偏乐观，止损线宁可收紧一档）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。本指数单边跌起来极易摸到深水区（锂钴价腰斩 + 盈利杠杆向下），这条尤其**致命**。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关，也是本指数（无可靠稳健的择时指标）压回撤的**主力手段**。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 本指数波动大、锂矿 / 新能源新闻天天有诱惑，更要克制别被脉冲诱发高频折腾——尤其因为没有可靠稳健的择时指标，频繁折腾只会把摩擦成本叠加到本就难做的择时上。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、锂 / 钴价格、新能源需求（车 + 储能）、库存 + 供给出清、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 周期顶 PE 最低（PE 陷阱） | 能源金属股**永远看 PB + 锂钴价位置**，不看 PE；只有盈利稳态品种才能用 PE |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 锂钴价 + 需求配合看 B，趋势破位 / 锂钴价转跌时极端读数当定性预警 |
| 量增（销量创新高）就该买 | 量增价跌利崩 | 看**供给出清没有 + 锂钴价方向**：需求增但产能集中投放压价（2023–24 式）看 B，需求增 + 供给紧 + 价格企稳看 A |
| 锂矿减产 / 涨价联盟是利好（供给收缩） | 减产托价托不住、需求才是命门 | 看**需求端配不配合**：减产 + 需求企稳看 A（涨）；需求仍弱、纯靠减产硬托看 B（撑不久） |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**锂钴价 + 库存方向**：领先端仍向下看 A，领先端见底回升（盈利滞后）看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但锂钴价 / 需求逻辑没坏看 A，锂钴单边下跌途中看 B |
| 强者恒强 | 物极必反 | 趋势中段 + 库存去化 + 需求加速看 A，极端情绪 + 锂钴价创新高 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 锂钴价见顶 / 库存累积 / 量价背离看 B |
| 三元回潮利好钴 | 磷酸铁锂挤压钴 | 看**装机路线占比方向**：高镍三元份额回升看前者，磷铁份额加速上升看后者（钴需求结构性下台阶） |
| 因子（吊灯 / 动量）说在场就重仓 | 因子不够稳健、靠它降回撤别靠它赚 alpha | 本指数无可靠稳健的择时指标，因子只当右侧第二意见 + 降回撤参考，权重低于锂钴价 + 需求基本面；与基本面冲突以基本面为准 |

> **核心一句**：CS稀金属—用 **锂 / 钴价格 + 新能源需求（车 + 储能）+ 库存 + 供给出清** 判景气、用 **PB + 成本曲线**（盐湖 / 辉石 / 云母三档）判空间（**永远别用 PE**）、用**趋势 / 动量**择时（**但本指数无可靠稳健的择时指标，择时只当第二意见**）、用**大开大合 + 压最大回撤**做仓位；吃该吃的 Beta、躲锂钴价转向与产能投放误伤、空仓不愧疚、按优势大小下注、进出算成本——在这个裸持有回撤极深的指数上，**靠仓位纪律压回撤把夏普做上去，比追择时信号重要得多**。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新锂源 / 新电池路线 / 新配额工具 / 新供需结构）。
- **定期 + 事件驱动**：一轮锂钴价周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PB 分位、回撤档、均线 / 波动率窗口、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各翼（锂 / 钴 / 稀土 / 钨钼）的差异化打法。**若后续在本指数上确实验证出时间稳定、可靠稳健的择时指标，可把它从"第二意见"升格为右侧主信号——但升格前必须有反复验证证据，不得凭一段行情把不稳健的因子当可靠信号用。**
- **不轻易动（信仰与原则层）**：唯一信仰（压回撤优先于追收益、锂钴价 + 需求确认才重仓、转空降仓）、风险优先于收益、不接飞刀、对本金保守对 β 放纵，以及**"本指数无可靠稳健的择时指标、择时因子只当降回撤工具、仓位纪律优先于择时"这一结论**。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动，避免推倒重来归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；锂钴价周期切换、电池技术路线颠覆、配额 / 补贴政策框架重置是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
