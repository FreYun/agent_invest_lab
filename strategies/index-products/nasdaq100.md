# 纳斯达克100指数投资框架（执行卡 v2.0）

**这是执行手册，不是研究视角。** 每天按 §3 的三步执行；规则没触发就输出"无操作"。本文档的规则穷尽了所有允许的仓位操作——任何文档之外的理由（估值、情绪、新闻、利率水平、账户盈亏）都不构成调仓依据。

> 纳指的精髓：长期向上、动量极强、V 型反弹凶——**踏空比回撤贵**。所以：默认 高仓位（根据用户风偏可上下浮动） 仓位拿住；急跌（距一年高点 −10%）是加仓礼物、一次加到 100%；只有"深熊保险丝"三条件全亮、且双杀证据确凿（2022 那种折现率 + 盈利慢熊）才降到 50%；价格收复 MA200 后 5 日内无条件回到 90%。其余一切时间：什么都不做。

## 0. 这套规则的来历（为什么要服从）

- **上一版方法论的回测教训**（bot11，2025-01 → 2026-06）：+7.5%，同期 513100 买入持有 +37.2%。败因复盘：4 月关税急跌中底部清仓 → 空仓 5 个月踏空 V 型反弹 → 反弹 +18% 后才追回，且全程从未满仓。根因：旧版给了七个研究视角、十几个可以减仓的理由，而加仓需要三项确认——结构性偏防守，且只写了怎么撤、没写怎么回来。
- **本执行卡经 513100 真实净值 12 年模拟验证**（2014–2026 三窗口，含 2022 熊市，脚本见 §6）：年化 ~+18%、最大回撤 −26%、卡玛 0.70（买入持有 0.65）；2021–2023 窗口回撤 −30% → −24%。**即使 §2 判别每次都错（每次保险丝亮都砍），卡玛仍有 0.67，不输买入持有**——服从规则的下限就是市场本身。

## 1. 仓位状态机（唯一的仓位规则）

仓位只有三档：**100% / 90% / 50%**。状态只有两个（常态 / 防守）：

```
            ┌── 距252日高回撤 ≥10%（仍处常态）──→ 满仓 100%
常态 90% ───┤                                    （创252日新高 → 回 90%）
            └── 保险丝三条全亮 + §2 判"双杀" ──→ 防守 50%
防守 50% ──── 收盘 > MA200 连续 5 个交易日 ──→ 无条件回 90%
```

| 规则 | 触发条件（全部基于 513100 净值序列） | 动作 |
|---|---|---|
| 急跌加仓 | 最新净值距 252 日最高 ≤ −10%，且当前为常态（保险丝没全亮，或亮了但 §2 判为事件型恐慌） | 加到 100%，一次到位 |
| 弹药重置 | 净值创 252 日新高 | 回到 90% |
| 深熊保险丝 | ① 收盘 < MA200 连续 ≥10 个交易日；② 今日 MA200 < 20 个交易日前的 MA200（均线本身转头向下）；③ 距 252 日高回撤 ≥18% —— 三条**同时**成立 | 进入 §2 判别（不是直接卖） |
| regime 修复 | 收盘 > MA200 连续 5 个交易日 | **无条件**回 90%，确认次日起尽快执行（≤5 个交易日） |

- 防守状态下急跌加仓规则停用；修复后重新启用。
- **历史校准**（513100 净值口径，已逐日验证）：保险丝 12 年里只亮过两轮——2022（多次）和 2025-04-21；2018Q4（−22.3%）与 2020-03 疫情（−27.9%）都因 MA200 斜率未转向而**机械不亮**，规则自动把 V 型崩盘当加仓窗口处理。

## 2. 唯一的判断点：双杀判别（仅当保险丝三条全亮）

只问一个问题：**这是事件型恐慌，还是利率 / 盈利双杀？**

判"双杀"必须凑齐 **≥2 项硬证据**：
1. 联储处于紧缩周期（加息或缩表进行中，声明 / 点阵图无转向迹象）；
2. 美债 10Y 在最近 60 个交易日上行 >50bp（`bond_yield_curve` 看**变化量**，不是水平）；
3. Mag7 / 半导体的盈利**指引**实质下修（财报与指引文本，不是股价跌幅）。

- 证据不足 2 项 → **默认事件型恐慌 → 不砍仓**（维持当前档位，急跌加仓规则继续有效）。
- 判定双杀 → 降到 50%，停止急跌加仓，只等 §1 的 regime 修复。
- 历史校准：2022 = 双杀（三项证据全有，−33% 慢熊，该砍）；2025-04 = 事件型（关税冲击、联储非紧缩、无盈利下修，不该砍）。**§2 存在的全部意义就是放过 2025-04、砍掉 2022。**

## 3. 每日三步（照抄执行）

1. **取数**：`fund_nav(513100, 252个交易日)` → 算 4 个数：MA200、20 日前的 MA200、252 日最高净值、当前回撤 =（最新净值 ÷ 252 日高 − 1）。
2. **查表**：对照 §1 四条规则，逐条判断今天是否触发状态切换。
3. **输出**（固定格式）：当前状态、4 个数、4 条规则的 ✓/✗、动作。**默认动作是"无操作"。**

无规则触发的日子：禁止调用 `research_search`、禁止读新闻、禁止重新论证持仓合理性。只有保险丝三条全亮的日子才允许做 §2 的研究取证。

## 4. 负面清单（违反任何一条 = 方法论执行失败）

1. **利率水平不是信号**："10Y 4.3% 偏高"这类表述禁止出现在调仓理由里；只有 60 日 +50bp 的**变化率**有意义，且仅在 §2 判别内有效。
2. 估值分位、情绪 z、拥挤度、集中度、关税 / 政治新闻、单日暴跌、财报临近、A 股市场情绪——**都不是纳指的仓位信号**。
3. **禁止账户级 PnL 止损**：账户回撤、浮亏浮盈不构成任何操作理由（风险已由状态机管理；上一版的"账户回撤破阈值机械降仓"正是底部清仓的元凶）。
4. **防守 ≠ 观望**：修复条件一到，5 日内无条件回 90%；"等更明朗""分批试探"都是违规（上一版空仓 5 个月就是这么来的）。
5. 状态机未触发时，禁止"主动减一点""先落袋一部分"。
6. 仓位档位只有 100 / 90 / 50，禁止发明 60%、75% 等中间档。

## 5. 执行备注（QDII）

- 场内 513100 出现高溢价（>2%）时改用 040046 场外申购，或等溢价收敛再动；T+2 确认与限购对本卡影响小——12 年仅约 75 次调仓（月均 ~0.5 次）。
- 净值是"纳指 + 人民币汇率"的复合敞口：不对冲、不作为择时理由，状态机直接在净值序列上消化。

## 6. 参数与重校（季度级，不进日决策）

`−10% / −18% / 10日确认 / 5日修复 / MA200 斜率看20日 / 90-100-50 档位`来自 2014–2026 三窗口模拟（bot11 回测窗口 / 2021–2023 熊市窗口 / 12 年全样本，脚本 `strategies/index-products/tools/nasdaq100_sim.py`）。改任何参数必须重跑模拟并记录三窗口卡玛对比；禁止在日决策中临时改参数。

## 附录：实盘增强视角（回测环境禁用）

以下维度在回测环境无数据源，**禁止用于回测决策**；实盘有数据时也只能作为 §2 判别的证据补充，**不得新增仓位规则**：

- **实际利率（10Y TIPS）**：纳指的折现率锚，系统性快速上行 = 双杀证据加强；
- **forward EPS 修正广度 / AI capex 周期**：盈利动量趋势性逆转 = 双杀证据加强；
- **VXN**：极端高位 + 保险丝未亮 = 急跌加仓的置信度加强（非必要条件）；
- **宽度 / 集中度**（Mag7 权重、等权 vs 市值权、SOX 背离）：结构脆弱性背景参考。
