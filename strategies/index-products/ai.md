# 人工智能指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据，**先判市场环境（〇节，永远的第一步）**，再逐视角审视，综合判断该不该动、动多少。

> 中证人工智能（930713）是 A 股**事件密度最高、主题轮动最剧烈**的品种之一，算力与应用两套估值逻辑同篮。玩法核心：**每天先判"算力行情、应用行情、还是普涨/普跌"，文本面给方向，趋势与回撤纪律给仓位**。

## 核心认知

930713.CSI（2015-07-31 起，约 10.8 年样本）选取为 AI 提供基础资源、技术与应用支持的公司：**基础层**（算力芯片/服务器/IDC：寒武纪、海光、中科曙光、浪潮信息类）、**技术层**（算法/平台：科大讯飞类）、**应用层**（办公/安防/金融 AI 应用：金山办公、海康威视类）。备选口径：创业板人工智能 970070.SZ（2018-12-28 起），见量化节。四个特性：

- **主题轮动是第一特性**："算力↔应用"轮动剧烈，与芯片、通信设备（光模块）、计算机/传媒共振。**每天第一个问题是"涨的是哪一半"**。
- **海外映射 + 事件密集**：英伟达财报、海内外大模型进展、算力出口管制、"人工智能+"政策——事件密度全市场数一数二，跳空常态。
- **叙事与兑现的剪刀差**：算力端有订单与业绩兑现；应用端长期靠叙事（渗透率/token 调用量/付费转化，多在研报口径）。**行情从"讲叙事"切到"要业绩"时，应用端杀得最狠**。
- **高 β 深回撤、价格因子弱**：OOS buyhold 最大回撤约 −47%、Calmar 仅 0.31；44 因子族扫描主口径无绿灯。

**估值特性**：PE 长期高位且失真（亏损成分 + 叙事定价），是两套逻辑的混合噪声；分位只做**极端预警**，绝不是择时扳机。

## 〇、先判市场环境（永远的第一步）

先答三问并**显式留痕**（写进复盘，明天继承）：

**1）全市场：欢迎高 β 主题成长吗？** AI 是风险偏好最尖的放大器。粗判**扩张/收缩/中性**；收缩期所有看多信号自动降一档。

**2）板块状态：趋势 / 震荡 / 过渡待定。** 均线单边排列 → 趋势骨架；长均线走平 + 假突破频出 → 防守骨架；都不像 → 过渡待定。**算力↔应用换挡期指数常呈震荡——内部换挡≠趋势终结**。状态有粘性：单日跳空不算切换证据。

**3）主驱动识别（本指数特色题，三分）：今天谁在定价？** 算力主导（催化在 capex/订单/管制/英伟达链 → A 链）／应用主导（催化在大模型/应用/政策叙事 → B 链，警惕剪刀差）／题材脉冲或无主线·普涨普跌（不入景气打分，按事件单独评估）。

**环境错判，所有信号都会读错**——没做完不进入任何加减仓决策。

## 一、估值视角（定性预警，绝非择时扳机）

- **禁止用 PE 分位低吸高抛**：贵不是减仓理由，便宜不是接飞刀理由。
- **顶部预警**：极端分位 + 全民进场（全民话题、主题基金爆量、研报集体转"远期空间"）→ 趋势尾段提示，交给止盈纪律。
- **底部**：极低分位 + 情绪冰点 + 预期下修多季 → 不抄底，**触发去文本找反转证据**，证据 + 趋势企稳再回补。
- **预期修正比分位承重**：`stock_alpha` 变动率分层读——算力端是硬信号；应用端预期本身就是叙事，只做密度参考。

## 二、趋势视角

- **方向锚**：收盘 vs MA120/MA200 + 斜率，20–60 日动量辅助，全部自算；突破需拥挤度同步抬升确认，**拥挤极端 + 价格加速 = 主升尾段**。
- **跳空甄别（日常课）**：**逻辑级**（管制落地/大额订单/资金级政策 → 可顺势）vs **情绪级**（映射美股波动/传闻 → 易回补），次日文本找增量，无增量当情绪脉冲；再问**打在算力还是应用**，错层利空别当全指数利空。

## 三、景气度视角（两链分层，主驱动链为主）

**A 链：算力链（capex/订单/出货）**：领先（母变量）= 智算 capex 表态、算力招标节奏、管制变化；同步 = 服务器订单/排产、国产芯片出货与生态；滞后（确认不择时）= 龙头季报，`stock_alpha` 变动率是最早的硬信号——等财报确认通常已走完半程。

**B 链：应用链（渗透/付费/标杆案例）**：领先 = 大模型版本与产品发布节奏、标杆案例落地；同步 = 渗透率/付费转化/调用量——研报口径，**方向可用、数字别当真**；滞后 = 财报，**且经常迟迟不来——这正是剪刀差的来源**。

**纪律**：主驱动链为主；领先定方向、滞后做确认、背离信领先；**应用链的"领先"多为叙事，承重低于算力链**。

## 四、事件/政策视角（与景气正交）

- **算力出口管制**：先拆层——限制先进算力进华 → 基础层国产替代强化、依赖海外算力的应用承压，**同一条新闻对两半方向可能相反**；次日拆层核实再定性。
- **"人工智能+"政策**：**提法级**（规划/表态）按脉冲对待；**资金级**（专项资金/招标落地）才进景气链、才改变景气判断。
- **大模型发布节奏**：海外发布 → 映射情绪 + 算力叙事；国内进展 → 应用端催化；"不及预期"是应用端高频利空，先按脉冲处理。重大事件窗口（英伟达财报夜等）不赌方向。

## 五、文本视角（zsxq+新闻+研报每日必读，**全框架最高权重**）

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail`（PIT 截断）+ `research_search` / `research_view`。**每个交易日必须执行，不许跳过**——其他视角可降级，这个不读完不许收工。**为什么权重最高**：①事件密度全市场最高之列；②母变量全部非结构化；③价格因子无绿灯，机械系统兜不了底。

**每日固定动作（3–5 次调用内，不许刷库）**：① `zsxq_topics` 扫纪要流并按三层标记——**机构密集调研哪一层就是主线信号**；② `zsxq_search` 1–2 个主线词（搜 0 条看 `query_used` 换词），正文 `zsxq_topic_detail` 最多 1–2 篇；③ `research_search`（search_type='all'）查管制/政策/订单/大模型增量，关键研报 `research_view` 读全文；④ 夜盘大波动专项：逻辑级还是情绪级、打在哪一半。

**怎么读（文本也是毒药）**：
- 读事实不抄结论：管制/招标/订单/capex 类事实 = 领先承重；研报观点/目标价 = 情绪代理，只做密度统计。
- **叙事温度计**："星辰大海/远期空间"类措辞密度，onset 期抬升是领先信号、成熟期一致沸腾是反向信号，属哪种回〇节定。
- **证据落链（硬性）**：当日 evidence 至少 1 条文本条目（topic_id 或 INFOCODE + 摘要）；没读到如实写"今日文本面无增量"，**无检索记录不许引用"听说/传言"**。
- **留痕（硬性）**：复盘固定一行 `文本增量: 无|低|中|高 —— <读到什么/有无改变判断>`。
- **权重边界**：给方向与证伪，不给仓位数字，不得突破回撤控仓与步长纪律。

## 六、证伪视角（对称化）

触发≠立刻清仓，但原论据失效，需新论据才能维持原仓位。

- **看多被证伪**：智算 capex 转冷/招标放缓；砍单传闻反复出现；龙头一致预期上修转下修（最早硬信号）；研报集体切向"兑现质疑"；管制砍断关键供给且无替代；风险偏好确认收缩。
- **看空被证伪**：capex/招标重新放量；国产芯片出货或生态突破；"人工智能+"资金级落地；爆款应用带来**真实付费证据**；管制落地但订单未受损；龙头下修结束 + 趋势企稳。

# 仓位管理方法论

## 唯一信仰：环境定骨架 + 文本定方向 + 纪律压回撤

深回撤（−47% 量级）品种，夏普提升几乎全靠压回撤：冲击来时少亏，主升浪在场吃足。仓位由信号（赔率）决定，**没有常态中枢仓位**——空仓满仓都合法，空仓不愧疚；该在场还空着 = 踏空，同样不及格。

## 一、骨架选择（承接〇-2）

- **趋势市 → 时序动量**：方向对就拿住让 β 跑，**主线单一且持续的趋势最可靠**；转空（破位 + 主线证伪）降仓乃至清空。
- **震荡市 → 防守、少动、守箱沿**：箱体中段不动手；**主线换挡期尤其不重仓赌哪边接棒**——双确认新主线才交还趋势骨架。过渡待定 → 维持原状态/轻仓。

## 二、操作纪律（步长/止盈/回撤/成本）

- **大开大合**：最小步长 20%，2–5% 微调无意义；**系统性风险/主线证伪/趋势转空确认 → 一把降到位，可以到 0**。
- **回补按赔率**：资金级政策/capex 上修 + 放量突破 + 文本扎实 + 拥挤未极端共振才大步；**只在趋势未坏的回调里加仓，绝不下跌趋势中摊薄**。
- **止盈止损**：只盯**趋势破没破**与**持仓高点回撤多少**；主升尾段（拥挤极端 + 估值预警 + 文本一致沸腾）吊灯线收紧；**保本线**：浮盈 ≥10% 后离场线抬到成本价。
- **回撤控仓（账户级总开关）**：净值从峰值明显回撤 → 机械降仓/暂停加仓，继续扩大 → 空仓复盘；事后闸门，不得反用。回撤数学不对称（−20% 需 +25%），在本品种上格外命。
- **成本**：7 日内赎回 1.5% 惩罚；每档**至少持有 3 个交易日**，只有趋势确认转空、回撤穿阈值、止盈触发允许跳档。

## 三、量化择时辅助（2026-06-11 全 44 因子族扫描）

> IS 样本起点–2021 / OOS 2022–2026.06，5bp 单边、T+1。**最重要的结论：主口径 930713 没有绿灯因子**——机械系统兜不了底，文本面与环境判断才是承重墙。**已注册进 `quant_factor` 工具**（2026-06-11）的只有 `ai_mom_20`（黄灯/探索性，**不承重**），doc 里固化"44 选 1 选择偏差 + CI 含 0 → 不单独触发任何加减仓"的硬纪律。备选口径 970070 的 `dl_bearonly_150` 验证于 970070、不外推到 930713，**未注册**。

### 主口径 930713：`mom_20`（🟡 黄灯·探索性第二意见，不承重）

- **是什么**：20 日收益 >0 → 满仓，否则空仓。OOS Calmar 0.61 vs buyhold 0.31、最大回撤 −30% vs −47%、CI[−0.02, 1.18]（**下界含 0**）、p+97%、wf 5/5、翻转 ≈20 次/年。
- **为什么只能黄灯**：44 族里挑出的**唯一**接近达标者——无同族佐证、CI 下界含 0，**44 选 1 的选择偏差**足以解释读数。定级探索性第二意见：**不承重、不单独触发任何加减仓**——同号是心理确认，反号回〇节与文本面找分歧来源。
- **盲区（公式可推）**：①震荡市 20 日收益在 0 附近反复变号，抽脸；②收盘计算、T+1 执行，**对跳空至少滞后一天**——事件密集品种的硬伤；③年均 ≈20 次翻转与 7 日赎回惩罚、3 日持有窗口天然冲突，机械执行成本上不可行。

### 备选口径 970070：`dl_bearonly_150`（✅ 绿灯，但只验证于 970070）

- **是什么**：默认满仓；close < MA150 且 MA150 的 20 日斜率向下 → 空仓。OOS Calmar 1.31 vs buyhold 0.82、CI[0.30, 1.80]、wf 5/5、翻转 14 次。
- **边界（硬性）**：**结论验证于 970070.SZ，外推到 930713 未验证**。交易 930713 时只能当背景参考，不得当执行信号。
- **盲区（公式可推）**：①**对均线上方的深回撤无防护**（高位横盘后快速下杀初段满仓挨打）；②离场与回归都等均线确认，V 型底必然迟到。

### 两口径差异与共同纪律

- 930713 全市场选样、三层齐备（含科创板算力芯片），10.8 年样本；970070 限创业板，样本短近一半、成分结构明显不同。**因子结论锚定具体口径，不跨口径搬运**。
- **不写也不执行"因子 = X 且 YY 时必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。黄灯因子永远不就地升级使用。

## 四、实战判断：成对格言

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 海外映射跌了要跟 | A 股 AI 有自己的主线 | 先分逻辑级（跟）还是情绪级，再看打在哪一半 |
| 叙事就是生产力 | 没业绩终究要还 | 看叙事期还是要业绩期（措辞密度 + 〇-1） |
| 主线切换要追新 | 轮动追涨两边挨打 | 有催化 + 双确认看 A；无催化日内轮动看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 主线没坏的系统性恐慌看 A；主线被证伪的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；拥挤 + 沸腾 + 估值预警叠加看 B |

> **核心一句**：人工智能指数——先判环境（风险偏好 + 板块状态 + 算力/应用/题材三分），用**文本面**给方向、**趋势与拥挤度**给择时、**回撤控仓**机械断后；价格因子只有黄灯不承重，超额全在把文本读完读对；主线换挡期不赌方向，空仓不愧疚。
