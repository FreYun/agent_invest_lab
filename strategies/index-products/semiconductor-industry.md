# 半导体产业指数投资框架（方法论）

这是研究视角，不是执行手册。**先判市场环境（〇节，永远第一步）**，再从各维度综合判断该不该动、动多少。

> 中证半导是 A 股**半导体全产业链综合敞口**：先定位全球库存周期位置，再判国产替代与 AI 算力谁在定价；文本面给方向，趋势与回撤纪律给仓位。

## 核心认知

中证半导体产业指数（931865.CSI，2016-12-30 起约 9.4 年样本）覆盖设计/制造/封测/设备/材料全产业链。四个特性：

- **全球半导体销售周期是母周期**：典型 3–4 年库存周期四阶段（三节），在哪一段是所有景气信号的总坐标系；最敏感现货温度计 = **存储价格**，全球映射 = 费城半导体指数。
- **两条结构线叠加**：国产替代/自主可控（制裁要反直觉读，四节）+ AI 算力需求（训练/推理芯片、HBM/先进封装，增量主线）。
- **高 β 深回撤 + 事件跳空频繁**：历史上回撤近五成的深熊反复发生；制裁/大基金/海外财报夜常跳空。不死扛，不追脉冲。
- **集中度高，必须穿透龙头**，各环节信号不同：设计看下游与库存、制造看稼动率与扩产、封测稼动率拐点是最早周期信号、设备材料看 capex（931743 主场）。

## 与相邻框架的分工（同一产业链，三个切面）

环境判断（周期定位、制裁读法）三者互通复用，弹性与信号侧重不同：

- **本文件（931865 中证半导）**：全产业链综合敞口，库存周期定位主轴 + 三线主驱动识别，周期判断主战场。
- **semiconductor.md（931743 设备材料）**："卖铲人"（capex 杠杆端）：晶圆厂 capex、订单、国产化率，弹性更极端。
- **chip.md（000685/980017）**：芯片设计制造口径，偏设计/制造端的下游需求与产品周期。

实操：表达"周期上行"用本指数，"capex 杠杆端"用 931743；同一条制裁新闻三者反应可能不同。

## 〇、先判市场环境（永远的第一步）

三问，显式留痕、明天直接继承：

**1）A 股现在欢迎高 β 科技成长吗？** 半导体是风险偏好放大器：`macro_50etf_vix`、市场情绪、大盘趋势粗判扩张/收缩/中性；收缩期所有看多信号降一档。

**2）板块状态三选一：趋势市 / 震荡市 / 过渡待定。** 趋势市 = MA60/MA120 单边排列；震荡市 = 长均线走平 + 箱体假突破反复；都不像 = 过渡待定。状态有粘性：默认继承昨日，单日跳空不算切换。

**3）主驱动识别：三条线谁在定价？** 库存周期主导（锚 = SIA、存储价格、稼动率；特征 = 全链普涨普跌、与全球联动高）/ 国产替代制裁主导（锚 = 制裁政策事件；特征 = 与海外背离）/ AI 需求主导（锚 = 算力链；特征 = 内部剧烈分化，算力强、消费电子弱）。

**环境错判，纪律也会用反**——〇节没做完，不允许进入加减仓决策。

## 一、估值视角（定性预警，绝非择时扳机）

- **禁止用 PE 分位低吸高抛**：盈利底 PE 天价（底部喊你跑）、盈利顶 PE 便宜。"趋势 > 估值"是单向过滤器——只否决"因为贵所以走/因为便宜所以接"。
- **底部辨识改看 PB/PS**（盈利坍塌时 B、S 比 E 稳）：极低分位 + 被动去库互证 → 不抄底，触发去文本找反转证据（三节）；证据出现且趋势企稳，快速回补。
- **极端泡沫预警**：估值极端 + 全民进场信号（主题基金爆量、研报切到"远期空间/国运"）→ 趋势尾段提示，配合止盈纪律。
- **盈利预期斜率比分位承重**：龙头一致预期转下修是最早的顶部领先信号之一，比价格破位早。

## 二、趋势视角

- **方向锚**：收盘价 vs MA120/MA200 + 斜率；20–60 日时序动量辅助。
- **量能/拥挤确认**：指数无量 → 板块拥挤度代理；突破时拥挤度同步抬升 = 有量，不跟 = 可疑假突破。拥挤极端 + 加速 = 主升尾段特征。
- **跳空甄别**：逻辑级（制裁加码、周期拐点、AI 订单 → 可顺势）vs 情绪级（映射海外波动、传闻 → 易回补）；次日文本面找增量，无增量当情绪脉冲。
- 震荡市转箱体思维；不问"能不能买"，问"信号强到什么程度"。

## 三、景气视角（库存周期为主轴）

**周期定位是慢变量，按月校准、写进记忆滚动继承**；四阶段：

- **主动去库**（砍单、存储价跌、SIA 下行）→ 防守。
- **被动去库**（存储价止跌、稼动率见底、SIA 降幅收窄）→ 标记筑底观察（持久态），等趋势企稳回补。
- **主动补库**（存储价上行、稼动率回升、SIA 转正）→ 在场吃足。
- **被动补库**（量价仍升但终端走弱、库存再累积）→ 止盈收紧。

**信号分层**：最敏感 = 存储价格；领先~同步 = 稼动率（制造/封测）、SIA 拐点；同步 = 费城半导体映射、龙头订单/涨价（以上全 `[仅文本]`）；滞后 = 龙头财报与预期修正（`[结构化·龙头]`，确认不择时）。领先端定方向、滞后端做确认，背离时信领先端；**等财报确认通常已走完半程**。

**下游三分（不许一锅烩）**：消费电子（量最大、周期性最强）/ AI·服务器（增量主线，可与消费电子错位，结论写明哪个下游在好）/ 汽车·工业（稳态压舱石）。

## 四、国产替代/制裁/政策视角（与全球景气正交）

- **制裁反直觉读法（最承重）**：先分清打的是**全球景气**还是**国产份额**——利空被卡环节（设计被断供），却利好国产替代环节（设备/材料/转单）。全链敞口两种效应同时存在，净方向取决于哪条线在定价（〇-3）与被打环节权重；当日先按情绪脉冲，核实后再定性。
- **大基金/产业政策**：真金白银注入，事件级催化，跟落地节奏。**双刃**：制裁也可能卡国产厂自身供应链，与"利好转单"同时评估。**事件前减敞口**：制裁窗口、海外财报夜前后不赌方向。

## 五、文本视角（zsxq + 新闻 + 研报，**每日必读、最高优先级**）

> 工具：`zsxq_topics` / `zsxq_search` / `zsxq_topic_detail` + `research_search` / `research_view`。**每个交易日必须执行、不读完不许收工**。母变量（存储价、稼动率、SIA、制裁、AI 订单）全部只活在文本里，丢掉它 = 退化成纯价格量化。

**每日固定动作（3–5 次调用内）**：① `zsxq_topics`（count=20）扫当日纪要流，调研密度即信号；② `zsxq_search` 1–2 个主线词（'存储'/'稼动率'/'算力'；0 条看 `query_used` 换词），`zsxq_topic_detail` 最多 1–2 篇；③ `research_search`（search_type='all'）查周期/制裁/AI 增量；海外夜盘大波动专项检索分级（二节）。

**怎么读**：读事实不抄结论——涨价/稼动率/订单类事实领先承重，研报观点只做密度统计；一致看多在趋势成熟期是反向信号、onset 期是领先信号，回〇节定。**证据落链（硬性）**：当日复盘 evidence 至少 1 条文本条目（topic_id 或 INFOCODE + 摘要），没读到如实写"今日文本面无增量"。**留痕（硬性）**：每日一行 `文本增量: 无|低|中|高 —— <读到什么、是否改变判断>`。文本只给方向与证伪，不给仓位数字。

## 六、证伪视角（对称化）

触发 ≠ 立刻清仓，但需新论据才能维持原仓位。

- **看多被证伪（下行）**：存储价格涨势停滞转跌（最敏感）；稼动率回落→砍单→排产下修（逐级加重）；SIA 拐头/库存再累积；AI 链 capex 下修或订单递延；龙头预期转下修（最早硬信号）；制裁断供关键环节无替代。
- **看空被证伪（上行）**：存储价格止跌回升 + 稼动率见底；SIA 降幅收窄/转正；AI 需求外溢到成熟制程/封测；制裁落地订单未损或实质催化转单；盈利下修结束 + 趋势企稳（〇-2 确认级）。

# 仓位管理方法论

## 唯一信仰：周期定方向 + 环境定骨架 + 纪律压回撤

夏普几乎全靠压回撤。仓位完全由信号（赔率）决定，**没有常态中枢仓位**：空仓满仓都合法，空仓不愧疚；该在场时不在场 = 踏空，同样不及格。

- **骨架选择（承〇-2）**：趋势市 → 时序动量，方向对拿住让 β 跑、转空降仓乃至清空，不高抛低吸，振幅骤增即降仓；震荡市 → 少动守箱沿、轻仓不赌箱体，放量/逻辑级突破站稳数日交接回趋势；过渡待定 → 维持/轻仓。
- **不对称操作**：最小步长 20%。系统性风险/周期顶部/趋势转空 → 一把降到位可至 0。回补按赔率：被动去库证据链 + 放量突破 + 涨价订单 + 拥挤未极端共振 → 大步上；不扎实分 2–3 大步或放弃。只在浮盈/趋势未坏的回调里加仓，**绝不下跌趋势中摊薄**。
- **止盈止损**：只盯趋势破没破 + 高点回撤多少；主升尾段（拥挤极端+泡沫预警+一致看多）吊灯线收紧；浮盈 ≥ 10% 离场线抬至成本，浮盈不许变浮亏。
- **回撤控仓（账户级总开关）**：净值从峰值明显回撤 → 机械降仓/停加仓；扩大 → 空仓复盘。事后闸门**不得反着用**（不拿假想回撤反推事前天花板）。−20% 需 +25%、−33% 需 +50%。
- **成本意识**：7 日内赎回 1.5% 惩罚，避免 round-trip；每档至少持 3 个交易日，仅趋势转空/回撤穿阈/止盈触发可跳档。

## 量化择时辅助（已验证因子）

> 研究室离线全因子族扫描（长样本、含费率与 T+1）。当作**客观第二意见 + 机械纪律提醒**，不替代框架打分。**已注册进 `quant_factor` 工具**：主因子 `semi_industry_rsi_panic_re_entry`、辅因子 `semi_industry_mom_20`。donchian_60 经复核时间稳定性不足、降级为黄灯，未注册。

### `rsi_panic_re_entry` ✅绿灯（主）—— 恐慌离场、回常态回归
- **是什么**：默认满仓；RSI14<30 **且** close<MA200（恐慌+破位双确认）→ 空仓；RSI 回到 >50 → 满仓。验证为绿灯：相对裸持有压低最大回撤、改善收益回撤比，时间稳定性达标。"绝大多数时间在场、只躲恐慌尾部"的防守因子。
- **会漏什么（公式可推）**：① 缓跌阴跌 RSI 到不了 30，主动去库的阴跌段无防护；② 单日闪崩滞后；③ 只看价格，对周期拐点/制裁/财报雷零预警——断后不侦察。
- **怎么用**：= 0 而框架看多 → 先核验文本面漏了什么；= 1 且框架看多 → 同号确认；框架看空它还 = 1 → 不构成"再等等"的理由。

### `mom_20` ✅绿灯（辅）—— 时序动量
- **是什么**：20 日收益 >0 → 满仓，否则空仓。同样验证为绿灯；翻转偏频繁（约每月一两次），摩擦成本要记在心里。
- **会漏什么**：震荡市来回抽脸（动量系统数学性质）；同样看不到周期/制裁/财报。
- **怎么用**：与 rsi_panic 同向 = 双确认；打架多在下行初段或震荡，回〇-2 裁决——不写机械组合规则。

### `donchian_60` 🟡黄灯（降级，写明演变）
早期筛选曾标"近绿"；复核发现时间稳定性不足（只有部分时段有效）→ **降级黄灯参考**。记录演变即诚实纪律：**结论随复核更新，引用前确认最新定级。**

### 共同纪律
两个绿灯都是**防守/趋势工具，不是收益增强器**，侦察靠三、四、五节文本面。**不写不执行"因子 = X 且 YY 必须 ZZ"的未回测组合规则**；冲突本身是信号，核验来源再决策。

## 实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 制裁是利空快跑 | 制裁逼出国产替代 | 打全球景气或断供自身看 A；打国产份额且趋势未坏看 B |
| PE 便宜可以买 | 周期股 PE 骗人 | 永远先想 B；底部辨识用 PB/PS + 被动去库证据链 |
| 估值太贵该减 | 趋势向上无视估值 | 主动补库 + 盈利上修看 B；被动补库 + 拥挤极端当顶部预警 |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 周期逻辑没坏的恐慌看 A；主动去库中的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升 + 保本线就位看 A；被动补库 + 量价背离看 B |

> **核心一句**：中证半导——先判环境（风险偏好+板块状态+主驱动），**库存周期定位**给方向、**存储价/稼动率文本侦察**给领先性、**趋势/动量**给择时、**rsi_panic/mom_20 + 回撤控仓**断后；制裁先分清打的是谁，空仓不愧疚，压回撤把夏普做上去。
