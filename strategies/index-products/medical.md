# 中证医疗指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证医疗指数（399989.SZ）**——中证全指里业务涉及医疗器械、医疗服务、医疗信息化的 50 只证券，自由流通市值加权（带权重上限），每半年调样。

## 核心认知

中证医疗（399989）≈ **医疗器械（影像 / IVD / 监护 / 高值耗材）约四成 + 医疗服务（连锁眼科口腔体检 + CXO）约四成 + 医美等其余**。注意：中证行业分类把 CXO 归入"医疗服务"，所以本指数实际带着约两成 CXO 暴露——**它不是纯器械指数，也不含化药 / 生物药**。五个特性决定玩法：

- **院端政策直接定价**：器械与院内服务的收入由**医院招标采购**实现，而招标由政策驱动——集采（杀价）、医疗反腐（冻结招标）、DRG/DIP 支付改革（压采购意愿）、设备更新财政资金（放量）。**政策不是外生扰动，是这个指数的第一性变量。**
- **院端招标数据是少见的可量化领先指标**：医院设备招投标 / 中标金额有公开月度数据（领先器械公司报表收入约 1–2 个季度）——这是本指数相对其他医药口径**最硬的景气抓手**，每月必须跟。
- **深回撤体质，政策三连杀有过先例**：集采杀价 + 反腐冻结招标 + 高基数退潮叠加时，本指数走出过**七成量级**的最大回撤（高点到低点"双腰斩"）。裸持有长期收益靠不住——**择时与仓位纪律不是锦上添花，而是这个指数能不能要的前提**。
- **三块资产逻辑不同步**：器械看院端招标 + 集采 + 出海；院端服务（眼科 / 口腔 / 体检）看居民消费力与客单量（消费属性）；CXO 部分跟全球医药融资周期（与院端政策无关）。**必须拆开看主导块。**
- **成长股估值但估值锚会被政策重置**：器械服务有真成长（渗透率 / 国产替代 / 老龄化），PE 可用；但单次集采能把一个品类的盈利中枢一夜砍掉大半——**估值分位的"历史区间"在政策重置后不可比**，分位读数要打折用。

驱动排序：**院端政策与招标（集采 / 反腐 / 设备更新 / 招标数据）> 子板块景气（消费医疗客流 / CXO 融资周期 / 器械出海）> 趋势 / 资金 > 估值分位**。研究时问三件事：

1. 院端政策环境现在是顺风还是逆风（招标在放量还是冻结、集采在扩围还是缓和）？→ 决定能不能重仓。
2. 趋势对不对、资金在不在？→ 决定现在是加是减。
3. 三块资产（器械 / 服务消费 / CXO）谁在主导边际变化、那条线的逻辑变没变？→ 决定是不是该撤。

## 一、估值视角（成长股 PE 可用，但政策能重置估值锚）

医疗器械与服务有真成长性（老龄化 + 渗透率 + 国产替代），PE 分位有参考意义——但两个本指数特有的陷阱：

- **政策重置陷阱**：集采能把一个品类的盈利中枢一夜砍掉大半、DRG 能系统性压低院端采购意愿——**政策重置前后的 PE 区间不可比**。"历史分位低"可能只是在用旧时代的估值区间量新时代的盈利逻辑。读分位时先问：**当前的盈利中枢假设和分位区间形成时一致吗？**
- **高分位 ≠ 顶**：本指数估值修复弹性大，盈利兑现期高分位可以持续——分位读数须配**招标 / 客流 / 订单的景气证据**一起读：高分位 + 招标放量 = 盈利兑现中，不构成减仓理由；高分位 + 招标失速 = 真危险。
- **在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走 / 不进"。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"。

估值做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）· froth 信号按"软 / 硬"分级，别一刀切**：
  - **软极值（常响 → 只停加仓）**：全民进场（医疗 / 器械主题新基金爆发、研报"非理性繁荣"、不看招标 / 客流齐涨）、拥挤度冲高（`sector_factor` 风险分 / `sector_factor_detail` 成交集中度分位）、`market_temperature` 综合温度过热、`macro_50etf_vix` 自满低位——当成"趋势可能见顶"的提示。**这些是逃顶辅助，不是 fade 扳机**：趋势健康（动量未转头、量价未背离、未破关键均线、招标未失速）时，单凭拥挤 / 过热极值**最多停止加仓，绝不据此减仓 / 清仓**；必须与趋势 / 动量走弱、招标增速见顶**同号共振**才配合趋势框架减仓。趋势里把软极值单独当卖出信号，会被政策顺风 + 招标放量的整段修复行情甩下车——这是本指数踏空的主因之一。
  - **硬极值（罕响 → 可削 froth 顶层一小片）**：唯独 **`sector_factor_detail` 的 MA200 乖离率冲到极端高位**（价格大幅脱离 200 日均线、进入本指数极少出现的过热区）这一档——**用绝对乖离率，不用乖离分位**（本指数深回撤体质，乖离分位在熊市底部因相对窗口失真会给假高读数、方向会反）。它极罕见，即便动量还没转头，也允许**把 core 之上的进攻 / froth 顶层减掉一小片**（**不清仓、不动 core 底仓**），乖离回落到常态档再补回。**但 core 始终由政策环境 + 招标景气 thesis 决定去留（thesis 坏了政策逆风 core 也可以到 0），绝不拿"老龄化 / 国产替代 / 渗透率逻辑还在"当扛 froth 顶层的理由**——基本面只为 core 背书，不为最尖那片 froth 背书。
  - **可靠性**：硬极值是**单一维度、且本指数可用历史不长**的预警，作"froth 顶部该削一刀"的提示用，**不是精确抓顶扳机**；与软极值同号、或与招标增速见顶 / 动量走弱共振时，才升级为更大的减仓动作。
- **政策出清底部观察（底）**：极低分位 + 集采 / 反腐靴子密集落地 + 招标边际回暖（可辅以 `market_temperature` 处于恐慌低位）→ 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。触发底部观察的是**政策出清 + 招标回暖证据**，不是低分位本身。

## 二、趋势视角

- **方向锚**：指数 vs 200 日均线 + 均线斜率；时序动量（20–60 日收益符号）辅助。**锚是动态的当日 MA200 / 斜率，不是记忆里某个固定点位**——把几个月前的旧高 / 旧低当成永久“硬支撑 / 硬阻力”来长期 gate 进出，是漂移不是纪律；每天用当日 MA200 重新读方向，别拿一个化石点位框死自己。
- **量能确认（板块代理）**：指数无量 → `sector_factor` 成交集中度 / 拥挤度代理；突破时拥挤度同步抬升 = 有量，不跟 = 可疑假突破。
- **波动率（板块代理）**：收盘价滚动波动率 + `sector_factor_detail` 的 MA200 乖离率代理；波动骤增本身是降仓信号。判读乖离**用绝对乖离率、不用乖离分位**（分位在深熊底部相对窗口失真、会给假高读数）；乖离冲极端高位归到估值节的 froth 硬极值处理。
- **事件跳空甄别**：集采结果 / 反腐通报 / 设备更新政策 / 海外法案（打 CXO 部分）常造成跳空，分清**逻辑级**（品类盈利中枢被真实改变 / 财政资金真落地）还是**情绪级**（联动情绪、程序性进展）。判别方法：第二天去研报里找有没有基本面增量；没有增量的跳空一律当情绪脉冲。
- **指数趋势与招标数据交叉验证**：指数涨而招标数据持续失速 = 估值修复型反弹（脆弱）；指数涨 + 招标放量 = 盈利驱动（扎实）。**两层共振时信号最强。**

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（医疗专属：院端招标为最硬母变量，三块分开跟）

### A 块：器械 / 院端（指数主轴）

- **领先（母变量）**：**月度招投标 / 中标金额**（领先报表收入约 1–2 个季度，本指数最可量化的景气抓手）；设备更新 / 财政专项资金（领先招标 2–4 个季度，政策 → 资金 → 招标 → 收入的传导链）。
- **同步**：龙头装机 / 入院进度（文本）、出海订单（第二曲线，独立于国内政策）。
- **滞后（确认不择时）**：报表收入 / 毛利率——招标放量等报表确认再动，行情已走半程。
- **结构 / 上限**：国产替代率（影像 / IVD / 电生理各品类不同段位）、集采后的品类盈利中枢——决定空间与重仓信心。

### B 块：消费医疗（眼科 / 医美 / 口腔 / 体检）

- 看**居民消费力 + 客单量 / 客流**：消费属性强，与院端政策弱相关、与社零 / 收入预期强相关。龙头经营数据（季报客流客单）是同步验证。
- 这条线给指数提供与政策周期不同步的第二引擎——消费疲软期它是拖累，消费回暖期它先起。

### C 块：CXO（约两成的"外来"暴露）

- 跟**全球生物医药融资周期**（融资领先订单、订单领先报表），与院端政策无关；海外法案是独立风险轴。
- 纪律：CXO 的涨跌别用"医疗政策"解释，反之亦然——**本指数最常见的误读就是把 CXO 波动当成院端政策信号**。

**纪律**：三块共用一个原则——**领先端（招标 / 客流 / 融资）定方向，滞后端（报表）做确认，背离时信领先端**。每天先回答"今天的边际变化属于哪一块"；A 块招标放量 + B 块消费回暖共振是本指数最强的赔率组合。

**招标"真空"≠"失速"，别混用**：取不到招标数据（时点稀疏 / 未到披露窗）是**缺失**，只降低置信度、最多软极值封顶不加，**绝不作为空仓或拒绝进场的独立理由**；只有招标**有数据且连续走弱（失速）**才是硬的看多证伪。趋势 + 资金在场、而只因"招标没确认"就空仓 = 踏空违规——空仓必须能把理由归到"趋势破位"或"招标失速 / 政策逆风"，归不出就是踏空。

### 可用的择时指标（定性）：本指数无可靠择时指标、仓位纪律优先

**核心结论（诚实，不可美化）**：研究室全因子族扫描下来，本指数**没有可靠稳健的择时因子**——趋势类、回撤类、动量类因子在本指数上时间稳定性都不够，找不到能稳定赚 alpha 的择时信号。且本指数只有收盘价、没有日内高 / 低，吊灯（chandelier）这类用 ATR 的因子只能用收盘代理，会**系统性偏乐观**，可靠性再打一档折扣。**而本指数裸持有长期收益也靠不住（深回撤 + 长熊有先例）——这意味着仓位纪律（快砍、压回撤、降波动）不是辅助，是这个指数能不能要的前提。**

**哪些指标可以怎么用**：

- **移动回撤止损（从滚动峰值回撤即减仓）/ mom_120（长周期动量）**：只能当"现在该不该把仓位往下压"的**右侧第二意见 + 降回撤参考**，权重低于"招标 / 政策 / 客流"的基本面主维度。**不能当独立进场扳机、不能重仓依赖。**
- 用任何回撤 / 波动类读数时，**把数值再往坏处打一档**（收盘代理低估真实波动），止损线宁可收紧。

**怎么用（判断，不机械执行）**：择时信号只调节仓位档位、不创造方向；与基本面冲突时，以"招标 / 政策 / 客流"的基本面判断为准。**结论一句话：仓位纪律优先于择时信号；择时价值主要在降回撤，不在提收益。**

## 四、政策视角（本指数的第一性变量）

- **集采（耗材 / IVD）**：杀价是单向的、但**预期杀在落地前**——发酵期是主要杀伤段，靴子落地常是利空出尽（历史上"第 N 批国采落地 + 影响淡去"是底部催化之一）。评估要点：**这次打的品类在指数里权重多大、降幅是出清式还是温和式、龙头是丢份额还是以价换量**。
- **医疗反腐**：风暴期 = 招标推广冻结 = 全板块收入滞后受压（有过单季深杀的先例）；常态化后边际钝化。跟踪强度变化（通报密度、牵涉层级），风暴升级是逻辑级利空、个案通报是情绪级。
- **设备更新 / 财政投入**：本指数独有的政策顺风轴——财政资金 → 招标放量的传导约 2–4 个季度，**资金落地进度（不是政策口号）才是承重墙**，按月用招标数据验证。
- **DRG / DIP 支付改革**：慢变量，系统性压院端采购意愿与服务定价——它决定的是行业 β 的长期天花板，不是当期方向。
- **海外法案（打 CXO 块）**：见生物医药口径同款纪律——程序性进展是情绪杀，条款落地 + 客户转单才是逻辑级。
- **事件前减敞口**：集采开标日、反腐敏感窗、重磅政策发布前后跳空风险大，事件不明朗时不赌方向。

## 五、风险管理视角

- **政策三连杀情景**：集采扩围 + 反腐升级 + 支付收紧同时出现时，本指数没有防御位——**识别到政策逆风共振就降仓，不要拿"估值已经便宜"扛**（七成量级回撤的先例就是这么走出来的）。
- **招标失速预警**：月度招标数据连续走弱 = 最硬的领先恶化信号，比报表早 1–2 个季度——这是本指数最值得机械执行的检查项（每月一扫）。
- **CXO 联动误伤**：约两成 CXO 暴露使本指数会被医药融资周期 / 海外法案砸出与院端基本面无关的下跌——分清误伤与逻辑伤，误伤是机会、逻辑伤是风险。
- **消费降级传导**：眼科 / 医美客单受居民消费力压制时，B 块从第二引擎变拖累。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界。**深回撤体质 + 无可靠择时因子，机械止损与回撤控仓是命脉。**

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称；触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 月度招标 / 中标金额连续失速（最硬的领先恶化信号）
  - 设备更新资金落地进度低于预期（政策口号未兑现为订单）
  - 集采扩围至指数权重品类、降幅出清式
  - 反腐从常态化重新升级为风暴式（招标再冻结）
  - 消费医疗客流 / 客单持续走弱
  - CXO 块：融资周期再转冷 / 海外客户实际转单
  - 趋势跌破 200 日均线且 1 月未收回、伴随资金持续撤离
- **看空被证伪（上行 veto-watch）**：
  - 招标数据连续回暖放量（设备更新资金真实落地）
  - 集采靴子落地且降幅温和 / 龙头以价换量守住份额（利空出尽）
  - 反腐进入常态化、招标恢复
  - 消费回暖带动客流客单回升
  - 盈利下修结束 + 趋势企稳放量（按「先识状态」确认级证据）

# 仓位管理方法论

## 唯一信仰：政策与招标定方向 + 纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 中证医疗是**政策定价 + 深回撤体质 + 无可靠择时因子**的品种，且裸持有长期收益靠不住——**仓位纪律是这个指数全部价值的前提**。你的活儿是政策逆风共振时少亏（招标失速、集采扩围、反腐升级来时快走），政策顺风 + 招标放量的修复段在场吃足。
- 仓位完全由信号（赔率）决定，**没有静态中枢、更没有静态天花板**——空仓、满仓都合法。但**默认态是“在场”（跟随本指数 β 的基线参与档），不是“空仓”**：环境没有明确 risk-off（政策逆风共振 / 招标失速 / 趋势破位）时，拿不准的正确动作是**待在基线仓**、不是退到现金。**空仓是需要主动理由才成立的动作，理由归不出上面三条硬 risk-off 就是踏空**（与三节「招标真空≠失速」同一条纪律）。“过渡待定”指的是仓位档位待定、人还在场，不是退回现金。**任何静态天花板都是违规**：尤其警惕把“账户最多承受 X% 回撤”反推成“仓位最多 Y%”。
- 该在场时别缺席：招标放量 + 政策出清 + 趋势多头时还空着 = 踏空，同样不及格。全市场系统性风险（`market_temperature` / VIX）不在极端、本指数只是阶段性落后补涨时，**落后本身不是看空理由**——那是“回基线”的场景，不是“离场”的场景。
- 不用硬止盈硬止损——择时交给政策、招标、趋势、回撤说话；但**机械回撤控仓在本指数是命脉，不是可选项**。

## 一、先识状态：政策环境 + 主导块 + 趋势市 / 震荡市

**每天第一步：先回答两个问题，再给价格状态分类。**

1. **政策环境**：顺风（设备更新放量 / 集采温和 / 反腐常态化）/ 逆风（集采扩围 / 反腐升级 / 支付收紧）/ 中性——这是本指数的〇号判断，政策逆风期里所有看多信号自动降一档。
2. **主导块**：器械院端 / 消费医疗 / CXO，谁在主导今天的边际变化。
3. **价格状态**（三选一）：趋势市（均线单边 + 斜率明显 + 招标同向）/ 震荡市（200 日线走平 + ±10–15% 箱体反复）/ 过渡待定（轻仓 / 观望 / 维持原状态）。
- **状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日跳空（集采 / 反腐新闻最常见）、单根假突破不算切换信号。每天显式记下**状态标签 + 政策环境 + 主导块 + 推翻它需要看到什么**。

## 二、趋势市骨架：时序动量 + 招标确认

- **时序动量**：指数过去数周到数月的方向，**叠加招标数据趋势**。两层共振向上 → 在场吃 β；任一转下（特别是招标失速）→ 降仓。
- **波动率体感**：越平静越敢拿；振幅骤增（政策跳空）本身是降仓信号；集采开标 / 政策敏感窗前主动把仓位调到"能扛跳空"的档。
- 趋势里不做高抛低吸。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 箱体中段不动手；轻仓不赌箱体（一条集采 / 反腐新闻就能突破或跌穿）；不追假突破。
- 放量 / 逻辑级催化（设备更新资金落地 / 集采温和靴子落地）突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回场分两层（回基线易、上进攻仓看赔率）

- **大开大合，不做微调**：最小步长 20%。
- **政策逆风共振 / 招标失速确认 / 趋势转空 → 一把降到位，可以到 0**：政策杀往往连续加码（集采一批接一批、反腐一轮接一轮），等“再确认一天”往往多亏一截。离场端的果断，保留。
- **回场分两层，别混成一道门**（这是本指数最容易踏空的地方）：
  - **回到基线仓（默认动作、门槛低）**：只要**急性 risk-off 解除**——趋势 / 资金企稳止跌（**不必等站上关键均线、更不必等缓冲修复到某个百分比**）、政策不再加码、招标没有在失速——就该**回到基线参与档**。回基线**不要求招标放量确认**：招标真空是常态，拿“等招标回暖”当回场前提 = 永远回不来 = 把踏空写进纪律。
  - **加到基线之上的进攻仓（门槛高、看赔率）**：政策出清（靴子密集落地）+ 招标回暖放量 + 趋势放量确认 + 拥挤度未极端 多因素共振 → 大步超配。**“宁可错过，不可做错”只约束“要不要加到进攻仓”这一层，不约束“要不要回基线”。**
- **只在浮盈 / 趋势未坏的回调里加进攻仓；绝不在政策逆风的下跌趋势中摊薄**（政策出清底部观察期的左侧试仓——小、分批、有招标回暖证据——可以接；招标仍在失速的下跌不能接）。

## 五、止盈止损：用政策、招标、趋势和回撤说话，不用固定数字

- 在场期间盯四件事：**政策环境有没有转向、招标数据有没有失速、趋势破没破、从持仓高点回撤了多少**。
- **主升尾段的主动止盈**：高分位 + 拥挤极端 + 招标增速见顶三者叠加时，移动止盈收紧（从持仓高点回撤即减档）。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关，本指数的命脉）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%、−50% 需翻倍。本指数走出过七成量级的回撤——**这条纪律就是它和"归零体验"之间唯一的隔离墙**。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；政策新闻密集的板块尤其要克制高频。
- 每个仓位档**至少持有 3 个交易日**；期间只有趋势 / 政策 / 招标转向、账户回撤穿阈值、止盈触发三类信号允许跳档。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 集采是利空快跑 | 靴子落地是底 | 看**预期消化程度 + 降幅**：扩围发酵期看 A（杀预期在前面）；落地且温和 / 以价换量看 B |
| 低分位该买 | 政策重置后区间不可比 | 先问盈利中枢假设变没变：政策出清 + 招标回暖看 A；品类逻辑被集采重置看 B |
| 高分位该减 | 盈利兑现期高分位可持续 | 高分位 + 招标放量看 B；高分位 + 招标失速看 A |
| 政策利好要追 | 口号不等于订单 | 看**资金落地进度**：招标数据验证到放量看 A；只有文件没有订单看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 招标 / 客流逻辑没坏的系统性恐慌（CXO 联动误伤）看 A；政策逆风共振驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；拥挤极端 + 招标增速见顶 + 量价背离看 B |
| 医疗是一个板块 | 器械服务 CXO 各走各的 | 默认按"分块"理解：院端政策 / 消费力 / 融资周期驱动不同，先定主导块再判断（**别把 CXO 波动读成院端政策信号**） |

> **核心一句**：中证医疗——**政策是第一性变量、月度招标数据是最硬的领先抓手**；器械看院端（政策 + 招标）、服务看消费力、CXO 跟融资周期，三块分开判；估值分位在政策重置后打折用；无可靠择时因子，**仓位纪律（快砍、压回撤）是这个指数能不能要的前提**；政策逆风共振不留仓、事件前减敞口；但**没有硬 risk-off 时默认在基线仓、空仓须归因（归不出=踏空）**，回基线不等招标、加进攻仓才看赔率。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角系统性失灵、出现框架没覆盖的新机制（新支付体系、新采购模式、AI 医疗等新品类进指数）。
- **定期 + 事件驱动**：一轮政策周期（集采批次 / 财政年度）走完或月度 / 季度体检；遇大回撤或明显误判时专项复盘。
- **单次噪声不改**。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值、视角权重与排序、三块各自的领先指标清单、新增失效模式与证伪条件、择时辅助指标在新数据上的表现复核（若未来扫描出可靠因子，升级三节择时小节）。
- **不轻易动（信仰与原则层）**：唯一信仰（政策与招标定方向 + 纪律压回撤）、三块拆解结构、政策环境是〇号判断、风险优先于收益、不接飞刀、回撤控仓是命脉、**“没有硬 risk-off 时默认在基线仓 + 空仓须归因 + 回场分两层（回基线不等招标、加进攻仓才看赔率）”这条反踏空默认**。

## 三、怎么迭代

- **决策与结果分离**：只为过程性、可重复的错误改方法论。
- **拿证据，不拿情绪**；**完整重写、写清 reason**；**小步快迭代优于大改**。

## 四、防过拟合

- **别拿方法论解释亏损**；**区分噪声与结构变化**（支付体系重置 / 采购模式变革是结构变化）；**保留可证伪性**；**迭代也会错**，敢于回退。
