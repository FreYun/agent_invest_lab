# 有色金属指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少，每次操作至少是20%仓位。


## 核心认知

有色金属 = **大宗商品价格 × 矿企经营杠杆**的强周期赛道。五个特性决定玩法：

- **极致周期 + 双重杠杆**：盈利 = (商品价 − 单位成本) × 销量，营业杠杆 + 财务杠杆叠加，**商品价格波动 10% 常对应矿企利润波动 50%+**；周期上下行幅度都被放大。
- **全球定价 + 美元主导**：铜 / 铝 / 锌 / 镍 / 锡 / 黄金都是美元计价的全球商品，**美元指数走弱 = 商品涨价的顺风、走强 = 系统性逆风**；A 股有色板块本质是"美元 + 全球宏观 + 中国需求"的组合。
- **子板块严重分化**：同叫"有色"，驱动逻辑完全不同——
  - **工业金属（铜 / 铝 / 锌 / 铅 / 锡）**：全球制造业 PMI + 中国基建 / 地产 / 电网
  - **贵金属（黄金 / 白银）**：实际利率 + 美元 + 避险情绪（与工业金属常**反向**）
  - **能源金属（锂 / 钴 / 镍硫酸）**：新能源车 / 储能 / 三元正极的需求弹性
  - **稀土 / 钨钼**：军工 + 高端制造 + 配额政策（行政定价色彩重）
  - 指数是一篮子，但同一时刻可能各子板块互相抵消，**必须穿透看子板块和龙头**。
- **库存 + 矿山扰动是高频信号**：LME / 上期所库存、矿山罢工 / 事故 / 资源民族主义（印尼禁矿、智利铜罢工、缅甸锡矿），事件单日 ±5–10% 常见。
- **政策双刃**：国内保供稳价（限制商品过热）、出口管制（稀土 / 钨 / 锑 / 镓锗）、新能源补贴 / 退坡、地产 / 基建刺激——**同一条政策对不同子板块方向相反**，必须穿透到对应子板块判断。

宏观（美元 + 全球景气）与商品价格趋势 > 仓位择时 > 选品；**周期 + 库存 + 子板块结构**思维 > 长期持有。

## 一、估值视角（周期股 PE 反着读，主用 PB）

对有色这种**强周期 + 商品价格驱动**的指数，**禁止把 PE 当价值锚做均值回归择时**——PE 在周期股里是**反向指标**。具体陷阱：

- **PE 陷阱（最关键认知）**：周期顶部，商品价飞天 → 盈利 E 顶 → PE 看起来**最低**；周期底部，商品价跌穿成本 → 盈利 E 坍塌甚至亏损 → PE 冲到**最高甚至为负**。**低 PE 是周期顶的卖出信号，高 PE 才可能是周期底的买入信号——和成长股完全相反。**
- **主用 PB**：矿企净资产相对稳定（矿山资源 + 固定资产），**PB 比 PE 稳得多**。历史 PB 分位有参考价值——周期底部龙头 PB 常打到 1x 附近甚至破净；周期顶部 PB 3x+ 普遍。但**PB 同样不做择时扳机，只做定性预警**。
- **看长周期商品价格分位 + 盈利兑现度**：商品价（铜价 / 金价 / 锂价）在历史 5 / 10 年分位的位置 + 当前盈利是否已兑现到位，比 PE / PB 更说明问题。
- **样本足够长，但分位仍非择时锚**：有色板块上市公司多、历史长，分位数本身可用，但**只用于"是否进入泡沫区 / 深熊区"的定性判断**，不用于"低 PE 抄底 / 高 PE 减仓"的机械操作。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量 + 商品价格框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端读数一票否决。极端读数仍是要认真对待的定性信号。

估值在这里只做两件**定性预警**的事（不是择时扳机）：
- **极端泡沫预警（顶）**：商品价创历史新高 + PB 顶部分位 + 全民进场（题材爆炒、卖水卖铲都被炒、研报"新长牛"非理性繁荣）→ 配合趋势框架减仓。**特别警惕周期顶部"低 PE + 高分红"组合，那常是最后一波**。
- **周期反转预警（底）**：出现 **商品库存见底回升 + 矿山供给收缩 + 龙头减产保价 + 下游补库 + PB 接近 1x**等周期反转证据 → 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是**商品价 / 库存 / 供给证据**，不是低 PE 或低 PB 分位（分位对周期股是**滞后**的）。

**真正的"价值标尺"是矿山资源 + 单位成本曲线**：低成本龙头在周期下行能盈亏平衡、高成本矿先停产 → 龙头穿越周期能力 = 重仓信心；同时关注资源储量 / 服务年限（紫金、洛钼、北方稀土的核心壁垒）。成本曲线管"值不值得在趋势里重仓"，不用来抄底或择时。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**有色还要额外把商品价格趋势纳入**——板块趋势与商品趋势背离时，以商品趋势为主参考。

- **方向锚（双层）**：
  - 板块层：指数 vs 200 日均线（收盘价即可算均线 / 时序动量）
  - 商品层：核心商品（铜 / 黄金 / 锂）的 200 日均线 + 价格分位
  - **两层共振时信号最强；只有板块涨而商品平 → 题材脉冲，须谨慎**。
- **量能确认（板块代理）**：指数取不到量 → 用 `sector_factor` 风险分（成交集中度）/ `sector_factor_detail` 拥挤度代理；突破时拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破。
- **波动率（板块代理）**：指数算不出 ATR（无高 / 低）→ 用**收盘价滚动波动率** + `sector_factor_detail` 的 **MA200 乖离率**代理；波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：矿山罢工 / 禁矿 / 收储 / 出口管制消息常造成跳空，要分清这是**逻辑级利好（供给真实收缩 / 价格中枢上移）**还是**情绪脉冲**——前者可顺势，后者易回补缺口。
- **子板块轮动**：工业金属和贵金属常**反向**（美元强 / 实际利率升 → 工业金属 + 黄金双杀少见，更常见是一升一降），不要把"有色板块跌"当成全员跌——可能是工业金属砸、贵金属在涨，反之亦然。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

## 三、景气度视角（有色专属：商品价 + 库存 + 下游需求为母变量）

有色的景气有**清晰的产业链传导链条**，按性质分四类，别用滞后指标做择时（具体取数见上「取数」节）：

- **领先(母变量)**：
  - **商品价格 + 库存**——铜 / 铝 / 锌 / 锂 / 金的现货 + 期货价 + LME / 上期所库存，**库存见底回升常领先价格 1–3 个月**
  - **下游需求**——全球 PMI、中国基建（电网投资、专项债）、地产新开工 / 竣工、新能源车销量、光伏装机
  - **供给端**——主要矿山产量指引、罢工 / 事故、品位下降、禁矿政策
  - 三档同向时信号最强（需求升 + 供给紧 + 库存降 = 商品价格主升）。
- **滞后（确认而非择时）**：矿企营收 / 净利 YoY + 一致预期修正，跟随商品价格 1–2 季度反映，**不当择时锚**——等盈利确认转向就晚了。
- **结构 / 上限**：矿山服务年限、储量、单位现金成本曲线——决定龙头穿越周期的能力与重仓信心，不决定主趋势开关。
- **事件驱动**：禁矿 / 罢工 / 出口管制 / 收储 / 战争（影响俄铝俄镍俄钯）—— 跳空催化，事件级单独评估。

- **商品价格是母变量**：它领先矿企盈利约 1–2 个季度。**看商品价格趋势 + 库存方向，不看矿企当期营收**（营收是滞后确认）。
- **库存是最高频的领先指标**：LME / 上期所 / 社会库存周度更新，**库存见底回升**是早期反转信号；但要区分"显性库存"（交易所）与"隐性库存"（隐性囤货 / 套保仓单）—— 显性库存降但隐性库存升，价格未必走强。
- **下游需求是真锚**：铜看电网 + 新能源 + 空调；铝看地产 + 新能源车轻量化 + 光伏边框；锂看新能源车 + 储能；黄金看实际利率 + 央行购金。需求拐点早于价格。
- **看的是趋势一致性**：商品价 + 库存 + 下游需求 + 供给四个领先维度同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**（盈利会跟上）。

## 四、宏观 / 美元 / 全球周期视角（有色专属：与商品价格深度耦合的母变量）

这是有色金属区别于科技 / 消费板块的**专属维度**，几乎所有商品价格都被它驱动：

- **美元指数（DXY）= 负相关母变量**：商品以美元计价 → 美元强势压制商品价（铜 / 黄金 / 工业金属普跌）；美元弱势抬升商品价。看到"美联储鸽派 / 美元转弱"消息 → 对有色普遍利好。
- **实际利率 = 黄金的核心定价锚**：10Y TIPS 收益率（名义 − 通胀预期）。**实际利率下行 → 黄金上行**；实际利率上行 → 黄金承压。这条比"避险情绪"更基础——避险只是短期脉冲，实际利率才是中长期方向。
- **全球 PMI = 工业金属的需求锚**：全球制造业 PMI 在 50 上下方向 + 中国 PMI 共振 → 工业金属趋势方向锚定；PMI 与商品价共振时仓位敢重，背离时要警惕。
- **中国宏观（地产 + 基建 + 制造业）= A 股有色的本土锚**：中国占全球铜 / 铝 / 锌消费 50%+，**中国地产 / 基建周期对工业金属价格的边际影响超过全球**；地产松绑 / 专项债加码 / 电网投资上修 → 直接利好工业金属。
- **新能源 / 军工独立周期**：锂 / 钴 / 稀土的需求驱动是**新能源车 + 储能 + 风电 + 军工**，**部分脱离工业金属周期**——可能出现"工业金属跌、能源金属涨"的分化。看新能源车销量 / 储能装机 / 军工订单，而不是 PMI。
- **地缘 / 资源民族主义**：印尼禁矿、智利铜矿罢工、缅甸佤邦锡矿停产、俄镍俄铝制裁、稀土出口管制——这是**供给端的脉冲**，单日跳空大。要区分"短期扰动（易回补）"vs"长期供给中枢上移（趋势级）"。
- **政策双刃**：保供稳价（压商品价）vs 收储 / 出口管制（抬商品价）；新能源补贴退坡（压锂钴）vs 储能强制配套（撑锂钴）。同一条政策对子板块方向相反，**别只看一面**。

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。有色波动大、商品价跳变快、地缘事件密，纪律不可省：

- **商品价格兑现 / 转向**：商品价创新高 + 库存高位 + 需求边际转弱 → 主动兑现得更积极（盈利顶通常滞后价格顶 1–2 季）；商品价跌穿主要矿山现金成本线 → 周期下行可能见底（但**别先抄底，等供给端真减产 + 库存企稳**）。
- **美元 / 实际利率反转预警**：美元指数从弱转强 / 实际利率从降转升 → 对有色（特别是黄金 + 工业金属）是系统性逆风，不必等价格回撤就该降仓。
- **子板块分化预警**：贵金属和工业金属共振涨（罕见）= 警惕系统性风险（滞胀预期 / 危机情绪）；共振跌（罕见）= 流动性危机（如 2020 年 3 月、2008 年）→ 这两种都是降仓信号。
- **事件前减敞口**：FOMC / 重大政策窗口 / 制裁 / 主要矿山谈判节点前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。
- **硬止损**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑（商品价上行 / 美元转弱 / 需求复苏）大概率已破。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **商品价证伪（下行，最关键）**：核心商品（铜 / 黄金 / 锂）跌破主要均线 + 库存持续累积 + 现货升水转贴水——价格逻辑直接被推翻，板块行情失去燃料。
- **需求证伪（下行）**：全球 / 中国 PMI 持续下行；地产新开工 + 电网投资 + 新能源车销量等下游指标连续走弱；下游主动去库。
- **美元 / 利率证伪（下行）**：美元指数转强趋势 / 实际利率上行通道——对工业金属 + 黄金都是系统性逆风。
- **供给证伪（下行）**：新增矿山 / 冶炼产能集中释放（如锂的盐湖 + 锂辉石新增产能 2023–2024 集中释放压垮锂价）；禁矿松绑（印尼镍 / 缅甸锡）。
- **趋势证伪（下行）**：指数跌破 200 日均线且 1 月未收回，但是你应该根据当时的市场环境修正你的指标。
- **估值证伪（下行，反向）**：商品价新高 + PE 看似"最低" + 全民进场 + 卖方高呼"超级周期"—— 周期顶部最危险信号组合（PE 陷阱叠加情绪过热）。
- **看空被证伪（上行 veto-watch）**：商品价跌破现金成本线后供给端主动减产 / 矿山关停；库存见底回升；美元 / 实际利率转向走弱；地缘冲击导致供给中枢上移；下游补库启动——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 有色金属是**极致周期 + 双重杠杆 + 商品价格驱动**的强周期赛道，单指数策略夏普的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是商品价格反转 / 美元转强 / 系统性风险来时少亏。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- 但该在场时别缺席：趋势明确向上（商品价上行 + 美元转弱 + 库存去化 + 需求复苏 + 价格多头）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由——更绝不拿"PE 低"当进场的理由（那可能是周期顶）。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行，**且核心商品价同向运动**。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10–15%（周期股波动大，箱体宽）内来回 + 箱体反复假突破 + **商品价也在区间内震荡**。
  - **过渡待定**：信号不清、板块趋势与商品趋势背离、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（商品价转跌 / 美元转强 / 趋势破位）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破（禁矿 / 收储 / 政策）即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：
- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（矿山事件最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日 + 商品价同向**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向，**叠加核心商品价格趋势**。两层共振向上→在场吃 Beta；任一转下（特别是商品价转下）→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：有色本就高波动，越平静越敢拿，振幅骤增 / 大涨大跌 / 商品价单日 5%+ 跳变时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **事件叠加**：FOMC / 重大政策 / 矿山停产 / 制裁窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（供给真实收缩 / 需求确认复苏）确认后再顺势加。
- 叠加：**方向（动量 + 商品价）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10–15% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：有色箱体随时可能因一条禁矿 / 收储 / FOMC 表态向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：商品脉冲多、矿山事件易反复，假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如美元方向转向 / 禁矿落地 / 大规模减产），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 商品价转向 / 美元转强 / 趋势转空 → 一把清到位，可以直接到 0**：有色周期下行往往加速（盈利杠杆向下），等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。有色的高赔率组合是 **商品价上行 + 美元转弱 + 库存去化 + 下游补库 + 价格放量突破** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；宁可错过，不可做错**——但"宁可错过，不可做错"只约束低赔率情形；高赔率时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破（含商品价趋势）** + **从持仓高点回撤了多少**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且有色主升浪回调动辄 20–30%（商品价波动 + 盈利杠杆），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。有色单边跌起来很容易摸到深水区（盈利杠杆向下），这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 有色波动大、商品 / 矿山新闻天天有诱惑，更要克制别被脉冲诱发高频折腾。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、商品价格、美元 / 实际利率、库存 + 下游需求、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 是便宜该买 | 周期顶 PE 最低（PE 陷阱） | 周期股**永远看 PB + 商品价位置**，不看 PE；只有盈利稳态品种才能用 PE |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + 商品价 + 美元配合看 B，趋势破位 / 商品价转跌时极端读数当定性预警 |
| 美元强势利空商品 | 滞胀里美元商品同涨 | 看通胀预期 + 实际利率：实际利率下行 + 通胀粘性 → 美元商品可能同涨；常态周期下美元主导，看 A |
| 制裁 / 禁矿是利好（供给收缩） | 制裁 / 禁矿是利空（需求受损） | 看打的是**供给端**还是**需求端**：俄镍 / 印尼禁矿 / 缅甸锡看 A（涨）；针对中国出口的制裁、加征关税看 B（短期承压） |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看**商品价 + 库存方向**：领先端仍向下看 A，领先端见底回升（盈利滞后）看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但商品价 / 美元逻辑没坏看 A，单边下跌途中看 B |
| 强者恒强 | 物极必反 | 趋势中段 + 库存去化 + 需求加速看 A，极端情绪 + 商品价创新高 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 商品价见顶 / 库存累积 / 量价背离看 B |
| 工业金属 = 黄金（都是有色） | 工业金属 vs 黄金常反向 | 大多数时候**反向**（实际利率 / 风险偏好驱动方向相反），只有滞胀 / 流动性危机时才共振，默认按"反向"理解 |

> **核心一句**：有色金属—用 **商品价格 + 美元 / 实际利率 + 库存 + 下游需求** 判景气、用 **PB + 成本曲线** 判空间（**永远别用 PE**）、用**趋势 / 动量**择时、用**大开大合 + 压最大回撤**做仓位；吃该吃的 Beta、躲商品价转向与美元转强误伤、空仓不愧疚、按优势大小下注、进出算成本，靠压回撤把夏普做上去。
