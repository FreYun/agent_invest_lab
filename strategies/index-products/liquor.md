# 中证酒指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

- 标的：**中证酒指数（399987.SZ）**，覆盖白酒 + 啤酒 + 其他酒类酿造的一篮子龙头（约 30 只，每年 6 / 12 月调样）。

## 核心认知

中证酒（399987）≈ **白酒约八九成 + 啤酒约一成 + 少量预调酒/葡萄酒**——本质是"白酒指数 + 一点啤酒缓冲"。白酒是**强品牌消费 × 渠道库存中周期**：既有消费股的高 ROE、高现金流、强护城河，又跟着商务/宴席景气与渠道库存走出数年级别的大周期。五个特性决定玩法：

- **批价是这个指数的"产业链价格"**：飞天茅台批价是全行业景气最重要的先行锚——批价企稳回升 → 渠道有利润 → 经销商敢打款进货 → 动销与报表跟上；批价阴跌 → 渠道倒挂亏钱 → 压货去库存 → 业绩坍塌。**盯批价比等财报及时得多**，这是本框架相对"看报表炒白酒"的全部领先性来源。
- **渠道库存是放大器，回款是蓄水池**：渠道库存高 = 顺周期时被掩盖、逆周期时引爆价盘的定时炸弹；合同负债/预收款反映经销商打款意愿。**报表收入可以被蓄水池调节，批价和库存更难长期伪装**——"报表增速仍亮眼但批价库存已恶化"是白酒最具迷惑性的顶部形态。
- **戴维斯双杀是最大杀伤**：白酒盈利稳定、可 DCF，PE 分位有意义——但去库存周期里 EPS 下修与杀估值同时发生，历史上的大调整（如限三公 + 塑化剂那轮戴维斯双杀）能把指数砍掉一半以上、持续数年。"喝酒永远涨"是死扛的借口，不是策略。
- **权重高度集中于白酒头部**：前十大权重约八成（茅五汾泸四家合计过半），指数方向几乎由高端白酒的批价与渠道状态决定，**必须穿透到茅五汾泸看，不能当宽基**。
- **啤酒是独立的小周期**：青啤/燕京/重啤约一成权重，逻辑是**旺季动销（天气/餐饮/夜场）+ 吨价高端化 + 成本（大麦/包材）**，与白酒的商务景气周期不同步——它给指数一点缓冲，但决定不了方向。研究主线放白酒，啤酒看结构。

驱动排序：**渠道景气（批价 / 库存 / 动销 / 回款）> 品牌定价权与格局 > 趋势 / 资金 > 政策与宏观（禁酒令 / 消费税 / 经济与场景）> 估值分位**。研究时问三件事：

1. 渠道景气在哪个阶段（去库存下行 / 底部企稳 / 景气扩张 / 高位压货）？批价与库存怎么说？→ 决定能不能重仓、是不是底部。
2. 趋势对不对、资金在不在？→ 决定现在是加是减。
3. 政策（禁酒令 / 消费税）、消费场景（商务 / 宴席 / 个人自饮的结构迁移）、品牌格局变没变？→ 决定是不是该撤。

## 取数

> 白酒的核心驱动（批价 / 渠道库存 / 动销 / 回款）**几乎全是非结构化数据**——批价不是交易所商品、库存动销靠渠道调研，全活在研报、新闻、调研纪要里。这正是文本面在这个指数上权重必须高的原因。能定量的只有价格系（趋势 / 回撤 / 动量）+ 估值分位 + 板块资金拥挤 + 龙头财务预期。**所有历史分位均以"截至当日 PIT"口径。**

- **指数（行情 + 估值）**：`market_index_quote / market_index_val 399987.SZ`（仅收盘 + 涨跌幅，无量与高低）。纯白酒口径可参 `399997.SZ 中证白酒` 做对照（本框架主口径是 399987）。

## 一、估值视角（白酒可用 PE 分位，但必须配批价 / 库存防双杀）

白酒龙头盈利稳定、现金流可预测，**与强周期股相反，PE 历史分位的均值回归在这里是有意义的择时辅助**——但有三条硬纪律：

- **PE 分位 + 渠道景气双重确认**：低 PE 分位本身不是买入信号，要叠加"批价止跌 + 库存去化 + 动销回暖"才成立；高 PE 分位也不是卖出信号，要叠加"批价见顶 + 库存累积 + 动销转弱"才危险。**估值分位定赔率，渠道景气定方向。**
- **警惕戴维斯双杀的分母陷阱**：去库存下行期 EPS 会持续下修，单看静态 PE 会"显得便宜"（E 还没降完），实际是双杀途中。底部要等 EPS 下修接近尾声 + 批价库存反转，才是真便宜。
- **在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器**，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。**别把它反过来用**：下跌 / 趋势破位时它只支持"不靠便宜接飞刀"，不能拿来把极端读数一票否决。

估值在这里做两件**定性预警**的事（不是择时扳机）：

- **极端泡沫预警（顶）**：PE 顶部分位 + 全民进场（囤酒理财、白酒主题基金爆发、研报一致"喝酒永远涨"）+ 批价冲高渠道疯狂囤货 → 当成趋势进入尾段的提示，配合趋势框架与止盈纪律处理。
- **深熊底部观察（底）**：PE 底部分位 + 龙头股息率高过长债 + 盈利下修已持续多季 → 不抄底，但**触发去文本里找渠道反转证据**（批价止跌回升、库存去化到位、龙头控货挺价、动销边际改善）；证据出现且趋势企稳，记为**潜在筑底观察**（持久观察态，写进记忆续到明天），按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。**白酒还要把批价趋势纳入**——指数趋势与批价趋势背离时，以批价为主参考（指数涨而批价阴跌 = 反弹不是反转的概率大）。

- **方向锚（双层）**：板块层看指数 vs 200 日均线 + 时序动量；渠道层看核心单品批价的方向（企稳 / 回升 / 阴跌 / 破位）。**两层共振时信号最强。**
- **量能确认（板块代理）**：指数无量 → `sector_factor` 成交集中度 / 拥挤度代理；突破时拥挤度同步抬升 = 有量，不跟 = 可疑假突破。
- **波动率（板块代理）**：收盘价过去 N 日滚动波动率 + MA200 乖离代理；波动骤增本身是降仓信号。
- **事件跳空甄别**：政策（禁酒令 / 消费税传闻）、龙头动作（提价 / 控货 / 停货）、食安黑天鹅常造成跳空，分清**逻辑级**（需求场景被真实砍掉 / 价盘政策性重估）还是**情绪级**（传闻、旧闻发酵）——前者跟，后者易回补。判别方法：第二天去研报 / 纪要找有没有基本面增量。
- 机构抱团是白酒特有的趋势放大器：抱团瓦解 + 批价走弱是顶部信号，外资与机构回流 + 批价企稳是底部确认。

震荡市里均线信号反复假突破，转箱体思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。研究时不问"能不能买"，问"信号强到什么程度"。

## 三、景气度视角（白酒专属：渠道周期四阶段 + 批价-库存-动销-回款一致性）

白酒盈利由**商务 / 宴席消费景气 + 渠道库存周期**主导（基酒产能通常不是主约束）。把渠道周期分四个阶段定位，这是本框架的价值锚：

- **去库存下行**：动销疲软、渠道被动累库、批价阴跌甚至倒挂、打款意愿差——业绩还在下修，戴维斯双杀主场。**少碰，趋势转空就清。**
- **底部企稳（反转前夜）**：库存去化到健康水位、批价跌无可跌并止跌、动销边际改善、回款回暖、龙头主动控货挺价——左侧布局区，但要批价 / 库存信号确认，不是见跌就抄。
- **景气扩张**：动销旺、库存低位、提价顺畅、结构升级、合同负债饱满——戴维斯双击主升段，**重仓吃 β**。
- **高位压货 / 过热**：批价冲高、渠道疯狂囤货、全民看好、厂家向渠道大幅压货透支——下一轮去库存的种子已埋下，**趋势走坏即减**。

判断阶段的依据按领先滞后分层：

- **领先（母变量）**：核心单品批价（飞天 / 普五 / 国窖 + 次高端单品）、渠道库存方向、龙头控货 / 提价 / 停货动作。
- **同步**：动销（春节 / 中秋旺季是一年两次的集中验证窗）、宴席 / 商务 / 自饮场景景气、回款进度。
- **滞后（确认不择时）**：报表营收 / 净利、合同负债——**等报表确认再动通常已走完半程**，且报表可被蓄水池调节；报表的价值是证实 / 证伪此前渠道面读到的方向。
- **结构 / 慢变量**：消费场景迁移（政务→商务→个人自饮的长期结构变化）、吨价与产品结构升级、高端 / 次高端 / 区域的分层景气——决定空间与重仓信心，不决定主趋势开关。

**纪律**：领先端（批价 / 库存）定方向，滞后端（报表）做确认；背离时信领先端。高端 / 次高端 / 区域三层经常不同步——**用主导层（权重大且边际变化大的层）的信号说话**，不能用茅台批价坚挺掩盖次高端价盘崩塌。

### 可用的择时指标（定性）：无可靠绿灯，动量只作第二意见

**核心结论（诚实，不可美化）**：研究室全因子族扫描下来，本指数**没有可靠稳健的择时因子**——趋势类、回撤类因子在本指数上时间稳定性不够。表现最好的是 **`mom_20`（20 日动量：近 20 日收益为正则在场，否则空仓）**，方向上有参考价值但置信度不足，**只能当黄灯第二意见，不能当独立扳机**。另外本指数只有收盘价、没有日内高 / 低，吊灯（chandelier）这类用 ATR 的因子只能用收盘代理，会**系统性偏乐观**（低估真实波动 → 止损线偏宽），可靠性再打一档折扣、仅作参考。

**怎么用（判断，不机械执行）**：

- `mom_20` 当"现在该不该动"的右侧第二意见：与渠道景气判断同号 → 确信度加一档；冲突 → 逐项核验是不是渠道面读漏了，**以批价 / 库存的基本面判断为准**。
- 已知盲区（从公式可推）：20 日动量在震荡市反复翻面、在 V 型反转前段必然迟到、对政策黑天鹅无预警——它是节奏参考，不是侦察兵。
- **仓位纪律（快砍、压回撤）优先于追逐任何择时信号**；择时价值主要在降回撤，不在提收益。

## 四、政策 / 事件视角（白酒的事件主引擎）

- **禁酒令 / 三公类政策**：直接砍需求场景，是逻辑级利空——但要评估**砍的是哪个场景、占比多大**（政务消费占比已远低于上一轮调整时，同样的政策弹药杀伤递减）。政策落地初期情绪杀往往超过实际需求杀，落地后"利空出尽 + 场景结构重估"才是关键判断。
- **消费税改革（征收环节后移）**：长期悬而未决的传闻型利空，每次发酵都砸盘。纪律：传闻级当情绪脉冲处理，**真落地才重估盈利中枢**（对高端 / 次高端 / 区域的影响幅度不同，须分层算）。
- **食安黑天鹅（塑化剂式）**：单日重创情绪，杀伤取决于是否动摇品牌信任。历史经验是黑天鹅叠加需求周期下行才致命，单独发生多为情绪坑。
- **龙头价格动作**：茅台提价 / 控货 / 停货、五粮液出厂价调整——是渠道周期的人为干预信号，控货挺价出现在底部区域是积极信号（厂家开始保价盘）。
- **旺季验证窗**：春节（一年最大动销窗）、中秋国庆——旺季前渠道备货与旺季后库存变化是每年两次的强制检验点，旺季动销证伪此前叙事时市场反应剧烈。
- **事件前减敞口**：重大政策窗口、旺季动销数据落地前后跳空风险大，事件不明朗时不赌方向。

## 五、风险管理视角

白酒的杀伤来自方向性的逻辑破坏与高估值叠加，不是日常震荡：

- **戴维斯双杀**：去库存 + 杀估值同时发生，且常在"报表增速仍亮眼"时悄悄开始（蓄水池掩盖）——最具迷惑性。批价 / 库存恶化先于报表，**靠渠道面 + 趋势提前离场，不能只等价格止损**。
- **价盘崩塌**：核心单品批价跌破经销商成本（倒挂）→ 渠道砸货、信心崩溃 → 越跌越卖的负反馈。批价倒挂加深是加速下行信号。
- **抱团拥挤**：机构核心资产属性，一致预期太强、持仓过度集中时，任何边际利空都会引发抱团瓦解式踩踏。
- **政策 / 黑天鹅**：见四节，政策窗口前主动降敞口。
- **硬止损**：单笔 −15% 是心理阈值；−25% 是逻辑边界——超过此跌幅，原买入逻辑（渠道反转 / 景气扩张）大概率已破。**绝不在去库存下行趋势里越跌越买。**

## 六、证伪视角（对称化）

证伪是**买入逻辑的破坏**，须对称——看多与看空的证伪都要列；触发不等于立刻清仓，但意味着原论据失效、需要新论据才能维持原仓位。

- **看多被证伪（下行 veto-watch）**：
  - 核心单品批价二次破位下行 / 倒挂加深（企稳逻辑反转）
  - 渠道库存重新累积、动销 / 进货比持续走弱（去库存失败）
  - 合同负债 / 预收款持续萎缩（蓄水池见底，报表掩盖不住了）
  - 龙头一致预期由稳转下修加速
  - 政策落地砍掉重要需求场景（禁酒令扩围 / 消费税落地）
  - 趋势跌破 200 日均线且 1 月未收回、伴随抱团资金撤离
- **看空被证伪（上行 veto-watch）**：
  - 批价持续企稳回升 + 库存去化到位（渠道周期触底的硬证据）
  - 龙头控货挺价后价盘站稳、旺季动销超预期
  - 政策靴子落地但动销未受损（利空出尽）
  - 盈利下修结束 + 趋势企稳放量（按「先识状态」确认级证据）

# 仓位管理方法论

## 唯一信仰：渠道景气定底、趋势资金定时、纪律压回撤

- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 白酒的超额来自**在去库存到位 / 批价企稳 + 趋势确认时重仓吃景气上行 β（戴维斯双击），在景气下行 + 趋势转空时果断降仓躲双杀**——不是靠见低 PE 抄底，也不是靠死扛"喝酒永远涨"。**空仓躲过去库存 + 杀估值的大跌，是这个策略最值钱的动作。**
- 仓位完全由信号（赔率）决定，**没有常态中枢仓位**——空仓、满仓都合法，空仓不愧疚。不知道怎么办时按「过渡待定」处理（轻仓 / 观望 / 维持原状态），不是习惯性下半注。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把事后闸门误用成事前枷锁。
- 该在场时别缺席：批价回升 + 库存去化 + 趋势多头共振时还空着 = 踏空，同样不及格。
- 不用硬止盈硬止损——择时交给渠道景气、趋势、批价、回撤说话，不交给固定数字。
- **活下来比赚得快重要**，但"活下来"约束的是下行：该满仓时不满仓（踏空）同样不及格。

## 一、先识状态：渠道景气阶段 + 趋势市 / 震荡市

**每天第一步：先给状态分类，再选骨架。** 两个锚叠加定打法：

- **渠道景气阶段**（去库存下行 / 底部企稳 / 景气扩张 / 高位压货）——价值锚，决定仓位中枢能开到多高。
- **价格状态**（趋势市 / 震荡市 / 过渡待定三选一）——择时锚：
  - 趋势市：均线（MA60 / MA120）单边排列、斜率明显，**且批价同向**。
  - 震荡市：200 日线走平 + 价格在均线 ±10–15% 箱体反复 + 假突破频出 + 批价也在区间内磨。
  - 过渡待定：两边都不像、或指数与批价背离 → 轻仓 / 观望 / 维持原状态。
- **状态有粘性**：默认继承昨日结论，今天只问"有没有确认级证据要改它"；单日跳空、单根假突破不算切换信号。宁可慢一拍，不在分类层来回翻。每天显式记下**状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

组合打法：**底部企稳 + 趋势转多** → 左侧轻仓试 + 右侧确认加重（最好的赔率区）；**景气扩张 + 趋势向上** → 重仓拿住让 β 跑；**去库存 + 趋势向下** → 降仓乃至清空，绝不抄底摊薄；**高位压货 + 趋势走坏** → 果断兑现。

## 二、趋势市骨架：时序动量 + 批价确认

- **时序动量**：指数过去数周到数月的方向，**叠加批价趋势**。两层共振向上 → 在场吃 β；任一转下（特别是批价转跌）→ 离场 / 降仓。`mom_20` 作右侧第二意见（黄灯，见三节择时小节）。
- **波动率体感**：越平静越敢拿；振幅骤增、单日大跳变（政策 / 黑天鹅）本身是降仓信号。
- 趋势里不做高抛低吸，方向对就拿住。

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

- 先划箱（200 日线 ±10–15% + 近数月高低点）；划不出清晰箱体 = 按「过渡待定」观望。
- 箱体中段不动手；轻仓不赌箱体（一条政策传闻就能突破或跌穿）；不追假突破。
- 放量 / 逻辑级催化（批价反转 / 政策落地）突破箱体并站稳数日 → **立即交接回趋势骨架**，别反向 fade。
- 震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉，箱体不明确时正确动作往往是**不动**。

## 四、不对称操作：离场快、回补看赔率

- **大开大合，不做微调**：最小步长 20%；2–5% 微调无意义。
- **双杀确认 / 批价破位 / 趋势转空 → 一把降到位，可以到 0**：白酒抱团瓦解 + 价盘崩起来又快又狠，等"再确认一天"往往多亏一截，宁可错杀。
- **回补按赔率**：高赔率组合 = 批价企稳回升 + 库存去化到位 + 趋势放量确认 + 机构资金回流 多因素共振 → 大步上仓位；信号不扎实就分 2–3 个大步或放弃。优势小却重仓 = 把数学优势送回去；**但"宁可错过，不可做错"只约束低赔率情形**，高赔率时真正的"做错"恰恰是轻仓。
- **只在浮盈 / 趋势未坏的回调里加仓；绝不在去库存下行趋势中摊薄**（底部企稳的左侧试仓——小、分批、有批价支撑——可以接；库存仍在累积、批价仍在跌的下跌不能接）。

## 五、止盈止损：用渠道景气、趋势、批价和回撤说话，不用固定数字

- 在场期间盯四件事：**批价 / 库存有没有见顶反转、趋势破没破、资金撤没撤、从持仓高点回撤了多少**。景气向上 + 趋势在场 + 回撤温和 → 拿住；批价见顶 / 库存累积 / 趋势破位 / 回撤明显放大 → 大块兑现乃至清空。
- **主升尾段的主动止盈**：估值泡沫预警 + 全民进场 + 渠道疯狂囤货三者叠加时，移动止盈收紧（从持仓高点回撤即减档），别等价盘反转才反应。
- **保本线**：浮盈 ≥ 10% 后把离场线抬到成本价——浮盈不许变浮亏。
- 亏损端窄而果断，浮盈端宽而敢加，两套口径不混用。

## 六、回撤控仓（账户级总开关）

- 账户净值从峰值明显回撤 → 机械降仓 / 暂停加仓，哪怕维度信号没转向；继续扩大 → 空仓复盘。这是事后闸门，**不得反着用**（不得拿假想回撤反推事前仓位天花板）。
- 回撤数学不对称：−20% 需 +25%、−33% 需 +50%。白酒双杀深跌动辄过半，这条尤其命。

## 七、成本意识

- 7 日内赎回 1.5% 惩罚 + 申赎费——避免同标的 7 日内 round-trip；政策传闻多的板块尤其要克制高频。
- 每个仓位档**至少持有 3 个交易日**（thesis 持续性窗口）；期间只有趋势 / 批价转向、账户回撤穿阈值、止盈触发三类信号允许跳档——单日情绪、单日跳空不打破持有窗口。

## 八、实战判断：成对格言，环境决定用哪条

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 低 PE 分位该买 | 便宜是双杀途中的陷阱 | 看**批价 / 库存**：渠道反转证据齐看 A，EPS 仍在下修、批价仍阴跌看 B |
| 估值太贵该减 | 趋势向上无视估值 | 景气扩张 + 趋势多头看 B；批价见顶 + 全民进场时极端读数当顶部预警 |
| 报表超预期要追 | 报表是蓄水池调出来的 | 看**批价库存是否同向**：渠道面配合看 A，报表亮眼但批价阴跌看 B（最具迷惑性的顶部形态） |
| 政策利空快跑 | 利空出尽是底 | 看**砍的场景占比 + 是否已 price in**：新场景被真实砍掉看 A，传闻反复发酵 / 落地后动销未损看 B |
| 别人恐惧我贪婪 | 顺势不接飞刀 | 渠道逻辑没坏的系统性恐慌看 A；批价崩塌驱动的下跌看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本线就位看 A；批价冲高 + 渠道囤货 + 一致看多看 B |
| 白酒是一个板块 | 高端次高端区域各走各的 | 默认按"分层"理解：用主导层信号说话，别用茅台批价掩盖次高端崩塌 |

> **核心一句**：中证酒——本质是白酒 + 一点啤酒缓冲；用**批价 / 库存 / 动销的渠道周期**定底、**趋势 + 资金**定时、**估值分位**定赔率（须配渠道证据防双杀）；政策事件先分级再反应，报表只做确认不做择时；空仓不愧疚，靠压回撤把夏普做上去。

# 方法论迭代机制

这套框架不刻死。跑一段时间后若发现某视角失灵、某阈值偏了、某类风险没覆盖，用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，带上所有要保留的内容），`reason` 一句话写清为什么改——进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早 / 晚触发、某视角对本指数系统性失灵、出现框架没覆盖的新机制（新消费场景、新政策工具、新渠道结构如直营 / 电商 / 即时零售）。
- **定期 + 事件驱动**：一轮渠道周期走完或月度 / 季度做系统性体检；遇大回撤或明显误判时事件驱动专项复盘。
- **单次噪声不改**：一两笔亏损、一次踏空多是执行或运气问题——先在日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值（PE 分位、回撤档、均线 / 动量周期、各子信号强弱定义）、视角权重与排序、景气表维度、新增失效模式与证伪条件、对各层（高端 / 次高端 / 区域 / 啤酒）的差异化打法、`mom_20` 在新数据上的表现复核。
- **不轻易动（信仰与原则层）**：唯一信仰（去库存到位 + 趋势确认重仓、景气下行 + 转空降仓）、双锚结构（渠道景气 = 价值锚 / 趋势资金 = 择时锚）、风险优先于收益、不接飞刀、对本金保守对 β 放纵、批价库存优先于报表。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架是为了让下一类决策更对，不是让上一笔亏损"显得合理"。
- **区分噪声与结构变化**：日常波动是噪声（不改）；消费场景重构、政策框架重置（消费税落地）、渠道结构变革是结构变化（写进框架）。
- **保留可证伪性**：每次迭代后框架仍要能被未来数据证伪——若改到"怎么走都对"就是过拟合。
- **迭代也会错**：新版上线后若表现更差或依据被证伪，敢于回退或再修正。
