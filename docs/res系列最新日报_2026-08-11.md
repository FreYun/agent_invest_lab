## 四部门联合发布会：加强逆周期调节、储备政策加码预期升温

> **定调**：730政治局会议后首轮政策信号，「积极财政+适度宽松货币」框架落地，力度边际加码但节奏审慎 · 受益地产链/消费/券商 · 短期情绪提振，中期看细则落地

### 一、事件概述

2026年8月4日，国家发改委、财政部、中国人民银行、国家税务总局联合召开"打好宏观政策组合拳"新闻发布会。这是7月30日政治局会议"加大逆周期调节力度"定调后的首轮部门级落实。

**来源**：发改委官网(ndrc.gov.cn)、央行官网(pbc.gov.cn)、证券时报、财新网等权威报道。

### 二、五维研判

|------|------|------|
| **类型** | 货币+财政协同（综合性） | 四部门首次联合发声，覆盖货币政策、税费政策、逆周期调节 |
| **力度** | 符合预期偏强 | 发改委提"力度更大的储备政策"超预期；但RRR措辞从"综合运用"降级为"综合评估"偏审慎 |
| **方向** | 结构性宽松 | 支持性货币立场不变，财政聚焦促消费+科技创新，非大水漫灌 |
| **受益板块** | 地产链、消费、券商、科技 | 存量房贷利率下调预期→地产需求链；税费优惠→消费/科技；政策协调→券商 |
| **时滞** | 短期情绪已反应，关键看Q3落地 | RRR/税费细则尚未公布，窗口期在9月前后 |

### 三、核心信号拆解

#### 1. 存款准备金率："综合评估"——信号已出，行动待验
发改委副秘书长袁达首提"综合评估存款准备金率政策"，央行配合表态维持流动性合理充裕。措辞由以往"综合运用"改为"综合评估"，隐含两层含义：
- **政策态度**：降准已在政策视野内，非空谈
- **约束条件**：汇率压力+银行净息差（2026Q1银行息差已逼近警戒线），节奏需谨慎拿捏

→ **判断**：降准大概率在三季度落地（9月概率最高），但幅度或在25bp而非50bp，以平衡多重约束。

#### 2. 存量房贷利率调整：指导而非强制，空间来自负债端降本
央行货币政策司司长邹澜明确"指导银行有序调整存量个人住房贷款利率"。需注意：
- 非行政强制降息，而是通过LPR改革传导
- 银行息差承压是核心掣肘，央行同步推动降低银行负债成本（降准+存款利率下调）
- 市场预计下半年5年期LPR有单独下调窗口

→ **判断**：存量房贷利率下行方向确定，但节奏取决于银行负债端成本下降幅度。重定价日在次年1月的浮动利率贷款将于2027年初享受降息。

#### 3. 税费优惠后续安排：聚焦三大方向
财政部税政司副司长魏岩承诺"近期公布"税费优惠后续安排，三大方向明确：
- 科技创新（研发费用加计扣除等延续优化）
- 促消费/增收（与扩大内需战略挂钩）
- 小微企业/个体工商户（确保优惠力度"不减弱"）

→ **判断**：新税费政策或在8月下旬至9月初落地，直接受益科技板块与可选消费。

#### 4. "防止合成谬误"：政策协调度质的提升
四部门联合强调跨部门政策一致性评估，避免各自出台政策产生抵消或叠加负面效应。这是历次发布会少见的表述。

→ **判断**：后续政策出台节奏可能更集中（避免零敲碎打），但也可能因协调成本导致时滞延长。

## 新型电力系统建设"十五五"规划：电力先行，2030年非化石能源发电占比50%

> **定调**：发改委+能源局联合印发，产业方向性规划 · 受益电力设备/储能/智能电网/充电桩 · 中期落地，五年维度受益

### 一、事件概述

8月3日，国家发改委、国家能源局联合印发《新型电力系统建设"十五五"规划》。规划锚定2030年"碳达峰"节点，首次以五年规划形式系统描绘新型电力系统建设路径。

**来源**：新华社、央视新闻、经济日报等权威报道。

### 二、核心量化目标

| 指标 | 2030年目标 | 含义 |
|------|-----------|------|
| 非化石能源发电量占比 | 50% | 首次过半，结构性拐点 |
| 非化石能源装机占比 | 65% | 风光水核为主力 |
| 新能源高水平消纳 | ≥28亿千瓦 | 消纳能力是瓶颈突破关键 |
| 充电设施总量 | ≥4000万个 | 支撑超1.1亿辆电动汽车出行 |
| 全国电力总装机 | ~54亿千瓦 | 年均新增用电~6000亿度 |
| 算力用电占比 | ~6% | 电力与算力协同发展 |

### 三、五维研判

| 维度 | 判断 |
|------|------|
| **类型** | 产业政策（能源+电力） |
| **力度** | 超预期——首次以五年规划形式系统部署，量化指标密集 |
| **方向** | 结构性倾斜——清洁能源/储能/电网/充电设施全链受益 |
| **受益板块** | 电力设备、储能、智能电网、充电桩、核电、风光 |
| **时滞** | 中期（十五五期间逐年落地，2027-2030） |

### 四、关键传导逻辑

1. **消纳瓶颈→储能刚需**：28亿千瓦新能源消纳目标，意味着储能（抽水蓄能+电化学）装机必须大幅跃升

3. **电力+算力协同**：6%算力用电占比，数据中心配套电力基础设施（微电网/UPS/液冷配电）新赛道
4. **煤电定位转变**：从主力电源转为灵活性调节电源，灵活性改造市场空间打开

- 新能源消纳依赖电网投资进度，若电网投资低于预期则兑现打折

### ⑤ 风险/失效提示

1. **相关≠因果**：本期所有链条均为「背离」状态，A 股行情由内因主导。用美股龙头涨幅推断 A 股后续走势的映射逻辑**本期失效**。

2. **板块指数「虚涨」**：CPO、消费电子、特斯拉概念等板块指数上涨，但权重龙头（中际旭创、新易盛、立讯精密、拓普集团）全线下跌——这是「高切低」的题材炒作特征，非基本面传导。

3. **背离的可持续性**：A 股科技链的独立行情依赖三个内因——①国产替代订单落地 ②大基金三期/政策支持 ③市场风险偏好维持。若任一因素退潮，背离可能快速收敛（A 股补跌）。

4. **数据缺失**：SMCI（AI 服务器）、VRT（液冷）数据缺失，用 DELL 代理 AI 服务器链、用 NVDA 代理液冷链，精确度有限。
