# 中证红利投资框架（METHODOLOGY.md）设计 spec

> 日期: 2026-05-21 · 目标指数: 中证红利 000922（纯红利 / 高股息价值风格） · 形态: 项目既有 `METHODOLOGY.md` 的「研究视角投资框架 + 仓位管理方法论」 · 落地: bots/bot1

## 1. 背景与目标

项目里每只 bot 用一份 `METHODOLOGY.md` 作为该指数的「研究 + 仓位心法」，喂给 LLM agent 在 World 回测里逐日做择时/仓位决策。

本 spec 产出一份**中证红利**的研究 + 投资框架，以「专业研究员」视角写成，作为 bot1 的 METHODOLOGY.md。框架要自洽：从红利自身的资产性质出发，给出可执行的研究角度与仓位心法。

## 2. 关键决策（已与用户对齐）

- **目标**: 中证红利 000922，纯红利、高股息价值风格（非红利低波、非红利质量）。重仓银行/煤炭/交运/电力/石油石化/钢铁。
- **结构**: 「核心认知 + 视角群（六视角）+ 仓位管理方法论 + 核心一句」。视角群按红利逻辑排列：估值锚领衔、利率/宏观独立成主轴、趋势降级并入风格。
- **落地**: 写入 `bots/bot1/METHODOLOGY.md`（当前 world.yaml 跑的就是 bot1）。
- **风格约定**:
  - 开篇声明「这是研究视角，不是执行手册」。
  - 以**定性原则**为主，硬数字只作少量「心理阈值 / 默认值」示意，可被研判覆盖。
  - 结尾保留「数据缺失时用 `research_search` 兜底查最近 365 日历史」。

## 3. 本框架的核心判断（红利的关键认知）

- **资产性质**: 高股息价值贝塔，低弹性、低波动；超额来自防御 + 股息再投复利，而非价格弹性。
- **周期类型**: 利率周期 + 成长/价值风格周期（非产业景气周期）。
- **估值锚**: 股息率分位可做均值回归择时（DPS 粘性、风格样本稳定）；股债性价比（股息率 − 10 年国债）是最重要的锚。
- **择时主轴**: 利率方向为总开关，均值回归（股息率箱体）为主，趋势仅作弱化辅助。
- **仓位哲学**: 底仓长持、仓位中枢较高，围绕股息率锚做波段。
- **最大风险**: 价值陷阱、利率上行、风格切换、拥挤度——靠基本面判断离场，价格止损往往来不及。

## 4. 内容蓝图（逐节）

### 核心认知
- 红利 = 高股息价值贝塔（银行/煤炭/交运/电力/石油石化），不是成长、不是宽基。三特性：低弹性、低波动、双周期（利率 + 风格）。
- 驱动排序：**利率/股债性价比 > 风格周期 > 成分股盈利质量 > 政策催化**。逆向 / 均值回归思维为主。
- 研究三问：现在便宜吗（股息率分位 / 股债利差）？风格和利率在不在红利这边？盈利分红的根基稳不稳（有没有价值陷阱）？

### 一、估值视角（红利的核心）
- 股息率分位**可以**做均值回归择时——DPS 分红粘性强、风格样本稳定，分位有效。
- **股债性价比 = 中证红利股息率 − 10 年国债收益率**：最重要的估值锚；利差走阔（如历史高分位）→ 强力看多，利差收敛 → 警惕。
- PB-ROE 看银行/周期成分（低 PB + 稳定 ROE + 高分红 = 安全垫）。
- **价值陷阱三重验证**：① 盈利/自由现金流是否可持续；② 分红率 payout 是否可持续、是否一次性高分红；③ 行业是否结构性衰退。高股息率必须区分「被低估」还是「盈利要崩」。
- 默认阈值示意（可被研判覆盖）：股息率分位 > ~70% 偏便宜可加；< ~30% 偏贵可减。

### 二、利率与宏观视角（红利的择时主轴）
- 10 年国债收益率方向 = 红利相对吸引力的总开关：下行 → 资产荒 / 险资 / 长线资金配置利好；上行 → 吸引力下降、资金回流成长。
- 经济预期双刃：弱复苏/通缩利好「防御」属性，但若导致成分股盈利恶化（银行息差收窄、煤价暴跌）则是价值陷阱来源。

### 三、风格与趋势视角
- 风格相对强弱（主）：红利/沪深300、红利/成长 比值趋势，判断风格在不在红利这边。
- 价值因子**拥挤度**：交易过度拥挤、ETF 爆量流入、一致预期过强 → 回调风险。
- 趋势框架**弱化版**：200 日均线只用于识别风格崩塌，不作主轴；主用均值回归（股息率箱体）。

### 四、景气度视角（盯成分股根基而非单一产业链）
维度表：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 利率环境 | 10 年期国债收益率（下行利好） | 领先 / 核心 |
| 股债性价比 | 红利股息率 − 10 年国债 利差 | 核心估值锚 |
| 风格 | 红利/成长相对强弱、价值因子拥挤度 | 同步 / 情绪 |
| 盈利质量 | 成分股 ROE 稳定性、自由现金流、分红可持续 | 防价值陷阱 |
| 资金 | 险资 / 红利 ETF 份额 / 北向配置 | 增量资金 |
| 政策 | 中特估 / 新国九条 / 分红与市值管理考核 | 催化 |
| 行业基本面 | 银行净息差、煤价、电价市场化、地产链 | 成分股盈利根基 |

看的是趋势一致性（多维同向），盈利质量与利率是主线，资金/政策是边际。

### 五、风险管理视角
- 四大风险：**价值陷阱、利率上行、风格切换、拥挤度**。
- 低波动 → 硬止损阈值可适当放宽；但风格切换 / 价值陷阱才是真杀伤，不靠价格止损能躲。
- 红利作「底仓 / 防御腿」的仓位哲学：可容忍较高仓位长期持有，在利率拐头向上 + 风格切向成长时降仓。

### 六、证伪视角
触发任一须重新评估持仓（触发 ≠ 立即清仓，但看多论据已不成立）：
- **利率证伪**：10 年国债收益率持续大幅上行（资产荒逻辑反转）。
- **风格证伪**：红利相对成长持续大幅跑输数月（风格切换确认）。
- **盈利分红证伪**：核心成分（银行/煤炭）盈利恶化、分红率下调或暂停 → 价值陷阱坐实。
- **拥挤证伪**：股息率分位极低 + 拥挤度极高 + ETF 爆量流入（一致繁荣顶部）。
- **趋势证伪（弱化）**：跌破 200 日均线且 1–2 月未收回。

### 仓位管理方法论
- **唯一信仰**：超额来自「便宜时（高股息分位 / 利差走阔）重仓拿住吃股息复利 + 拥挤 / 利率反转 / 风格切换时降仓」；在风格站在自己这边时拿满，在风格/利率反转时果断撤。
- **仓位中枢**：底仓长持、中枢较高、步长以 10%–25% 大动作为主，围绕中枢上下。
- **股息率箱体高吸低抛**：高股息分位区重仓、低分位区减仓。
- **止盈止损**：用利率 / 风格 / 估值锚 / 回撤说话，不设固定数字；价值陷阱 / 利率反转为离场主因。
- **回撤控仓**：盯自己净值，风格崩塌期大幅降仓。
- **成本意识**：换手天然低、成本友好；但仍有申购费 + 指增 7 日内 1.5% 早赎惩罚，避免无意义 round-trip。
- **核心一句**收尾。

- 仓位管理体现「底仓长持 + 股息率箱体波段」。
