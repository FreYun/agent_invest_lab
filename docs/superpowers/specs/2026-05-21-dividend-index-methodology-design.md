# 中证红利投资框架（METHODOLOGY.md）设计 spec

> 日期: 2026-05-21 · 目标指数: 中证红利 000922（纯红利 / 高股息价值风格） · 形态: 沿用 bot7 `METHODOLOGY.md` 的「研究视角投资框架 + 仓位管理方法论」

## 1. 背景与目标

项目里每只 bot 用一份 `METHODOLOGY.md` 作为该指数的「研究 + 仓位心法」，喂给 LLM agent 在 World 回测里逐日做择时/仓位决策。现有 bot7/bot11 是双创指数框架（高弹性成长贝塔，趋势 > 估值）。

本 spec 要产出一份**中证红利**的等价框架，以「专业研究员」视角写成。核心难点：**红利与双创几乎是镜像的**，照搬双创心法会让 agent 套错逻辑。这份框架最大的价值就是把每一处「与双创的倒置」显式写出来。

## 2. 关键决策（已与用户对齐）

- **目标**: 中证红利 000922，纯红利、高股息价值风格（非红利低波、非红利质量）。重仓银行/煤炭/交运/电力/石油石化/钢铁。
- **结构（方案 A）**: 镜像 bot7 外壳——「核心认知 + 视角群 + 仓位管理方法论 + 核心一句」，但视角群按红利重排（估值锚领衔、利率/宏观独立成主轴、趋势降级并入风格），并在每节显式标注「与双创相反之处」。
- **风格约定（沿用 bot7）**:
  - 开篇声明「这是研究视角，不是执行手册」。
  - 以**定性原则**为主，硬数字只作少量「心理阈值 / 默认值」示意，可被研判覆盖（与现有 bot 风格一致）。
  - 结尾保留「数据缺失时用 `research_search` 兜底查最近 365 日历史」。

## 3. 红利 vs 双创 倒置对照（本框架的灵魂）

| 维度 | 双创（bot7） | 中证红利（本框架） |
|---|---|---|
| 资产性质 | 成长贝塔、高弹性高波动 | 价值贝塔、低弹性低波动 |
| 周期类型 | 产业景气周期 3–4 年 | 利率周期 + 成长/价值风格周期 |
| 估值锚 | 禁止用 PE 分位做均值回归 | **股息率分位可做均值回归**（DPS 粘性、风格稳定） |
| 核心宏观驱动 | 流动性/产业催化 | **10 年国债收益率 / 股债性价比** |
| 择时主轴 | 趋势 / 时序动量 | **均值回归（股息率箱体）** 为主，趋势弱化 |
| 仓位哲学 | 大开大合、空仓不愧疚 | **底仓长持 + 围绕股息率锚做波段**，中枢更高 |
| 最大的坑 | 因「估值贵」踏空整轮上涨 | **价值陷阱 + 利率反转 + 风格切换** |
| 离场主因 | 趋势破位 / 流动性收紧 | 价值陷阱坐实 / 利率上行 / 风格切向成长 |

## 4. 内容蓝图（逐节）

### 核心认知
- 红利 = 高股息价值贝塔（银行/煤炭/交运/电力/石油石化），不是成长、不是宽基。三特性：低弹性、低波动、双周期（利率 + 风格）。
- 驱动排序：**利率/股债性价比 > 风格周期 > 成分股盈利质量 > 政策催化**。
- 单列「与双创的四点根本倒置」：① 股息率是可均值回归的真锚，允许高股息吸、低股息抛；② 趋势权重低、均值回归权重高；③ 适合底仓长持而非大开大合；④ 最大的坑是价值陷阱与利率反转，不是踏空。
- 研究三问（红利版）：现在便宜吗（股息率分位 / 股债利差）？风格和利率在不在红利这边？盈利分红的根基稳不稳（有没有价值陷阱）？

### 一、估值视角（红利的核心，与双创完全相反）
- 股息率分位**可以**做均值回归择时——DPS 分红粘性强、风格样本稳定，分位有效。显式对照双创「禁用分位」。
- **股债性价比 = 中证红利股息率 − 10 年国债收益率**：最重要的估值锚；利差走阔（如历史高分位）→ 强力看多，利差收敛 → 警惕。
- PB-ROE 看银行/周期成分（低 PB + 稳定 ROE + 高分红 = 安全垫）。
- **价值陷阱三重验证**：① 盈利/自由现金流是否可持续；② 分红率 payout 是否可持续、是否一次性高分红；③ 行业是否结构性衰退。高股息率必须区分「被低估」还是「盈利要崩」。
- 默认阈值示意（可被研判覆盖）：股息率分位 > ~70–75% 偏便宜可加；< ~25–30% 偏贵可减。

### 二、利率与宏观视角（红利专属主轴，替代双创的趋势主轴）
- 10 年国债收益率方向 = 红利相对吸引力的总开关：下行 → 资产荒 / 险资 / 长线资金配置利好；上行 → 吸引力下降、资金回流成长。
- 经济预期双刃：弱复苏/通缩利好「防御」属性，但若导致成分股盈利恶化（银行息差收窄、煤价暴跌）则是价值陷阱来源。

### 三、风格与趋势视角
- 红利 vs 成长（双创）**跷跷板**：用红利/沪深300、红利/双创 比值趋势判断风格在不在红利这边。
- 价值因子**拥挤度**：交易过度拥挤、ETF 爆量流入、一致预期过强 → 回调风险。
- 趋势框架**弱化版**：200 日均线只用于避开风格崩塌，不作主轴；主用均值回归（股息率箱体）。

### 四、景气度视角（红利版，盯成分股根基而非单一产业链）
维度表：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 利率环境 | 10 年期国债收益率（下行利好） | 领先 / 核心 |
| 股债性价比 | 红利股息率 − 10 年国债 利差 | 核心估值锚 |
| 风格 | 红利/成长相对强弱、价值因子拥挤度 | 同步 / 情绪 |
| 盈利质量 | 成分股 ROE 稳定性、自由现金流、分红可持续 | 防价值陷阱 |
| 资金 | 险资 / ETF 份额 / 北向 对红利配置 | 增量资金 |
| 政策 | 中特估 / 新国九条 / 分红与市值管理考核 | 催化 |
| 行业基本面 | 银行净息差、煤价、电价市场化、地产链 | 成分股盈利根基 |

看的是趋势一致性（多维同向），盈利质量与利率是主线，资金/政策是边际。

### 五、风险管理视角
- 四大风险：**价值陷阱、利率上行、风格切换、拥挤度**。
- 低波动 → 硬止损阈值可比双创宽松；但风格切换 / 价值陷阱才是真杀伤，不靠价格止损能躲。
- 红利作「底仓 / 防御腿」的仓位哲学：可容忍较高仓位长期持有，在利率拐头向上 + 风格切向成长时降仓。

### 六、证伪视角（红利版）
触发任一须重新评估持仓（触发 ≠ 立即清仓，但看多论据已不成立）：
- **利率证伪**：10 年国债收益率持续大幅上行（资产荒逻辑反转）。
- **风格证伪**：红利相对成长持续大幅跑输 N 个月（风格切换确认）。
- **盈利分红证伪**：核心成分（银行/煤炭）盈利恶化、分红率下调或暂停 → 价值陷阱坐实。
- **拥挤证伪**：股息率分位极低 + 拥挤度极高 + ETF 爆量流入（一致繁荣顶部）。
- **趋势证伪（弱化）**：跌破 200 日均线且 X 月未收回。

### 仓位管理方法论（红利版，与双创逐条对照）
- **唯一信仰（改写）**：超额来自「便宜时（高股息分位 / 利差走阔）重仓拿住吃股息复利 + 拥挤 / 利率反转 / 风格切换时降仓」；红利的活儿是在风格站在自己这边时拿满，在风格/利率反转时果断撤。
- **与双创的核心倒置清单**：估值锚允许使用、底仓长持、仓位中枢更高、步长可中等（不必大开大合）。
- **股息率箱体高吸低抛**：高股息分位区重仓、低分位区减仓（与双创禁令相反）。
- **风格防御腿思维**：红利在组合里可作为成长腿的对冲/防御。
- **止盈止损**：仍用趋势 + 回撤，但阈值更宽；**价值陷阱 / 利率反转为离场主因**，而非单纯价格回撤。
- **回撤控仓**：盯自己净值，风格崩塌期大幅降仓。
- **成本意识**：换手天然低、成本友好；但仍有申购费 + 指增 7 日内 1.5% 早赎惩罚，避免无意义 round-trip。
- **核心一句**（红利版收尾）。
