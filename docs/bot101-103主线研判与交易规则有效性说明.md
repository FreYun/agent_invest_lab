# bot101/102/103 主线研判与交易规则有效性说明

整理日期：2026-07-29

## 文档目的

本文用于向领导说明多基金投资三个 bot（bot101、bot102、bot103）中“主线研判”和“交易规则”两项功能的有效性。

三个 bot 都属于多指数权益基金配置：

| bot | 风险定位 | 组合表达 |
|---|---|---|
| bot101 | 高风险进攻型 | 主线明确时集中到最强 2-4 个权益指数，追求收益弹性 |
| bot102 | 中风险平衡型 | 宽基核心仓 + 主线增强仓 + 现金 |
| bot103 | 低风险防守型 | 防守核心仓 + 小比例确认主线 + 高现金 |

两项功能的关系是：**主线研判解决“买什么方向”，交易规则解决“怎么买、买多少、什么时候纠错”。** 只有两者同时生效，bot 的输出才不是单纯观点，而是可复盘、可约束、可执行的投资闭环。

## 一、主线研判

### 1. 生效方式

主线研判不是由 bot 临场主观判断，而是作为每日决策的前置管线生效。

每日流程中，bot 先用 `market-context` 判断市场风险状态，再用 `market-mainline` 读取 v5 主线计划，输出当前 regime、top15 主线板块、核心/卫星组合、基金匹配结果；随后由 `mainline-rotation` 判断是否维持、切换或退出主线。

主线研判必须输出明确结论：

| 输出项 | 作用 |
|---|---|
| `risk_state` | 判断今天是否允许权益进攻 |
| `market_regime` | 判断趋势环境是 uptrend、range 还是 downtrend |
| 主线类别 | 归入科技、新能源、医药、消费、金融、周期、制造、基建地产、全市场等口径 |
| 主线确信度 | 强 / 中 / 弱 / 无 |
| 主线板块 | 具体板块代码，如 BK1106.DC 创新药、BK1163.DC 可控核聚变 |
| 可投基金池 | 通过“成分重叠 × 净值相关”双测度筛出的基金载体 |
| 证伪条件 | 主线失效、拥挤、资金流出或趋势破坏时的退出依据 |

这里的关键机制有三层：

| 机制 | 说明 |
|---|---|
| regime 层 | 先判断“该不该找主线”。有主线则抱主线，无主线则退宽基，防御时退红利或现金 |
| 主线识别层 | 用动量、资金、景气/叙事、持续性、扩散度、拥挤度共同确认，避免只追单日涨幅 |
| 基金映射层 | 用板块成分和基金跟踪指数成分重叠度、板块收益和基金净值相关性匹配基金，避免只靠基金名称选品 |

### 2. 有效范围

主线研判适用于 bot101、bot102、bot103 的多基金权益配置和行业轮动，但三个 bot 的落地力度不同。

| bot | 主线研判如何使用 |
|---|---|
| bot101 | 主线明确且趋势向上时，作为主攻方向，可以提高总仓位并集中配置 |
| bot102 | 主线明确时必须开增强仓，但增强仓不能超过宽基核心仓 |
| bot103 | 主线只作为卫星仓候选；弱主线不开仓，强/中主线也要经过更严格确认 |

该功能最适合有持续产业主线的权益市场；在无主线、震荡或风险偏好下降时，它不会强行选择主题，而是引导组合退回宽基、防守核心或现金。

### 3. 具体案例

**案例 A：2026-05-06，半导体/芯片被识别为新主线，持有后获得正收益。**

在 `dash-2026-06-17T01-35-03` 这轮 bot101 回测中，2026-05-06 的 `mainline_rotation` 将半导体/芯片识别为新卫星主线：BK1036.DC 半导体动量 rank 1、站上 MA60、连续进入 top5 达 3 日。基金映射层选择 512480 半导体ETF国联安作为载体，原因是它与半导体主线的成分重叠 97.2%、净值相关 0.96、β=0.97，规模约 199 亿。

## 二、交易规则

### 1. 生效方式

交易规则负责把主线研判翻译为真实仓位和真实订单。它不是“建议”，而是每日下单前的硬约束。

核心规则包括：

| 规则 | 作用 |
|---|---|
| 单次调仓最小步长 20% | 避免 2%-5% 的碎片化交易 |
| 先审旧仓，再买新仓 | 避免每天像空仓一样重新选一遍 |
| 7 日内 round-trip 克制 | 避免申赎费和短期反复交易损耗 |
| 新候选至少多赢 2 项才允许替换 | 避免因为短期排名波动频繁换仓 |
| 主线失效先降增强仓 | 区分主题风险和组合整体风险 |
| 回撤闸门优先级高于单一主线 | 账户风险超过阈值时先降仓 |
| belief 与仓位方向一致 | 避免“嘴上看多、仓位空仓”的执行偏差 |

三个 bot 的交易规则会根据风险偏好分化：

| bot | 交易规则侧重点 |
|---|---|
| bot101 | 强主线 + uptrend 时允许 80%-100% 高仓；但主线证伪、情绪过热或账户回撤触发时要快速降风险 |
| bot102 | 核心仓是收益底盘；判出中等以上主线必须有主线增强仓，但增强仓不得超过宽基核心仓 |
| bot103 | 看不清就轻仓或空仓；主题只能小卫星；估值和情绪过热时优先降仓 |

### 2. 有效范围

交易规则覆盖 bot101/102/103 的买入、卖出、仓位上限、仓位下限、回撤控制、止盈止损、再入场和持仓复核。

在组合层面，它解决三类问题：

| 问题 | 交易规则的处理方式 |
|---|---|
| 看对主线但不敢买 | bot102 设置“判出中等以上主线必须建仓”的硬规则 |
| 主线仓失控变成孤注一掷 | bot102 设置“增强仓不得超过核心仓”的硬上限 |
| 防守动作变成长期踏空 | 卖出必须写清楚加回条件，情绪或估值风险解除后按 20% 步长恢复 |

### 3. 具体案例

**案例 A：bot102 判出主线后必须补齐主线仓。**

2025-06-09，v5 主线报告识别 BK1163 可控核聚变为动量 rank#1 主线板块，且连续进入 top5 达 12 日、站上 MA60。159628 是其代理载体，净值相关 0.80。

当时 bot102 的增强仓只覆盖创新药和减肥药，缺少可控核聚变，违反“判出主线必须有主线仓”的规则。因此 bot102 买入 159628，补齐第三条主线仓。

这个案例说明：交易规则能把“识别到主线”强制落到实际持仓，避免 bot 只写观点、不下单。

**案例 B：bot102 增强仓超过核心仓后自动修复。**

2025-06-16，bot102 的增强仓合计约 59.9%，超过核心仓约 40.1%，违反“增强仓不得超过宽基核心仓”的硬上限。系统执行卖出 159628，卖出后增强仓降至约 25.9%，低于核心仓。

这说明交易规则不仅能促使 bot 买入主线，也能防止主线仓失控，保证中风险 bot 不退化成高风险集中押注。

**案例 C：bot103 过热降仓，证伪后再加回。**

2025-06-23，bot103 看到双情绪因子过热、沪深300估值偏贵，虽然趋势未破，但按低风险规则将沪深300仓位从 40% 降到约 20%。

2025-06-30，原先的过热减仓逻辑被证伪：情绪因子回落到中性，沪深300仍站稳 MA60、MA120、MA200，仓位建议回升。bot103 按最小 20% 步长把仓位从 20% 加回 40%。

这说明低风险规则不是永久空仓，而是“风险升高先降仓，风险解除再恢复”，能同时控制回撤和减少踏空。

**案例 D：bot101 半导体主线中先加仓、后按环境切换降仓。**

2026-05-06，bot101 确认半导体/芯片为新主线后，卖出不再属于主线组合的医药载体，并买入 512480 半导体ETF国联安；2026-05-11 在 recovery+risk_on 延续、情绪冰点出现后继续加仓。到 2026-06-08，`market_context` 从 easing 切换为 range，规则要求目标仓位从 80%-100% 降到 40%-60%，因此先减半 512480；2026-06-15，range+neutral 继续约束总仓位，清仓半导体卫星。

这说明交易规则不是“看对后一直拿”，而是把主线观点放进市场环境和仓位上限里管理：强主线时敢加，环境变弱时也能按规则收回风险。该轮 512480 实际仓位扣费后约 +6.5%；账户净值在确认日至退出确认日上涨约 +17.8%，但这是包含通信/CPO核心仓的组合整体收益，其中 2026-05-07 通信/CPO持仓合计约 79.7%，不能直接归因于 512480 单一标的。


**案例 E：bot101 每日样本外运行中的近期减仓情况。**

这部分使用 `world/runtime/runs/oos-bot101-daily` 的每日样本外运行结果，观察区间为 2026-06-11 至 2026-07-28。它说明 bot101 的交易规则不是只在回测中生效，而是在每日样本外运行中也能把“主线变化、组合重构、回撤闸门”落成真实减仓动作。

两次主要减仓动作可以这样汇报：

| 日期 | 动作 | 触发规则 | 结果 |
|---|---|---|---|
| 2026-07-01 | 卖出 159546、159732、159773、020840、013811 | v5 月度组合重构：旧卫星跌出卫星池或不再是最优载体；半导体链取代部分旧科技卫星；已有浮盈先兑现 | 159546 浮盈 +32.64%、159732 浮盈 +24.09%、159773 浮盈 +11.45%、020840 浮盈 +11.36%、013811 浮盈 +4.22%；总仓从约 85% 降到约 50% 附近，保留通信核心仓 |
| 2026-07-20 | 卖出 007818 通信设备和 008888 芯片 | 日度 `mainline_rotation` 报告剔除 BK1128.DC CPO 概念，原因是连续 3 日破 MA60；同时 `risk_off` 环境和账户回撤约 -15% 触发 defensive review | 通信/CPO核心仓清空，半导体卫星也只保留 007301、019633 两个底仓；总仓压到 0-10% 目标区间 |
| 2026-07-28 | 不买不卖 | 半导体/芯片仍是强主线，但账户最大回撤 -15.92%，总仓位约 4.65%-4.74%，已在 defensive review 目标区间 | 不追加强主线仓位，只保留种子仓位等待风险修复 |

这里的有效性不在于“每次都能卖在最高点”，而在于规则能区分三类不同场景：

| 场景 | bot101 的处理 | 有效性 |
|---|---|---|
| 主线仍强但旧卫星不再最优 | 7 月 1 日卖出旧卫星，把半导体链替换进组合，但只建底仓 | 避免旧仓惯性持有，同时避免估值极贵时一次性追满 |
| 核心主线出现硬证伪 | 7 月 20 日 CPO 连续 3 日破 MA60，清掉通信核心仓 | 说明“通信/CPO曾经是主线”不等于永久持有，趋势证伪后能退出 |
| 账户回撤超过闸门 | 7 月 20 日后把总仓压到约 4%-5%，7 月 28 日仍不加仓 | 回撤闸门优先级高于主线观点，防止强主线判断演变成无约束补仓 |

因此，最近的减仓可以概括为：**7 月 1 日是主线内部组合重构和获利了结，7 月 20 日是主线证伪叠加账户风控的防御降仓，7 月 28 日是防御区间内的低仓观察。** 这正好体现交易规则的有效性：看对主线时敢上仓，但主线失效、技术破位、账户回撤触发时，也能把仓位从约 85% 快速压到 5%以内。

## 三、对领导汇报时的结论口径

可以概括为三句话：

1. **主线研判提高了方向选择的确定性。** 它把“今天市场在交易什么”拆成 regime、主线、确信度、板块、基金载体五个可复盘字段，避免 bot 凭印象追热点。
2. **交易规则提高了执行一致性。** 它把研究结论强制翻译成仓位动作，解决“看对不买、买了乱换、仓位失控、风险来了不降”的问题。
3. **三个 bot 的差异不是判断体系不同，而是风险预算不同。** 同一主线下，101 进攻、102 平衡、103 防守，这让系统既能验证策略有效性，也能服务不同风险偏好的账户。
