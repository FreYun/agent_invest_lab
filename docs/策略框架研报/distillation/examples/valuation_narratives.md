# 招商证券 A 股策略周报「估值段固定套话」样例库

> §数据·估值 段是招商体里格式最刚性的段落，3 份样本几乎一字不差。
> 本文只抽段落结构里"以句为单位"复用度极高的模板句。

## 整体表述（3 份样本雷打不动）

**开篇（大盘）：**
> 本周整体 A 股估值水平{direction}。截至{date}收盘，万得全 A 指数 PE(TTM) 为{pe1}，处于历史估值水平（10 年以来）的{pct1}%分位数。创业板指 PE(TTM){cyb_dir}{cyb_delta}至{cyb_pe}，处于历史估值水平的{cyb_pct}%分位数。代表大盘股的沪深 300 指数 PE(TTM){hs_dir}{hs_delta}至{hs_pe}，处于历史估值水平的{hs_pct}%分位数。代表中小盘股的中证 500 指数 PE(TTM){zz_dir}{zz_delta}至{zz_pe}，处于历史估值水平的{zz_pct}%分位数。

**结尾（行业前五）：**
> 截至{date}收盘，一级行业估值排名前五的行业分别是{ind_1}、{ind_2}、{ind_3}、{ind_4}、{ind_5}。

## 行业估值单行模板（重复 5-6 次）

> {行业}指数估值{dir}{delta}至{pe}，处于{pct}%历史分位；

**样本高频组合（近三周 3 份雷同）**：
- 电子 → PE 分位 98-99%，"接近历史极值"
- 建筑材料 → PE/PS 分位均 >95%
- 综合 → PE 分位 ~97%
- 机械设备 → PB 分位 >85%
- 国防军工 → PS/PB 分位 >78%
- 通信 → PB 分位 >97%
- 食品饮料 → PE/PS 分位 <2%，"接近历史底部"
- 非银金融 → PE/PS 分位 <2%
- 美容护理 → PE 分位 <20%
- 社会服务 → PE 分位 <30%

## 分位数定性话术（可直接引用 rules/valuation_rules.yaml 的 verdict）

- {pct}%分位数 ≥ 98%：**接近历史极值区间**
- {pct}%分位数 ∈ [80%, 98%)：**偏高位，估值消化压力上升**
- {pct}%分位数 ∈ [30%, 80%)：**位于历史中枢附近**
- {pct}%分位数 ∈ [5%, 30%)：**偏低位，有一定安全边际**
- {pct}%分位数 < 5%：**接近历史底部，估值支撑充分**
