# 半导体设备指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少，每次操作至少是20%仓位。


## 核心认知

半导体设备 = 半导体产业链**最上游的"卖铲人"**，但它的贝塔被**晶圆厂资本开支（capex）周期**放大。四个特性决定玩法：

- **超高弹性**：设备是周期的**杠杆端**——下游晶圆厂赚钱→扩产→下设备订单，所以设备业绩弹性比芯片本身还猛，牛市涨幅常是双创的再上一档。
- **超高波动 + 事件跳空**：单一上游赛道，叠加制裁 / 出口管制 / 大基金等政策事件，单日可能跳空 ±10% 。
- **强 capex 周期**：营收滞后晶圆厂资本开支决策约 **2–4 个季度**——周期顶 / 底设备都比芯片更夸张（晶圆厂砍单时设备先挨刀，扩产时设备最先吃到）。
- **极致集中**：指数 ≈ 少数几只权重龙头（北方华创 / 中微 / 拓荆 / 盛美 / 华海清科 / 中科飞测等）的篮子，**指数走势高度由龙头基本面与订单驱动**，必须穿透到龙头看，不能只当宽基。

宏观与产业环境 > 仓位择时 > 选品；**周期 + 国产替代渗透**思维 > 长期持有。

## 一、估值视角（定性预警，绝非择时扳机）

对半导体设备这种**早周期 + 高弹性 + 单一上游**的成长指数，**禁止用 PE/PB 历史分位做均值回归（低吸高抛）择时**，比双创更禁。原因更强：

- **分母极不稳**：设备厂盈利波动巨大、周期底部可亏损，E 坍塌会让 PE 冲到天上——在底部喊你跑。
- **样本太短**：龙头上市才几年，指数发布更短，"分位"几乎等于全样本，没有稳定"正常区间"。
- **牛市必然高分位 + 按订单估值**：国产替代牛市的本质就是估值 re-rating，市场常切换到 PS / 在手订单 / 远期利润口径，静态 PE 分位完全失效。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——"趋势 > 估值"是单向过滤器，只否决"因为贵所以走 / 不进"，不是无视估值的通行证。** 择时主轴整个交给趋势 / 动量框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；不能拿来把极端估值读数一票否决。极端读数仍是要认真对待的定性信号。

所以估值在这里只做两件**定性预警**的事（不是择时扳机）：
- **极端泡沫预警（顶）**：出现全民进场信号（散户开户创新高、设备主题新基金爆发、研报"非理性繁荣"、连卖水卖铲都被爆炒）→ 当成"趋势可能见顶"的提示，配合趋势框架减仓。
- **周期反转预警（底）**：出现 **capex 拐点 / 设备订单见底回升 / 合同负债与存货回升 / 晶圆厂重启扩产**等周期反转证据（呼应核心认知④）→ 记为**潜在筑底观察**（持久观察态，写进记忆续到明天），**不立刻抄底**；趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是周期 / 订单证据，不是低 PE 分位（分位对它是噪音）。

**真正的"价值标尺"是国产化率**：国产设备渗透率离天花板还远（很多卡脖子环节国产化率仍是个位数到二三成）→ 成长空间未尽，趋势里值得重仓；某环节国产化率已逼近饱和 → 该环节增量逻辑减弱，重仓需更谨慎。国产化率管"值不值得在趋势里重仓"，不用来抄底或择时。

## 二、趋势视角

趋势研判别只看一根均线，多角度交叉验证。

- **方向锚**：指数 vs 200 日均线（收盘价即可算均线 / 时序动量，足够）。
- **量能确认（板块代理）**：指数取不到量 → 用 `sector_factor` 风险分（成交集中度）/ `sector_factor_detail` 拥挤度代理"有没有量配合"：突破时板块拥挤度同步抬升 = 有量；拥挤度不跟 = 可疑假突破（设备题材脉冲多，无量突破极易是假的）。
- **波动率（板块代理）**：指数算不出 ATR（无高 / 低）→ 用**收盘价滚动波动率** + `sector_factor_detail` 的 **MA200 乖离率**代理；波动 / 乖离骤增即降仓信号。
- **事件跳空甄别**：制裁 / 政策 / 大基金消息常造成跳空，要分清这是**逻辑级利好（国产替代加速）**还是**情绪脉冲**——前者可顺势，后者易回补缺口。

震荡市里均线信号反复假突破，要转箱体思维而非趋势思维——识别标准与状态切换纪律见「仓位管理方法论 · 先识状态」。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

## 三、景气度视角（半导体设备专属：capex 周期为母变量）

半导体设备的景气有**清晰的产业链传导链条**，按性质分四类，别用滞后指标做择时（具体取数见上「取数」节）：

- **领先（母变量）**：晶圆厂 capex 指引 → 全球设备出货（SEMI / 北美 billings / 日本）→ 设备厂新签订单 / 在手订单 / 中标，再到财务端的合同负债 / 存货——这四档同向时信号最强。
- **滞后（确认而非择时）**：设备厂营收 / 净利 YoY + 一致预期修正，跟随领先端，不当择时锚。
- **结构 / 上限**：国产化率与中标份额——决定空间天花板与重仓信心，不决定主趋势的开关。
- **事件驱动**：大基金各期投向 / 出口管制 / 实体清单 / 国家专项——跳空催化，事件级单独评估。

- **capex 是母变量**：晶圆厂资本开支决策领先设备营收约 2–4 个季度。**看 capex 指引的方向，不看设备厂当期营收**（营收是滞后确认，等它转向就晚了）。
- **合同负债 / 存货本是最好用的财务领先指标**：理想上合同负债 / 存货回升领先营收 1–2 季反映订单热度；实际**合同负债无字段、存货只有周转率**（`financial_quality` 营运能力），绝对的备货 / 在手只能从 `research_search` 研报读 → 这条退化为**定性线索，不进定量打分**。可定量的盈利端改盯 `stock_alpha` 一致预期修正 + `financial_quality` 成长（龙头加权）。
- **国产化率是结构 / 上限指标**：它不构成主趋势的择时，但决定"这一轮渗透还有多少空间"，是重仓信心的来源。
- **看的是趋势一致性**：capex、设备出货、订单、合同负债几个领先维度同向运动信号最强；与滞后的盈利端背离时，**以领先端为准**（盈利会跟上）。

## 四、国产替代 / 政策视角（与全球景气正交的独立信号）

这是半导体设备区别于双创的**专属维度**，且与全球半导体周期**半解耦**：

- **结构性 alpha**：国产替代 / 自主可控是这条赛道的长期主线，国产化率从低位往上爬是**穿越全球周期的独立动力**——哪怕全球设备景气平淡，国产份额提升也能撑住国产设备厂业绩。
- **反直觉信号（最承重）**：海外制裁 / 出口管制 / 实体清单**收紧** → 短期利空全球半导体景气，但**加速国产替代**（晶圆厂被迫转单给国产）→ 对国产设备指数常是**上行催化**。看到制裁新闻先问：它打的是"全球景气"还是"国产份额"？方向可能与直觉相反。
- **政策 / 大基金事件**：国家集成电路产业基金（大基金）各期投向、国家专项、扩产补贴等是**真金白银的需求注入**，是事件级催化；要跟踪资金落地节奏，而非停留在消息面。
- **双刃**：制裁也可能**直接卡国产设备厂自身的零部件 / 材料供应**（如高端零部件被断供）——这是国产替代逻辑的下行风险，要与"利好转单"同时评估，别只看一面。

## 五、风险管理视角

收益越大、估值越极端、越靠单一催化，仓位越保守——这是原则，不是公式。半导体设备波动更大、事件更密，纪律不可省：

- **capex 周期兑现**：晶圆厂 capex 指引上修、设备订单饱满 → 让利润奔跑；capex 指引下修 / 晶圆厂砍单 / 扩产推迟 → 主动兑现得更积极（设备是周期杠杆端，下行最先最猛）。
- **估值收缩 / 切口径预警**：当市场从"按订单 / PS 估值"切回"按 PE 估值"时，本身就是降温信号，不必等价格回撤。
- **事件前减敞口**：重大政策 / 制裁 / 大基金窗口前后跳空风险大，单押方向胜率低；事件不明朗时降仓或观望，别赌跳空方向。
- **硬止损（更严）**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑（capex 上行 / 国产替代加速）大概率已破。

## 六、证伪视角（对称化）

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。须**对称**——既列看多被证伪（下行），也留意看空被证伪（上行）。

- **景气证伪（下行）**：主要晶圆厂 capex 指引连续下修 / 公开砍单 / 扩产推迟；全球设备出货额连续数月同比负增长。
- **订单证伪（下行）**：设备厂在手订单、合同负债连续 2 季下滑；中标份额停滞或被海外回夺。
- **逻辑证伪（下行，最关键）**：国产替代逻辑被破坏——制裁实质性放松导致海外设备回流、或关键环节国产份额长期停滞、或国产厂自身被断供卡死。
- **趋势证伪（下行）**：跌破 200 日均线且 1 月未收回，但是你应该根据当时的市场环境修正你的指标。
- **估值证伪（下行）**：极端泡沫读数 + 全民进场信号 + 营收 / 订单增速已显著回落。
- **看空被证伪（上行 veto-watch）**：制裁收紧驱动转单加速；capex 重启上行；合同负债 / 存货见底回升；国产化率出现非线性跳升——这些会成为"看空"判断的上行风险。

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。** 亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向；亏损端**风险厌恶**、浮盈端**适度风险偏好**；把**回撤**当第一风险指标而非收益。
- 半导体设备是**极致弹性 + 极致波动 + 事件密集**的单一上游赛道，单指数策略夏普的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是 capex 转向 / 制裁误伤 / 系统性风险来时少亏。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成事前枷锁。
- 但该在场时别缺席：趋势明确向上（capex 上行 + 国产替代加速 + 价格多头）时还空着 = 踏空。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"约束的是**下行**：该满仓时不满仓（踏空）同样不及格，生存纪律绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**：
  - **趋势市**：均线（MA60 / MA120）单边排列、斜率明显，价格沿一侧运行。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10–15%（设备波动大，箱体更宽）内来回 + 箱体反复假突破。
  - **过渡待定**：信号不清、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空（capex 下行 / 趋势破位）就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量 / 事件驱动突破即交接。

**状态要有粘性——不是一天震荡、一天趋势地翻**：
- **跨日继承**：每天先取昨日状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"。
- **进入 / 切换都要确认，不看单日**：单日跳空（设备最常见）、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向。向上→在场吃 Beta；转下→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：设备本就高波动，越平静越敢拿，振幅骤增 / 大涨大跌时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- **事件叠加**：政策 / 制裁 / 大基金窗口前，主动把仓位调到"能扛跳空"的档；逻辑级利好（国产替代加速）确认后再顺势加。
- 叠加：**方向（动量）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10–15% + 近数月明显高低点定上下沿。划不出清晰箱体 = 按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间噪音一律不接。
- **轻仓、绝不重仓赌箱体**：半导体设备箱体随时可能因一条政策 / 制裁消息向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位。宁可仓位轻，不可方向赌死。
- **不追假突破**：设备题材脉冲多、假突破最凶，别每根都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量 / 事件驱动突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体并站稳数日（或出现逻辑级催化如制裁加码 / 大基金落地），震荡假设作废 → 立刻切回趋势市骨架按时序动量重定方向和仓位；别在突破后还反向 fade。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体不明确时，正确动作往往是**不动**——等突破给方向。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长20%；2%–5% 那种微调毫无意义。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称。**新手恰好做反：跌时慢慢割肉、涨时浅尝辄止；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / capex 转向 / 趋势转空 → 一把清到位，可以直接到 0**：半导体设备跌得比双创更快更狠（杠杆端 + 事件砸盘），下跌往往加速，等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。设备的高赔率组合是 **capex 上行 + 国产替代加速 + 价格放量突破 + 龙头订单饱满** 多因素共振，此时一把上重仓乃至满仓；信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；宁可错过，不可做错**——但"宁可错过，不可做错"只约束低赔率情形；高赔率时真正的"做错"恰恰是轻仓，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶、亏损时风险偏好，结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情；且设备主升浪回调动辄 20–30%（比双创更深），用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，该放宽口径主动加；本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**：**保本止损**（浮盈到位把离场线抬到成本价，本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降）、**分批止盈**（涨到位分批减，剩余用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难：-20% 需 +25%、-33% 需 +50%、-50% 需翻倍、-70% 需 +233%。半导体设备单边跌起来很容易摸到深水区，这条更命。
- **账户级闸门优先于任何单笔逻辑**：从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。这是"防止一错再错"的总开关。
- **这是事后闸门，不是事前上限**：它只在净值从峰值真的回撤后才收紧。**严禁反着用**——不得拿"指数假如跌 X%"的假想情景，在动手前反推出静态仓位天花板。事前该上多大只由赔率决定（第四条）；回撤控仓只在事后说话。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免同一标的 7 日内来回 round-trip。好在你做的都是大动作，频率天然不高。
- 半导体设备波动大、诱惑多（天天有题材），更要克制别被脉冲诱发高频折腾。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、capex 周期、国产替代逻辑、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 制裁是利空快跑 | 制裁逼出国产替代是利好 | 先分清打的是**全球景气**还是**国产份额**：卡晶圆厂逼转单看 B，断国产厂自身供应看 A |
| 估值太贵该减 | 趋势向上无视估值 | 上升趋势 + capex 在上行看 B，趋势破位 / capex 转下时极端读数当定性预警 |
| 盈利下滑该谨慎 | 盈利见底是底部信号 | 看 **capex 与订单方向**：领先端仍向下看 A，领先端见底回升（盈利滞后）看 B |
| 别人恐惧我贪婪 | 顺势不接下跌 | 系统性恐慌但 capex / 国产逻辑没坏看 A，单边下跌途中看 B |
| 强者恒强 | 物极必反 | 趋势中段 + 订单饱满看 A，极端情绪 + 量价背离 + 全民进场看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 量价背离 / capex 见顶看 B |

> **核心一句**：半导体设备—用 **capex 周期 + 国产化率** 判景气与空间、用**趋势 / 动量**择时、用**大开大合 + 压最大回撤**做仓位；吃该吃的 Beta、躲 capex 下行与制裁误伤、空仓不愧疚、按优势大小下注、进出算成本，靠压回撤把夏普做上去。
