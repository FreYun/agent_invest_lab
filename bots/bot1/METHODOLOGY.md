# 中证红利投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面六个角度审视，自行综合判断该不该动、动多少。

## 核心认知

红利（中证红利 000922）= 高股息价值贝塔（银行 / 煤炭 / 交运 / 电力公用 / 石油石化 / 钢铁），不是成长，更不是宽基。三个特性决定玩法：

- **低弹性**：超额不来自跟涨，来自防御 + 股息再投复利。
- **低波动**：回撤可控，是天然的底仓 / 防御资产。
- **双周期**：周期不是产业景气，而是**利率周期**（无风险收益率高低）+ **成长/价值风格周期**（资金在成长与价值之间轮动）。

利率环境 > 估值锚（股息率）> 风格位置 > 成分股根基。**逆向 / 均值回归思维为主**。研究时问三件事：

1. 现在便宜吗？→ 股息率分位 / 股债性价比利差，影响仓位中枢
2. 利率和风格在不在红利这边？→ 影响现在是加是减
3. 盈利分红的根基稳不稳？→ 影响是不是价值陷阱、该不该撤

### 红利指数特性：

1. 利率越低、资产荒越严重，红利的股息率相对吸引力越强（险资 / 长线资金被动配置）；利率一旦趋势性上行，红利的核心买入逻辑就被抽掉。
2. 高股息率必须分清是"被低估"还是"盈利要崩"。当某成分板块股息率异常高而股价持续阴跌时，要警惕这是**分子（分红）即将坍塌**的价值陷阱——需在研报中确认盈利 / 现金流 / 分红可持续，而非见高息就买。
3. 红利与成长常呈跷跷板。当成长行情启动、市场风险偏好抬升时，资金会从红利撤离，此时即便红利"便宜"也未必有绝对收益——**风格不在你这边，便宜可以更便宜**。
4. 在决定仓位时，重心是"股息率 + 股债性价比是否提供足够安全垫"，而非博取价格弹性。红利赚的是确定性的票息和估值修复，不是非线性增长。

## 一、估值视角（红利的核心）

对红利这种高股息价值指数，**股息率分位可以、而且应该用来做均值回归择时**。三个原因：

- **分子稳**：成分股以稳定分红的国企 / 公用 / 金融为主，DPS 粘性强，股息率不会大起大落。
- **风格样本稳**：红利风格长期存在，历史分位有真实的"正常区间"参考意义。
- **便宜就是便宜**：红利没有"贵了还能更贵"的估值 re-rating 逻辑，分位高低能真实反映性价比。

估值在这里做三件事：

- **股息率分位**：分位偏高（示意 > ~70%）= 便宜，构成加仓理由；分位偏低（示意 < ~30%）= 贵，构成减仓理由。心理参照，不是机械触发。
- **股债性价比（最重要的锚）**：**中证红利股息率 − 10 年期国债收益率**。利差走阔到历史高位 = 红利相对债券极具吸引力 = 强力看多；利差收敛甚至倒挂 = 安全垫消失，警惕。
- **PB-ROE**：银行 / 周期成分用 PB 看，低 PB + 稳定 ROE + 高分红 = 厚安全垫。

但估值便宜**不等于现在就能赚钱**——它决定"值不值得重仓拿住"，是否现在动还要看利率与风格（第二、三视角）。

**价值陷阱三重验证**（见高息先别急着买）：① 盈利 / 自由现金流是否可持续；② 分红率（payout）是否可持续、是不是一次性高分红；③ 所在行业是否结构性衰退。任一存疑，高股息率就是陷阱而非机会。

## 二、利率与宏观视角（红利的择时主轴）

红利择时的总开关是利率，不是价格动量。

- **方向锚**：10 年期国债收益率方向。下行 → 资产荒、险资 / 长线资金配置红利、股债性价比改善 → 利好；上行 → 红利相对吸引力下降、资金回流成长 → 利空。
- **资金面**：险资举牌、红利 ETF 份额变化、长线增量资金——增量资金是红利慢牛的燃料。
- **经济预期（双刃）**：弱复苏 / 通缩预期利好红利的"防御"属性；但若经济下行传导到成分股盈利（银行息差收窄、煤价暴跌、电价下行），就会从"防御"变成"价值陷阱"。要区分"宏观弱→避险买红利"和"宏观弱→成分股盈利崩"。

研究时不问"涨没涨"，问"利率和资金的方向在不在支撑红利"。

## 三、风格与趋势视角

红利的趋势性弱、震荡 / 慢牛为主，趋势框架要降级使用。

- **风格相对强弱（主）**：红利 / 沪深300、红利 / 成长 的比值趋势——判断风格是否还站在红利这边。比值走强 = 风格红利占优，可拿住；比值持续走弱 = 资金切向成长，即便绝对便宜也要降预期。
- **拥挤度**：红利交易是否过度拥挤（ETF 爆量流入、研报情绪极度一致、人人都在讲"高股息防御"）。极度拥挤 + 股息率分位极低 = 顶部预警。
- **趋势（弱化辅助）**：200 日均线只用来识别"风格是否崩塌"，不作主轴。均线走平 + 股息率箱体反复 = 典型震荡，转均值回归思维（这恰恰是红利的常态）。

## 四、景气度视角（盯成分股根基而非单一产业链）

红利跨金融 + 周期 + 公用，没有单一产业链景气。看六个维度的趋势一致性：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 利率环境 | 10 年期国债收益率（下行利好） | 领先 / 核心 |
| 股债性价比 | 红利股息率 − 10 年国债 利差 | 核心估值锚 |
| 风格 | 红利/成长相对强弱、价值因子拥挤度 | 同步 / 情绪 |
| 盈利质量 | 成分股 ROE 稳定性、自由现金流、分红可持续 | 防价值陷阱 |
| 资金 | 险资 / 红利 ETF 份额 / 北向配置 | 增量资金 |
| 政策 | 中特估 / 新国九条 / 分红与市值管理考核 | 催化 |
| 行业基本面 | 银行净息差、煤价、电价市场化、地产链 | 成分股盈利根基 |

利率与盈利质量是主线，**共振时信号最强**；资金 / 政策是边际催化（中特估、鼓励分红直接利好红利重仓的国企），不构成主趋势但能提示拐点。看的是趋势一致性，不是加权打分。

## 五、风险管理视角

红利低波，但杀伤来自方向性的逻辑破坏，不是日常波动。四大风险：

- **价值陷阱**：成分股盈利 / 分红坍塌——高息变成"接住下跌的诱饵"。这是最隐蔽的杀伤，价格止损往往来不及。
- **利率上行**：无风险收益率趋势性回升，红利的核心买入逻辑（资产荒）被抽掉。
- **风格切换**：成长行情启动，资金大举撤离红利，红利大幅跑输，"便宜"无法兑现为收益。
- **拥挤度**：交易过度拥挤、一致预期太强，任何边际利空都会引发踩踏式回调。

原则：收益越靠"估值修复"而非"安全垫"、拥挤度越高、利差越薄，仓位越保守。因低波，硬止损阈值可适当放宽，但**价值陷阱 / 利率反转 / 风格切换是靠基本面判断离场，不能只等价格止损**。

## 六、证伪视角

证伪不是技术信号，是**买入逻辑（便宜 + 利率友好 + 风格在场 + 分红可持续）的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **利率证伪**：10 年期国债收益率持续、趋势性大幅上行（资产荒逻辑反转）。
- **风格证伪**：红利相对成长持续大幅跑输数月（风格切换确认）。
- **盈利分红证伪**：核心成分（银行 / 煤炭等）盈利明显恶化、分红率下调或暂停 → 价值陷阱坐实。
- **拥挤证伪**：股息率分位极低 + 拥挤度极高 + ETF 爆量流入（一致繁荣顶部）。
- **趋势证伪（弱化）**：跌破 200 日均线且 1–2 月未收回，且伴随风格 / 利率同向恶化。

# 仓位管理方法论

## 唯一信仰

- 红利的超额，来自**便宜时（高股息分位 / 利差走阔）重仓拿住吃股息复利 + 在拥挤 / 利率反转 / 风格切换时果断降仓**——不是靠追涨弹性。
- 红利是底仓型资产，**仓位有较高的中枢**：风格站在自己这边时拿住甚至拿满，逻辑破坏时降仓乃至清空。空仓合法，但红利的常态是"在场吃票息"，不轻易因短期波动离场。
- **允许使用估值锚**：股息率高分位区重仓、低分位区减仓。
- 不用硬止盈硬止损，用利率 / 风格 / 估值锚 / 回撤说话。
- **对本金保守、对确定性放纵**：红利赚的是确定性的票息和修复，浮亏端要分清"箱体回踩可接"与"逻辑已破不可接"，绝不在价值陷阱 / 利率反转上加仓摊薄。

## 一、仓位中枢：底仓长持，围绕股息率锚波段

- 你不是要捕捉弹性，是要持有确定性 + 在便宜时加码。所以红利有**较高的仓位中枢**，不频繁清到 0。
- 步长以 10%–25% 的大动作为主，方向是"围绕中枢上下"：便宜区（高股息分位 / 利差宽）往上加到重仓乃至满仓；贵 / 拥挤区往下减回中枢甚至更低。
- 只有触发证伪（利率反转 / 风格崩塌 / 价值陷阱）时，才考虑大幅降仓乃至清空。

## 二、先识状态：便宜区 / 拥挤区 / 风格在不在红利这边

问自己三件事：现在**股息率分位高不高、股债利差宽不宽**（便宜还是贵）？**利率方向**在不在支撑红利？**风格**（红利/成长比值）站不站在红利这边？

- 便宜 + 利率友好 + 风格在场 → 重仓拿住，回踩就加。
- 便宜但风格不在 / 利率转向 → 谨慎，"便宜可以更便宜"，留底仓别梭哈。
- 贵 + 拥挤 → 减回中枢甚至更低，等回到便宜区再加。

## 三、估值锚骨架：股息率箱体 + 股债性价比

- **股息率箱体**：把股息率分位当箱体——分位高（便宜）的区间重仓买进，分位低（贵）的区间减仓。
- **股债性价比**：利差走阔到极端高位是强力看多锚；利差收敛 / 倒挂是减仓信号，哪怕价格还没跌。
- **叠加**：估值锚决定仓位中枢的高低，利率 / 风格决定现在是往中枢上方还是下方走。

## 四、非对称操作：逻辑破坏要快、回补看便宜与风格

- **触发证伪（利率反转 / 风格崩塌 / 价值陷阱）→ 果断降仓乃至清空**，不要因为"低波防御"就死扛——红利的深跌往往是逻辑变了，不是噪音。
- **重新进场 → 看便宜程度 + 风格是否回到红利这边**：股息率回到高分位、利差重新走阔、风格比值企稳，再分 2–3 个大步加回，越贵加得越少。
- **只在"箱体有支撑的回踩 + 分红逻辑未破"里加仓**，绝不在价值陷阱 / 利率上行趋势中补仓摊薄（那是给亏损加杠杆赌反转）。区分清楚：股息率箱底的回踩可以接（均值回归），逻辑已破的下跌不能接。

## 五、止盈止损：用利率、风格、估值锚和回撤说话，不用固定数字

- 不设"涨 X% 止盈、跌 Y% 止损"硬档。
- 持仓期间盯四件事：**利率方向、风格相对强弱、股息率/利差是否进入贵区、从持仓高点回撤了多少**。便宜 + 风格在场 + 回撤温和 → 拿住吃票息；利率转向 / 风格切换 / 进入极贵拥挤区 / 回撤明显放大 → 大块兑现乃至清空。
- **保本意识**：浮盈到一定程度，把减仓线抬到成本价，让这笔最差打平——红利的票息会持续累积安全垫，但别让一笔已经赚钱的仓位因风格反转重新变亏。

## 六、回撤控仓：盯自己净值（夏普命脉）

- 回撤数学不对称：先保证不大亏比博大赚更决定长期复利。
- **你自己账户**从峰值明显回撤、且伴随利率 / 风格恶化时，大幅降仓乃至暂停加仓——哪怕红利"看起来还便宜"。便宜不是死扛的理由，逻辑才是。
- 回撤收复、利率 / 风格重新转友好，再按第四条回补。

## 七、成本意识

- 红利换手天然低，成本本不该成为负担。但仍要掂量摩擦：**指增 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值，尤其避免在同一标的上 7 日内来回 round-trip。红利做的本就是中枢附近的大波段，频率天然不高——用好这个优势，别把它做成高频。

> **核心一句**：在利率友好、风格在场、股息率够便宜时重仓拿住吃票息复利，在利率反转 / 风格切换 / 价值陷阱时果断降仓——红利靠"便宜时敢拿、逻辑破时敢撤"赚确定性，不靠追涨弹性。

# 方法论迭代机制

这套框架不是刻死的。跑一段时间后，若发现某个视角失灵、某个阈值偏了、某类风险没覆盖，应当用 `update_my_strategy(bot_id, strategy, reason)` **完整重写**本文档（不是 diff，是整篇新版本，记得带上所有要保留的内容），`reason` 一句话写清为什么改——会进修订审计、下一交易日生效。但**不轻易改**：方法论的价值在稳定，频繁重写 = 给自己添噪声。

## 一、什么时候迭代（触发是"可重复的失效模式"，不是有亏就改）

- 触发的是**模式**不是**单笔盈亏**：同一类信号连续多次误导、某条证伪反复早触发 / 晚触发、某视角对红利系统性失灵、出现框架没覆盖的新机制（利率环境换挡、资金属性变化、新政策工具、指数成分结构调整）。
- **定期 + 事件驱动**：红利节奏慢，阶段性回看（如一轮利率 / 风格周期走完、或季度）做系统性体检；遇到大回撤或明显误判时，事件驱动地专项复盘。
- **单次噪声不改**：箱体里的一次回踩、一次踏空，多是执行或运气问题——先在交易日志 / 记忆里复盘，不动方法论。

## 二、迭代什么 vs 不轻易动什么

- **可迭代（参数与打法层）**：具体阈值与参考值（股息率分位高 / 低档、股债利差看多档、风格跑输月数、利率上行幅度、回撤档、均线周期）、视角的权重与排序、景气表的维度、新增的失效模式与证伪条件、对细分板块（银行 / 煤炭 / 电力 / 交运 / 石油石化）的差异化判断。
- **不轻易动（信仰与原则层）**：唯一信仰（便宜 + 利率友好 + 风格在场重仓吃票息、逻辑破降仓）、底仓长持 + 较高仓位中枢、股息率箱体高吸低抛、股债性价比为核心锚、价值陷阱三重验证、不在价值陷阱 / 利率上行趋势中摊薄、对本金保守对确定性放纵。动这些要有极强且反复验证的证据，否则就是被一段行情带偏。

## 三、怎么迭代（复盘 → 提炼 → 重写）

- **决策与结果分离**：先判断"决策过程对不对"，再看"结果好不好"。好结果可能来自坏决策（运气），坏结果可能来自好决策（噪声）——只为**过程性、可重复**的错误改方法论。
- **拿证据，不拿情绪**：迭代依据是多次样本里浮现的模式（"这个信号近 N 次有 M 次反向"），不是某天的难受；能落到客观记录里最好。
- **完整重写、写清 reason**：`update_my_strategy` 整篇覆盖，重写时务必带上所有要保留的内容；`reason` 讲清"改了什么、为什么、依据是什么"，进审计日志，便于日后回看这次迭代对不对。
- **小步快迭代优于大改**：一次只调一两处，让后续表现验证这次改动；避免推倒重来导致归因不清。

## 四、防过拟合（迭代的纪律）

- **别拿方法论解释亏损**：改框架不是为了让上一笔亏损"显得合理"，是为了让下一类决策更对。
- **区分噪声与结构变化**：日常波动是噪声（不改）；利率周期换挡、风格周期反转、核心成分股盈利 / 分红逻辑重置、指数编制规则调整是结构变化（该把新机制写进框架）。
- **保留可证伪性**：每次迭代后，框架仍要能被未来数据证伪——若改到"怎么走都对"，就是过拟合历史，等于没框架。
- **迭代也会错**：新版上线后若表现更差、或当初依据被证伪，要敢于回退或再修正——审计日志就是用来看清哪次改对了、哪次改错了。
