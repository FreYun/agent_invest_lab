# 市场行情判断 /market-context

**触发词**: `/market-context`、"今天市场怎么样"、"判断一下行情"、"当前市场环境"
**执行时机**: 每日组合巡检第一步，在 market-mainline / 选品 / 仓位决策之前
**定位**: 端到端一步——把宏观与股债金行情交叉验证成一个**权益市场总体判断**（行情类型 + 置信度 + risk_state）。**不识别主线、不选基金、不给仓位**——那些交 market-mainline / fund-screening / METHODOLOGY。

---

## 0. 核心原则（铁律）

**判断的目标是识别"当前市场由什么力量主导"，而不是简单判断涨跌。**

任何单一指标都不能直接推出行情结论。必须同时观察六组证据并相互验证：

```
宏观环境 + 资产价格表现 + 资金行为 + 风险偏好 + 反向证据 + 持续性
```

- PMI 上行 ≠ 复苏成立；利率下行 ≠ 宽松成立；A股上涨 ≠ 风险偏好全面修复；黄金上涨 ≠ 通胀行情成立。
- 只有当**宏观环境、资产价格、资金行为相互验证**时，才能给较高置信度。
- 这是**当前 bot 自己的市场观点**：同样的数据，不同人设(风险偏好、能力圈、对信号的敏感度)可能给出不同判断——这是设计意图。

## 1. 输出口径：五类行情 + Stress 态

行情判断**只在五类中选择**（外加一个优先级更高的独立极端状态 Stress）：

| 行情类型 | code | 主导力量 | 典型价格特征 | 权益 stance（risk_state）|
|---|---|---|---|---|
| 复苏 | `recovery` | 增长改善、盈利修复、风险偏好回升 | A股走强，周期/成长修复，债承压或中性 | **进攻 risk_on** |
| 宽松 | `easing` | 流动性宽松、利率下行、政策托底 | 债走强，A股估值有修复空间 | **偏多 risk_on**（估值驱动，重质量）|
| 通缩/衰退 | `deflation` | 需求弱、价格弱、盈利承压 | 债偏强，A股承压，现金价值上升 | **防守 risk_off** |
| 通胀/再通胀 | `inflation` | 商品/PPI/通胀预期上行 | 黄金/商品偏强，债承压 | **中性偏谨慎 neutral**（权益非主角，高通胀压估值）|
| 震荡 | `range` | 指标分化、轮动快、趋势不持续 | 各类资产缺乏持续方向，信号冲突多 | **中性 neutral**（不强行进攻）|
| **Stress 态** | `stress` | 战争/制裁/关税/政策突发/流动性冲击/汇率剧烈波动 | 常规信号失效，股债金可能同时失效 | **risk_off**（保命优先，暂停加仓）|

> Stress 不是第六类行情，而是**优先级更高的独立状态**——一旦触发，先走风险识别流程（§6），不强行套常规分类。

## 2. 判断流程（5 步交叉验证）

**Step 0｜先查极端事件**：若出现 §6 的重大冲击，直接进入 Stress 判断，跳过常规流程。

**Step 1｜宏观四维**：判断每一维当前状态，并找出"**哪个变量最能解释当前资产价格**"（不是简单平均）。

| 维度 | 要回答的问题 | 取值 |
|---|---|---|
| 增长 | 改善 / 弱复苏 / 放缓 / 衰退 | improving / weak_recovery / slowing / contracting |
| 通胀 | 上行 / 回落 / 通缩压力 | rising / falling / deflation |
| 流动性 | 宽松 / 中性 / 收紧 | easy / neutral / tight |
| 风险偏好 | risk-on / risk-off / 震荡 | risk_on / risk_off / mixed |

**Step 2｜价格验证（硬规则）**：宏观初判**必须**经股/债/金/商品价格验证。

| 若初判 | 需要看到的价格验证 |
|---|---|
| 复苏 | A股走强、周期/成长修复、商品偏强、债不再明显走强 |
| 宽松 | 债走强、利率下行、A股估值端修复 |
| 通缩/衰退 | 债走强、A股偏弱、商品偏弱 |
| 通胀/再通胀 | 黄金或商品走强、债承压 |
| 震荡 | 多资产轮动快、趋势不持续、缺乏一致方向 |

> **硬规则**：① 无价格验证 → **最高只能给中置信度**；② 价格与宏观明显背离 → 必须降置信度；③ 资产价格相互冲突 → **优先判 `range`**。

**Step 3｜反向证据检查**：反向强于支持 → 降置信度。

| 初判 | 典型反向证据 |
|---|---|
| 复苏 | 盈利仍弱、信用未改善、债仍强、A股上涨缺成交配合 |
| 宽松 | 利率下行但风险资产不修复、信用扩张不起、资金空转 |
| 通缩/衰退 | 政策强托底、风险资产持续上涨、商品反弹 |
| 通胀/再通胀 | 需求不足、商品上涨不可持续、实际利率上行 |
| 震荡 | 某类资产持续走强且获宏观+资金验证（→可能不是震荡）|

**Step 4｜持续性判断**：单日不算行情。看宏观是否连续改善/恶化、价格是否连续验证、资金是否持续同向、相关资产是否同步、能否跨越单日事件扰动。
> **硬规则**：单日涨跌不定义行情；第一次出现的新行情只能给中/低置信度；**连续两期确认后**才可升高置信度。

**Step 5｜输出**：行情类型 + 置信度 + 主导变量一句话 + 权益 stance（落 mem0，见 §5）。

### 判断优先级（冲突时按此裁决）

```
极端风险状态 > 资产价格验证 > 宏观环境 > 资金行为 > 单一指标 > 主观判断
```

- 宏观与价格冲突 → **优先尊重价格**，但降置信度。
- 价格短期剧烈波动但无持续性 → 不过度解读。
- 极端事件已发生 → 优先进入风险识别。

## 3. 数据采集（simworld-data）

数据走 `simworld-data`（市场状态/指数行情/股债性价比/估值/情绪/宏观/商品/资金流/研报）。时间由 proxy 自动注入，bot 不写日期。**建议默认 5 年回看**（支持 `start_date/end_date` 的工具显式传长窗，否则默认窗口太短）。所有工具调完再做交叉验证。

| 服务的维度 | 工具 | 看什么 |
|---|---|---|
| 增长 / 通胀 / 流动性(M2社融) | `macro_data(region="cn", categories=["gdp","pmi","cpi","ppi","m2","social_finance"])` | 增长动能、通胀方向、社融/M2 |
| 流动性(利率) / 价格验证-债 | `bond_yield_curve(curve_type="cn", maturities=["10Y"])` | 10Y 国债方向（利率下行=宽松/债牛）|
| 信用利差(反向证据) | `bond_yield_curve(curve_type="credit") − bond_yield_curve(curve_type="cn")` | 信用利差走阔=风险上升（自算 10Y）|
| 价格验证-股 / 趋势 | `market_index_quote(market="cn", symbols=["000001.SH","000300.SH","399006.SZ"])` | 上证/沪深300/创业板 K 线 → 5/20/60/120/250 日 MA、近 N 日方向 |
| 价格验证-股 / 估值 | `market_index_val(symbols=["000300.SH"])` | 沪深300 PE/PB 百分位（估值水位、股债性价比锚）|
| 价格验证-金 / 商品 | `commodity_market(market_type="spot", symbols=["AU9999"])` | 黄金现货走势（通胀/避险）；必要时加原油/工业金属 |
| 风险偏好 / 情绪 | `option_vix()` ⚠️返回 VIX/GVIX/GVSpread | 隐含波动率 vs 历史区间（高=risk_off）|
| 风险偏好 / 资金量能 | `market_temperature()` ⚠️成交额阈值降级 | 成交额量能档位（萎缩/一般/放量/巨量）|
| 资金行为 | `stock_capital_flow(stock_codes=[...])` ⚠️仅个股级，无市场级北向聚合 | 主力/北向方向（短期信号）|
| 持续性 / 叙事 / 反向证据 | `research_view(view_type="weekly")` 或 `ttjj_research_search(query="A股策略 大势研判", search_type="research", search_days=30)` | 当日策略研报的"大势研判"，验证宏观+价格之外的共识/叙事 |

**数据缺失处理**：某工具超时/为空 → 对应维度写"缺失，按 X 处理"，**不使用该指标、不强行推断**；证据不足整体置信度降级，默认 `range`。

## 4. 置信度与降级规则

### 置信度

| 置信度 | 判断标准 |
|---|---|
| 高 | 宏观、价格验证、资金行为、持续性均成立，反向证据少 |
| 中 | 有部分证据支持，但存在明显冲突 |
| 低 | 证据不足，价格不验证，持续性不足 |
| （震荡）| 多类信号冲突、轮动快、无法确认方向 → 直接判 `range` |

置信度决定下游决策力度：高 = 可作主要依据；中 = 仅作参考；低 = 不应推动明显动作。

### 降级规则（判断不清时必须降级）

| 情况 | 降级动作 |
|---|---|
| 宏观证据冲突 | 降低置信度 |
| 没有价格验证 | 最高只能中置信度 |
| 资产价格互相矛盾 | 判为 `range` |
| 反向证据强 | 降低判断强度 |
| 数据缺失 | 不使用该指标、不强行推断 |
| 单日事件扰动 | 等待持续性确认 |
| 极端事件发生 | 优先进入 Stress 判断 |

## 5. 输出范式（每天 mem0_add 必须落成 categorical）

**模糊判断 ≈ 没判**：必须落到 categorical，不能写"看着像复苏但不太确定"，否则下一日 mem0 拉到一片浆糊。market-mainline / METHODOLOGY 读 mem0 里的 `risk_state` 决定敢不敢上仓。

```
行情类型: 复苏 / 宽松 / 通缩衰退 / 通胀 / 震荡   (code: recovery/easing/deflation/inflation/range)
置信度: 高 / 中 / 低
risk_state(权益 stance): risk_on(进攻) / risk_on(偏多) / neutral / risk_off   ← 给下游"敢不敢上仓"的总环境
主导变量: <一句话——当前哪个变量最能解释资产价格>
宏观四维: 增长=<...> ｜ 通胀=<...> ｜ 流动性=<...> ｜ 风险偏好=<...>
价格验证: 股 √/✗ ｜ 债 √/✗ ｜ 金 √/✗  （是否印证宏观初判；背离则说明）
反向证据: <列举 + 强弱评估>
持续性: <第几期 / 能否跨单日扰动 / 是否连续两期确认>
Stress: 是 / 否   （触发则 risk_state 强制 risk_off）
风险提示: <2-3 条：经济超预期 / 政策变化 / 地缘 / 流动性…>
一句话研判: <定调 + 后市方向，供调仓叙事引用>
```

> 不输出任何目标仓位或配比——仓位由 METHODOLOGY 据 risk_state + 置信度 + market-mainline 主线确信度决定。

## 6. 极端事件（Stress）处理

出现下列重大事件时，**优先判断是否进入 Stress**，而不是强行套常规分类：

> 战争 / 制裁 / 关税冲击 / 重大政策突发 / 汇率快速波动 / 流动性冲击 / 海外市场剧烈波动 / 金融机构风险事件

极端事件下常规宏观与价格信号可能短期失效，优先判断：
- 风险是否已扩散？
- 股票、债券、黄金是否同时失效（避险资产也跌 = 流动性挤兑）？
- 市场是否出现流动性挤兑？
- 是否需要等待进一步确认？

→ Stress 态下 `risk_state=risk_off`，进入安全模式、暂停加仓。

## 7. 与下游的边界

- **上游**：本 skill 是每日第一步，无上游依赖（直接采数据）。
- **下游**：
  - `market-mainline` 读本 skill 的 `risk_state`（敢不敢上仓）后，再判"上在哪条主线 / 哪些板块 / 哪些基金"。
  - `METHODOLOGY` 据 `risk_state` + 置信度 + 主线确信度翻译成目标仓位。
- 本 skill **到"行情类型 + 置信度 + risk_state"为止**——主线识别 / 选基 / 配置都不在本 skill。

## 8. 核心纪律

- 不用单一指标定义行情；
- 不把单日涨跌当成行情变化；
- 不把宏观判断直接等同于资产表现（必须价格验证）；
- 不忽略反向证据；
- 不在价格没有验证时给高置信度；
- 不在震荡行情下强行找方向；
- 数据缺失不强行推断，证据冲突默认 `range`；
- 极端事件下，先判断风险状态（Stress），再判断行情类型；
- 行情判断是**当前 bot 自己的市场观点**，不与其他 bot 同步——人设差异前置体现在"对市场状态的判断本身"。
