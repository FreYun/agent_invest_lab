# 基金主线识别 /fund-mainline

**触发词**: `/fund-mainline`、"面向基金的主线是什么"、"主线落到哪个行业指数"、"基金该配哪条主线"、"主题指数选哪个"
**执行时机**: `market-mainline` 给出当日主线/行业落点之后、`fund-screening` 选载体之前
**定位**: 只回答"哪条主线值得用基金做**中线**配置、落到哪个**可交易的行业/主题指数**、配置档位（超配/标配/低配）"。**不在概念板块/个股层做交易判断、不筛具体基金载体、不给目标仓位。**

> **本 skill 的时间坐标是中线**：判据看月度到季度的趋势与景气，持有与再平衡按月/季节奏。月度以下周期的涨跌波动是噪音，不作为本 skill 的进出依据。

---

## 一、为什么需要本 skill：板块动量信号 ≠ 基金主线

板块动量榜、主线雷达这类 EOD 引擎（`sector_factor` / scout `board_trend`）回答的是"此刻资金在涌向哪些板块"，信号**又快又碎**，对基金中线配置直接用会跑偏。四点差异：

| 维度 | 板块动量原始信号 | 基金主线（本 skill） |
|---|---|---|
| **粒度** | 概念板块（MLCC、被动元件，10~20 只成分的窄板） | 行业/主题指数（有可投 ETF 对标的赛道） |
| **周期** | 月内动量（ret20/ret60、量能放大、成交占比） | 中线（ret120/250、季度相对强弱、数周到数月的趋势） |
| **拥挤含义** | 拥挤+加速 = 资金关注度高 | 拥挤>90 分位 = **减配信号**，不是配置理由 |
| **换手** | 高，板块快轮动 | 低，月/季级，主线趋势稳定才动 |

**实锤（窄板块没有干净基金对标）**：对窄概念板块做"龙头股反查重仓基金"，捞到的多是 <2 亿、跑偏的边角小 ETF——MLCC→创业板科技ETF(1.7亿)、被动元件→创科技ETF(0.39亿)——**绝大多数过不了 fund-screening 的规模门槛**。而升维到行业/主题指数后，对标立刻变干净变大：集成电路制造→科创芯片ETF(386亿)、光模块/CPO→通信ETF(144亿)。**这就是"升维"在本 skill 里是第一步、且不可省的原因。**

## 二、与其它环节的边界（链路定位）

```
market-context   →  risk_state（敢不敢上仓、总仓位档）
market-mainline  →  当日主线(9类) + 行业落点(板块码) + 确信度 + 质地   ← 日级识别
fund-mainline    →  基金主线(主题指数) + 中线确信度 + 配置档 + 可投载体候选   ← 本 skill，中线、面向基金
fund-screening   →  同赛道选载体（跟踪40%/费率35%/规模25%）
METHODOLOGY      →  给这几只基金多少仓位、是否再平衡
```

- **上游**：`market-mainline` 的"行业落点（板块码）+ 质地"是本 skill 的**候选输入**，不是结论——本 skill 要对它做升维、拉长到中线、过中线闸门，可能把 market-mainline 当日认定的"强主线"在基金口径下定成"标配"甚至"观察"（板块当下强 ≠ 中线该重配）。
- **下游**：本 skill 输出"主题指数 + 配置档"后，由 `fund-screening` 在该指数的跟踪基金里选最优 1-3 只载体；再由 METHODOLOGY 定仓位。**选哪只基金不在本 skill。**

## 三、目标口径：主题指数为主

升维落点用**主题/赛道指数**（科创芯片 / 半导体 / 中证通信 / 新能源车 / 创新药 / 消费电子 …），不用概念板块、也不强求申万一级。理由：主题指数与新兴主线最对口、可投 ETF 最丰富。

- **落地工具**：`mcp__simworld_data__sector_index_match(sec_codes=[板块码])` —— PIT 把板块映射到可交易指数/ETF，这是升维的官方桥。
- **可投性校验**：候选主题指数必须能用 `mcp__simworld_data__fund_index_tracking(index_code)` 查到**有规模够的跟踪基金**（≥2 亿 ETF 或 ≥1 亿场外），否则该主线"无干净载体"——走第五节兜底，或向上归并到更宽的主题。
- **申万一级**仅用作"风格/大类"对齐与回测基准（成长 vs 价值、电子 vs 周期），不作为主配置落点。

## 四、三步法

### F0 · 升维降噪：概念板块 → 主题指数

- **判什么**：把窄板块动量卷成主题层强弱，滤掉单板的快轮动噪音。
- **工具与做法**：
  1. `mcp__simworld_data__sector_factor(top_n=25)` 取板块动量榜（市场侧量化底座）。
  2. **同主题组聚合**：把同属一个赛道的多个概念板块（如 半导体/设备/材料/封测/存储/HBM）合成"主题强弱" = 成交占比加权的动量分；看**该主题在榜板块数 + 成交占比合计**，而非单板排名。
  3. `sector_index_match(sec_codes=[组内代表板块])` → 落到可交易主题指数。
- **定档**：
  - 某主题组 **≥3 个子板进榜 top25 + 成交占比合计领先** → 强主线候选（赛道级共振，不是单板拉动）。
  - 仅 1-2 个子板冒头 → 弱候选，多半是单板事件驱动，**基金口径先放观察**。

### F1 · 拉长到中线周期 + 中线质量闸门：定主线确信度

把月内信号换成中线信号，再过五道闸门。**每过一道确信度才稳一档。**

| 闸门 | 工具 | 中线判据（关键：比 market-mainline 拉长一个量级） |
|---|---|---|
| **中线趋势** | `market_index_quote`（主题指数 ret120/250、MA120/250 年线）+ `market_index_val`（PE/PB 分位） | 指数站上 MA120（最好 MA250）、ret120 为正、相对宽基季度超额为正；**月度级别成立才算数** |
| **持续性** | `sector_factor` 多周比对 | 该主题**连续 4 周以上（数周到数月）**在主题强弱榜前列；只靠近一两周冲上来的不算 |
| **资金质地** | `fund_index_subscription_redemption(index_code, 区分个人/机构)` | **机构净申购 + 个人净赎回 = 聪明钱进、质地好（上调）**；个人猛申购+机构赎回 = 散户接盘（降档）。这是基金口径最重的资金证据 |
| **景气/叙事** | `research_search` + `stock_alpha`（龙头一致预期/ROE 趋势） | 中期产业逻辑（政策周期/景气拐点/订单与产能），且需有跨季度的可验证性；研报反复指向同一中线逻辑，而非单一事件 |
| **拥挤度（降配闸）** | `idx_congestion_pctrank(index_code)` | **拥挤>90 分位 → 即便主线真，也强制降一档（超配→标配）**；对基金"真主线+拥挤"= 别此刻重配，等估值/拥挤回到合理区再加 |

### F2 · 正向对标 + 输出配置档

- **正向对标**：对定档后的主题指数，`fund_index_tracking(index_code)` 拉全部跟踪基金 → **交给 `fund-screening`** 选最优 1-3 只载体（本 skill 只给指数和候选池，不打分选基金）。
- **配置档**（本 skill 的最终结论，给 METHODOLOGY 用）：

| 条件 | 配置档 |
|---|---|
| 中线趋势√ + 持续性√（≥4 周）+ 质地非散户 + 拥挤<90 | **超配** |
| 中线趋势√ + 闸门过 2-3 道，但拥挤 80-90 或质地中性 | **标配** |
| 仅候选/单板冒头/拥挤>90/质地散户主导/趋势未上年线 | **低配 / 观察**（先不进基金组合，留雷达） |
| 主线分散、各主题都不占优 | **无基金主线 → 配宽基/红利**（防守，等主线明朗） |

## 五、兜底：新兴主线没有干净对标指数时

有些真主线太新，`fund_index_tracking` 查不到规模够的跟踪基金（如早期"固态电池""玻璃基板"）。两条兜底，按优先级：

1. **向上归并**：归到能投的更宽主题指数（玻璃基板 → 消费电子 / 电子；固态电池 → 新能源车 / 电池），用宽载体捕捉 β，在结论里注明"代理载体、非纯主线"。
2. **成分反查（最后手段）**：复用"龙头股→重仓基金"反查（ttjj `fund_stock_holdings_screen`），但**必须叠加 fund-screening 硬门槛**（规模≥2 亿、成立≥1 年），滤掉边角小 ETF；若反查只剩 <2 亿的小基金，则判定"该主线暂无可投基金载体"，**只在雷达、不进配置**——宁可漏配，不可拿不合格小 ETF 凑数。

## 六、输出范式（每条基金主线落成 categorical）

```
基金主线: <主题/赛道名>
主题指数: <可交易指数名 + 代码>（sector_index_match 落点）
配置档: 超配 / 标配 / 低配·观察 / 无主线·配宽基
中线确信度: 强 / 中 / 弱
闸门: 中线趋势 √/✗(是否上MA120/250) ｜ 持续性 √(连续X周) ｜ 资金质地 机构主导/散户主导/中性 ｜ 景气叙事 √/✗ ｜ 拥挤度 分位XX%(是否>90触发降配)
可投载体候选: <fund_index_tracking 拉到的跟踪基金池，交 fund-screening 选最终 1-3 只>  ← 到候选池为止，不打分
证伪/再平衡: <满足什么就降配——如"该主题连续2周跌出强弱榜前三""跌破MA120""拥挤破95分位""机构转净赎回">
```

**模糊判断 ≈ 没判**：必须落到"主题指数 + 配置档"。不能写"科技看着强"——要写"基金主线=半导体，主题指数=科创芯片(588200族)，配置档=超配，趋势已上年线、拥挤72分位"。

## 七、常见陷阱（反复自检）

1. **拿板块动量榜首当基金主线**：窄板块（MLCC/被动元件）当下动量第一，但成分窄+拥挤0.91+无干净大 ETF → 基金口径应升维到"半导体/电子"且因拥挤降配，不是落到窄板。
2. **越过 fund-screening 直接选基金**：本 skill 只到"主题指数 + 候选池"，谁跟得准/费率低/规模稳是 fund-screening 的事。
3. **拿拥挤当利好**：板块动量里拥挤=资金关注，基金口径拥挤>90=减配。方向对 ≠ 此刻该重配。
4. **用成分反查凑载体**：窄板反查的小 ETF 多不合规；宁可判"无可投载体、只在雷达"，也不拿 <2 亿小基金充数。
5. **被波动带着换手**：基金主线是月/季级。主题指数没连续跌出前列、没跌破 MA120、机构没转赎回，就不要因为一两周动量变化频繁切换。
6. **无主线时硬找主线**：各主题都不占优时，正确答案是"配宽基/红利防守"，不是矮子里拔将军。
