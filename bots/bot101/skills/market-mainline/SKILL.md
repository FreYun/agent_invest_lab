# 市场主线识别 /market-mainline

**触发词**: `/market-mainline`、"今天的主线是什么"、"识别市场主线"、"哪个方向是主线"
**执行时机**: 每日 risk_state（market-context）判定之后、仓位/选品决策之前
**定位**: 只回答"主线是什么、信几分、指向哪些行业"。**不映射到具体 ETF/基金、不给目标仓位**——那是 METHODOLOGY 选品与交易纪律的事。

---

## 一、什么是"主线"

主线 ≠ 今天涨得最多的板块。主线 = **被多个独立维度同时确认、且有持续性的投资方向**。

判断主线只靠一个铁律：**一个真主线必须同时拿到「动量 + 资金 + 景气/叙事」三类独立证据，并扛得住「持续性 + 扩散度 + 拥挤度」三道质量闸门。** 单日异动、单龙头硬拉、纯资金博弈、估值极贵的拥挤交易——都不是主线。

输出粒度**到行业/板块为止**（9 类主题 + 具体板块代码），不下沉到基金。

---

## 二、九类主题口径（与 fund.theme / 可买池主题分布对齐）

所有主线判定必须归到下面 9 类之一，或多类共振（如"新能源,科技"）：

| 类 | 覆盖 |
|---|---|
| 科技 | AI / 半导体 / 计算机 / 通信 / 传媒 / 军工 |
| 新能源 | 锂电 / 光伏 / 新能车 / 绿电 |
| 医药 | 创新药 / 医疗器械 / 中药 |
| 消费 | 白酒 / 食品 / 家电 / 体育 / 农业 |
| 金融 | 银行 / 证券 / 保险 |
| 周期 | 有色 / 钢铁 / 煤炭 / 化工 / 油气 |
| 制造 | 机械 / 工程机械 / 机床 / 机器人 |
| 基建地产 | — |
| 全市场 | 宽基 / 红利 / 风格因子（**无主线时方向在这里**） |

## 三、五层漏斗（每层钉死：判什么 → 用什么工具取什么 → 怎么定档）

顺序固定，逐层收敛。任一层判出"无主线"即可提前结束，输出「无主线」。

### L0 · 环境闸门：今天有没有主线土壤

- **判什么**：板块动量是否集中，还是一锅散沙。
- **工具**：`mcp__simworld_data__sector_factor(top_n=15)` —— 取动量分 top15，按所属主题映射到 9 类。
- **定档**：
  - top15 中 **≥4 个同属一类** → 有强主线土壤，进 L1
  - 集中在 1-2 类但都不足 4 个 → 有弱主线土壤，进 L1
  - **分散到 ≥5 类** → 直接判「无主线」，方向 = 全市场，结束

### L1 · 方向粗筛：成长/价值 × 大小盘

- **判什么**：风格象限，缩小候选范围（防止凭训练惯性盲选宽基）。
- **工具**：`market_index_quote`（宽基趋势 / 相对强弱，至少扫 6 个：沪深300 / 中证500 / 中证1000 / 中证A500 / 中证红利 / 创业板 / 科创50）+ `market_index_val`（PE 分位辅助）。
- **读法**：
  - 创业板 / 科创50 领跑 → 偏成长科技
  - 沪深300 / 中证A500 领跑 → 偏大盘价值 / 风险偏好平稳
  - 中证红利 / 红利低波领跑 → 偏防守
  - 多宽基不分胜负 → 主线可能不在宽基层，看 L2 板块

### L2 · 主题定位：候选主线

- **判什么**：具体哪类主题在走强。
- **工具**：
  - `sector_factor(top_n=15)`（L0 已调，复用）—— 动量分 + 风险分 + 机会分
  - `mcp__simworld_data__sector_market(top_n=15)` —— 日收益率 + PE/PB + **主力净流入**
- **定档**：
  - top15 ≥4 个同类 + 该类主力净流入为正 → **强主线候选**
  - 1-2 类占优 → **弱主线候选**
  - 候选可以是单类，也可以是多类共振（科技+新能源等）

### L3 · 三重独立确认（得分制，主线确信度主要来自这里）

三个维度**独立打分**，每命中一项 +1。这是判断"涨幅是不是真主线"的核心。

| 维度 | 工具 | 命中条件 |
|---|---|---|
| **资金** | `mcp__simworld_data__stock_capital_flow(stock_codes=[主线龙头])` | 龙头主力净流入持续为正 + 北向 / 超大单同向；**严防"价涨量出"**（涨但资金流出 = 拉高出逃，不命中） |
| **景气** | `mcp__simworld_data__stock_alpha`（一致预期 / Barra）+ `stock_financial_quality`（ROE/增速/盈利质量） | 龙头一致预期上修 或 盈利质量改善 |
| **叙事** | `mcp__simworld_data__research_search(query=主线关键词, search_type='research', search_days=7, top_k=10)` + `research_view` | 近 7 天 **≥3 篇**研报反复提及该主线的产业逻辑 |

> 没有资金确认的"涨幅靠前" = 补涨 / 单日异动；没有产业叙事支撑的纯资金博弈 → 确信度下调。

### L4 · 质量闸门：真伪 / 持续性 / 过热

L2-L3 拿到候选后，过三道闸门，**每过一道确信度才稳一档**：

1. **持续性**：近 5 个交易日 **≥3 日**该主线保持板块动量前列（`sector_factor` 多日比对）；只靠单日暴涨贡献的不算。
2. **扩散度**：`mcp__simworld_data__sector_constituents(板块代码)` 看主线内部宽度——是普涨（多只成分共振）还是只有 1-2 只龙头硬拉。普涨才是真主线。配合 `sector_search` 把主线名反查成 BKxxxxxx 板块代码。
3. **拥挤度 / 过热（决定要不要降档）**：
   - `mcp__simworld_data__idx_congestion_pctrank(指数代码)` —— 复合拥挤度 + 历史分位
   - `mcp__simworld_data__sector_factor_detail(板块代码)` —— 把风险分拆成构成因子，看拥挤来源
   - **拥挤度 > 90% 分位 → 主线虽真但已晚，确信度强制降一档**（"真主线 + 拥挤" ≠ 此刻该重仓）

---

## 四、特色维度：聪明钱 vs 散户（判主线"质地"）

主线对应的钱是谁在进，决定它的可持续性。

- **工具**：`mcp__simworld_data__fund_index_subscription_redemption(index_code, 区分个人/机构)`
- **读法**：
  - **机构净申购 + 个人净赎回** → 质地好（聪明钱进场，散户还没反应过来）→ 确信度可上调
  - 个人/机构同向净申购 → 中性，看其它维度
  - **个人猛净申购 + 机构净赎回** → 质地差（散户接盘，机构出货），警惕见顶 → 即便动量强也降档
- **输出字段**：`质地 = 机构主导 / 散户主导 / 中性`

---

## 五、主线综合定档

综合 L3 得分（0-3）、L4 闸门（过几道）、质地，归档：

| 条件 | 主线档位 |
|---|---|
| L3 = 3/3 + L4 三道全过 + 质地非散户主导 | **强主线** |
| L3 ≥ 2/3 + L4 至少过 2 道 | **中主线** |
| L3 = 1/3 或 L4 只过 0-1 道 或 质地散户主导 | **弱主线** |
| L0 判散沙 / 各维度互相矛盾 / 候选 ≤1 步指向 | **无主线**（方向 = 全市场） |

**拥挤度 >90% 分位、或"价涨量出"、或散户主导**，任一成立都强制降一档。

---

## 六、输出范式（每天 mem0_add 必须落成 categorical，不能写"看着像"）

```
主线: <9 类之一 / 多类共振 / 无主线>
确信度: 强 / 中 / 弱 / 无
行业落点: <具体板块代码 BKxxxxxx + 对应行业指数>   ← 用 sector_search / sector_index_match 表达，到行业为止
质地: 机构主导 / 散户主导 / 中性
L3 得分: 资金 X / 景气 X / 叙事 X  （命中打 √）
L4 闸门: 持续性 √/✗ ｜ 扩散度 √/✗ ｜ 拥挤度 分位 XX%（是否 >90 触发降档）
证伪条件: <满足什么就降档或推翻——如"龙头连续 2 日主力净流出""动量跌出 top15""拥挤度破 95%">
```

**模糊判断 ≈ 没判**：必须落到 categorical（"中主线 = 科技，行业落点 = 半导体 BKxxxx"），不能写"像是科技但不太确定"——否则下一日 mem0 拉到一片浆糊。

---

## 七、与其它环节的边界

- **上游**：先有 `market-context` 的 `risk_state`（敢不敢上仓的总环境），再跑本 skill（上在哪条主线）。两者都要落 mem0。
- **下游**：本 skill 输出"主线 + 行业落点"后，交 `fund-mainline` 升维成"面向基金的中线主线（主题指数 + 配置档）"，再由 `fund-screening` 选载体——**升维、选品都不在本 skill 范围内**。
- **证伪**：主线一旦被自己写下的"证伪条件"命中，当天就要在 mem0 里显式降档或推翻，不能拖到"明天再看"。
