# 市场主线方法论对比：券商研报 vs 现有 market-mainline skill

> 生成日期：2026-06-04
> 数据源：ttjj-api `/api/research/search`（`search_type=research`）实抓的近 30 天券商策略/行业配置研报
> 对比对象：[bots/bot101/skills/market-mainline/SKILL.md](SKILL.md)
> 目的：用真实卖方方法论校准 skill，找出已对齐处、缺口、以及该不该改

---

## 0. 一句话结论

研报这两年已经从「**自上而下行业轮动**」整体迁移到「**自下而上主题链 + 行业框架只做风险约束**」；现有 skill 仍停在前者——9 类行业硬聚类 + 五层漏斗收敛。最该补的是 **主题链口径**（一条主线可横跨多个行业类）和 **二阶扩散当进攻线索**（顺产业链找下一个边际受益者），这两条恰好也是下游 `fund-mainline` 升维成主题指数时最吃的输入。

## 2. 现有 skill 方法论速览（被对比对象）

- **口径**：9 类主题硬聚类（科技/新能源/医药/消费/金融/周期/制造/基建地产/全市场），所有主线必须归到其中之一或多类共振。
- **五层漏斗**（顺序固定、逐层收敛）：
  - L0 环境闸门：板块动量是否集中（top15 ≥4 同类 → 有主线土壤）
  - L1 方向粗筛：成长/价值 × 大小盘静态象限
  - L2 主题定位：候选主线（动量 + 主力净流入）
  - L3 三重独立确认：**资金 / 景气 / 叙事**，每命中 +1（0–3 分）
  - L4 三道质量闸门：**持续性 / 扩散度 / 拥挤度**，每过一道确信度稳一档
- **特色维度**：聪明钱 vs 散户（机构/个人申赎分歧）判"质地"。
- **输出**：categorical 强制落档（主线 + 确信度 + 行业落点 + 质地 + L3 得分 + L4 闸门 + 证伪条件）。

## 4. 七大差异详述

### 差异 1 · 行业边界 vs 产业链/主题链（最大分歧）

研报 R6 原文：
> "2023 年以来 A 股市场的主线并非沿着传统一级行业边界展开，而是遵循'AI 产业趋势—关键瓶颈—业绩验证—应用扩散'的跨行业链条……单纯依赖自上而下的行业轮动难以完整捕捉主线收益。"
> "主题投资为主，行业轮动为辅：以主题识别主线，并以行业框架进行风险约束与仓位分配。"

skill 的口径是「所有主线必须归到 9 类之一」「输出粒度到行业/板块为止」——这本质是**自上而下行业轮动**。一条真实 AI 主线会同时横跨 skill 的科技（算力/光模块）+ 新能源（绿电/电力设备）+ 制造（机器人/液冷）+ 周期（新金属/铜）四类，9 类硬聚类会**把同一条主线切成四块**，导致：
- L0 环境闸门误判（"分散到 ≥5 类 → 无主线"，但其实是一条链的多个环节）；
- 行业落点输出失真（只报"科技 = 半导体"，漏掉同链的电力设备/机器人）。

**这是最该改的一条。**

### 差异 2 · 二阶扩散：进攻地图 vs 防伪闸门

研报 R6/R7 把扩散当**前瞻 alpha 来源**：
> "捕捉二阶扩散收益：核心在于顺着主线从上游到下游不断寻找新的边际受益者。例如 AI 行情从大模型、算力、应用扩散到基础设施、新金属、电力设备，再到液冷、绿电、存储、机器人等方向。"

skill 的 L4「扩散度」只用来**验真伪**（普涨才是真主线，龙头硬拉不算），没有回答"扩散到第几环了、下一环是谁"。同样一份扩散数据，研报用来**前瞻进攻**，skill 用来**事后防伪**——这是定位差异，不是数据差异。

### 差异 3 · 风格的时序/极致结构

研报 R2：
> "市场宽度 + 成交额集中度二维框架显示市场风格或未达到极致状态'临界点'……鉴于本轮主线行情尚未进入第五期（共识松动期），可右侧继续持有。"

skill 的 L1 只给静态象限（成长/价值×大小盘），回答不了"这条主线是初期、加速期还是共识松动期"。而时序恰恰决定**该追还是该撤**——同样一条强主线，初期该上、第五期该减。

### 差异 4 · 相对收益 / 绝对收益双线 + 季节性

研报 R2/R4 普遍给两条腿：主线右侧进攻 + "三低资产"（低位/低估值/低拥挤度）左侧防守对冲；并用日历效应（"每年 6 月较高概率超额的行业集中在电子/通信/计算机/军工 + 家电/社服/食饮"）。skill 是单主线输出，无对冲腿、无季节性。（注：对冲腿可能本就该由上游 `大类资产配置Agent投资方法论_v2.0.md` 兜，但 skill 至少该把"主线之外的低拥挤防守方向"作为附带输出提示下游。）

### 差异 5 · 固定等权 vs 财报季动态调权

研报 R3：
> "非财报季时期对五个维度等权打分，而在财报季则给予基本面维度更高权重，并降低市场风格及估值维度的权重。"

skill 的 L3 三维永远各 +1 等权。财报季（4月底、8月底、10月底前后）业绩是硬证据，景气维度该加权；纯主题炒作期叙事该加权。固定等权会在财报季高估纯资金/叙事型"伪主线"。

### 差异 6 · 持续性口径：持续热度 vs 瞬时热度

研报 R6 给了一个可证伪命题：
> "主题的持续时间长度与指数涨跌幅显著正相关，而瞬时热度（打板/单日爆量）则不相关。"

skill 的 L4 持续性 = "近5日≥3日动量前列"，没有区分"持续累积的热度"和"单日脉冲式爆量"。建议把持续性从"天数计数"升级为"持续热度斜率 / 是否瞬时脉冲"的判定。

### 差异 7 · 拥挤度：单指标 vs 温度计

skill 拥挤度只用 `idx_congestion_pctrank` 单指标 + 90% 分位一刀切。研报 R5 用 20 个微观指标分过热/中性/偏冷区间、跟踪区间占比和分位环比。权益侧可用 skill 已有工具组合出迷你温度计：换手率历史分位（`sector_market`）+ 成交额占比 + `idx_congestion_pctrank` + `sector_factor_detail` 风险因子拆解，分区间而非一刀切。

## 5. skill 的特色维度——以及一个要标注的隐患 ⚠️

skill 的「聪明钱 vs 散户（机构/个人申赎分歧）」判质地，是研报里**几乎没人系统化使用**的特色维度，理论上有差异化价值。但是：

> 本项目历史回测记忆 **project_divergence_sr_negative** 明确记录：个人-机构 / 股-债 / 主动-被动 / 联合状态共 5 个申赎分歧因子家族**全挖、全军覆没**，做择时 validation 三关全挂，baseline 已最优。

因此这个"特色维度"在**自己的历史回测里效果存疑**。把它当确信度上调/降档的**硬依据**风险不小。建议：**降级为软信号**（仅作辅助标注，不参与硬定档），或在 skill 里显式注明"该维度未通过本项目回测验证、仅作经验参考"。

## 6. 改进建议（分两批，待确认是否落地）

### 第一批（高优先，触及定位）

1. **主题链口径**：把 9 类硬聚类放宽为"主题链可跨类"。允许一条主线同时标注多个行业类（如"AI 算力链 = 科技+制造+周期"），L0 环境闸门相应改为"按主题链聚合后是否集中"，避免把一条链误判成"分散无主线"。
2. **二阶扩散输出字段**：在输出范式里新增"扩散环节：当前在第 N 环（如算力）/ 下一环候选（如液冷、绿电、存储）"，把扩散从防伪闸门升级为进攻线索——直接喂给下游 `fund-mainline`。
3. **申赎质地降级为软信号**：见 §5。

### 第二批（增强，不触定位）

4. **风格时序**：L1 增加"主线行情走到第几期（初期/加速/共识松动）"的判定，工具用市场宽度（涨家数占比）+ 成交额集中度。
5. **L3 动态权重**：财报季（4/8/10 月底前后）景气维度加权、叙事降权；纯主题期反之。
6. **持续性升级**：L4 持续性区分"持续热度 vs 瞬时脉冲"，而非单纯数天数。
7. **拥挤度温度计**：多指标分区间替代单指标 90% 一刀切。
8. **季节性维度（可选）**：引入日历效应作为弱信号（注意 PIT 合规，只能用历史同月规律，不能用未来）。
