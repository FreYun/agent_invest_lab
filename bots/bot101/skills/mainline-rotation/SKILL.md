# 主线轮动配置 /mainline-rotation

**触发词**: `/mainline-rotation`、"主线组合怎么配"、"主线基金组合"、"今天要不要换主线"
**执行时机**: **每个交易日都评估，但默认持有不动、低换手**——主线不会天天变，所以这是"每天检查有没有触发换仓条件"，不是"每天换一次"，也**不在固定日历日换仓**。核心/卫星状态与各自的"连续天数计数器"用 mem0 跨日持久化。换仓只在 §换仓纪律 的确认条件满足时发生。
**定位**: 组合策略层——**不重复识别主线（那是 market-mainline）、不判总仓位（那是 market-context + METHODOLOGY）**；只回答"此刻该持有哪几条主线、核心/卫星结构、**今天要不要动**"。

> **核心纪律：稳为先**。回测用月度再平衡近似，是为了表达"低换手"；实盘每日运行时**用确认窗口+迟滞带+最小持有期把换手压到月级**，绝不因单日波动来回切。识别准 ≠ 天天调。

> **适用 scope（务必先读）**：本方法基于 **2025 年后**的行情逻辑开发。9·24（2024-09-24）是结构性切换节点，前后市场逻辑不同，**不适用于 2024 及更早**。回测/评价只看 2025-01 起。代价：这是单一 regime 内的 in-sample 结果，超额（v5 +26.8% vs 沪深300）是"在为它设计的行情里有效"，**不是跨 regime 验证，别当承诺**。

## 五层框架总览（自上而下）

| 层 | 解决什么 | 本 skill 做法 |
|---|---|---|
| **第0层 regime** | 现在该不该抱主线 | 沪深300 年线 + 主线集中度 → 抱主线/退宽基/退红利 |
| 第1层 锚 | 选主线靠什么 | 景气×资金×叙事共振为主、动量做确认（治"买在高位"） |
| 第2层 生命周期 | 主线走到第几期 | 加速买龙头/扩散买补涨/拥挤减配/松动退出 |
| 第3层 大主线 vs 题材 | 抱还是快进快出 | 持续性+质地+景气+扩散度 → 核心惯性持有 |
| 第4层 选基金 | 哪只载体 | 交 market-mainline §七 双测度 + fund-screening |

回测验证：v1 龙头(+20%/-8.1%) → v2 扩散(+26.8%/-1.3%) → v3 top3分散(+36.7%/+8.6%) → v4 持续性(+47.2%/+19.2%) → **v5 +regime(+54.8%/+26.8%)**（2025-01~2026-05，超额 vs 沪深300+28.1%）。

## 第0层 · regime 开关（先判环境，再定打法）

两个信号（最少参数、可解释）：
1. **大盘趋势**：`market_index_quote(market='cn', symbols=['000300.SH'])` 取沪深300，算距 **MA120（年线）** 的偏离。
2. **有无主线**：`sector_search(sector_type='industry')` 枚举板块 → `sector_factor(sec_codes=[全部])` 本地取动量 top15 → 按 9 类/产业链组归类 → 看**最大集中度**（某组 ≥4 个进 top15 = 有主线）。

| regime | 条件 | 打法 |
|---|---|---|
| **防御** | 沪深300 跌破年线 -3% | 全退**红利**（中证红利/红利低波 ETF），不碰主线 |
| **抱主线** | 站年线 且 主线集中度 ≥4 | 走下面第1-3层，构建核心+卫星组合 |
| **无主线·宽基** | 站年线 但 主线发散（集中度 <4） | 退**宽基**（沪深300/中证A500 ETF），别精选主线 |

> **regime 切换要确认，不能单日抖动就切**：regime 信号需**连续 ≥5 个交易日**维持新状态，才真正切换打法（防止沪深300 在年线上下反复、主线集中度在 3/4 边界抖动导致来回切防御/进攻）。年线偏离用 ±3% 的**迟滞带**：跌破 -3% 才转防御、要回到 -1% 以上才解除防御（不是一碰年线就翻）。
> ⚠️ "防御→红利"分支是**滞后型趋势滤网**，在 9·24 式 V 反转处会 whipsaw（实测踏空）。2025+ 未触发；跨 regime 实盘须换**领先信号**（两融/北向触底）或改"**只降仓不全切**"。

## 抱主线态 · 第1-3层组合构建

> 所有"连续 X 月"在实盘按**交易日**计，约定 1 月 ≈ 20 交易日。mem0 为每个候选/核心板块记 `{板块码: 状态, in_topK_天数, out_topK_天数, 入选日}`，每日更新计数器。

### 核心仓（大主线，惯性持有）
- **晋升核心**：某主线板块**连续 ≥40 个交易日（≈2 月）在动量 top5 且站上 MA60**（产业趋势在）→ 升核心。靠"连续天数计数器"判定，不是某天突然进 top5 就升。
- **回调不割**（第2层精髓）：核心短期下跌/排名回落，**只要仍站 MA60 就持有，不动**（研报实证：主线均线偏离下穿 -5% 后 T+60 平均 +5.25%）。回调期反而是加仓点，不是离场点。
- **趋势破才换（且要确认）**：核心**收盘跌破 MA60 连续 ≥3 个交易日**（确认趋势破，防单日假摔），**或 连续 ≥20 个交易日跌出 top15**（彻底没了）→ 才剔除。
- **拥挤×基本面双触发退出**（松动函数）：`sector_factor_detail(sec_codes=[核心], win=200)` 拥挤分位 >90 **且** 产业逻辑/景气出现反转证据（research_search + 龙头一致预期下修）→ 减配/撤。**光拥挤不撤、叠加基本面反转才撤**。

### 卫星仓（top3 新兴主线，轮动）
- 候选 = 动量 top3 中不在核心的板块；但**换入要确认**：连续 ≥5 个交易日在 top3 才纳入（防单日冲上来就追）。
- **优先扩散段**（第2层，治追高）：若该板块所属产业链组里龙头已涨透+拥挤，则在同组内挑**刚启动的扩散段**（站上 MA20 + 放量 + ret60 低于龙头 + 未拥挤），而非追涨透龙头。
- 卫星**换出要确认**：连续 ≥5 个交易日跌出 top5 才剔除；且有最小持有期（见 §换仓纪律）。

### 锚（第1层，降低纯动量过拟合）
选核心/卫星时，动量只做"确认它在走"；优先级锚是 **景气（`stock_alpha`/`stock_financial_quality` 龙头一致预期上修/ROE）× 资金（`stock_capital_flow` + 北向/两融持续净流入）× 叙事（`research_search` 研报反复讲同一产业逻辑）三类独立证据共振**。共振强的主线优先。

### 组合与权重
- 持仓 = 核心 + 卫星，**等权**，最多 5 只；**无触发则全部留仓不动**（核心长期留仓 = 低换手、也是回调加仓的载体）。

## 换仓纪律（每日运行、但压到月级换手的关键）

**默认动作 = 不动（hold）。** 每天只做"检查触发条件"，绝大多数交易日的结论应是"维持原组合"。只有下列**确认型**触发才调仓：

| 动作 | 触发（都要确认窗口，非单日） |
|---|---|
| 核心升级 | 连续 ≥40 交易日 top5 + 站 MA60 |
| 核心剔除 | 连续 ≥3 日破 MA60，或 连续 ≥20 日出 top15，或 拥挤>90×基本面反转 |
| 卫星纳入 | 连续 ≥5 日在 top3（且过双测度有可投基金） |
| 卫星剔除 | 连续 ≥5 日跌出 top5 |
| regime 切换 | 信号连续 ≥5 日维持 + 年线 ±3% 迟滞带 |

**三条硬纪律**：
1. **最小持有期**：任何标的纳入后 **≥15 交易日**内不因排名波动剔除（除非破 MA60 这种趋势硬信号）。
2. **冷却期**：标的被剔除后 **≥15 交易日**内不再纳回（防 whipsaw 来回切）。
3. **小变动不调**：组合权重偏离目标 <5%、或仅卫星末位轻微变动，**当日不动**，等下次真触发一起调，避免日度微调累积成高换手。

> 一句话：**主线是月级的事，daily 跑只是为了"早一天发现真的趋势破/真的新主线确立"，不是为了天天微操。** 拿不准就维持原仓。

## 第4层 · 每个持仓板块 → 选基金
对组合里每个板块，交 `market-mainline` §七 **双测度**（`idx_constituents` 指数全成分 ∩ 板块成分 的权重重叠 × `fund_nav` 净值相关，分纯载体/代理/兜底）取 1 只；多只候选时 `fund-screening`（跟踪40/费率35/规模25）精排。优先**场内 ETF**（月度轮动场外联接 0.6%/次的申赎费是大头）。

## 边界（与其它环节）
- **上游**：`market-context`（risk_state 决定总仓位档/敢不敢上）；`market-mainline`（识别主线板块 + §七 基金池）。本 skill **消费**它们的输出，不重复做。
- **本 skill**：第0层 regime 开关 + 第1-3层 核心/卫星组合 + 再平衡纪律。
- **下游**：`fund-screening` 精排载体；**总仓位**由 METHODOLOGY 据 risk_state + 本 skill 的 regime 给定（防御态压权益总仓、抱主线态可上）。

## 诚实警示（写进每次结论）
1. **scope=2025 年后**，单一 regime in-sample，超额不是跨 regime 验证。
2. **regime 防御分支**（趋势滤网）跨 regime 会 whipsaw，实盘须换领先信号或只降仓。
3. **参数未充分调优**（top5/top15/2月/拥挤90/重叠50/相关0.8），需敏感性 + 滚动窗口检验，别钉死。
4. 月度轮动**优先场内 ETF**，控换手成本。
