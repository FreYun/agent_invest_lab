# 指数型基金筛选 /fund-screening

**触发词**: `/fund-screening`、"筛选指数基金"、"这几只 ETF/指数基金哪个好"、"同一个指数选哪只基金"、"指数基金选品"
**执行时机**: market-mainline 锁定主线/赛道、确定要配某个指数之后；选品收敛的最后一步
**定位**: 只回答"给定同赛道候选，谁出局、入围怎么排序"。**不选赛道（选哪个指数是 market-mainline 的事）、不判断现在该不该买（择时是 market-context 的事）、不给目标仓位（配置是 METHODOLOGY 的事）**。输入 = 同赛道指数基金候选池，输出 = 出局名单 + 入围打分排序。

---

## 一、适用范围与边界

- **只筛指数型基金**：普通指数基金、增强指数基金、ETF 及其联接基金。主动权益、债基、货基、QDII 债、商品基金不适用。
- **筛选 ≠ 选赛道**：指数基金的收益主要由**所跟踪的指数**决定，不是基金经理的选股能力。"选哪个指数"（科技 vs 红利 vs 宽基）是 market-mainline 的赛道判断，**不在本 skill**。本 skill 假定赛道已定，只在**跟踪同一指数或同一赛道的若干只基金**之间挑最优载体。
- **核心比什么**：同赛道里，基金之间的真实差异 = **跟得准不准（跟踪质量）+ 长期成本（费率）+ 规模够不够稳（清盘/流动性）**。绝对收益几乎一样（同指数），所以不靠收益排名，靠这三件事。
- **ETF vs 场外（联接/普通指数）口径不同**：规模下限、流动性代理、费率结构有差异，下文凡有差异处分别注明。

## 二、数据边界（只用真实存在的工具）

| 维度 | 主用工具 | 取什么字段 |
|---|---|---|
| 候选池 | `fund_index_tracking` | 查某指数的全部跟踪基金，作为候选输入 |
| 跟踪质量 | `fund_index_return` / `fund_performance` | 多周期**超额收益**（vs 标的指数）、`max_drawdown_pct`、`rank_pct` 同类排名 |
| 费率 | `fund_rate` | 管理费 + 托管费（年持有成本，指数基金的核心差异项）、申购费、赎回费 |
| 规模 | `fund_basic_info` / `get_fund_detail` | `scale`（亿元）、成立时间 `estabdate` |
| 辅助·增强超额 | `fund_index_return` / `fund_style_analysis` | 增强型超额是否稳定、是否靠风格/小盘暴露偷来的"伪超额" |

**没有的工具，别假装有**：当前无 ETF 折溢价、实时成交额、盘口深度工具。**"流动性"只能用 `scale`（规模）作代理**——规模大 = 通常流动性好、清盘风险低，但这是代理不是实测，下结论时如实标注。

**净值红线**：`fund_nav` 原则上不主动调用；跟踪质量用 `fund_index_return`（已是 NAV 派生的超额收益量）即可，不要批量拉净值自己算。`get_fund_detail` 只对最终 1–3 只候选深查。

## 三、流程：硬门槛排除 → 三维加权打分 → 排序入围

1. **第一段·硬门槛（一票否决）**：剔除结构性不合格（要清盘的、没足够跟踪样本的、跟踪质量长期垫底的），不达标直接出局、不进打分。
2. **第二段·三维加权打分（0–100）**：对通过门槛的，按 **跟踪质量 40% / 费率 35% / 规模·流动性 25%** 合成综合分排序。辅助维度（增强超额来源等）不进主分，只做 ±5 微调与质检。

> 为什么费率权重比主动基金高这么多：同一指数的几只基金，绝对收益几乎相同，**长期跑出差距的主因就是费率拖累 + 跟踪偏离**，而费率是 100% 确定、可前瞻的。主动基金里费率只是 tie-breaker，指数基金里费率是主战场之一。

---

## 四、第一段：硬门槛（任一不达标即出局）

| # | 门槛 | ETF | 场外（联接/普通指数） | 理由 |
|---|---|---|---|---|
| 1 | **规模下限** | ≥ 2 亿 | ≥ 1 亿 | 低于此线有清盘风险；ETF 还叠加场内流动性枯竭风险，故下限更高 |
| 2 | **跟踪质量** | 普通型：长期超额显著为负（年化跟踪缺口过大）或同类排名末 30% → 出局；增强型：长期超额为负 → 出局 | 同 | 指数基金的本职就是跟得准；长期跟不住的、增强反而跑输指数的，直接淘汰 |

> **成立时间不设硬门槛**：不因"成立 < 1 年"就一票否决——一只刚成立但规模已上量的主题 ETF（如新主线的首发龙头）不应被年限一刀切挡在外面。成立时间仍是**质检信息**：样本不足 1 年的，跟踪质量维度按"样本不足、暂作观察"处理（见第五节①），既不硬性出局、也不给满分。

> 注意：普通指数基金的超额收益**长期应接近 0、且略微为负**（被费率和现金拖累吃掉一点点）——这是正常的，不是淘汰理由。淘汰的是"缺口大到异常"（如年化偏离明显超过费率能解释的范围）。增强型才要求**稳定正超额**。

被任一门槛淘汰 → 进"出局名单"，注明触发了哪条，**不再进入第二段**。

---

## 五、第二段：三维加权打分

**综合分 = 跟踪质量×0.4 + 费率×0.35 + 规模·流动性×0.25**

### ① 跟踪质量（40%）——跟得准不准，是指数基金的本职

用 `fund_index_return` 的多周期超额收益 + `fund_performance` 判断：

1. **普通指数型**：超额收益**越接近 0、越稳定**越好（小幅负值正常 = 费率拖累）。超额忽正忽负、振幅大 = 跟踪不稳，扣分。看长周期（1y/2y/3y）而非单月。
2. **增强指数型**：要求**长期稳定的正超额**，且**超额波动可控**（信息比率高）。一年暴正、隔年暴负的"伪稳定"要压分。
3. **同类排名一致性**：`rank_pct` 在指数型同类里多周期靠前 > 单期靠前。
4. **回撤贴合**：`max_drawdown_pct` 应与标的指数接近——明显大于指数 = 有额外风险敞口（可能偏离了被动跟踪）。
5. **样本不足（成立 < 1 年）**：跟踪数据不够长、跟踪质量无法稳定评估时，本维度记为"样本不足、暂作观察"，封顶给中档（≤60），不给优档满分；**不因此出局**——年限已不设硬门槛。规模够大、首发龙头的新基可凭规模/费率两维入围，跟踪质量待样本积累再复评。

| 档 | 特征 | 分 |
|---|---|---|
| 优 | 普通型超额贴近 0 且稳 / 增强型长期稳定正超额、信息比率高 | 80–100 |
| 良 | 跟踪基本贴合、偶有小偏离 / 增强超额为正但略波动 | 60–80 |
| 中 | 跟踪偏离略大或超额不稳 / 成立 < 1 年样本不足暂作观察 | 40–60 |
| 差 | 跟踪缺口明显 / 增强长期跑输指数（已多被门槛 2 拦掉） | < 40 |

### ② 费率（35%）——长期跑出差距的主战场

同一指数的几只基金，**费率几乎是长期收益差的最大确定性来源**。

1. **年持有成本（主体）= 管理费 + 托管费**，在**同类指数基金内横比**，越低越高分。
   - 普通指数基金常见 0.15%–0.5%；增强型略高（含主动管理）；宽基 ETF 已有 0.15% 甚至更低的"地板价"产品。
2. **交易摩擦（次要）= 申购费 + 赎回费（场外）**：长期持有影响小，仅提示；ETF 走场内佣金不在此项。

**分档**：同类型内年持有成本最低 1/3 → 80–100；中间 1/3 → 50–80；最高 1/3 → < 50。**费率是同分时的硬决胜项**——跟踪质量相近时，选更便宜的那只。

### ③ 规模·流动性（25%）——够稳就行，不是越大越好但偏大更安全

指数基金/ETF 与主动基金相反：**规模偏大通常更好**（流动性足、跟踪更稳、无清盘风险），不存在主动基金的"规模诅咒"。

| 规模区间 | 含义 | 分 |
|---|---|---|
| **≥ 50 亿** | 龙头规模：流动性最好、跟踪最稳、几乎无清盘风险 | 85–100 |
| 10 亿 – 50 亿 | 稳健：流动性与清盘均无虞 | 70–90 |
| 2 亿 – 10 亿（场外 1–10 亿） | 合格但需关注：规模偏小，留意趋势 | 55–75 |

- **规模趋势**：持续净赎回/缩水 → 减分（可能临近清盘或资金撤离）。
- **流动性仅用规模代理**：无折溢价/成交额工具，结论里写明"以规模代理流动性"。同赛道两只跟踪质量与费率相近时，规模大的那只优先（流动性更安全）。

## 六、辅助维度（不进主分，作 ±5 微调与最终质检）

- **增强型的超额来源**：用 `fund_style_analysis` 看增强超额是不是靠**额外的小盘/风格暴露**偷来的——若是，本质是变相的风格押注、不是稳定的增强能力，超额可持续性存疑，微调向下。来源干净（选股/打新/量化分散）→ 微调向上。
- **基金公司指数产品线**：成熟的指数/ETF 大厂（系统、做市、调仓能力强）跟踪通常更稳 → 微调向上；指数线单薄的小厂产品 → 谨慎。
- **同标的指数 vs 同赛道不同指数**：若候选里混了跟踪**不同指数**的基金（如沪深300 vs 中证A500），先归一到"标的指数代表性"——但选哪个指数是 market-mainline 的赛道判断，本 skill 默认赛道已定，只在"基金载体"层面排序。

辅助只做微调/质检，**不能把三维低分的基金靠"大厂出品"硬拉进来**。

---

## 七、输出范式

每只候选必须落到结构化结论：

- **出局名单**：代码 + 触发门槛（"159xxx：门槛 1，规模 1.1 亿 < 2 亿（ETF），清盘+流动性风险"）
- **入围打分表**：每只 → `跟踪质量分 / 费率分 / 规模分 → 综合分` + 一句话结论
  - 例："510xxx：跟踪 88（超额贴近 0 且稳、回撤贴合指数）/ 费率 90（0.15% 同类地板价）/ 规模 95（420 亿龙头）→ 综合 90，跟得准、最便宜、流动性最好，同赛道首选。"
- **排序**：综合分降序 → 推荐前 N 名 + 理由；同分用**费率**决胜，再同分用**规模**决胜。

**模糊判断 ≈ 没判**——必须落到分数和档位。

---

## 八、常见陷阱（筛选时反复自检）

1. **拿绝对收益排名选指数基金**：同指数的几只基金收益几乎一样，比"谁今年涨得多"是噪音；要比的是**跟踪偏离 + 费率 + 规模**。
2. **增强 ≠ 一定更好**：增强型多收的费率若换不来稳定正超额，反而长期跑输普通指数基金；增强的"超额"若靠风格暴露偷来，是伪超额。
3. **费率幻觉**：跨类型比费率没意义（增强型本就比普通型贵）；只在同类型内横比；但别因便宜就买进跟踪质量差的。
4. **规模过小的流动性陷阱**：ETF 规模太小 = 场内买卖冲击大、易清盘；本框架无盘口工具，规模是唯一可用的流动性代理，宁可偏保守。
5. **越界选赛道**：本 skill 不判断"该买科技还是红利"——那是 market-mainline。若候选混入不同指数，先确认赛道判断已由上游给出，否则退回 market-mainline。

## 与选品链路的对接

- **上游**：`market-mainline` 识主线、选主线板块并产出"主线板块 + 可投基金池"（§七：成分重叠 × 净值相关双测度 + 硬门槛），该基金池即本 skill 的候选池输入。
- **本 skill**：在同赛道候选里筛出"载体最优的 1–3 只指数基金"。
- **下游**：METHODOLOGY 决定这 1–3 只**此刻给多少仓位、是否重仓**——那是择时+配置。

一句话：**market-mainline 选赛道（哪个指数）→ fund-screening 选载体（同指数里哪只基金跟得准、费率低、规模稳）→ METHODOLOGY 决定仓位。** 本 skill 只管中间这一环。
