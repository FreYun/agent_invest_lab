## 一、什么是"主线"，铁律是什么

主线 ≠ 今天涨得最多的板块。主线 = **被多个独立维度同时确认、且有持续性的投资方向**。

判断主线只靠一个铁律：**一个真主线必须同时拿到「动量 + 资金 + 景气/叙事」三类独立证据，并扛得住「持续性 + 扩散度 + 拥挤度」三道质量闸门。** 单日异动、单龙头硬拉、纯资金博弈、估值极贵的拥挤交易——都不是主线。

主线常**跨一级行业**展开（如 AI 算力链横跨电子/通信/电力设备/机械），所以识别同时走**行业**与**主题**两条轨，最终都落到板块代码 BKxxxxxx，并归到 §二 的 9 类。

## 三、工具与因子总表 + 调用铁律

识别全程**只用 `simulated_datetime` 系工具**——proxy 自动注入"世界当前日期 15:00"，bot 不写时间、看不到日期、也不会引入未来函数。

| 用途 | 工具（已核验签名，前缀 `mcp__simworld_data__`） | 取什么字段 |
|---|---|---|
| 枚举/搜板块码 | `sector_search(sector_type='industry'\|'theme'\|'all', keyword?)` | 板块代码 BKxxxxxx + 名称 + 类型 |
| 板块动量/拥挤 | `sector_factor(sec_codes)` | 动量分(240日:普通/夏普/信息比率) + 风险分(越高越拥挤) |
| 拥挤度拆解 | `sector_factor_detail(sec_codes, win=200)` | 成交集中度 + MA200乖离 两子因子 + 历史分位 |
| 板块行情/资金 | `sector_market(sec_codes, start_date?)` | 日收益率 + PE/PB + **主力净流入**（可取区间序列） |
| 板块成分宽度 | `sector_constituents(sec_codes)` | 成分股清单（判普涨 vs 龙头硬拉、取龙头喂个股工具；**§七成分重叠的板块侧**） |
| **指数全成分** | `idx_constituents(index_code)` | 指数【全部成分股 + 权重百分比】（**§七成分重叠的指数侧**；基金跟踪指数的成分） |
| **基金净值** | `fund_nav(fund_codes, start_date, end_date)` | 基金日收益率序列（**§七净值相关用**；start/end 要带横杠 YYYY-MM-DD） |
| 板块↔ETF映射(辅助) | `sector_index_match(sec_codes=[...])` | 板块对应的可交易指数/ETF（名称桥，仅作参考；§七不靠它，靠成分重叠） |
| 市场温度/宽度 | `market_temperature(start_date?)` | 综合分0-100 + 子因子「创新高低」(宽度)「价量偏离」 |
| 宽基趋势/估值/ERP | `market_index_quote(market='cn',symbols)` · `market_index_val(symbols)` · `market_index_gzxjb(symbols)` | 趋势相对强弱 / PE分位 / 股债性价比 |
| 龙头资金 | `stock_capital_flow(stock_codes)` | 主力净流入 + 北向持股 + 超大单 |
| 龙头景气 | `stock_financial_quality` · `stock_alpha` · `stock_events`(stock_codes) | ROE/增速/质量 · 一致预期 · SUE 盈余惊喜 |
| 宏观周期 | `macro_data(region='cn', categories=['ppi','pmi',...])` | 价格/库存/景气周期定位 |
| 叙事 | `research_search(query, search_type='research', top_k)` | 近 N 天研报产业逻辑 |
| 客观第二意见 | `quant_factor()` | `market_retail_contrarian_20_90` 等量化因子(0/0.5/1) |

### ⚠️ 调用铁律（违反必出错）

1. **没有 `top_n` 参数**：`sector_factor` / `sector_market` 必传 `sec_codes`。要"动量前 N"得两步——`sector_search(sector_type='industry')` 枚举全部板块码 → `sector_factor(sec_codes=[全部])` → **本地按动量分降序取前 N**。
2. **拥挤度/成交集中度/低位走板块级 `sector_factor_detail`**。指数级 `idx_turnover_concentration` / `idx_congestion_pctrank` / `idx_ma200_deviation` 用的是 `date`+`securityvarietycode`，proxy 不注入 date、bot 不知日期 → **禁用**。⚠️ 但 `idx_constituents` 用的是 `simulated_datetime`（proxy 会注入）→ **可正常调用**，别误当 idx_* 一并禁掉（§七要用它取指数全成分）。
3. **`fund_index_subscription_redemption` 用 `calc_date`**（proxy 不注入）→ bot 调不动 → 申赎"质地"维降为软参考（§五），客观第二意见改用 `quant_factor`（§四·阶段5）。

## 四、主线识别流水线（阶段 0→5，逐层收敛，任一阶段判"无主线"即提前结束）

### 阶段 0 · 环境闸门：今天有没有主线土壤、大环境是否极致

- **判什么**：① 板块动量是集中还是一锅散沙；② 全市场是普涨扩散还是少数股硬撑、情绪是否过热。
- **工具与算法**：
  - `sector_search(sector_type='industry')` 枚举全部行业板块码 → `sector_factor(sec_codes=[全部行业板块])` → 本地按动量分降序，看 **top15 集中在 §二 的几类**。
  - `market_temperature()` 读综合分 + 「创新高低」(宽度近似) + 「价量偏离」。
- **定档**：
  - top15 **≥4 个同属一类** → 有强主线土壤，进阶段 1。
  - 集中在 1-2 类但都不足 4 个 → 有弱主线土壤，进阶段 1。
  - **动量分散到 ≥5 类**、且无板块明显领先 → 判「无主线」，方向 = 全市场，结束。
  - 旁注：综合分 >80 且「创新高低」转弱 = 情绪过热/宽度收窄，记下来——后续主线确信度不再上调（阶段 4 会用）。

### 阶段 1 · 候选板块定位：动量 × 资金，行业 + 主题双轨

- **判什么**：哪些具体板块在被资金真金白银买入走强（不是纯涨）。
- **工具与算法**：
  - **行业轨**：复用阶段 0 的动量前 15 行业板块，`sector_market(sec_codes=[动量前15])` 取主力净流入。
  - **主题轨**（主线常跨行业）：`sector_search(sector_type='theme', keyword=候选主题名)` 拿主题板块 BK 码 → `sector_market(sec_codes=[多个主题板块])` 横向比日收益 + 主力净流入。
- **定档**：
  - 动量前列 **且** 主力净流入为正 的板块 → **候选主线板块**（行业 BK + 主题 BK 都收进候选集）。
  - 候选集按 §二 归 9 类；可单类，也可多类共振（科技+新能源等）。
  - 候选集为空（涨的都没资金、或资金都在流出）→ 判「无主线」，结束。

### 阶段 2 · 三重独立确认：候选 → 真主线（得分制 0–3）

从候选板块用 `sector_constituents(sec_codes=候选板块)` 取成分股，挑权重靠前的 2-3 只**龙头**，对龙头做三维独立打分，每命中一项 +1：

| 维度 | 工具 | 命中条件 |
|---|---|---|
| **资金** | `stock_capital_flow(stock_codes=[龙头])` | 龙头主力净流入持续为正 + 北向/超大单同向；**严防"价涨量出"**（涨但资金流出 = 拉高出逃，不命中） |
| **景气** | `stock_financial_quality` + `stock_alpha` + `stock_events`(龙头) + `macro_data(region='cn',categories=['ppi','pmi'])` | 龙头盈利质量改善 或 一致预期上修 或 SUE 为正，且所处行业在库存/盈利上行段 |
| **叙事** | `research_search(query=主线关键词, search_type='research', top_k=10)` | 近 7 天 **≥3 篇**研报反复讲该主线的产业逻辑 |

> 没有资金确认的"涨幅靠前" = 补涨/单日异动；没有产业叙事支撑的纯资金博弈 → 确信度下调。

### 阶段 3 · 三道质量闸门：持续性 / 扩散度 / 拥挤度

每过一道，确信度才稳一档：

1. **持续性（持续累积 vs 单日脉冲）**：`sector_factor(sec_codes=[主线板块], start_date=近10交易日)` 取动量分序列 + `sector_market(sec_codes=[主线板块], start_date=近10交易日)` 取主力净流入序列。**近 5 日动量分稳定前列 + 主力净流入多日为正** = 持续型（√）；只靠单日跳升、资金脉冲后转流出 = 瞬时（✗，不命中）。研报实证：主题持续时间与涨幅正相关、瞬时热度不相关。
2. **扩散度（普涨 vs 龙头硬拉，且产业链是否扩散）**：`sector_constituents(主线板块)` 看内部宽度——多只成分共振普涨才是真主线；只 1-2 只龙头硬拉不算。再看主线相关的上下游板块是否同步走强（产业链扩散 = 主线更实）。
3. **拥挤度（决定要不要降档）**：`sector_factor_detail(sec_codes=[主线板块], win=200)` 读「成交集中度」子因子的历史分位。**分位 > 90% → 主线虽真但已晚，确信度强制降一档**（"真主线 + 拥挤" ≠ 此刻该重仓）。

### 阶段 4 · 时序定位：主线走到第几期

合成 阶段 3 拥挤度分位 + 阶段 0 `market_temperature` 综合分与宽度子因子，近似判断主线行情阶段：

- 低集中度 + 宽度扩散 → **初期 / 加速期**（可追，确信度可给足）。
- 高集中度 + 高温度 + 宽度收窄 → **共识 / 松动期**（只减不加）。
- 判为「松动期」→ 即便动量仍强也**强制降档**，并写进证伪条件。

### 阶段 5 · 综合定档 + 客观第二意见

综合 阶段 2 得分（0–3）、阶段 3 闸门（过几道）、阶段 4 时序、§五 质地，归档：

| 条件 | 主线档位 |
|---|---|
| 阶段2 = 3/3 + 阶段3 三道全过 + 非松动期 + 质地非散户主导 | **强主线** |
| 阶段2 ≥ 2/3 + 阶段3 至少过 2 道 | **中主线** |
| 阶段2 = 1/3 或 阶段3 只过 0–1 道 或 处松动期 | **弱主线** |
| 阶段0 判散沙 / 候选集为空 / 各维度互相矛盾 | **无主线**（方向 = 全市场） |

**强制降档（任一成立降一档）**：拥挤度分位 >90% ｜ "价涨量出" ｜ 处松动期 ｜ 质地散户主导。

**客观第二意见（防 LLM 主观漂移）**：`quant_factor()` 读 `market_retail_contrarian_20_90`（全市场散户申赎反向，0/0.5/1）。自判强主线但该因子 = 0（散户在猛申购、模型示警）→ 质地降档；两者同向 → 确信度更稳。

## 五、质地维度：聪明钱 vs 散户（软参考，不作硬定档）

> ⚠️ 本维度降为**软信号**：① `fund_index_subscription_redemption` 用 `calc_date`、proxy 不注入 → 实际多半调不动；② 申赎分歧单独作择时不稳。**能取到就当经验信号、取不到就跳过，不据它强行升/降档**；真正的客观第二意见用 §四·阶段5 的 `quant_factor`。

- **读法（若可得）**：机构净申购 + 个人净赎回 → 质地好（聪明钱进、散户没反应）；个人猛申购 + 机构净赎回 → 质地差（散户接盘），警惕见顶。
- **输出字段**：`质地 = 机构主导 / 散户主导 / 中性`（数据缺失填"中性"）。

## 七、主线板块 → 可投基金池（成分重叠 × 净值相关 双测度）

主线板块定下后，本节把它筛成"一篮子可投基金"。**不靠名称/分类映射**——板块是东财体系（BKxxxx）、指数是中证/国证体系，名称匹配大量断链（实测 98 个板块只 26% 能对上池内指数名，且"商业航天→卫星通信/空天一体"这种全靠语义、名称匹配假阴性）。改用两个落在**股票代码 / 交易日**上的客观测度——**股票代码是板块与基金之间唯一可靠的通用连接键**。

**候选宇宙 = 可买池**（被动指数型基金全集，每只带其跟踪指数代码；项目维护在 `data/被动指数型基金池（权益黄金）.xlsx`）。两测度对全池批量算，由 `scout/board_fund_match.py` 引擎落地（指数成分本地缓存、净值批量取，**低频不高频**）。基金侧工具全部吃 `simulated_datetime`（proxy 注入，bot 不写时间）。

### 7.1 两个客观测度

| 测度 | 算什么 | 工具（PIT） |
|---|---|---|
| **① 成分重叠（结构：是不是同一批股）** | 基金跟踪指数【全成分】里，落在主线板块成分内的【权重】之和 ÷ 指数总权重 | `idx_constituents(index_code)` 指数全成分+权重 ∩ `sector_constituents(主线板块)` 板块成分 → 在股票代码上交集、按指数权重加总 |
| **② 净值相关（行为：是不是真的一起动）** | 主线板块日收益 vs 基金净值日收益 的 Pearson，**120 日窗口** | `sector_market(主线板块, start_date)` 板块日收益序列 vs `fund_nav(fund, start, end)` 日收益率 → 按交易日对齐算相关 |

> 股票代码去后缀对齐（`600879.SH`→`600879`）；基金代码补零 6 位（xlsx 把 0 开头场外基金代码当数字存会丢前导零，`000596→596`，不补会查无此基金被误剔）。

### 7.2 判定分档（相关性高即入选；底线每条主线≥1只产品）

| 档 | 成分重叠 | 净值相关 | 含义 |
|---|---|---|---|
| **✓纯载体** | ≥50% | ≥0.8 | 同一批股 + 真的一起动（首选） |
| **○代理载体** | <50% | ≥0.8 | 走势跟得上、只是不够纯——**相关高即入选**，作可投代理 |
| **△弱代理** | 任意 | 0.6–0.8 | 次优 |
| **▽兜底代理** | 很低 | ≥0.5 | 上面都没有时，取「重叠×相关」最高的一只 |
| ✗非该主线 | — | <0.6 | 走势都不跟，真不相关，剔除 |

- **核心原则**：**相关性高就入选**（哪怕重叠不高，作代理）——面向投资，有个跟得上的代理 > 干等无货。重叠只决定"纯不纯"（分到哪一档），不再一票否决。
- **底线**：**每条主线最少要有一只产品**。窄概念（MLCC/被动元件/可控核聚变这类无纯对标指数的）若无纯/代理，放宽到重叠最高的 top15 指数再算一轮相关，挑同板块最跟得上的作**兜底代理**；档位如实标注"非纯/兜底"，让下游知道这是代理而非干净载体。
- 档内排序按 **重叠×相关**（让同板块代理压过纯宽基β，如别让"中证1000"冒充"MLCC"）。
- **净值对齐不足 120 日窗口（成立不满半年）→ 剔除**（无法验证走势相关，与 fund-screening 不设年限门槛一致——年限由这一步自然兜住）。
- 两测度**互补**：重叠是"因"（真是同一批股），相关是"果"（真的一起动）。只重叠不相关 = 指数漂移/跟踪差；只相关不重叠 = 宽基普涨——但后者在"找不到纯载体"时仍是可用代理，分到代理/兜底档而非直接弃用。

### 7.3 硬门槛（一票否决）

| 门槛 | 工具 · 字段 | 标准 |
|---|---|---|
| 规模下限 | `fund_basic_info(fund_codes)` 的 `scale` | ETF ≥ 2 亿 / 场外 ≥ 1 亿 |
| 类型对口 | `fund_basic_info` 类型 | 只留指数型（ETF / 联接 / 普通指数 / 增强指数）；主动权益 / 债基 / 货基不进 |

> **成立时间不设硬门槛**（与 fund-screening 一致）——净值不满半年者已在 7.2 因相关性算不出而剔除，无需再设年限门槛。

### 7.4 输出基金池（categorical，紧跟 §六 主线结论之后）

```
主线板块: BKxxxxxx <名>
可投基金池(按 重叠×相关 降序, 标档):
  [代码 <名> 跟踪<指数> 档=纯/代理/弱/兜底 重叠X% 相关Y β Z scale=N亿 入池档 | ...]
底线产品(每条主线≥1只): <最佳那只 + 档位>   ← 哪怕只是兜底代理也要给出
剔除: [代码 <名> — 原因(净值<半年 / 规模<2亿 / 相关<0.5非该主线)]
```

### 7.5 交棒下游

- **精排选载体**：把基金池交 `fund-screening`，按 跟踪质量 40% / 费率 35% / 规模 25% 三维打分选最终 1–3 只（细则在 fund-screening，本 skill 不重复）。
- **仓位**：最终给这几只基金多少仓位由 METHODOLOGY 据本 skill 的主线确信度（强/中/弱）定。

本 skill 到"主线板块 + 可投基金池"为止——**识别 + 客观匹配完成，精选 / 择时 / 配置不在本 skill**。

## 八、与其它环节的边界

- **上游**：先有 `market-context` 的 `risk_state`（敢不敢上仓的总环境），再跑本 skill。两者都要落 mem0。
- **下游**：本 skill 产出"主线板块 + 可投基金池"后——`fund-screening` 在池内精排选 1–3 只载体、METHODOLOGY 据主线确信度定仓位（详见 §7.5）。**精选 / 配置都不在本 skill**。
- **证伪**：主线一旦被自己写下的"证伪条件"命中，当天就要在 mem0 里显式降档或推翻，不能拖到"明天再看"。
