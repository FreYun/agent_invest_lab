# market-context 市场行情判断 · 月度回测（2025-01 → 2026-06）

> 方法论：`bots/bot101/skills/market-context`（宏观四维 + 股/债/金价格验证 + 反向证据 + 持续性 五步交叉验证 → 五类行情 + 置信度 + risk_state）
> 数据源：ttjj-data-pit MCP（:18078），服务端按 `simulated_datetime` **强制截断未来数据**
> 回测口径：每月**首个交易日 15:00（A股收盘）**作为时点，独立判断一次，共 18 期

## 防数据穿越（PIT）设计

1. **数据层**：每次取数都把 `simulated_datetime` 钉在当月首交易日，服务端只返回该日及之前可见的数据。已实测验证——查 2025-01-02 时沪深300行情止于 2025-01-02；查 2025-01-02 时 CPI 只到 2024-11（12月CPI尚未发布），PMI 到 2024-12（月末发布），宏观数据**天然遵守发布滞后**，无穿越。
2. **推理层**：13 个月分别由 **13 个互相失明的子 agent** 判断，每个 agent 只能读自己当月那一份数据包、禁止读其他月份/联网/调用训练知识里"后来A股怎么走"。这样消除了"判 3 月时已知 4 月关税大跌"这类**推理层穿越**。
3. **事后验证列**：表格最右"次月前瞻"仅供我方评估命中率，**从未提供给做判断的 agent**。

## 二、命中评估（risk_state vs 次月前瞻）

- **方向大体正确**：H2 单边上行（7~9月、12月）均给 risk_on 并吃到涨幅，其中 **8月 risk_on → 次月+11.56%** 是最大一次正确进攻；春季震荡期（4~6月）转 neutral，**4月 neutral → 次月−2.04%** 成功规避下跌。
- **两处值得复盘的踩点**：
  - **2025-03 给 risk_on(进攻)**，恰在 4月初"对等关税"冲击之前。按当时 PIT 数据（科技强、风险偏好满格、研报春季躁动）判进攻是合理的，但方法论的"关税反向证据=中等强度"已写进风险提示——只是没降到 neutral。次月-0.02%（月初到月初拉平），但**月内回撤剧烈**，是典型"事件无法预知、但反向证据已提示"的案例。
  - **2025-10 / 11 给 risk_on**，处在 4700 高位、PE 历史分位 86~89%，次月各 −1.19% / −1.65% 小幅回调。判断本身已反复强调"估值偏高+情绪过热"，属于"看多但提示风险"的偏多，回撤幅度可控。
- **偏保守的一处**：6月 neutral 而次月 +2.36%，是震荡期错失的小幅上行——多信号冲突下默认 range 的代价。

> 结论：这套方法论在 2025 年表现为**"趋势期敢上、震荡期收手、高位反复示警"**，risk_state 序列与沪深300实际节奏吻合度高；主要漏洞是无法提前定价突发关税事件（这是任何 PIT 方法的共性，只能靠 Stress 流程事后快速切换）。

**2026 上半年延续评估（H1）**：

- **2026-02 easing 偏多 → 次月+2.66% ✓**；**2026-04 range/neutral → 次月+7.76%** 是本段最大一次"保守踏空"——4月初市场已破均线、地缘(美以打击伊朗)压制、估值87%分位，按多信号冲突判 neutral 合理，但随后强势反弹，neutral 错失了主升。
- **2026-03 easing 偏多 → 次月−4.28%** 是本段最大一次"偏多踩点"：恰逢 2/28 美以打击伊朗+霍尔木兹封锁的地缘冲击发酵期，agent 已把地缘列为强反向并下调到"偏多·重质量"（非进攻），但未降到 neutral，次月仍吃了回撤。
- **2026-05 recovery 进攻 → 次月−0.67%**：在 26Q1 盈利+11.8%修复、成长领涨下判进攻，方向没错但估值已 92% 分位、风险偏好骤降，次月小幅回落，属高位追多的轻微回吐。
- H1 的共同背景是**中东地缘(美以-伊朗)反复**+**估值持续在 80~92% 高分位**，方法论整体仍是"宽松托底→偏多，地缘/高估值→降级重质量"，但在 3、4 月连续两次被地缘节奏甩了一下（3月偏多挨打、4月转身又踏空），反映**事件驱动行情下单期判断的滞后性**——这正是 market-context "持续性/连续两期确认"纪律想缓解、但单点回测无法完全规避的部分。

## 三、全年行情演化主线（按 PIT 判断串起来）

1. **1~2月｜宽松过渡**：10Y 国债跌至 1.63% 历史低位，债牛金牛、股弱；DeepSeek/AI 点燃结构性风险偏好 → easing 偏多。
2. **3月｜短暂复苏**：PMI 重回扩张、科技主线 + 两会催化，风险偏好满格 → recovery 进攻（但已警示3月4日关税）。
3. **4~6月｜关税震荡**：关税落地冲击 PMI（4月骤降至49.0）、通缩加深（PPI −2.7%→−3.3%）、股债双弱金独强、信号分歧 → 连续三期 range / neutral，规避了4月下跌。
4. **7~9月｜流动性水牛**："反内卷"政策预期 + 机构/散户/外资/ETF 多路资金入场，温度从34飙到77，沪深300 从 3943 涨到 4524 → easing 偏多，吃到主升浪。
5. **10~12月｜高位震荡**：估值升到 PE 历史 85%+ 分位、利率反而上行(债熊苗头)、温度大起大落（10月67→12月极冷11→），中美缓和支撑 → easing 偏多但"重质量"、反复示警估值与过热。
6. **2026-01｜春季躁动**：降准降息预期前置、股债双牛、温度再度跳升至 73 → easing 偏多。
7. **2026-02~03｜宽松+地缘**：10Y 1.78~1.81% 极低、M2 升至 9%，股债同涨；但 2/28 美以打击伊朗、霍尔木兹封锁，温度从 ~71/77 急降，黄金一度冲到 1160 元 → easing 偏多但"重质量"。
8. **2026-04｜地缘震荡**：中东推升美元、黄金反而回落、A股破均线、估值 87% 分位、增长 nowcast 深负，信号分歧 → range / neutral。
9. **2026-05｜盈利复苏**：26Q1 全A非金融盈利 +11.8%、营收加速，PPI 3月转正、4月冲 +2.8%，创业板大涨，温度回 59 → recovery 进攻（但估值已 92% 分位）。
10. **2026-06｜宽松延续**：流动性宽松驱动估值修复，PPI 翻正但被市场视为输入性(债牛未破)、黄金回落、风险偏好骤降 → easing 偏多·重质量。

## 五、已知数据局限（非穿越，需知悉）

- **VIX 自 2025-11-06 起整体缺失（影响 2025-12 ~ 2026-06）**：上游 `option_vix` 数据停更于 2025-11-06。2026-02 期 90 天窗口尚能捞到最后一条(已过期约3个月)，**2026-03 ~ 06 完全无 VIX 数据**。这些期的波动率/风险偏好维度改用 `market_temperature` 的「VIX得分」子项作代理，各 agent 已按"数据缺失→不强行推断→降级"处理。**不影响 PIT 正确性（缺数据≠看未来）**，但 H1 几期的情绪维度证据偏弱，是置信度只到"中"的原因之一。
- **黄金/商品口径**：仅取 AU9999 现货，未含原油/工业金属，通胀维度的商品验证偏窄。
- **资金行为**：本回测未逐期调 `stock_capital_flow`（仅个股级、无市场级北向聚合），资金维度主要靠 `market_temperature`(升贴水/北向RSI 等综合得分) 与研报近似。
- **macro_nowcast**：信澳 nowcasting 为标准化打分(非原始值)，方向意义>绝对值；正负号与量纲在各期解读时已统一为"方向"。
