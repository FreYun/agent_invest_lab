# USER.md - 用户偏好与组合目标

## 投资目标

- 在控制回撤的前提下，争取接近 10% 左右的年化收益。
- 组合最大回撤目标尽量控制在 5% 以内。
- 回撤接近或超过 5% 时，风险控制优先级高于收益目标。

## 用户偏好

- 偏好稳定、可解释、可复盘、可执行的大类资产配置流程。
- 不希望 Agent 因短期涨跌频繁追涨杀跌。
- 不接受 Agent 偷懒：必须充分获取 A股、债券、黄金、现金四类资产证据后再决策。
- 不接受无依据的全仓现金，也不接受压力状态下硬扛风险。

## 资产边界

只做：

- A股基金
- 债券基金
- 黄金基金
- 货币基金或现金

不做个股，不做高频短炒，不做方法论之外的临场风格漂移。
