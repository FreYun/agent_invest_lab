# 大类资产配置 Agent 投资方法论 v2.0

## Agent 执行增强：最低证据包与工具纪律

本文件是 `bot_multi` 的正式执行手册。每次运行必须先识别任务类型：

```text
日度风险扫描 / 周度主线复核 / 月度正式调仓 / 极端风险临时处理
```

不同任务允许的动作不同：

| 任务类型 | 必须完成 | 允许动作 |
|---|---|---|
| 日度风险扫描 | 风险项目逐项检查 | normal 不交易；warning 暂停加风险；fail 临时降风险 |
| 周度主线复核 | 上期主线复盘 + 本期证据更新 | 小幅收缩或增加战术偏离 |
| 月度正式调仓 | 完整 11 步权重流程 | 生成最终权重和交易动作 |
| 极端风险临时处理 | 明确风险闸门 fail | 临时进入压力状态并降风险 |

补充硬约束：

```text
日度风险扫描若输出为 normal -> 禁止下单；
日度风险扫描若输出为 warning -> 只允许暂停加风险或等待复核，禁止继续卖出已处于正常下限附近的资产；
只有 fail 或月度正式调仓，才允许突破“日度只扫描不重配”的默认边界。
```

### 最低证据包

月度正式调仓和周度主线复核前，必须至少形成以下证据包。证据包不完整时，不得进行完整调仓，只能维持、降级或等待复核。

| 证据包 | 必须回答 | 示例工具 |
|---|---|---|
| 账户证据 | 当前持仓、现金、历史交易、组合回撤是否清楚 | `portfolio_get_my_history`, `portfolio_get_my_trades`, `portfolio_get_my_performance` |
| 可买池证据 | 四类资产是否都有可买替代标的，货币基金缺失时现金如何承担角色 | `portfolio_get_buyable_funds`, `get_fund_detail` |
| A股证据 | 估值、盈利或宏观、趋势、资金、情绪是否支持增减配 | `market_index_quote`, `market_index_val`, `market_index_gzxjb`, `market_temperature`, `option_vix` |
| 债券证据 | 利率位置、期限利差、信用利差、趋势、久期风险是否清楚 | `bond_yield_curve`, `bond_yield_curve(curve_type="cn")`, `bond_yield_curve(credit−cn 自算利差)` |
| 黄金证据 | 金价趋势、实际利率或美元线索、避险需求、风险事件是否清楚 | `commodity_market`, `commodity_market(market_type="futures")`, `research_search(search_type="news")` |
| 现金证据 | 短端收益、风险资产机会成本、回撤压力、等待价值是否清楚 | 账户现金、货币基金收益、短端利率 |
| 宏观与事件证据 | 增长、通胀、流动性、政策或海外冲击是否清楚 | `macro_data`, `macro_data(region="cn")`, `macro_nowcasting_snapshot`, `research_search`, `research_search(search_type="news")` |

### 不充分取证的硬性降级

```text
只看 A股 -> 不能完整调仓
只看账户盈亏 -> 不能完整调仓
没有债券证据 -> 债券权重只能回中枢或维持
没有黄金证据 -> 黄金权重只能回中枢或维持
没有可买池证据 -> 不得下单
没有成本检查 -> 不得下单
风险闸门未逐项输出 -> 不得下单
```

低换手不是偷懒理由。只有在完成最低证据包后，才能得出“不交易”的结论。

## 0. 方法论总纲

本方法论用于指导 Agent 在 **A股基金、债券基金、黄金基金、货币/现金类资产** 四类资产之间进行配置。

本方法论的核心目标不是预测每一天市场涨跌，而是在不同市场环境下形成一套 **稳定、可解释、可复盘、可执行** 的资产配置流程。

本方法论的完整流程为：

```text
战略中枢
→ 市场状态分层
→ 市场主线识别
→ 资产性价比判断
→ 候选权重生成
→ 风险闸门检查
→ 最终权重与交易动作
→ 日度风险扫描 / 周度主线复核 / 月度正式调仓
→ 复盘与证伪
```

---

## 1. 资产范围

初版只覆盖四类资产：

| 资产类别 | 含义 | 组合角色 |
|---|---|---|
| A股基金 | 权益类基金，可使用宽基指数基金或代表性权益基金 | 提供主要收益弹性 |
| 债券基金 | 纯债、债券指数、偏稳健固收类基金 | 提供稳定底仓和回撤缓冲 |
| 黄金基金 | 黄金 ETF 联接、黄金主题基金 | 提供避险、抗通胀和尾部风险对冲 |
| 货币/现金 | 货币基金或账户可用现金 | 提供流动性、等待机会和风险缓冲 |

如果可买基金池中没有货币基金，则账户现金临时承担货币/现金类资产的角色。  
但除非进入压力状态，否则现金类资产仍应受到正常状态上限约束，不能随意变成 100% 现金。

---

## 2. 组合目标

组合管理目标为：

```text
在控制回撤的前提下，争取接近 10%左右的年化收益；
组合最大回撤目标尽量控制在 5%以内。
```

需要说明：

1. 该目标是组合管理目标，不是收益承诺；
2. 实际表现取决于市场环境、资产波动、交易成本和风险事件；
3. 如果市场持续单边下跌或股债同跌，组合可能阶段性突破回撤目标；
4. 若回撤接近或超过 5%，风险控制优先级高于收益目标。

---

## 3. 战略中枢与资产上下限

### 3.1 战略中枢

战略中枢用于定义组合的长期默认配置，是 Agent 在没有高置信度市场主线时回归的基准状态。

| 资产类别 | 战略中枢 | 组合角色 |
|---|---:|---|
| A股基金 | 45% | 提供主要收益弹性 |
| 债券基金 | 35% | 提供稳定底仓和回撤缓冲 |
| 黄金基金 | 10% | 提供避险、抗通胀和尾部风险对冲 |
| 货币/现金 | 10% | 提供流动性和等待机会的缓冲 |

战略中枢不是固定不变的交易指令，而是组合的长期锚。  
Agent 可以根据市场主线、资产性价比和风险状态围绕中枢进行战术偏离。

---

### 3.2 正常状态配置区间

正常状态指未触发重大风险闸门的市场环境。此时 Agent 可以根据市场主线和资产性价比调整权重，但必须遵守以下正常配置区间。

| 资产类别 | 正常状态下限 | 正常状态上限 |
|---|---:|---:|
| A股基金 | 20% | 70% |
| 债券基金 | 15% | 60% |
| 黄金基金 | 0% | 25% |
| 货币/现金 | 0% | 30% |

正常状态下，A股不轻易降至 0%。  
原因是大类资产配置不是短期择时模型，如果普通估值偏贵或短期趋势走弱就清空 A股，组合容易退化成追涨杀跌或现金择时。

正常状态下：

```text
A股偏弱 → 优先降至正常下限附近，而不是直接清仓；
主线低置信度 → 优先回到战略中枢，而不是全仓现金；
无主线震荡 → 可小幅提高货币/现金，但不得突破正常上限。
```

额外约束：

```text
如果 A股已经处于正常下限附近（20%±5%）或已经低于自身估值锚/仓位模型建议值，
则在 Normal / Warning 状态下不得继续卖出；
除非出现明确风险闸门 fail，或进入月度正式调仓并给出完整四类资产证据。
```

---

### 3.3 压力状态配置区间

当市场出现明显风险冲击，且风险闸门判定为 fail 时，组合进入压力状态。  
压力状态下，Agent 允许临时突破正常配置区间，以保护组合净值。

| 资产类别 | 压力状态允许区间 |
|---|---:|
| A股基金 | 0%-30% |
| 债券基金 | 25%-70% |
| 黄金基金 | 0%-30% |
| 货币/现金 | 10%-80% |

压力状态的典型触发条件包括：

1. A股趋势破位，且组合回撤扩大；
2. 股债同跌，传统分散效果失效；
3. 流动性冲击或重大宏观风险事件；
4. 组合最大回撤接近或超过 5%的控制目标；
5. 市场主线证伪，且风险资产价格同步走弱；
6. 债券和黄金也无法提供有效对冲，组合相关性明显上升。

压力状态下，A股可以降至 0%，但必须满足明确风险触发条件。  
不能因为普通估值偏贵、短期震荡、主线低置信度或单日回调就直接清仓 A股。

---

### 3.4 恢复状态

当压力状态解除后，Agent 不应立即大幅加回风险资产，而应进入恢复状态，分批回到正常配置区间。

恢复状态的判断条件包括：

1. 组合回撤停止扩大；
2. A股或主要风险资产重新站回关键趋势线；
3. 股债相关性恢复正常；
4. 市场主线重新出现并获得价格验证；
5. 风险闸门从 fail 降级为 warning 或 pass。

恢复状态下，A股每次加仓不宜超过 10%，避免从极端防守状态快速切换到高风险暴露。

---

## 4. 市场状态分层

Agent 每次运行时，必须先判断当前组合处于哪个状态：

```text
Normal State：正常配置状态
Warning State：风险预警状态
Stress State：压力防守状态
Recovery State：压力恢复状态
```

| 状态 | 典型特征 | 权重规则 |
|---|---|---|
| Normal | 未触发重大风险闸门 | 使用战略中枢和正常上下限 |
| Warning | 风险升温但尚未确认恶化 | 暂停加风险，可小幅提高现金 |
| Stress | 风险闸门 fail，组合需要防守 | 允许进入压力状态区间 |
| Recovery | 压力缓和但主线未完全恢复 | 分批回到正常区间 |

状态判断优先级高于市场主线。  
如果风险状态为 Stress，即使某类资产短期信号较强，也不能直接大幅加仓风险资产。

---

## 5. 市场主线识别

### 5.1 核心原则

市场主线不是单个宏观指标，而是当前资产价格主要在交易的矛盾。

Agent 每期必须先回答：

> **当前市场主要在交易复苏、宽松、通缩、通胀，还是无主线震荡？**

主线必须同时经过：

```text
宏观证据
+ 价格验证
+ 反向证据检查
+ 持续性确认
```

不允许直接从单个指标推出结论。  
例如，PMI 上行不等于复苏交易成立，利率下行也不等于债券一定要加仓。

---

### 5.2 五类候选主线

Agent 只能从以下五类主线中选择：

| 主线 | 含义 | 典型资产倾向 |
|---|---|---|
| 复苏交易 | 增长改善、盈利修复、风险偏好回升 | A股有利，债券中性或承压，货币降低 |
| 宽松交易 | 流动性宽松、利率下行、政策托底 | 债券有利，A股观察，黄金中性偏有利 |
| 通缩/衰退交易 | 需求弱、价格弱、盈利承压 | 债券和货币有利，A股承压 |
| 通胀/再通胀交易 | 商品、PPI、通胀预期上行 | 黄金有利，债券承压，A股分化 |
| 无主线震荡 | 指标分化、资产轮动快、趋势不持续 | 回到中枢，降低换手，保留货币 |

---

### 5.3 主线识别表

每期必须生成以下结构化判断：

| 候选主线 | 宏观证据 | 价格验证 | 反向证据 | 持续性 | 结论 |
|---|---|---|---|---|---|
| 复苏交易 | 增长、盈利、信用是否改善 | A股/商品是否走强 | 债券是否仍强、盈利是否弱 | 是否连续确认 | 成立/不成立 |
| 宽松交易 | 资金面、政策利率、长债利率 | 债券是否走强、估值是否修复 | 信用是否迟迟不起 | 是否连续确认 | 成立/不成立 |
| 通缩/衰退交易 | 增长弱、PPI低、需求弱 | 债券强、A股弱 | 政策是否强托底 | 是否连续确认 | 成立/不成立 |
| 通胀/再通胀交易 | PPI/商品/通胀预期上行 | 黄金/商品强、债券弱 | 需求是否不足 | 是否连续确认 | 成立/不成立 |
| 无主线震荡 | 指标分化 | 资产轮动快、趋势不持续 | 是否已有强趋势资产 | 是否持续混乱 | 成立/不成立 |

---

### 5.4 主线置信度

| 置信度 | 条件 | 权重动作 |
|---|---|---|
| 高 | 宏观证据、价格验证、持续性均成立，反向证据少 | 允许完整战术偏离 |
| 中 | 有部分证据，但存在冲突 | 只允许半幅战术偏离 |
| 低 | 证据冲突、价格不验证、持续性不足 | 不做战术偏离 |
| 无主线 | 多资产快速轮动，无稳定方向 | 回到中枢或小幅提高货币/现金 |

重要规则：

```text
没有价格验证的主线，最高只能给中置信度；
没有持续性的主线，不能触发完整战术偏离；
反向证据强于支持证据时，默认无主线震荡；
无主线震荡不等于全仓现金。
```

## 6. 全局状态与资产映射

本框架不要求 Agent 每期对四类资产分别重复计算六套因子。  
正确流程是：

```text
先判断统一市场状态
再映射到四类资产
最后生成权重
```

全局状态每期只判断一次：

| 全局状态 | 关键问题 |
|---|---|
| 增长状态 | 经济是在改善、弱复苏、放缓还是衰退？ |
| 通胀状态 | 通胀是在上行、下行，还是存在通缩压力？ |
| 流动性状态 | 资金面和政策环境是宽松、中性还是收紧？ |
| 风险偏好 | 市场是 risk-on、risk-off，还是震荡？ |

资产自身状态分别判断：

| 资产 | 自身状态 |
|---|---|
| A股 | 估值、盈利、趋势、资金 |
| 债券 | 利率位置、期限利差、趋势、久期风险 |
| 黄金 | 实际利率、美元、避险需求、趋势 |
| 货币/现金 | 短端收益、现金价值、等待机会 |

---

## 7. 四类资产核心矛盾

| 资产 | 核心问题 | 主要看点 |
|---|---|---|
| A股 | 盈利能否改善，风险偏好是否支持估值扩张 | 增长、盈利、流动性、估值、趋势、资金 |
| 债券 | 利率是否还有下行空间，久期风险是否可控 | 经济动能、通胀、货币政策、利率位置、趋势 |
| 黄金 | 黄金是否具备避险或抗通胀价值 | 实际利率、美元、地缘风险、央行购金、趋势 |
| 货币/现金 | 现金是否比冒险更有价值 | 风险压力、短端收益、其他资产信号弱化 |

每次正式配置判断时，四类资产都必须有独立证据。  
不能只用 A股数据决定全部资产权重。

## 7.1 每类资产下的基金选择逻辑

大类资产配置先决定“这类资产要不要配、配多少”，再决定“这类资产里买哪只基金”。  
选品只服务于资产表达，不允许让选品反过来绑架大类资产判断。

### 7.1.1 总原则

参考 `bot101` 的收敛思路，但这里简化为三步：

```text
先确定资产角色
→ 再从可买池收敛候选
→ 最后只对 1-3 只候选做深查
```

硬规则：

1. 先读 `portfolio_get_buyable_funds` 和 daily prompt 已注入的可买池摘要，不得为了探索全池而批量调 `get_fund_detail` 或 `fund_nav`。
2. 每类资产先按“是否符合当前主线 / 当前状态 / 当前角色”收敛到少数候选，再做基金层比较。
3. `get_fund_detail` 只允许用在最终 1-3 只候选阶段，主要看 `theme`、`style.size_style`、`style.invest_style`、长期收益、回撤、Sharpe、同类排名。
4. 同一类资产优先选“角色清晰”的工具型基金，不选风格漂移太大、资产暴露混杂、难解释的产品。
5. 若某类资产在可买池里没有合适表达工具，该类资产权重应回到更保守的中性表达，而不是硬挑一个不匹配的基金凑数。

### 7.1.2 A股基金选择

#### 第一步：先按主线收敛

- 主线为复苏交易：优先宽基、顺周期、大盘价值或与复苏受益方向匹配的权益基金。
- 主线为宽松交易但 A股只获部分验证：优先低波宽基、红利、央国企、全市场平衡型基金，不追最强主题。
- 主线为无主线震荡：优先 `theme = 全市场` 的宽基或红利，不用高弹性主题基金重仓表达。
- 若 A股只是组合的低配保留仓：优先选宽基，不用高波动赛道基金。

#### 第二步：同主题候选怎么筛

- 宽基 / 平衡表达优先：规模适中、跟踪清晰、风格稳定。
- 若需要主线弹性，优先选择 `invest_style` 更偏成长、`size_style` 更贴近当前市场强势风格的候选。
- 同主题下，优先长期 `max_drawdown_pct` 更可控、`sharpe_ratio` 更高、`rank_pct` 更靠前的基金。

#### 第三步：最终落地

- A股通常保留 1-2 只基金即可。
- 没有明确主线时，A股原则上只保留 1 只核心宽基或宽基 + 红利。
- 若新候选相对旧持仓没有在“主线匹配度、趋势、长期 Sharpe、回撤、同类排名”里至少多赢 2 项，默认不换。

### 7.1.3 债券基金选择

#### 第一步：先按利率环境收敛

- 宽松交易、通缩/衰退交易：优先中短久期利率债、高等级信用债、纯债指数基金。
- 利率下行已验证且久期风险可控：可接受久期略长的债券基金。
- 利率快速上行、通胀抬头或债券趋势破位：优先缩短久期，降低长债表达。

#### 第二步：债券候选怎么筛

- 优先纯债、国债、高等级信用债，不优先混合债、可转债增强这类权益噪音更大的产品。
- 优先“角色清晰”的防守型工具，不让债券仓变成隐藏的二次权益仓。
- 同类候选中，优先长期回撤小、Sharpe 更高、近 2y/3y 表现更稳定的基金。

#### 第三步：最终落地

- 债券通常保留 1-2 只：一个偏利率债底仓，一个偏高等级信用债增厚即可；如果池子有限，1 只也可以。
- 没有明确优势时，优先国债或中短久期纯债，不为多拿一点票息去承担过高信用或久期风险。
- 若市场进入 Stress 且债券也失去对冲能力，债券基金仍可保留，但要优先换成更短久期、更高流动性的表达。

### 7.1.4 黄金基金选择

#### 第一步：先确认黄金角色

- 黄金在组合中主要承担避险、抗通胀和相关性分散，不承担复杂风格表达。
- 主线为通胀/再通胀、风险冲击或实际利率下行时，黄金更适合配置。
- 若只是为了“看起来分散”而配黄金，但价格、实际利率、避险需求都不支持，可以不配。

#### 第二步：黄金候选怎么筛

- 优先直接跟踪黄金现货或黄金 ETF 的联接基金。
- 优先规模更大、跟踪更直接、结构更简单的候选。
- 不选主题外延太多、夹杂矿股或复杂衍生暴露的“伪黄金表达”。

#### 第三步：最终落地

- 黄金通常只保留 1 只，不需要在多只黄金联接之间做假分散。
- 如果 `002610`、`518880` 这类标准黄金工具都可买，优先选历史角色最稳定、流动性更好的那只。
- 黄金仓的替换门槛要高于 A股，不因短期 1 周相对收益小差异频繁换基。

### 7.1.5 货币/现金选择

#### 第一步：先判断是否需要产品表达

- 若可买池里有货币基金，可把它作为现金管理工具。
- 若可买池中没有货币基金，账户现金直接承担该资产角色，这是允许且正常的。

#### 第二步：候选怎么筛

- 优先高流动性、低波动、低费用的货币或现金管理型基金。
- 不把短债增强、固收+、可转债增强误当成货币替代。

#### 第三步：最终落地

- 货币/现金类通常只需要 0-1 只产品。
- 如果账户现金已经能充分承担等待机会和缓冲风险的作用，可以不额外买货币基金。
- 货币/现金的职责是吸收剩余权重、留出机动性，不追求用它制造超额。

### 7.1.6 选品层的降级规则

```text
资产方向明确，但基金候选不清晰 -> 保留该资产权重，选择最中性的标准表达
资产方向不明确 -> 不靠选品强行制造超额
同类候选差异很小 -> 默认不换
只有短期业绩领先，没有长期质量支持 -> 不升格为核心持仓
需要批量扫描全池才能做决定 -> 停止扫描，先收敛问题
```

一句话：  
大类资产判断决定“买哪一类”，基金选择只决定“用什么工具表达”，后者不能喧宾夺主。

## 8. 市场主线到战术偏离

### 8.1 基础映射表

| 市场主线 | A股基金 | 债券基金 | 黄金基金 | 货币/现金 |
|---|---:|---:|---:|---:|
| 复苏交易 | + | -/0 | 0/- | - |
| 宽松交易 | 0/+ | + | 0/+ | - |
| 通缩/衰退交易 | - | + | 0/+ | + |
| 通胀/再通胀交易 | 0/- | - | + | 0 |
| 无主线震荡 | 0 | 0 | 0 | + |

---

### 8.2 偏离幅度

由于本方法论不再区分风险偏好，战术偏离采用统一档位。

| 主线置信度 | 单类资产常规偏离幅度 |
|---|---:|
| 高 | 10%-20% |
| 中 | 5%-10% |
| 低 | 0%-5% |
| 无主线 | 0%，或仅小幅提高货币/现金 |

规则：

1. 第一次切换主线，只允许半幅偏离；
2. 连续两期确认后，才允许完整偏离；
3. 如果主线置信度下降，先收缩偏离，不急于反向大调；
4. 如果判断为无主线震荡，默认回到战略中枢或小幅提高货币/现金；
5. 正常状态下，偏离后的权重不得突破正常配置区间；
6. 压力状态下，偏离后的权重可以进入压力状态区间，但必须说明触发条件。

---

### 8.3 主线与资产动作约束

为保证主线和权重动作一致，加入以下硬约束：

1. 若主线为 **宽松交易** 且置信度为中及以上，债券权重原则上不得低于战略中枢；
2. 若利率下行获得价格验证且无债券风险闸门，债券可高配 5%-10%；
3. 若主线为 **复苏交易** 且置信度为中及以上，A股权重原则上不得低于战略中枢；
4. 若主线为 **通缩/衰退交易**，A股不得高于战略中枢，债券或现金至少一项应高于中枢；
5. 若主线为 **通胀/再通胀交易**，黄金权重原则上不得低于战略中枢；
6. 若主线为 **无主线震荡**，不得大幅偏离中枢，不得直接 100% 现金。

---

## 9. 资产性价比修正

市场主线决定大方向，资产性价比决定是否需要小幅修正。

### 9.1 修正原则

```text
候选权重 = 战略中枢 + 主线战术偏离 + 资产性价比修正
```

资产性价比修正不是重新决定方向，只能做小幅调整。

```text
单类资产最大修正幅度：±5%
没有强证据，不修正；
如果资产性价比和市场主线冲突，优先降低主线置信度，而不是大幅反向修正。
```

---

### 9.2 四类资产修正规则

| 资产 | 提高权重的条件 | 降低权重的条件 |
|---|---|---|
| A股 | 估值不贵、盈利或政策改善、趋势确认、资金改善 | 估值过热、盈利转弱、趋势破位、资金流出 |
| 债券 | 经济偏弱、通胀回落、利率有下行空间、债券趋势好 | 利率处低位、通胀上行、债券趋势破位、久期风险上升 |
| 黄金 | 实际利率下行、美元走弱、避险升温、黄金趋势强 | 实际利率上行、美元走强、风险偏好改善、黄金趋势破位 |
| 货币/现金 | 风险资产信号弱、组合回撤压力上升、短端收益有吸引力 | 主线清晰且风险可控、继续高现金会造成明显踏空 |

---

## 10. 权重生成规则

### 10.1 生成流程

Agent 每次正式配置时按照以下步骤生成权重：

```text
第一步：读取战略中枢和正常/压力状态上下限
第二步：判断当前市场状态：Normal / Warning / Stress / Recovery
第三步：识别市场主线和置信度
第四步：根据主线和置信度生成战术偏离
第五步：根据资产性价比做小幅修正
第六步：得到候选权重
第七步：执行资产上下限检查
第八步：执行调仓步长检查
第九步：执行交易成本检查
第十步：执行风险闸门检查
第十一步：生成最终权重
```

---

### 10.2 候选权重公式

```text
candidate_weight
= strategic_center
+ regime_tilt
+ asset_adjustment
```

其中：

```text
strategic_center：战略中枢
regime_tilt：市场主线偏离
asset_adjustment：资产性价比修正
```

---

### 10.3 归一化规则

候选权重必须满足：

```text
A股 + 债券 + 黄金 + 货币/现金 = 100%
```

若加总不等于 100%，按以下顺序处理：

1. 优先用货币/现金吸收多余或不足权重；
2. 货币/现金触及上下限后，按资产主线方向调整其他资产；
3. 不允许突破当前状态对应的资产上下限；
4. 最终权重使用 5% 或 10% 档位，避免过度精确。

---

### 10.4 调仓步长

| 状态 | 正常单次调仓步长 | 风险恶化时最大降仓步长 |
|---|---:|---:|
| Normal | 5%-10% | 10%-15% |
| Warning | 0%-5% | 10%-20% |
| Stress | 不主动加风险 | 20%-30% |
| Recovery | 5%-10% | 10%-15% |

首日建仓可一次性建立目标组合。  
非首日调仓应遵守调仓步长，避免权重剧烈跳变。

---

## 11. 风险闸门

风险闸门不是常规权重优化器，而是异常情况下的防守机制。

常规情况下，最终权重由：

```text
战略中枢 + 市场主线偏离 + 资产性价比修正
```

决定。

风险闸门只回答三个问题：

```text
能不能加风险？
要不要暂停调仓？
是否需要临时降风险？
```

---

### 11.1 风险闸门类型

| 闸门 | 触发条件 | 动作 |
|---|---|---|
| 回撤闸门 | 组合回撤接近或超过 5%目标 | 暂停加仓或降低风险 |
| 趋势闸门 | A股/债券/黄金关键趋势破位 | 降低对应资产 |
| 相关性闸门 | 股债同跌，分散失效 | 提高黄金或货币/现金 |
| 波动闸门 | 高波动 + 回撤扩大 | 降低风险资产 |
| 成本闸门 | 调仓收益不足以覆盖成本 | 不交易 |
| 主线闸门 | 主线置信度下降或反向证据增强 | 收缩战术偏离 |
| 冲击闸门 | 重大宏观、政策、海外或流动性冲击 | 进入 Warning 或 Stress |

---

### 11.2 风险闸门分项输出

每次正式配置时，Agent 必须分项输出：

```text
回撤闸门：pass / warning / fail
趋势闸门：pass / warning / fail
相关性闸门：pass / warning / fail
波动闸门：pass / warning / fail
成本闸门：pass / warning / fail
主线闸门：pass / warning / fail
冲击闸门：pass / warning / fail
```

如果任一核心闸门 fail，组合进入 Stress State。  
如果仅出现 warning，组合进入 Warning State，暂停加风险但不一定降风险。

---

### 11.3 高波动不等于坏风险

Agent 不应机械地因为波动率升高就降仓。  
需要区分：

| 情况 | 判断 | 动作 |
|---|---|---|
| 高波动 + 趋势向上 + 回撤未扩大 | 主升行情中的可容忍波动 | 不强制降仓，只限制继续加仓 |
| 高波动 + 趋势破位 | 风险恶化 | 降低对应资产 |
| 高波动 + 回撤扩大 | 用户体验恶化 | 降低风险资产 |
| 股债同跌 + 黄金走强 | 分散结构变化 | 提高黄金或货币/现金 |
| 所有资产信号不清 | 无主线震荡 | 提高货币或回到中枢 |

---

## 12. 运行频率与任务分层

本方法论采用：

```text
日度风险扫描，周度主线复核，月度正式调仓，极端风险临时处理。
```

### 12.1 日度风险扫描

日度运行只承担风险扫描功能，不进行常规重配。

日度扫描只回答：

```text
今天有没有发生必须处理的异常？
是否需要暂停加风险？
是否需要临时降风险？
是否需要等待周度复核？
```

日度扫描重点检查：

| 模块 | 检查内容 | 目的 |
|---|---|---|
| 价格冲击 | A股、债券、黄金单日/近5日大跌 | 识别极端波动 |
| 趋势破位 | A股/债券/黄金是否跌破关键均线 | 判断原逻辑是否被破坏 |
| 利率冲击 | 10Y/30Y国债收益率是否快速上行 | 识别债券风险 |
| 股债同跌 | 股票跌、债券也跌 | 判断分散是否失效 |
| 黄金异常 | 黄金大跌或避险失效 | 判断对冲资产是否失灵 |
| 组合回撤 | 组合净值是否触发观察/警戒线 | 保护账户 |
| 重大事件 | 政策、海外、汇率、流动性事件 | 识别非线性冲击 |

日度扫描输出只能是以下三种：

| 输出 | 含义 | 动作 |
|---|---|---|
| normal | 无重大异常 | 不交易，仅记录 |
| warning | 风险升温但未确认恶化 | 暂停加风险，等待复核 |
| fail | 出现明确风险冲击 | 允许临时降风险 |

执行解释：

```text
normal = 不得下单，不得借机做常规减仓或再平衡；
warning = 不得新增风险，不得做完整重配；若某风险资产已在正常下限附近，禁止继续卖出；
fail = 才允许临时降风险；若因此突破正常区间，必须明确写出触发的闸门项。
```

日度扫描不能做以下事情：

1. 重新设定战略中枢；
2. 重新完整生成大类资产权重；
3. 因为单日小波动进行 5%-10% 常规调仓；
4. 因为短期涨跌重写方法论；
5. 在没有风险闸门 fail 的情况下突破正常上下限。
6. 在 `normal` 或 `warning` 结论下继续卖出已经处于正常下限附近的 A股仓位；
7. 在仓位已经低于自身估值锚、ERP 锚或模型建议仓位时，仅因情绪/温度/单一因子继续减仓。

---

### 12.2 周度主线复核

周度复核用于检查当前市场主线是否仍然成立。

周度复核必须回答：

1. 上周主线是什么；
2. 本周宏观证据是否延续；
3. 资产价格是否继续验证；
4. 反向证据是否增强；
5. 主线置信度是否上调、维持或下调；
6. 是否需要小幅收缩或增加战术偏离。

周度复核可以小幅调仓，但必须满足：

```text
主线至少中置信度；
风险闸门未 fail；
调仓幅度原则上不超过 5%-10%；
交易成本可以接受。
```

---

### 12.3 月度正式调仓

月度正式调仓是完整的大类资产配置流程。

月度必须完成：

1. 市场状态分层；
2. 五类市场主线识别；
3. 四类资产独立证据检查；
4. 资产性价比修正；
5. 候选权重生成；
6. 风险闸门检查；
7. 最终权重输出；
8. 本期交易动作；
9. 下期观察条件。

月度正式调仓可以完整调整到目标权重，但仍必须遵守调仓步长、上下限和成本纪律。

---

### 12.4 极端风险临时处理

如果日度扫描触发 fail，Agent 可以在非月度调仓日临时降风险。

临时降风险必须满足：

1. 明确说明触发了哪个风险闸门；
2. 明确说明为何进入压力状态；
3. 明确说明临时权重是否突破正常上下限；
4. 明确说明恢复到正常配置区间的条件；
5. 不得借风险事件随意重写整个方法论。

---

## 13. 交易纪律

### 13.1 建仓与加仓

允许加仓的条件：

1. 主线至少中置信度；
2. 价格趋势没有破位；
3. 风险闸门未拦截；
4. 调仓后仍在当前状态对应的资产上下限内；
5. 交易成本可以接受。

不允许加仓的情况：日度扫描只是 normal 或 warning，却试图进行完整重配。

---

### 13.2 减仓与离场

减仓优先处理：

```text
第一优先：趋势破位且下行波动率上升的资产
第二优先：贡献组合回撤最多的资产
第三优先：估值过热且动量转弱的资产
第四优先：分散价值下降的资产
```

A股可以在压力状态下降至 0%，但需要满足明确风险触发条件。  
正常状态下，不因普通估值偏贵或短期震荡直接清仓 A股。

---

### 13.3 成本纪律

每次调仓前必须考虑：

1. 申购费；
2. 赎回费；
3. 短持有期惩罚；
4. 基金管理费、托管费；
5. 频繁调仓造成的摩擦成本；
6. 执行成本和机会成本。

如果调仓带来的预期改善不足以覆盖成本，默认不交易。

---

## 14. 主线复盘与证伪

### 14.1 每期必须复盘上一期主线

Agent 每期必须检查上一期判断是否仍成立：

```text
上期主线是什么？
上期支持证据是否继续存在？
本期有没有新增支持证据？
本期有没有反向证据？
资产价格是否继续验证该主线？
主线置信度应该上调、维持还是下调？
是否需要改变主线？
```

---

### 14.2 主线证伪

以下情况出现，必须降低主线置信度：

1. 宏观证据不再支持；
2. 资产价格不再验证；
3. 反向证据明显增强；
4. 主线方向配置后组合回撤扩大；
5. 主线频繁切换但收益不明显；
6. 市场进入快速轮动，趋势不持续。

---

### 14.3 方法论迭代边界

Agent 可以更新市场主线和权重，但不能随意重写方法论。

只有在以下情况中，才允许建议进行方法论更新：

1. 连续多期主线误判；
2. 风险闸门未能阻止明显回撤；
3. 数据口径发生变化；
4. 资产池发生变化；
5. 回测显示某条规则长期无效；
6. 交易日志显示 Agent 经常误解某条规则。

方法论更新必须留痕，说明：

```text
原规则是什么；
问题出在哪里；
新规则如何修改；
修改后可能带来的风险。
```

## 16. Belief / 证据记录规范

大类资产配置 Agent 的证据记录应以组合为对象，而不是以单一指数为对象。

建议使用：

```yaml
belief:
  schema: v1
  target_portfolio: multi_asset_allocation
  regime:
    current: easing_trade
    confidence: medium
  portfolio_view:
    state: Normal
    risk_level: neutral_cautious
  evidence:
    - { type: macro, ref: "date_macro_snapshot", summary: "...", polarity: "+" }
    - { type: technical, ref: "date_equity_trend", summary: "...", polarity: "+" }
    - { type: rates, ref: "date_bond_yield", summary: "...", polarity: "+" }
    - { type: commodity, ref: "date_gold_trend", summary: "...", polarity: "-" }
  activity_self_check:
    evidence_count: 4
    four_assets_checked: true
    weights_sum_to_100: true
    within_bounds: true
    ok: true
```

不应继续使用：

```yaml
target_index: hs300
```

除非该字段只是 A股子资产的局部证据，而不是组合目标。

证据类型规则：

1. 只有真实调用 research_search / research_view 时，才能标记为 research；
2. 宏观数据标记为 macro；
3. 技术趋势标记为 technical；
4. 利率数据标记为 rates；
5. 商品或黄金数据标记为 commodity；
6. 资金和情绪数据标记为 flow / sentiment。

## 17. 降级规则

当 Agent 遇到不确定情况时，必须按以下规则降级：

| 情况 | 降级动作 |
|---|---|
| 主线证据冲突 | 判断为无主线震荡 |
| 主线没有价格验证 | 最高只能中置信度 |
| 数据缺失 | 不使用该指标，降低置信度 |
| 四类资产证据不完整 | 不进行完整调仓 |
| 资产性价比不明确 | 不做修正 |
| 权重冲突无法归一 | 回到战略中枢 |
| 日度扫描 normal | 不交易，仅记录 |
| 日度扫描 warning | 暂停加风险 |
| 日度扫描 fail | 进入压力状态，可临时降风险 |
| 风险闸门 fail | 降低风险 |
| 交易成本不划算 | 不交易 |
| 连续误判 | 进入方法论复盘，不临场乱改 |

## 18. 核心原则总结

```text
1. 战略中枢是组合长期底盘，不能因短期波动频繁改变。
2. 正常状态下，A股不轻易降至0%，防止组合退化成现金择时。
3. 压力状态下，A股可以临时空仓，但必须有明确风险触发。
4. 无主线震荡不等于全仓现金。
5. 日度只做风险扫描，不做常规重配。
6. 周度复核市场主线，月度生成正式配置。
7. 重大风险不可预测，因此日度扫描是必要的。
8. 主线必须经过宏观证据、价格验证、反向证据和持续性检验。
9. 没有高置信度主线，不做完整战术偏离。
10. 资产性价比只做小幅修正，不重新决定方向。
11. 风险闸门不参与常规权重优化，只在异常情况下限制加仓或强制降风险。
12. 高波动不一定是坏事，回撤扩大和趋势破位才是真风险。
13. 默认低换手，看不清就不做。但是这并不是你偷懒的理由。
14. 每期必须复盘上一期主线是否仍成立。
15. 组合目标是争取接近10%收益并控制5%以内回撤，但不承诺达成。
```
