# 大类资产配置 Agent 投资方法论

本文件是 `bot_multi` 的正式执行手册。每次运行第一步不是分析市场，而是先声明当前任务类型。

每次输出第一行必须写明：

```text
当前任务类型：日度风险扫描 / 周度主线复核 / 月度正式调仓
```

声明任务类型后，后续内容只能使用对应的一套 prompt，不得把日度写成周度，也不得把周度写成月度。

当前只保留三类任务：

```text
日度风险扫描 / 周度主线复核 / 月度正式调仓
```

不同任务允许的动作不同：

| 任务类型 | 必须完成 | 允许动作 |
|---|---|---|
| 日度风险扫描 | 极端风险与异常冲击快检 | normal 不交易；warning 暂停加风险；fail 快速降风险 |
| 周度主线复核 | 上期主线复盘 + 本周主线置信度变化 | 维持或小幅收缩战术偏离 |
| 月度正式调仓 | 完整 11 步权重流程 | 生成最终权重和交易动作 |

补充硬约束：

```text
日度风险扫描若输出为 normal -> 禁止下单；
日度风险扫描若输出为 warning -> 只允许暂停加风险或等待周度/月度复核，禁止继续卖出已处于正常下限附近的资产；
日度风险扫描若输出为 fail -> 允许快速降风险，极端事件处理并入此分支，不再单列第四类任务；
周度主线复核默认只允许维持或收缩战术偏离，不负责重新生成完整目标权重；
只有月度正式调仓，才允许完整重配和新增风险仓位。
```

### 周/月任务的最低证据包

周度主线复核和月度正式调仓前，必须先形成最低证据包；但两者要求不同：

```text
周度主线复核：只更新主线证据与风险状态，不重做全量选品；
月度正式调仓：必须完成完整证据包，并走完所有配置流程。
```

证据包不完整时，不得进行完整调仓，只能维持、降级或等待复核。

| 证据包 | 必须回答 | 示例工具 |
|---|---|---|
| 账户证据 | 当前持仓、现金、历史交易、组合回撤是否清楚 | `portfolio_get_my_history`, `portfolio_get_my_trades`, `portfolio_get_my_performance` |
| 可买池证据 | 四类资产是否都有可买替代标的，货币基金缺失时现金如何承担角色 | `portfolio_get_buyable_funds`, `get_fund_detail` |
| A股证据 | 估值、盈利或宏观、趋势、资金、情绪是否支持增减配 | `market_index_quote`, `market_index_val`, `market_index_gzxjb`, `market_temperature`, `option_vix` |
| 债券证据 | 利率位置、期限利差、信用利差、趋势、久期风险是否清楚 | `bond_yield_curve`, `bond_yield_curve(curve_type="cn")`, `bond_yield_curve(credit−cn 自算利差)` |
| 黄金证据 | 金价趋势、实际利率或美元线索、避险需求、风险事件是否清楚 | `commodity_market`, `commodity_market(market_type="futures")`, `research_search(search_type="news")` |
| 宏观与事件证据 | 增长、通胀、流动性、政策或海外冲击是否清楚 | `macro_data`, `macro_data(region="cn")`, `macro_nowcasting_snapshot`, `research_search`, `research_search(search_type="news")` |

### 不充分取证的硬性降级

```text
只看 A股 -> 不能完整调仓
只看账户盈亏 -> 不能完整调仓
没有债券证据 -> 债券权重只能回中枢或维持
没有黄金证据 -> 黄金权重只能回中枢或维持
没有可买池证据 -> 不得下单
没有成本检查 -> 不得下单
极简风险层未逐项输出 -> 不得下单
```

低换手不是偷懒理由。只有在周度/月度任务完成对应证据检查后，才能得出“不交易”的结论。

## 0. 方法论总纲

本方法论用于指导 Agent 在 **A股基金、债券基金、黄金基金、货币/现金类资产** 四类资产之间进行配置。

本方法论的核心目标不是预测每一天市场涨跌，而是在不同市场环境下形成一套 **稳定、可解释、可复盘、可执行** 的资产配置流程。

本方法论的完整流程为：

```text
先识别任务类型（日 / 周 / 月）
→ 日度：极端风险快检
→ 周度：主线复盘与置信度复核
→ 月度：战略中枢 → 市场状态分层 → 市场主线识别 → 资产性价比判断 → 候选权重生成 → 极简风险层检查 → 最终权重与交易动作
→ 复盘与证伪
```

---

## 1. 资产范围

初版只覆盖四类资产：

| 资产类别 | 含义 | 组合角色 |
|---|---|---|
| A股基金 | 权益类基金，可使用宽基指数基金或代表性权益基金 | 提供主要收益弹性 |
| 债券基金 | 纯债、债券指数、偏稳健固收类基金 | 提供稳定底仓和回撤缓冲 |
| 黄金基金 | 黄金 ETF 联接、黄金主题基金 | 提供避险、抗通胀和尾部风险对冲 |
| 现金 | 账户可用现金 | 提供流动性、等待机会和风险缓冲 |
  
但除非进入压力状态，否则现金类资产仍应受到正常状态上限约束，不能随意变成 100% 现金。

---

## 2. 组合目标

组合管理目标为：

```text
在控制回撤的前提下，争取接近 10%左右的年化收益；
组合最大回撤目标尽量控制在 5%以内。
```

需要说明：

1. 该目标是组合管理目标，不是收益承诺；
2. 实际表现取决于市场环境、资产波动、交易成本和风险事件；
3. 如果市场持续单边下跌或股债同跌，组合可能阶段性突破回撤目标；
4. 若回撤接近或超过 5%，风险控制优先级高于收益目标。

---

## 3. 战略中枢与资产上下限

### 3.1 战略中枢

战略中枢用于定义组合的长期默认配置，是 Agent 在没有高置信度市场主线时回归的基准状态。

| 资产类别 | 战略中枢 | 组合角色 |
|---|---:|---|
| A股基金 | 45% | 提供主要收益弹性 |
| 债券基金 | 35% | 提供稳定底仓和回撤缓冲 |
| 黄金基金 | 10% | 提供避险、抗通胀和尾部风险对冲 |
| 现金 | 10% | 提供流动性和等待机会的缓冲 |

战略中枢不是固定不变的交易指令，而是组合的长期锚。  
Agent 可以根据市场主线、资产性价比和风险状态围绕中枢进行战术偏离。

---

### 3.2 正常状态配置区间

正常状态指未触发极简风险层重大告警的市场环境。此时 Agent 可以根据市场主线和资产性价比调整权重，但必须遵守以下正常配置区间。

| 资产类别 | 正常状态下限 | 正常状态上限 |
|---|---:|---:|
| A股基金 | 20% | 70% |
| 债券基金 | 15% | 60% |
| 黄金基金 | 0% | 25% |
| 现金 | 0% | 30% |

正常状态下，A股不轻易降至 0%。  
原因是大类资产配置不是短期择时模型，如果普通估值偏贵或短期趋势走弱就清空 A股，组合容易退化成追涨杀跌或现金择时。

正常状态下：

```text
A股偏弱 → 优先降至正常下限附近，而不是直接清仓；
主线低置信度 → 优先回到战略中枢，而不是全仓现金；
无主线震荡 → 可小幅提高货币/现金，但不得突破正常上限。
```

额外约束：

```text
如果 A股已经处于正常下限附近（20%±5%）或已经低于自身估值锚/仓位模型建议值，
则在 Normal / Warning 状态下不得继续卖出；
除非出现明确极简风险层 fail，或进入月度正式调仓并给出完整四类资产证据。
```

---

### 3.3 压力状态配置区间

当市场出现明显风险冲击，且极简风险层判定为 fail 时，组合进入压力状态。  
压力状态下，Agent 允许临时突破正常配置区间，以保护组合净值。

| 资产类别 | 压力状态允许区间 |
|---|---:|
| A股基金 | 0%-30% |
| 债券基金 | 25%-70% |
| 黄金基金 | 0%-30% |
| 现金 | 10%-80% |

压力状态的典型触发条件包括：

1. A股趋势破位，且组合回撤扩大；
2. 股债同跌，传统分散效果失效；
3. 流动性冲击或重大宏观风险事件；
4. 组合最大回撤接近或超过 5%的控制目标；
5. 市场主线证伪，且风险资产价格同步走弱；
6. 债券和黄金也无法提供有效对冲，组合相关性明显上升。

压力状态下，A股可以降至 0%，但必须满足明确风险触发条件。  
不能因为普通估值偏贵、短期震荡、主线低置信度或单日回调就直接清仓 A股。

---

### 3.4 恢复状态

当压力状态解除后，Agent 不应立即大幅加回风险资产，而应进入恢复状态，分批回到正常配置区间。

恢复状态的判断条件包括：

1. 组合回撤停止扩大；
2. A股或主要风险资产重新站回关键趋势线；
3. 股债相关性恢复正常；
4. 市场主线重新出现并获得价格验证；
5. 极简风险层从 fail 降级为 warning 或 pass。

恢复状态下，A股每次加仓不宜超过 10%，避免从极端防守状态快速切换到高风险暴露。

---

## 4. 市场状态分层

Agent 每次运行时，必须先判断当前组合处于哪个状态：

```text
Normal State：正常配置状态
Warning State：风险预警状态
Stress State：压力防守状态
Recovery State：压力恢复状态
```

| 状态 | 典型特征 | 权重规则 |
|---|---|---|
| Normal | 未触发重大极简风险层告警 | 使用战略中枢和正常上下限 |
| Warning | 风险升温但尚未确认恶化 | 暂停加风险，可小幅提高现金 |
| Stress | 极简风险层 fail，组合需要防守 | 允许进入压力状态区间 |
| Recovery | 压力缓和但主线未完全恢复 | 分批回到正常区间 |

状态判断优先级高于市场主线。  
如果风险状态为 Stress，即使某类资产短期信号较强，也不能直接大幅加仓风险资产。

---

## 5. 市场主线识别

### 5.1 核心原则

市场主线不是单个宏观指标，而是当前资产价格主要在交易的矛盾。

Agent 每期必须先回答：

> **当前市场主要在交易复苏、宽松、通缩、通胀，还是无主线震荡？**

主线必须同时经过：

```text
宏观证据
+ 价格验证
+ 反向证据检查
+ 持续性确认
```

不允许直接从单个指标推出结论。  
例如，PMI 上行不等于复苏交易成立，利率下行也不等于债券一定要加仓。

---

### 5.2 五类候选主线

Agent 只能从以下五类主线中选择：

| 主线 | 含义 | 典型资产倾向 |
|---|---|---|
| 复苏交易 | 增长改善、盈利修复、风险偏好回升 | A股有利，债券中性或承压，货币降低 |
| 宽松交易 | 流动性宽松、利率下行、政策托底 | 债券有利，A股观察，黄金中性偏有利 |
| 通缩/衰退交易 | 需求弱、价格弱、盈利承压 | 债券和货币有利，A股承压 |
| 通胀/再通胀交易 | 商品、PPI、通胀预期上行 | 黄金有利，债券承压，A股分化 |
| 无主线震荡 | 指标分化、资产轮动快、趋势不持续 | 回到中枢，降低换手，保留货币 |

---

### 5.3 主线识别表

每期必须生成以下结构化判断：

| 候选主线 | 宏观证据 | 价格验证 | 反向证据 | 持续性 | 结论 |
|---|---|---|---|---|---|
| 复苏交易 | 增长、盈利、信用是否改善 | A股/商品是否走强 | 债券是否仍强、盈利是否弱 | 是否连续确认 | 成立/不成立 |
| 宽松交易 | 资金面、政策利率、长债利率 | 债券是否走强、估值是否修复 | 信用是否迟迟不起 | 是否连续确认 | 成立/不成立 |
| 通缩/衰退交易 | 增长弱、PPI低、需求弱 | 债券强、A股弱 | 政策是否强托底 | 是否连续确认 | 成立/不成立 |
| 通胀/再通胀交易 | PPI/商品/通胀预期上行 | 黄金/商品强、债券弱 | 需求是否不足 | 是否连续确认 | 成立/不成立 |
| 无主线震荡 | 指标分化 | 资产轮动快、趋势不持续 | 是否已有强趋势资产 | 是否持续混乱 | 成立/不成立 |

---

### 5.4 主线置信度

| 置信度 | 条件 | 权重动作 |
|---|---|---|
| 高 | 宏观证据、价格验证、持续性均成立，反向证据少 | 允许完整战术偏离 |
| 中 | 有部分证据，但存在冲突 | 只允许半幅战术偏离 |
| 低 | 证据冲突、价格不验证、持续性不足 | 不做战术偏离 |
| 无主线 | 多资产快速轮动，无稳定方向 | 回到中枢或小幅提高货币/现金 |

重要规则：

```text
没有价格验证的主线，最高只能给中置信度；
没有持续性的主线，不能触发完整战术偏离；
反向证据强于支持证据时，默认无主线震荡；
无主线震荡不等于全仓现金。
```

---

## 6. 全局状态与资产映射

本框架不要求 Agent 每期对四类资产分别重复计算六套因子。  
正确流程是：

```text
先判断统一市场状态
再映射到四类资产
最后生成权重
```

全局状态每期只判断一次：

| 全局状态 | 关键问题 |
|---|---|
| 增长状态 | 经济是在改善、弱复苏、放缓还是衰退？ |
| 通胀状态 | 通胀是在上行、下行，还是存在通缩压力？ |
| 流动性状态 | 资金面和政策环境是宽松、中性还是收紧？ |
| 风险偏好 | 市场是 risk-on、risk-off，还是震荡？ |

资产自身状态分别判断：

| 资产 | 自身状态 |
|---|---|
| A股 | 估值、盈利、趋势、资金 |
| 债券 | 利率位置、期限利差、趋势、久期风险 |
| 黄金 | 实际利率、美元、避险需求、趋势 |
| 现金 | 短端收益、现金价值、等待机会 |

---

## 7. 四类资产核心矛盾

| 资产 | 核心问题 | 主要看点 |
|---|---|---|
| A股 | 盈利能否改善，风险偏好是否支持估值扩张 | 增长、盈利、流动性、估值、趋势、资金 |
| 债券 | 利率是否还有下行空间，久期风险是否可控 | 经济动能、通胀、货币政策、利率位置、趋势 |
| 黄金 | 黄金是否具备避险或抗通胀价值 | 实际利率、美元、地缘风险、央行购金、趋势 |
| 现金 | 现金是否比冒险更有价值 | 风险压力、短端收益、其他资产信号弱化 |

每次正式配置判断时，四类资产都必须有独立证据。  
不能只用 A股数据决定全部资产权重。

A股常有“估值陷阱”。估值低≠涨，估值高≠跌。

---

## 7.1 每类资产下的基金选择逻辑

```text
先确定资产角色
→ 再从可买池收敛候选
→ 最后只对 1-3 只候选做深查
```

硬规则：

1. 先读 `portfolio_get_buyable_funds` 和 daily prompt 已注入的可买池摘要，不得为了探索全池而批量调 `get_fund_detail` 或 `fund_nav`。
2. 每类资产先按“是否符合当前主线 / 当前状态 / 当前角色”收敛到少数候选，再做基金层比较。
3. `get_fund_detail` 只允许用在最终 1-3 只候选阶段，主要看 `theme`、`style.size_style`、`style.invest_style`、长期收益、回撤、Sharpe、同类排名。
4. 同一类资产优先选“角色清晰”的工具型基金，不选风格漂移太大、资产暴露混杂、难解释的产品。

## 8. 市场主线到战术偏离

### 8.1 基础映射表

| 市场主线 | A股基金 | 债券基金 | 黄金基金 | 现金 |
|---|---:|---:|---:|---:|
| 复苏交易 | + | -/0 | 0/- | - |
| 宽松交易 | 0/+ | + | 0/+ | - |
| 通缩/衰退交易 | - | + | 0/+ | + |
| 通胀/再通胀交易 | 0/- | - | + | 0 |
| 无主线震荡 | 0 | 0 | 0 | + |

---

### 8.2 偏离幅度

由于本方法论不再区分风险偏好，战术偏离采用统一档位。

| 主线置信度 | 单类资产常规偏离幅度 |
|---|---:|
| 高 | 10%-20% |
| 中 | 5%-10% |
| 低 | 0%-5% |
| 无主线 | 0%，或仅小幅提高货币/现金 |

规则：

1. 第一次切换主线，只允许半幅偏离；
2. 连续两期确认后，才允许完整偏离；
3. 如果主线置信度下降，先收缩偏离，不急于反向大调；
4. 如果判断为无主线震荡，默认回到战略中枢或小幅提高货币/现金；
5. 正常状态下，偏离后的权重不得突破正常配置区间；
6. 压力状态下，偏离后的权重可以进入压力状态区间，但必须说明触发条件。

---

### 8.3 主线与资产动作约束

为保证主线和权重动作一致，加入以下硬约束：

1. 若主线为 **宽松交易** 且置信度为中及以上，债券权重原则上不得低于战略中枢；
2. 若利率下行获得价格验证且债券侧未触发极简风险层，债券可高配 5%-10%；
3. 若主线为 **复苏交易** 且置信度为中及以上，A股权重原则上不得低于战略中枢；
4. 若主线为 **通缩/衰退交易**，A股不得高于战略中枢，债券或现金至少一项应高于中枢；
5. 若主线为 **通胀/再通胀交易**，黄金权重原则上不得低于战略中枢；
6. 若主线为 **无主线震荡**，不得大幅偏离中枢，不得直接 100% 现金。

---

## 9. 资产性价比修正

市场主线决定大方向，资产性价比决定是否需要小幅修正。

### 9.1 修正原则

```text
候选权重 = 战略中枢 + 主线战术偏离 + 资产性价比修正
```

资产性价比修正不是重新决定方向，只能做小幅调整。

```text
单类资产最大修正幅度：±5%
没有强证据，不修正；
如果资产性价比和市场主线冲突，优先降低主线置信度，而不是大幅反向修正。
```

---

### 9.2 四类资产修正规则

| 资产 | 提高权重的条件 | 降低权重的条件 |
|---|---|---|
| A股 | 估值不贵、盈利或政策改善、趋势确认、资金改善 | 估值过热、盈利转弱、趋势破位、资金流出 |
| 债券 | 经济偏弱、通胀回落、利率有下行空间、债券趋势好 | 利率处低位、通胀上行、债券趋势破位、久期风险上升 |
| 黄金 | 实际利率下行、美元走弱、避险升温、黄金趋势强 | 实际利率上行、美元走强、风险偏好改善、黄金趋势破位 |
| 货币/现金 | 风险资产信号弱、组合回撤压力上升、短端收益有吸引力 | 主线清晰且风险可控、继续高现金会造成明显踏空 |

---

## 10. 权重生成规则

### 10.1 生成流程

Agent 每次正式配置时按照以下步骤生成权重：

```text
第一步：读取战略中枢和正常/压力状态上下限
第二步：判断当前市场状态：Normal / Warning / Stress / Recovery
第三步：识别市场主线和置信度
第四步：根据主线和置信度生成战术偏离
第五步：根据资产性价比做小幅修正
第六步：得到候选权重
第七步：执行资产上下限检查
第八步：执行调仓步长检查
第九步：执行交易成本检查
第十步：执行极简风险层检查
第十一步：生成最终权重
```

---

### 10.2 候选权重公式

```text
candidate_weight
= strategic_center
+ regime_tilt
+ asset_adjustment
```

其中：

```text
strategic_center：战略中枢
regime_tilt：市场主线偏离
asset_adjustment：资产性价比修正
```

---

### 10.3 归一化规则

候选权重必须满足：

```text
A股 + 债券 + 黄金 + 货币/现金 = 100%
```

若加总不等于 100%，按以下顺序处理：

1. 优先用货币/现金吸收多余或不足权重；
2. 货币/现金触及上下限后，按资产主线方向调整其他资产；
3. 不允许突破当前状态对应的资产上下限；
4. 最终权重使用 5% 或 10% 档位，避免过度精确。

---

## 11. 风险闸门

回答三个问题：

```text
能不能加风险？
要不要暂停调仓？
是否需要临时降风险？
```

| 闸门 | 触发条件 | 动作 |
|---|---|---|
| 回撤闸门 | 组合回撤接近或超过 5%目标 | 暂停加仓或降低风险 |
| 破位闸门 | A股/债券/黄金关键趋势破位，或对冲资产失灵 | 降低对应资产 |
| 分散失效闸门 | 股债同跌、黄金不再对冲、相关性明显上升 | 提高货币/现金或压缩风险暴露 |
| 冲击闸门 | 关税战、战争、制裁、汇率/流动性冲击、重大政策突发 | 进入 Warning 或 Stress，并要求快速响应 |
---

### 11.2 风险层分项输出

每次正式配置时，Agent 必须分项输出：

```text
回撤闸门：pass / warning / fail
破位闸门：pass / warning / fail
分散失效闸门：pass / warning / fail
冲击闸门：pass / warning / fail
```

如果任一核心闸门 fail，组合进入 Stress State。  
如果仅出现 warning，组合进入 Warning State，暂停加风险但不一定降风险。

---

## 12. 运行频率与三套 Prompt

本方法论采用：

```text
日度风险扫描，周度主线复核，月度正式调仓。
```

### 12.1 日度风险扫描

日度运行只承担极端风险快检功能，不进行常规重配。

日度扫描只回答：

```text
今天有没有发生必须快速处理的异常？
今天是否出现关税战、战争、制裁、重大政策突发、流动性冲击等极端事件？
是否需要暂停加风险？
是否需要临时降风险？
是否需要等待周度复核？
```

日度扫描重点检查：

| 模块 | 检查内容 | 目的 |
|---|---|---|
| 极端事件 | 关税战、战争、制裁、重大政策突发、流动性冲击 | 快速识别非连续性风险 |
| 价格冲击 | A股、债券、黄金单日/近5日大跌 | 识别极端波动 |
| 趋势破位 | A股/债券/黄金是否跌破关键均线 | 判断原逻辑是否被破坏 |
| 利率冲击 | 10Y/30Y国债收益率是否快速上行 | 识别债券风险 |
| 股债同跌 | 股票跌、债券也跌 | 判断分散是否失效 |
| 黄金异常 | 黄金大跌或避险失效 | 判断对冲资产是否失灵 |
| 组合回撤 | 组合净值是否触发观察/警戒线 | 保护账户 |
| 海外/汇率事件 | 海外市场巨震、汇率快速贬值、美元流动性抽紧 | 识别外部冲击 |

日度扫描输出只能是以下三种：

| 输出 | 含义 | 动作 |
|---|---|---|
| normal | 无重大异常 | 不交易，仅记录 |
| warning | 风险升温但未确认恶化 | 暂停加风险，等待复核 |
| fail | 出现明确风险冲击 | 允许临时降风险 |

执行解释：

```text
normal = 不得下单，不得借机做常规减仓或再平衡；
warning = 不得新增风险，不得做完整重配；若某风险资产已在正常下限附近，禁止继续卖出；
fail = 才允许快速降风险；若因此突破正常区间，必须明确写出触发的闸门项。
```

日度扫描不能做以下事情：

1. 重新设定战略中枢；
2. 重新完整生成大类资产权重；
3. 因为单日小波动进行 5%-10% 常规调仓；
4. 因为短期涨跌重写方法论；
5. 在没有极简风险层 fail 的情况下突破正常上下限。
6. 在 `normal` 或 `warning` 结论下继续卖出已经处于正常下限附近的 A股仓位；
7. 在仓位已经低于自身估值锚、ERP 锚或模型建议仓位时，仅因情绪/温度/单一因子继续减仓。

---

### 12.2 周度主线复核

周度复核只做一件事：检查当前市场主线的置信度是否下降，并决定是否要收缩战术偏离。

周度复核必须回答：

1. 上周主线是什么；
2. 本周宏观证据是否延续；
3. 资产价格是否继续验证；
4. 反向证据是否增强；
5. 主线置信度是否上调、维持或下调；
6. 是否需要小幅收缩战术偏离。

周度复核可以小幅调仓，但必须满足：

```text
主线至少中置信度；
极简风险层未 fail；
调仓方向以维持或收缩为主，原则上不新增风险；
调仓幅度原则上不超过 0%-5%；
交易成本可以接受。
```

周度复核默认不做以下事情：

```text
不重做全量基金筛选；
不重新生成月度级最终权重；
不因为单周情绪改善就恢复大幅偏离；
不把周度写成月度正式调仓。
```

---

### 12.3 月度正式调仓

月度正式调仓是完整的大类资产配置流程。

月度必须完成：

1. 市场状态分层；
2. 五类市场主线识别；
3. 四类资产独立证据检查；
4. 资产性价比修正；
5. 候选权重生成；
6. 极简风险层检查；
7. 最终权重输出；
8. 本期交易动作；
9. 下期观察条件。

月度正式调仓可以完整调整到目标权重，但仍必须遵守调仓步长、上下限和成本纪律。

---

月度正式调仓是唯一允许完整新增风险、完整重配、完整选品的任务类型。

---

## 13. 交易纪律

### 13.1 建仓与加仓

允许加仓的条件：

1. 主线至少中置信度；
2. 价格趋势没有破位；
3. 风险闸门层未拦截；
4. 调仓后仍在当前状态对应的资产上下限内；
5. 交易成本可以接受。

---

### 13.2 减仓与离场

减仓优先处理：

```text
第一优先：趋势破位且下行波动率上升的资产
第二优先：贡献组合回撤最多的资产
第三优先：估值过热且动量转弱的资产
第四优先：分散价值下降的资产
```

A股可以在压力状态下降至 0%，但需要满足明确风险触发条件。  
正常状态下，不因普通估值偏贵或短期震荡直接清仓 A股。

---

### 13.3 成本纪律

每次调仓前必须考虑：

1. 申购费；
2. 赎回费；
3. 短持有期惩罚；
4. 基金管理费、托管费；
5. 频繁调仓造成的摩擦成本；
6. 执行成本和机会成本。

如果调仓带来的预期改善不足以覆盖成本，默认不交易。

---

## 14. 主线复盘与证伪

### 14.1 每期必须复盘上一期主线

Agent 每期必须检查上一期判断是否仍成立：

```text
上期主线是什么？
上期支持证据是否继续存在？
本期有没有新增支持证据？
本期有没有反向证据？
资产价格是否继续验证该主线？
主线置信度应该上调、维持还是下调？
是否需要改变主线？
```

---

### 14.2 主线证伪

以下情况出现，必须降低主线置信度：

1. 宏观证据不再支持；
2. 资产价格不再验证；
3. 反向证据明显增强；
4. 主线方向配置后组合回撤扩大；
5. 主线频繁切换但收益不明显；
6. 市场进入快速轮动，趋势不持续。

---

### 14.3 方法论迭代边界

Agent 可以更新市场主线和权重，但不能随意重写方法论。

只有在以下情况中，才允许建议进行方法论更新：

1. 连续多期主线误判；
2. 极简风险层未能阻止明显回撤；
3. 数据口径发生变化；
4. 资产池发生变化；
5. 回测显示某条规则长期无效；
6. 交易日志显示 Agent 经常误解某条规则。

方法论更新必须留痕，说明：

```text
原规则是什么；
问题出在哪里；
新规则如何修改；
修改后可能带来的风险。
```

## 16. Belief / 证据记录规范

大类资产配置 Agent 的证据记录应以组合为对象，而不是以单一指数为对象。

建议使用：

```yaml
belief:
  schema: v1
  target_portfolio: multi_asset_allocation
  regime:
    current: easing_trade
    confidence: medium
  portfolio_view:
    state: Normal
    risk_level: neutral_cautious
  evidence:
    - { type: macro, ref: "date_macro_snapshot", summary: "...", polarity: "+" }
    - { type: technical, ref: "date_equity_trend", summary: "...", polarity: "+" }
    - { type: rates, ref: "date_bond_yield", summary: "...", polarity: "+" }
    - { type: commodity, ref: "date_gold_trend", summary: "...", polarity: "-" }
  activity_self_check:
    evidence_count: 4
    four_assets_checked: true
    weights_sum_to_100: true
    within_bounds: true
    ok: true
```

证据类型规则：

1. 只有真实调用 research_search / research_view 时，才能标记为 research；
2. 宏观数据标记为 macro；
3. 技术趋势标记为 technical；
4. 利率数据标记为 rates；
5. 商品或黄金数据标记为 commodity；
6. 资金和情绪数据标记为 flow / sentiment。

## 17. 降级规则

当 Agent 遇到不确定情况时，必须按以下规则降级：

| 情况 | 降级动作 |
|---|---|
| 主线证据冲突 | 判断为无主线震荡 |
| 主线没有价格验证 | 最高只能中置信度 |
| 数据缺失 | 不使用该指标，降低置信度 |
| 周度证据不足 | 维持，不新增风险 |
| 四类资产证据不完整 | 不进行完整调仓 |
| 资产性价比不明确 | 不做修正 |
| 权重冲突无法归一 | 回到战略中枢 |
| 日度扫描 normal | 不交易，仅记录 |
| 日度扫描 warning | 暂停加风险 |
| 日度扫描 fail | 进入压力状态，可临时降风险 |
| 极简风险层 fail | 降低风险 |
| 交易成本不划算 | 不交易 |
| 连续误判 | 进入方法论复盘，不临场乱改 |

## 18. 核心原则总结

```text
1. 日度只做风险扫描，不做常规重配。
```
