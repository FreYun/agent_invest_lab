# 沪深300指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面几个**正交**角度审视，自行综合判断该不该动、动多少。

> 沪深300 是大盘价值蓝筹，但**中国 A 股是资金 + 情绪 + 趋势驱动的市场，趋势才是方向的第一信号——尤其牛市，贵可以更贵，踏空整段行情的代价大于一次回调**。估值不是方向的裁判，是**风险刻度 + 仓位上限**：它告诉你这一程能跑多满、止盈该多严，但**不能单维否决"趋势转强 → 加仓"**。估值方法仍要用对（动态、行业中性、相对债券、正交、可证伪），但永远**让位于趋势**。

## 核心认知

沪深300 = 大盘价值蓝筹贝塔（金融 / 消费 / 工业龙头为主），宽基核心资产。三个特性决定玩法：

- **低弹性**：牛市涨幅有限，但熊市回撤也浅——天生的核心底仓料。
- **低波动 / 高流动性**：适合做仓位的"压舱石"，不是做大开大合的弹性品种。
- **盈利稳、分母稳**：成分股盈利波动小，分母不会在周期底部坍塌，PE / 股息率 / ERP 这些估值信号**真的能用**、分位不失真。


### 沪深300 估值特性：
1. 裸 PE/PB 历史分位会被**行业结构漂移**污染（金融权重高拉低绝对 PE，赛道权重升又抬高）——必须行业中性化才可比，否则分位本身就是噪音。
2. 真正承重的口径是**相对债券**：ERP（盈利收益率 − 10y 国债）和股息率 − 10y gap，做动态 z-score。利率中枢一移，同样的 PE 对应的"贵贱"完全不同；低利率会让"看着贵"的估值其实相对债券不贵。
3. 宽基蓝筹估值**有中枢、会回归**，可以做均值回归择时；但阈值必须动态（滚动 z / 分位），不能用固定 5%/3%。
4. **趋势给"哪边"（第一顺位），估值给"这一程能跑多满 + 止盈多严"**——二者叠加择时，但中国市场趋势优先：趋势向上时估值贵只压缩仓位上限、不否决持有 / 加仓；趋势向下时估值便宜也别急着接下跌。沪深300 蓝筹趋势黏性强、减仓宜分批别一把清，但**趋势一旦确认转强就要敢进，别让"还贵"把自己钉在场外**。

## 一、估值视角（沪深300 的风险刻度信号 / 仓位上限，合并 PE/PB/ERP/股息率只算一票）

- **只折一票**：PE 分位、PB 分位、ERP、股息率 gap 高度同源（都在量"贵不贵"），塞进同一维度算**一票**。四个一致不是"四重交叉验证"，是同一信号听四遍。真正的确认来自**别的维度**（盈利 / 资金 / 情绪）同号。
- **行业中性化**：按申万 / GICS 一级行业分组算各行业**组内**估值分位，再用指数权重加权回去——把"结构变了所以不可比"从口号变成计算。经验上裸 90%+ 的"明显贵"经中性化常降到 50–60%，那 ~30pp 是 mix 假象。
- **相对债券（最承重）**：ERP = 盈利收益率(1/PE_ttm) − 10y 国债；股息率 gap = dv_ttm − 10y 国债。都做 **3 年滚动 z-score**，看动态偏离不看静态绝对值。指数级股息率没有现成工具，用**成分股 dv_ttm 按当前指数权重加权**算（weight-drift 近似，标 indicative）。
- **作用（已降级为风险刻度，不再直接定方向）**：估值 z 越负（越贵）→ 压低仓位**上限**、加严止盈，但**不等于减仓、更不等于空仓**；越正（越便宜）→ 放宽上限、提供安全垫。方向交给趋势 + 多维确认。**估值的活儿是"贵了别满仓、便宜了敢多扛"，不是"贵了就清仓"——尤其牛市，极端泡沫预警之外别让它单维主导仓位。**

## 二、盈利视角（重在变化不在水平）

- 看**一致预期修正广度**（上调家数 − 下调家数）/ 覆盖股数，和**前向盈利斜率**（FY2/FY1），不看静态 PE 里的 E 水平。
- 修正广度转负（下调多于上调）= 盈利向下确认，是估值之外的**独立空头确认**；同号才构成交叉验证。
- 口径坑：用 **FY1 远期一致预期**别用 TTM（财报季实际值滚入会污染动量，方向被做反）；前向斜率取**等权中位**别取加权均值（小分母 FY1≈0 会被异常值放大几十个点）。

## 三、资金 / 流动性视角（与估值正交的真·独立信号）

- A股最稳健的流动性领先指标：**M1 − PPI 剪刀差**（M1 同比 − PPI 同比），多年序列做 z / 分位；社融增量做旁证。
- **关键陷阱——必看分解**：剪刀差收窄既可能是 M1 减速（偏空流动性），也可能是 PPI 反弹（reflation，利好名义盈利）。**不可单看符号**：PPI 反弹驱动的收窄反而是工业盈利的上行信号，会成为"看空估值"判断的上行风险。
- 北向资金日频净买若不可得，降级为季度配置参考，并保留"可能反向指标"的警惕（散户化后北向 ≠ 聪明钱）。

## 四、情绪视角（反向使用）

- A股恐慌指数 GVIX（IV 代理）做历史分位 / z：**极低 IV = 自满（偏空）、极高 IV = 恐慌（反向偏多）**；PCR、市场温度计同理反向。
- 情绪是边际 / 择时辅助，不构成主趋势，但在极端值能提示拐点。
- z 在 ±1 内 = 中性、不反向，**别硬解读**——没有极端就当它不投票。

## 五、宏观视角（中长期参考，显式控过拟合）

- 汇率、实际利率、信用脉冲等只做**中长期环境定性**，不做精确择时。
- **显式限制权重**：宏观变量多、易过拟合，宁可少用几个，也不堆一堆回归出"精确"信号。自由度纪律：因子数 ≤ √样本量。

## 六、证伪视角（对称化）

证伪不是技术信号，是**论据的破坏**，而且必须**对称**——既列"看空被证伪"（上行风险），也列"看多被证伪"（下行风险）。只测一个方向是 v1 的毛病。任一触发不等于立刻反手，但意味着原论据已不成立，需要新论据才能继续持有。

- **看空（偏低配）被证伪 / 上行 veto-watch**：**指数重新站稳 MA60 / 进入上行趋势——这是最强一条，趋势转多即应解除空仓、恢复底仓，不必等估值变便宜**；PPI 持续反弹并传导到工业盈利；修正广度由负转正；剪刀差因 **M1 加速**（非 PPI）走阔；估值动态 z 回到中枢上方。
- **看多（偏超配）被证伪 / 下行 veto-watch**：盈利修正广度转负且加速；ERP / 股息 gap 动态 z 跌破 −1；流动性剪刀差因 M1 减速收窄；情绪从恐慌快速转向自满。

# 仓位管理方法论
## 唯一信仰：趋势定方向 + 估值定上限 + 正交确认 + 概率化倾斜

- 沪深300 是**趋势锚方向 + 估值锚风险上限 + 多维正交确认 + 概率化仓位倾斜**的核心底仓打法。**中国市场趋势 > 估值，尤其牛市。**
- 不抓顶底，只做：**趋势向上 + 多维同号则敢配、趋势向下则收**；估值只调"配多满"——贵则封顶、便宜则放宽，**绝不让估值单维把仓位锁在 0**。
- 加仓要 **≥2 个正交维度同号**，但**趋势可作为其中独立的一票**（不再要求"估值必须同号才动"）。单一维度不足以重仓，同源指标一致不算。
- **活下来比赚得快重要，但踏空整段牛市也是一种"没活好"**：沪深300 是压舱石，系统性风险来时少亏、把组合夏普托住；可一旦趋势确认向上，**该上的仓不上、被估值钉在场外，同样是失职**。

## 一、综合打分：正交维度加权 → 仓位倾斜

```
Composite_z = w_trend·z_trend + w_val·z_val + w_earn·z_earn + w_liq·z_liq + w_macro·z_macro + w_sent·z_sent
```

- 权重用**固定先验**，且**趋势是方向主力**：趋势 0.30、估值 0.25、盈利 0.20、资金 0.15、情绪 0.10、宏观从轻（中国市场趋势 > 估值、尤其牛市，故趋势权重首位、估值退居其后）。**刻意不做回测拟合**——可得样本太薄（月频宏观 ~7 年、情绪序列更短），拟合权重必然过拟合，做出的"精确权重"比简单先验更不可信。
- **趋势 z 的方向否决力（非对称）**：Composite_z 偏多但**趋势 z 明确转负（破位）**→ 以趋势为准、压低仓位；反之**趋势 z 明确转强**→ 即便估值 z 很负（贵），也**只压上限、不把仓位压到 0**。估值的极端读数只能封顶，不能单维主导方向。
- 映射到仓位倾斜（**滚动标准化后**）：

| Composite_z | 仓位倾斜 | 含义 |
|---|---|---|
| > +1.5σ | 显著超配 | 多维同号偏低估 |
| +0.5 ~ +1.5σ | 温和超配 | |
| −0.5 ~ +0.5σ | 中性 | 信号冲突或灰区 |
| −1.5 ~ −0.5σ | 温和低配 | |
| < −1.5σ | 显著低配 | 多维同号偏高估 |

- **置信度**：同号维度越多 → 倾斜越大；维度冲突 → 收窄倾斜、回归中性。**真正的交叉验证是跨正交维度同号，不是同源指标一致。**
- **诚实纪律**：既然不信精确权重，输出只取**方向 + 档位**（中性 / 轻微 / 温和 / 显著），**不报"低配 X%"的伪精确数值**。

## 二、动态阈值，不用固定线

- 所有"贵 / 便宜""高 / 低"都用**滚动窗口 z-score 或滚动分位偏离**，不用固定 5%/3%。利率中枢、估值中枢会漂移，固定阈值必然钝化、迟早失效（固定 ERP 阈值在利率下行期会一直误报"便宜"）。

## 三、趋势给方向（第一顺位），估值给风险刻度 —— 兼破"逃顶后锁死"单向陷阱

中国 A 股是资金 + 情绪 + 趋势驱动，沪深300 虽低弹性但 beta 趋势属性真实、蓝筹趋势黏性强。**方向第一看趋势，估值定这一程的仓位上限与止盈纪律**：

- **趋势转强 = 独立的加仓通道**：指数站上并站稳 MA60（或明确进入上行趋势）**+ 任一非估值维度同号**（资金面回暖 / 情绪触底反向 / 盈利修正转正）→ 即可建 / 恢复 ≥40% 底仓，**哪怕 ERP / 估值仍在低分位**。注意不是"单看 MA 翻仓"——MA5/MA20 只是短期情绪，要看 MA60/120/200 的趋势锚 + 一个正交维度确认。低估值分位此时只把仓位上限压到 60–80%、要求止盈更严，**不构成不进场的理由**。
- **🔴 破单向陷阱（对症硬规则）**：清仓 / 空仓后，**再进场绝不能被估值单维否决**。历史教训——ERP 3y 分位在低利率环境会长期卡在 1–5% 的极低区间，若把它当加仓前置条件，会一卖就再也回不来、系统性踏空整段行情。**只要趋势重新转强 + 一个非估值维度同号，就回 ≥40% 底仓，估值低分位仅封顶、不封零。**
- 估值偏贵 + 趋势仍强：**继续持有、不急减**（牛市贵可以更贵），只压上限、严止盈，趋势真破位再分批减。
- 估值便宜 + 趋势转强：最舒服的**加仓窗口**，可以加得果断些。
- 估值便宜 + 趋势仍弱：**别接下跌**，等趋势确认；便宜只是安全垫，不是扳机。
- 趋势向下破位：这是减仓的**第一理由**（高于估值），分批降、别一把清、也别硬扛。

## 四、回撤控仓（夏普命脉）

- **账户级净值回撤是高于单笔信号的总开关**：从峰值明显回撤就降仓、暂停加仓，哪怕维度信号还没转向。回撤往往是连续错误堆出来的，这是"防止一错再错"的闸门。
- 回撤数学不对称：-20% 需 +25% 回本、-33% 需 +50%、-50% 需翻倍。先定"最多能承受多少回撤"，再反推该不该降仓——不是先想能赚多少。
- 蓝筹波动虽低，但系统性风险（流动性危机、政策冲击）来时同样要快降仓，别因为"它是蓝筹"就硬扛。

## 五、成本意识

- ETF / 基金的申赎费 + **7 日内早赎 1.5% 惩罚**——一笔进出要能赚回成本才值，避免同标的 7 日内 round-trip。沪深300 是底仓品种，本就不该高频折腾。

## 六、防过拟合 / 数据诚实纪律

- 维度数压到 **≤ √样本量**；样本不足时**诚实退回固定先验 / 等权，不硬拟合**——拟合出的精确权重比诚实的简单先验更危险。
- 🔴 来源（散户回测、无署名"资料"、记忆数据）只能**提假设，不作结论承重**。
- 所有数字标 **source / as-of / 口径**；矛盾处标 `{{待核}}`，核验前不进决策。

## 七、实战判断：环境决定用哪条

格言大多成对矛盾，同一句在不同环境给相反指令——经验不是背格言，是认清当下环境该用哪条。沪深300 的环境抓手就是前面的**趋势方向（第一）+ 动态估值 + 盈利方向 + 流动性分解**。

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 趋势没破、牛市贵能更贵 | 估值贵了该减仓 | **趋势优先**：趋势未破只压上限 + 严止盈、不清仓；趋势破位才是减仓第一理由 |
| 估值贵了该减 | 低利率下贵是合理的 | 看 **ERP 动态 z（相对债券）**，不看裸 PE 分位 |
| 盈利下修该谨慎 | 盈利见底是底部信号 | 看修正广度**方向** + PPI reflation 是否传导 |
| 剪刀差收窄=流动性转差 | 收窄=PPI 反弹利好盈利 | 必看**分解**：M1 减速 vs PPI 反弹 |
| 别人恐慌我贪婪 | 顺势不接下跌 | GVIX 极端 **且** 估值同时便宜才贪婪，否则顺势 |
| 估值便宜该加 | 单维度不重仓 | 估值便宜 + **≥2 维同号**才加大倾斜 |

## 八、量化择时辅助：`quant_factor` 工具里的 `hs300_erp_vix_timing`

研究室离线挖出的沪深300 单指数择时因子，包在 `simworld-mcp.quant_factor` 里。**客观第二意见，不替代框架打分。**（另：市场级市场情绪指数反向 `market_sentiment_*` 见 AGENTS「机构数据优势」，任何指数可用。）

### `hs300_erp_vix_timing` —— 估值×情绪极值 风险管理择时（黄灯/探索性）
- **是什么**：沪深300 股债性价比（ERP，3 年分位，**正是你框架里最承重的相对债券估值锚**）定基仓 + 50ETF VIX 252 日 z 极值调整——便宜+恐慌（z>1.5）偏多加仓、贵+自满（z<−1.5）偏空减仓，输出 0–1 建议仓位 + 估值/情绪状态读数。它把你格言表里那条 **"GVIX 极端且估值同时便宜才贪婪"** 打包成了一个量化读数。
- **底气**：研究室离线经 IS/OOS 验证的探索性因子（黄灯），核心 edge 是把你格言里"估值便宜 + 情绪恐慌"的双极值打包成一个量化读数。**作客观第二意见、不承重、权重 ≤ 框架主维度。**
- **会漏什么**（公式可推）：① 是**降回撤工具、不是收益增强器**——牛市持续上涨时低暴露让出绝对涨幅，只赢风险调整后收益；② ERP 绝对水平受利率 regime 影响（低利率、债券收益率走低时股票相对显"贵"，因子偏防御、可能过早减仓）——与你"裸 PE 分位会骗人、要看 ERP 动态 z"的纪律一致，**别把因子的'贵'当绝对真理**；③ 超额集中在急跌后的 V 型反弹，磨人长熊里反弹后置。
- **怎么用**：与框架的多维正交打分**对照**——同号时作加仓/减仓确认的一票（尤其"便宜+恐慌"双低，与你的估值锚 + 情绪反向同号，是较果断的加仓窗口）；冲突时逐项核验谁在抢拐点。**权重 ≤ 框架主维度，且趋势上行时它的"贵 → 减仓"建议要让位于趋势**——这因子本质是降回撤工具、在低利率 / 牛市里会系统性偏空踏空（低利率 regime 下债券收益率走低使股票相对显"贵"、因子偏防御、可能过早减仓），**绝不能让它的减仓读数把你在上行趋势里锁进空仓**。别当机械规则。

> **核心一句**：沪深300 在中国市场靠**趋势给方向（趋势 > 估值，尤其牛市）**、**行业中性 + 相对债券的动态估值给仓位上限与止盈纪律**、**正交维度同号给置信度**、**固定先验 + 概率化倾斜给仓位**——趋势向上敢配、向下则收，贵则封顶不封零、便宜则放宽，不抓顶底、**不被估值单维锁死**、靠纪律压回撤。
