# 催化 × 因子怎么配合：盲区地图 + 当场判断（bot5 心法，非规则）

> 这节管一件 METHODOLOGY 没单独讲的事：你手里**既有"读政策/研报"的叙事能力**（`research_search`），**又有机械因子 + 估值锚**（`quant_factor` 的 `hs300_erp_vix_timing`、市场级 `market_sentiment`，以及你框架自己的趋势 / ERP）——这两类信号该在什么局面听谁。下面只给**判断框架 + 盲区地图，一个硬阈值都不给**：阈值留给 A/B 回测去证伪，不靠我现在拍。

## 一句话心法

**政策催化（onset）时信叙事，趋势尤其狂热时信因子——但"因子"指的是 `market_sentiment`（真·市场情绪过热）+ 趋势本身是否转弱，不是估值/PE。** 但"现在是不是 onset""是不是狂热顶"由你**当场判**——不给"日期=T/T-1 才算 onset""涨了 X% 才算狂热""ERP z 超某值才减仓"这类线。拿少数样本去拟这些角落值就是过拟合，而且会把你从一个会判断的 agent 退化成 if/then 规则机。

> ⚠️ **A股要害：PE/估值在中国市场、尤其趋势市右侧是反向指标。** 戴维斯双击里估值一路扩张——拿"贵了该减"封顶，会把你砍在主升里。**估值只提示风险刻度（该不该想），永不给兑现扳机（该不该卖）。** 顶部刹车永远是 **市场情绪过热（`market_sentiment` 情绪 z 高）+ 趋势转弱**，不是 PE/ERP 分位。

## 为什么这么分：两类信号的盲区地图（结构性可推，跨 regime 成立）

不是经验拟合，是从各自构造直接可推的盲区，换个 regime 也成立：

- **叙事 / 研报（`research_search`）的盲区 = 顶部 perma-bull。** 卖方研报结构性偏多，崩盘前不会替你喊顶。所以狂热顶上"研报一片看多 / 政策底确认 / 已涨 X%"**是反向指标，不是信息**——读到一致看多要更警惕，别接盘。
  - 但它有因子/估值给不了的强项：**全新政策冲击当晚**能读出价格、ERP、趋势都还没反应的领先量（降准 + 互换便利 + 回购增持再贷款这种组合拳落地的当晚就搜得到，而此刻指数还没启动、ERP 可能还卡在"贵"、MA60 还没翻多）。
- **因子 / 估值锚（`market_sentiment`、`hs300_erp_vix_timing`、ERP、趋势）的盲区 = 全新 onset。** 它们都是拿历史价格 / 情绪 / 估值拟的，对**没发生过的政策冲击天生盲**——组合拳落地当晚 ERP 还在低分位（甚至因利率 regime 显"贵"）、情绪还在冰点喊减、MA60 还没站上，跟着它会**踏空主升**。这正是你那条 🔴 **破单向陷阱**（清仓后再进场不许被估值单维否决）要防的东西——**onset 就是"估值/因子说别进、但该进"的典型局面**。
  - 但 `market_sentiment`（市场情绪过热）有叙事接不住的强项：**情绪狂热顶**它最看空，正好补上研报 perma-bull 的盲区。⚠️ 注意刹车是**情绪面过热**，**不是 ERP"贵"**——估值在趋势右侧反向，别把它算进顶部刹车。
- **关键：这两者的失效模式反相关**——一个在 onset 盲、一个在狂热顶盲，正好互补。所以不是二选一，是**在对的局面用对的那一个**。

## 当场怎么判（给思考结构，不给输出映射）

1. **两个信号并排看**：今天 `research_search` 有没有冒出**新的政策事件**（多家券商共识簇 = 真事件，不是每日盘面复盘流水）？同时 `market_sentiment` / `erp_vix` 是在喊"情绪过热、贵+自满"（顶部信号）还是"情绪冰点、便宜+恐慌"（底部信号）？
2. **判这是哪种局面**：
   - 更像**全新政策冲击 / onset**（研报刚冒出新政策、指数和 ERP/趋势都还没反应）→ **让政策叙事主导**，敢在 ERP 低分位 / 情绪还喊减 / MA60 还没翻多时分批建底仓——这正是 🔴 破单向陷阱说的"估值低分位只封顶、不封零"，因子/估值在 onset 盲，等它们同号就踏空了。
   - 更像**成熟的狂热趋势 / 顶部**（已涨一大段、市场情绪过热、研报喊"政策底确认/已涨"）→ **让 `market_sentiment`（真·市场情绪过热）+ 趋势本身是否转弱来刹**，研报越看多越警惕，别被卖方默认偏多带去接盘。**别用 PE/ERP"贵"封顶兑现**——趋势右侧"贵"是反向指标，拿它兑现会砍在主升里；趋势没破、情绪面没过热，就让利润跑。
   - **拿不准**（既不是清晰 onset、也不是明显狂热顶）→ 回到 METHODOLOGY 的"趋势定方向 + 估值定上限 + 正交同号"，催化和因子**都只算一票**，谁都不许一票否决。
3. **把判断写出来**：每次因为催化或因子动仓位，写清你判的是哪种局面、引了哪条研报（带 INFOCODE）/ 哪个因子读数、为什么这么权衡。判断可被审计，才不是拍脑袋。

## 诚实纪律（承接你一贯的"数据诚实纪律"）

- **不给阈值**："onset = 日期 T/T-1""已涨 X% 才算确认""ERP z / VIX z / 情绪 z 超某值减仓""score > 某值才有催化"——全删，少数样本的角落值，写死必过拟合。
- **读方向不读结论**：研报只读"发生了什么新政策 / 什么边际变化"，不抄它的涨跌结论。
- **防幻觉**：没真检索到具体研报（INFOCODE）就**不许编催化**，宁可写"本窗口无新政策催化"。
- **谁对让 A/B 证伪，不是我现在拍**：这套"onset 信叙事、过热信因子/估值"的分时主导，对不对、在哪个 regime 失效，由回测去验（尤其顶部/确认期窗口能不能扛住不接盘），不预先钉死任何机械线。

## 沪深300 特化（接 METHODOLOGY）

- 沪深300 是**蓝筹宽基**，能驱动它 regime 的政策催化主要是**全市场级**的：货币组合拳（降准降息/SFISF/再贷款）、政治局/中央经济工作会议定调、维稳/平准/国家队增持、外围（关税/美联储）。**小盘风格催化（科创/专精特新）对它弱**，别拿去当 300 的承重催化。
- **北向/外资对 300 有效**（不像小盘）：政策 onset 后北向常顺势流入，可作**确认**——但偏滞后，且"散户化后北向 ≠ 聪明钱、顶部可能反向"（见 METHODOLOGY 三）；当确认的一票看，不当领先扳机。
- **`hs300_erp_vix_timing` 当顶部刹车要拆两条腿看**：它"减仓"= ERP贵 + VIX自满。**ERP"贵"那条腿在趋势右侧是反向指标**——牛市里 ERP 一直喊贵会让你过早减仓（因子自己的研究都承认"牛市低暴露让出绝对涨幅"），**别信它的"贵"**。真正有用的是 **VIX 低位自满**那条腿（情绪自满预警），且要 VIX 低位才触发；**剧烈高 VIX 逼空顶**它的恐慌腿反而会误读成"抄底"。所以 HS300 顶部刹车的主力是 `market_sentiment`（真·市场情绪过热），erp_vix 只当"VIX 情绪那半"的辅助。
- 你的承重是**趋势**；**ERP/估值只是风险刻度（上限意识），不是择时扳机**——尤其趋势右侧"贵"反向。催化只在 onset 改"该不该提前进"、`market_sentiment` 只在市场情绪狂热顶改"该不该兑现"，**趋势转弱才是真正的离场扳机**；估值始终只封顶、不发兑现令。
