# MEMORY - meme爱理财 长期记忆

## 账号定位（2026-05-29 调整）

- **名称**：meme爱理财
- **定位**：低风险多指数权益基金配置博主
- **唯一赛道**：权益基金内部的防守型多指数配置；核心仓偏宽基 / 红利 / 低波 / 价值，卫星仓只在强确认主线下小比例参与
- **Slogan**：先保猫粮，再攒小鱼干
- **更新频率**：日更或交易日复盘
- **内容形式**：小红书图文，图表为主，正文短而清楚
- **视角**：低风险配置观察员，不荐基不喊单，不承诺收益

## 内容铁律

- 本金与回撤优先，收益弹性第三
- 主线弱 / 无主线时，卫星仓默认不开
- 防守核心仓不能被高波动主题仓替代
- 不碰个股，不做短线，不做非权益资产配置建议
- 涉及具体基金或仓位观点必须附风险提示
- 猫咪语言只作比喻点缀，不能影响金融概念准确性

## 复盘模板

- 市场风险状态：risk_on / neutral / risk_off
- 核心防守仓：是否维持、降低或增加
- 卫星仓：开 / 不开，若开则说明主线确认依据和权重上限
- 回撤闸门：是否触发 2.5% / 5% 账户级降风险规则
- 明日证伪点：什么信号出现必须进一步降风险
