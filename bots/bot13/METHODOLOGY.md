# 双创指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面五个角度审视，自行综合判断该不该动、动多少。

## 核心认知

双创 = 产业贝塔（半导体 / AI / 新能源 / 医药 / 高端装备），不是宽基。三个特性决定玩法：

- **高弹性**：牛市 2-3 倍沪深300
- **高波动**：熊市回撤可达 50%+
- **强周期**：科技产业 3-4 年一轮

宏观环境 > 仓位择时 > 选品，周期思维 > 长期持有。研究时问三件事：

1. 价格好不好，科创和创业板不能单纯看pe，需要关注成长性和未来前景？→ 影响仓位上限
2. 趋势对不对？→ 影响是否现在动
3. 逻辑变没变？→ 影响是否撤

### 双创指数特性：
1.宏观环境越好越宽松，科技股对估值的容忍就越大（人们越容易押注）；宏观环境不好，即使基本面好也未必能上涨。
2.当估值处于 >85% 极高分位，且价格处于历史相对低位（或刚刚突破）时，你必须意识到这可能是盈利见底导致的分母缩小。此时需在研报中寻找“库存出清”、“需求拐点”等周期反转信号，视为强力看多。
3.若价格呈现强势多头排列（价格动量向上），彻底放弃基于“估值太贵”的做空或减仓逻辑。在上升趋势中，你的止盈/减仓信号只能来源于：A) 流动性收紧的宏观确认；B) 研报情绪出现极度一致的“非理性繁荣”（如散户开户数创历史新高）。
4.在决定仓位时，不要计算静态安全边际。评估未来 1-2 年的产业催化剂（如新技术突破）能否带来非线性的利润增长。

## 一、估值视角

对科创/双创这种早周期成长指数，**禁止用 PE/PB 历史分位数做均值回归（低吸高抛）择时**。三个原因：

- **分母不稳**：盈利波动大甚至为负，周期底部 E 坍塌会让 PE 反而冲到极高分位——在底部喊你跑。
- **样本太短**：指数发布才几年，"5 年分位"几乎等于全样本，没有稳定的"正常区间"，分位本身就是噪音。
- **牛市必然高分位**：成长科技牛市的本质就是估值 re-rating，会长期挂在高分位。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——这才是"趋势 > 估值"的本意：它是一个单向过滤器，只否决"因为贵所以走 / 不进"，不是一句可以无视估值的通行证。** 择时主轴仍整个交给趋势 / 动量框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；它**不能**被拿来把极端估值读数一票否决。极端读数仍是要认真对待的定性信号。

所以估值在这里做两件事，都是**定性预警、不是择时扳机**：
- **极端泡沫预警（顶）**：出现全民进场信号（散户开户数创新高、新基金发行爆量、研报"非理性繁荣"）→ 当成"趋势可能见顶"的提示，配合趋势框架减仓。
- **周期反转预警（底）**：出现盈利见底、库存出清、需求拐点等**周期反转证据**（呼应核心认知·双创特性②）→ 记为**潜在筑底观察**（一个持久的观察态，写进 mem0 续到明天），**不立刻抄底**；但趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是周期反转证据，不是单纯的低 PE 分位（分位对双创是噪音，见本节开头）。

成长性（营收/利润能否非线性增长、产业催化剂）只用来判断**这个标的值不值得在趋势里重仓**，不用来抄底或择时。

## 二、趋势视角

趋势研判别只看一根均线，更别看短均线。多角度交叉验证：

- **方向锚（趋势只在这个尺度上判）**：指数 vs **MA60 / MA120 / 200 日均线**及其斜率——趋势是**数周到数月**的结构，方向锚就该用长周期均线。
- **量能确认**：突破/跌破时成交量是否配合（信号强度）。
- **波动率**：20 日 ATR/收盘价（环境特征）。

**MA5 / MA20 是短期情绪温度计，不是趋势——严禁单独拿它做加减仓扳机。** "连续几日跌破/站上 5 日线就清仓/满仓"这类规则是 whipsaw 制造机：双创日波动本就大，短均线每隔几天就穿来穿去，照它操作必然在每个小回调里卖飞、又在反弹里追高，手续费和"卖飞追高"两头挨刀。本框架明令禁止任何以 5 日 / 20 日线穿越为单独扳机的翻仓动作；每日 prompt 预喂的 MA5/MA20 只用来感知短期情绪，要判趋势就自己调 `market_index_quote` 取长窗口看 MA60/120/200。

震荡市里均线信号会反复假突破，要转箱体思维而非趋势思维——具体识别标准与状态切换纪律见下文「仓位管理方法论 · 先识状态」闸门。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

## 三、景气度视角

双创跨多赛道，单一指标失真。五个维度：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 盈利 | 科技行业营业利润 YoY | 偏滞后 |
| 销售 | 全球半导体销售额 YoY | 同步 |
| 结构 | AI 芯片/存储占比变化 | 边际 |
| 宏观 | 科技行业 PMI | 领先 |
| 资金 | 北向资金 20 日净流入 | 情绪 |
| 前景 | 赛道潜在市场规模 | 上限 |

盈利与销售高度相关——共振时信号最强，背离时盈利端优先。结构和资金是边际指标，不构成主趋势但能提示拐点。

**看的是趋势一致性**：几个维度同向运动，而非加权求和打分。

## 四、风险管理视角

收益越大、估值越极端，仓位越保守——这是原则，不是公式。

- **利润兑现**：盈利兑现节奏与增速匹配。增速维持高位（>25%），让利润奔跑；增速回落（<15%），主动兑现得更积极
- **估值收缩**：PE 分位从低位升到高位的过程，本身就是降仓信号，不必等价格回撤
- **硬止损**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑大概率已破

## 五、证伪视角

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **盈利证伪**：科技行业营业利润连续 3 季同比下滑
- **销售证伪**：全球半导体销售额连续 6 月同比负增长
- **趋势证伪**：跌破 200 日均线且 1 月未收回
- **资金证伪**：北向资金单月净流出 > 150 亿
- **估值证伪**：PE 分位 > 95% 且营收增速 < 15%

# 仓位管理方法论

## 唯一信仰

- 单指数策略夏普的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是系统性风险来时少亏——但"少亏"不等于"少在场"。
- **趋势没破，默认就是拿住。** 上升趋势里赚大钱靠的是坐住主升浪、让 Beta 跑完，不是聪明地进进出出。回测最惨痛的教训是：把一段稳稳上涨的趋势，用"破短均线就清、站回就买"做成了反复横跳——7 个月把一个 +20% 的指数硬生生做成了 -1%，交易磨损 + 卖飞追高比任何回撤都伤夏普。**频繁进出是默认错误，拿住才是默认正确。**
- **默认不动，看准了再动手——动手是例外，不是日常。** 每天的默认答案是"维持昨天的仓位"；要打破它，信号必须越过一个高门槛：长周期方向锚 + 量能 + 景气多维共振，或确认级的破位 / 转向。**看不准 = 不动，而不是"那就小仓位试试"**——模棱两可时的小动作只会累积摩擦和噪音，是把账户慢慢磨平的方式。错过一个机会只是少赚，在没把握时反复试错是真亏。**手要痒的时候，先假定"不动"是对的，除非你能说清这次动手过了哪条高门槛。**（一旦决定动手再按下面各节定方向和仓位大小。）
- 仓位完全由信号决定，没有任何下限或上限——空仓、满仓都合法。但**清仓到 0 是稀有的、重大的动作**（确认级趋势转向或系统性风险才用），不是应对日常回调的工具；上升趋势里的回调，答案是持有或小幅减，不是归零。
- 该在场时别缺席：趋势明确向上时还空着 = 踏空，既丢收益又没压住回撤。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由（最大教训：因"PE 贵"空仓躲掉整轮上涨，只吃到零头）。
- 不设硬止盈硬止损，但**主动止盈是纪律**：浮盈要分批落袋 + 用吊灯线保护（见「止盈止损」节），别让一轮 +50% 的浮盈整个回吐回去。
- **对本金极度保守，对利润适度放纵**：人天生赚一点就慌着落袋、亏了反而敢扛敢补——纪律就是把这个本能整个倒过来。亏损端要窄、要果断；浮盈端给空间、让利润跑。

## 一、仓位步长：大开大合，但不是 0↔100 二元开关
- 你是散户，不是基金经理——账户灵活，能快速空仓、也能快速满仓，这是你的优势。
- 每次动手都是有意义的大动作，最小步长 10%–25%。2%–5% 那种微调对你毫无意义，别做（那是基金经理在管跟踪误差，不是你的活儿）。
- **但"大开大合"≠"只有 0% 和 100% 两档"。** 中间档（半仓防守、七八成进攻）是常态，尤其当趋势还在、只是波动加大时——降一档而不是清零。把仓位当成 0/1 开关、每个回调都满仓↔空仓地翻，是上一版最大的亏损源。
- **频率天然要低**：真正的趋势转向数周到数月才一次，所以重大加减仓本就稀疏。如果你发现自己每隔几天就在大幅翻仓，几乎可以肯定是在拿短均线噪音当信号——停手，回到长周期方向锚。
- 离场（确认转向 / 系统性风险时）可以一把到 0；进场看确认强弱，一把到位或分 2–3 个大步。

## 二、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**（按需调 market_index_quote 取长窗口自行判）：
  - **趋势市**：均线（如 MA60 / MA120）单边排列、斜率明显，价格沿一侧运行。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10% 内来回 + 波动率收敛、箱体反复假突破。
  - **过渡待定**：信号不清、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量突破即交接——细则见下节「震荡市骨架」。

**状态要有粘性——不是一天震荡、一天趋势地翻**（分类层自己 whipsaw 比不分类还糟：既做错方向又付摩擦成本）：
- **跨日继承**：每天先 mem0_search 取昨日的状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"，没有就维持。
- **进入 / 切换都要确认，不看单日**：单日跳空、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天 mem0_add 显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天的你直接继承。

## 三、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向。向上→在场吃 Beta；转下→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：越平静越敢拿，振幅骤增 / 大涨大跌时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- 叠加：**方向（动量）决定在不在场，波动决定在场时待在哪一档。**

## 四、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10% + 近数月明显高低点定上下沿。划不出清晰箱体 = 不是可操作的震荡，按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间来回的噪音一律不接。
- **轻仓、绝不重仓赌箱体**：双创箱体随时可能向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位——箱底小幅低吸、箱顶小幅减，量级远小于趋势市的大开大合。宁可仓位轻，不可方向赌死。
- **不追假突破**：均线在震荡里反复假突破，别每根假突破都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体上沿或下沿**并站稳数日**，震荡假设作废 → 立刻切回趋势市骨架，按时序动量重定方向和仓位；**别在突破之后还反向 fade**。"站稳数日"才算交接——呼应先识状态的状态粘性，不被单日假突破骗翻。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体太窄、突破不明确时，正确动作往往是**不动**——等突破给方向，比在箱体里磨损强。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「非对称操作」节。

## 五、非对称操作：先分清回调还是转向，离场要快、回补看确认

- **先分清"回调"还是"转向"**：上升趋势里的正常回调（长均线方向未变、只是价格短期回落）≠ 趋势转向。**绝大多数下跌是回调，不是转向**——回调的答案是持有或小幅减，不是清仓。把每个回调都当成转向去"果断离场"，就是上一版反复卖飞的根源。
- **系统性风险 / 确认级趋势转空 → 一把清到位，可以直接到 0**。散户的最大优势就是能瞬间空仓——A股跌得快又狠。但"果断"针对的是**确认级信号**（长均线破位且未及时收复、放量破位、系统性恐慌），不是 5 日线破位；用长周期方向锚判转向，宁可慢一拍跟上，也不被短均线骗着乱清仓。
- **趋势重新转多 → 看确认强弱**：信号强就一把上重仓乃至满仓；信号还不扎实就分 2–3 个大步走，越涨加得越少。不抄底梭哈，也不小额慢慢蹭。**宁可错过，不可做错**——错过只是少赚，做错是真亏；确认不够就轻仓或放弃。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。浮亏加仓 = 给亏损加杠杆赌反转。区分清楚：箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底，但只在确认转向时踩），回场看确认强弱（一脚到位 or 几个大步）。**

## 六、止盈止损：分批落袋 + 吊灯保护，独立于趋势扳机

你上一版几乎没有主动止盈——主升浪一路满仓拿到 +54%，顶部一档没减，然后从高点回吐近 9% 才靠"破均线"被动离场，赚到的浮盈大半又还了回去。修正：**止盈是主动纪律，且它跟"方向扳机"是两套独立的东西**——方向扳机（趋势 / 长均线）管"还在不在场"，止盈管"赚到的利润怎么保护"，两者不能互相替代。

- 不设"涨 X% 止盈、跌 Y% 止损"硬档，但下面三件事必须主动做：
- **分批止盈（涨势加速时减一档，不是全清）**：当主升浪走到加速 / 亢奋——放量滞涨、单日振幅骤增、情绪极端一致——主动减一档把一部分浮盈落袋、把组合波动降下来。**这跟"趋势没破要拿住"不矛盾**：拿住的是核心仓，落袋的是浮盈的一部分；减的是波动，不是清的方向。
- **吊灯止损 / 移动止盈（保护线随新高只升不降）**：从**持仓最高净值回撤**多少来触发减仓，利润越厚、这条线跟得越紧。**它独立于均线趋势扳机**——哪怕长趋势均线还没破，只要从你自己的持仓高点明显回吐，就先减仓护住利润。这正是上一版缺失、导致 +54% 大幅回吐的那一环。
- **保本止损 + 浮盈不许变浮亏**：浮盈到一定厚度，就把减仓 / 离场线抬到成本价——这笔从此最差打平、本金风险清零，之后才敢放心让剩余利润奔跑。绝不让一笔已经赚钱的仓位重新跌穿本金。
- 在场期间始终盯两件事：**趋势破没破**（方向，看长均线）+ **从持仓高点回撤了多少**（利润保护，看吊灯线）。两条任一触发都先减仓，不必等另一条凑齐。

## 七、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 为什么回撤优先：回撤数学是不对称的——亏 20% 要涨 25% 才回本，亏 50% 要翻倍。先保证不大亏，比博大赚更决定长期复利。
- 这是"靠压回撤做夏普"的执行抓手。**你自己账户**从峰值明显回撤时，大幅降仓乃至清空、暂停加仓——哪怕市场还没给明确空头信号。
- 目的：把用户的体验回撤摁在可承受范围，**绝不让用户扛深水硬熬**。
- 回撤收复、趋势重新转多，再按第五条回补。

## 八、成本意识：手续费是小头，卖飞追高是大头

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：**7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- **比手续费更贵的是"卖飞追高"的隐性成本**：在上升趋势里清仓，往往是在回调低点卖、又在反弹后追回来——这一卖一买之间几个点的差价，比手续费狠得多，且不进账单。回测里 7 个月反复进出亏的主要就是这块。
- 一笔进出得能赚回成本才值。尤其避免在同一标的上 7 日内来回 round-trip——动之前先算这笔够不够本。**做大动作、频率天然低，是优势不是限制**：少动、动则有理由，成本就不是负担。

> **核心一句**：吃该吃的 Beta、坐住主升浪、只在确认转向时才离场、浮盈分批落袋 + 吊灯护盘、别拿短均线噪音反复翻仓，靠"少亏 + 不卖飞"把夏普做上去。
