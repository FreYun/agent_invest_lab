# 沪深300指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面几个**正交**角度审视，自行综合判断该不该动、动多少。

> 沪深300 是大盘价值蓝筹，**估值才是最承重的信号**——关键是用对方法：动态、行业中性、相对债券、正交、可证伪。

## 核心认知

沪深300 = 大盘价值蓝筹贝塔（金融 / 消费 / 工业龙头为主），宽基核心资产。三个特性决定玩法：

- **低弹性**：牛市涨幅有限，但熊市回撤也浅——天生的核心底仓料。
- **低波动 / 高流动性**：适合做仓位的"压舱石"，不是做大开大合的弹性品种。
- **盈利稳、分母稳**：成分股盈利波动小，分母不会在周期底部坍塌，PE / 股息率 / ERP 这些估值信号**真的能用**、分位不失真。


### 沪深300 估值特性：
1. 裸 PE/PB 历史分位会被**行业结构漂移**污染（金融权重高拉低绝对 PE，赛道权重升又抬高）——必须行业中性化才可比，否则分位本身就是噪音。
2. 真正承重的口径是**相对债券**：ERP（盈利收益率 − 10y 国债）和股息率 − 10y gap，做动态 z-score。利率中枢一移，同样的 PE 对应的"贵贱"完全不同；低利率会让"看着贵"的估值其实相对债券不贵。
3. 宽基蓝筹估值**有中枢、会回归**，可以做均值回归择时；但阈值必须动态（滚动 z / 分位），不能用固定 5%/3%。
4. 估值给"该偏哪边"，趋势 / 动量给"是否现在动"——二者叠加择时，不是互斥。沪深300 也有 beta 趋势属性，蓝筹趋势黏性强，减仓宜分批别一把清。

## 一、估值视角（沪深300 的承重信号，合并 PE/PB/ERP/股息率只算一票）

- **只折一票**：PE 分位、PB 分位、ERP、股息率 gap 高度同源（都在量"贵不贵"），塞进同一维度算**一票**。四个一致不是"四重交叉验证"，是同一信号听四遍。真正的确认来自**别的维度**（盈利 / 资金 / 情绪）同号。
- **行业中性化**：按申万 / GICS 一级行业分组算各行业**组内**估值分位，再用指数权重加权回去——把"结构变了所以不可比"从口号变成计算。经验上裸 90%+ 的"明显贵"经中性化常降到 50–60%，那 ~30pp 是 mix 假象。
- **相对债券（最承重）**：ERP = 盈利收益率(1/PE_ttm) − 10y 国债；股息率 gap = dv_ttm − 10y 国债。都做 **3 年滚动 z-score**，看动态偏离不看静态绝对值。指数级股息率没有现成工具，用**成分股 dv_ttm 按当前指数权重加权**算（weight-drift 近似，标 indicative）。
- **方向**：估值 z 越负（相对自身历史 / 相对债券越贵）→ 偏低配；越正（越便宜）→ 偏超配。**估值在这里直接给仓位方向，不只是做极端泡沫预警。**

## 二、盈利视角（重在变化不在水平）

- 看**一致预期修正广度**（上调家数 − 下调家数）/ 覆盖股数，和**前向盈利斜率**（FY2/FY1），不看静态 PE 里的 E 水平。
- 修正广度转负（下调多于上调）= 盈利向下确认，是估值之外的**独立空头确认**；同号才构成交叉验证。
- 口径坑：用 **FY1 远期一致预期**别用 TTM（财报季实际值滚入会污染动量，方向被做反）；前向斜率取**等权中位**别取加权均值（小分母 FY1≈0 会被异常值放大几十个点）。

## 三、资金 / 流动性视角（与估值正交的真·独立信号）

- A股最稳健的流动性领先指标：**M1 − PPI 剪刀差**（M1 同比 − PPI 同比），多年序列做 z / 分位；社融增量做旁证。
- **关键陷阱——必看分解**：剪刀差收窄既可能是 M1 减速（偏空流动性），也可能是 PPI 反弹（reflation，利好名义盈利）。**不可单看符号**：PPI 反弹驱动的收窄反而是工业盈利的上行信号，会成为"看空估值"判断的上行风险。
- 北向资金日频净买若不可得，降级为季度配置参考，并保留"可能反向指标"的警惕（散户化后北向 ≠ 聪明钱）。

## 四、情绪视角（反向使用）

- A股恐慌指数 GVIX（IV 代理）做历史分位 / z：**极低 IV = 自满（偏空）、极高 IV = 恐慌（反向偏多）**；PCR、市场温度计同理反向。
- 情绪是边际 / 择时辅助，不构成主趋势，但在极端值能提示拐点。
- z 在 ±1 内 = 中性、不反向，**别硬解读**——没有极端就当它不投票。

## 五、宏观视角（中长期参考，显式控过拟合）

- 汇率、实际利率、信用脉冲等只做**中长期环境定性**，不做精确择时。
- **显式限制权重**：宏观变量多、易过拟合，宁可少用几个，也不堆一堆回归出"精确"信号。自由度纪律：因子数 ≤ √样本量。

## 六、证伪视角（对称化）

证伪不是技术信号，是**论据的破坏**，而且必须**对称**——既列"看空被证伪"（上行风险），也列"看多被证伪"（下行风险）。只测一个方向是 v1 的毛病。任一触发不等于立刻反手，但意味着原论据已不成立，需要新论据才能继续持有。

- **看空（偏低配）被证伪 / 上行 veto-watch**：PPI 持续反弹并传导到工业盈利；修正广度由负转正；剪刀差因 **M1 加速**（非 PPI）走阔；估值动态 z 回到中枢上方。
- **看多（偏超配）被证伪 / 下行 veto-watch**：盈利修正广度转负且加速；ERP / 股息 gap 动态 z 跌破 −1；流动性剪刀差因 M1 减速收窄；情绪从恐慌快速转向自满。

# 仓位管理方法论
## 唯一信仰：估值锚 + 正交确认 + 概率化倾斜

- 沪深300 是**估值锚定 + 多维正交确认 + 概率化仓位倾斜**的核心底仓打法。
- 不抓顶底，只做：**贵则少配、便宜则多配**，且只在 **≥2 个正交维度同号**时才加大倾斜。
- 单一维度（哪怕估值极端）不足以重仓——必须正交确认。同源指标一致不算。
- **活下来比赚得快重要**：沪深300 是压舱石，它的活儿是系统性风险来时少亏、把组合夏普托住，不是博弹性。

## 一、综合打分：正交维度加权 → 仓位倾斜

```
Composite_z = w_val·z_val + w_earn·z_earn + w_liq·z_liq + w_macro·z_macro + w_sent·z_sent
```

- 权重用**固定先验**（估值 / 盈利各 0.30 为两根主力支柱，资金 0.15 / 宏观 0.10 / 情绪 0.15 从轻），**刻意不做回测拟合**——可得样本太薄（月频宏观 ~7 年、情绪序列更短），拟合 5 个权重必然过拟合，做出的"精确权重"比简单先验更不可信。
- 映射到仓位倾斜（**滚动标准化后**）：

| Composite_z | 仓位倾斜 | 含义 |
|---|---|---|
| > +1.5σ | 显著超配 | 多维同号偏低估 |
| +0.5 ~ +1.5σ | 温和超配 | |
| −0.5 ~ +0.5σ | 中性 | 信号冲突或灰区 |
| −1.5 ~ −0.5σ | 温和低配 | |
| < −1.5σ | 显著低配 | 多维同号偏高估 |

- **置信度**：同号维度越多 → 倾斜越大；维度冲突 → 收窄倾斜、回归中性。**真正的交叉验证是跨正交维度同号，不是同源指标一致。**
- **诚实纪律**：既然不信精确权重，输出只取**方向 + 档位**（中性 / 轻微 / 温和 / 显著），**不报"低配 X%"的伪精确数值**。

## 二、动态阈值，不用固定线

- 所有"贵 / 便宜""高 / 低"都用**滚动窗口 z-score 或滚动分位偏离**，不用固定 5%/3%。利率中枢、估值中枢会漂移，固定阈值必然钝化、迟早失效（固定 ERP 阈值在利率下行期会一直误报"便宜"）。

## 三、估值给方向，趋势给择时

沪深300 也有 beta 趋势属性，蓝筹趋势黏性强：

- 估值偏低配 + 趋势仍强：**分批减，别一把清**（蓝筹趋势可以走很久，急清易踏空）。
- 估值偏超配 + 趋势转强：较好的**加仓窗口**，可以加得果断些。
- 估值与趋势打架：收窄倾斜、回中性、等确认，不猜方向。

## 四、回撤控仓（夏普命脉）

- **账户级净值回撤是高于单笔信号的总开关**：从峰值明显回撤就降仓、暂停加仓，哪怕维度信号还没转向。回撤往往是连续错误堆出来的，这是"防止一错再错"的闸门。
- 回撤数学不对称：-20% 需 +25% 回本、-33% 需 +50%、-50% 需翻倍。先定"最多能承受多少回撤"，再反推该不该降仓——不是先想能赚多少。
- 蓝筹波动虽低，但系统性风险（流动性危机、政策冲击）来时同样要快降仓，别因为"它是蓝筹"就硬扛。

## 五、成本意识

- ETF / 基金的申赎费 + **7 日内早赎 1.5% 惩罚**——一笔进出要能赚回成本才值，避免同标的 7 日内 round-trip。沪深300 是底仓品种，本就不该高频折腾。

## 六、防过拟合 / 数据诚实纪律

- 维度数压到 **≤ √样本量**；样本不足时**诚实退回固定先验 / 等权，不硬拟合**——拟合出的精确权重比诚实的简单先验更危险。
- 🔴 来源（散户回测、无署名"资料"、记忆数据）只能**提假设，不作结论承重**。
- 所有数字标 **source / as-of / 口径**；矛盾处标 `{{待核}}`，核验前不进决策。

## 七、实战判断：环境决定用哪条

格言大多成对矛盾，同一句在不同环境给相反指令——经验不是背格言，是认清当下环境该用哪条。沪深300 的环境抓手就是前面的**动态估值 + 盈利方向 + 流动性分解**。

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 估值贵了该减 | 低利率下贵是合理的 | 看 **ERP 动态 z（相对债券）**，不看裸 PE 分位 |
| 盈利下修该谨慎 | 盈利见底是底部信号 | 看修正广度**方向** + PPI reflation 是否传导 |
| 剪刀差收窄=流动性转差 | 收窄=PPI 反弹利好盈利 | 必看**分解**：M1 减速 vs PPI 反弹 |
| 别人恐慌我贪婪 | 顺势不接下跌 | GVIX 极端 **且** 估值同时便宜才贪婪，否则顺势 |
| 估值便宜该加 | 单维度不重仓 | 估值便宜 + **≥2 维同号**才加大倾斜 |

> **核心一句**：沪深300 靠**行业中性 + 相对债券的动态估值**给方向、**正交维度同号**给置信度、**固定先验 + 概率化倾斜**给仓位——贵则少配、便宜则多配，不抓顶底、不伪精确、靠纪律压回撤。
