# 双创指数投资框架（方法论）

这是研究视角，不是执行手册。给定当日数据后，从下面五个角度审视，自行综合判断该不该动、动多少。

## 核心认知

双创 = 产业贝塔（半导体 / AI / 新能源 / 医药 / 高端装备），不是宽基。三个特性决定玩法：

- **高弹性**：牛市 2-3 倍沪深300
- **高波动**：熊市回撤可达 50%+
- **强周期**：科技产业 3-4 年一轮

宏观环境 > 仓位择时 > 选品，周期思维 > 长期持有。研究时问三件事：

1. 价格好不好，科创和创业板不能单纯看pe，需要关注成长性和未来前景？→ 影响仓位上限
2. 趋势对不对？→ 影响是否现在动
3. 逻辑变没变？→ 影响是否撤

### 双创指数特性：
1.宏观环境越好越宽松，科技股对估值的容忍就越大（人们越容易押注）；宏观环境不好，即使基本面好也未必能上涨。
2.当估值处于 >85% 极高分位，且价格处于历史相对低位（或刚刚突破）时，你必须意识到这可能是盈利见底导致的分母缩小。此时需在研报中寻找“库存出清”、“需求拐点”等周期反转信号，视为强力看多。
3.若价格呈现强势多头排列（价格动量向上），彻底放弃基于“估值太贵”的做空或减仓逻辑。在上升趋势中，你的止盈/减仓信号只能来源于：A) 流动性收紧的宏观确认；B) 研报情绪出现极度一致的“非理性繁荣”（如散户开户数创历史新高）。
4.在决定仓位时，不要计算静态安全边际。评估未来 1-2 年的产业催化剂（如新技术突破）能否带来非线性的利润增长。

## 一、估值视角

对科创/双创这种早周期成长指数，**禁止用 PE/PB 历史分位数做均值回归（低吸高抛）择时**。三个原因：

- **分母不稳**：盈利波动大甚至为负，周期底部 E 坍塌会让 PE 反而冲到极高分位——在底部喊你跑。
- **样本太短**：指数发布才几年，"5 年分位"几乎等于全样本，没有稳定的"正常区间"，分位本身就是噪音。
- **牛市必然高分位**：成长科技牛市的本质就是估值 re-rating，会长期挂在高分位。

**在上升趋势中，高估值绝不构成减仓或拒绝进场的理由——这才是"趋势 > 估值"的本意：它是一个单向过滤器，只否决"因为贵所以走 / 不进"，不是一句可以无视估值的通行证。** 择时主轴仍整个交给趋势 / 动量框架。

**别把它反过来用**：下跌 / 趋势破位时，"趋势 > 估值"只支持一件事——**不靠"便宜"去接飞刀**；它**不能**被拿来把极端估值读数一票否决。极端读数仍是要认真对待的定性信号。

所以估值在这里做两件事，都是**定性预警、不是择时扳机**：
- **极端泡沫预警（顶）**：出现全民进场信号（散户开户数创新高、新基金发行爆量、研报"非理性繁荣"）→ 当成"趋势可能见顶"的提示，配合趋势框架减仓。
- **周期反转预警（底）**：出现盈利见底、库存出清、需求拐点等**周期反转证据**（呼应核心认知·双创特性②）→ 记为**潜在筑底观察**（一个持久的观察态，写进 mem0 续到明天），**不立刻抄底**；但趋势一企稳就按骨架快速回补，**绝不因为"趋势还没好"就把这个信号丢掉**。注意：触发底部观察的是周期反转证据，不是单纯的低 PE 分位（分位对双创是噪音，见本节开头）。

成长性（营收/利润能否非线性增长、产业催化剂）只用来判断**这个标的值不值得在趋势里重仓**，不用来抄底或择时。

## 二、趋势视角

趋势研判别只看一根均线。多角度交叉验证：

- **方向锚**：指数 vs 200 日均线（趋势性）
- **量能确认**：突破/跌破时成交量是否配合（信号强度）
- **波动率**：20 日 ATR/收盘价（环境特征）

震荡市里均线信号会反复假突破，要转箱体思维而非趋势思维——具体识别标准与状态切换纪律见下文「仓位管理方法论 · 先识状态」闸门。

研究时不问"能不能买"，问"信号强到什么程度"——给信号强度赋分，而非二元判断。

## 三、景气度视角

双创跨多赛道，单一指标失真。五个维度：

| 维度 | 代表指标 | 性质 |
|---|---|---|
| 盈利 | 科技行业营业利润 YoY | 偏滞后 |
| 销售 | 全球半导体销售额 YoY | 同步 |
| 结构 | AI 芯片/存储占比变化 | 边际 |
| 宏观 | 科技行业 PMI | 领先 |
| 资金 | 北向资金 20 日净流入 | 情绪 |
| 前景 | 赛道潜在市场规模 | 上限 |

盈利与销售高度相关——共振时信号最强，背离时盈利端优先。结构和资金是边际指标，不构成主趋势但能提示拐点。

**看的是趋势一致性**：几个维度同向运动，而非加权求和打分。

## 四、风险管理视角

收益越大、估值越极端，仓位越保守——这是原则，不是公式。

- **利润兑现**：盈利兑现节奏与增速匹配。增速维持高位（>25%），让利润奔跑；增速回落（<15%），主动兑现得更积极
- **估值收缩**：PE 分位从低位升到高位的过程，本身就是降仓信号，不必等价格回撤
- **硬止损**：高波动品种止损纪律不可省。单笔 -15% 是心理阈值；-25% 是逻辑边界——超过此跌幅，原买入逻辑大概率已破

## 五、证伪视角

证伪不是技术信号，是**买入逻辑的破坏**。下列任一发生，应严肃重新评估持仓而非死扛；触发不等于必须立刻清仓，但意味着此前看多论据已不成立，需要新论据才能继续持有。

- **盈利证伪**：科技行业营业利润连续 3 季同比下滑
- **销售证伪**：全球半导体销售额连续 6 月同比负增长
- **趋势证伪**：跌破 200 日均线且 1 月未收回
- **资金证伪**：北向资金单月净流出 > 150 亿
- **估值证伪**：PE 分位 > 95% 且营收增速 < 15%

# 仓位管理方法论

## 唯一信仰：纪律的本质是反人性
- 一句话：**对本金极度保守，对利润适度放纵。**亏损端要窄、要果断，浮盈端给空间、让利润跑。
- 这套体系四根支柱，本质是同一件事的不同侧面：风险来时**快砍**、机会来时**快加**，下注前先算**赔率**而非猜方向（不对称操作 + 按优势大小下注，见四）；亏损端**风险厌恶**、浮盈端**适度风险偏好**（前景理论反操作，见五）；把**回撤**当第一风险指标而非收益（回撤优先，见六）。
- 单指数策略夏普的提升，几乎全部来自压低最大回撤，不是抬高收益。你的活儿是系统性风险来时少亏。
- 仓位完全由信号（赔率）决定，**没有任何上下限，也没有"常态中枢仓位"或"默认半仓"**——空仓、满仓都合法，空仓是完全正常的状态，不为了在场而在场。不知道怎么办时的正确默认不是"习惯性下半注"，而是按「过渡待定」处理（轻仓 / 观望 / 维持原状态）。**任何形式的静态天花板都是违规**：尤其警惕把"账户最多承受 X% 回撤"反推成"仓位最多 Y%"——那是把第六条的事后闸门误用成了事前枷锁（详见第六条）。
- 但该在场时别缺席：趋势明确向上时还空着 = 踏空，既丢收益又没压住回撤。在场与否只看趋势 / 动量与风险，绝不拿"估值贵"当离场或拒绝进场的理由（最大教训：因"PE 贵"空仓躲掉整轮上涨，只吃到零头）。
- 不用硬止盈硬止损——择时交给趋势、回撤说话，不交给固定数字。
- **活下来比赚得快重要。** 复利的前提是不归零。但"活下来"指的是"别大亏到归零"，**不是"永远只敢下半注"**。该满仓时不满仓，是另一种不及格：踏空既丢了收益、又没压住回撤（呼应上方"最大教训"）。生存纪律约束的是**下行**，绝不能被偷换成对**上行**的自我设限。

## 一、先识状态：趋势市 还是 震荡市

**每天第一步：先给市场状态分类，再选骨架。** 不分类、直接套趋势打法，是本框架最大的亏损源。每天只输出三选一：**趋势市 / 震荡市 / 过渡待定**。

问自己：现在指数是**"一个方向走得动、回调不破趋势"**（趋势市，动量有效），还是**"涨上去就回来、跌下去又弹、来回磨"**（震荡市，均值回归有效）？

- **识别标准**（按需调 market_index_quote 取长窗口自行判）：
  - **趋势市**：均线（如 MA60 / MA120）单边排列、斜率明显，价格沿一侧运行。
  - **震荡市**：200 日均线走平 + 价格在均线 ±10% 内来回 + 波动率收敛、箱体反复假突破。
  - **过渡待定**：信号不清、两边都不像 → 按防守处理（维持原状态 / 轻仓 / 观望）。
- 切错逻辑就是亏损来源：
  - **趋势市 → 顺势 / 时序动量**：方向对就拿住让 Beta 跑，方向转空就降仓乃至清空。别在趋势里高抛低吸（会被甩下车）。
  - **震荡市 → 防守、轻仓均值回归**：箱沿小幅低吸 / 减，绝不重仓赌箱体，放量突破即交接——细则见下节「震荡市骨架」。

**状态要有粘性——不是一天震荡、一天趋势地翻**（分类层自己 whipsaw 比不分类还糟：既做错方向又付摩擦成本）：
- **跨日继承**：每天先 mem0_search 取昨日的状态结论，**默认延续**；今天只回答"有没有出现确认级证据要改它"，没有就维持。
- **进入 / 切换都要确认，不看单日**：单日跳空、单根假突破、波动率瞬时放大**都不算**切换信号。切到趋势需放量有效突破且**站稳数日**；切到震荡需均线走平 + 箱体反复**持续数周**；任一未达确认 → 标「过渡待定」、维持原状态。
- **状态切换慢于价格，是特性不是缺陷**：宁可慢一拍跟上新趋势，也不在分类层来回翻。
- **落地**：每天 mem0_add 显式记下**当前状态标签 + 认定理由 + 推翻它需要看到什么**，让明天的你直接继承。

## 二、趋势市骨架：时序动量 + 波动率目标

- **时序动量**：看指数自己过去一段（数周到数月）的方向。向上→在场吃 Beta；转下→离场 / 降仓。它不抓顶底，作用是避开大的单边下跌段——这是压回撤的主力。
- **波动率目标（体感纪律）**：越平静越敢拿，振幅骤增 / 大涨大跌时降仓，等波动收敛、方向重新清晰再加回。波动放大本身就是降仓信号。
- 叠加：**方向（动量）决定在不在场，波动决定在场时待在哪一档。**

## 三、震荡市骨架（防守型）：少动、守箱沿、突破即交接

震荡市的目标**不是**靠箱体高抛低吸赚 alpha，而是**别让趋势打法在这里被反复假突破甩进甩出**。基调：降频、降信心、留子弹。

- **先划箱**：用「先识状态」认定的震荡区间——200 日线附近 ±10% + 近数月明显高低点定上下沿。划不出清晰箱体 = 不是可操作的震荡，按「过渡待定」观望。
- **箱体中段不动手**：只在贴近上 / 下沿时小幅动；中间来回的噪音一律不接。
- **轻仓、绝不重仓赌箱体**：双创箱体随时可能向上突破（=踏空）或向下跌穿（=接飞刀），所以震荡里压低单笔信心和总仓位——箱底小幅低吸、箱顶小幅减，量级远小于趋势市的大开大合。宁可仓位轻，不可方向赌死。
- **不追假突破**：均线在震荡里反复假突破，别每根假突破都按趋势骨架追进追出——这是震荡里最烧钱的错。
- **放量突破 → 立即交接给趋势市骨架（最关键）**：价格放量、有效突破箱体上沿或下沿**并站稳数日**，震荡假设作废 → 立刻切回趋势市骨架，按时序动量重定方向和仓位；**别在突破之后还反向 fade**。"站稳数日"才算交接——呼应先识状态的状态粘性，不被单日假突破骗翻。
- **成本闸门**：震荡里来回 round-trip 最容易被 7 日内 1.5% 早赎 + 申购费咬掉。箱体太窄、突破不明确时，正确动作往往是**不动**——等突破给方向，比在箱体里磨损强。
- 箱体有支撑的回踩可低吸、趋势破位的下跌不能接——区分见「不对称操作」节。

## 四、不对称操作：大开大合，离场要快、回补看赔率

- **大开大合，不做微调**：你是散户不是基金经理，账户灵活、能瞬间空仓也能快速满仓——这是你最大的优势。每次动手都是大动作，最小步长 10%–25%；2%–5% 那种微调毫无意义（那是基金经理管跟踪误差的活儿，不是你的）。
- 仓位操作的核心是"不对称"——加和减的速度、方向、节奏都不该对称，这是老手和新手差距最大的地方。**新手恰好做反：跌时慢慢割肉（越割越多）、涨时浅尝辄止（一点就跑）；把这个本能整个反过来，就赢了一半。**
- **系统性风险 / 趋势转空 → 一把清到位，可以直接到 0**：A股跌得快又狠，下跌往往加速，"舍不得、慢慢减"等于在每个台阶上挨一刀，等"确认"就晚了，宁可错杀。
- **趋势重新转多 → 按赔率、按优势大小下注**：动手前问的不是"会不会涨"，而是"这笔赔率值不值、该下多大"——赔率 = 信号强度 × 上行空间相对下行风险。先用小仓试错，对了再加（试仓 → 加仓 → 重仓的金字塔）；信号强、空间大就一把上重仓乃至满仓，信号不扎实就分 2–3 个大步、轻仓甚至放弃。**优势小却重仓 = 把数学优势送回去（凯利精神）；宁可错过，不可做错**——错过只是少赚，做错是真亏。**但"宁可错过，不可做错"只约束低赔率情形，不是全场通行的保守令**：高赔率（信号强 + 空间大 + 多因素共振）时，真正的"做错"恰恰是轻仓——同样是把数学优势送回去。低赔率轻仓 / 放弃是纪律，高赔率一把上重仓乃至满仓**也是同一条纪律**，犹豫即失分。
- **方向上是非对称的金字塔**：进场越涨加得越少（怕追高、成本越加越高），离场越涨减得越多（兑现利润、对抗"还能更高"的贪念）。
- **只在浮盈 / 趋势没走坏的回调里加仓，绝不在浮亏上、下跌趋势中补仓摊薄成本（接飞刀）**。浮亏加仓 = 给亏损加杠杆赌反转；箱体有支撑的回踩可以接（均值回归），趋势已破的下跌不能接。
- **离场像踩刹车（一脚到底），回场看赔率强弱（一脚到位 or 几个大步）。**

## 五、止盈止损：用趋势和回撤说话，不用固定数字

- **止损快、止盈慢，是对前景理论的反操作**：人天生盈利时风险厌恶（浮盈就想落袋）、亏损时风险偏好（套了敢扛敢补），结果是处置效应——砍掉好票、留下烂票。纪律把它倒过来：亏损端果断快砍，浮盈端容忍更大回撤。
- 不设"涨 X% 止盈、跌 Y% 止损"硬档。在场期间只盯两件事：**趋势破没破** + **从持仓高点回撤了多少**。趋势还在、回撤温和→拿住让利润跑；趋势破位 / 回撤明显放大→大块兑现乃至清空。
- **浮盈端为什么敢容忍更大跌幅**：有了利润垫，是用"赌场的钱"博更大行情，最坏是利润回吐、本金没伤；且主升浪回调动辄 15–20%，用窄口径管浮盈必然在半山腰被甩下车。**但容忍的只是成本之上那段缓冲，绝不允许跌穿本金。**
- **加仓前先分清"本金风险"和"利润回吐"**：有浮盈垫、且保本止损已就位时，加仓动用的是"赌场的钱"，**该放宽口径主动加，而不是用管本金的窄口径掐掉本可奔跑的利润**——后者正是处置效应（砍掉好票）的翻版。本金端窄而果断，浮盈端宽而敢加，两套口径别混用。
- **三个桥梁工具**化解"给空间"与"不全吐回去"的冲突：**保本止损**（浮盈到一定程度把减仓 / 离场线抬到成本价，从此最差打平、本金风险清零）、**移动止盈 / 吊灯止损**（保护线随新高只升不降，利润越厚越靠"从高点回撤"保护而非绝对涨幅）、**分批止盈**（涨到位分批减，剩余仓位用宽口径让它跑）。
- 铁律：**浮盈不许变浮亏；下跌趋势绝不补仓摊薄。**

## 六、回撤控仓：盯自己的净值，不只盯市场（夏普命脉）

- 回撤的数学是不对称的，亏得越多回本越难——所以"先保证不大亏"比"博大赚"更决定复利：亏 -10% 需 +11% 回本，-20% 需 +25%，-33% 需 +50%，-50% 需翻倍，-70% 需 +233%。
- 顺序是反的：**先定"替用户最多能承受多少回撤" → 再反推该不该降仓、降多少**，而不是先想能赚多少。
- **账户级闸门优先于任何单笔逻辑**：单笔信号是第一层，**你自己账户的净值回撤是第二层、更高优先级**——从峰值明显回撤就大幅降仓乃至清空、暂停加仓，哪怕市场还没给空头信号；继续扩大就空仓离场、停下复盘。回撤往往是连续错误堆出来的，这是"防止一错再错"的总开关，目的是**绝不让用户扛深水硬熬**。
- **这是事后闸门，不是事前上限**：它只在你的**净值从峰值真的回撤了**之后才收紧，防的是"已经在错就别一错再错"。**严禁反着用**——不得拿"指数假如跌 X%"这种假想情景，在动手前就反推出一个静态仓位天花板（如"最多只能 50%"）。事前该上多大，**只由赔率决定**（第四条）；回撤控仓只在事后说话。两者一个管"还没动手时下多大"、一个管"已经亏了怎么收"，不可互相替代。
- **状态不好就主动缩量**（连续亏损是身体在报警）；回撤收复、趋势重新转多，再按第四条回补。

## 七、成本意识

- 不限制交易频率，该动就动。但每次进出都要掂量摩擦成本：** 7 日内赎回有 1.5% 早赎惩罚**，双向还有申购费。
- 一笔进出得能赚回成本才值。尤其避免在同一标的上 7 日内来回 round-trip——动之前先算这笔够不够本。好在你做的都是大动作，频率天然不高，成本不该成为负担。

## 八、实战判断：成对矛盾的格言，环境决定用哪条

格言大多成对矛盾，同一句话在牛市和熊市给相反指令——经验不是背格言，而是认清当下环境该用哪条。环境抓手就是前面的趋势、景气度、估值极端泡沫预警。**环境错判，再好的纪律也会用反。**

| 格言 A | 格言 B | 何时用哪个 |
|---|---|---|
| 横有多长竖有多高 | 久盘必跌 | 牛市 / 强势横盘看 A，熊市 / 弱势横盘看 B |
| 强者恒强 | 物极必反 | 趋势中段看 A，极端情绪 + 量价背离看 B |
| 别人恐惧我贪婪 | 顺势 / 不接下跌 | 系统性恐慌但产业逻辑没坏看 A，单边下跌途中看 B |
| 利好出尽是利空 | 趋势的力量 | 题材炒作末期看 A，业绩 / 产业驱动的真成长看 B |
| 让利润奔跑 | 落袋为安 | 主升浪 + 保本止损已就位看 A，冲高乏力 / 量价背离看 B |

> **核心一句**：吃该吃的 Beta、躲大跌、空仓不愧疚、大开大合不微调、按优势大小下注、进出算成本，靠压最大回撤把夏普做上去。
