# 找主线方法论 · 五层漏斗框架（设计总纲）

> 综合 157 篇券商研报（方法库见 `研报方法库_行业轮动主线择时.md`）+ v1–v4 回测实测，提炼的"找主线"总纲。
> 核心立场：**"选最强板块"是最易过拟合、也最不值钱的一层；真正决定成败的是它外面的四层——先判"有没有主线/什么环境"，再判"主线在第几期、是不是大主线"，最后才选环节。** v1–v4 一直在最里层打转，所以再优化也只是换一种过拟合。

---

## 五层漏斗（自上而下收敛）

### 第0层 · regime：现在该不该找主线
- **依据**：A股仅 ~60% 时间有清晰主线、40% 无主线（`AP202506231696159932`/`AP202511231786994815`）；HMM 四状态（趋势涨/震荡涨/震荡跌/趋势跌，`AP202508201731109321`）。
- **判据**：行业轮动强度、市场宽度、成交集中度、市场温度（`market_temperature`）。
- **动作**：趋势市→找产业大主线并抱住；震荡市→拥挤反转/高低切、降集中；**无主线→红利/宽基兜底、空着等**。
- **现状**：完全缺失 = v4 过拟合总根源。

### 第1层 · 锚：产业趋势+景气+增量资金，动量只做确认
- **教训**：纯动量（涨幅）找主线 = 买在高位（v1 实证）。涨幅是结果不是原因。
- **四抓手优先级**（`AP202605071822042771`）：宏观叙事 > 产业趋势 > 增量资金 > 风格，**价格排最后**。
- **真主线 = 景气（盈利上修/订单）× 资金（北向/两融/ETF 持续净流入）× 叙事（研报反复讲同一产业逻辑）三类独立证据共振**；动量只确认"真的在走"，不做选择主因。
- **工具**：`stock_alpha`/`stock_financial_quality`（景气）、`stock_capital_flow`+北向/两融（资金）、`research_search`（叙事）、`sector_factor`（动量确认）。

### 第2层 · 生命周期：主线在第几期，定动作
一条主线走 **萌芽 → 加速 → 扩散 → 拥挤 → 松动**：
- 萌芽/加速 → 买龙头（景气+动量共振）；
- 扩散 → 买补涨环节（= v2 产业链扩散）；
- **拥挤（成交占比>80% `AP202509061739696961`、拥挤分位>90）→ 减配/高低切，不是加仓**；
- **松动（松动函数 = 拥挤 × 基本面反转 `AP202605151822357152`）→ 撤**。
- **工具**：`sector_factor_detail`（拥挤分位/成交集中度）、`market_index_quote`（均线偏离度，`AP202510201765545152`：偏离下穿 -5% 后 T+60 +5.25%）。

### 第3层 · 大主线 vs 题材：决定抱还是快进快出
四个客观标尺：① 底层产业逻辑是否持续（未证伪）；② 资金质地（机构/北向 vs 散户）；③ 景气可验证（订单/业绩兑现）；④ 扩散度（全链普涨 vs 单龙头硬拉）。
- 四条都硬 = **大主线**（抱、回调加仓，= v4 惯性持有）；
- 只有价格+情绪 = **题材**（分散、快进快出）。

### 第4层 · 选环节 → 选基金（已成熟，无需改）
环节定了之后，用 **成分重叠 × 净值相关**双测度选可投基金（market-mainline §七 / `board_fund_match.py`）。

## 对照：当前实现的覆盖与缺口

| 层 | 内容 | 现状 |
|---|---|---|
| 第0层 regime | 该不该找主线 / 打法切换 | ❌ 完全缺失 |
| 第1层 锚 | 景气+资金+叙事共振 | ⚠️ 只有动量一半，缺景气/资金确认 |
| 第2层 生命周期 | 加速/扩散/拥挤/松动 | ⚠️ v2 做了扩散；缺拥挤减配、松动退出 |
| 第3层 大主线甄别 | 抱 vs 快进快出 | ⚠️ v4 用持续性近似；缺逻辑/质地/景气校验 |
| 第4层 选基金 | 双测度 | ✅ 已实现 |

v1（纯第1层动量）→ v2（+第2层扩散）→ v3（分散摊过拟合）→ v4（+第3层持续性近似）。**始终缺第0层和第1层的景气/资金锚**，这是过拟合的根。

## 最高性价比的三件改进（v5 方向）

1. **加 regime 层（第0层）**：判趋势/震荡/无主线 → 切换 "抱主线 / 高低切 / 红利兜底" 三套打法。把 v4 从"押对了 regime"变成"认得出 regime"。
2. **锚从动量换成"景气+资金+叙事共振"（第1层）**，动量降级为确认 → 治"买在高位"。
3. **退出用"拥挤×基本面反转"双触发（第2层），不只看 MA60；无主线退红利（第0层兜底）** → 给策略装刹车+安全垫。

## 适用 scope（重要）
- **本方法基于 2025 年后的行情逻辑开发，回测/评价只看 2025-01 起。** 9·24（2024-09-24）是公认的结构性切换节点，前后市场逻辑不同；拿 2024 检验不公平（实测：naive 趋势 regime 滤网在 9·24 V 反转处 whipsaw、2024 段 -6.8%）。
- 代价：2025-01~2026-05 是单一 regime，**无法在 scope 内做真正样本外**——所有超额都是 in-sample，是 scope 决定不是验证。别把数字当承诺。

## 落地版本进展（2025-01 起，统一口径，净收益/超额沪深300）
- v1 top-1龙头 +20.0%/-8.1% → v2 产业链扩散 +26.8%/-1.3% → v3 top-3分散 +36.7%/+8.6% → v4 大主线惯性持有+回调不割 +47.2%/+19.2% → **v5 +regime层(无主线切宽基) +54.8%/+26.8%**（沪深300 +28.1%）。五层逐层累加正贡献。详见 `主线回测_v{2..5}_*.md`。
- v5 regime "防御→红利"分支在 2025+ 未触发(沪深300 全程站年线)；该分支用 naive 趋势滤网跨 regime 会 whipsaw，真实盘须换领先信号或"只降仓不全切"。

## 验证纪律（防过拟合）
- 参数（top-N、拥挤阈值、持续月数、regime 阈值）做敏感性 + 滚动窗口，别钉死单一区间。
- 区分"真原则（研报+多区间支持）"与"对某段行情的过拟合"。
