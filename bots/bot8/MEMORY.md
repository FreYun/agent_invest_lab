## 工具使用规范

### MDP 微信搜索铁律（2026-05-06 血泪教训）

**错误做法** ❌：
```bash
# 不传 user 参数，搜索范围是全库
npx mcporter call 'media-data-pack.search_weixin(query: "重远投资观", top_k: 50, ...)'
# 结果：找不到目标公众号文章
```

**正确做法** ✅：
```bash
# 必须传 user 参数锁定具体公众号
npx mcporter call 'media-data-pack.search_weixin(query: "", user: "重远投资观", top_k: 100, fields: ["TITLE", "CONTENT", "PUB_TIME"])'
# 结果：精准获取该公众号全部历史文章
```

**参数规范**：
| 参数 | 必填 | 说明 |
|------|------|------|
| `query` | 可选 | 搜索关键词，留空则获取全部 |
| `user` | **必传（锁定公众号时）** | 公众号名称，如"重远投资观" |
| `top_k` | 可选 | 返回文章数量，默认 50 |
| `fields` | 可选 | 返回字段，如 `["TITLE", "CONTENT", "PUB_TIME"]` |
| `score_threshold` | 可选 | 相关性阈值，0.05-0.7 |

**重要限制**：
- MDP 收录范围有限，「重远投资观」只收录了 6 篇（2026 年 4-5 月）
- 该公众号自称 2023 年发过十几篇逃顶文章，但 MDP 未收录
- 如需更早历史文章，需通过其他渠道获取（知乎/知识星球）
