# 港股创新药研究指南

## 用法

这是一份**思考框架**，不是数据接口。看完它之后，回到 simworld-data MCP 工具去查具体数据，把数据填到框架的位置上，再做判断。

调用顺序大致是：

1. 先 load 这份 skill，确定要回答的是「中长期配置」还是「短期择时」类问题。
2. 用 `fund_theme_screening(sec_name="创新药" / "医药")` 或 `simple_fund_search` 在 `portfolio_get_buyable_funds` 池里筛出候选基金/ETF，**禁止凭印象编代码**。
3. 用 `get_fund_comprehensive_analysis` / `get_fund_industry_holding` / `get_fund_top_stocks` 看候选基金真实暴露——很多名字带"医药/创新药"的基金重仓股可能是 A 股 CXO、中药、医疗器械，**必须查实际持仓**，名字不算数。
4. 用 `research_search` / `news_search` 查行业研报、BD 出海、临床数据、政策事件。
5. 用 `get_hshares_index_quote("HSI.HI,HSTECH.HI,HSCEI.HI")` + `get_southbound_hkd_turnover` 看港股大盘和南向资金。
6. 用 `get_us_bond_yield("10Y,2Y")` + `get_cn_macro_data("m2,cpi,ppi")` 看利率/流动性环境（港股创新药对美债利率极敏感）。
7. 回到本文的「周期位置判断」「配置 vs 择时」两节对照数据下结论。

## 一、为什么单独拉出来讲

港股创新药不是普通行业基金，它有四个特殊属性，研究时必须分开考虑：

1. **港币计价 + 美元利率锚定**：估值锚是美债 10Y。美联储进入加息周期 → 港股成长股估值压制；进入降息周期 → 港股创新药 beta 弹性极大。比 A 股医药基金对美债更敏感。
2. **南向资金边际定价**：港股流动性差，南向资金净流入是港股创新药短期方向的**关键边际买盘**。光看恒生指数涨跌不够，要看南向。
3. **创新药主线 vs 仿制药/中药/CXO 主线完全不同**：港股创新药指数（恒生港股通创新药、国证港股通创新药等）和 A 股医药指数（中证医药、申万医药）的成分股、风格、催化剂都不一样。研究前先确认 bot 看的是哪个指数/基金跟踪的是哪条主线。
4. **催化剂事件密度高且跳跃**：AACR/ASCO 会议数据、license-out 大单（如 100m+ USD 首付款）、医保谈判结果、FDA 审批，这些事件单点冲击大，板块情绪极易短期 overshoot。

## 二、六维分析框架

研究港股创新药时按下面六个维度独立打分，每一维都要有数据支撑（写明用哪个 simworld-data 工具查的、`as_of` 是哪天）。**不要给具体星级分数**——simworld 没有那套灰盒打分机制——给定性结论即可（利空 / 偏空 / 中性 / 偏多 / 利多）。

### A. 宏观环境

| 关注点 | simworld-data 工具 | 怎么解读 |
|---|---|---|
| 美债 10Y 收益率水平与方向 | `get_us_bond_yield("10Y,2Y", start_date, end_date)` | 港股创新药估值的核心锚。10Y 上行 → 估值压制；下行 → 估值修复弹性 |
| 美联储政策预期 | `us_macro_simple` + `news_search("美联储 降息")` / `research_search("美联储 利率")` | 加息末段 → 提前布局；降息周期 → 直接利多 |
| 中美利差 | `get_bond_yield_spread(spread_type="cn_vs_us", maturity="10Y")` | 利差走阔（中国相对宽松）→ 利好港股成长 |
| 国内流动性 | `get_cn_macro_data("m2,cpi,ppi")` | M2 上行 + CPI 温和 → 估值环境友好 |
| 人民币/港币汇率 | `get_cn_macro_data("usdcny")` | 人民币贬值预期 → 南向资金可能更倾向港股资产保值 |

**结论模板**：宏观偏多 / 中性 / 偏空，写清楚是因为哪一两个最关键指标。

### B. 行业基本面（供给端 + 需求端 + 验证端）

光看股价不算，要看产业真实进展。重点关注：

**供给端**（中国创新药研发实力）：
- 研发管线数量与质量：用 `research_search("创新药 管线 临床")` 拉最新研报。
- 临床数据读出节奏：AACR（4 月）、ASCO（5-6 月）、ESMO（10 月）、ASH（12 月）这些会议窗口前后两周用 `news_search` 跟踪。
- 研发效率/成本优势：中国创新药相对 MNC 的研发成本仍有 50-70% 折扣，这是结构性优势。

**需求端**（全球药企支付意愿）：
- MNC 现金储备 + 专利悬崖：`research_search("MNC 专利悬崖 BD")` 拉全球药企未来 3-5 年的"专利失效金额"。专利悬崖越陡 → 越愿意为中国创新药 license-in 付费。
- 国内医保谈判节奏：`news_search("医保谈判 创新药 价格")` 看医保支付端是否在改善（如多次降价幅度收窄、独家品种保护期延长）。

**验证端**（最重要——已经发生的交易而非"未来故事"）：
- License-out 大单：用 `news_search("license-out 创新药 首付款")` 或 `research_search("BD 出海")` 跟踪。**真正能验证赛道**的是首付款 ≥1 亿美元的大单，小额合作不算。
- License-out 总金额累计：一年内累计金额超过 X 百亿美元，是创新药价值兑现的硬指标。

**研究第一步永远是问**：当前是"故事阶段"（只有研报和概念）还是"兑现阶段"（已有大单和临床读出）？两者对应估值容忍度完全不同。

### C. 指数 / 跟踪标的基本面

研究港股创新药 ETF / 主题基金时，**第一步是查它真实跟踪什么、真实持仓是什么**，不要被名字迷惑：

| 检查项 | 工具 | 判断标准 |
|---|---|---|
| 基金真实行业暴露 | `get_fund_industry_holding(fund_code)` 或 `get_fund_ind_by_report(fund_code)` | 港股创新药主线含量是否 >70%？还是混了 A 股 CXO / 中药 / 医疗器械？ |
| 前十大重仓股 | `get_fund_top_stocks(fund_code)` / `fund_invest(fund_code)` | 重仓股是否是港股创新药龙头（如百济神州/信达生物/和黄医药/再鼎医药/中国生物制药等）？ |
| 集中度风险 | `get_fund_top_stocks` 看前十大权重合计 | >70% = 高集中度，少数龙头决定大部分波动；<40% = 较分散 |
| 风格定位 | `get_fund_style_analysis(fund_code)` | 是大盘成长还是小盘成长？是否真的是"成长股"画像？ |
| 跟踪误差 | `get_fund_index_return(fund_code)` 看超额收益指标 | 越接近 0 → 工具属性越纯；偏离大 → 主动配置成分高 |

**注意指数差异**：「恒生港股通创新药指数」「国证港股通创新药指数」「中证恒生港股通创新药精选指数」等不同指数的成分股、调仓规则、权重上限都不一样。**先用 `get_fund_comprehensive_analysis` 看清基金跟踪的是哪一个**，再下结论。

### D. 收益 / 风险特征

| 指标 | 工具 |
|---|---|
| 近 1 年 / 3 年 / 5 年收益 | `get_fund_performance(fund_code)` |
| 最大回撤 | `get_fund_performance` 或 `get_fund_comprehensive_analysis` |
| 波动率 / 夏普 | `get_fund_performance` |
| 净值曲线对比 | `get_multiple_funds_nav("fundA,fundB,fundC", start, end)` |
| 异动检测 | `get_fund_abnormal_movement(fund_code)` |

**港股创新药的画像应该是**：高弹性 + 高波动 + 大回撤（历史最大回撤经常超过 40%）。如果某只号称"港股创新药"的基金回撤一直 <20%，**反而要警惕**：它可能仓位很低、底层混了债券或大盘股，工具属性不纯。

### E. 估值

港股创新药不能只看 PE：很多 Biotech 还在亏损或微利期，PE 失真。要组合看：

| 估值指标 | 工具 | 解读 |
|---|---|---|
| 恒生医药指数 PE / 历史百分位 | `get_hshares_index_quote("HSCI"... )` + 板块研报 `research_search("港股 医药 估值")` | 看相对历史的位置 |
| 个股估值 PE_TTM / PB | `get_stock_valuation(stock_code)` （重仓股逐个查） | 龙头估值是否合理 |
| 中证港股创新药指数股息率 / PB | 板块研报 | 港股创新药通常无股息，PB 较高（资产端是管线/IP） |
| 风险溢价（ERP）= 1/PE - 10Y 美债收益 | 用 `get_us_bond_yield("10Y")` 配合估值算 | ERP 高 → 性价比好；ERP 低 → 估值透支 |

**结论模板**：估值是否在历史 30% 分位以下（便宜）/ 30-70%（合理）/ 70% 以上（偏贵）。不要只用 PE，要用「估值 + 业绩兑现进度」组合判断——高估值 + 业绩快速兑现是合理；高估值 + 故事还没兑现是危险。

### F. 交易情绪 / 资金面

港股创新药的**短期方向**由资金面主导：

| 信号 | 工具 |
|---|---|
| 南向资金净流入 | `get_southbound_hkd_turnover(start_date, end_date)` |
| 港股大盘成交额 | `get_hshares_turnover(start_date, end_date)` |
| 恒生指数 / 恒生科技 / 恒生国企走势 | `get_hshares_index_quote("HSI.HI,HSTECH.HI,HSCEI.HI", start, end)` |
| 港币流动性（HIBOR） | 用 `news_search("HIBOR 港币")` 或研报跟踪 |
| 个股北向资金（如有 A+H 上市的） | `get_stock_northbound_holding(stock_code)` |
| 创新药 ETF 成交活跃度 | `get_fund_abnormal_movement` + 基金日成交额（基金详情） |

**怎么读**：
- 南向连续 5-10 个交易日净买入 + 港股大盘成交放大 → 短期资金面利多。
- 南向连续净卖出 + 大盘缩量 → 流动性退潮，短期防守。
- 注意区分"南向涌入"和"南向流出后又回流"——后者是更确定的右侧信号。

## 三、周期位置判断

港股创新药是 3-5 年大周期 + 一年内小周期叠加。判断错周期位置，比选错基金/股票要命。

### 大周期（3-5 年）信号

| 阶段 | 典型信号 | 应对 |
|---|---|---|
| **泡沫顶部**（如 2020-2021） | 美联储降息末段 + 港股大涨 + Biotech 一级估值离谱 + "未盈利上市"集中 | 减配/不上车 |
| **下行段**（如 2021H2-2023） | 美联储加息 + 估值杀 + IPO 破发率高 + 一级估值打折出清 | 等右侧 |
| **底部**（如 2023H2-2024H1） | 估值百分位 <20% + 龙头跌幅 60-80% + license-out 数据开始好转 + 政策回暖 | 左侧布局/分批配置 |
| **复苏段** | 美联储停止加息/开启降息 + 临床数据集中读出 + BD 大单频出 + 南向回流 | 加配/趋势 |
| **景气段** | 业绩兑现 + 板块情绪正反馈 + 一级二级估值修复 | 持有/适度获利了结 |

**判完位置才能定策略**。下行段抄底（哪怕看似便宜）经常死在"基本面没起来 + 利率还在加"的双杀里。

### 小周期（半年到一年）信号

由四个事件流叠加：
1. **临床数据窗口**：AACR/ASCO/ESMO/ASH 前后的预期管理与读出。
2. **业绩窗口**：港股上市公司半年报（8 月）、年报（3-4 月）的减亏/扭亏数据。
3. **BD 大单窗口**：通常 Q4 和年初密集。
4. **政策窗口**：医保谈判（年底）、CDE 审评、FDA 审批节奏。

## 四、中长期配置 vs 短期择时

**这两层必须分开下结论**，不要混着讲。原 skill 把这两层用加权评分粘起来，是过度量化的伪精确。simworld 里更建议给定性结论。

### 中长期配置（看 1-3 年）

主要看：**宏观环境 + 行业基本面 + 指数/基金质量**。

下结论模板：
- **配置价值突出**：大周期底部/复苏 + 行业兑现进度好 + 基金真实暴露干净 → 可作为重点配置方向，建议分批配置。
- **可考虑分批配置**：大周期复苏中段 + 行业兑现进度一般 + 基金质量 OK → 分批，不要重仓。
- **观察为主**：大周期景气段后段 + 估值偏贵 + 但基本面仍在 → 持有不加仓。
- **不建议中长期配置**：大周期下行 / 泡沫顶部 + 行业兑现乏力。

### 短期择时（看 1-3 月）

主要看：**估值位置 + 交易情绪 + 催化剂事件**。

下结论模板：
- **重点关注**：南向回流 + 临近临床数据窗口/医保谈判窗口 + 估值低位 → 可短期跟。
- **可以关注**：方向不明但有催化预期 → 小仓位试。
- **不宜短期跟**：南向流出 + 无近期催化 + 估值偏贵 → 等右侧。

**关键纪律**：中长期方向不对的赛道，短期再热也不参与；中长期方向对的赛道，短期回调反而是机会。

## 五、不同问句应该怎么回答

| 用户问句类型 | 主要看哪一层 | 必须输出 |
|---|---|---|
| "港股创新药还能买吗 / 值得配置吗" | 中长期配置 | 大周期位置 + 行业基本面 + 估值 |
| "回调后能不能上车" | 短期择时为主 + 中长期校验 | 资金面 + 催化剂 + 中长期方向是否未变 |
| "推荐哪只港股创新药 ETF / 基金" | 基金/指数质量层 | 候选 ETF/基金的真实持仓 + 跟踪误差 + 集中度 + 费率（`fund_rate`）+ 规模 |
| "场内还是场外" | 持有期匹配 | 短线/盘中交易 → 场内 ETF；长期定投 → 场外联接 |
| "适合什么投资者" | 风险特征层 | 给出波动/回撤画像，明确"不适合作为低波稳健工具" |

**禁止行为**：
- 禁止凭印象编基金代码、产品名称、管理人——必须用 `portfolio_get_buyable_funds` + `fund_theme_screening` / `simple_fund_search` 实查。
- 禁止把卖方研报口径当作"客观事实"——研报偏乐观，要用 `news_search` 交叉验证。
- 禁止给具体的星级评分（★★★★这种）——simworld 没有那个打分接口；给定性结论。
- 禁止把催化剂等同于必涨——催化只提高关注度，不替代估值与基本面判断。

## 六、风险提示（研究港股创新药时容易踩的坑）

1. **名字陷阱**：很多基金名字带"医药/医疗/健康"但港股创新药含量极低（重仓 A 股 CXO 或医疗器械）。必须查 `get_fund_industry_holding` 和 `get_fund_top_stocks`。
2. **指数陷阱**：「港股通创新药」「恒生医疗保健」「恒生医药」是完全不同的指数，成分和风格差异极大。看清楚基金跟踪的是哪一个。
3. **估值陷阱**：用 PE 估 Biotech 失真（很多公司亏损，PE 是负的或极高）。要用 PS、管线 NPV、license-out 累计金额这些组合估值。
4. **周期错判**：在 2021 年泡沫顶部加仓（估值已透支）、在 2022-2023 下行段过早抄底（利率还在压制）、在 2024 复苏初期下车（错过最大涨幅）。看大周期信号必须组合判断。
5. **催化剂兑现陷阱**：临床数据读出"超预期"也可能开盘高开低走（预期已 priced in）；BD 大单签了也可能因为后续里程碑达成度低而被反复消化。事件交易要看「事件 vs 预期」差异，不是事件本身。
6. **流动性陷阱**：港股创新药小盘股流动性差，单日成交可能只有几千万港币。基金重仓个股流动性差会放大净值波动。
7. **政策风险**：医保谈判降价幅度、CDE 审评政策、中美生物医药相关出口管制、PE/VC 投资监管等都对赛道有强影响。
8. **汇兑风险**：港股以港币计价，对人民币持有人有额外的 HKD/CNY 汇率波动。如果是 QDII 还有汇兑限额风险。
