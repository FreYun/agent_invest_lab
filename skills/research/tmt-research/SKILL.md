# TMT 行业研究指南

## 用法

这是一份**思考框架**，不是数据接口。看完它之后，回到 simworld-data MCP 工具去查具体数据，把数据填到框架的位置上，再做判断。

调用顺序大致是：
1. 先 load 这份 skill，记下要研究的子赛道和关键指标。
2. 用 `research_search` 拉对应赛道的研报、新闻（query 用本文给出的关键词）。
3. 用 `stock_alpha` / `fund_industry_exposure` / `market_index_quote` 查具体公司/基金/行业指数。
4. 回到本文的"周期位置判断"那节，对照数据下结论。

## 一、TMT 拆细分（六个子赛道）

把 TMT 当一个整体看会失真——各子赛道的周期、估值锚、催化剂完全不同。研究前先确认你看的是哪个：

| 子赛道 | 核心驱动 | A 股代表行业指数/概念 | 关键观察点 |
|---|---|---|---|
| 半导体 | 全球库存周期 + 国产替代 + AI 算力需求 | 申万半导体、中证芯片 | 全球半导体销售额 YoY、SOX 指数、晶圆代工稼动率、设备订单 |
| AI / 算力 | 训练/推理算力需求、模型迭代节奏 | AIGC 概念、算力概念、CPO | 北美云厂 capex guidance、国内 IDC 上架率、HBM/光模块价格 |
| 软件 / SaaS | 企业 IT 支出、订阅模式渗透率 | 中证软件、计算机应用 | 上市 SaaS 公司 NDR、ARR 增速、订阅占比 |
| 消费电子 | 创新周期（iPhone / AI 终端 / XR）、消费力 | 申万消费电子、果链概念 | iPhone 出货量、AI 手机渗透率、面板价格 |
| 媒体 / 游戏 / 广告 | 内容供给、用户时长、广告主预算 | 中证传媒、游戏 ETF | 版号节奏、游戏流水、广告 RPM、剧集播放量 |
| 通信 / 运营商 | 资本开支周期、ARPU、5G/算力网络投入 | 中证 5G、电信运营 | 运营商 capex、5G/光纤渗透、IDC 上架率 |

**研究第一步永远是问**：我看的是哪个子赛道？它的核心驱动是什么？不要把"AI 算力"和"半导体周期"混着讲——前者是上行 alpha 故事，后者是周期 beta 故事，节奏经常错开。

## 二、周期位置判断（最关键一节）

TMT 不是一直涨的，它是 3-5 年一轮的**强周期**。判断错周期位置，比选错股要命。

按下面这个框架对每个子赛道独立判断：

### 半导体周期（最重要）
- **底部信号**：全球半导体销售 YoY 转负且持续 6+ 个月、晶圆厂稼动率跌破 75%、设备订单同比腰斩、龙头公司单季毛利探底。
- **复苏信号**：库存指标见底回升、稼动率重新 >85%、销售 YoY 由负转正、设备订单同比转正。
- **顶部信号**：销售 YoY >20%、稼动率满载（>95%）、设备订单创历史新高、市场开始用"长期需求"为远期估值找理由。
- **下行信号**：销售 YoY 见顶回落、稼动率松动、客户砍单传闻。

判完位置才能定策略：底部+复苏初期 = 加配；顶部+下行初期 = 减配/止盈；中段 = 持仓不动。

### AI / 算力周期
跟传统半导体周期**部分脱钩**，看的是另一组信号：
- 北美超大规模云厂年度 capex guidance 是否上修。
- 国产算力卡（昇腾、寒武纪等）出货节奏。
- 大模型新版本发布密度（密集发布 = 训练算力需求强）。
- HBM / 光模块价格、交付周期。

注意：AI 算力上行期，半导体里只有"AI 相关"（HBM、先进制程代工、光模块、CPO）受益，传统消费类芯片（MCU、电源管理）可能仍在去库存。

### 消费电子周期
看创新周期 + 消费力：
- 苹果创新周期：iPhone 大改款年、AI iPhone、Vision Pro 是否走通。
- 安卓阵营是否跟进新形态（折叠屏、AI 手机）。
- 消费力指标：社零消费电子分项、双十一/618 销售。

### 软件 / SaaS / 媒体游戏
- 软件 SaaS 跟企业 IT 支出走，宏观盈利好转半年后才会传到 SaaS NDR/ARR。
- 游戏跟版号节奏、内容供给走，强周期但短（半年到一年一轮）。
- 广告跟广告主预算走，是 GDP 增速的高 beta 品种。

## 三、竞争格局 / 护城河

判断个股 / 基金的重仓股是否有 alpha，看下面这些维度：

| 维度 | 半导体 / 算力 | 软件 / SaaS | 消费电子 | 媒体游戏 |
|---|---|---|---|---|
| 技术壁垒 | 制程、设备、IP | 工程效率、垂直 know-how | 创新设计、品牌 | 内容 IP、用户心智 |
| 客户粘性 | 验证周期长（1-2 年） | 切换成本高（数据 + 集成） | 中（消费决策快） | 强（IP / 关系网） |
| 规模效应 | 极强（资本支出门槛） | 强（边际成本低） | 中 | 中 |
| 国产替代逻辑 | 强（设备 / 材料 / EDA） | 弱-中（信创领域强） | 弱（已是中国主场） | 不适用 |

**研究个股时**：先问它在产业链哪个环节、有没有技术壁垒、客户切换成本多高。没有壁垒的"概念股"在周期下行期会比赛道指数跌得多得多。

## 四、关键指标速查

用 simworld-data 查时按下面这些指标拉数据：

**行业 beta 指标**：
- `market_index_quote` 拉行业指数走势（半导体、计算机、传媒、电子、通信指数）
- 行业指数 PE / PB 历史百分位（>80% 注意泡沫，<20% 注意低估）

**基金底层**（如果你研究 TMT 主题基金）：
- `fund_industry_exposure` 看基金真实行业暴露——很多名字带"科技"的基金重仓股其实是新能源 / 医药，**必须查实际暴露**，不能只看名字
- `fund_heavy_stocks` 看前十大重仓股、行业集中度
- `fund_turnover_rate` 看换手率（TMT 主题基金换手通常很高，>200% 算正常）

**个股 alpha 指标**：
- `stock_alpha` 看个股相对行业 / 大盘的超额
- 财务数据看营收增速、毛利率趋势、研发投入占比、订单/合同负债（前瞻指标）

**研报和新闻**：
- `research_search` query 关键词："半导体 库存"、"AI 算力 capex"、"国产替代"、"消费电子 创新"、"信创"、"游戏 版号"等
- 注意区分卖方研报口径（偏乐观）和实际产业链调研口径（更真实）

## 五、风险提示（研究 TMT 时容易踩的坑）

1. **概念股陷阱**：很多公司只是"沾边 AI"，没真实业务。看研报时优先看营收、订单、产能这些**已经发生的事**，少听"未来 3 年 CAGR" 这种故事。
2. **周期错判**：在半导体顶部加仓（最危险）；在复苏初期下车（错过最大涨幅）。看库存 + 销售 YoY + 稼动率三个指标交叉验证，单一信号不下结论。
3. **行业混淆**：TMT 主题基金重仓可能是新能源 / 医药 / 消费——只看名字会买错。一定查 `fund_industry_exposure` 看真实暴露。
4. **估值锚错位**：高景气子赛道（AI 算力）用 PE 估值会失真，看 EV/Sales 或市值/订单更合理。下行期才回到 PE 估值锚。
5. **政策风险**：游戏（版号）、教育（双减后已退出）、信创（推进节奏）、半导体（中美出口管制）都受政策强影响，研究时必须把政策变量单列考虑。

## 用完之后

研究完写 mem0：把你的 TMT 周期判断、看好/不看好的子赛道、关键 catalyst（哪些事件会触发你买入/卖出）落记忆，下次决策直接调用，不必每次重做。
